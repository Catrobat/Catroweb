O Pocket Code é o app principal do Catrobat. É um app grátis e de código aberto para criar jogos, animações e histórias interativas direto no seu celular ou tablet. Com o **sistema de programação com blocos** do Pocket Code, você monta projetos encaixando blocos de código – como as peças de um quebra-cabeça. Você não precisa saber programar, por isso ele é perfeito para iniciantes!

O Pocket Code vai além dos projetos digitais. Com os novos **recursos de makerspace**, você também pode criar **arquivos SVG para plotters de corte**. Assim, suas criações digitais viram objetos de verdade, e você descobre novas ideias além da tela.

Se você está aprendendo a programar, testando novas ideias ou ensinando programação, o Pocket Code é um jeito divertido e fácil de entrar no mundo da programação

[Mais informações](https://catrobat.org/pocket-code/)
