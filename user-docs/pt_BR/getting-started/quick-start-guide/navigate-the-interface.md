Quando você abre o Pocket Code, você vê esta tela inicial.

![Tela inicial](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Quando você abre o Pocket Code, você vê esta tela inicial.\
[Abrir imagem](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Ajuda](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
No canto de cima, à direita, tem um símbolo de que leva você à documentação do Catrobat, com dicas úteis para você.

![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Ao lado fica o menu.

Por ele, você chega fácil às configurações, onde pode mudar o idioma ou ligar extensões, como os blocos de plotter e outras.

![Ícone de editar](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Toque no ícone de editar para abrir a tela do projeto e continuar criando o seu projeto.

Embaixo, você vê o projeto que você editou por último.

![Começar o seu projeto](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Use o botão de executar para começar o seu projeto.

![Projetos no aparelho](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Tocando em “Projetos” no aparelho, você chega aos seus projetos salvos.

![Comunidade Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Se você quer conhecer e mexer em mais projetos de outras pessoas, toque em Comunidade Catrobat no Share.

Lá você encontra muitos projetos legais.

![Adicionar](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Se você quer criar um novo projeto, toque no ícone de mais.
