Quando você abre o Pocket Code, você vê esta tela inicial.

![Tela inicial](../../../media/getting-started/MainScreen-e1732269599192.jpg)

No canto de cima, à direita, tem um símbolo de ![Ajuda](../../../media/getting-started/Screenshot-2024-11-22-111748.png) que leva você à documentação do Catrobat, com dicas úteis para você.

Ao lado fica o menu ![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png). Por ele, você chega fácil às configurações, onde pode mudar o idioma ou ligar extensões, como os blocos de plotter e outras.

Embaixo, você vê o projeto que você editou por último. Toque no ícone de editar ![Ícone de editar](../../../media/getting-started/Screenshot-2024-11-22-111825.png) para abrir a tela do projeto e continuar criando o seu projeto.

Use o botão de executar ![Começar o seu projeto](../../../media/getting-started/Screenshot-2024-11-22-111818.png) para começar o seu projeto.

Tocando em “Projetos” no aparelho, você chega aos seus projetos salvos. ![Projetos no aparelho](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Se você quer conhecer e mexer em mais projetos de outras pessoas, toque em Comunidade Catrobat no Share. Lá você encontra muitos projetos legais. ![Comunidade Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Se você quer criar um novo projeto, toque no ícone de mais. ![Adicionar](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
