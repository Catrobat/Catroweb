Toque no botão de mais para adicionar uma nova figura ou um novo objeto ao seu projeto.

![Adicionar figura](../../../media/getting-started/FigurHinzufuegen.png)

No Pocket Code, você pode adicionar um personagem ou um objeto ao seu projeto de vários jeitos:

**Desenhar**: Você pode criar seu próprio personagem com o **Pocket Paint**. O Pocket Paint é um programa de desenho ([mais sobre o Pocket Paint](https://catrobat.org/pocket-paint/))

**Aparências**: Escolha um ator ou objeto de uma coleção de figuras prontas ([mais sobre a biblioteca de mídia](../elements/medialibrary.md)).

**Galeria**: Você pode escolher uma imagem da galeria do seu celular.

**Biblioteca**: Na biblioteca, você encontra atores e objetos que já estão programados, ou seja, que já têm um script. Escolha eles se quiser usar partes prontas no seu jogo (por exemplo, uma contagem regressiva) ([mais sobre a biblioteca](../elements/medialibrary.md#adicionar-um-objeto-da-biblioteca-de-mídia)).

**Câmera**: Você pode usar a câmera do seu aparelho para tirar uma foto e adicionar ela como personagem.

**Mochila**: A mochila está vazia agora. Você pode usar de novo os atores ou objetos que guardou na sua mochila. O script inteiro vem junto quando você tira da mochila ([mais sobre a mochila](../elements/backpack.md)).

**Atores e objetos locais**: Aqui você encontra personagens prontos para usar no seu projeto. Os atores e objetos locais funcionam como uma biblioteca de mídia offline: mesmo sem internet, você pode usar esses atores.

**Objeto vazio**: Adicione um objeto vazio, ou seja, um objeto sem aparência. Você pode programar esse objeto normalmente.

**Projetos locais**: Escolha um projeto. O primeiro ator dele vai para o seu projeto, junto com o script.
