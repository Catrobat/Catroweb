O Pocket Code é um app de programação visual para criar jogos, animações e histórias interativas direto no seu celular ou tablet. Você arrasta e solta “blocos” de código de um jeito fácil, então dá para criar seus projetos sem saber programar antes. É fácil adicionar sons, imagens e movimento para dar vida às suas ideias.

Este guia ajuda você a começar e explica como:

- usar as telas do app,
- criar o seu primeiro projeto,
- trabalhar com objetos e fundos,
- usar blocos para programar ações e
- salvar o seu projeto.

O Pocket Code é perfeito para iniciantes e professores. Ele ajuda na criatividade, a resolver problemas e a pensar com lógica.
