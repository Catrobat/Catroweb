![Quando a cena começar](../../../media/bricks/When_scene_starts_btn2.png)

Se você usar este bloco, o script começa na hora em que a cena começa. Uma cena é o começo do seu programa. Uma cena é uma tela nova no seu programa, onde outras coisas podem aparecer e coisas diferentes podem acontecer. Você pode ter muitas cenas para as diferentes partes do seu programa. Por exemplo: uma cena para a abertura, uma cena para o menu principal, uma para o primeiro nível, uma para o segundo nível e assim por diante. Em programas mais simples, uma cena só já basta. Aí o começo do seu programa também é o começo da cena.

Como todo script, este começa com um bloco de evento: o evento decide **quando** o script começa, e os blocos que vêm depois dizem para o programa **o que** fazer.
