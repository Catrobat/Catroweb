![Se, senão](../../../media/bricks/if_else_brick2.png)

*Confere se uma condição é verdadeira. Se for, faz uma lista de instruções. Se não for, faz outra lista. É como dar duas opções: “Se isto for verdade, faça isto; se não, faça aquilo.”*

![Começar a cena](../../../media/bricks/StartScene.png)

Quando a cena começa, a variável X recebe o valor 0.

![Se, senão](../../../media/bricks/IfElse.png)

Quando você toca no animal, o programa confere se X módulo 2 é verdadeiro, ou seja, se X é um número ímpar.

Se for, o som Tweet1 toca e a variável X aumenta em 1.

Se não for, ou seja, se X for par, só X aumenta em 1.

As instruções que vão acontecer ficam separadas por um “Fim do se”.
