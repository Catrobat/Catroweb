![Começar a plotar](../../../media/bricks/Start_to_plot.png)

Este bloco começa a plotagem enquanto o ator se move. É parecido com encostar a caneta no papel para começar a desenhar uma linha. Se você quer pausar o desenho e levar o ator para outro lugar, use o bloco “Parar de plotar”. Depois comece de novo com “Começar a plotar”.
