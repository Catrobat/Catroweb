![Definir a cor das partículas para “#ff0000”](../../../media/bricks/Set_particle_colour_to_ff0000.png)

Este bloco muda a cor das partículas que saem do ator. É como mudar a cor dos confetes de um lança-confete.

Um código de cor hexadecimal é um jeito de escrever cores com números hexadecimais. Ele tem seis caracteres, que podem ser números (0-9) ou letras (A-F). Normalmente o código começa com um “#”, assim: `#RRGGBB`.

- Os dois primeiros caracteres (`RR`) são a parte vermelha da cor.
- Os dois do meio (`GG`) são a parte verde.
- Os dois últimos (`BB`) são a parte azul.

Cada par de caracteres vai de `00` (nada daquela cor) até `FF` (o máximo daquela cor). Por exemplo:

`#000000` é preto (nenhuma cor).

`#FF0000` é vermelho puro.

`#00FF00` é verde puro.

`#0000FF` é azul puro.

`#FFFFFF` é branco (o máximo de vermelho, verde e azul).
