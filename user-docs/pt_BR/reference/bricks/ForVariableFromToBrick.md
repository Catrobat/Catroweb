![Para valores de](../../../media/bricks/for-values-from-brick.png)

Este bloco faz uma lista de instruções um certo número de vezes. Ele usa um contador que começa num valor e termina em outro. É como montar uma repetição em que você sabe direitinho quantas vezes ela vai acontecer.

Imagine que você tem uma lista de itens e quer fazer alguma coisa com cada um. Este bloco passa por cada item, um de cada vez, e faz a mesma coisa com todos.
