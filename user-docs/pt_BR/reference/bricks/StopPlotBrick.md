![Parar de plotar](../../../media/bricks/Stop_to_plot.png)

O bloco “Parar de plotar” pausa a plotagem. Assim você pode levar o ator para outro lugar ou terminar a plotagem. É como tirar a caneta do papel para mudar de lugar ou parar de desenhar. Quando você terminar a plotagem, pode usar o bloco “Salvar plotagem como SVG” para salvar o seu desenho como um arquivo SVG.
