![Colocar em x e y](../../../media/bricks/place_at_x_y_brick.png)

Leva o objeto para um lugar certo da tela, que você escolhe com as coordenadas x e y. É como teletransportar o seu personagem para um ponto exato.

O lugar é marcado num sistema de coordenadas, como o plano cartesiano: os eixos x e y passam pelo meio da tela. Então x = 0 e y = 0 é o meio da tela.
