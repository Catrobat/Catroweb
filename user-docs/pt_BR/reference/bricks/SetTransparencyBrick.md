![Definir a transparência para 50%](../../../media/bricks/Set_transparency_to_50_pct_.png)

Este bloco decide o quanto um ator é transparente. Com 0% ele aparece por inteiro, e com 100% ele fica totalmente transparente. É como ajustar o quanto dá para ver através de uma imagem.
