![Definir a cor da caneta para vermelho 0, verde 0, azul 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Este bloco muda a cor da caneta que o ator usa. É como trocar de caneta colorida enquanto você desenha.

**Vermelho, verde, azul (RGB)**: o modelo de cores RGB mistura luz vermelha, verde e azul, mais forte ou mais fraca, para fazer muitas cores. Cada parte da cor (vermelho, verde e azul) pode ter um valor de 0 a 255:

- **Vermelho**: a parte vermelha da cor. Um valor maior quer dizer mais vermelho.
- **Verde**: a parte verde da cor. Um valor maior quer dizer mais verde.
- **Azul**: a parte azul da cor. Um valor maior quer dizer mais azul.

Misturando valores diferentes de vermelho, verde e azul, você pode fazer qualquer cor. Por exemplo:

- `RGB(255, 0, 0)` é vermelho puro.
- `RGB(0, 255, 0)` é verde puro.
- `RGB(0, 0, 255)` é azul puro.
- `RGB(255, 255, 255)` é branco (o máximo de vermelho, verde e azul).
- `RGB(0, 0, 0)` é preto (nenhuma cor).

Misturando essas cores em quantidades diferentes, você faz todas as cores que aparecem nas telas.
