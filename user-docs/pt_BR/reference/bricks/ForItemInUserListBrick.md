![Para cada valor da lista](../../../media/bricks/for-each-value_brick.png)

Este bloco faz uma lista de instruções para cada item de uma lista ou de um intervalo. É como passar por cada item, um de cada vez, e fazer a mesma coisa com todos.

Imagine que você tem uma lista de números, de cores ou de qualquer outra coisa. Este bloco pega cada item dessa lista e faz alguma coisa com ele. Por exemplo: se você tem uma lista de cores e quer mudar a cor do cenário para cada cor da lista, você usa este bloco.

É como dizer: “Para cada item deste grupo, faça estas instruções.”
