Este bloco troca o cenário por um cenário certo, escolhido pelo número dele na lista de cenários. Depois ele espera a troca terminar antes de continuar o script. É como escolher um fundo de uma lista numa peça de teatro e parar a ação até o cenário novo ficar pronto.
