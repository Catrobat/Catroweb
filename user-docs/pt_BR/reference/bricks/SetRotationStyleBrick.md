![Definir o estilo de rotação](../../../media/bricks/set_rotation_style_brick2.png)

Muda o jeito que o objeto gira (gira em todas as direções, só esquerda e direita, ou não gira). É como decidir se o seu personagem pode dar uma volta inteira, só virar para a esquerda e para a direita, ou não girar nada.
