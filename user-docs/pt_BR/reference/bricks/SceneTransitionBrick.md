![Continuar a cena](../../../media/bricks/continue_scene_brick2.png)

Este bloco continua a cena do ponto onde ela parou. Se a sua cena parou por causa de uma pausa ou de uma espera, este bloco faz a ação continuar bem de onde parou.

Imagine que você pausou um jogo ou uma animação e agora quer que continue. Este bloco funciona como o botão de “play”: tudo continua do ponto onde parou.
