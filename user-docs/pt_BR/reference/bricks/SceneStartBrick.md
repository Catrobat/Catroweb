![Começar a cena](../../../media/bricks/start_scene_brick2.png)

Este bloco troca para outra cena do seu projeto e começa essa cena do início. É como mudar de capítulo num livro ou passar para o próximo nível num jogo.

Imagine que o seu projeto tem várias cenas, e cada uma é uma parte diferente da sua história ou do seu jogo. Com este bloco, você pula para qualquer cena e começa ela do comecinho. Assim a passagem entre as partes do seu projeto fica bem suave.
