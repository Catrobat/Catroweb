![Mover passos](../../../media/bricks/move-brick.png)

Move o objeto alguns passos para o lado para onde ele está virado. É como pedir para um personagem dar um certo número de passos para a frente. No Embroidery Designer, 10 passos são 2 mm (1 cm são 50 passos).
