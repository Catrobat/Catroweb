![Fazer o efeito de partículas aparecer](../../../media/bricks/Fade_particle_effect_in.png)

Este bloco coloca partículas no seu personagem e faz elas sumirem aos poucos. Use, por exemplo, para fazer fogos de artifício, colocar fumaça ou fazer o seu personagem aparecer bem rápido.
