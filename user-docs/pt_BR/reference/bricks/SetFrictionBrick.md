![Definir o atrito](../../../media/bricks/set_friction_to_brick2.png)

Muda o atrito do objeto. O atrito decide se o objeto escorrega fácil ou se ele vai parando. É como mudar o quanto o chão do seu personagem é escorregadio: mais atrito quer dizer que ele escorrega menos.
