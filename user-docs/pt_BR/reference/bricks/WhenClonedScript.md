![Quando você começar como clone](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Dá instruções para um clone de um objeto fazer o que você quer. Assim o clone pode fazer as mesmas coisas que o objeto original, mas você controla o clone sozinho. Você pode escolher vários comportamentos ou características para o clone, do jeito que precisar.
