Este bloco faz uma cópia do objeto que você escolher. Essa cópia se chama clone e funciona igual ao original. Imagine copiar um personagem ou um objeto do seu jogo. O clone pode ter os seus próprios comportamentos e scripts. Assim você pode ter várias cópias de um objeto, e cada uma age sozinha.
