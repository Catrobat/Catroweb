Quando a plotagem começa, cada movimento é desenhado como se fosse com uma caneta. São essas as linhas que o plotter vai cortar depois.

Esta estrela tem 6 pontas. Uma ponta é uma linha reta ("Mover 100 passos"), uma virada e mais uma linha reta que termina a forma da ponta. Antes da próxima ponta, você tem que virar para o outro lado, para que a próxima ponta saia certa.

***Observação**: Uma volta inteira tem 360°. Em cada ponta, viramos 100° para a direita e 40° para a esquerda, ou seja, 60° para a direita no total.*

*Com as seis pontas, viramos 360° para a direita.*

**Vá além**: Teste outras combinações de viradas e mude o número de pontas.
