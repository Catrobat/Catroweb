Quando a plotagem começa, cada movimento é desenhado como se fosse com uma caneta. São essas as linhas que o plotter vai cortar depois.

Esta flor tem 7 pétalas. Cada pétala é um arco: você desenha uma linha bem pequena, vira, desenha outra linha bem pequena e vira de novo (veja a repetição "Repetir 10 vezes" – "Mover 10 passos" – "Virar à direita 16 graus").

Antes de começar a próxima pétala, você tem que virar mais uma vez.
