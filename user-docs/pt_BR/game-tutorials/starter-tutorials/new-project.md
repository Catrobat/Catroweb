### 1. Instalar o Pocket Code

Primeiro, instale o app Pocket Code no seu aparelho. Para isso, você precisa de uma conta do Google. Agora o seu aparelho baixa e instala o app. Isso pode demorar um pouco, dependendo da sua internet.

![Novo programa (2)](../../../media/game-tutorials/New-Program-2.png)\
Procure “Pocket Code” na Google Play Store e baixe o app tocando em “Instalar”.\
[Abrir imagem](../../../media/game-tutorials/New-Program-2.png)

Depois de baixar e instalar o Pocket Code, você encontra o app na lista de apps ou na tela inicial, dependendo do seu aparelho. Você pode pegar o app e colocar onde quiser.

### 2. Abrir o app

![Novo programa (1)](../../../media/game-tutorials/New-Program-1.png)\
Quando você abre o app, você vê várias categorias.\
[Abrir imagem](../../../media/game-tutorials/New-Program-1.png)

### 3. Criar um novo projeto

Agora vamos criar um novo projeto de verdade. Digite um nome para o projeto e escolha se ele vai ficar deitado (paisagem) ou não. Tocando em “OK”, o projeto é criado.

![Novo programa](../../../media/game-tutorials/New-Program.png)\
Para isso, toque no botão amarelo de mais, no canto de baixo à direita.\
[Abrir imagem](../../../media/game-tutorials/New-Program.png)

### 4. Você conseguiu! Você criou o seu próprio projeto novo.

Agora você instalou o Pocket Code e sabe criar um novo projeto. Agora você pode começar a programar!

Para isso, você precisa saber como criar um novo objeto num projeto. Veja o tutorial **[Novo objeto](new-object.md)**, que explica tudo passo a passo.
