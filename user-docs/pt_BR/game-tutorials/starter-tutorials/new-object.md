Neste tutorial, você aprende a criar um novo objeto no seu projeto e as várias formas de fazer isso.

![Novo objeto](../../../media/game-tutorials/New-Object.png)

Para isso, você já precisa ter baixado o app Pocket Code e saber criar um novo projeto. Se precisar de ajuda, veja o tutorial **[Novo projeto](new-project.md)**.

*Aqui você pode baixar o tutorial em PDF:*

[Novo objeto](../../../media/game-tutorials/New-Object.pdf)

### 1. Criar um novo objeto

Primeiro, abra o seu novo projeto.

Você encontra ele na tela inicial do app Pocket Code. Se você tem mais de um projeto, toque em “Projetos”. Depois escolha o seu novo projeto. Se você ainda não criou um projeto ou quer saber como fazer isso, veja o tutorial **[Novo projeto](new-project.md)**.

### 2. Criar um novo objeto

Agora você pode criar um novo objeto. Para isso, toque no botão amarelo de mais, no canto de baixo à direita. Vai abrir uma janela nova com sete opções para escolher.

![Novo objeto (1)](../../../media/game-tutorials/New-Object-1.png)

### 4. Desenhar uma imagem

Para começar do jeito mais fácil, vamos usar a função “Desenhar” e desenhar só um ponto. Quando você terminar o ponto no Pocket Paint, pode sair dele (voltando um passo).

### 5. Dar um nome

Agora dê um nome para a sua imagem.

### 6. Colocar no lugar

Depois, coloque a imagem no lugar arrastando ela com o dedo para a esquerda, direita, para cima ou para baixo. Salve com o botão no canto de cima à direita.

![Novo objeto (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. Você conseguiu! Você criou o seu próprio objeto novo.

Agora você tem um projeto com um objeto que pode programar!

Para isso, é bom saber quais blocos existem. O tutorial **[Primeiros blocos](first-bricks.md)** mostra bem as categorias de blocos. Mas você também pode começar direto o seu primeiro projeto. Escolha um tutorial da série para iniciantes.
