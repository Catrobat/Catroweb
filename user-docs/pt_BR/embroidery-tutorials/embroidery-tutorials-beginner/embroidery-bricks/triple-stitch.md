O ponto triplo costura cada ponto três vezes.

Depois do primeiro ponto, o ponto triplo pula para trás, dá um ponto, pula para a frente de novo e dá mais um ponto.

![Iniciar ponto triplo com comprimento 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Funciona igual ao [ponto corrido](running-stitch.md).

![Ponto triplo](../../../../media/embroidery-tutorials/TripleStitch.png)

Assim a costura dura mais.
