A máquina borda sem parar, com um comprimento que você escolhe.

Normalmente, você usa o ponto corrido junto com um bloco de mover.

![Iniciar ponto corrido com comprimento 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

A máquina começa um ponto corrido que dá um ponto a cada **10 passos**.

Depois, a máquina se move **200 passos**.

Isso dá **20 pontos**.

![Ponto corrido](../../../../media/embroidery-tutorials/RunningStitch.png)

Com o ponto corrido fica mais fácil fazer uma costura, porque você não precisa mais de um laço de repetição.
