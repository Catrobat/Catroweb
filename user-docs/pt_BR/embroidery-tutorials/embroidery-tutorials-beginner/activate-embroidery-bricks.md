Neste tutorial, você vai aprender a ativar os blocos de bordado.

![Ativar os blocos de bordado 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Você não precisa saber programar para isso. Este é o primeiro passo para começar os tutoriais de bordado. Depois, você pode criar, programar e até bordar os seus próprios desenhos na sua peça de roupa favorita.

Para mais informações ou ideias de desenhos, veja os outros tutoriais.

*Aqui você pode baixar o tutorial em PDF*:

[Ativar os blocos de bordado](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Abra o app “Pocket Code”. Siga os toques!

### 2. Abra o menu (os pontinhos no canto de cima à direita).

![Ativar os blocos de bordado](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Vá em “Configurações”.

![Ativar os blocos de bordado 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Escolha “Extensão de bordado”.

![Ativar os blocos de bordado 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Agora os blocos de bordado aparecem como uma categoria própria entre os seus blocos!

[![Ativar os blocos de bordado 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Agora você também encontra todos os blocos de bordado junto com os outros blocos.

Para saber mais sobre cada bloco, veja a documentação dos blocos [aqui](../../../reference/) ou siga o tutorial **[Blocos de bordado](embroidery-bricks/index.md)**.

Agora você já pode começar e criar os seus próprios desenhos!

Se precisar de ideias ou ajuda, veja os outros tutoriais ou continue com o tutorial **[Criar objetos de bordado](create-embroidery-objects.md)**.
