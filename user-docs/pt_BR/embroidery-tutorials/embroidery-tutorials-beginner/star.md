Neste tutorial, você vai aprender a bordar uma estrela (57 x 60 mm).

![imagem (5)](../../../media/embroidery-tutorials/image-5.png)

Você já deve saber criar um novo objeto e colocar blocos nele. Se ainda precisar de ajuda, veja os tutoriais da [série Primeiros passos](../../game-tutorials/starter-tutorials/index.md). Os blocos de bordado também já precisam estar ativados. Você aprende como fazer isso no tutorial **[Ativar os blocos de bordado](activate-embroidery-bricks.md)**.

Para mais informações ou ideias de desenhos, veja os outros tutoriais.

### 2. Agora comece e coloque os blocos no seu script, um passo de cada vez.
