Neste tutorial, você vai aprender a criar objetos que depois vão bordar os seus desenhos.

Para este tutorial, você já deve saber criar um projeto. Se precisar de ajuda, veja os tutoriais da [série Primeiros passos](../../game-tutorials/starter-tutorials/index.md).

Para mais informações ou ideias de desenhos, veja os outros tutoriais.

*Aqui você pode baixar o tutorial em PDF*:

[Criar objetos de bordado](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Toque no botão de mais, embaixo à direita no seu projeto, para adicionar um novo objeto.

![Criar objetos de bordado](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Para escolher uma imagem, vá até a biblioteca de mídia.

![Criar objetos de bordado (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Um objeto de bordado é uma camada da agulha da máquina de bordar. Vários objetos de bordado são bordados um depois do outro. Assim você pode usar várias cores.

Você pode escolher o seu objeto pela cor que quiser.

Role para baixo e procure a seta certa.

![Criar objetos de bordado (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Dê um nome bom para o seu novo objeto e toque em OK.

![Criar objetos de bordado (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Pronto, você criou um novo objeto. Agora você pode adicionar um script e programar o objeto.

![Criar objetos de bordado (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Agora você sabe criar um objeto. Adicione um novo objeto para cada cor que você quer usar.

Você pode adicionar um script em cada cor, programar os seus próprios desenhos e até bordá-los depois.
