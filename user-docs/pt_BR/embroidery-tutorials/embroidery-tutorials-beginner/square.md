Neste tutorial, você vai aprender a bordar um quadrado (60 x 60 mm).

![imagem (3)](../../../media/embroidery-tutorials/image-3.png)

Você já deve saber criar um novo objeto e colocar blocos nele. Se ainda precisar de ajuda, veja os tutoriais da [série Primeiros passos](../../game-tutorials/starter-tutorials/index.md). Os blocos de bordado também já precisam estar ativados. Você aprende como fazer isso no tutorial **[Ativar os blocos de bordado](activate-embroidery-bricks.md)**.

Para mais informações ou ideias de desenhos, veja os outros tutoriais.

*Aqui você pode baixar o tutorial em PDF*:

[Quadrado](../../../media/embroidery-tutorials/Square.pdf)

### 1. Crie um novo objeto de bordado (veja [Criar objetos de bordado](create-embroidery-objects.md)).

### 2. Agora comece e coloque os blocos no seu script, um passo de cada vez.

![Quadrado](../../../media/embroidery-tutorials/Square.png)

Um quadrado é feito de quatro linhas que se encontram num ângulo de 90°.

Primeiro, o script começa o ponto corrido. Depois, ele move a agulha 300 passos e gira 90°. Isso se repete 4 vezes.

O que acontece se você mudar o ângulo ou os passos? **Teste!**

### 3. Toque em Executar para começar o seu desenho!
