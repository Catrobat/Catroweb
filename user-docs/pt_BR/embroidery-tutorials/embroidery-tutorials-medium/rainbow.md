Neste tutorial, você vai aprender a bordar um arco-íris (112 x 57,2 mm).

![Arco-íris](../../../media/embroidery-tutorials/Regenbogen.webp)

Você já deve saber o que é um laço de repetição e como ele funciona.

O tutorial **[Semicírculo](../embroidery-tutorials-beginner/semicircle.md)** pode ajudar você neste tutorial.

Se você ainda não bordou nada, veja os tutoriais de bordado da série [Iniciante](../embroidery-tutorials-beginner/index.md).

Para mais informações ou ideias de desenhos, veja os outros tutoriais.

### 3. Copiar o objeto

Para o próximo arco, que é maior, você pode simplesmente copiar o objeto que acabou de criar.

Toque nos três pontinhos no canto de cima à direita da lista de objetos.

Depois vá em “Copiar” e escolha o objeto.

![Arco-íris (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Se você usar um objeto diferente para cada arco, depois pode bordar cada um com uma cor diferente.

### 4. Ajustar o objeto

Para os arcos ficarem de tamanhos diferentes, precisamos mudar alguns valores.

Para isso, vá até o script do objeto copiado e mude estes valores:
