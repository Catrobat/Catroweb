Pocket Code er en app til visuel programmering, der lader dig lave spil, animationer og interaktive historier direkte på din smartphone eller tablet. Med en intuitiv træk-og-slip-grænseflade med “klodser” (kodeblokke) kan du designe dine projekter uden programmeringserfaring. Du kan nemt tilføje lyde, billeder og bevægelse for at få dine idéer til at leve.

Denne guide hjælper dig i gang ved at forklare, hvordan du:

- Navigerer i grænsefladen,
- Opretter dit første projekt,
- Arbejder med objekter og baggrunde,
- Bruger klodser til at programmere handlinger, og
- Gemmer dit projekt.

Pocket Code er perfekt til begyndere og undervisere, og den fremmer kreativitet, problemløsning og logisk tænkning.
