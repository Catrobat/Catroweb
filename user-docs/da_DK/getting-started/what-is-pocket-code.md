Pocket Code er Catrobats hovedapp, en gratis mobilapp med åben kildekode, der lader dig lave spil, animationer og interaktive historier direkte på din smartphone eller tablet. Med Pocket Codes **klodsbaserede kodesystem** kan du bygge projekter ved at klikke kodeklodser sammen, ligesom når du sætter brikker sammen i et puslespil. Du behøver ingen programmeringserfaring, så appen er perfekt til begyndere!

Pocket Code rækker ud over digitale projekter. Med nye **makerspace-funktioner** kan du også designe **SVG-filer til skæreplottere**. Det betyder, at du kan omdanne dine digitale kreationer til ting i den virkelige verden og udforske kreative muligheder ud over skærmen.

Uanset om du lærer at kode, eksperimenterer med nye idéer eller underviser i programmering, giver Pocket Code dig en legende og let adgang til kodning.

[Mere information](https://catrobat.org/pocket-code/)
