![Vent, indtil alle andre scripts er stoppet](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Denne klods sætter det aktuelle script på pause, indtil alle andre scripts i projektet er færdige. Forestil dig, at du sætter dit script på vent, indtil alt andet er færdigt. Det er nyttigt for at sikre, at der ikke sker andre handlinger, før du går videre med de næste trin i dit aktuelle script.
