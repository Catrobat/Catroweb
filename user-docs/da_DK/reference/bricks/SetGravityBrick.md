![Sæt tyngdekraft for alle objekter](../../../media/bricks/set-gravity-brick.png)

Justerer tyngdekraften for alle objekter i projektet. Det er som at ændre, hvor kraftigt tingene bliver trukket nedad eller sidelæns af tyngdekraften, så det påvirker, hvordan de falder eller bevæger sig.
