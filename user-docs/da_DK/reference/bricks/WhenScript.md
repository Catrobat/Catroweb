Kører scriptet, når objektet bliver trykket på. Forskellen til klodsen *“Når der trykkes på spillefladen”* er, at *“Når der trykkes på dig”* gælder for bestemte figurer eller objekter, mens *“Når der trykkes på spillefladen”* gælder for hele skærmen.
