Det tredobbelte sting syr hvert sting tre gange.

Det tredobbelte sting hopper tilbage efter det første sting, syr, hopper derefter frem igen og syr endnu en gang.

![Start tredobbelt sting med længden 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Virker på samme måde som [forsting](running-stitch.md).

![Tredobbelt sting](../../../../media/embroidery-tutorials/TripleStitch.png)

Det gør sømmen mere holdbar.
