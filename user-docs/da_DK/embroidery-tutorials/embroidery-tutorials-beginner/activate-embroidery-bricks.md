I denne vejledning forklares det, hvordan du aktiverer broderiklodser.

![Aktivér broderiklodser](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Du behøver ingen programmeringskendskab til dette. Det er det første skridt i broderivejledningerne. Senere kan du designe, programmere og endda brodere dine egne designs på dit yndlingsstykke tøj.

For mere information eller designforslag kan du tjekke de andre vejledninger.

*Her kan du downloade vejledningen i PDF-format*:

[Aktivér broderiklodser](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Start appen “Pocket Code”. Følg klikkene!

### 2. Åbn menuen (prikkerne øverst til højre).

![Aktivér broderiklodser](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Gå til “Indstillinger”.

![Aktivér broderiklodser (3)](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Vælg “Broderiudvidelse”.

![Aktivér broderiklodser (4)](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Du finder broderiklodserne som en egen kategori blandt dine klodser!

[![Aktivér broderiklodser (5)](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Nu finder du også alle broderiklodser blandt de andre klodser.

For mere information om hver klods kan du tjekke dokumentationen for klodserne [her](../../../reference/) eller følge vejledningen **[Broderiklodser](embroidery-bricks/index.md)**.

Nu kan du gå i gang og lave dine egne designs!

Har du brug for idéer eller hjælp til det, så tjek de andre vejledninger, eller fortsæt med vejledningen **[Lav broderiobjekter](create-embroidery-objects.md)**.
