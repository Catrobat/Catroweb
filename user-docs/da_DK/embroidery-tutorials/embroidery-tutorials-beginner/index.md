Har du lyst til at være kreativ og samtidig lære at kode på en legende måde? Kan du også lide at lave ting, som du kan bruge, have på og se på med det samme?

Med Embroidery Designer kan du uden forudgående erfaring programmere en broderimaskine, der automatisk broderer dit design på en T-shirt, taske, bukser, telefoncover eller endda dine sko. Du kan brodere på alt, der er lavet af stof. Lad din fantasi og kreativitet få frit spil! Du kan downloade og redigere andres designs fra Catrobat-fællesskabet. Og selvfølgelig kan du også dele dine projekter med dine venner og hele verden!
