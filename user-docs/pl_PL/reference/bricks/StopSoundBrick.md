![Zatrzymaj dźwięk](../../../media/bricks/Stop_sound_record.png)

Ten klocek zatrzymuje odtwarzanie konkretnego dźwięku. To jak naciśnięcie przycisku stop tylko dla jednej piosenki, podczas gdy inne dźwięki albo muzyka grają dalej. Wyobraź sobie, że mówisz swojej postaci, żeby przestała odtwarzać jedną konkretną ścieżkę.
