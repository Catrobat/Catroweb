![Ustaw kolor pisaka na czerwony 0, zielony 0, niebieski 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Ten klocek zmienia kolor pisaka, którym rysuje postać. To jak przełączenie na inny kolor długopisu podczas rysowania.

**Czerwony, zielony, niebieski (RGB)**: Model kolorów RGB używa różnych natężeń czerwonego, zielonego i niebieskiego światła, żeby stworzyć szerokie spektrum kolorów. Każda składowa koloru (czerwona, zielona i niebieska) może mieć wartość od 0 do 255:

- **Czerwony**: Składowa czerwona koloru. Większa wartość oznacza więcej czerwieni.
- **Zielony**: Składowa zielona koloru. Większa wartość oznacza więcej zieleni.
- **Niebieski**: Składowa niebieska koloru. Większa wartość oznacza więcej błękitu.

Łącząc różne wartości czerwonego, zielonego i niebieskiego, możesz stworzyć dowolny kolor. Na przykład:

- `RGB(255, 0, 0)` to czysty czerwony.
- `RGB(0, 255, 0)` to czysty zielony.
- `RGB(0, 0, 255)` to czysty niebieski.
- `RGB(255, 255, 255)` to biel (maksimum czerwonego, zielonego i niebieskiego).
- `RGB(0, 0, 0)` to czerń (brak koloru).

Mieszanie tych kolorów w różnych proporcjach tworzy wszystkie kolory, które widzisz na ekranach cyfrowych.
