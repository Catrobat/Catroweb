![Przestań rysować ploterem](../../../media/bricks/Stop_to_plot.png)

Klocek „Przestań rysować ploterem” wstrzymuje proces rysowania i pozwala przesunąć postać w nowe miejsce albo zakończyć rysowanie. To jak uniesienie pisaka znad papieru, żeby go przestawić albo przestać rysować. Kiedy skończysz rysować, możesz użyć klocka „Zapisz rysunek plotera jako SVG”, żeby zapisać swój projekt jako plik SVG.
