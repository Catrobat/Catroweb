![Kiedy zaczynasz jako klon](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Nadaje utworzonemu klonowi obiektu polecenia, żeby wykonał pożądane czynności. Dzięki temu można odtworzyć działanie oryginalnego obiektu, a jednocześnie sterować klonem niezależnie. Można określić różne zachowania albo właściwości klonu, żeby spełnić konkretne wymagania.
