### 1. Instalacja Pocket Code

Najpierw musisz zainstalować aplikację Pocket Code na swoim urządzeniu. Do tego kroku potrzebne jest konto Google. Urządzenie pobierze i zainstaluje aplikację. Ten krok może chwilę potrwać, zależnie od twojego internetu.

![Nowy program (2)](../../../media/game-tutorials/New-Program-2.png)\
Znajdziesz ją, wpisując „Pocket Code” w Sklepie Google Play, a potem kliknij „Zainstaluj”.\
[Otwórz obraz](../../../media/game-tutorials/New-Program-2.png)

Po pobraniu i zainstalowaniu Pocket Code znajdziesz aplikację w szufladzie aplikacji albo na ekranie głównym, zależnie od urządzenia. Możesz ją przenieść w dowolne miejsce.

### 2. Uruchom aplikację

![Nowy program (1)](../../../media/game-tutorials/New-Program-1.png)\
Kiedy otworzysz aplikację, zobaczysz różne kategorie.\
[Otwórz obraz](../../../media/game-tutorials/New-Program-1.png)

### 3. Stwórz nowy projekt

Następny krok to stworzenie nowego projektu. Teraz wpisz nazwę projektu i wybierz, czy projekt ma być poziomy, czy nie. Naciśnij „OK” i projekt zostanie stworzony.

![Nowy program](../../../media/game-tutorials/New-Program.png)\
W tym celu naciśnij żółty przycisk plus w prawym dolnym rogu.\
[Otwórz obraz](../../../media/game-tutorials/New-Program.png)

### 4. Udało się! Stworzyłeś swój nowy projekt.

Teraz zainstalowałeś Pocket Code i wiesz, jak stworzyć nowy projekt. Możesz zacząć programować!

Żeby to robić, musisz wiedzieć, jak stworzyć nowy obiekt w projekcie. Zajrzyj do samouczka **[Nowy obiekt](new-object.md)**, gdzie wszystko jest krok po kroku wyjaśnione.
