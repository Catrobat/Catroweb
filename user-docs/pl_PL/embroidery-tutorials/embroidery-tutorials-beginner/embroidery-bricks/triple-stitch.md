Ścieg potrójny szyje każdy ścieg trzy razy.

Ścieg potrójny cofa się po pierwszym ściegu, szyje, potem znów przesuwa się do przodu i szyje ponownie.

![Zacznij ścieg potrójny](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Działa tak samo jak [ścieg prosty](running-stitch.md).

![Ścieg potrójny](../../../../media/embroidery-tutorials/TripleStitch.png)

Dzięki temu szew wytrzyma dłużej.
