Pozwala maszynie szyć nieprzerwanie o zmiennej długości.

Zwykle łączysz ścieg prosty z klockiem ruchu.

![Zacznij ścieg prosty](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Maszyna zaczyna ścieg prosty, który będzie wykonywać co **10 kroków**.

Potem maszyna przesuwa się o **200 kroków**.

W efekcie wychodzi **20 ściegów**.

![Ścieg prosty](../../../../media/embroidery-tutorials/RunningStitch.png)

Ścieg prosty ułatwia szycie szwu, bo nie potrzebujesz już pętli.
