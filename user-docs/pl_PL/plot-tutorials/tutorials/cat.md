Kiedy ploter się uruchomi, każdy ruch jest rysowany jak pisakiem. Są to linie, po których ploter później wytnie.

Nasz obiekt jest skierowany w kierunku 150 stopni.

W tym samouczku najpierw robimy prawą stronę głowy kota. Jeśli przyjrzysz się uważnie, krzywizna na początku jest duża, więc obiekt musi skręcać mocniej po każdej małej linii. Potem zakręty są mniejsze w dolnej części głowy. Lewa strona głowy znowu jest mocno zakrzywiona. Dlatego ta część głowy ma w sumie trzy pętle.

Potem robimy lewe ucho. Składa się tylko z prostych linii, więc możemy użyć klocka „Przesuń o __ kroków”.

Część między uszami znowu jest łukiem i programujemy ją kolejną pętlą.

Potem robimy prawe ucho.

Rysunek jest już gotowy. Zakończ go klockiem „Przestań rysować ploterem” i zapisz w telefonie przyciskiem „Zapisz rysunek plotera jako SVG”.

Teraz możesz wysłać plik SVG do plotera (tnącego).
