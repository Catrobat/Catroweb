Pocket Code to główna aplikacja Catrobat, darmowa aplikacja mobilna o otwartym kodzie, która pozwala tworzyć gry, animacje i interaktywne historie prosto na smartfonie albo tablecie. Korzystając z **systemu programowania klockowego** Pocket Code, możesz budować projekty, łącząc bloki kodu – jak układanie puzzli. Nie potrzebujesz żadnego doświadczenia w programowaniu, więc to idealne rozwiązanie dla początkujących!

Pocket Code to coś więcej niż cyfrowe projekty. Dzięki nowym **funkcjom makerspace** możesz też projektować **pliki SVG dla ploterów tnących**. Oznacza to, że możesz zamienić swoje cyfrowe pomysły w prawdziwe przedmioty i odkrywać twórcze możliwości poza ekranem.

Niezależnie od tego, czy uczysz się programować, testujesz nowe pomysły, czy uczysz innych programowania, Pocket Code daje ci zabawny i łatwy sposób na wejście w świat kodowania.

[Więcej informacji](https://catrobat.org/pocket-code/)
