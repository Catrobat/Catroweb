Dotknij przycisku plus, żeby dodać nową postać albo obiekt do swojego projektu.

![Dodawanie figury](../../../media/getting-started/FigurHinzufuegen.png)

W Pocket Code możesz dodać postać albo obiekt do swojego projektu na różne sposoby:

**Rysuj**: Możesz stworzyć własną postać w **Pocket Paint**. Pocket Paint to program do rysowania ([więcej o Pocket Paint](https://catrobat.org/pocket-paint/))

**Wygląd**: Wybierz jedną z gotowych postaci i obiektów ([więcej o bibliotece mediów](../elements/medialibrary.md)).

**Galeria**: Możesz wybrać obraz z galerii swojego smartfona.

**Biblioteka**: W bibliotece znajdziesz postacie i obiekty, które są już zaprogramowane, czyli mają już skrypt. Możesz je wybrać, jeśli chcesz użyć gotowych elementów w swojej grze (np. odliczania) ([więcej o bibliotece](../elements/medialibrary.md#dodaj-obiekt-z-biblioteki-mediów)).

**Kamera**: Możesz użyć aparatu w swoim urządzeniu, żeby zrobić zdjęcie i dodać je jako postać.

**Plecak**: Plecak jest na razie pusty. Możesz ponownie użyć postaci albo obiektów, które zapisałeś w plecaku. Cały skrypt zostanie wtedy wypakowany razem z nią ([więcej o plecaku](../elements/backpack.md)).

**Lokalne postacie i obiekty**: Tutaj znajdziesz gotowe postacie, których możesz użyć w swoim projekcie. Lokalne postacie i obiekty działają jak biblioteka offline, więc możesz z nich korzystać, nawet jeśli nie masz połączenia z internetem.

**Pusty obiekt**: Dodaj pusty obiekt, czyli obiekt, który nie ma wyglądu. Możesz go programować tak samo jak inne obiekty.

**Projekty lokalne**: Wybierz projekt, z którego chcesz wstawić pierwszą postać razem ze skryptem do swojego projektu.
