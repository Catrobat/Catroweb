Pocket Code to aplikacja do programowania wizualnego, która pozwala tworzyć gry, animacje i interaktywne historie bezpośrednio na smartfonie albo tablecie. Dzięki intuicyjnemu interfejsowi przeciągania i upuszczania **klocków** (bloków kodu) możesz projektować swoje projekty bez wcześniejszej wiedzy o programowaniu. Łatwo dodasz dźwięki, obrazy i ruch, żeby twoje pomysły ożyły.

Ten przewodnik pomoże ci zacząć, pokazując, jak:

- poruszać się po interfejsie,
- stworzyć swój pierwszy projekt,
- pracować z obiektami i tłami,
- używać klocków do programowania działań i
- zapisać swój projekt.

Pocket Code jest idealny dla początkujących i nauczycieli, a do tego rozwija kreatywność, umiejętność rozwiązywania problemów i logiczne myślenie.
