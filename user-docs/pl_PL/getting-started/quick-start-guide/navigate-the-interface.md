Kiedy uruchomisz Pocket Code, zobaczysz następujący ekran główny.

![Ekran główny](../../../media/getting-started/MainScreen-e1732269599192.jpg)

W prawym górnym rogu jest symbol ![Pomoc](../../../media/getting-started/Screenshot-2024-11-22-111748.png), który prowadzi do dokumentacji Catrobat, gdzie znajdziesz pomocne wskazówki.

Obok jest menu ![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png). Stamtąd łatwo przejdziesz do ustawień, gdzie możesz zmienić język albo włączyć rozszerzenia, na przykład klocki do ploterów i inne.

Poniżej widzisz swój ostatnio edytowany projekt. Kliknij ikonę edycji ![Ikona edycji](../../../media/getting-started/Screenshot-2024-11-22-111825.png), żeby otworzyć ekran projektu, gdzie możesz dalej rozwijać swój projekt.

Użyj przycisku play ![Uruchom swój projekt](../../../media/getting-started/Screenshot-2024-11-22-111818.png), żeby uruchomić swój projekt.

Kliknij „Projekty na urządzeniu”, żeby otworzyć zapisane projekty. ![Projekty na urządzeniu](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Jeśli chcesz poznać i pracować nad projektami innych użytkowników, kliknij „Społeczność Catrobat” w Share. Znajdziesz tam wiele świetnych projektów. ![Społeczność Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Jeśli chcesz stworzyć nowy projekt, kliknij ikonę plus. ![Dodaj](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
