Kiedy uruchomisz Pocket Code, zobaczysz następujący ekran główny.

![Ekran główny](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Kiedy uruchomisz Pocket Code, zobaczysz następujący ekran główny.\
[Otwórz obraz](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Pomoc](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
W prawym górnym rogu jest symbol, który prowadzi do dokumentacji Catrobat, gdzie znajdziesz pomocne wskazówki.

![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Obok jest menu.

Stamtąd łatwo przejdziesz do ustawień, gdzie możesz zmienić język albo włączyć rozszerzenia, na przykład klocki do ploterów i inne.

![Ikona edycji](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Kliknij ikonę edycji, żeby otworzyć ekran projektu, gdzie możesz dalej rozwijać swój projekt.

Poniżej widzisz swój ostatnio edytowany projekt.

![Uruchom swój projekt](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Użyj przycisku play, żeby uruchomić swój projekt.

![Projekty na urządzeniu](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Kliknij „Projekty na urządzeniu”, żeby otworzyć zapisane projekty.

![Społeczność Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Jeśli chcesz poznać i pracować nad projektami innych użytkowników, kliknij „Społeczność Catrobat” w Share.

Znajdziesz tam wiele świetnych projektów.

![Dodaj](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Jeśli chcesz stworzyć nowy projekt, kliknij ikonę plus.
