Кога започнува сюжетот, секој потег се црти како со перо. Ова се редови кои заговорникот ги пресече подоцна.

Оваа лисица е направена само од праве линии („Помести се \_\_\_ чекора“) и вртења.

**Написка**: Пробајте го твојот програм додека го градите.
