Во овој упатство ќе научите се што треба да знаете за Pocket Code за да започнете со создавање на твојот прв проект. Ќе ви ги водиме чекор по чекор како да ја преземете апликацијата, да ја отворите и да креирате нов проект.

![Нов програм](../../../media/game-tutorials/New-Program.png)\
Ќе ви ги водиме чекор по чекор како да ја преземете апликацијата, да ја отворите и да креирате нов проект.\
[Отвори ја сликата](../../../media/game-tutorials/New-Program.png)

Ова е првиот упатство, и не ви треба претходно знаење.

Па, на што чекаш? Земи го телефонот и почне веднаш!

*Овде можеш да го преземете наставникот во PDF-формат:*

[Отвори PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Инсталирање на Pocket Code

Прво, треба да инсталирате апликацијата Pocket Code на твојот уред. За овој чекор е потребна сметка на Google. Сега твојот уред ќе го преземе и инсталира апликацијата. Овој чекор може да потрае некое време во зависност од твојата интернет врска.

![Нов програм (2)](../../../media/game-tutorials/New-Program-2.png)\
Можеш да ја најдете апликацијата со пребарување „Pocket Code“ во Google Play Store и преземете го со притискање на „инсталирање“.\
[Отвори ја сликата](../../../media/game-tutorials/New-Program-2.png)

Откако успешно ќе ја преземете и инсталирате Pocket Code можеш да ја најдете апликацијата во аптечката или на твојот стартен екран, во зависност од твоето уредно средство. Можеш лесно да ја земете апликацијата и да ја ставите каде што сакаш.

### 2. Почнете ја апликацијата

![Нов програм (1)](../../../media/game-tutorials/New-Program-1.png)\
Кога ја отворите апликацијата, ќе видите различни категории.\
[Отвори ја сликата](../../../media/game-tutorials/New-Program-1.png)

### 3. Создавање на нов проект

Следниот чекор е да се создаде нов проект. Сега треба да внесете име на проектот и да избери дали твојот проект треба да биде пејзаж или не. Со притискање „Во ред“ се создава проектот.

![Нов програм](../../../media/game-tutorials/New-Program.png)\
За да го направите тоа, можеш да притиснете жълтото копче на долниот десен агол.\
[Отвори ја сликата](../../../media/game-tutorials/New-Program.png)

### 4. Ти си го направил својот нов проект.

Сега сте инсталирани Pocket Code и знаете како да креирате нов проект. Сега можеш да почнеш со програмирање!

За да го направите ова, треба да знаете како да создадете нов објект во еден проект. Погледнете го **[Нов објект](new-object.md)**-учењето, каде што се објаснувате чекор по чекор.
