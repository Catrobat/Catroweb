![Пауза за 1 бјат](../../../media/bricks/Pause_for_1_beats.png)

Овој блок на код го прави сценарисот да чека одреден број бутови пред да продолжи. Тоа е како да се направи кратка пауза во песната пред да ја свириш следната нота или звук. Представи си дека ќе го прекинеш своето изведение, ќе ги броиш ударите и потоа ќе ја продолжиш акцијата.
