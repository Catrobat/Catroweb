![Продолжи ја сцената](../../../media/bricks/continue_scene_brick2.png)

Овој блок на код ја повторува сцената од каде што беше стапен. Ако твојата сцена е прекината со пауза или чекање, користејќи го овој блок на код ќе ја започне акцијата веднаш каде што се спря.

Представи дека си ја прекинал играта или анимацијата, а сега сакаш да продолжи да работи. Овој блок на код дејствува како копчето „Стартувај“, што го прави сè да продолжи од моментот кога беше паузирано.
