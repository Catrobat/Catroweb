![Постави боја на конецот на ’#ff0000′](../../../media/bricks/Set_thread_color_to_ff0000.png)

Со користење на овој блок, можеш да ја промените бојата на нивото за твојот проект за шивање. Бојата ќе биде прикажана во твојата програма. Ова не значи дека машината за градење потоа ќе користи токму овие бои.
