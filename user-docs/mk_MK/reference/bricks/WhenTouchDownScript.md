Използува сценарио кога се допре екранот.

Разликата со блокот *„Кога ќе те допрат“* е дека *„Кога ќе се допре бината“* се однесува на целиот екран, додека *„Кога ќе те допрат“* е специфичен за поединечни спирити или предмети.
