![Кога ќе те допрат](../../../media/bricks/when-tapped2.png)

Използува сценарио кога објектот е натрупан.

Разликата со блокот *„Кога ќе се допре бината“* е дека *„Кога ќе те допрат“* е специфичен за поединечни спирити или предмети, додека *„Кога ќе се допре бината“* се однесува на целиот екран.
