![чекајте до-се-други-скрипти-стап-код блок](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Овој блок на код ја паузира тековната сценарија додека сите други скрипти во проектот не завршат да се работат. Представи си го сценаријот да биде приостанат додека се не заврши. Тоа е корисно за да се осигура дека нема други активности пред да продолжи со следниве чекори во твојот тековна сценарија.
