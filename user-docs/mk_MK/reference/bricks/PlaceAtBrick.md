![Смести на](../../../media/bricks/place_at_x_y_brick.png)

Преместува го објектот на одредена позиција на екранот, дефинирана од x и y координати. Тоа е како да го телепортираш ликот на точна точка.

Позицијата е поставена во координатниот систем како Картезијанската рамка: х и й осите поминуваат низ центарот на екранот, па x = 0 и y = 0 е средината на екранот.
