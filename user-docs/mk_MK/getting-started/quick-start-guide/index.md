Pocket Code е апликација за визуелна програмирање која ви овозможува да креирате игри, анимации и интерактивни приказни директно на твојот паметен телефон или таблет. Користејќи интуитивен интерфејс за влез и спуштање со „блокови на кодови“ (код блокови), можеш да ги дизајнирате твоите проекти без претходно искуство во програмирање. Лесно додадете звуци, слики и движење за да ги претворите твоите идеи во живот.

Овој водич ќе ви помогне да почнете со објаснување на како:

- Навигирајте во интерфејс,
- Создадете го твојот прв проект,
- Работете со предмети и фондови,
- Користете блокови со код за програмирање на акции, и
- Заштеди го твојот проект.

Перфектен за почетници и наставници, Pocket Code охрабрува креативност, решавање на проблеми и логично размислување.
