Pocket Code е главната апликација на Catrobat. Бесплатна е и има отворен код. Со неа можеш да правиш игри, анимации и интерактивни приказни на телефонот или таблетот. Во Pocket Code **програмираш со блокови**. Спој ги блоковите како делови од сложувалка за да направиш проект. Не мора веќе да знаеш да програмираш. Одлична е за почетници!

Pocket Code оди подалеку од дигитални проекти. Со новиот **карактеристики на создавачот**, можеш да дизајнирате и **SVG датотеки за резачки на парче**. Ова значи дека можеш да ги претворите твоите дигитални креации во предмети од реалниот свет и да истражувате креативни можности надвор од екранот.

Без разлика дали се учите да кодирате, експериментирате со нови идеи или учите на програмирање, Pocket Code обезбедува забавен и достапен начин за погрупување во кодирањето

[Повеќе информации](https://catrobat.org/pocket-code/)
