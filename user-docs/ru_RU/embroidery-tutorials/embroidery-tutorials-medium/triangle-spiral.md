В этом уроке ты узнаешь, как вышить треугольную спираль (50,2 x 58 мм).

![Треугольная спираль](../../../media/embroidery-tutorials/Triangle-Spiral.png)

Ты уже должен знать, что такое цикл и как он работает.

Если ты ещё ничего не вышивал, посмотри уроки по вышивке [для начинающих](../embroidery-tutorials-beginner/index.md).

Больше информации и идей для узоров есть в других уроках.

*Здесь можно скачать урок в формате PDF*:

[Треугольная спираль](../../../media/embroidery-tutorials/Triangle-Spiral-1.pdf)

### 1. Создай новый объект для вышивки (смотри [Создать объекты для вышивки](../embroidery-tutorials-beginner/create-embroidery-objects.md)) и вставь этот скрипт:

![Треугольная спираль (2)](../../../media/embroidery-tutorials/Triangle-Spiral-2.png)

### 2. Нажми «Запуск», чтобы начать свой узор!

Нажми «новое…», чтобы создать новую переменную.

![картинка (15)](../../../media/embroidery-tutorials/image-15.png)

Переменную «degree» ты найдёшь в группе «Данные».

![Спираль (1)](../../../media/embroidery-tutorials/Spiral-1.png)
