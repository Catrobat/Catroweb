В этом уроке ты узнаешь, как вышить Инь и Ян (78,4 x 78,4 мм).

![Инь и Ян](../../../media/embroidery-tutorials/Yin-und-Yang.png)

Ты уже должен знать, что такое цикл и как он работает.

Для этого урока может пригодиться урок **[Круг](../embroidery-tutorials-beginner/circle.md)**.

Если ты ещё ничего не вышивал, посмотри уроки по вышивке [для начинающих](../embroidery-tutorials-beginner/index.md).

Больше информации и идей для узоров есть в других уроках.

*Здесь можно скачать урок в формате PDF*:

[Инь и Ян](../../../media/embroidery-tutorials/Yin-and-Yang.pdf)

### 1. Создай новый объект для вышивки (смотри [Создать объекты для вышивки](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![Инь и Ян](../../../media/embroidery-tutorials/Yin-and-Yang.png)

### 2. Вставь этот скрипт для большого круга:

![Инь и Ян (1)](../../../media/embroidery-tutorials/Yin-and-Yang-1.png)

### 3. Кривая в середине

Добавь в скрипт ещё и эту часть:

![Инь и Ян (2)](../../../media/embroidery-tutorials/Yin-and-Yang-2.png)

### 4. Маленький круг сверху

Создай новый объект для вышивки и вставь этот скрипт:

![Инь и Ян (3)](../../../media/embroidery-tutorials/Yin-and-Yang-3.png)

### 5. Скопируй маленький круг

Можно просто скопировать объект из шага 4:

![Инь и Ян (4)](../../../media/embroidery-tutorials/Yin-and-Yang-4.png)

### 6. Маленький круг снизу

Поменяй место второго круга:

![Инь и Ян (5)](../../../media/embroidery-tutorials/Yin-and-Yang-5.png)

### 7. Нажми «Запуск», чтобы начать свой узор!
