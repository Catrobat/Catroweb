В этом уроке ты узнаешь, как вышить радугу (112 x 57,2 мм).

![Радуга](../../../media/embroidery-tutorials/Regenbogen.webp)

Ты уже должен знать, что такое цикл и как он работает.

Для этого урока может пригодиться урок **[Полукруг](../embroidery-tutorials-beginner/semicircle.md)**.

Если ты ещё ничего не вышивал, посмотри уроки по вышивке [для начинающих](../embroidery-tutorials-beginner/index.md).

Больше информации и идей для узоров есть в других уроках.

*Здесь можно скачать урок в формате PDF*:

[Радуга](../../../media/embroidery-tutorials/Rainbow.pdf)

### 1. Создай новый объект для вышивки (смотри [Создать объекты для вышивки](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![Радуга](../../../media/embroidery-tutorials/Rainbow.png)

### 2. Вставь этот скрипт:

![Радуга (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. Скопируй объект

Для следующей, большей дуги можно просто скопировать объект, который ты только что сделал.

Нажми на три точки вверху справа в списке объектов.

Потом нажми «Скопировать» и выбери объект.

![Радуга (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Если для каждой дуги есть свой объект, потом их можно вышить разными цветами.

### 4. Измени объект

Чтобы дуги были разного размера, нужно поменять несколько чисел.

Для этого открой скрипт скопированного объекта и поменяй вот эти числа:

![Радуга (2)](../../../media/embroidery-tutorials/Rainbow-2.png)

### 5. Повтори шаги 3 и 4 для других дуг!

### 6. Нажми «Запуск», чтобы начать свой узор!
