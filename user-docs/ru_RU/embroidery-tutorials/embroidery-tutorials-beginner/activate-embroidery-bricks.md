В этом уроке ты узнаешь, как включить блоки вышивки.

![Включить блоки вышивки 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Уметь программировать для этого не нужно. Это первый шаг перед уроками по вышивке. Потом ты сможешь придумывать, программировать и даже вышивать свои узоры на любимой одежде.

Больше информации и идей для узоров есть в других уроках.

*Здесь можно скачать урок в формате PDF*:

[Включить блоки вышивки](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Открой приложение «Pocket Code». Нажимай по шагам!

### 2. Открой меню (точки вверху справа).

![Включить блоки вышивки](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Перейди в «Настройки».

![Включить блоки вышивки 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Выбери «Расширение для вышивки».

![Включить блоки вышивки 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Блоки вышивки появятся среди твоих блоков в отдельной группе!

[![Включить блоки вышивки 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Теперь все блоки вышивки есть среди других блоков.

Больше о каждом блоке можно узнать в описании блоков [здесь](../../../reference/) или в уроке **[Блоки вышивки](embroidery-bricks/index.md)**.

Теперь можно начинать и придумывать свои узоры!

Если нужны идеи или помощь, посмотри другие уроки или продолжи с урока **[Создать объекты для вышивки](create-embroidery-objects.md)**.
