В этом уроке ты узнаешь, как сохранить готовые узоры на телефоне и поделиться ими.

Для этого нужен готовый узор для вышивки. Если его ещё нет, найди идеи в наших [уроках по вышивке](index.md)!

*Здесь можно скачать урок в формате PDF*:

[Сохранить узоры](../../../media/embroidery-tutorials/Export-Designs.pdf)

### 1. Запусти проект и подожди, пока узор нарисуется до конца. Иначе узор будет неполным.

### 2. Нажми «назад» и нажми кнопку «Поделиться».

![Сохранить узоры (1)](../../../media/embroidery-tutorials/Export-Designs-1.png)

### 3. Отправь файл вышивки по электронной почте или сохрани его на телефоне.

![Сохранить узоры (2)](../../../media/embroidery-tutorials/Export-Designs-2.png)

На разных телефонах окно «Поделиться» может выглядеть немного по-разному.

Твой узор сохранится как файл DST.

Вышивальная машина понимает этот формат и вышивает твой узор на ткани.
