Останавливает текущую строчку.

Этот блок нужен, если ты хочешь переставить иголку после того, как начал прямую строчку, строчку зигзагом или тройную строчку.

![Остановить текущую строчку](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

Иначе появится лишний шов, который тебе не нужен.

![Остановить текущую строчку](../../../../media/embroidery-tutorials/StopCurrentStitch.png)
