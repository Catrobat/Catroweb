Машина шьёт всё время, длину стежка можно менять.

Обычно прямую строчку используют вместе с блоком движения.

![Начать прямую строчку с длиной стежка 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Машина начинает прямую строчку и делает стежок через каждые **10 шагов**.

Потом машина проходит **200 шагов**.

Получается **20 стежков**.

![Прямая строчка](../../../../media/embroidery-tutorials/RunningStitch.png)

С прямой строчкой шить шов проще, потому что цикл больше не нужен.
