В этом уроке ты узнаешь всё, что нужно знать о блоках вышивки!

Уметь программировать для этого не нужно.

Каждый блок вышивки объяснён на примере.

Если ты ещё не включил блоки вышивки, посмотри урок **[Включить блоки вышивки](../activate-embroidery-bricks.md)**.

*Здесь можно скачать урок в формате PDF*:

[Блоки вышивки](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Нажми на блок, чтобы узнать о нём больше:**

[![Сделать стежок](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*Машина один раз прокалывает ткань иголкой!*

[![Начать прямую строчку с длиной стежка 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*Машина шьёт всё время, длину стежка можно менять.*

[![Начать строчку зигзагом с длиной стежка 2 и шириной 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Шьёт всё время, длину и ширину можно менять.*

[![Начать тройную строчку с длиной стежка 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*Тройная строчка прошивает каждый стежок три раза.*

[![Остановить текущую строчку](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Останавливает текущую строчку.*
