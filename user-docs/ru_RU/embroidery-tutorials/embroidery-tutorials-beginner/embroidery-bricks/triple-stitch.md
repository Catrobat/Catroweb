Тройная строчка прошивает каждый стежок три раза.

После первого стежка тройная строчка прыгает назад и делает стежок, потом прыгает снова вперёд и делает ещё один стежок.

![Начать тройную строчку с длиной стежка 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Работает так же, как [прямая строчка](running-stitch.md).

![Тройная строчка](../../../../media/embroidery-tutorials/TripleStitch.png)

Так шов получается прочнее.
