В этом уроке ты узнаешь, как создать объекты, которыми потом будешь вышивать свои узоры.

Для этого урока ты уже должен уметь создавать проект. Если нужна помощь, посмотри [уроки для начинающих](../../game-tutorials/starter-tutorials/index.md).

Больше информации и идей для узоров есть в других уроках.

*Здесь можно скачать урок в формате PDF*:

[Создать объекты для вышивки](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Нажми на кнопку с плюсом внизу справа в своём проекте, чтобы добавить новый объект.

![Создать объекты для вышивки](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Чтобы выбрать картинку, открой медиатеку.

![Создать объекты для вышивки (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Один объект для вышивки — это одна нитка в иголке вышивальной машины. Несколько объектов вышиваются один за другим. Так можно использовать несколько цветов.

Выбирай объект по цвету, который тебе нужен.

Прокрути вниз и найди подходящую стрелку.

![Создать объекты для вышивки (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Дай новому объекту подходящее имя и нажми «ОК».

![Создать объекты для вышивки (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Ты создал новый объект. Теперь можно добавить скрипт и запрограммировать объект.

![Создать объекты для вышивки (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Теперь ты умеешь создавать объект. Добавь новый объект для каждого цвета, который хочешь использовать.

В каждом цвете можно сделать скрипт, запрограммировать свои узоры и потом даже вышить их.

Нужны идеи или помощь? Посмотри наши другие уроки!
