В этом уроке ты узнаешь, как вышить круг строчкой зигзагом (54,7 x 54,8 мм).

![картинка](../../../media/embroidery-tutorials/image-8.png)

Ты уже должен уметь создавать новый объект и вставлять в него блоки. Если тебе ещё нужна помощь, посмотри [уроки для начинающих](../../game-tutorials/starter-tutorials/index.md). Ещё нужно заранее включить блоки вышивки. Как это сделать, рассказано в уроке **[Включить блоки вышивки](activate-embroidery-bricks.md)**.

Больше информации и идей для узоров есть в других уроках.

*Здесь можно скачать урок в формате PDF*:

[Круг зигзагом](../../../media/embroidery-tutorials/Circle-Zigzag.pdf)

### 1. Создай новый объект для вышивки (смотри [Создать объекты для вышивки](create-embroidery-objects.md)).

### 2. Теперь вставляй блоки в свой скрипт шаг за шагом.

![Круг зигзагом](../../../media/embroidery-tutorials/Circle-Zigzag.png)

### 3. Нажми «Запуск», чтобы начать свой узор!

Больше о том, как вышить круг, рассказано в уроке **[Круг](circle.md)**.
