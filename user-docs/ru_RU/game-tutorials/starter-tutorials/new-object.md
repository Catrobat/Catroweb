В этом уроке ты узнаешь, как создать в проекте новый объект и какие для этого есть способы.

![Новый объект](../../../media/game-tutorials/New-Object.png)\
В этом уроке ты узнаешь, как создать в проекте новый объект и какие для этого есть способы.\
[Открыть изображение](../../../media/game-tutorials/New-Object.png)

Для этого у тебя уже должно быть приложение Pocket Code, и ты должен уметь создавать новый проект. Если тебе нужна помощь, посмотри урок **[Новый проект](new-project.md)**.

*Здесь можно скачать урок в формате PDF:*

[Открыть PDF](../../../media/game-tutorials/New-Object.pdf)

### 1. Создай новый объект

Сначала открой свой новый проект.

Он есть на главном экране Pocket Code. Если у тебя несколько проектов, нажми «Проекты». Потом выбери свой новый проект. Если у тебя ещё нет проекта или ты не знаешь, как его создать, посмотри урок **[Новый проект](new-project.md)**.

### 2. Создай новый объект

Теперь можно создать новый объект. Откроется окно, где можно выбрать один из семи способов.

![Новый объект (1)](../../../media/game-tutorials/New-Object-1.png)\
Просто нажми на жёлтую кнопку с плюсом внизу справа.\
[Открыть изображение](../../../media/game-tutorials/New-Object-1.png)

### 3. Способы создать объект

![Новый объект (2)](../../../media/game-tutorials/New-Object-2.png)\
Вот из чего можно выбирать.\
[Открыть изображение](../../../media/game-tutorials/New-Object-2.png)

### 4. Нарисуй картинку

Чтобы начать как можно проще, выбери «Нарисовать» и нарисуй просто точку. Когда точка в Pocket Paint готова, выйди из программы (вернись на шаг назад).

### 5. Дай имя

Теперь дай своей картинке имя.

### 6. Поставь её

Потом поставь картинку на место: двигай её пальцем влево, вправо, вверх или вниз.

![Новый объект (3)](../../../media/game-tutorials/New-Object-3.png)\
Сохрани кнопкой вверху справа.\
[Открыть изображение](../../../media/game-tutorials/New-Object-3.png)

### 7. Получилось! Ты создал свой новый объект.

Теперь у тебя есть проект с объектом, который можно программировать!

Для этого нужно знать, какие есть блоки. Урок **[Первые блоки](first-bricks.md)** хорошо показывает разные группы блоков. А можешь сразу начать свой первый проект. Выбери подходящий урок для начинающих.
