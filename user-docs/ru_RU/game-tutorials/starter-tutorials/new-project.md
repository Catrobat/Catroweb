В этом уроке ты узнаешь всё, что нужно знать о Pocket Code, чтобы начать свой первый проект. Мы шаг за шагом покажем, как скачать приложение, открыть его и создать новый проект.

![Новый проект](../../../media/game-tutorials/New-Program.png)\
Мы шаг за шагом покажем, как скачать приложение, открыть его и создать новый проект.\
[Открыть изображение](../../../media/game-tutorials/New-Program.png)

Это самый первый урок, и тебе не нужно ничего знать заранее.

Так чего же ты ждёшь? Бери телефон и начинай!

*Здесь можно скачать урок в формате PDF:*

[Открыть PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Установи Pocket Code

Сначала установи приложение Pocket Code на своё устройство. Для этого нужен аккаунт Google. Устройство скачает и установит приложение. Это может занять немного времени, всё зависит от интернета.

![Новый проект (2)](../../../media/game-tutorials/New-Program-2.png)\
Найди «Pocket Code» в Google Play и нажми «Установить».\
[Открыть изображение](../../../media/game-tutorials/New-Program-2.png)

Когда Pocket Code установлен, ты найдёшь его в списке приложений или на главном экране телефона. Значок приложения можно перетащить куда хочешь.

### 2. Открой приложение

![Новый проект (1)](../../../media/game-tutorials/New-Program-1.png)\
Когда ты откроешь приложение, ты увидишь разные разделы.\
[Открыть изображение](../../../media/game-tutorials/New-Program-1.png)

### 3. Создай новый проект

Теперь создадим новый проект. Введи название проекта и выбери, будет ли проект горизонтальным. Нажми «ОК», и проект готов.

![Новый проект](../../../media/game-tutorials/New-Program.png)\
Нажми на жёлтую кнопку с плюсом внизу справа.\
[Открыть изображение](../../../media/game-tutorials/New-Program.png)

### 4. Получилось! Ты создал свой новый проект.

Теперь Pocket Code установлен, и ты умеешь создавать новый проект. Можно начинать программировать!

Для этого нужно уметь создавать в проекте новый объект. Посмотри урок **[Новый объект](new-object.md)**, там всё объяснено шаг за шагом.
