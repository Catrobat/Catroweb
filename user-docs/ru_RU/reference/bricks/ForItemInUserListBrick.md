![Для каждого значения в списке](../../../media/bricks/for-each-value_brick.png)

Этот блок выполняет команды для каждого элемента в списке или диапазоне. Это как пройти по всем элементам по очереди и с каждым сделать одно и то же.

Представь, что у тебя есть список чисел, цветов или чего угодно. Этот блок берёт каждый элемент из списка, и ты можешь что-то с ним сделать. Например, у тебя есть список цветов, и ты хочешь по очереди покрасить фон в каждый цвет из списка. Для этого и нужен этот блок.

Это как сказать: «Для каждого элемента в этой группе выполни эти команды».
