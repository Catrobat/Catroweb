![Задать цвет пера красный 0 зелёный 0 синий 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Этот блок меняет цвет пера, которым рисует актер. Это как взять во время рисования ручку другого цвета.

**Красный, зелёный, синий (RGB)**: В модели RGB разные цвета получаются, если смешивать красный, зелёный и синий свет разной яркости. Каждая часть цвета (красная, зелёная и синяя) может быть от 0 до 255:

- **Красный**: красная часть цвета. Чем больше число, тем больше красного.
- **Зелёный**: зелёная часть цвета. Чем больше число, тем больше зелёного.
- **Синий**: синяя часть цвета. Чем больше число, тем больше синего.

Если смешивать разные значения красного, зелёного и синего, можно получить любой цвет. Например:

- `RGB(255, 0, 0)` — чистый красный.
- `RGB(0, 255, 0)` — чистый зелёный.
- `RGB(0, 0, 255)` — чистый синий.
- `RGB(255, 255, 255)` — белый (больше всего красного, зелёного и синего).
- `RGB(0, 0, 0)` — чёрный (нет цвета).

Если смешивать эти цвета в разных количествах, получаются все цвета, которые ты видишь на экранах.
