![При нажатии на сцену](../../../media/bricks/When_stage_is_tapped_btn.png)

Запускает скрипт, когда касаются экрана.

Отличие от блока *«При нажатии»*: блок *«При нажатии на сцену»* работает для всего экрана, а *«При нажатии»* — только для одного актера или объекта.
