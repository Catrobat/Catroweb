![Задать цвет частиц «#ff0000»](../../../media/bricks/Set_particle_colour_to_ff0000.png)

Этот блок меняет цвет частиц, которые выпускает актер. Это как поменять цвет конфетти в хлопушке.

Шестнадцатеричный код цвета (hex-код) — это способ записать цвет с помощью шестнадцатеричных чисел. Он состоит из шести знаков: цифр (0–9) или букв (A–F). Обычно в начале пишут «#», вот так: `#RRGGBB`.

- Первые два знака (`RR`) — это красная часть цвета.
- Следующие два знака (`GG`) — это зелёная часть.
- Последние два знака (`BB`) — это синяя часть.

Каждая пара знаков может быть от `00` (этого цвета нет совсем) до `FF` (этого цвета больше всего). Например:

`#000000` — чёрный (нет цвета).

`#FF0000` — чистый красный.

`#00FF00` — чистый зелёный.

`#0000FF` — чистый синий.

`#FFFFFF` — белый (больше всего красного, зелёного и синего).
