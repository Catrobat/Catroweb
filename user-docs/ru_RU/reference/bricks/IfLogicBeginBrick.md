![Если … истинно, то … Иначе](../../../media/bricks/if_else_brick2.png)

*Проверяет, истинно ли условие. Если да, выполняет одни команды, а если нет — другие. Это как выбор из двух вариантов: «Если это правда, сделай это, а иначе сделай то».*

![Запуск эпизода](../../../media/bricks/StartScene.png)

Когда эпизод запускается, переменной X задаётся значение 0.

![Если … иначе](../../../media/bricks/IfElse.png)

Когда ты нажимаешь на животное, программа проверяет, истинно ли X modulo 2, то есть нечётное ли число X.

Если да, играет звук Tweet1, и переменная X увеличивается на 1.

Иначе, если X чётное, X просто увеличивается на 1.

Команды, которые нужно выполнить, заканчиваются блоком «Конец условия».
