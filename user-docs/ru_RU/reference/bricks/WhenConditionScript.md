![Как только … станет истинным](../../../media/bricks/when_brick3.png)

*Ждёт, пока значение или функция станет истинной, и тогда запускает скрипт.*

![Запуск эпизода](../../../media/bricks/StartScene.png)

Когда эпизод запускается, переменной X задаётся значение 0.

![При нажатии, как только X modulo 2](../../../media/bricks/WhenTappedWhenModulo.png)

Когда ты нажимаешь на животное, X увеличивается на 1.

Как только X modulo 2 становится истинным, то есть если X нечётное, играет звук Tweet1.
