![При нажатии](../../../media/bricks/when-tapped2.png)

Запускает скрипт, когда нажимают на объект.

Отличие от блока *«При нажатии на сцену»*: блок *«При нажатии»* работает только для одного актера или объекта, а *«При нажатии на сцену»* — для всего экрана.
