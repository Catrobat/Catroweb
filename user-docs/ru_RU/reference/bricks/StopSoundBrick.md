![Остановить звук](../../../media/bricks/Stop_sound_record.png)

Этот блок останавливает один определённый звук. Это как выключить только одну песню, а другие звуки и музыка продолжают играть. Представь, что ты говоришь персонажу перестать играть одну определённую мелодию.
