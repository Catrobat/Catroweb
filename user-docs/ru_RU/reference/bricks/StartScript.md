![При запуске эпизода](../../../media/bricks/When_scene_starts_btn2.png)

С этим блоком скрипт начинается сразу, когда запускается эпизод. Эпизод — это начало твоей программы. Эпизод — это новый экран в твоей программе, где можно показывать разные вещи, и там могут происходить разные действия. Для разных частей программы может быть много эпизодов. Например, один эпизод для заставки, один для главного меню, один для первого уровня, один для второго уровня и так далее. В простых программах хватит и одного эпизода, и тогда начало программы — это и начало эпизода.

Как и каждый скрипт, этот начинается с блока-события: событие говорит, **когда** начинается скрипт, а блоки после него говорят программе, **что** делать.
