![Ждать остановки всех других скриптов](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Этот блок ставит скрипт на паузу, пока все другие скрипты в проекте не закончат работу. Представь, что твой скрипт ждёт, пока всё остальное не будет сделано. Это полезно, если ты хочешь, чтобы ничего другого не происходило, прежде чем твой скрипт пойдёт дальше.
