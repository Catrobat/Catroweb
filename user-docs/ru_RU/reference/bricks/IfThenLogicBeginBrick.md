![Если … истинно, то](../../../media/bricks/if_brick2.png)

*Проверяет, истинно ли условие, и если да, выполняет команды. Это как сказать: «Если это правда, то сделай это».*

![Запуск эпизода](../../../media/bricks/StartScene.png)

Когда эпизод запускается, переменной X задаётся значение 0.

![Если](../../../media/bricks/If.png)

Когда ты нажимаешь на животное, переменная X увеличивается на 1.

Программа проверяет, равна ли переменная X числу 2.

Если да, играет звук Tweet1, и переменной X снова задаётся 0.
