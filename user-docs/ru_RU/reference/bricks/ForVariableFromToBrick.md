![Для значений от … до …](../../../media/bricks/for-values-from-brick.png)

Этот блок выполняет команды определённое число раз. Для этого есть счётчик, который начинается с одного числа и заканчивается другим. Это цикл, про который ты точно знаешь, сколько раз он повторится.

Представь, что у тебя есть список, и ты хочешь что-то сделать с каждым его элементом. Этот блок проходит по элементам по очереди и делает с каждым одно и то же.
