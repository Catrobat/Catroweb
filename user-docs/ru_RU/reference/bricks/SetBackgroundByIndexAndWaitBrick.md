![Сменить фон на номер 1 и ждать](../../../media/bricks/Set_background_to_number_1_and_wait_.png)

Этот блок ставит фон по его номеру в списке фонов и ждёт, пока смена закончится. Только потом скрипт идёт дальше. Это как выбрать в спектакле нужный задник из списка и подождать, пока новые декорации будут готовы.
