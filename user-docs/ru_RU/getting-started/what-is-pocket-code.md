Pocket Code — главное приложение Catrobat. Это бесплатное приложение с открытым кодом. В нём ты делаешь игры, анимации и интерактивные истории прямо на телефоне или планшете. В Pocket Code программы собираются из **блоков**. Ты соединяешь блоки, как кусочки пазла. Уметь программировать не нужно, поэтому Pocket Code отлично подходит для новичков!

Pocket Code умеет не только цифровые проекты. С новыми **функциями для мастерских** ты можешь создавать **файлы SVG для режущих плоттеров**. Так твои идеи становятся настоящими вещами, а не только картинками на экране.

Ты учишься программировать, пробуешь новые идеи или учишь других? Pocket Code — это весёлый и простой способ начать программировать.
