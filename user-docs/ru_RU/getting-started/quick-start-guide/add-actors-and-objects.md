Нажми на кнопку с плюсом, чтобы добавить в проект нового актера или объект.

![Добавить актера](../../../media/getting-started/FigurHinzufuegen.png)

В Pocket Code есть разные способы добавить в проект персонажа или объект:

**Нарисовать**: Ты можешь нарисовать своего персонажа в **Pocket Paint**. Pocket Paint — это программа для рисования ([подробнее о Pocket Paint](https://catrobat.org/pocket-paint/))

**Загрузить из библиотеки**: Выбери готового актера или объект из собрания ([подробнее о медиатеке](../elements/medialibrary.md)).

**Загрузить из галереи**: Ты можешь выбрать картинку из галереи своего телефона.

**Моя библиотека**: Здесь есть актеры и объекты, которые уже запрограммированы, то есть у них уже есть скрипт. Выбирай их, если хочешь взять в игру готовые части (например, таймер обратного отсчёта) ([подробнее о библиотеке](../elements/medialibrary.md#добавить-объект-из-медиатеки)).

**Сделать снимок**: Ты можешь сфотографировать что-нибудь камерой устройства и добавить фото как персонажа.

**Портфель**: Сейчас портфель пуст. Ты можешь снова использовать актеров или объекты, которые положил в портфель. Весь скрипт распаковывается вместе с ними ([подробнее о портфеле](../elements/backpack.md)).

**Локальные актеры и объекты**: Здесь есть готовые персонажи для твоего проекта. Это как медиатека без интернета: даже если интернета нет, ты можешь взять этих актеров.

**Пустой объект**: Добавь пустой объект — это объект, у которого нет внешнего вида. Его можно программировать как обычно.

**Загрузить из локальных проектов**: Выбери проект. Его первый актер вместе со скриптом попадёт в твой проект.
