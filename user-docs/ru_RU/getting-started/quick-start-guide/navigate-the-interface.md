Когда ты запускаешь Pocket Code, ты видишь вот такой главный экран.

![Главный экран](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Когда ты запускаешь Pocket Code, ты видишь вот такой главный экран.\
[Открыть изображение](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Помощь](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Вверху справа есть значок.

Он ведёт к документации Catrobat, где много полезных советов.

![Меню](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Рядом с ним находится меню.

Оттуда легко попасть в настройки. Там можно поменять язык или включить дополнения, например блоки для плоттера и другие.

![Значок изменения](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Нажми на значок карандаша, чтобы открыть окно проекта и работать дальше.

Ниже ты видишь проект, который менял последним.

![Запусти свой проект](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Кнопкой запуска ты запускаешь проект.

![Проекты на устройстве](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Нажми «Проекты», чтобы открыть проекты, сохранённые на устройстве.

![Сообщество Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Хочешь посмотреть проекты других людей и поработать с ними?

Нажми «Сообщество Catrobat». Там много классных проектов.

![Добавить](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Чтобы создать новый проект, нажми на значок с плюсом.
