Когда ты запускаешь Pocket Code, ты видишь вот такой главный экран.

![Главный экран](../../../media/getting-started/MainScreen-e1732269599192.jpg)

Вверху справа есть значок ![Помощь](../../../media/getting-started/Screenshot-2024-11-22-111748.png). Он ведёт к документации Catrobat, где много полезных советов.

Рядом с ним находится меню ![Меню](../../../media/getting-started/Screenshot-2024-11-22-111804.png). Оттуда легко попасть в настройки. Там можно поменять язык или включить дополнения, например блоки для плоттера и другие.

Ниже ты видишь проект, который менял последним. Нажми на значок карандаша ![Значок изменения](../../../media/getting-started/Screenshot-2024-11-22-111825.png), чтобы открыть окно проекта и работать дальше.

Кнопкой запуска ![Запусти свой проект](../../../media/getting-started/Screenshot-2024-11-22-111818.png) ты запускаешь проект.

Нажми «Проекты», чтобы открыть проекты, сохранённые на устройстве. ![Проекты на устройстве](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Хочешь посмотреть проекты других людей и поработать с ними? Нажми «Сообщество Catrobat». Там много классных проектов. ![Сообщество Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Чтобы создать новый проект, нажми на значок с плюсом. ![Добавить](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
