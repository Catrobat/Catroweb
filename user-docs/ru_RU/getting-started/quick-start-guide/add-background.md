В Catrobat ты можешь добавить в проект фон.

Фоны можно использовать по-разному. В Pocket Code они делают **игры** красивее, помогают рассказывать **истории** и показывают, где находятся твои актеры и объекты.

Для машин из мастерской, например **плоттеров** или **вышивальных машин**, фон — это шаблон рисунка, например для резки или вышивки.

Чтобы добавить фон, нажми «Фон» в окне проекта.

![Нажми на фон](../../../media/getting-started/grafik-16.png)

В **разделе скриптов (2)** ты можешь программировать фон. Но там есть не все блоки. Особенно важны вот эти два блока: ![Установить прозрачность на 50 %](../../../media/bricks/Set_transparency_to_50_pct_.png) и ![Установить размер на 60 %](../../../media/bricks/Set_size_to_60_pct_.png)

В **разделе образов (1)** ты добавляешь фон. Для этого нажми на значок +.

![Добавить фон](../../../media/getting-started/grafik-14.png)

Ты можешь загрузить свои картинки, взять готовые фоны или нарисовать фон сам.

**Нарисовать**: Ты можешь нарисовать свой фон в **Pocket Paint**. Pocket Paint — это программа для рисования ([подробнее о Pocket Paint](https://catrobat.org/pocket-paint/))

**Загрузить из библиотеки**: Выбери готовый фон из собрания ([подробнее о медиатеке](../elements/medialibrary.md)).

**Загрузить из галереи**: Ты можешь выбрать картинку из галереи своего телефона.

**Сделать снимок**: Ты можешь сфотографировать что-нибудь камерой устройства и добавить фото как фон.

![картинка](../../../media/getting-started/grafik-17.png)

Готово, ты добавил фон. Нажми на стрелку назад вверху справа, чтобы вернуться в **окно проекта**.
