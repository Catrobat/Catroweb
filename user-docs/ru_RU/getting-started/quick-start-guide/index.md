Pocket Code — это приложение для визуального программирования. В нём ты делаешь игры, анимации и интерактивные истории прямо на телефоне или планшете. Ты просто перетаскиваешь «блоки» (кусочки кода), и опыт программирования не нужен. Добавляй звуки, картинки и движение, и твои идеи оживут.

Это руководство поможет тебе начать. Ты узнаешь, как:

- разобраться в приложении,
- создать свой первый проект,
- работать с объектами и фонами,
- программировать действия с помощью блоков и
- сохранить проект.

Pocket Code отлично подходит для новичков и учителей. Он учит придумывать, решать задачи и думать логически.
