[Кошка (PDF, на немецком)](../../../media/plot-tutorials/Katze.pdf)

Когда начинается рисунок плоттера, каждое движение рисуется, как будто ручкой. Потом по этим линиям плоттер будет резать.

Наш объект смотрит в направлении 150 градусов.

В этом уроке сначала делаем правую сторону головы кошки. Посмотри внимательно: сначала линия сильно изгибается, поэтому после каждой маленькой линии объект должен поворачиваться сильнее. Потом, внизу головы, повороты становятся меньше. Левая сторона головы снова сильно изогнута. Поэтому для этой части головы нужно всего три цикла.

Дальше идёт левое ухо. Оно состоит только из прямых линий, поэтому можно взять блок «Идти \_\_ шагов».

Часть между ушами — снова дуга. Её мы программируем ещё одним циклом.

Потом делаем правое ухо.

Рисунок готов. Закончи его блоком «Перестать рисовать плоттером» и сохрани на телефоне блоком «Сохранить рисунок плоттера в SVG \_\_\_».

Теперь файл SVG можно отправить на (режущий) плоттер.
