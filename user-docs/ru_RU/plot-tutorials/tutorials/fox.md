[Лиса (PDF, на немецком)](../../../media/plot-tutorials/Fuchs.pdf)

Когда начинается рисунок плоттера, каждое движение рисуется, как будто ручкой. Потом по этим линиям плоттер будет резать.

Эта лиса состоит только из прямых линий («Идти \_\_\_ шагов») и поворотов.

**Совет**: Проверяй свою программу, пока её делаешь.
