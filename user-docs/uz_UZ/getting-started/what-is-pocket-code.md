Pocket Code — Catrobat’ning asosiy ilovasi. U bepul va ochiq kodli. Unda telefon yoki planshetingda o‘yin, animatsiya va ishtirok etish mumkin bo‘lgan hikoyalar yasay olasan. Pocket Code’da **kod bloklar yordamida tuziladi**. Loyihangni yasash uchun kod bloklarini pazl bo‘laklaridek birlashtir. Boshlash uchun dasturlashni oldindan bilishing shart emas!

Pocket Code faqatgina raqamli loyihalardan tashqari. Yangi **makerspace xususiyatlari** bilan sen ham dizayn qilishingiz mumkin **SVG kesish plotsers uchun fayllar**. Bu sening raqamli ijodlaringizni haqiqiy dunyoga aylantirishingiz va ekran tashqarisida ijodiy imkoniyatlarni kashf etishingiz mumkinligini anglatadi.

Sen kodlashni o'rganyapsizmi, yangi g'oyalar bilan tajriba qilyapsizmi yoki dasturlashni o'rgatyapsizmi, Pocket Code kodlashda o'yinli va qulay usulni taqdim etadi
