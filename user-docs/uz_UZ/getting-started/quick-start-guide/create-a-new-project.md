Telefoning yoki planshetingda ilovani och. Yangi loyiha yaratish uchun + belgisini bos.

![Bosh ekran Yangi loyiha](../../../media/getting-started/MainScreen_NewProject.png)

Loyihaga nom qo‘y (1). O‘yin ekrani tik (portret) yoki yotiq (albom) bo‘lishini tanla (2). So‘ng tasdiqlash uchun belgilash tugmasini bos (3).

![Yangi loyiha](../../../media/getting-started/NewProject.png)

Sen endi loyiha ko'rinishida. Yuqorida o'yiningizning nomi ko'rinadi.

Quyida **Fon** ni ko'rishingiz mumkin - hozirda, orqa fon bo'sh. Agar uni o'zgartirishni istasangiz, bos.

Orqa fonda o'yiningizga qo'shgan **aktyorlar va obyektlar** maydonini ko'rasiz. Hozirgi vaqtda bu hudud hali ham bo'sh.

O'ng tomonda pastki qismda ikkita muhim tugma ko'rishingiz mumkin:

![Boshlang](../../../media/getting-started/Start.png) **Ishga tushirish** tugmasi bilan o'yinni boshlaysiz.

![Qoʻshimcha tugma](../../../media/getting-started/Screenshot-2024-11-22-143219.png) **Bundan tashqari** tugmasi yordamida o'yiningizga yangi belgi/obʼekt qo'shasiz.
