Pocket Code - bu o'yinlar, animatsiyalar va interaktiv hikoyalarni bevosita smartfon yoki planshetda yaratishga imkon beradigan vizual dasturlash dasturi. “kod bloklari” (kod bloklari) bilan intuitiv chiziq-chiqarish interfeysidan foydalangan holda, sen dastlabki dasturlash tajribasi bo'lmagan holda loyihalaringizni loyihalashtirishingiz mumkin. Fikrlaringizni hayotga tatbiq etish uchun ovoz, rasm va harakatlarni qo'shish oson.

Ushbu qo'llanma senga quyidagilarni tushuntirib, boshlashingizga yordam beradi:

- Interfeysni navigatsiya qiling,
- Birinchi loyihangizni yarating,
- Ob'ektlar va orqa fonlar bilan ishlash,
- Amallarni dasturlash uchun kod bloklaridan foydalanish; va
- Loyihaningni saqlang.

Yangi boshlanuvchilar va o'qituvchilar uchun mukammal Pocket Code ijodiylikni, muammolarni hal qilishni va mantiqiy fikrlashni rag'batlantiradi.
