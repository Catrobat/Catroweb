Pocket Code ishga tushganda quyidagi asosiy ekran ko'rinadi.

![Bosh ekran](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Pocket Code ishga tushganda quyidagi asosiy ekran ko'rinadi.\
[Rasmni och](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Yordam](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Yuqori o'ng burchada sen uchun foydali maslahatlar mavjud bo'lgan Catrobat hujjatlariga olib boradigan ramzi mavjud.

![Menyu](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Uning yonida esa menyu bor.

U yerdan sen o'rnatishlarga osonlikcha o'tishingiz mumkin, u erda tilni o'zgartirish yoki plot bloklari kabi kengaytmalarni yoqishingiz mumkin va boshqalar.

![Tasvirlash nishonchasi](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Loyiha ekraniga kirish uchun tahrirlash nishonchasini bos.

Pastda sen so'nggi tahrirlangan loyihangizni ko'rishingiz mumkin.

![Loyihaningni boshlash](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Loyihaning boshlanishiga o'ynash tugmasini qo'llash.

![Qurilmalar bo'yicha loyihalar](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Bir marta bosish bilan Loyihalar, sen saqlangan loyihalarga kirishingiz mumkin.

![Catrobat Iqtisodiy ahvol](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Boshqa foydalanuvchilarning loyihalarini ko‘rish va sinab ko‘rish uchun Share’da Catrobat hamjamiyatiga kir.

U yerda sen ko'plab ajoyib loyihalarni topasiz.

![Qoʻshish](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Agar sen yangi loyiha yaratmoqchi bo'lsangiz, qo'shimcha nishonchaga bos.
