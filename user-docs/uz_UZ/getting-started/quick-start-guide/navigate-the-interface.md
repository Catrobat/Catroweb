Pocket Code ishga tushganda quyidagi asosiy ekran ko'rinadi.

![Bosh ekran](../../../media/getting-started/MainScreen-e1732269599192.jpg)

Yuqori o'ng burchada sen uchun foydali maslahatlar mavjud bo'lgan Catrobat hujjatlariga olib boradigan ![Yordam](../../../media/getting-started/Screenshot-2024-11-22-111748.png) ramzi mavjud.

Uning yonida esa menyu ![Menyu](../../../media/getting-started/Screenshot-2024-11-22-111804.png) bor. U yerdan sen o'rnatishlarga osonlikcha o'tishingiz mumkin, u erda tilni o'zgartirish yoki plot bloklari kabi kengaytmalarni yoqishingiz mumkin va boshqalar.

Pastda sen so'nggi tahrirlangan loyihangizni ko'rishingiz mumkin. Loyiha ekraniga kirish uchun tahrirlash nishonchasini bos ![Tasvirlash nishonchasi](../../../media/getting-started/Screenshot-2024-11-22-111825.png).

Loyihaning boshlanishiga o'ynash tugmasini ![Loyihaningni boshlash](../../../media/getting-started/Screenshot-2024-11-22-111818.png) qo'llash.

Bir marta bosish bilan Loyihalar, sen saqlangan loyihalarga kirishingiz mumkin. ![Qurilmalar bo'yicha loyihalar](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Agar sen boshqa foydalanuvchilarning ko'proq loyihalarini bilishni va ularda ishlashni istasangiz, faqat Catrobat Community on the Share-da bos. U yerda sen ko'plab ajoyib loyihalarni topasiz. ![Catrobat Iqtisodiy ahvol](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Agar sen yangi loyiha yaratmoqchi bo'lsangiz, qo'shimcha nishonchaga bos. ![Qoʻshish](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
