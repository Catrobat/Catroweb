![Koʻrinishni boshla:](../../../media/bricks/StartScene.png)

Sahna boshlanganda, o'zgaruvchi X 0 ga o'rnatilgan.

![Agar boshqa](../../../media/bricks/IfElse.png)

Agar hayvon endi to'plansa, X modulo 2 haqiqiymi yoki yo'qmi, ya'ni X n° bir xilmi, deb tekshirish amalga oshiriladi.

Agar shunday bo'lsa, ovoz Tweet1 o'ynatiladi va o'zgaruvchi X 1 ga ko'paytirilgan.

Aks holda, agar X teng bo'lsa, faqat X 1 ga ko'paytirilgan.
