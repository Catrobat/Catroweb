Ushbu kod bloklari aktyor harakatlanayotganda dizaynni boshlaydi. Bu qalamni qog'ozga qo'yib, chiziq chizishni boshlash bilan o'xshaydi. Agar chizishni to'xtatmoqchi bo'lsangiz, “Chizishni toʻxtat” kod blokidan foydalanishingiz mumkin va aktyorni boshqa joyga ko'chirishingiz va keyin plotni yana “Chizishni boshla” bilan boshlashingiz mumkin.
