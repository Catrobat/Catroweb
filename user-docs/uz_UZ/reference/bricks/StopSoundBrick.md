Ushbu kod blokida aniq tovush o'ynashini to'xtatadi. Bu boshqa tovushlar yoki musiqa o'ynashni davom ettirganida, faqat bitta qo'shiq uchun to'xtatish tugmasini bosish kabi. O'zingizning xarakteringizga bitta ovoz qo'shiqini o'ynashni to'xtatishni aytishingizni tasavvur qiling.
