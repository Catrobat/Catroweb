![Chizishni toʻxtat](../../../media/bricks/Stop_to_plot.png)

“Chizishni toʻxtat” kod bloklari dizaynni to'xtatib, aktyorni yangi joyga ko'chirish yoki dizaynni tugatishga imkon beradi. Bu qog'ozdan qalamni ko'tarish yoki chizishni to'xtatish kabi. Sen rejalashtirishni tugatgandan so'ng, sen “Chizmani SVG sifatida saqla:” dizayningizni saqlash uchun kod blokini SVG fayl.
