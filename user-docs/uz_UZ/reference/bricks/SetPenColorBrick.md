![Qalam rangini oʻrnat: o qizil 0 yashil 0 ko'k 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Ushbu kod blokasi aktyor tomonidan ishlatiladigan qalamning rangini o'zgartiradi. Bu rasm chizishda boshqa rangli qalamga o'tish kabi.

**Qizil, yashil, ko'k (RGB)**: RGB rangli model turli xil ranglar spektrini yaratish uchun qizil, yashil va ko'k yorug'lik intensivliklaridan foydalanadi. Har bir rang komponentining (qizil, yashil va ko'k) qiymati 0 dan 255 gacha bo'lishi mumkin:

- **Qizil**: Rangning qizil tarkibiy qismi. Yuqori qiymat ko'proq qizillikni anglatadi.
- **Yashil**: Rangning yashil tarkibiy qismi. Yuqori qiymat ko'proq yashillikni anglatadi.
- **Koʻk**: Rangning ko'k tarkibiy qismi. Yuqori qiymat ko'proq ko'kni anglatadi.

Qizil, yashil va ko'k ranglarning turlicha qiymatlarini birlashtirish orqali sen har qanday rangni yaratishingiz mumkin. Masalan:

- `RGB(255, 0, 0)` to'liq qizil.
- `RGB(0, 255, 0)` sof yashil.
- `RGB(0, 0, 255)` sof ko'k rangda.
- `RGB(255, 255, 255)` oq (kamida qizil, yashil va ko'k).
- `RGB(0, 0, 0)` qora (rangsiz).

Ushbu ranglarni turli miqdorlarda aralashtirish raqamli ekranlarda ko'rgan barcha ranglarni yaratadi.
