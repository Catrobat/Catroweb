Ob'ektni x va y koordinatalari bilan aniqlangan ekrandagi muayyan joyga ko'chirish. Bu sening shaxsaningizni aniq joyga teleport qilish kabi.

Pozitsiya kartesian tekisligi kabi koordinat tizimida belgilanadi: x va y o'qi ekrani markazidan o'tadi, shuning uchun x = 0 va y = 0 ekranning o'rtasida bo'ladi.
