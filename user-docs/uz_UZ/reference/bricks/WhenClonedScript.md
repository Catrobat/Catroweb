![Klon sifatida boshlaganingda](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Ishtirok qilingan amallarni bajarish uchun ko'rsatmalar bilan yaratilgan ob'ektning klonini yo'naltirish. Ushbu jarayon asl ob'ektning funktsionalligini takrorlashga imkon beradi, shu bilan birga klonni mustaqil ravishda nazorat qiladi. Klon ob'ektining turli xatti-harakatlari yoki xususiyatlari aniq talablarga javob berish uchun aniqlanishi mumkin.
