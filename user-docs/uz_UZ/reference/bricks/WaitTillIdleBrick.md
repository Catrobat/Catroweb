![bekat-to-hamma boshqa skriptlar-toʻxtatilgan kod blok](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Ushbu kod blokida loyihadagi barcha skriptlar ishlayotgan bo'lguncha joriy skript to'xtatiladi. Boshqa hamma narsa bo'lmaguncha, ssenariyingizni to'xtatishni tasavvur qiling. Bu sening joriy skriptingizdagi keyingi qadamlar bilan davom etishdan oldin boshqa harakatlar sodir bo'lmasligini ta'minlash uchun foydali.
