Ushbu darsda sen birinchi loyihangizni yaratishni boshlash uchun Pocket Code haqida bilishingiz kerak bo'lgan hamma narsani bilib olasan. Biz senga dasturni qanday yuklab olish, uni ochish va yangi loyiha yaratish haqida qadam-halaq yo'l ko'rsatamiz.

![Yangi dastur](../../../media/game-tutorials/New-Program.png)

Bu birinchi dars, va sen hech qanday oldindan bilimga muhtoj emassiz.

[Yangi dastur](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code o'rnatish

Avval sen qurilmangizga Pocket Code dasturini o'rnatishingiz kerak. Ilova qidirish orqali topishingiz mumkin “Pocket Code” bilan Google Play Store va uni urish orqali yuklab olish “oʻrnatish”. Ushbu bosqich uchun Google hisob raqami kerak. Endi qurilmangiz dasturni yuklab olish va o'rnatadi. Internetga ulanishingizga qarab, bu qadam biroz vaqtni talab qilishi mumkin.

![Yangi dastur (2)](../../../media/game-tutorials/New-Program-2.png)

Undan keyin Pocket Code dasturni muvaffaqiyatli yuklab olish va o'rnatishdan so'ng, qurilmangizga qarab dasturlar qutigi yoki bosh ekraniga ega bo'lasiz. Sen ilovani o'zingiz xohlagan joyga joylashtirishingiz mumkin.

Ilova ochilganda turli toifalarni ko'rasiz:

### 3. Yangi loyiha yaratish

Keyingi qadam - yangi loyiha yaratish. Buni bajarish uchun sen o'ng burchakdagi sariq qo'shimcha tugmani bosishingiz mumkin. Endi sen loyiha nomini kiriting va loyihaning landshaft bo'lishi kerakmi yoki yo'qmi tanla. “OK” bosish orqali loyiha yaratilgan.

![Yangi dastur](../../../media/game-tutorials/New-Program.png)

### 4. Sen o'zingizning yangi loyihangizni yaratdingiz.

Endi sen Pocket Code o'rnatgansiz va yangi loyiha yaratish haqida bilasiz. Endi dasturlashni boshlashingiz mumkin!

Buning uchun sen loyiha ichida yangi ob'ektni qanday yaratishni bilishingiz kerak. **[Yangi ob'ekt](new-object.md)** -o'quvga qarang, unda senga hamma narsa qadam-qadam tushuntiriladi.
