Wanneer die plot begin, word elke beweging soos met 'n pen geteken. Die plotter sny later langs hierdie lyne.

Hierdie vos is slegs van reguit lyne gemaak (“Beweeg \_\_\_ treë”) en draai.

**Tip**: Toets jou program terwyl jy dit bou.
