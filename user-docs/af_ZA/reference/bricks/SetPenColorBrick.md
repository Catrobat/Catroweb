![Stel penkleur op rooi 0 groen 0 blou 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Hierdie kodeblok verander die kleur van die pen wat deur die akteur gebruik word. Dit is soos om 'n ander kleur pen te gebruik terwyl jy teken.

**Rooi, groen, blou (RGB)**: Die RGB kleurmodel gebruik verskillende intensiteite van rooi, groen en blou lig om 'n wye spektrum kleure te skep. Elke kleurkomponent (rooi, groen en blou) kan 'n waarde tussen 0 en 255 hê:

- **Rooi**: Die rooi komponent van die kleur. 'n Hoër waarde beteken meer rooi.
- **Groen**: Die groen komponent van die kleur. 'n Hoër waarde beteken meer groen.
- **Blou**: Die blou komponent van die kleur. 'n Hoër waarde beteken meer blou.

Deur verskillende waardes vir rooi, groen en blou te kombineer, kan jy enige kleur skep. Byvoorbeeld:

- `RGB(255, 0, 0)` is suiwer rooi.
- `RGB(0, 255, 0)` is suiwer groen.
- `RGB(0, 0, 255)` is suiwer blou.
- `RGB(255, 255, 255)` is wit (maksimum rooi, groen en blou).
- `RGB(0, 0, 0)` is swart (geen kleur nie).

As jy hierdie kleure in verskillende hoeveelhede meng, skep dit al die kleure wat jy op digitale skerms sien.
