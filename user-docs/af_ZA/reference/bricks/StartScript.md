![Wanneer toneel begin](../../../media/bricks/When_scene_starts_btn2.png)

As jy hierdie blok gebruik, sal die skrif begin onmiddellik wanneer die toneel begin. 'n Scene is die begin van jou program. 'n Scenario is 'n nuwe uitsig in jou program waarin ander elemente vertoon kan word en verskillende interaksies kan plaasvind. Jy kan baie toneelstukke vir verskillende fases in jou program hê. Byvoorbeeld, een toneel vir die inleiding, een toneel vir die hoofmenu, een vir die eerste vlak, een vir die tweede vlak en so aan. Met eenvoudiger programme kan 'n enkele toneel ook genoeg wees, dan is die begin van jou program ook die begin van die toneel.

Soos elke skrif, begin hierdie een met 'n gebeurtenis kodeblok: die gebeurtenis definieer **wanneer** die skrif begin, die kodeblokke nadat dit sê vir die program **wat** om te doen.
