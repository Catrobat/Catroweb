Pocket Code is die hoof-app van Catrobat, 'n gratis en open source mobiele app wat jou toelaat om speletjies, animasies en interaktiewe stories direk op jou slimfoon of tablet te skep. Met die **blokgebaseerde koderingstelsel** in Pocket Code kan jy projekte bou deur kodeblokke saam te sny - soos om stukke van 'n legkaart saam te stel. Geen programmeringservaring is nodig nie, wat dit ideaal maak vir beginners!

Pocket Code gaan verder as net digitale projekte. Met nuwe **makerspace funksies**, kan jy ook ontwerp **SVG lêers vir sny-plotters**. Dit beteken jy kan jou digitale skeppings in werklike items omskep en kreatiewe moontlikhede buite die skerm ondersoek.

Of jy nou leer om te kodeer, eksperimenteer met nuwe idees of programmeer onderrig, Pocket Code bied 'n speelse, toeganklike manier om in kodering te duik
