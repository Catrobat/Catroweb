Pocket Code is 'n visuele programmering app wat jou toelaat om speletjies, animasies en interaktiewe stories direk op jou slimfoon of tablet te skep. Met behulp van 'n intuïtiewe sleep-en-laat koppelvlak met “kodeblokke” (kodeblokke), kan jy jou projekte ontwerp sonder vooraf programmering ervaring. Jy kan maklik klank, beelde en beweging byvoeg om jou idees tot lewe te bring.

Hierdie gids sal jou help om te begin deur te verduidelik hoe:

- Navigeer die koppelvlak,
- Skep jou eerste projek,
- Werk met voorwerpe en agtergronde,
- Gebruik kodeblokke om aksies te programmeer, en
- Bespaar jou projek.

Ideaal vir beginners en opvoeders, Pocket Code moedig kreatiwiteit aan, probleemoplossing en logiese denke.
