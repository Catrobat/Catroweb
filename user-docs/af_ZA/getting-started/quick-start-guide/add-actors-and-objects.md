Tik op die plusknoppie om 'n nuwe figuur of voorwerp by jou projek te voeg.

![Voeg 'n akteur by](../../../media/getting-started/FigurHinzufuegen.png)

In Pocket Code kan jy 'n karakter of voorwerp by jou projek voeg op verskillende maniere:

**Teken**: Jy kan jou eie karakter te skep met **Pocket Paint**. Pocket Paint is 'n tekening program ([meer oor Pocket Paint](https://catrobat.org/docs/pocket-paint/))

**Kostuums**: Kies een uit 'n versameling vooraf gemaakte akteurs en voorwerpe ([meer oor die mediabiblioteek](../elements/medialibrary.md)).

**Galery**: Jy kan 'n beeld kies uit die galery van jou slimfoon.

**Biblioteek**: In die biblioteek sal jy akteurs en voorwerpe vind wat reeds geprogrammeer is, wat beteken dat hulle reeds 'n skrif het. Jy kan hulle kies as jy gereedgemaakte elemente in jou spel wil gebruik (bv. 'n aftelling ([meer oor die biblioteek](../elements/medialibrary.md#voeg-n-voorwerp-by-uit-die-mediabiblioteek)).

**Kamera**: Jy kan die kamera van jou toestel gebruik om 'n foto te neem en dit as 'n karakter by te voeg.

**Rugsak**: Die rugsak is tans leeg. Jy kan akteurs of voorwerpe wat jy in jou rugsak gestoor het, hergebruik. Die hele skrif sal met dit uitpak word ([meer oor die rugsak](../elements/backpack.md)).

**Plaaslike karakters en voorwerpe**: Hier sal jy gereedgemaakte karakters vind wat jy in jou projek kan gebruik. Plaaslike akteurs en voorwerpe funksioneer soos 'n offline mediabiblioteek, wat beteken dat jy selfs as jy nie 'n internetverbinding het nie, toegang tot hierdie akteurs kan kry.

**Leë voorwerp**: Voeg 'n leë voorwerp by, wat 'n voorwerp is wat geen voorkoms het nie. Jy kan hierdie voorwerp normaalweg te programmeer.

**Plaaslike projekte**: Kies 'n projek waaruit jy die eerste akteur saam met die skrif in jou projek wil insit.
