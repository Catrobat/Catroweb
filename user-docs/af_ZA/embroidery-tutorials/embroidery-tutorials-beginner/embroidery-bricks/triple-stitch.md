Die drievoudige naaldwerk brei elke naaldwerk drie keer op.

Die drievoudige naald spring terug ná die eerste naald, naald, dan spring dit weer vorentoe en naald weer.

![Begin drievoudige naald met lengte 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Werk dieselfde as die [loop naaldwerk](running-stitch.md).

![Begin drievoudige steek met lengte](../../../../media/embroidery-tutorials/TripleStitch.png)

Dit maak die naald langer.
