Nechá stroj šiť nepretržite s premenlivou dĺžkou.

Priamy steh zvyčajne kombinuješ s pohybovým blokom.

![Začiatok priameho stehu s dĺžkou 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Stroj spustí priamy steh, ktorý bude šiť každých **10 krokov**.

Potom sa stroj posunie o **200 krokov**.

Výsledkom je **20 stehov**.

![Priamy steh](../../../../media/embroidery-tutorials/RunningStitch.png)

Priamy steh uľahčuje šitie švu, pretože už nepotrebuješ slučku.
