Pocket Code je vizuálna programovacia aplikácia, ktorá ti umožní vytvárať hry, animácie a interaktívne príbehy priamo v smartfóne alebo tablete. Vďaka intuitívnemu rozhraniu presúvania s „blokmi“ (blokmi kódu) môžeš navrhovať svoje projekty aj bez predchádzajúcich znalostí programovania. Ľahko pridáš zvuky, obrázky a pohyb, aby tvoje nápady ožili.

Tento návod ti pomôže začať tým, že ti vysvetlí, ako:

- sa orientovať v rozhraní,
- vytvoriť svoj prvý projekt,
- pracovať s objektmi a pozadiami,
- používať bloky na naprogramovanie akcií a
- uložiť svoj projekt.

Pocket Code je ideálny pre začiatočníkov a učiteľov a podporuje kreativitu, riešenie problémov a logické myslenie.
