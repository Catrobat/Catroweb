[Otvor obrázok](../../../media/getting-started/FigurHinzufuegen.png)

V aplikácii Pocket Code môžeš do projektu pridať postavu alebo objekt rôznymi spôsobmi:

**Nakresliť**: Vlastnú postavu si môžeš nakresliť v aplikácii **Pocket Paint**. Pocket Paint je kresliaci program ([viac o Pocket Paint](https://catrobat.org/pocket-paint/))

**Vzhľady**: Vyber si z kolekcie hotových postáv a objektov ([viac o knižnici médií](../elements/medialibrary.md)).

**Galéria**: Môžeš vybrať obrázok z galérie v telefóne.

**Knižnica**: V knižnici nájdeš postavy a objekty, ktoré už sú naprogramované, teda už majú skript. Môžeš si ich vybrať, ak chceš do hry použiť hotové prvky (napríklad odpočítavanie) ([viac o knižnici](../elements/medialibrary.md#pridaj-objekt-z-knižnice-médií)).

**Kamera**: Pomocou kamery zariadenia môžeš urobiť fotku a pridať ju ako postavu.

**Batoh**: Batoh je zatiaľ prázdny. Môžeš znovu použiť postavy alebo objekty, ktoré si uložil do batoha. Celý skript sa pri tom rozbalí ([viac o batohu](../elements/backpack.md)).

**Miestne postavy a objekty**: Tu nájdeš hotové postavy, ktoré môžeš použiť vo svojom projekte. Miestne postavy a objekty fungujú ako knižnica médií bez pripojenia na internet, takže k týmto postavám máš prístup aj bez internetu.

**Prázdny objekt**: Pridaj prázdny objekt, ktorý nemá žiadny vzhľad. Tento objekt môžeš programovať úplne normálne.

**Miestne projekty**: Vyber projekt, z ktorého chceš do svojho projektu vložiť prvú postavu spolu so skriptom.
