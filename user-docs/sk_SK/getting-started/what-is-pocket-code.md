Pocket Code je hlavná aplikácia Catrobat, bezplatná open-source mobilná aplikácia, ktorá ti umožní vytvárať hry, animácie a interaktívne príbehy priamo v smartfóne alebo tablete. Pomocou **blokového programovacieho systému** Pocket Code môžeš skladať projekty z programovacích blokov – ako keď skladáš kúsky skladačky. Programovacie skúsenosti netreba, a preto je aplikácia ideálna pre začiatočníkov!

Pocket Code ide nad rámec digitálnych projektov. S novými **funkciami pre makerspace** môžeš navrhovať aj **súbory SVG pre rezacie plotre**. To znamená, že svoje digitálne výtvory môžeš premeniť na skutočné predmety a objaviť tvorivé možnosti, ktoré presahujú obrazovku.

Či sa učíš programovať, skúšaš nové nápady alebo učíš programovanie, Pocket Code ponúka zábavný a dostupný spôsob, ako sa do programovania ponoriť.

[Viac informácií](https://catrobat.org/pocket-code/)
