![Nastav farbu pera na červená 0, zelená 0, modrá 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Tento blok zmení farbu pera, ktorým postava kreslí. Je to ako prepnúť na pero inej farby pri kreslení.

**Červená, zelená, modrá (RGB)**: Model farieb RGB používa rôzne intenzity červeného, zeleného a modrého svetla, aby vytvoril široké spektrum farieb. Každá zložka farby (červená, zelená a modrá) môže mať hodnotu od 0 do 255:

- **Červená**: Červená zložka farby. Vyššia hodnota znamená viac červenej.
- **Zelená**: Zelená zložka farby. Vyššia hodnota znamená viac zelenej.
- **Modrá**: Modrá zložka farby. Vyššia hodnota znamená viac modrej.

Kombináciou rôznych hodnôt červenej, zelenej a modrej môžeš vytvoriť akúkoľvek farbu. Napríklad:

- `RGB(255, 0, 0)` je čistá červená.
- `RGB(0, 255, 0)` je čistá zelená.
- `RGB(0, 0, 255)` je čistá modrá.
- `RGB(255, 255, 255)` je biela (maximum červenej, zelenej a modrej).
- `RGB(0, 0, 0)` je čierna (žiadna farba).

Miešaním týchto farieb v rôznom množstve vzniknú všetky farby, ktoré vidíš na digitálnych obrazovkách.
