Tento blok vytvorí kópiu vybraného objektu, takzvaný klon, ktorý sa správa rovnako ako originál. Predstav si, že zdvojíš postavu alebo objekt vo svojej hre. Klon môže mať vlastné správanie a skripty, takže môžeš vytvoriť viacero samostatne konajúcich exemplárov objektu.
