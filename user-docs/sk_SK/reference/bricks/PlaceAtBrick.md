![Umiestni na x y](../../../media/bricks/place_at_x_y_brick.png)

Presunie objekt na konkrétnu pozíciu na obrazovke, ktorú určujú súradnice x a y. Je to ako teleportovať svoju postavu na presné miesto.

Pozícia sa zadáva v súradnicovej sústave ako kartézska rovina: osi x a y prechádzajú stredom obrazovky, takže x = 0 a y = 0 je stred obrazovky.
