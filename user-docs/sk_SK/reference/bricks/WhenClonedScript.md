![Keď začneš ako klon](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Vytvorenému klonu objektu zadáš pokyny, aby vykonal požadované akcie. Tento postup umožňuje zopakovať funkcie pôvodného objektu a klon zároveň ovládať samostatne. Správanie alebo vlastnosti klonu sa dajú nastaviť tak, aby spĺňali konkrétne požiadavky.
