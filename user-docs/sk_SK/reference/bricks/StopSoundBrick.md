Tento blok zastaví prehrávanie konkrétneho zvuku. Je to ako stlačiť tlačidlo stop len pri jednej piesni, zatiaľ čo ostatné zvuky alebo hudba hrajú ďalej. Predstav si, že svojej postave povieš, aby prestala hrať jednu konkrétnu zvukovú stopu.
