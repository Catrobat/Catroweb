Keď sa plot spustí, každý pohyb sa kreslí, akoby perom. Sú to čiary, pozdĺž ktorých ich plotter neskôr vyreže.

Táto líška je tvorená len rovnými čiarami („Pohni sa o ___ krokov“) a zákrutami.

**Tip**: Svoj program si testuj už počas toho, ako ho tvoríš.
