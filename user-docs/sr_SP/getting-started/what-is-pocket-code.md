Pocket Code је главна Catrobat апликација, бесплатна мобилна апликација отвореног кода која ти омогућава да правиш игрице, анимације и интерактивне приче директно на свом паметном телефону или таблету. Користећи Pocket Code-ов **систем програмирања заснован на блоковима**, можеш да правиш пројекте тако што спајаш блокове кода – као кад слажеш делове слагалице. Није потребно никакво знање програмирања, зато је савршена за почетнике!

Pocket Code иде даље од дигиталних пројеката. Уз нове **радионица функције** можеш да правиш и **SVG датотеке за плотере за сечење**. То значи да своје дигиталне креације можеш да претвориш у праве предмете и да истражујеш креативне могућности ван екрана.

Било да учиш да програмираш, испробаваш нове идеје или предајеш програмирање, Pocket Code пружа забаван и приступачан начин да уђеш у свет програмирања.

[Више информација](https://catrobat.org/pocket-code/)
