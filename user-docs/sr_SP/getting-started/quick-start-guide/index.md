Pocket Code је апликација за визуелно програмирање која ти омогућава да правиш игрице, анимације и интерактивне приче директно на свом паметном телефону или таблету. Користећи интуитиван интерфејс за превлачење са „блоковима“ (блокови кода), можеш да правиш своје пројекте без претходног искуства у програмирању. Лако додај звукове, слике и покрете да оживиш своје идеје.

Овај водич ће ти помоћи да почнеш тако што ће објаснити како да:

- крећеш кроз интерфејс,
- направиш свој први пројекат,
- радиш са објектима и позадинама,
- користиш блокове за програмирање радњи и
- сачуваш свој пројекат.

Pocket Code је савршен за почетнике и наставнике, и подстиче креативност, решавање проблема и логичко размишљање.
