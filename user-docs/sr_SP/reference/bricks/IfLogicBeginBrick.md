![Ако је тачно, онда … Иначе](../../../media/bricks/if_else_brick2.png)

*Проверава да ли је услов тачан и изводи један скуп наредби ако јесте, а други ако није. Као кад даш две могућности: „Ако је ово тачно, уради ово; иначе, уради оно.“*

![Када сцена почне](../../../media/bricks/StartScene.png)

Кад сцена почне, променљива X се постави на 0.

![Иначе](../../../media/bricks/IfElse.png)

Ако је животиња сада додирнута, проверава се да ли је X по модулу 2 тачно, то јест да ли је X непаран број.

Ако јесте, пушта се звук Tweet1 и променљива X се повећава за 1.

Иначе, ако је X паран, само се X повећава за 1.

Наредбе које треба извршити раздвајају се блоком Крај услова.
