![Почни да црташ](../../../media/bricks/Start_to_plot.png)

Овај блок почиње цртање док се лик креће. Слично је као кад спустиш оловку на папир да почнеш да црташ линију. Ако хоћеш да паузираш цртање и померићеш лик на друго место, користи блок „Престани да црташ“, а затим поново почни блоком „Почни да црташ“.
