![Постави фактор одбијања на](../../../media/bricks/set_bounce_factor_to_brick.png)

Поставља колико ће објекат одскочити кад нешто удари у њега. Већи проценат значи јачи одскок. Као кад одлучујеш колико се твој лик одбија од зидова или других предмета.
