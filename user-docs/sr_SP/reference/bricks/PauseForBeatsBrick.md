![Паузирај за 1 удар](../../../media/bricks/Pause_for_1_beats.png)

Овај блок чека одређени број удараца пре него што настави скрипту. Као кад се накратко одмориш у песми пре следеће ноте или звука. Замисли да паузираш свој наступ, бројиш удар по удар, па опет наставиш радњу.
