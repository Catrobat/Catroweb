![Постави боју оловке на црвену 0, зелену 0, плаву 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Овај блок мења боју оловке којом црта лик. Као кад док црташ, узмеш оловку друге боје.

**Црвена, зелена, плава (RGB)**: RGB модел боја користи различите јачине црвене, зелене и плаве светлости да направи широк спектар боја. Свака компонента боје (црвена, зелена и плава) може имати вредност од 0 до 255:

- **Црвена**: Црвена компонента боје. Већа вредност значи више црвене.
- **Зелена**: Зелена компонента боје. Већа вредност значи више зелене.
- **Плава**: Плава компонента боје. Већа вредност значи више плаве.

Мешањем различитих вредности црвене, зелене и плаве можеш да направиш било коју боју. На пример:

- `RGB(255, 0, 0)` је чиста црвена.
- `RGB(0, 255, 0)` је чиста зелена.
- `RGB(0, 0, 255)` је чиста плава.
- `RGB(255, 255, 255)` је бела (највише црвене, зелене и плаве).
- `RGB(0, 0, 0)` је црна (нема боје).

Мешањем ових боја у различитим количинама настају све боје које видиш на дигиталним екранима.
