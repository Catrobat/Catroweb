![Постави на x и y](../../../media/bricks/place_at_x_y_brick.png)

Помера објекат на одређени положај на екрану, који су одредиле x и y координате. Као кад телепортујеш свог лика на тачно место.

Положај се задаје у координатном систему, као Декартова раван: x и y осе пролазе кроз средину екрана, па су x = 0 и y = 0 средина екрана.
