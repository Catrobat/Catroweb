Машина шије непрекидно, са променљивом дужином.

Прави бод обично комбинујеш са блоком за померање.

![Почни прави бод дужине 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Машина почиње прави бод који ће шити на сваких **10 корака**.

Онда се машина помери за **200 корака**.

То даје **20 убода**.

![Прави бод](../../../../media/embroidery-tutorials/RunningStitch.png)

Прави бод олакшава шивење шава јер ти више није потребна петља.
