Pocket Code, Catrobat ਦੀ ਮੁੱਖ ਐਪ ਹੈ। ਇਹ ਮੁਫ਼ਤ ਹੈ ਤੇ ਇਸ ਦਾ ਸੋਰਸ ਕੋਡ ਖੁੱਲ੍ਹਾ ਹੈ। ਇਸ ਨਾਲ ਆਪਣੇ ਫ਼ੋਨ ਜਾਂ ਟੈਬਲੈੱਟ ’ਤੇ ਖੇਡਾਂ, ਐਨੀਮੇਸ਼ਨ ਤੇ ਅਜਿਹੀਆਂ ਕਹਾਣੀਆਂ ਬਣਾ ਜਿਨ੍ਹਾਂ ਵਿੱਚ ਤੂੰ ਹਿੱਸਾ ਲੈ ਸਕੇਂ। Pocket Code ਵਿੱਚ **ਬਲਾਕ ਜੋੜ ਕੇ ਕੋਡ ਬਣਾਉਂਦੇ ਹਾਂ**। ਜਿਵੇਂ ਪਹੇਲੀ ਦੇ ਟੁਕੜੇ ਜੋੜਦੇ ਹਾਂ, ਉਸੇ ਤਰ੍ਹਾਂ ਕੋਡ ਬਲਾਕ ਜੋੜ ਕੇ ਆਪਣਾ ਪ੍ਰੋਜੈਕਟ ਬਣਾ। ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਪਹਿਲਾਂ ਤੋਂ ਕੋਡਿੰਗ ਆਉਣੀ ਜ਼ਰੂਰੀ ਨਹੀਂ!

Pocket Code ਸਿਰਫ਼ ਡਿਜੀਟਲ ਪ੍ਰੋਜੈਕਟਾਂ ਤੋਂ ਪਰੇ ਹੈ। ਨਵ **ਮੇਕਰਸਪੇਸ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ** ਨਾਲ, ਤੈਨੂੰ ਇਹ ਵੀ ਡਿਜ਼ਾਇਨ ਕਰ ਸਕਦਾ ਹੈਂ **SVG ਕੱਟਣ ਵਾਲੇ ਟਰਾਪਟਰਾਂ ਲਈ ਫਾਈਲਾਂ**. ਇਸ ਦਾ ਮਤਲਬ ਹੈ ਕਿ ਤੂੰ ਆਪਣੀਆਂ ਡਿਜੀਟਲ ਰਚਨਾਵਾਂ ਨੂੰ ਅਸਲ ਸੰਸਾਰ ਦੀਆਂ ਚੀਜ਼ਾਂ ਵਿੱਚ ਬਦਲ ਸਕਦੇ ਹੋ ਅਤੇ ਸਕ੍ਰੀਨ ਤੋਂ ਪਰੇ ਸਿਰਜਣਾਤਮਕ ਸੰਭਾਵਨਾਵਾਂ ਦੀ ਪੜਚੋਲ ਕਰ ਸਕਦਾ ਹੈਂ।

ਭਾਵੇਂ ਤੂੰ ਕੋਡਿੰਗ ਸਿੱਖ ਰਹੇ ਹੋ, ਨਵੇਂ ਵਿਚਾਰਾਂ ਨਾਲ ਪ੍ਰਯੋਗ ਕਰ ਰਹੇ ਹੋ ਜਾਂ ਪ੍ਰੋਗਰਾਮਿੰਗ ਸਿਖਾ ਰਹੇ ਹੋ, Pocket Code ਕੋਡਿੰਗ ਵਿੱਚ ਡੁੱਬਣ ਦਾ ਇੱਕ ਖੇਡਦਾ ਹੈ, ਪਹੁੰਚਯੋਗ ਤਰੀਕਾ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ
