Pocket Code ਇੱਕ ਵਿਜ਼ੂਅਲ ਪ੍ਰੋਗਰਾਮਿੰਗ ਐਪ ਹੈ ਜੋ ਤੈਨੂੰ ਆਪਣੇ ਸਮਾਰਟਫੋਨ ਜਾਂ ਟੈਬਲੇਟ ਤੇ ਸਿੱਧੇ ਗੇਮਾਂ, ਐਨੀਮੇਸ਼ਨ ਅਤੇ ਇੰਟਰਐਕਟਿਵ ਕਹਾਣੀਆਂ ਬਣਾਉਣ ਦੀ ਆਗਿਆ ਦਿੰਦੀ ਹੈ. “ਕੋਡ ਬਲਾਕ” (ਕੋਡ ਬਲਾਕ) ਦੇ ਨਾਲ ਇੱਕ ਅਨੁਭਵੀ ਡਰੈਗ-ਐਂਡ-ਡ੍ਰੌਪ ਇੰਟਰਫੇਸ ਦੀ ਵਰਤੋਂ ਕਰਕੇ, ਤੂੰ ਆਪਣੇ ਪ੍ਰੋਜੈਕਟਾਂ ਨੂੰ ਬਿਨਾਂ ਕਿਸੇ ਪ੍ਰੋਗਰਾਮਿੰਗ ਤਜਰਬੇ ਦੇ ਡਿਜ਼ਾਈਨ ਕਰ ਸਕਦਾ ਹੈਂ. ਆਪਣੇ ਵਿਚਾਰਾਂ ਨੂੰ ਜੀਵਨ ਵਿੱਚ ਲਿਆਉਣ ਲਈ ਆਵਾਜ਼ਾਂ, ਤਸਵੀਰਾਂ ਅਤੇ ਅੰਦੋਲਨ ਨੂੰ ਆਸਾਨੀ ਨਾਲ ਜੋੜੋ।

ਇਹ ਗਾਈਡ ਤੈਨੂੰ ਇਸ ਬਾਰੇ ਦੱਸ ਕੇ ਸ਼ੁਰੂਆਤ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰੇਗੀ ਕਿ ਕਿਵੇਂਃ:

- ਇੰਟਰਫੇਸ ਨੂੰ ਨੈਵੀਗੇਟ ਕਰੋ,
- ਆਪਣਾ ਪਹਿਲਾ ਪ੍ਰੋਜੈਕਟ ਬਣਾਓ,
- ਵਸਤੂਆਂ ਅਤੇ ਪਿਛੋਕੜਾਂ ਨਾਲ ਕੰਮ ਕਰਨਾ,
- ਕਾਰਵਾਈਆਂ ਨੂੰ ਪ੍ਰੋਗਰਾਮ ਕਰਨ ਲਈ ਕੋਡ ਬਲਾਕ ਦੀ ਵਰਤੋਂ ਕਰੋ, ਅਤੇ
- ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਬਚਾਓ.

ਸ਼ੁਰੂਆਤ ਕਰਨ ਵਾਲਿਆਂ ਅਤੇ ਅਧਿਆਪਕਾਂ ਲਈ ਸੰਪੂਰਨ, Pocket Code ਰਚਨਾਤਮਕਤਾ, ਸਮੱਸਿਆ ਹੱਲ ਕਰਨ ਅਤੇ ਤਰਕਸ਼ੀਲ ਸੋਚ ਨੂੰ ਉਤਸ਼ਾਹਿਤ ਕਰਦਾ ਹੈ.
