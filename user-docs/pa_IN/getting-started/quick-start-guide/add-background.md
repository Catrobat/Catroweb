ਤੂੰ ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਇੱਕ ਪਿਛੋਕੜ ਜੋੜ ਸਕਦੇ ਹੋ Catrobat.

ਪਿਛੋਕੜ ਨੂੰ ਕਈ ਤਰੀਕਿਆਂ ਨਾਲ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ। Pocket Code ਵਿੱਚ, ਉਹਨਾਂ ਨੂੰ ਦ੍ਰਿਸ਼ਟੀਗਤ ਤੌਰ ਤੇ ਵਧਾਉਣ ਲਈ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ **ਖੇਡਾਂ**, ਦੱਸੋ **ਕਹਾਣੀਆਂ**, ਜਾਂ ਆਪਣੇ ਅਦਾਕਾਰਾਂ ਅਤੇ ਵਸਤੂਆਂ ਨੂੰ ਵਧੇਰੇ ਪ੍ਰਸੰਗ ਪ੍ਰਦਾਨ ਕਰੋ.

ਮੇਕਰਸਪੇਸ ਡਿਵਾਈਸਾਂ ਲਈ ਜਿਵੇਂ ਕਿ **ਕੰਟਰੋਲਰ** ਜਾਂ **ਕਢਾਈ ਦੀਆਂ ਮਸ਼ੀਨਾਂ**, ਪਿਛੋਕੜ ਡਿਜ਼ਾਈਨ ਟੈਂਪਲੇਟਸ ਵਜੋਂ ਕੰਮ ਕਰਦੇ ਹਨ, ਜਿਵੇਂ ਕਿ ਕੱਟਣ ਜਾਂ ਕਢਾਈ ਦੇ ਪੈਟਰਨ ਲਈ.

ਇੱਕ ਪਿਛੋਕੜ ਜੋੜਨ ਲਈ, ਪ੍ਰੋਜੈਕਟ ਵਿਯੂ ਵਿੱਚ “ਪਿਛੋਕੜ” ਤੇ ਟੈਪ ਕਰੋ।

![ਪਿਛੋਕੜ ਬਾਰੇ ਸੁਝਾਅ](../../../media/getting-started/grafik-16.png)

**ਸਕ੍ਰਿਪਟ ਭਾਗ(2)** ਵਿੱਚ, ਤੂੰ ਆਪਣੇ ਪਿਛੋਕੜ ਨੂੰ ਪ੍ਰੋਗਰਾਮ ਕਰ ਸਕਦਾ ਹੈਂ - ਹਾਲਾਂਕਿ, ਸਾਰੇ ਬਲਾਕ ਇਸ ਲਈ ਉਪਲਬਧ ਨਹੀਂ ਹਨ. ਹੇਠ ਲਿਖੇ ਦੋ ਬਲਾਕ ਵਿਸ਼ੇਸ਼ ਤੌਰ 'ਤੇ ਮਹੱਤਵਪੂਰਨ ਹਨਃ ![ਪਾਰਦਰਸ਼ਤਾ 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) ਅਤੇ ![ਆਕਾਰ ਨੂੰ ਇਸ 'ਤੇ ਸੈੱਟ ਕਰੋ: 60%](../../../media/bricks/Set_size_to_60_pct_.png)

**ਵੇਖਦਾ ਹੈ ਭਾਗ(1)** ਵਿੱਚ, ਤੈਨੂੰ ਇੱਕ ਪਿਛੋਕੜ ਸ਼ਾਮਿਲ ਕਰੋ. ਇਸ ਨੂੰ ਕਰਨ ਲਈ, + ਪ੍ਰਤੀਕ ਨੂੰ ਟੈਪ ਕਰੋ.

![ਪਿਛੋਕੜ ਜੋੜੋ](../../../media/getting-started/grafik-14.png)

ਤੂੰ ਆਪਣੀਆਂ ਤਸਵੀਰਾਂ ਅਪਲੋਡ ਕਰ ਸਕਦਾ ਹੈਂ, ਪਹਿਲਾਂ ਤੋਂ ਪਰਿਭਾਸ਼ਿਤ ਪਿਛੋਕੜ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦਾ ਹੈਂ ਜਾਂ ਆਪਣੇ ਆਪ ਪਿਛੋਕੜ ਬਣਾ ਸਕਦੇ ਹੋ।

**ਚਿੱਤਰ ਬਣਾਓ**: ਤੈਨੂੰ ਆਪਣੇ ਹੀ ਪਿਛੋਕੜ ਬਣਾ ਸਕਦੇ ਹੋ ਨਾਲ **Pocket Paint**. Pocket Paint ਇੱਕ ਡਰਾਇੰਗ ਪ੍ਰੋਗਰਾਮ ([ਬਾਰੇ ਹੋਰ Pocket Paint](https://catrobat.org/pocket-paint/)) ਹੈ

**ਦਿੱਖਾਂ**: ਪ੍ਰੀ-ਮੇਡ ਬੈਕਗ੍ਰਾਉਂਡਾਂ ਦੇ ਸੰਗ੍ਰਹਿ ਵਿੱਚੋਂ ਇੱਕ ਚੁਣੋ ([ਮੀਡੀਆ ਲਾਇਬ੍ਰੇਰੀ ਬਾਰੇ ਹੋਰ](../elements/medialibrary.md)).

**ਗੈਲਰੀ**: ਤੂੰ ਆਪਣੇ ਸਮਾਰਟਫੋਨ ਦੀ ਗੈਲਰੀ ਤੋਂ ਇੱਕ ਚਿੱਤਰ ਚੁਣ ਸਕਦੇ ਹੋ।

**ਕੈਮਰਾ**: ਤੂੰ ਆਪਣੇ ਡਿਵਾਈਸ ਦੇ ਕੈਮਰੇ ਦੀ ਵਰਤੋਂ ਫੋਟੋ ਲੈਣ ਅਤੇ ਇਸਨੂੰ ਪਿਛੋਕੜ ਵਜੋਂ ਜੋੜਨ ਲਈ ਕਰ ਸਕਦਾ ਹੈਂ।

![ਮੀਡੀਆ ਲਾਇਬ੍ਰੇਰੀ ਵਿੱਚੋਂ ਚੁਣੋ](../../../media/getting-started/grafik-17.png)

ਤੂੰ ਹੁਣ ਇੱਕ ਪਿਛੋਕੜ ਜੋੜਿਆ ਹੈ। **ਪ੍ਰੋਜੈਕਟ ਵਿਊ** ਨੂੰ ਵਾਪਸ ਕਰਨ ਲਈ ਸੱਜੇ ਸਿਖਰ 'ਤੇ ਪਿਛਲੇ ਤੀਰ' ਤੇ ਕਲਿੱਕ ਕਰੋ.
