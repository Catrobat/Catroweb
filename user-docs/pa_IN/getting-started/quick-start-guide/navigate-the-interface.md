ਜਦੋਂ ਤੂੰ ਸ਼ੁਰੂ ਕਰਦੇ ਹੋ Pocket Code, ਤੈਨੂੰ ਹੇਠ ਦਿੱਤੀ ਮੁੱਖ ਸਕ੍ਰੀਨ ਦਿਖਾਈ ਦਿੰਦੀ ਹੈ.

![ਮੁੱਖ ਸਕ੍ਰੀਨ](../../../media/getting-started/MainScreen-e1732269599192.jpg)

ਸੱਜੇ ਉੱਪਰਲੇ ਕੋਨੇ ਵਿੱਚ, ਇੱਕ ![ਮਦਦ](../../../media/getting-started/Screenshot-2024-11-22-111748.png) ਪ੍ਰਤੀਕ ਹੈ ਜੋ ਤੈਨੂੰ Catrobat ਦਸਤਾਵੇਜ਼ ਵੱਲ ਲੈ ਜਾਂਦਾ ਹੈ, ਜਿਸ ਵਿੱਚ ਤੇਰੇ ਲਈ ਮਦਦਗਾਰ ਸੁਝਾਅ ਹਨ.

ਇਸਦੇ ਅੱਗੇ ਮੇਨੂ ਹੈ ![ਮੇਨੂ](../../../media/getting-started/Screenshot-2024-11-22-111804.png). ਉੱਥੇ ਤੋਂ, ਤੂੰ ਆਸਾਨੀ ਨਾਲ ਸੈਟਿੰਗਜ਼ ਤੇ ਜਾ ਸਕਦੇ ਹੋ, ਜਿੱਥੇ ਤੂੰ ਭਾਸ਼ਾ ਬਦਲ ਸਕਦੇ ਹੋ ਜਾਂ ਐਕਸਟੈਂਸ਼ਨਾਂ ਨੂੰ ਚਾਲੂ ਕਰ ਸਕਦਾ ਹੈਂ ਜਿਵੇਂ ਕਿ ਪਲਾਟ ਬਲਾਕ ਅਤੇ ਹੋਰ.

ਹੇਠਾਂ, ਤੂੰ ਆਪਣੇ ਸਭ ਤੋਂ ਨਵੇਂ ਸੰਪਾਦਿਤ ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਦੇਖ ਸਕਦੇ ਹੋ। ਪ੍ਰੋਜੈਕਟ ਸਕ੍ਰੀਨ ਤੇ ਪਹੁੰਚਣ ਲਈ ਸੰਪਾਦਨ ਆਈਕਾਨ ![ਆਈਕਾਨ ਸੰਪਾਦਿਤ ਕਰੋ](../../../media/getting-started/Screenshot-2024-11-22-111825.png) 'ਤੇ ਕਲਿੱਕ ਕਰੋ, ਜਿੱਥੇ ਤੂੰ ਆਪਣਾ ਪ੍ਰੋਜੈਕਟ ਵਿਕਸਿਤ ਕਰਨਾ ਜਾਰੀ ਰੱਖ ਸਕਦੇ ਹੋ.

ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਪਲੇ ਬਟਨ ![ਆਪਣਾ ਪ੍ਰੋਜੈਕਟ ਸ਼ੁਰੂ ਕਰੋ](../../../media/getting-started/Screenshot-2024-11-22-111818.png) ਦੀ ਵਰਤੋਂ ਕਰੋ।

'ਤੇ ਕਲਿੱਕ ਨਾਲ ਪ੍ਰੋਜੈਕਟ, ਤੂੰ ਆਪਣੇ ਸੁਰੱਖਿਅਤ ਪ੍ਰੋਜੈਕਟਾਂ ਤੱਕ ਪਹੁੰਚ ਸਕਦੇ ਹੋ. ![ਉਪਕਰਣ 'ਤੇ ਪ੍ਰੋਜੈਕਟ](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

ਜੇ ਤੂੰ ਹੋਰ ਉਪਭੋਗਤਾਵਾਂ ਤੋਂ ਵਧੇਰੇ ਪ੍ਰੋਜੈਕਟਾਂ ਬਾਰੇ ਜਾਣਨਾ ਅਤੇ ਉਨ੍ਹਾਂ 'ਤੇ ਕੰਮ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਸਿਰਫ Catrobat ਕਮਿਊਨਿਟੀ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਸ਼ੇਅਰ. ਉੱਥੇ ਤੈਨੂੰ ਬਹੁਤ ਸਾਰੇ ਮਹਾਨ ਪ੍ਰਾਜੈਕਟ ਮਿਲਣਗੇ। ![Catrobat ਕਮਿਊਨਿਟੀ](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

ਜੇਕਰ ਤੈਨੂੰ ਇੱਕ ਨਵ ਪ੍ਰਾਜੈਕਟ ਨੂੰ ਬਣਾਉਣ ਲਈ ਚਾਹੁੰਦੇ ਹੋ, ਪਲੱਸ ਆਈਕਾਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ. ![ਜੋੜੋ](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
