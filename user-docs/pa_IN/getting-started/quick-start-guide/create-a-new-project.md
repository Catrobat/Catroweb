ਆਪਣੇ ਫ਼ੋਨ ਜਾਂ ਟੈਬਲੈੱਟ ’ਤੇ ਐਪ ਖੋਲ੍ਹ।

![ਮੁੱਖ ਸਕ੍ਰੀਨ ਨਵੀਂ ਪ੍ਰੋਜੈਕਟ](../../../media/getting-started/MainScreen_NewProject.png)\
ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਬਣਾਉਣ ਲਈ + ਦਾ ਨਿਸ਼ਾਨ ਦਬਾ।\
[ਤਸਵੀਰ ਖੋਲ੍ਹ](../../../media/getting-started/MainScreen_NewProject.png)

ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਨਾਂ ਦੇ (1)। ਚੁਣ ਕਿ ਖੇਡ ਦੀ ਸਕਰੀਨ ਖੜ੍ਹੀ (ਪੋਰਟਰੇਟ) ਹੋਵੇਗੀ ਜਾਂ ਲੇਟਵੀਂ (ਲੈਂਡਸਕੇਪ) (2)।

![ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ](../../../media/getting-started/NewProject.png)\
ਫਿਰ ਪੱਕਾ ਕਰਨ ਲਈ ਸਹੀ ਦਾ ਨਿਸ਼ਾਨ ਦਬਾ (3)।\
[ਤਸਵੀਰ ਖੋਲ੍ਹ](../../../media/getting-started/NewProject.png)

ਤੂੰ ਹੁਣ ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਦੇ ਦ੍ਰਿਸ਼ਟੀਕੋਣ ਵਿੱਚ ਹੋ. ਸਿਖਰ 'ਤੇ, ਤੂੰ ਆਪਣੀ ਖੇਡ ਦਾ ਨਾਮ ਵੇਖਦੇ ਹੋ।

ਹੇਠਾਂ ਤੂੰ **ਪਿਛੋਕੜ** ਵੇਖ ਸਕਦੇ ਹੋ - ਇਸ ਸਮੇਂ, ਪਿਛੋਕੜ ਖਾਲੀ ਹੈ. ਜੇ ਤੂੰ ਇਸਨੂੰ ਬਦਲਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਇਸ 'ਤੇ ਟੈਪ ਕਰੋ.

ਪਿਛੋਕੜ ਦੇ ਹੇਠਾਂ, ਤੂੰ ਆਪਣੀ **ਅਦਾਕਾਰ ਅਤੇ ਵਸਤੂਆਂ** ਲਈ ਖੇਤਰ ਵੇਖਦੇ ਹੋ ਜੋ ਤੂੰ ਆਪਣੇ ਗੇਮ ਵਿੱਚ ਜੋੜਿਆ ਹੈ. ਇਸ ਸਮੇਂ, ਖੇਤਰ ਅਜੇ ਵੀ ਖਾਲੀ ਹੈ।

ਸੱਜੇ ਪਾਸੇ ਹੇਠਲੇ ਹਿੱਸੇ ਵਿੱਚ, ਤੂੰ ਦੋ ਮਹੱਤਵਪੂਰਨ ਬਟਨ ਵੇਖਦੇ ਹੋਃ:

![ਸ਼ੁਰੂ ਕਰੋ](../../../media/getting-started/Start.png)\
ਨਾਲ **ਚਲਾਓ** ਬਟਨ, ਤੂੰ ਆਪਣੀ ਖੇਡ ਸ਼ੁਰੂ ਕਰੋ.

![ਪਲੱਸ ਬਟਨ](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
**ਅਤੇ ਨਾਲ ਹੀ** ਬਟਨ ਨਾਲ, ਤੈਨੂੰ ਆਪਣੇ ਖੇਡ ਨੂੰ ਇੱਕ ਨਵ ਅੱਖਰ / ਇਕਾਈ ਸ਼ਾਮਿਲ.

![ਪ੍ਰੋਜੈਕਟ ਸਕ੍ਰੀਨ](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
