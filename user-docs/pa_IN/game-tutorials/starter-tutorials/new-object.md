ਇਸ ਟਿਊਟੋਰਿਅਲ ਵਿੱਚ, ਤੂੰ ਸਿੱਖੋਗੇ ਕਿ ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਇੱਕ ਨਵੀਂ ਵਸਤੂ ਕਿਵੇਂ ਬਣਾਈਏ ਅਤੇ ਇਸਦੇ ਲਈ ਤੇਰੇ ਕੋਲ ਵੱਖੋ ਵੱਖਰੀਆਂ ਸੰਭਾਵਨਾਵਾਂ ਹਨ.

![ਨਵੀਂ ਵਸਤੂ](../../../media/game-tutorials/New-Object.png)

ਅਜਿਹਾ ਕਰਨ ਲਈ, ਤੈਨੂੰ ਪਹਿਲਾਂ ਹੀ Pocket Code ਐਪ ਡਾਊਨਲੋਡ ਕਰਨੀ ਚਾਹੀਦੀ ਹੈ ਅਤੇ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਕਿਵੇਂ ਬਣਾਇਆ ਜਾਵੇ ਇਹ ਜਾਣਨਾ ਚਾਹੀਦਾ ਹੈ। ਜੇ ਤੈਨੂੰ ਇਸ ਨਾਲ ਮਦਦ ਦੀ ਲੋੜ ਹੈ, ਤਾਂ **[ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ](new-project.md)** -ਟਿਊਟੋਰਿਅਲ 'ਤੇ ਇੱਕ ਨਜ਼ਰ ਮਾਰੋ।

*ਇੱਥੇ ਤੂੰ ਟਿਊਟੋਰਿਅਲ ਨੂੰ PDF-ਫਾਰਮੈਟ ਵਿੱਚ ਡਾਊਨਲੋਡ ਕਰ ਸਕਦਾ ਹੈਂਃ:*

[ਨਵੀਂ ਵਸਤੂ](../../../media/game-tutorials/New-Object.pdf)

### 1. ਇੱਕ ਨਵੀਂ ਵਸਤੂ ਬਣਾਓ

ਸ਼ੁਰੂ ਵਿੱਚ, ਤੈਨੂੰ ਆਪਣਾ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਖੋਲ੍ਹਣਾ ਚਾਹੀਦਾ ਹੈ।

ਤੂੰ ਇਸਨੂੰ Pocket Code ਐਪ ਦੇ ਹੋਮ ਸਕ੍ਰੀਨ 'ਤੇ ਪਾਓਗੇ। ਜੇਕਰ ਤੇਰੇ ਕੋਲ ਇੱਕ ਤੋਂ ਵੱਧ ਪ੍ਰੋਜੈਕਟ ਹਨ, ਤਾਂ ਤੂੰ “ਪ੍ਰੋਜੈਕਟ” 'ਤੇ ਕਲਿੱਕ ਕਰ ਸਕਦਾ ਹੈਂ। ਫਿਰ ਆਪਣਾ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਚੁਣੋ। ਜੇਕਰ ਤੂੰ ਕੋਈ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਨਹੀਂ ਬਣਾਇਆ ਹੈ ਜਾਂ ਤੈਨੂੰ ਇਸ ਬਾਰੇ ਹੋਰ ਜਾਣਕਾਰੀ ਦੀ ਲੋੜ ਹੈ ਤਾਂ **[ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ](new-project.md)** ਟਿਊਟੋਰਿਅਲ 'ਤੇ ਇੱਕ ਨਜ਼ਰ ਮਾਰੋ।

### 2. ਇੱਕ ਨਵੀਂ ਵਸਤੂ ਬਣਾਓ

ਹੁਣ ਤੂੰ ਇੱਕ ਨਵੀਂ ਚੀਜ਼ ਬਣਾਉਣ ਲਈ ਤਿਆਰ ਹੋ। ਅਜਿਹਾ ਕਰਨ ਲਈ ਸਿਰਫ ਸੱਜੇ ਹੇਠਲੇ ਕੋਨੇ 'ਤੇ ਪੀਲੇ ਪਲੱਸ ਬਟਨ' ਤੇ ਕਲਿੱਕ ਕਰੋ. ਤੈਨੂੰ ਇੱਕ ਨਵੀਂ ਵਿੰਡੋ ਮਿਲੇਗੀ ਜਿਸ ਵਿੱਚ ਤੈਨੂੰ ਚੁਣਨ ਲਈ ਸੱਤ ਸੰਭਾਵਨਾਵਾਂ ਦਿੱਤੀਆਂ ਜਾਣਗੀਆਂ।

![ਨਵੀਂ ਵਸਤੂ (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. ਸਿਰਜਣ ਦੇ ਤਰੀਕੇ

ਇਹ ਉਹ ਸੰਭਾਵਨਾਵਾਂ ਹਨ ਜਿਨ੍ਹਾਂ ਵਿੱਚੋਂ ਤੂੰ ਚੋਣ ਕਰ ਸਕਦਾ ਹੈਂਃ:

![ਨਵੀਂ ਵਸਤੂ (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. ਚਿੱਤਰ ਬਣਾਓ

ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਇਸ ਨੂੰ ਸੰਭਵ ਤੌਰ 'ਤੇ ਆਸਾਨ ਬਣਾਉਣ ਲਈ, ਸਾਨੂੰ “ਚਿੱਤਰ ਬਣਾਓ” ਫੰਕਸ਼ਨ ਵਰਤਣ ਅਤੇ ਸਿਰਫ਼ ਇੱਕ ਬਿੰਦੂ ਨੂੰ ਖਿੱਚਣ ਲਈ ਚਾਹੁੰਦੇ ਹੋ. ਜਦੋਂ ਤੂੰ Pocket Paint ਨਾਲ ਬਿੰਦੂ ਖਿੱਚ ਲਿਆ ਹੈ ਤਾਂ ਤੂੰ ਇਸਨੂੰ ਛੱਡ ਸਕਦੇ ਹੋ (ਇੱਕ ਕਦਮ ਪਿੱਛੇ ਜਾ ਕੇ).

### 5. ਇੱਕ ਨਾਮ ਦਿਓ

ਹੁਣ ਤੈਨੂੰ ਆਪਣੀ ਤਸਵੀਰ ਦਾ ਨਾਂ ਦੇਣਾ ਹੋਵੇਗਾ।

### 6. ਇਸ ਨੂੰ ਪਾਓ

ਇਸ ਤੋਂ ਬਾਅਦ ਤੈਨੂੰ ਇਸਨੂੰ ਆਪਣੀ ਉਂਗਲ ਨਾਲ ਖੱਬੇ/ਸੱਜੇ ਜਾਂ ਉੱਪਰ/ਹੇਠਾਂ ਵੱਲ ਲਿਜਾ ਕੇ ਵਿਜ਼ੂਅਲ ਰੂਪ ਵਿੱਚ ਰੱਖਣਾ ਪਵੇਗਾ। ਤੈਨੂੰ ਇਸ ਨੂੰ ਸੱਜੇ ਉੱਪਰਲੇ ਕੋਨੇ ਵਿੱਚ ਬਟਨ ਨਾਲ ਬਚਾਉਣਾ ਹੈ।

![ਨਵੀਂ ਚੀਜ਼ (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. ਤੂੰ ਆਪਣਾ ਨਵਾਂ ਵਸਤੂ ਬਣਾਇਆ ਹੈ।

ਹੁਣ ਤੇਰੇ ਕੋਲ ਇੱਕ ਪ੍ਰੋਜੈਕਟ ਹੈ ਜਿਸ ਵਿੱਚ ਇੱਕ ਵਸਤੂ ਹੈ ਜੋ ਤੂੰ ਪ੍ਰੋਗਰਾਮ ਕਰ ਸਕਦਾ ਹੈਂ!

ਅਜਿਹਾ ਕਰਨ ਲਈ, ਤੈਨੂੰ ਪਤਾ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ ਕਿ ਕਿਹੜੇ ਕੋਡ ਬਲਾਕ ਉਪਲਬਧ ਹਨ। **[ਪਹਿਲਾ ਕੋਡ ਬਲਾਕ](first-bricks.md)**-ਟਿਊਟੋਰਿਅਲ ਤੈਨੂੰ ਕੋਡ ਬਲਾਕ ਦੀਆਂ ਵੱਖ-ਵੱਖ ਸ਼੍ਰੇਣੀਆਂ ਦਾ ਚੰਗੀ ਤਰ੍ਹਾਂ ਜਾਣਕਾਰੀ ਦਿੰਦਾ ਹੈ। ਹਾਲਾਂਕਿ, ਤੂੰ ਆਪਣੇ ਪਹਿਲੇ ਪ੍ਰੋਜੈਕਟ ਨਾਲ ਸਿੱਧੇ ਤੌਰ 'ਤੇ ਸ਼ੁਰੂਆਤ ਵੀ ਕਰ ਸਕਦਾ ਹੈਂ। ਸ਼ੁਰੂਆਤੀ ਲੜੀ ਵਿੱਚੋਂ ਇੱਕ ਢੁਕਵੀਂ ਟਿਊਟੋਰਿਅਲ ਚੁਣੋ।
