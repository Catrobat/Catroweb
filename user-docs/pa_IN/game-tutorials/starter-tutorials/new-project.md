ਇਸ ਟਿਊਟੋਰਿਅਲ ਵਿੱਚ, ਤੂੰ ਆਪਣੀ ਪਹਿਲੀ ਪ੍ਰੋਜੈਕਟ ਬਣਾਉਣ ਲਈ ਜਾਣਨ ਦੀ ਲੋੜੀਂਦੀ ਹਰ ਚੀਜ਼ ਸਿੱਖੋਗੇ Pocket Code. ਅਸੀਂ ਤੈਨੂੰ ਕਦਮ-ਦਰ-ਕਦਮ ਨਿਰਦੇਸ਼ ਦੇਵਾਂਗੇ ਕਿ ਐਪ ਨੂੰ ਕਿਵੇਂ ਡਾਊਨਲੋਡ ਕਰਨਾ ਹੈ, ਇਸਨੂੰ ਖੋਲ੍ਹਣਾ ਹੈ ਅਤੇ ਇੱਕ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਕਿਵੇਂ ਬਣਾਇਆ ਜਾਵੇ।

![ਨਵਾਂ ਪ੍ਰੋਗਰਾਮ](../../../media/game-tutorials/New-Program.png)\
ਅਸੀਂ ਤੈਨੂੰ ਕਦਮ-ਦਰ-ਕਦਮ ਨਿਰਦੇਸ਼ ਦੇਵਾਂਗੇ ਕਿ ਐਪ ਨੂੰ ਕਿਵੇਂ ਡਾਊਨਲੋਡ ਕਰਨਾ ਹੈ, ਇਸਨੂੰ ਖੋਲ੍ਹਣਾ ਹੈ ਅਤੇ ਇੱਕ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਕਿਵੇਂ ਬਣਾਇਆ ਜਾਵੇ।\
[ਤਸਵੀਰ ਖੋਲ੍ਹ](../../../media/game-tutorials/New-Program.png)

ਇਹ ਪਹਿਲਾ ਟਿਊਟੋਰਿਅਲ ਹੈ, ਅਤੇ ਤੈਨੂੰ ਕਿਸੇ ਵੀ ਪੁਰਾਣੇ ਗਿਆਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ।

ਤਾਂ, ਤੂੰ ਕਿਸ ਗੱਲ ਦਾ ਇੰਤਜ਼ਾਰ ਕਰ ਰਹੇ ਹੋ? ਆਪਣਾ ਫੋਨ ਚੁੱਕੋ ਅਤੇ ਹੁਣੇ ਸ਼ੁਰੂ ਕਰੋ!

*ਇੱਥੇ ਤੂੰ ਟਿਊਟੋਰਿਅਲ ਨੂੰ PDF-ਫਾਰਮੈਟ ਵਿੱਚ ਡਾਊਨਲੋਡ ਕਰ ਸਕਦਾ ਹੈਂਃ:*

[PDF ਖੋਲ੍ਹ](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code ਦੀ ਸਥਾਪਨਾ

ਪਹਿਲਾਂ, ਤੈਨੂੰ ਆਪਣੇ ਡਿਵਾਈਸ 'ਤੇ Pocket Code ਐਪ ਨੂੰ ਇੰਸਟਾਲ ਕਰਨ ਦੀ ਲੋੜ ਹੈ। ਇਸ ਕਦਮ ਲਈ ਇੱਕ ਗੂਗਲ ਖਾਤਾ ਦੀ ਲੋੜ ਹੈ. ਹੁਣ ਤੇਰੀ ਡਿਵਾਈਸ ਐਪ ਨੂੰ ਡਾਊਨਲੋਡ ਅਤੇ ਇੰਸਟਾਲ ਕਰੇਗੀ। ਤੇਰੇ ਇੰਟਰਨੈੱਟ ਕੁਨੈਕਸ਼ਨ ਦੇ ਅਨੁਸਾਰ ਇਸ ਕਦਮ ਵਿੱਚ ਕੁਝ ਸਮਾਂ ਲੱਗ ਸਕਦਾ ਹੈ।

![ਨਵਾਂ ਪ੍ਰੋਗਰਾਮ (2)](../../../media/game-tutorials/New-Program-2.png)\
ਤੂੰ ਐਪ ਨੂੰ Google Play Store ਵਿੱਚ “Pocket Code” ਲੱਭ ਕੇ ਅਤੇ ਇਸ ਨੂੰ “ਇੰਸਟਾਲ ਕਰੋ” ਦਬਾ ਕੇ ਡਾਊਨਲੋਡ ਕਰਕੇ ਲੱਭ ਸਕਦੇ ਹੋ।\
[ਤਸਵੀਰ ਖੋਲ੍ਹ](../../../media/game-tutorials/New-Program-2.png)

ਸਫਲਤਾਪੂਰਵਕ ਡਾਊਨਲੋਡ ਅਤੇ ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਬਾਅਦ Pocket Code ਤੂੰ ਐਪਲੀਕੇਸ਼ਨ ਨੂੰ ਆਪਣੇ ਡਿਵਾਈਸ ਦੇ ਅਧਾਰ ਤੇ ਐਪ ਡਰਾਅਰ ਜਾਂ ਤੇਰੀ ਹੋਮ ਸਕ੍ਰੀਨ 'ਤੇ ਲੱਭ ਸਕਦੇ ਹੋ. ਤੂੰ ਆਸਾਨੀ ਨਾਲ ਐਪ ਨੂੰ ਲੈ ਕੇ ਜਿੱਥੇ ਵੀ ਚਾਹੋ ਇਸ ਨੂੰ ਲਗਾ ਸਕਦੇ ਹੋ।

### 2. ਐਪ ਨੂੰ ਸ਼ੁਰੂ ਕਰੋ

![ਨਵਾਂ ਪ੍ਰੋਗਰਾਮ (1)](../../../media/game-tutorials/New-Program-1.png)\
ਜਦੋਂ ਤੂੰ ਐਪ ਖੋਲ੍ਹਦੇ ਹੋ, ਤਾਂ ਤੈਨੂੰ ਵੱਖੋ ਵੱਖਰੀਆਂ ਸ਼੍ਰੇਣੀਆਂ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨਃ.\
[ਤਸਵੀਰ ਖੋਲ੍ਹ](../../../media/game-tutorials/New-Program-1.png)

### 3. ਇੱਕ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਬਣਾਓ

ਅਗਲਾ ਕਦਮ ਹੈ ਅਸਲ ਵਿੱਚ ਇੱਕ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਬਣਾਉਣਾ। ਹੁਣ ਤੈਨੂੰ ਇੱਕ ਪ੍ਰੋਜੈਕਟ ਦਾ ਨਾਮ ਦਰਜ ਕਰਨਾ ਹੈ ਅਤੇ ਚੁਣੋ ਕਿ ਤੇਰਾ ਪ੍ਰੋਜੈਕਟ ਲੈਂਡਸਕੇਪ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ ਜਾਂ ਨਹੀਂ। “ਠੀਕ ਹੈ” ਦਬਾ ਕੇ ਪ੍ਰੋਜੈਕਟ ਬਣਾਇਆ ਜਾਂਦਾ ਹੈ।

![ਨਵਾਂ ਪ੍ਰੋਗਰਾਮ](../../../media/game-tutorials/New-Program.png)\
ਅਜਿਹਾ ਕਰਨ ਲਈ, ਤੂੰ ਸੱਜੇ ਹੇਠਲੇ ਕੋਨੇ ਵਿੱਚ ਪੀਲੇ ਪਲੱਸ-ਬਟਨ ਨੂੰ ਦਬਾ ਸਕਦੇ ਹੋ।\
[ਤਸਵੀਰ ਖੋਲ੍ਹ](../../../media/game-tutorials/New-Program.png)

### 4. ਤੂੰ ਆਪਣਾ ਨਵਾਂ ਪ੍ਰੋਜੈਕਟ ਬਣਾਇਆ ਹੈ।

ਹੁਣ ਤੈਨੂੰ ਇੰਸਟਾਲ ਕੀਤਾ ਹੈ Pocket Code ਅਤੇ ਪਤਾ ਹੈ ਕਿ ਇੱਕ ਨਵ ਪ੍ਰਾਜੈਕਟ ਨੂੰ ਬਣਾਉਣ ਲਈ. ਹੁਣ ਤੂੰ ਪ੍ਰੋਗਰਾਮਿੰਗ ਸ਼ੁਰੂ ਕਰ ਸਕਦਾ ਹੈਂ!

ਅਜਿਹਾ ਕਰਨ ਲਈ, ਤੈਨੂੰ ਇੱਕ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਇੱਕ ਨਵੀਂ ਵਸਤੂ ਕਿਵੇਂ ਬਣਾਈ ਜਾਣ ਦੀ ਜ਼ਰੂਰਤ ਹੈ। **[ਨਵੀਂ ਵਸਤੂ](new-object.md)** -ਟਿਊਟੋਰਿਅਲ 'ਤੇ ਇੱਕ ਨਜ਼ਰ ਮਾਰੋ, ਜਿੱਥੇ ਤੈਨੂੰ ਹਰ ਚੀਜ਼ ਕਦਮ-ਦਰ-ਕਦਮ ਸਮਝਾਇਆ ਜਾਂਦਾ ਹੈ।
