ਦੇਖੋ ਕਿ ਅਧਿਆਪਕਾਂ ਅਤੇ ਵਿਦਿਆਰਥੀਆਂ ਨੇ ਕਲਾਸ ਵਿੱਚ Pocket Code ਦੀ ਵਰਤੋਂ ਬਾਰੇ ਕੀ ਕਿਹਾ ਹੈ।

::video{youtube=75i10o_uv0U}

ਇਹ ਵੀਡੀਓ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਕਿਵੇਂ Pocket Code ਨੂੰ ਸਿੱਖਣ ਦੇ ਇੱਕ ਢਾਂਚਾਗਤ ਤਰੀਕੇ ਨਾਲ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ। ਸਿੱਖਣ ਦੇ ਮਾਹੌਲ ਵਿੱਚ ਅਧਿਆਪਕ ਅਤੇ ਵਿਦਿਆਰਥੀਆਂ ਦੇ ਕਿਹੜੇ ਕੰਮ ਹਨ Pocket Code?
