![ਪੈੱਨ ਦਾ ਰੰਗ ਇਸ 'ਤੇ ਸੈੱਟ ਕਰੋ: o ਲਾਲ 0 ਹਰੀ 0 ਨੀਲਾ 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

ਇਹ ਕੋਡ ਬਲਾਕ ਅਦਾਕਾਰ ਦੁਆਰਾ ਵਰਤੀ ਗਈ ਕਲਮ ਦਾ ਰੰਗ ਬਦਲਦਾ ਹੈ. ਇਹ ਡਰਾਇੰਗ ਕਰਦੇ ਸਮੇਂ ਵੱਖਰੇ ਰੰਗ ਦੇ ਕਲਮ 'ਤੇ ਜਾਣ ਵਰਗਾ ਹੈ।

**ਲਾਲ, ਹਰੀ, ਨੀਲੀ (RGB)**: ਰੰਗਾਂ ਦੀ ਇੱਕ ਵਿਆਪਕ ਸਪੈਕਟ੍ਰਮ ਬਣਾਉਣ ਲਈ ਰੰਗ ਮਾਡਲ RGB ਲਾਲ, ਹਰੇ ਅਤੇ ਨੀਲੇ ਰੌਸ਼ਨੀ ਦੀਆਂ ਵੱਖੋ ਵੱਖਰੀਆਂ ਤੀਬਰਤਾਵਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ। ਹਰੇਕ ਰੰਗ ਭਾਗ (ਲਾਲ, ਹਰੇ ਅਤੇ ਨੀਲੇ) ਦਾ ਮੁੱਲ 0 ਤੋਂ 255 ਦੇ ਵਿਚਕਾਰ ਹੋ ਸਕਦਾ ਹੈਃ:

- **ਲਾਲ**: ਰੰਗ ਦਾ ਲਾਲ ਹਿੱਸਾ। ਇੱਕ ਉੱਚ ਮੁੱਲ ਦਾ ਮਤਲਬ ਹੈ ਵਧੇਰੇ ਲਾਲ.
- **ਹਰੀ**: ਰੰਗ ਦਾ ਹਰਾ ਹਿੱਸਾ। ਇੱਕ ਉੱਚ ਮੁੱਲ ਦਾ ਮਤਲਬ ਹੈ ਵਧੇਰੇ ਹਰੀ.
- **ਨੀਲਾ**: ਰੰਗ ਦਾ ਨੀਲਾ ਹਿੱਸਾ। ਇੱਕ ਉੱਚ ਮੁੱਲ ਦਾ ਮਤਲਬ ਹੈ ਵਧੇਰੇ ਨੀਲਾ.

ਲਾਲ, ਹਰੇ ਅਤੇ ਨੀਲੇ ਦੇ ਵੱਖ-ਵੱਖ ਮੁੱਲਾਂ ਨੂੰ ਜੋੜ ਕੇ ਤੂੰ ਕੋਈ ਵੀ ਰੰਗ ਬਣਾ ਸਕਦੇ ਹੋ। ਉਦਾਹਰਨ ਲਈਃ:

- `RGB(255, 0, 0)` ਸ਼ੁੱਧ ਲਾਲ ਹੈ.
- `RGB(0, 255, 0)` ਸ਼ੁੱਧ ਹਰੀ ਹੈ.
- `RGB(0, 0, 255)` ਸ਼ੁੱਧ ਨੀਲਾ ਹੈ.
- `RGB(255, 255, 255)` ਚਿੱਟਾ ਹੈ (ਵੱਧ ਤੋਂ ਵੱਧ ਲਾਲ, ਹਰਾ ਅਤੇ ਨੀਲਾ).
- `RGB(0, 0, 0)` ਕਾਲਾ ਹੈ (ਕੋਈ ਰੰਗ ਨਹੀਂ).

ਇਨ੍ਹਾਂ ਰੰਗਾਂ ਨੂੰ ਵੱਖ-ਵੱਖ ਮਾਤਰਾਵਾਂ ਵਿੱਚ ਮਿਲਾ ਕੇ ਤੂੰ ਡਿਜੀਟਲ ਸਕ੍ਰੀਨਾਂ 'ਤੇ ਦੇਖਣ ਵਾਲੇ ਸਾਰੇ ਰੰਗ ਬਣਾਉਂਦੇ ਹੋ।
