ਆਪਣੇ ਸਮਾਰਟਫੋਨ 'ਤੇ ਸਿੱਧੇ ਤੌਰ' ਤੇ ਆਪਣੀ ਪਲਾਟ ਨੂੰ ਇੱਕ SVG ਚਿੱਤਰ ਦੇ ਰੂਪ ਵਿੱਚ ਸੁਰੱਖਿਅਤ ਕਰਨ ਲਈ ਇਸ ਬਲਾਕ ਦੀ ਵਰਤੋਂ ਕਰੋ. ਫਿਰ ਤੂੰ ਇਸਨੂੰ ਸਾਂਝਾ ਕਰ ਸਕਦਾ ਹੈਂ ਅਤੇ ਇਸਨੂੰ ਇੱਕ ਕੱਟਣ ਵਾਲੇ ਨੂੰ ਭੇਜ ਸਕਦੇ ਹੋ।
