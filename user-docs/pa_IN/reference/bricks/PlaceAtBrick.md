ਵਸਤੂ ਨੂੰ ਸਕ੍ਰੀਨ 'ਤੇ ਇਕ ਖਾਸ ਸਥਿਤੀ' ਤੇ ਭੇਜਦਾ ਹੈ, ਜਿਸ ਨੂੰ x ਅਤੇ y ਤਾਲਮੇਲ ਦੁਆਰਾ ਪਰਿਭਾਸ਼ਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ. ਇਹ ਤੇਰੇ ਕਿਰਦਾਰ ਨੂੰ ਸਹੀ ਜਗ੍ਹਾ 'ਤੇ ਟੈਲੀਪੋਰਟ ਕਰਨ ਵਰਗਾ ਹੈ।

ਸਥਿਤੀ ਕਾਰਟੇਸੀਅਨ ਜਹਾਜ਼ ਵਰਗੀ ਤਾਲਮੇਲ ਪ੍ਰਣਾਲੀ ਵਿੱਚ ਨਿਰਧਾਰਤ ਕੀਤੀ ਗਈ ਹੈਃ ਐਕਸ ਅਤੇ ਵਾਈ ਧੁਰੇ ਸਕ੍ਰੀਨ ਦੇ ਕੇਂਦਰ ਵਿੱਚੋਂ ਲੰਘਦੇ ਹਨ, ਇਸ ਲਈ x = 0 ਅਤੇ y = 0 ਸਕ੍ਰੀਨ ਦਾ ਮੱਧ ਹੈ.
