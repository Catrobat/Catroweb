![ਇਸ ਦਾ ਕਲੋਨ ਬਣਾਓ:](../../../media/bricks/create_clone_of_brick2.png)

ਇਹ ਕੋਡ ਬਲਾਕ ਨਿਰਧਾਰਤ ਵਸਤੂ ਦੀ ਇੱਕ ਕਾਪੀ ਬਣਾਉਂਦਾ ਹੈ, ਜਿਸਨੂੰ ਕਲੋਨ ਕਿਹਾ ਜਾਂਦਾ ਹੈ, ਜੋ ਕਿ ਅਸਲ ਵਾਂਗ ਵਿਵਹਾਰ ਕਰਦਾ ਹੈ। ਕਲਪਨਾ ਕਰੋ ਕਿ ਤੂੰ ਆਪਣੀ ਖੇਡ ਵਿੱਚ ਕਿਸੇ ਕਿਰਦਾਰ ਜਾਂ ਵਸਤੂ ਨੂੰ ਦੁਹਰਾ ਰਹੇ ਹੋ। ਕਲੋਨ ਦੇ ਆਪਣੇ ਵਿਵਹਾਰ ਅਤੇ ਸਕ੍ਰਿਪਟਾਂ ਹੋ ਸਕਦੀਆਂ ਹਨ, ਜਿਸ ਨਾਲ ਤੂੰ ਕਿਸੇ ਵਸਤੂ ਦੀਆਂ ਕਈ ਉਦਾਹਰਣਾਂ ਬਣਾ ਸਕਦੇ ਹੋ ਜੋ ਸੁਤੰਤਰ ਤੌਰ ਤੇ ਕੰਮ ਕਰ ਸਕਦੀਆਂ ਹਨ।
