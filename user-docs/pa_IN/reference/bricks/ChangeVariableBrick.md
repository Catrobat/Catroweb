ਇੱਕ ਵੇਰੀਏਬਲ ਦੇ ਮੌਜੂਦਾ ਮੁੱਲ ਤੋਂ ਜੋੜਨਾ ਜਾਂ ਘਟਾਉਣਾ ਚਾਹੁੰਦੇ ਹੋ? ਇਹ ਕੋਡ ਬਲਾਕ ਤੈਨੂੰ ਅਜਿਹਾ ਕਰਨ ਦਿੰਦਾ ਹੈ। ਇਹ ਕਹਿਣ ਵਰਗਾ ਹੈ, “ਜੋ ਤੂੰ ਜਾਣਦੇ ਹੋ, ਉਸ ਨੂੰ ਲੈ ਕੇ ਇਸ ਨੂੰ ਜੋੜੋ.”
