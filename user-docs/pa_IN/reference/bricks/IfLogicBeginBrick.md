![ਜੇ ਹੋਰ ਕੋਡ ਬਲਾਕ](../../../media/bricks/if_else_brick2.png)

*ਇਹ ਜਾਂਚ ਕਰਦਾ ਹੈ ਕਿ ਕੀ ਇੱਕ ਸ਼ਰਤ ਸਹੀ ਹੈ, ਅਤੇ ਨਿਰਦੇਸ਼ਾਂ ਦਾ ਇੱਕ ਸੈੱਟ ਚਲਾਉਂਦਾ ਹੈ ਜੇ ਇਹ ਸੱਚ ਹੈ, ਅਤੇ ਇਕ ਹੋਰ ਸੈੱਟ ਜੇ ਨਹੀਂ. ਇਹ ਦੋ ਵਿਕਲਪ ਦੇਣ ਵਰਗਾ ਹੈਃ “ਜੇ ਇਹ ਸੱਚ ਹੈ, ਤਾਂ ਇਹ ਕਰੋ; ਨਹੀਂ ਤਾਂ, ਉਹ ਕਰੋ।”*

![ਦ੍ਰਿਸ਼ ਸ਼ੁਰੂ ਕਰੋ:](../../../media/bricks/StartScene.png)

ਜਦੋਂ ਦ੍ਰਿਸ਼ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ, ਪਰਿਵਰਤਨ X ਨੂੰ 0 ਤੇ ਸੈੱਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ.

![ਜੇ ਹੋਰ](../../../media/bricks/IfElse.png)

ਜੇ ਜਾਨਵਰ ਨੂੰ ਹੁਣ ਟੈਪ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਇਹ ਜਾਂਚ ਕੀਤੀ ਜਾਂਦੀ ਹੈ ਕਿ ਕੀ X ਮੋਡੂਲੋ 2 ਸਹੀ ਹੈ, ਯਾਨੀ ਜੇ X ਇੱਕ ਅਜੀਬ ਨੰਬਰ ਹੈ.

ਜੇ ਅਜਿਹਾ ਹੈ, ਤਾਂ ਆਵਾਜ਼ Tweet1 ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ ਅਤੇ ਪਰਿਵਰਤਨਕ X ਨੂੰ 1 ਨਾਲ ਵਧਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ.

ਨਹੀਂ ਤਾਂ, ਜੇ X ਵੀਰ ਹੈ, ਸਿਰਫ X 1 ਦੁਆਰਾ ਵਧਾਇਆ ਜਾਂਦਾ ਹੈ.

ਲਾਗੂ ਕੀਤੇ ਜਾਣ ਵਾਲੇ ਬਿਆਨ ਨੂੰ ਇੱਕ ਜੇ ਦਾ ਅੰਤ ਨਾਲ ਵੱਖ ਕੀਤਾ ਗਿਆ ਹੈ।
