![ਛਾਪ ਲਗਾਓ](../../../media/bricks/Stamp_.png)

ਇਸ ਕੋਡ ਬਲਾਕ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਤੂੰ ਆਪਣੇ ਕਿਰਦਾਰ ਦੀ ਦਿੱਖ ਦੀ ਇੱਕ ਕਾਪੀ ਸਕ੍ਰੀਨ 'ਤੇ ਛੱਡ ਦਿੰਦੇ ਹੋ। ਇਹ ਕਾਗਜ਼ 'ਤੇ ਰੰਗਦਾਰ ਸਟੈਂਪ ਲਗਾਉਣ ਅਤੇ ਸਟੈਂਪ ਡਿਜ਼ਾਈਨ ਦੀ ਇੱਕ ਕਾਪੀ ਛੱਡਣ ਵਰਗਾ ਹੈ। ਇਸ ਤਰ੍ਹਾਂ, ਤੂੰ ਆਪਣੇ ਪਿਛੋਕੜ ਨੂੰ ਵਧਾਉਂਦੇ ਹੋ - ਤੂੰ ਇੱਕ ਕਲੋਨ ਨਹੀਂ ਬਣਾ ਰਹੇ ਹੋ!
