![ਇਸ ਵੱਲ ਮੂੰਹ ਕਰੋ:](../../../media/bricks/point_towards_brick.png)

ਵਸਤੂ ਨੂੰ ਕਿਸੇ ਹੋਰ ਵਸਤੂ ਜਾਂ ਮਾਊਸ-ਪੁਆਇੰਟਰ ਦੇ ਸਾਹਮਣੇ ਕਰ ਦਿੰਦਾ ਹੈ। ਕਲਪਨਾ ਕਰੋ ਕਿ ਤੂੰ ਆਪਣੇ ਕਿਰਦਾਰ ਨੂੰ ਹਮੇਸ਼ਾ ਕਿਸੇ ਖਾਸ ਟੀਚੇ ਜਾਂ ਦਿਸ਼ਾ ਵੱਲ ਦੇਖਣ ਲਈ ਕਹਿੰਦੇ ਹੋ।
