![ਆਵਾਜ਼ ਰੋਕੋ:](../../../media/bricks/Stop_sound_record.png)

ਇਹ ਕੋਡ ਬਲਾਕ ਕਿਸੇ ਖਾਸ ਆਵਾਜ਼ ਨੂੰ ਚਲਾਉਣ ਤੋਂ ਰੋਕਦਾ ਹੈ। ਇਹ ਇਕ ਗੀਤ ਲਈ ਸਟਾਪ ਬਟਨ ਦਬਾਉਣ ਵਰਗਾ ਹੈ ਜਦੋਂ ਕਿ ਹੋਰ ਆਵਾਜ਼ਾਂ ਜਾਂ ਸੰਗੀਤ ਖੇਡਦੇ ਰਹਿੰਦੇ ਹਨ। ਕਲਪਨਾ ਕਰੋ ਕਿ ਤੂੰ ਆਪਣੇ ਕਿਰਦਾਰ ਨੂੰ ਇੱਕ ਖਾਸ ਆਵਾਜ਼ ਦਾ ਟਰੇਕ ਖੇਡਣਾ ਬੰਦ ਕਰਨ ਲਈ ਕਹਿ ਰਹੇ ਹੋ।
