ਮਸ਼ੀਨ ਨੂੰ ਲਗਾਤਾਰ ਇੱਕ ਪਰਿਵਰਤਨਸ਼ੀਲ ਲੰਬਾਈ ਨਾਲ ਸਿਲਾਈ ਕਰਨ ਦਿੰਦਾ ਹੈ.

ਆਮ ਤੌਰ 'ਤੇ ਤੂੰ ਚੱਲ ਰਹੇ ਸਿਲਾਈ ਨੂੰ ਇੱਕ ਮੂਵ-ਕੋਡ ਬਲਾਕ ਨਾਲ ਜੋੜਦੇ ਹੋ.

![ਇਸ ਲੰਬਾਈ ਨਾਲ ਕੱਚਾ ਟਾਂਕਾ ਸ਼ੁਰੂ ਕਰੋ: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

ਮਸ਼ੀਨ ਨੂੰ ਚੱਲਣ ਵਾਲੀ ਸਿਲਾਈ ਸ਼ੁਰੂ ਕਰੋ ਜੋ ਹਰ **10 ਕਦਮ** ਨੂੰ ਸਿਲਾਈ ਕਰੇਗੀ.

ਫਿਰ ਮਸ਼ੀਨ ਚਲਦੀ ਹੈ **200 ਕਦਮ**.

ਇਸ ਦੇ ਨਤੀਜੇ ਵਜੋਂ **20 ਸਿਲਾਈਆਂ**.

![ਇਸ ਲੰਬਾਈ ਨਾਲ ਕੱਚਾ ਟਾਂਕਾ ਸ਼ੁਰੂ ਕਰੋ:](../../../../media/embroidery-tutorials/RunningStitch.png)

ਚੱਲਣ ਵਾਲੀ ਸਿਲਾਈ ਇੱਕ ਸਿਲਾਈ ਨੂੰ ਸਿਲਾਈ ਕਰਨਾ ਸੌਖਾ ਬਣਾਉਂਦੀ ਹੈ ਕਿਉਂਕਿ ਤੈਨੂੰ ਹੁਣ ਲੂਪ ਦੀ ਜ਼ਰੂਰਤ ਨਹੀਂ ਹੋਏਗੀ.
