ਟ੍ਰਿਪਲ ਸਿਲਾਈ ਹਰ ਸਿਲਾਈ ਨੂੰ ਤਿੰਨ ਵਾਰ ਜੋੜਦੀ ਹੈ.

ਤਿੰਨ ਵਾਰ ਸਿਲਾਈ ਤੋਂ ਬਾਅਦ, ਇਹ ਵਾਪਸ ਛਾਲ ਮਾਰਦਾ ਹੈ, ਫਿਰ ਅੱਗੇ ਮੁੜ ਕੇ ਛਾਲ ਮਾਰਦਾ ਹੈ ਅਤੇ ਫਿਰ ਦੁਬਾਰਾ ਸਿਲਾਈ ਕਰਦਾ ਹੈ।

![ਇਸ ਲੰਬਾਈ ਨਾਲ ਤੀਹਰਾ ਟਾਂਕਾ ਸ਼ੁਰੂ ਕਰੋ: 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

ਇਹ [ਚੱਲ ਰਹੀ ਸਿਲਾਈ](running-stitch.md) ਦੇ ਸਮਾਨ ਕੰਮ ਕਰਦਾ ਹੈ।

![ਇਸ ਲੰਬਾਈ ਨਾਲ ਤੀਹਰਾ ਟਾਂਕਾ ਸ਼ੁਰੂ ਕਰੋ:](../../../../media/embroidery-tutorials/TripleStitch.png)

ਇਸ ਨਾਲ ਤਿਲਕ ਲੰਬਾ ਸਮਾਂ ਰਹਿੰਦਾ ਹੈ।
