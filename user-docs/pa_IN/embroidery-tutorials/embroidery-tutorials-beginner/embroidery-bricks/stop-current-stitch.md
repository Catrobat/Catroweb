ਮੌਜੂਦਾ ਸਿਲਾਈ ਨੂੰ ਰੋਕਣ ਦਿਓ.

ਤੈਨੂੰ ਇਸ ਕੋਡ ਬਲਾਕ ਦੀ ਲੋੜ ਹੋਵੇਗੀ ਜੇ ਤੂੰ ਦੌੜ, ਜ਼ਿਗਜ਼ੈਗ ਜਾਂ ਟ੍ਰਿਪਲ ਸਿਲਾਈ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਬਾਅਦ ਸੂਈ ਦੀ ਸਥਿਤੀ ਬਦਲਣਾ ਚਾਹੁੰਦੇ ਹੋ.

![ਮੌਜੂਦਾ ਟਾਂਕਾ ਰੋਕੋ](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

ਨਹੀਂ ਤਾਂ ਇੱਕ ਅਣਚਾਹੇ ਵਿਚਕਾਰਲੇ ਤਣਾਅ ਪੈਦਾ ਹੋ ਜਾਵੇਗਾ.

![ਮੌਜੂਦਾ ਟਾਂਕਾ ਰੋਕੋ](../../../../media/embroidery-tutorials/StopCurrentStitch.png)
