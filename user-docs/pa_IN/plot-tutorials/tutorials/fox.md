ਜਦੋਂ ਕਹਾਣੀ ਸ਼ੁਰੂ ਹੁੰਦੀ ਹੈ, ਤਾਂ ਹਰ ਅੰਦੋਲਨ ਨੂੰ ਕਲਮ ਨਾਲ ਖਿੱਚਿਆ ਜਾਂਦਾ ਹੈ। ਇਹ ਉਹ ਲਾਈਨਾਂ ਹਨ ਜਿਹੜੀਆਂ ਬਾਅਦ ਵਿੱਚ ਕਥਾਕਾਰ ਦੁਆਰਾ ਕੱਟੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।

ਇਹ ਲੂੰਬ ਸਿਰਫ ਸਿੱਧੀਆਂ ਲਾਈਨਾਂ (“ਅੱਗੇ ਵਧੋ: \_\_\_ ਕਦਮ”) ਅਤੇ ਮੋੜਾਂ ਤੋਂ ਬਣਿਆ ਹੁੰਦਾ ਹੈ।

**ਟਿਪ**: ਜਦੋਂ ਤੂੰ ਇਸਨੂੰ ਬਣਾਉਂਦੇ ਹੋ ਤਾਂ ਆਪਣੇ ਪ੍ਰੋਗਰਾਮ ਦੀ ਜਾਂਚ ਕਰੋ।
