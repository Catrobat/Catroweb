![对列表中的每个值](../../../media/bricks/for-each-value_brick.png)

这个积木会对列表或范围中的每一个项目运行一组指令。就像一个一个地检查每一项，并对每一项做同样的事情。

想象你有一个数字列表、颜色列表，或者任何其他项目的列表。这个积木可以让你依次取出列表中的每一项，并对它做一些事情。例如，如果你有一个颜色列表，并且想把背景颜色依次换成列表中的每种颜色，就可以使用这个积木。

就像在说：“对这一组中的每一项，都执行这些指令。”
