![如果...那么...否则](../../../media/bricks/if_else_brick2.png)

*检查一个条件是否成立：如果成立，运行一组指令；如果不成立，运行另一组指令。就像给出两个选择：“如果这是真的，就做这个；否则，就做那个。”*

![开始场景](../../../media/bricks/StartScene.png)

场景开始时，变量 X 被设为 0。

![如果否则](../../../media/bricks/IfElse.png)

如果现在点击了动物，程序会检查 X 除以 2 的余数是否为真，也就是 X 是否为奇数。

如果是，就播放声音 Tweet1，并把变量 X 增加 1。

否则，如果 X 是偶数，就只把 X 增加 1。

要执行的语句用“如果结束”分开。
