![广播](../../../media/bricks/broadcast2-1.png)

向项目的其他部分发送一条消息，告诉它们开始运行自己的脚本。就像发布一个所有人都会听的通知。

**为什么要发送广播消息？**

通过消息，同一场景中的不同对象可以互相交流和互动。一个对象可以把消息发送给所有其他对象，接收到消息的对象随后就能做出反应。

这些消息**不会显示**在屏幕上！如果你想显示文字，请使用“外观”类别中的积木！

**它是如何工作的？**

- *发送方对象：* 发送方对象通过一个*“广播”*积木开始通信。这个积木会把消息发送给场景中的所有其他对象（包括背景）。
- *接收方对象：* 接收方对象负责监听并响应消息。它使用*“当接收到”*积木来检测某个特定消息是否被接收。
- *消息处理：* 当接收方对象收到消息时，它会执行*“当接收到”*积木下面的所有积木。这样，你就可以设定收到某个消息时要做的特定动作。
