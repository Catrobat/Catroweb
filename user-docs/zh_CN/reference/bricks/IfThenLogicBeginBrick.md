*检查一个条件是否成立，如果成立，就运行一组指令。就像在说：“如果这是真的，那么就做这个。”*

![开始场景](../../../media/bricks/StartScene.png)

场景开始时，变量 X 被设为 0。

![如果](../../../media/bricks/If.png)

如果现在点击了动物，变量 X 就增加 1。

程序会检查变量 X 是否等于 2。

如果是，就播放声音 Tweet1，并把变量 X 设为 0。
