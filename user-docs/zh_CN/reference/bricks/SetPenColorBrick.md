这个积木会改变角色所用画笔的颜色。就像在画画时换一支不同颜色的笔。

**红、绿、蓝（RGB）**：RGB 颜色模式使用不同强度的红、绿、蓝光来创造很多种颜色。每种颜色成分（红、绿、蓝）的值可以在 0 到 255 之间：

- **红**：颜色中的红色成分。数值越高，红色越多。
- **绿**：颜色中的绿色成分。数值越高，绿色越多。
- **蓝**：颜色中的蓝色成分。数值越高，蓝色越多。

把红、绿、蓝的不同数值组合起来，就能做出任何颜色。例如：

- `RGB(255, 0, 0)` 是纯红色。
- `RGB(0, 255, 0)` 是纯绿色。
- `RGB(0, 0, 255)` 是纯蓝色。
- `RGB(255, 255, 255)` 是白色（红、绿、蓝都是最大量）。
- `RGB(0, 0, 0)` 是黑色（没有颜色）。

按不同的比例混合这些颜色，就能得到你在数字屏幕上看到的所有颜色。
