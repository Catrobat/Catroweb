![将粒子颜色设为“#ff0000”](../../../media/bricks/Set_particle_colour_to_ff0000.png)

这个积木会改变角色发出的粒子的颜色。就像改变派对礼炮里彩纸的颜色。

十六进制颜色代码是一种用十六进制数字来表示颜色的方式。它由六个字符组成，字符可以是数字（0-9）或字母（A-F）。代码通常以“#”开头，写法如下：`#RRGGBB`。

- 前两个字符（`RR`）表示颜色中的红色成分。
- 接下来的两个字符（`GG`）表示绿色成分。
- 最后两个字符（`BB`）表示蓝色成分。

每对字符的范围是从 `00`（表示没有这种颜色）到 `FF`（表示这种颜色的最大量）。例如：

`#000000` 是黑色（没有颜色）。

`#FF0000` 是纯红色。

`#00FF00` 是纯绿色。

`#0000FF` 是纯蓝色。

`#FFFFFF` 是白色（红、绿、蓝都是最大量）。
