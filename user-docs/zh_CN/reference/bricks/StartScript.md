![场景开始时](../../../media/bricks/When_scene_starts_btn2.png)

如果你使用这个积木，脚本会在场景开始时立即运行。场景是你程序的开端。场景是程序中的一个新画面，其他元素可以显示在其中，并且可以发生各种互动。你的程序可以有很多场景，用于不同的阶段。例如，一个场景用于开场，一个用于主菜单，一个用于第一关，一个用于第二关，依此类推。对于比较简单的程序，一个场景就够了，那时程序的开始也就是场景的开始。

和每个脚本一样，这个脚本也以一个事件积木开始：事件决定脚本**何时**开始，后面的积木告诉程序**做什么**。
