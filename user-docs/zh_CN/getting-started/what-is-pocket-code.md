Pocket Code 是 Catrobat 的主要应用，是一款免费的开源手机应用，让你直接在智能手机或平板上制作游戏、动画和互动故事。使用 Pocket Code 的**积木式编程系统**，你可以像拼拼图一样，把代码积木拼接在一起来做项目。不需要编程经验，非常适合初学者！

Pocket Code 不只是做数字作品。通过新的**创客功能**，你还可以设计用于切割绘图机的 **SVG 文件**。这样，你就能把数字作品变成现实中的东西，探索屏幕之外的创意可能。

无论你是在学编程、尝试新想法，还是在教编程，Pocket Code 都能提供一种好玩又容易上手的方式，让你开始编程。

[更多信息](https://catrobat.org/pocket-code/)
