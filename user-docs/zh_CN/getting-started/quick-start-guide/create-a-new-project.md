在你的智能手机或平板上打开应用。点击 + 符号来创建新项目。

![主屏幕_新项目](../../../media/getting-started/MainScreen_NewProject.png)

给项目起个名字（1），然后选择你的游戏是竖屏（纵向）还是横屏（横向）（2）。最后点击对勾确认（3）。

![新项目](../../../media/getting-started/NewProject.png)

现在你来到了项目视图。在顶部，你可以看到游戏的名字。

下面是**背景**，目前背景还是空的。如果想更换背景，点击它就可以。

在背景下面，是你加入游戏的**角色和对象**区域。目前这个区域还是空的。

在右下角，你会看到两个重要的按钮：

![开始](../../../media/getting-started/Start.png) 点击**播放**按钮，就能开始你的游戏。

![加号按钮](../../../media/getting-started/Screenshot-2024-11-22-143219.png) 点击**加号**按钮，就能向游戏中添加新的角色或对象。

![项目界面](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
