启动 Pocket Code 后，你会看到下面的主屏幕。

![主屏幕](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
启动 Pocket Code 后，你会看到下面的主屏幕。\
[打开图片](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![帮助](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
在右上角有一个 符号，点击它会打开 Catrobat 文档，那里有很多有用的小提示。

![菜单](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
旁边是菜单。

在菜单里，你可以轻松进入设置，更改语言，或者打开积木扩展等功能。

![编辑图标](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
点击编辑图标 ，就能进入项目页面，继续开发你的项目。

下面可以看到你最近编辑过的项目。

![开始你的项目](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
点击播放按钮 ，就能运行你的项目。

![设备上的项目](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
点击“设备上的项目”，你可以打开已保存的项目。

![Catrobat 社区](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
如果你想了解和体验其他用户的更多项目，只要在分享页面点击“Catrobat 社区”。

那里有很多很棒的项目。

![添加](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
如果你想创建新项目，点击加号图标。
