点击加号按钮，向你的项目添加新的角色或对象。

![添加角色](../../../media/getting-started/FigurHinzufuegen.png)

在 Pocket Code 中，你可以用多种方式向项目添加角色或对象：

**绘制**：你可以用 **Pocket Paint** 画出自己的角色。Pocket Paint 是一款绘图程序（[关于 Pocket Paint 的更多信息](https://catrobat.org/docs/pocket-paint/)）。

**造型**：从预先做好的角色和对象中选一个（[关于媒体库的更多信息](../elements/medialibrary.md)）。

**图库**：你可以从手机的相册中选一张图片。

**素材库**：在素材库中，你会找到已经编好程序的角色和对象，也就是它们已经带有脚本。如果你想在游戏中使用现成的元素（例如倒计时），可以选择它们（[关于素材库的更多信息](../elements/medialibrary.md#从媒体库添加对象)）。

**相机**：你可以用设备的相机拍一张照片，并把它添加为角色。

**背包**：背包现在是空的。你可以重复使用保存在背包里的角色或对象。整个脚本也会随之一起取出（[关于背包的更多信息](../elements/backpack.md)）。

**本地角色和对象**：这里有一些现成的角色，你可以在项目中使用。本地角色和对象就像离线的媒体库，即使没有网络，你也能使用这些角色。

**空对象**：添加一个没有外观的空对象。你可以像平常一样为它编程。

**本地项目**：选择一个项目，把它的第一个角色连同脚本一起插入到你的项目中。
