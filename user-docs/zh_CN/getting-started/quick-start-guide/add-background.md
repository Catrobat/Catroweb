你可以在 Catrobat 中为项目添加背景。

背景有很多用处。在 Pocket Code 中，背景可以让**游戏**更漂亮、讲述**故事**，或者为你的角色和对象提供更多的环境。

对于绘图机或刺绣机等创客设备，背景可以作为设计模板，例如切割图案或刺绣图案。

![点击背景](../../../media/getting-started/grafik-16.png)\
要添加背景，请在项目视图中点击“背景”。\
[打开图片](../../../media/getting-started/grafik-16.png)

在**脚本区（2）**，你可以为背景编程，但并不是所有积木都可以用。下面两个积木特别重要：![将透明度设为 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) 和 ![将大小设为 60%](../../../media/bricks/Set_size_to_60_pct_.png)

在**造型区（1）**，你可以添加背景。

![添加背景](../../../media/getting-started/grafik-14.png)\
为此，请点击 + 符号。\
[打开图片](../../../media/getting-started/grafik-14.png)

你可以上传自己的图片，使用预设的背景，或者自己制作背景。

**绘制**：你可以用 **Pocket Paint** 画出自己的背景。Pocket Paint 是一款绘图程序（[关于 Pocket Paint 的更多信息](https://catrobat.org/pocket-paint/)）。

**造型**：从预先做好的背景中选一个（[关于媒体库的更多信息](../elements/medialibrary.md)）。

**图库**：你可以从手机的相册中选一张图片。

**相机**：你可以用设备的相机拍一张照片，并把它添加为背景。

![背景](../../../media/getting-started/grafik-17.png)\
点击右上角的返回箭头，回到**项目视图**。\
[打开图片](../../../media/getting-started/grafik-17.png)

你现在已经添加了背景。
