Pocket Code 是一款可视化编程应用，让你直接在智能手机或平板上制作游戏、动画和互动故事。通过直观的拖放界面和“积木”（代码块），你无需编程经验就能设计自己的项目。还可以轻松添加声音、图片和动作，让你的想法活起来。

本指南将帮你快速上手，教你如何：

- 浏览界面，
- 创建你的第一个项目，
- 使用角色和背景，
- 使用积木编写动作，以及
- 保存你的项目。

Pocket Code 很适合初学者和老师，它能激发创造力、解决问题的能力和逻辑思维。
