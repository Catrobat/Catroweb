Catrobat 是一种免费的开源**可视化编程语言**。它可以帮助每个人，从初学者到高级用户，直接在手机或平板上制作自己的游戏、动画和互动故事。它使用简单的**积木式**编程界面，你只要把代码“积木”拖来拖去，就能一步一步做出自己的作品，完全不需要任何编程经验！

通过 Catrobat 的主要应用 **Pocket Code**，你还可以制作超出屏幕的数字作品。除了普通的编程作品，Catrobat 还支持创客精神：你可以制作用于刺绣机的 **DST 文件**，也可以制作用于切割绘图机的 **SVG 文件**。这样，你的数字设计就能变成布料和其他实物！

无论你是学生、爱好者还是老师，Catrobat 都能让你以有趣、动手的方式学习编程、解决问题，以及数字制造。
