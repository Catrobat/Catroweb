让机器以可变的针距持续缝纫。

通常，平针缝要和一个“移动”积木组合使用。

![开始平针缝，针距 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

机器会开始平针缝，每 **10 步**缝一针。

然后机器移动 **200 步**。

这样一共会缝出 **20 针**。

![平针缝](../../../../media/embroidery-tutorials/RunningStitch.png)

平针缝让缝合线变得更容易，因为你不再需要循环了。
