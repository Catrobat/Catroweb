三重缝会把每一针缝三次。

三重缝在第一针之后会往回跳，缝一针，然后再向前跳回去，再缝一针。

![开始三重缝，针距 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

它的工作方式和[平针缝](running-stitch.md)一样。

![三重缝](../../../../media/embroidery-tutorials/TripleStitch.png)

这样缝合线会更耐用。
