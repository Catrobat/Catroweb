让当前的缝法停下来。

如果你在开始平针缝、之字形缝或三重缝之后，想改变针的位置，就需要这个积木。

![停止当前缝法](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

否则会出现一条不需要的中间缝线。
