在本教程中，你将学会创建对象，之后用它们绣出你的图案。

在这个教程中，你应该已经知道如何创建项目。如果你需要帮助，请看看[入门系列](../../game-tutorials/starter-tutorials/index.md)的教程。

如需更多信息或设计灵感，请看看其他教程。

*你可以在这里下载 PDF 格式的教程*：

[创建刺绣对象](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. 点击项目右下角的加号按钮，添加一个新对象。

![创建刺绣对象](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. 要选择图片，请进入媒体库。

![创建刺绣对象（1）](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. 一个刺绣对象代表绣花机针的一个层次。多个刺绣对象会一个接一个地被绣出，这样就能使用多种颜色。

你可以根据想要的颜色选择你的对象。

向下滚动，找到合适的箭头。

![创建刺绣对象（5）](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. 给你的新对象起一个合适的名字，然后点击“确定”。

![创建刺绣对象（3）](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. 你已经创建了一个新对象。现在你可以添加脚本，为对象编程了。

![创建刺绣对象（4）](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

现在你已经知道如何创建对象。每想使用一种颜色，就添加一个新对象。

你可以为每种颜色添加一段脚本，设计属于你自己的图案，之后甚至可以把它绣出来。

需要灵感或帮助吗？快去看看我们的其他教程吧！
