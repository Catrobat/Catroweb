你想在有趣的方式中发挥创意，同时学习编程吗？你是否也喜欢创作一些可以马上使用、穿戴和欣赏的东西？

借助 Embroidery Designer，即使没有任何经验，你也能为绣花机编程，让它自动把你的设计绣在 T 恤、包、裤子、手机壳，甚至你的鞋子上。只要是布做的东西，都可以绣。尽情发挥你的想象力和创造力吧！你还可以从 Catrobat 社区下载和编辑别人的设计。当然，你也可以和朋友以及全世界分享你的项目！
