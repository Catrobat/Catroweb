在本教程中，你将学会如何在移动设备上保存和分享你完成的设计。

为此，你需要一个想要导出的、已经完成的刺绣设计。如果你还没有，可以从我们的[刺绣教程](index.md)中获得灵感！

*你可以在这里下载 PDF 格式的教程*：

[导出设计](../../../media/embroidery-tutorials/Export-Designs.pdf)

### 1. 启动你的项目，并等待它完全展开。否则图案会不完整。

### 2. 点击返回，然后按下分享按钮。

![导出设计（1）](../../../media/embroidery-tutorials/Export-Designs-1.png)

### 3. 通过电子邮件分享你的刺绣文件，或者把它保存到手机上。

![导出设计（2）](../../../media/embroidery-tutorials/Export-Designs-2.png)

不同手机上的分享功能可能略有不同。

你的刺绣设计会被保存为 DST 文件。

绣花机认识这种文件格式，会把你的设计绣在布料上。
