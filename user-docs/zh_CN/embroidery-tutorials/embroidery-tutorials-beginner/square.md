在本教程中，你将学会绣一个正方形（60 x 60 毫米）。

![图片（3）](../../../media/embroidery-tutorials/image-3.png)

你应该已经知道如何创建新对象，并在其中插入积木。如果你还需要帮助，可以看看[入门系列](../../game-tutorials/starter-tutorials/index.md)的教程。此外，刺绣积木必须已经启用。你可以在**[启用刺绣积木](activate-embroidery-bricks.md)**教程中了解如何启用。

如需更多信息或设计灵感，请看看其他教程。

*你可以在这里下载 PDF 格式的教程*：

[正方形](../../../media/embroidery-tutorials/Square.pdf)

### 1. 创建一个新的刺绣对象（参见[创建刺绣对象](create-embroidery-objects.md)）。

### 2. 现在一步一步地把积木插入到你的脚本中。

![正方形](../../../media/embroidery-tutorials/Square.png)

正方形由四条线组成，它们之间的角度都是 90°。

首先，脚本运行平针缝。之后，针移动 300 步，并转 90°。这个过程重复 4 次。

如果你改变角度或步数，会发生什么呢？**试试看！**

### 3. 点击运行，开始绣你的设计！
