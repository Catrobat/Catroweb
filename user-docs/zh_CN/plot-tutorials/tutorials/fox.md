[狐狸（PDF，德语）](../../../media/plot-tutorials/Fuchs.pdf)

绘图开始后，每一次移动都会像用笔画出来一样被记录下来。这些就是绘图机之后会沿着切割的线条。

这只狐狸只由直线（“移动 ___ 步”）和转弯组成。

**提示**：边做边测试你的程序。
