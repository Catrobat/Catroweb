绘图开始后，每一次移动都会像用笔画出来一样被记录下来。这些就是绘图机之后会沿着切割的线条。

我们的角色朝向 150 度。

在本教程中，我们先做猫头的右侧。仔细看就会发现，一开始弯曲得很厉害，所以每画完一小段线，角色都要转得更多一些。然后，下半部分的头部弯度变小。猫头的左侧又弯得很厉害，所以这一部分总共要用三次循环。

接下来是左耳。它只由直线组成，所以我们可以使用“移动 __ 步”积木。

两耳之间的部分又是一段弧线，我们用另一个循环来编程。

然后做右耳。

绘图现在完成了。用“停止绘图”积木结束，再用“将绘图保存为 SVG 文件 ___”把它保存到手机上。

现在你可以把 SVG 文件发送给（切割）绘图机了。
