在本教程中，你将学会开始创建第一个项目前，需要了解的关于 Pocket Code 的一切。我们会一步一步地告诉你如何下载应用、打开它，以及创建新项目。

![新程序](../../../media/game-tutorials/New-Program.png)\
我们会一步一步地告诉你如何下载应用、打开它，以及创建新项目。\
[打开图片](../../../media/game-tutorials/New-Program.png)

这是第一个教程，你不需要任何预先的知识。

那么，还等什么？拿起你的手机，现在就开始吧！

*你可以在这里下载 PDF 格式的教程：*

[打开 PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. 安装 Pocket Code

首先，你需要在你的设备上安装 Pocket Code 应用。 这一步需要一个 Google 账户。 之后，你的设备会下载并安装这个应用。 根据你的网络情况，这一步可能需要一些时间。

![新程序（2）](../../../media/game-tutorials/New-Program-2.png)\
你可以在 Google Play 商店中搜索“Pocket Code”，然后点击“安装”来下载它。\
[打开图片](../../../media/game-tutorials/New-Program-2.png)

成功下载并安装 Pocket Code 后，你可以在应用列表或主屏幕上找到它，具体取决于你的设备。你可以把应用拖到任何你喜欢的位置。

### 2. 打开应用

![新程序（1）](../../../media/game-tutorials/New-Program-1.png)\
打开应用时，你会看到不同的分类：\
[打开图片](../../../media/game-tutorials/New-Program-1.png)

### 3. 创建新项目

下一步是真正创建新项目。 现在你需要输入项目名称，并选择你的项目是否使用横屏。 按下“确定”，项目就创建好了。

![新程序](../../../media/game-tutorials/New-Program.png)\
为此，你可以按右下角的黄色加号按钮。\
[打开图片](../../../media/game-tutorials/New-Program.png)

### 4. 你做到了！你创建了自己的新项目。

现在你已经安装了 Pocket Code，并且知道如何创建新项目。接下来就可以开始编程了！

要做到这一点，你需要知道如何在项目中创建新对象。请看看**[新对象](new-object.md)**教程，里面一步一步地讲解了所有内容。
