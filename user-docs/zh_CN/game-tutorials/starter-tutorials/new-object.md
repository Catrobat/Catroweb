在本教程中，你将学会如何在项目中创建新对象，以及你有哪些不同的方法。

![新对象](../../../media/game-tutorials/New-Object.png)

要做到这一点，你应该已经下载了 Pocket Code 应用，并且知道如何创建新项目。如果你需要帮助，可以看看**[新项目](new-project.md)**教程。

*你可以在这里下载 PDF 格式的教程：*

[新对象](../../../media/game-tutorials/New-Object.pdf)

### 1. 创建新对象

首先，你需要打开你的新项目。

你可以在 Pocket Code 应用的主屏幕上找到它。如果你有不止一个项目，可以点击“设备上的项目”，然后选择你的新项目。如果你还没有创建新项目，或者需要更多关于如何创建的信息，请看看**[新项目](new-project.md)**教程。

### 2. 创建新对象

现在你可以创建新对象了。点击右下角的黄色加号按钮。会出现一个新窗口，里面有七种可以选择的方式。

![新对象（1）](../../../media/game-tutorials/New-Object-1.png)

### 4. 绘制图片

为了让刚开始的时候尽量简单，我们使用“绘制”功能，画一个点就行。用 Pocket Paint 画好点之后，退出它（返回一步即可）。

### 5. 起一个名字

现在，你需要给你的图片起一个名字。

### 6. 放置图片

之后，你需要用手指把它向左右或上下移动，直观地放置它。然后点击右上角的按钮保存。

![新对象（3）](../../../media/game-tutorials/New-Object-3.png)

### 7. 你做到了！你创建了自己的新对象。

现在你有了一个带有对象的项目，可以为它编程了！

要做到这一点，你应该知道有哪些积木可以用。**[第一批积木](first-bricks.md)**教程会让你很好地了解各个积木类别。当然，你也可以直接开始做你的第一个项目。请从初级系列中选一个合适的教程。
