Dalam tutorial ini, kamu akan belajar semua yang perlu kamu tahu tentang Pocket Code untuk mula mencipta projek pertama kamu. Kami akan memandu kamu langkah demi langkah tentang cara memuat turun aplikasi, membukanya, dan mencipta projek baharu.

Ini ialah tutorial pertama, dan kamu tidak perlukan pengetahuan sedia ada.

Jadi, apa lagi yang kamu tunggu? Ambil telefon kamu dan mula sekarang!

*Di sini kamu boleh muat turun tutorial dalam format PDF:*

[Buka PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Pemasangan Pocket Code

Pertama, kamu perlu pasang aplikasi Pocket Code pada peranti kamu. Untuk langkah ini, Akaun Google diperlukan. Sekarang peranti kamu akan memuat turun dan memasang aplikasi. Langkah ini mungkin mengambil sedikit masa bergantung pada sambungan internet kamu.

![Program Baharu (2)](../../../media/game-tutorials/New-Program-2.png)\
Kamu boleh cari aplikasi dengan mencari “Pocket Code” dalam Google Play Store dan memuat turunnya dengan menekan “install”.\
[Buka gambar](../../../media/game-tutorials/New-Program-2.png)

Selepas berjaya memuat turun dan memasang Pocket Code, kamu boleh cari aplikasi dalam laci aplikasi atau pada skrin utama, bergantung pada peranti kamu. Kamu boleh mengalihkan aplikasi ke mana-mana tempat yang kamu suka dengan mudah.

### 2. Mulakan Aplikasi

![Program Baharu (1)](../../../media/game-tutorials/New-Program-1.png)\
Apabila kamu membuka aplikasi, kamu nampak kategori yang berbeza.\
[Buka gambar](../../../media/game-tutorials/New-Program-1.png)

### 3. Cipta projek baharu

Langkah seterusnya ialah mencipta projek baharu. Sekarang kamu perlu masukkan nama projek dan pilih sama ada projek kamu patut dalam format landskap atau tidak. Dengan menekan “OK”, projek itu dicipta.

![Program Baharu](../../../media/game-tutorials/New-Program.png)\
Untuk berbuat demikian, kamu boleh tekan butang tambah kuning di sudut kanan bawah.\
[Buka gambar](../../../media/game-tutorials/New-Program.png)

### 4. Berjaya! Kamu telah mencipta projek baharu kamu sendiri.

Kini kamu telah memasang Pocket Code dan tahu cara mencipta projek baharu. Sekarang kamu boleh mula mengaturcara!

Untuk itu, kamu perlu tahu cara mencipta objek baharu dalam projek. Lihat tutorial **[Objek Baharu](new-object.md)**, di mana semuanya diterangkan kepada kamu langkah demi langkah.
