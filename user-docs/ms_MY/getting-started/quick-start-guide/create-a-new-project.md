Buka aplikasi pada telefon pintar atau tablet kamu.

![MainScreen_NewProject](../../../media/getting-started/MainScreen_NewProject.png)\
Ketik simbol + untuk mencipta projek baharu.\
[Buka gambar](../../../media/getting-started/MainScreen_NewProject.png)

Beri nama kepada projek (1) dan tentukan sama ada kamu mahu mencipta permainan dalam format potret (menegak) atau landskap (mendatar) (2).

![NewProject](../../../media/getting-started/NewProject.png)\
Kemudian sahkan dengan tanda semak (3).\
[Buka gambar](../../../media/getting-started/NewProject.png)

Kini kamu berada dalam paparan projek. Di bahagian atas, kamu nampak nama permainan kamu.

Di bawahnya kamu nampak **latar belakang** – buat masa ini, latar belakang masih kosong. Jika kamu mahu menukarnya, ketik padanya.

Di bawah latar belakang, kamu nampak ruang untuk **pelakon dan objek** yang telah kamu tambah ke dalam permainan kamu. Buat masa ini, ruang itu masih kosong.

Di bahagian kanan bawah, kamu nampak dua butang penting:

![Main](../../../media/getting-started/Start.png)\
Dengan butang **Main**, kamu memulakan permainan kamu.

![Butang Tambah](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Dengan butang **Tambah**, kamu menambah watak/objek baharu ke dalam permainan kamu.
