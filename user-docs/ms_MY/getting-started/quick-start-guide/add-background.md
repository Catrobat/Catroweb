Kamu boleh menambah latar belakang pada projek kamu dalam Catrobat.

Latar belakang boleh digunakan dengan pelbagai cara. Dalam Pocket Code, ia boleh digunakan untuk menceriakan **permainan** secara visual, menceritakan **cerita**, atau memberi pelakon dan objek kamu lebih konteks.

Untuk peranti makerspace seperti **pemplot** atau **mesin sulaman**, latar belakang berfungsi sebagai templat reka bentuk, seperti untuk potongan atau corak sulaman.

![Ketik Latar belakang](../../../media/getting-started/grafik-16.png)\
Untuk menambah latar belakang, ketik “Latar belakang” dalam paparan projek.\
[Buka gambar](../../../media/getting-started/grafik-16.png)

Dalam **bahagian skrip (2)**, kamu boleh mengaturcara latar belakang kamu – namun, tidak semua blok tersedia untuk ini. Dua blok berikut sangat penting: ![Tetapkan_ketelusan_kepada_50_peratus](../../../media/bricks/Set_transparency_to_50_pct_.png) dan ![Tetapkan_saiz_kepada_60_peratus](../../../media/bricks/Set_size_to_60_pct_.png)

Dalam **bahagian rupa (1)**, kamu menambah latar belakang.

![Tambah latar belakang](../../../media/getting-started/grafik-14.png)\
Untuk berbuat demikian, ketik simbol +.\
[Buka gambar](../../../media/getting-started/grafik-14.png)

Kamu boleh muat naik imej sendiri, guna latar belakang yang sedia ditetapkan, atau cipta latar belakang sendiri.

**Lukis**: Kamu boleh mencipta latar belakang sendiri dengan **Pocket Paint**. Pocket Paint ialah program lukisan ([maklumat lanjut tentang Pocket Paint](https://catrobat.org/pocket-paint/))

**Rupa**: Pilih satu daripada koleksi latar belakang sedia buat ([maklumat lanjut tentang Pustaka Media](../elements/medialibrary.md)).

**Galeri**: Kamu boleh memilih imej daripada galeri telefon pintar kamu.

**Kamera**: Kamu boleh guna kamera peranti untuk mengambil gambar dan menambahnya sebagai latar belakang.

![grafik](../../../media/getting-started/grafik-17.png)\
Klik anak panah undur di sudut kanan atas untuk kembali ke **Paparan Projek**.\
[Buka gambar](../../../media/getting-started/grafik-17.png)

Kini kamu telah menambah latar belakang.
