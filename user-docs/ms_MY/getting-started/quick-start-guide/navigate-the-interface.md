Apabila kamu mula Pocket Code, kamu nampak skrin utama berikut.

![Skrin Utama](../../../media/getting-started/MainScreen-e1732269599192.jpg)

Di sudut kanan atas, ada simbol ![Bantuan](../../../media/getting-started/Screenshot-2024-11-22-111748.png) yang membawa kamu ke dokumentasi Catrobat, yang mempunyai tip berguna untuk kamu.

Di sebelahnya ialah menu ![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png). Dari situ, kamu boleh pergi ke tetapan dengan mudah, di mana kamu boleh menukar bahasa atau menghidupkan sambungan seperti blok plot dan banyak lagi.

Di bawahnya, kamu nampak projek yang paling baru kamu edit. Klik pada ikon edit ![Ikon edit](../../../media/getting-started/Screenshot-2024-11-22-111825.png) untuk membuka paparan projek, tempat kamu boleh meneruskan pembangunan projek kamu.

Guna butang main ![Mulakan projek kamu](../../../media/getting-started/Screenshot-2024-11-22-111818.png) untuk memulakan projek kamu.

Dengan klik pada Projects on device, kamu boleh mengakses projek yang disimpan. ![Projects on device](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Jika kamu mahu mengenali dan bekerja pada lebih banyak projek daripada pengguna lain, klik sahaja pada Catrobat Community di Share. Di sana kamu akan jumpa banyak projek hebat. ![Catrobat Community](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Jika kamu mahu mencipta projek baharu, klik pada ikon tambah. ![Tambah](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
