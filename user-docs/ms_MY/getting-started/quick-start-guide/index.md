Pocket Code ialah aplikasi pengaturcaraan visual yang membolehkan kamu mencipta permainan, animasi dan cerita interaktif terus pada telefon pintar atau tablet kamu. Dengan antara muka seret dan lepas yang mudah menggunakan “blok” (blok kod), kamu boleh mereka bentuk projek tanpa pengalaman mengaturcara. Tambah bunyi, gambar dan gerakan dengan mudah untuk menghidupkan idea kamu.

Panduan ini akan membantu kamu bermula dengan menerangkan cara untuk:

- Melayari antara muka,
- Mencipta projek pertama kamu,
- Bekerja dengan objek dan latar belakang,
- Guna blok untuk mengaturcara tindakan, dan
- Menyimpan projek kamu.

Sesuai untuk pemula dan pendidik, Pocket Code menggalakkan kreativiti, penyelesaian masalah dan pemikiran logik.
