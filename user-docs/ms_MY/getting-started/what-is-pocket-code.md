Pocket Code ialah aplikasi utama Catrobat, aplikasi mudah alih percuma dan sumber terbuka yang membolehkan kamu mencipta permainan, animasi dan cerita interaktif terus pada telefon pintar atau tablet kamu. Dengan **sistem pengaturcaraan berasaskan blok** Pocket Code, kamu boleh membina projek dengan menyambungkan blok kod seperti memasang kepingan teka-teki. Kamu tidak perlu pengalaman pengaturcaraan, jadi ia sesuai untuk pemula!

Pocket Code lebih daripada projek digital sahaja. Dengan **ciri makerspace** yang baharu, kamu juga boleh mereka bentuk **fail SVG untuk pemplot pemotong**. Ini bermakna kamu boleh menukar ciptaan digital kamu menjadi barangan sebenar dan meneroka kemungkinan kreatif di luar skrin.

Sama ada kamu sedang belajar mengaturcara, mencuba idea baharu, atau mengajar pengaturcaraan, Pocket Code menyediakan cara yang menyeronokkan dan mudah untuk mula mengaturcara.
