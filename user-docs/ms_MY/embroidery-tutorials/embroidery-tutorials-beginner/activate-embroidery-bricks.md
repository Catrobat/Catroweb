Dalam tutorial ini, cara mengaktifkan blok sulaman akan diterangkan.

![Aktifkan blok sulaman5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Kamu tidak perlukan pengetahuan mengaturcara untuk ini. Ini ialah langkah pertama untuk mula dengan tutorial sulaman. Kemudian, kamu boleh mereka bentuk, mengaturcara, dan malah menyulam reka bentuk kamu sendiri pada kain kegemaran kamu.

Untuk maklumat lanjut atau cadangan reka bentuk, lihat tutorial yang lain.

*Di sini kamu boleh muat turun tutorial dalam format PDF*:

[ActivateEmbroideryBricks](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Mulakan aplikasi “Pocket Code”. Ikut klik-klik ini!

### 2. Buka menu (titik di sudut kanan atas).

![Aktifkan blok sulaman](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Pergi ke “Tetapan”.

![Aktifkan blok sulaman3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Pilih “Sambungan sulaman”.

![Aktifkan blok sulaman4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Kamu akan jumpa blok sulaman sebagai kategori sendiri dalam blok kamu!

[![Aktifkan blok sulaman5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Kini kamu juga akan jumpa semua blok sulaman di antara blok-blok yang lain.

Untuk maklumat lanjut tentang setiap blok, sila semak dokumentasi blok [di sini](../../../reference/) atau ikuti tutorial **[Blok-blok sulaman](embroidery-bricks/index.md)**.

Kini kamu boleh mula dan mencipta reka bentuk kamu sendiri!

Jika kamu perlukan idea atau bantuan, lihat tutorial yang lain atau teruskan dengan tutorial **[Cipta objek sulaman](create-embroidery-objects.md)**.
