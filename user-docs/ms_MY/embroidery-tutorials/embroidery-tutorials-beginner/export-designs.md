Dalam tutorial ini, kamu akan belajar cara menyimpan dan berkongsi reka bentuk siap kamu pada peranti mudah alih.

Untuk ini, kamu perlukan reka bentuk sulaman yang sudah siap untuk dieksport. Jika kamu belum ada, jangan segan untuk mendapat inspirasi daripada [tutorial sulaman](index.md) kami!

*Di sini kamu boleh muat turun tutorial dalam format PDF*:

[Eksport reka bentuk](../../../media/embroidery-tutorials/Export-Designs.pdf)

### 1. Mulakan projek kamu dan tunggu sehingga ia terbuka sepenuhnya. Jika tidak, corak itu akan tidak lengkap.

### 2. Tekan kembali dan tekan butang kongsi.

![Eksport reka bentuk (1)](../../../media/embroidery-tutorials/Export-Designs-1.png)

### 3. Kongsi fail sulaman kamu melalui e-mel atau simpannya pada telefon kamu.

![Eksport reka bentuk (2)](../../../media/embroidery-tutorials/Export-Designs-2.png)

Fungsi kongsi mungkin kelihatan sedikit berbeza pada setiap telefon.

Reka bentuk sulaman kamu akan disimpan sebagai fail DST.

Mesin sulaman mengenali format fail ini dan melengkapkan reka bentuk kamu pada kain kamu.
