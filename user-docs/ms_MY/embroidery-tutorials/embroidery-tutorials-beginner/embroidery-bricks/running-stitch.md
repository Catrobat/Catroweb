Membiarkan mesin menjahit secara berterusan dengan panjang yang boleh diubah.

Biasanya kamu gabungkan jahitan jelujur dengan blok gerak.

![Mulakan_jahitan_jelujur_dengan_panjang_10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Mesin memulakan jahitan jelujur yang akan menjahit setiap **10 langkah**.

Kemudian mesin bergerak **200 langkah**.

Ini menghasilkan **20 jahitan**.

![Jahitan jelujur](../../../../media/embroidery-tutorials/RunningStitch.png)

Jahitan jelujur memudahkan menjahit sambungan kerana kamu tidak perlu gelung lagi.
