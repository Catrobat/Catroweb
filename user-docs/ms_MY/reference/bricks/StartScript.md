![Apabila_babak_bermula](../../../media/bricks/When_scene_starts_btn2.png)

Jika kamu guna blok ini, skrip akan mula dengan serta-merta apabila babak bermula. Babak ialah permulaan program kamu. Babak ialah paparan baharu dalam program kamu di mana elemen lain boleh dipaparkan dan pelbagai interaksi boleh berlaku. Kamu boleh ada banyak babak untuk fasa program yang berbeza. Contohnya, satu babak untuk pengenalan, satu babak untuk menu utama, satu untuk tahap pertama, satu untuk tahap kedua dan seterusnya. Untuk program yang lebih ringkas, satu babak sahaja sudah mencukupi, dan permulaan program kamu juga ialah permulaan babak.

Seperti setiap skrip, yang ini bermula dengan blok peristiwa: peristiwa itu menentukan **bila** skrip bermula, dan blok selepasnya memberitahu program **apa** yang perlu dibuat.
