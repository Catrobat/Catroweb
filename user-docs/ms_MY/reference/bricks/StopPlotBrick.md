![Berhenti_memplot](../../../media/bricks/Stop_to_plot.png)

Blok “Berhenti memplot” menghentikan proses memplot dan membolehkan kamu memindahkan pelakon ke kedudukan baharu atau menamatkan pemplotan. Ia seperti mengangkat pen dari atas kertas untuk meletakkannya semula atau berhenti melukis. Selepas kamu siap memplot, kamu boleh guna blok “Simpan plot sebagai SVG” untuk menyimpan reka bentuk kamu sebagai fail SVG.
