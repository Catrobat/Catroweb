*Menyemak sama ada syarat benar, dan menjalankan satu set arahan jika ia benar, dan satu set lagi jika tidak. Ia seperti memberi dua pilihan: “Jika ini benar, buat ini; jika tidak, buat itu.”*

![Mulakan_babak](../../../media/bricks/StartScene.png)

Apabila babak bermula, pemboleh ubah X ditetapkan kepada 0.

![JikaTidak](../../../media/bricks/IfElse.png)

Jika haiwan itu kini diketik, semakan dibuat sama ada X modulo 2 adalah benar, iaitu sama ada X ialah nombor ganjil.

Jika ini berlaku, bunyi Tweet1 dimainkan dan pemboleh ubah X ditambah 1.

Jika tidak, jika X ialah genap, hanya X ditambah 1.

Penyata yang perlu dijalankan dipisahkan dengan Tamat jika.
