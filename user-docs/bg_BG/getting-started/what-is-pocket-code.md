Pocket Code е основното приложение на Catrobat – безплатно мобилно приложение с отворен код, с което можеш да създаваш игри, анимации и интерактивни истории направо на смартфона или таблета си. С помощта на **системата за програмиране с блокове** на Pocket Code можеш да създаваш проекти, като сглобяваш блокове с код – като парчета от пъзел. Не е нужен опит в програмирането, което го прави идеално за начинаещи!

Pocket Code е повече от цифрови проекти. С новите **функции за творчески работилници** можеш да създаваш и **SVG файлове за режещи плотери**. Това означава, че можеш да превърнеш цифровите си творби в реални предмети и да изследваш творчески възможности отвъд екрана.

Независимо дали учиш програмиране, експериментираш с нови идеи или преподаваш програмиране, Pocket Code ти дава игрив и достъпен начин да се потопиш в програмирането.

[Повече информация](https://catrobat.org/pocket-code/)
