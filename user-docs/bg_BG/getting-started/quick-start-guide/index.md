Pocket Code е приложение за визуално програмиране, с което можеш да създаваш игри, анимации и интерактивни истории направо на смартфона или таблета си. С интуитивен интерфейс „плъзни и пусни“ с „блокове“ (блокове с код) можеш да проектираш проектите си, без никакъв предишен опит в програмирането. Лесно добавяй звуци, изображения и движение, за да оживиш идеите си.

Това ръководство ще ти помогне да започнеш, като обяснява как да:

- се ориентираш в интерфейса,
- създадеш първия си проект,
- работиш с обекти и фонове,
- използваш блокове, за да програмираш действията, и
- запазиш проекта си.

Идеално за начинаещи и учители, Pocket Code насърчава творчеството, решаването на проблеми и логическото мислене.
