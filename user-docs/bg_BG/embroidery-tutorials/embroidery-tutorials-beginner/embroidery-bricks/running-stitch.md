Кара машината да бродира непрекъснато с променлива дължина.

Обикновено комбинираш прав бод с блок за движение.

![Започни прав бод с дължина 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Машината започва прав бод, който бодва на всеки **10 стъпки**.

После машината се премества с **200 стъпки**.

Това дава **20 бода**.

![Прав бод](../../../../media/embroidery-tutorials/RunningStitch.png)

Правият бод улеснява бродирането на шев, защото вече не ти трябва цикъл.
