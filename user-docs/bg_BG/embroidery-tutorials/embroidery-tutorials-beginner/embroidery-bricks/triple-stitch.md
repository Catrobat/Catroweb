Тройният бод прави всеки бод три пъти.

Тройният бод се връща назад след първия бод, бодва, после се връща отново напред и бодва пак.

![Започни троен бод с дължина 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Работи по същия начин като [прав бод](running-stitch.md).

![Троен бод](../../../../media/embroidery-tutorials/TripleStitch.png)

Това прави шева по-траен.
