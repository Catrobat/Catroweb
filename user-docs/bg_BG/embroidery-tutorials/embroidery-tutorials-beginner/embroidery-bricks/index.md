В този урок ще научиш всичко, което трябва да знаеш за блоковете за бродерия!

За това не са ти нужни познания по програмиране.

Всеки блок за бродерия е обяснен с пример.

Ако още не си активирал блоковете за бродерия, виж урока **[Активиране на блоковете за бродерия](../activate-embroidery-bricks.md)**.

[Блокове за бродерия](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)
