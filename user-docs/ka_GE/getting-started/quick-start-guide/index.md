Pocket Code არის ვიზუალური პროგრამირების აპლიკაცია, რომელიც საშუალებას გაძლევთ შექმნათ თამაშები, ანიმაციები და ინტერაქტიული ისტორიები პირდაპირ შენს სმარტფონზე ან ტაბლეტზე. ინტუიციური მიზიდვისა და ჩამოსვლის ინტერფეისის გამოყენებით „კოდის ბლოკები“ (კოდი ბლოკები), შენ შეგიძლია შექმნათ შენი პროექტები წინასწარი პროგრამირების გამოცდილების გარეშე. მარტივად დაამატეთ ხმები, სურათები და მოძრაობა შენი იდეების გაცოცხლებისთვის.

ეს სახელმძღვანელო დაგეხმარებათ დაიწყოთ, თუ როგორ უნდა:

- გადმოიყვანეთ ინტერფეისი,
- შექმენი შენი პირველი პროექტი,
- მუშაობა ობიექტებთან და ფონდებთან,
- გამოიყენეთ კოდის ბლოკები პროგრამული ქმედებებისთვის და
- ჲეალთ ჟჲპჟრთრვ.

იდეალური დამწყებთათვის და პედაგოგებისთვის, Pocket Code წახალისებს შემოქმედებითობას, პრობლემების გადაჭრას და ლოგიკურ აზროვნებას.
