შეგიძლია დაამატოთ შენი პროექტის ფონზე Catrobat.

ფონები შეიძლება გამოყენებულ იქნას სხვადასხვა გზით. Pocket Code შეიძლება გამოყენებულ იქნას ვიზუალურად გაძლიერებისთვის **თამაშები**, მოსაყუარებლად **ისტორიები**, ან შენი მსახიობებისა და ობიექტებისათვის მეტი კონტექსტის შესაცვლელად.

მწარმოებელ სივრცეში მოწყობილობებისათვის, როგორიცაა **მკვლელები** ან **საფირმო მანქანები**, ფონდები ემსახურებიან დიზაინის შაბლონებს, მაგალითად, ჭრილობისა და კერპების ნიმუშებისთვის.

დამატებისათვის, დააჭირე „ფონი“ პროექტის ნახვაზე.

![რჩევები](../../../media/getting-started/grafik-16.png)

**სცენარის ნაწილი ((2)** -ში შეგიძლია პროგრამირება შენი ფონი - თუმცა, ყველა ბლოკი არ არის ხელმისაწვდომი ამისთვის. განსაკუთრებით მნიშვნელოვანია შემდეგი ორი ბლოკი: ![დააყენე გამჭვირვალობა 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) და ![დააყენე ზომა 60%](../../../media/bricks/Set_size_to_60_pct_.png)

**გამოიყურება განყოფილება(1)** -ში დაამატეთ ფონი. ამისათვის დააჭირე + სიმბოლოს.

![დაამატეთ ფონი](../../../media/getting-started/grafik-14.png)

შეგიძლია ატვირთოთ საკუთარი სურათები, გამოიყენოთ წინასწარ განსაზღვრული ფონები ან შექმნათ ფონი თავად.

**დახატვა**: შეგიძლია შექმნათ შენი საკუთარი ფონი **Pocket Paint**. Pocket Paint არის ხატვის პროგრამა ([მეტი ინფორმაცია Pocket Paint](https://catrobat.org/pocket-paint/))

**იერსახეები**: აირჩიე ერთი წინასწარ დამზადებული ფონების კოლექციიდან ([მეტი მედია ბიბლიოთეკაზე](../elements/medialibrary.md)).

**გალერეა**: შეგიძლია აირჩიოთ სურათი შენი სმარტფონის გალერეიდან.

**კამერა**: შეგიძლია გამოიყენოთ შენი მოწყობილობის კამერა ფოტოს გადასაღებად და დაამატოთ იგი ფონად.

![აირჩიე მედია ბიბლიოთეკიდან](../../../media/getting-started/grafik-17.png)

ახლა შენ დაამატეთ ფონი. დააჭირე უკანა ისარს ზედა მარჯვენა მხარეს, რომ დაბრუნდეთ **პროექტის ნახვა**.
