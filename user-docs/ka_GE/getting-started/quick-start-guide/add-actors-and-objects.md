დააჭირე + ღილაკს, რომ დაამატოთ ახალი ფიგურა ან ობიექტი შენს პროექტში.

![დამატება მსახიობი](../../../media/getting-started/FigurHinzufuegen.png)

Pocket Code -ში შეგიძლია დაამატოთ პერსონაჟი ან ობიექტი შენს პროექტში სხვადასხვა გზით:

**დახატვა**: შეგიძლია შექმნათ შენი საკუთარი პერსონაჟი **Pocket Paint**. Pocket Paint არის ხატვის პროგრამა ([მეტი ინფორმაცია Pocket Paint](https://catrobat.org/pocket-paint/))

**იერსახეები**: აირჩიე ერთი წინასწარ დამზადებული მსახიობებისა და ობიექტების კოლექციიდან ([მეტი მედია ბიბლიოთეკაზე](../elements/medialibrary.md)).

**გალერეა**: შეგიძლია აირჩიოთ სურათი შენი სმარტფონის გალერეიდან.

**ბიბლიოთეკა**: ბიბლიოთეკაში შენ ნახავთ მსახიობებს და ობიექტებს, რომლებიც უკვე პროგრამირებულია, რაც ნიშნავს, რომ მათ უკვე აქვთ სცენარი. შეგიძლია აირჩიოთ ისინი, თუ გსურთ გამოიყენოთ მზადყოფნაში მყოფი ელემენტები შენს თამაშში (მაგალითად, უკუთვალება) ([ბიბლიოთეკაზე მეტი](../elements/medialibrary.md#დაამატეთ-ობიექტი-მედია-ბიბლიოთეკიდან)).

**კამერა**: შეგიძლია გამოიყენოთ შენი მოწყობილობის კამერა ფოტოს გადასაღებად და დაამატოთ იგი პერსონაჟად.

**ზურგჩანთა**: ზურგჩანთე ამჟამად ცარიელია. შეგიძლია გამოიყენოთ მსახიობები ან ნივთები, რომლებიც შენს ზურგჩანთში ინახავს. მთლიანი სცენარი გათავისუფლდება მასთან ([უფრო მეტი ზურგჩანთის შესახებ](../elements/backpack.md)).

**პერსონაჟები და ობიექტები მოწყობილობაზე**: აქ შენ ნახავთ მზადყოფნაში მყოფი პერსონაჟები, რომლებიც შეგიძლია გამოიყენოთ შენს პროექტში. ადგილობრივი მოთამაშეები და ობიექტები ფუნქციონირებენ როგორც ოფლაინ მედია ბიბლიოთეკა, რაც იმას ნიშნავს, რომ თუნდაც ინტერნეტ კავშირი არ გაქვს, ამ მოთამაშეებზე წვდომა შეგიძლია.

**ცარიელი ობიექტი**: დაამატეთ ცარიელი ობიექტი, რომელიც არის ობიექტი, რომელსაც არ აქვს გარეგნობა. შეგიძლია ამ ობიექტს ჩვეულებრივად გადააწეროთ.

**პროექტები მოწყობილობაზე**: აირჩიე პროექტი, რომლის მიხედვითაც გსურთ შენი პროექტში ჩასვათ პირველი მსახიობი სცენართან ერთად.
