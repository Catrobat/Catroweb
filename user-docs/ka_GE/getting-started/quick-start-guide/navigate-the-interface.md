როდესაც დაიწყებთ Pocket Code, შენ ნახავთ შემდეგ მთავარ ეკრანს.

![მთავარი ეკრანი](../../../media/getting-started/MainScreen-e1732269599192.jpg)

მარჯვენა ზედა კუთხეში არის ![დახმარება](../../../media/getting-started/Screenshot-2024-11-22-111748.png) სიმბოლო, რომელიც მიგიყვანთ დოკუმენტაციაში Catrobat, სადაც არის სასარგებლო რჩევები შენთვის.

ამის გვერდით არის მენიუ ![მენიუ](../../../media/getting-started/Screenshot-2024-11-22-111804.png). იქიდან მარტივად შეგიძლია გადახვიდეთ პარამეტრებზე, სადაც შეგიძლია შეცვალოთ ენა ან ჩართოთ გაფართოებები, როგორიცაა ბლოკები და სხვა.

ქვემოთ შეგიძლია იხილოთ შენი ბოლო რედაქტირებული პროექტი. დააჭირე რედაქტირების იკონს ![შეარედაქტირება](../../../media/getting-started/Screenshot-2024-11-22-111825.png) პროექტის ეკრანზე მისასვლელად, სადაც შეგიძლია გააგრძელოთ შენი პროექტი განვითარება.

დაიწყეთ შენი პროექტი დააჭირე Play ღილაკს ![დაიწყეთ შენი პროექტი](../../../media/getting-started/Screenshot-2024-11-22-111818.png).

დაწკაპუნებით პროექტები შეგიძლია მიაღწიოთ შენს შეინახულ პროექტებს. ![პროექტები მოწყობილობაზე](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

თუ გსურთ სხვა მომხმარებლების მიერ დამატებითი პროექტების გაცნობა და მუშაობა, უბრალოდ დააჭირე Catrobat საზოგადოებას გაზიარებაში. იქ ბევრი შესანიშნავი პროექტი ნახავთ. ![Catrobat საზოგადოება](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

თუ გსურთ შექმნათ ახალი პროექტი, დააჭირე პლუს-ის იკონს. ![დამატება](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
