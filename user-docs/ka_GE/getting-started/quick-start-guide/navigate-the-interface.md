როდესაც დაიწყებთ Pocket Code, შენ ნახავთ შემდეგ მთავარ ეკრანს.

![მთავარი ეკრანი](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
როდესაც დაიწყებთ Pocket Code, შენ ნახავთ შემდეგ მთავარ ეკრანს.\
[გახსენი სურათი](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![დახმარება](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
მარჯვენა ზედა კუთხეში არის სიმბოლო, რომელიც მიგიყვანთ დოკუმენტაციაში Catrobat, სადაც არის სასარგებლო რჩევები შენთვის.

![მენიუ](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
ამის გვერდით არის მენიუ.

იქიდან მარტივად შეგიძლია გადახვიდეთ პარამეტრებზე, სადაც შეგიძლია შეცვალოთ ენა ან ჩართოთ გაფართოებები, როგორიცაა ბლოკები და სხვა.

![შეარედაქტირება](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
დააჭირე რედაქტირების იკონს პროექტის ეკრანზე მისასვლელად, სადაც შეგიძლია გააგრძელოთ შენი პროექტი განვითარება.

ქვემოთ შეგიძლია იხილოთ შენი ბოლო რედაქტირებული პროექტი.

![დაიწყეთ შენი პროექტი](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
დაიწყეთ შენი პროექტი დააჭირე Play ღილაკს.

![პროექტები მოწყობილობაზე](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
დაწკაპუნებით პროექტები შეგიძლია მიაღწიოთ შენს შეინახულ პროექტებს.

![Catrobat საზოგადოება](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
თუ გსურთ სხვა მომხმარებლების მიერ დამატებითი პროექტების გაცნობა და მუშაობა, უბრალოდ დააჭირე Catrobat საზოგადოებას გაზიარებაში.

იქ ბევრი შესანიშნავი პროექტი ნახავთ.

![დამატება](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
თუ გსურთ შექმნათ ახალი პროექტი, დააჭირე პლუს-ის იკონს.
