გახსენი აპი ტელეფონზე ან ტაბლეტზე.

![მთავარი ეკრანი ახალი პროექტი](../../../media/getting-started/MainScreen_NewProject.png)\
ახალი პროექტის შესაქმნელად დააჭირე + ნიშანს.\
[გახსენი სურათი](../../../media/getting-started/MainScreen_NewProject.png)

დაარქვი პროექტს სახელი (1). აირჩიე თამაშისთვის ვერტიკალური (პორტრეტი) ან ჰორიზონტალური (ალბომი) ფორმატი (2).

![ახალი პროექტი](../../../media/getting-started/NewProject.png)\
შემდეგ დასადასტურებლად დააჭირე მონიშვნის ნიშანს (3).\
[გახსენი სურათი](../../../media/getting-started/NewProject.png)

ახლა შენ ხართ შენი პროექტის ხედვა. ზემოდან ხედავთ თამაშის სახელს.

ქვემოთ შეგიძლია იხილოთ **ფონი** - ამჟამად, ფონი ცარიელია. თუ გინდათ შეცვალოთ, დააჭირე მას.

ფონზე, შენ ხედავთ შენი **მოთამაშეები და ობიექტები** რაიონი, რომელიც დაამატეთ შენს თამაშში. ამჟამად, ტერიტორია კვლავ ცარიელია.

მარჯვენა ქვემოთ, შენ ხედავთ ორი მნიშვნელოვანი ღილაკი:

![დაიწყეთ](../../../media/getting-started/Start.png)\
ღილაკით **გაშვება** იწყებთ თამაშს.

![პლუს ღილაკი](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
ღილაკით **აგრეთვე** შენ დაამატებთ ახალ პერსონაჟს/ობიექტს შენს თამაშში.

![პროექტის ეკრანი](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
ახლა შენ ხართ შენი პროექტის ხედვა.\
[გახსენი სურათი](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
