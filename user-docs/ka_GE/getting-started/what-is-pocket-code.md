Pocket Code არის Catrobat-ის მთავარი აპი. ის უფასოა და ღია კოდი აქვს. შეგიძლია ტელეფონზე ან ტაბლეტზე თამაშები, ანიმაციები და ინტერაქტიული ამბები შექმნა. Pocket Code-ში **კოდს ბლოკებით აწყობ**. პროექტი რომ შექმნა, კოდის ბლოკები თავსატეხის ნაწილებივით შეაერთე. პროგრამირების გამოცდილება არ გჭირდება. ეს აპი დამწყებთათვისაც კარგია!

Pocket Code არა მხოლოდ ციფრული პროექტების მიღმა. ახალი **makerspace მახასიათებლები** -ის საშუალებით შენ ასევე შეგიძლია შექმნათ **SVG საჭრელად მოწყობილ ფაილებს**. ეს ნიშნავს, რომ შენ შეგიძლია შენი ციფრული შემოქმედება რეალურ სამყაროში გადააქციოთ და ეკრანის მიღმა შემოქმედებითი შესაძლებლობები გამოისწავლოთ.

თუ შენ სწავლობთ კოდირებას, ექსპერიმენტებს ახალ იდეებთან ან პროგრამირების სწავლას, Pocket Code უზრუნველყოფს თამაშის და ხელმისაწვდომი გზას კოდირებაში ჩახვილებისთვის

[დამატებითი ინფორმაცია](https://catrobat.org/pocket-code/)
