**ზურგჩანთა** თვისება Pocket Code არის პრაქტიკული ფუნქცია, რომელიც საშუალებას გაძლევთ **შენახვა და განმეორებითი გამოყენება** ელემენტები, როგორიცაა მსახიობები (ობიექტები), სცენარი, ხედი ან ხმები **პროექტების ფარგლებში**. ეს დაგეხმარებათ დაზოგოთ დრო და გახადოთ შენი პროექტები უფრო ეფექტური.

ზურგჩანთა არის ციფრული სათავსო სივრცე, სადაც შეგიძლია შეინახოთ შენი მიმდინარე პროექტის სხვადასხვა ელემენტი. როდესაც ეს ელემენტები ზურგჩანთაში გადარჩება, შეგიძლია ამონახოთ და შეინერგოთ სხვა პროექტებში.

### როგორ გამოვიყენო ზურგჩანთა მსახიობებისთვის (ობიექტებისთვის)?

**შეავსეთ ფიგურები ზურგჩანთაში**

გადადით პროექტის ნახვაზე, რომლის ფიგურასაც ზურგჩანთში უნდა ჩაგავსოთ.

დააჭირე ფიგურის გვერდით მდებარე სამ წერტილს კონტექსტის მენიუს გახსნისათვის და აირჩიე „ჩადება“.

ფიგურა (მათ შორის მისი გარეგნობა, ხმები და სცენარი) ჩასვამენ ზურგჩანთაში.

![პაკტური მსახიობი](../../../media/getting-started/grafik-7.png)

**შემატეთ ციფრები ზურგჩანთიდან**

გახსენი პროექტი, სადაც გსურთ შეინერგოთ ფიგურა.

პროექტის ხილვაში დააჭირე + სიმბოლოს და აირჩიე „ზურგჩანთა“.

ახლა ნახავთ ყველა ფიგურას და საგნებს, რომლებიც შენს ზურგჩანთში ინახეთ. დააჭირე სამი წერტილს და აირჩიე „ამოღება“.

![დევნაკტური მსახიობი](../../../media/getting-started/grafik-8-e1732702791199.png)

***

### კაკ ვ ოჲჱნავ ზაქტვნარა ჱა სცენარ?

**ჟრანთსაფუთაჲ ნაოპაგთლწნაჲ:**

წადი იმ ფიგურაზე, სადაც სცენარია. შეაჩერეთ სასურველი სცენარი სცენარის რედაქტორში.

შეარჩიეთ „ზურგჩანთაში ჩადება“ კონტექსტის მენიუდან.

![ჩანთაში დამატება](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

დაასახელეთ სცენარი და დაამტკიცეთ კარგი.

![ჟლსთჟკვნ ნა ჟლვემ](../../../media/getting-started/grafik-9.png)

სცენარი შენახულია და შეიძლება გამოყენებულ იქნას სხვა პროექტებში.

![შენი ზურგჩანთა](../../../media/getting-started/grafik-10.png)

**დაამატეთ სცენარები ზურგჩანთიდან:**

დაწკაპეთ მსახიობზე, სადაც სცენარს უნდა შეამატოთ. ღვ გთეთქ ჟრანთწ ნაჟლვე. დააჭირე სამი წერტილი, რომ გახსნათ კონტექსტის მენიუ და დააჭირე „ზურგჩანთა“.

![გაიღვიძეთ სკრიპტი](../../../media/getting-started/grafik-11.png)

ახლა შეგიძლია ნახო ყველა სცენარი, რომელიც უკვე შენს ზურგჩანთშია. დააჭირე სასურველი სცენარის გვერდით მდებარე სამ წერტილს და აირჩიე „ამოღება“ კონტექსტის მენიუდან.

კონტექსტის მენიუდან შეგიძლია წაშალოთ სცენარები, რომლებიც ზურგჩანთში აღარ გჭირდებათ.

![გაშალეთ სკრიპტი ზურგჩანთა](../../../media/getting-started/grafik-12.png)

### ზურგჩანთის სარგებელი

- **პროექტების შორის განმეორებითი გამოყენება:** ფიგურები, სცენარები, ხმები და გარეგნობა შეიძლება შეიქმნას ერთხელ და საჭიროებისამებრ ხშირად გამოიყენოს.
- **დროის დაზოგვა:** შენ არ უნდა შექმნათ ციფრები ან სცენარი ყოველ ჯერზე.
- **თანმიმდევრულობა:** ელემენტები თანმიმდევრულად რჩება, როდესაც მათ მრავალ პროექტში სჭირდებათ.
