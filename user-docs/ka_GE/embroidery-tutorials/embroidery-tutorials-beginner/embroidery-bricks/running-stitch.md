აძლევს მანქანის მუდმივ შეხებას ცვლადი სიგრძით.

ოჲჟლვმთვ, ჟრანთრვ ჟვ ჟჲბაბა ჟ ჟ ჟრანთ ჟრანთჟრთმ.

![დაიწყე სწორი ნაკერი სიგრძით 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

მანქანა იწყებს მიმდინარე კერვას, რომელიც ყველა **10 ნაბიჯი** კერავს.

მაშ, აპარატმა მოძრაობა დაიწყო **200 ნაბიჯი**.

ამან გამოიწვია **20 საცვლე**.

![დაიწყე სწორი ნაკერი სიგრძით](../../../../media/embroidery-tutorials/RunningStitch.png)

ფუნქციონირებადი კერძი უფრო ადვილი გახდის კერძი, რადგან აღარ დაგჭირდებათ ბეჭედი.
