ამ მასწავლებელში შენ გაიგებთ ყველაფერს, რაც უნდა იცოდეთ ბლოკების შესახებ!

ნვ სჭირდება რპწბგა ეა ჱნამ გპვმვ ჱა რჲგა.

თითოეული ბლოკი "ბროდერის კოდი" განმარტდება მაგალითით.

თუ ჯერ არ გააქტიურეთ Embroidery-code ბლოკები, გადახედეთ **[გააქტიურება ბლოკები embroidery- კოდი](../activate-embroidery-bricks.md)** -ის მასწავლებელზე.

*აქ შეგიძლია ჩამოტვირთოთ მასწავლებელი PDF ფორმატში*:

[ბლოკები, რომლებიც შედის კერპების კოდებით](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**დააჭირე სხვადასხვა კოდის ბლოკებს, რათა გაიგოთ მეტი მათ შესახებ:**

[![გააკეთე ნაკერი](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*ეა ჟვ ჟრანთ ოპაგრა ნა ჲბჲპარა!*

[![დაიწყე სწორი ნაკერი სიგრძით 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*აძლევს მანქანის მუდმივ შეხებას ცვლადი სიგრძით.*

[![დაიწყე ზიგზაგისებრი ნაკერი სიგრძით 2 და სიგანით 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*მუდმივად შეხეთ ცვალებადი სიგრძითა და სიგანით.*

[![დაიწყე სამმაგი ნაკერი სიგრძით 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*სამგარეო კერძი თითოეულ კერკს სამჯერ აწვენებს.*

[![შეწყვიტე მიმდინარე ნაკერი](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*ეა ჟრწამ ნა ჟრჟრა.*

შეგიძლია იხილოთ მეტი ბლოკები Embroidery-code და ინფორმაცია მათ შესახებ [აქ](../../../../reference/#category_embroidery).

დამატებითი ინფორმაციისთვის ან დიზაინის წინადადებებისთვის იხილეთ სხვა მასწავლებლები!
