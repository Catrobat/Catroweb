ეა ჟრწამ ნა ჟრჟრა.

ეს კოდი აუცილებელია იმ შემთხვევაში, თუ გსურთ შეცვალოთ ნემრის პოზიცია გაშვების შემდეგ, თუკი დაიწყოთ გაშვება, ციგზაგის ან სამმაგი ძერღვის.
