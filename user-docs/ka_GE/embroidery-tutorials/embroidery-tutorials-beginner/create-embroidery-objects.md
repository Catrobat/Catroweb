ამ გაკვეთილში ისწავლით, როგორ შექმნათ ობიექტები, რომლითაც მოგვიანებით შეგიძლია შენი ნიმუშების ჩასახვა.

ამ მასწავლებლისთვის, შენ უკვე უნდა იცოდეთ როგორ შექმნათ პროექტი. იხილეთ გაკვეთილები [საწყისი სერია](../../game-tutorials/starter-tutorials/index.md), თუ დაგჭირდებათ დახმარება.

დამატებითი ინფორმაციისთვის ან დიზაინის წინადადებებისთვის, შეგიძლია გაეცნოთ სხვა მასწავლებლებს.

*აქ შეგიძლია ჩამოტვირთოთ მასწავლებელი PDF ფორმატში*:

[შექმნას საფირმო ობიექტები](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. დააჭირე პროექტის მარჯვენა ქვედა ნაწილში არსებულ "+" ღილაკს, რათა დაამატოთ ახალი ობიექტი.

![შექმნას საფირმო ობიექტები](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. სურათის შესარჩევი მიზნით, გადადით მედია ბიბლიოთეკაში.

![შექმნას საფირმო ნივთები (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. საფირმო ნივთი წარმოადგენს საფირმო მანქანის ნემსის ერთ დონეს. რამდენიმე საფირმო ნივთი დაიფირება ერთმანეთის შემდეგ. ეს საშუალებას იძლევა გამოიყენოს რამდენიმე ფერი.

შეგიძლია აირჩიოთ შენი ობიექტი, რაც დამოკიდებულია შენთვის სასურველ ფერზე.

გადმოიფარეთ და ეძებეთ შესაფერისი ისრა.

![შექმნას საფირმო ნივთები (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. დაასახელეთ შენი ახალი ობიექტი შესაბამისი სახელი და დააჭირე კარგი.

![შექმნა საფირმო ნივთები (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. ახლა შენ შექმნეს ახალი ობიექტი. შეგიძლია ახლა დაამატოთ სცენარი და პროგრამა ობიექტი.

![შექმნა საფირმო ნივთები (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

ახლა იცით როგორ შექმნათ ობიექტი. დაამატეთ ახალი ობიექტი თითოეული ფერის, რომელსაც გსურთ გამოიყენოთ.

შეგიძლია დაამატოთ თითოეული ფერის სცენარი და გადააწეროთ შენი დიზაინი და კიდევ შემდგომაც კი გააკრიფოთ.

გჭირდებათ შთაგონება ან დახმარება? შეხედე ჩვენს სხვა გაკვეთილებს!
