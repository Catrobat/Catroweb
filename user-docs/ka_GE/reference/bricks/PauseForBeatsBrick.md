ეს კოდი ბლოკი სცენარს აძლევს დაველოდოს მითითებული რაოდენობის ბეტები, სანამ გააგრძელებს. ეს ისეთივეა, როგორც სიმღერაში მცირე პაუზა დაყენება შემდეგ ნოტაზე ან ჟღერადობაზე. წარმოიდგინეთ, რომ შეაჩერეთ შენი შესრულება ერთი წუთით, გათვალეთ ტემპები და შემდეგ განაახლეთ მოქმედება.
