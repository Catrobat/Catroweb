![დააყენე ბრუნვის სტილი](../../../media/bricks/set_rotation_style_brick2.png)

იცვლის, თუ როგორ ბრუნავს ობიექტი (ყველაფერში, მარცხნივ-მარჯვნივ მხოლოდ ან არ ბრუნდება). ეს ისეთივეა, როგორც გადაწყვიტოთ, თუ შეიძლება შენი პერსონაჟი მთელი გზა გადატრიალდეს, უბრალოდ მარცხნივ და მარჯვნივ გადატრიალდეს ან საერთოდ არ დაიბრუნოს.
