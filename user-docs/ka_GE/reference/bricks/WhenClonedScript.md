![როცა კლონის სახით დაიწყებ](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

საგნის შექმნილი კლონის მიმართვა სასურველი ქმედებების განხორციელების ინსტრუქციებით. ეს პროცესი საშუალებას იძლევა რეპლიკაცია ფუნქციონალურობა ორიგინალური ობიექტი, ხოლო კონტროლი კლონი დამოუკიდებლად. კლონური ობიექტის სხვადასხვა ქცევა ან თვისებები შეიძლება განისაზღვროს სპეციფიკური მოთხოვნების დასაკმაყოფილებლად.
