![გაუგზავნე ყველას და დაელოდე:](../../../media/bricks/brodcast_wait_brick3.png)

გზავნის შეტყობინებას შენი პროექტის სხვა ნაწილებს და შემდეგ ელოდება, სანამ ისინი დასრულებენ თავიანთ ამოცანებს, სანამ გადავა. ეს ისეთივეა, როგორც მეგობარს რაღაცის გაკეთება მოსთხოვო და ელოდე, სანამ შენ გააგრძელებ.

**ჱაღჲრჲ ეა თჱვჟლევქ გმვნ?**

შეტყობინებებით შეგიძლია კომუნიკაცია და ურთიერთქმედება სხვადასხვა ობიექტებს შორის სცენაში. ეს საშუალებას აძლევს ერთ ობიექტს, გააგზავნოს შეტყობინება ყველა სხვა ობიექტზე და მისაღები ობიექტები შემდეგ რეაგირებენ ან პასუხობენ ამ შეტყობინებას.

ეს შეტყობინებები არის **არ არის ნაჩვენები** ეკრანზე! თუ გსურთ შეტყობინებების ჩვენება, გამოიყენეთ კოდის ბლოკები „იერსახეები“ კატეგორიაში!

**კაკჲ ოპვრთმ?**

- *გამგზავრებელი ობიექტი:* გამგზავნებელი ობიექტი იწყებს კომუნიკაციას *„გაუგზავნე ყველას:“* ბლოკის გამოყენებით. ეს ბლოკი გამოიყენება სცენის ყველა სხვა ობიექტისთვის (ასევე ფონის) შეტყობინების გაგზავნისთვის.
- *მიმღები ობიექტი:* მიმღები ობიექტი არის ის, რომელიც უსმენს და პასუხობს შეტყობინებებს. ეს გამოიყენება *„როცა მიიღებ შეტყობინებას:“* ბლოკი იმისათვის, რომ აღმოაჩინოს, თუ როდის მიიღება კონკრეტული შეტყობინება.
- *შეტყობინებების მართვა:* როდესაც მიმღები ობიექტი იღებს შეტყობინებას, ის განახორციელებს ყველა ბლოკს, რომელიც არის ქვემოთ *„როცა მიიღებ შეტყობინებას:“* ბლოკი. ეს საშუალებას გაძლევთ განსაზღვროთ მორგებული ქცევა ან მოქმედებები, რომლებიც ხდება როდესაც კონკრეტული შეტყობინება მიიღება.
