![დაიწყე ხაზვა](../../../media/bricks/Start_to_plot.png)

ეს კოდი იწყებს პროცესს, როდესაც მსახიობი მოძრაობს. ეს არის მსგავსი, როგორც ფუნტი ქაღალდზე დაწყებული ხაზის მოხატვა. შეგიძლია გამოიყენოთ კოდის ბლოკი „შეწყვიტე ხაზვა“ თუ გსურთ შეაჩეროთ ნახატის და გადაიტანოთ მსახიობი სხვა ადგილას და შემდეგ კვლავ დაიწყოთ სიუჟეტი „დაიწყე ხაზვა“.
