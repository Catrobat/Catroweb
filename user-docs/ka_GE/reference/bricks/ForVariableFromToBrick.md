ამ კოდის ბლოკში ინსტრუქციების ნაკრები განხორციელდება კონკრეტული რაოდენობის დროს, გამრიცხველი გამოიყენება, რომელიც იწყება ერთ ღირებულებაზე და მთავრდება მეორეზე. ეს ისეთივეა, როგორც წრეების შექმნა სადაც ზუსტად იცი რამდენჯერ უნდა გაიქცეს.

წარმოიდგინეთ, რომ შენ გაქვთ ნივთების ჩამონათვალი და გსურთ თითოეულ მათგანთან ერთად რაღაც გააკეთოთ. ეს ბლოკი საშუალებას გაძლევთ გადახედოთ თითოეულ ნივთს ერთი და ერთი, გააკეთოთ იგივე თითოეულზე.
