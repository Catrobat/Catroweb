![დააყენე კალმის ფერი o წითელი 0 მწვანე 0 ლურჯი 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

ეს კოდი ბლოკი შეცვლის მსახიობის მიერ გამოყენებული ფერის. ეს ისეთივეა, როგორც სხვა ფერის კალამიდან გადასვლა ხატვის დროს.

**წითელი, მწვანე, ლურჯი (RGB)**: RGB ფერის მოდელი იყენებს სხვადასხვა ინტენსივობას წითელი, მწვანე და ლურჯი სინათლე ფერების ფართო სპექტრის შესაქმნელად. თითოეულ ფერის კომპონენტს (წითელი, მწვანე და ლურჯი) შეუძლია 0-დან 255-მდე ღირებულება ჰქონდეს:

- **წითელი**: ფერის წითელი კომპონენტი. უფრო მაღალი ღირებულება ნიშნავს უფრო წითელ.
- **მწვანე**: ფერის მწვანე კომპონენტი. უფრო მაღალი ღირებულება ნიშნავს უფრო მწვანე.
- **ლურჯი**: ფერის ლურჯი კომპონენტი. უფრო მაღალი ღირებულება ნიშნავს უფრო ლურჯს.

წითელი, მწვანე და ლურჯი ფერის სხვადასხვა მნიშვნელობის კომბინირებით შეგიძლია შექმნათ ნებისმიერი ფერი. მაგალითად:

- `RGB(255, 0, 0)` არის წითელი.
- `RGB(0, 255, 0)` არის მწვერვალზე მწვანე.
- `RGB(0, 0, 255)` არის სუფთა ლურჯი.
- `RGB(255, 255, 255)` არის თეთრი (მაქსიმალურად წითელი, მწვანე და ლურჯი).
- `RGB(0, 0, 0)` შავი (არ აქვს ფერი).

ამ ფერების სხვადასხვა რაოდენობით შერევა ყველა ფერს ქმნის, რომელიც ციფრულ ეკრანებზე ჩანს.
