![დასასრული ეტაპის კოდი ბლოკი](../../../media/bricks/finish-stage-brick.png)

ეს კოდი ბლოკი ყველა სცენარს შეაჩერებს და ამჟამინდელი სტადიის ან სცენის დასრულებას აპირებს. ეს არის ისეთი, როგორც ამბობენ, „ეს ნაწილი დასრულდა.“ ყველაფერი წყდება და პროექტი შეიძლება გადავიდეს სხვა სცენაზე ან დასრულდეს მთლიანად. გამოიყენეთ ეს, როდესაც გსურთ დაასრულოთ შენი პროექტის კონკრეტული ეტაპი ან დონე.
