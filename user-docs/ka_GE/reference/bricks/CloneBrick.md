![შექმენი კლონი:](../../../media/bricks/create_clone_of_brick2.png)

ეს კოდი ბლოკი ქმნის მითითებული ობიექტის ასლს, რომელსაც კლიონი ჰქვია და რომელიც მოქმედებს როგორც ორიგინალი. წარმოიდგინეთ, რომ შენს თამაშში ასახელებთ პერსონაჟს ან ობიექტს. კლოონს შეუძლია ჰქონდეს საკუთარი ქცევები და სცენარები, რაც საშუალებას გაძლევთ შექმნათ რამდენიმე ინსტანცია ობიექტის, რომელსაც შეუძლია დამოუკიდებლად მოქმედოს.
