![დაიწყე ეპიზოდი:](../../../media/bricks/start_scene_brick2.png)

ეს კოდი ბლოკი გადადის შენს პროექტში სხვა სცენაზე და იწყებს ამ სცენის შესრულებას თავიდანვე. ეს ისეთივეა, როგორც წიგნის თავის შეცვლა ან თამაშში მომდევნო დონეზე გადასვლა.

წარმოიდგინეთ, რომ შენს პროექტში რამდენიმე სცენაა. თითოეული შენი ისტორიის ან თამაშის სხვადასხვა ნაწილს წარმოადგენს. ამ კოდის ბლოკის გამოყენებით შეგიძლია გადახვიდეთ ნებისმიერ სცენაზე და დაიწყოთ ის თავიდანვე, შექმნით გლუვი გარდამავალი შენი პროექტის სხვადასხვა ნაწილებს შორის.
