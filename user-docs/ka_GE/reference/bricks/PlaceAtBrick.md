![მოთავსდი წერტილში](../../../media/bricks/place_at_x_y_brick.png)

გადააქვს ობიექტი ეკრანზე კონკრეტულ პოზიციაზე, რომელიც განსაზღვრულია x და y კოორდინატებით. ჟჲგვრთ ეა ჟვ ოპვპაგთრვ გჟვნა ჟთ ნა ჱვქა.

პოზიცია განისაზღვრება კოორდინატების სისტემაში, როგორიცაა კარტეზიანული თვითმფრინავი: x და y ღერძები გადის ეკრანის ცენტრში, ასე რომ x = 0 და y = 0 არის ეკრანის შუა ნაწილი.
