![ცალი ნაწილაკების ფერის დაყენება "#ff0000"](../../../media/bricks/Set_particle_colour_to_ff0000.png)

ეს კოდი ბლოკი შეცვლის მსახიობის მიერ გამონაბოლქული ნაწილაკების ფერს. ჟჲგვრთ ეა ჟვ ჲრთევქ გალჲჟა ნა კჲნფეთნთრვ ფსკრა.

ქეცის კოდი ფერის წარმოჩენის საშუალებაა ქეცების ქეცის ღირებულებების გამოყენებით. ეს არის შედგენილი ექვსი ხასიათის, რომელიც შეიძლება იყოს რიცხვები (0-9) ან ასოები (A-F). კოდი ჩვეულებრივ იწერება „#“ თავიდან, ასე: `#RRGGBB`.

- პირველი ორი ხასიათი (`RR`) წარმოადგენს ფერის წითელ კომპონენტს.
- შემდეგი ორი ხასიათი (`GG`) წარმოადგენს მწვანე კომპონენტს.
- ბოლო ორი ხასიათი (`BB`) წარმოადგენს ლურჯ კომპონენტს.

თითოეული წყვილი სიმბოლო შეიძლება იყოს `00` (რაც ნიშნავს, რომ არც ერთი ამ ფერის) და `FF` (რაც ნიშნავს ამ ფერის მაქსიმალურ რაოდენობას). მაგალითად:

`#000000` შავი (არ აქვს ფერი).

`#FF0000` არის წითელი.

`#00FF00` არის მწვერვალზე მწვანე.

`#0000FF` არის სუფთა ლურჯი.

`#FFFFFF` არის თეთრი (მაქსიმალურად წითელი, მწვანე და ლურჯი).
