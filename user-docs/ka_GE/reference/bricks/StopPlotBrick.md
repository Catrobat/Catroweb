![შეწყვიტე ხაზვა](../../../media/bricks/Stop_to_plot.png)

„შეწყვიტე ხაზვა“ კოდის ბლოკი შეაჩერებს სათამაშოების პროცესს და საშუალებას გაძლევთ გადაიტანოთ მსახიობი ახალ პოზიციაზე ან დასრულდეთ სათამაშოები. ეს ისეთივეა, როგორც ფურცლის ამოღება ქაღალდზე, რომ გადავადგინოთ მისი ადგილი ან შეწყვიტოთ ხატვა. როდესაც შენ დასრულებული გაქვთ გეგმის შექმნა, შეგიძლია გამოიყენოთ კოდის ბლოკი „შეინახე ნახაზი SVG ფაილად“ შენი დიზაინის შესანახად SVG ფაილად.
