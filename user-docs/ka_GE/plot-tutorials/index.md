თჟკაქ ეა ჟვ ნაოპაგთქ ლთ ჟთ? ჩვენი გაკვეთილები გირჩევთ გამოიყენოთ კოდი ბლოკები, რათა გადაჭრას ხაზები მოჭრილი plotter. შეისწავლეთ ტექნიკა და ინსტრუმენტები, რომლებიც საჭიროა შენი დიზაინის ზუსტი და შემოქმედებითი გამოყენებისათვის.
