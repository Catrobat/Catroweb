როდესაც სიუჟეტი იწყება, თითოეული მოძრაობა ისეა ხატული, თითქოს კალმით. ეს არის ხაზები, რომელსაც შემთქმელი მოგვიანებით გაჭრის.

ჩვენი ობიექტი მიმართულებით მიუთითებს 150 გრანდი.

ამ გაკვეთილში, კატის თავის მარჯვენა მხარე პირველად გაკეთებულია. თუ კარგად დააკვირდებით, თავდაპირველად კრუვა ძლიერია, ამიტომ ობიექტს უნდა გადატრიალდეს უფრო მეტი თითოეული პატარა ხაზის შემდეგ. კალკები უფრო მცირდება თავის ქვედა ნაწილში. მკლავის მარცხენა მხარე კვლავ ძლიერად არის მოხრილი. ამიტომაც ამ ნაწილში სულ სამი ბეჭედია.

შემდეგ კი მარცხენა ყური. ეს მხოლოდ სწორი ხაზებითაა დამზადებული, ამიტომ შეგვიძლია კოდის ბლოკი „გადადგი \_\_ ნაბიჯი“ გამოვიყენოთ.

ყურებს შორის არსებული ნაწილი ისევ კისერია და პროგრამირებულია სხვა ლუპით.

მაშინ მარჯვენა ყური მზადდება.

ჟვდა ნაოპაგთმ ჟლვე. დაასრულეთ კოდი „შეწყვიტე ხაზვა“ და შეინახეთ ტელეფონზე „შეინახე ნახაზი SVG ფაილად \_\_\_“.

აწ შეგიძლია გააგზავნოთ ფაილი SVG (გაჭრის) შემქმნელს.
