[ვარსკვლავი (PDF, გერმანული)](../../../media/plot-tutorials/Stern.pdf)

როდესაც სიუჟეტი იწყება, თითოეული მოძრაობა ისეა ხატული, თითქოს კალმით. ეს არის ხაზები, რომელსაც შემთქმელი მოგვიანებით გაჭრის.

ამ ვარსკვლავს აქვს 6 ქულა. წერტილი არის სწორი ხაზი („გადადგი 100 ნაბიჯი“), ბრუნვა და სხვა სწორი ხაზი, რომელიც ამთავრებს წერტილის ფორმას. შემდეგი წერტილის წინ, უნდა გადახვიდეთ საპირისპირო მიმართულებით, რათა შემდეგი წერტილი გამოჩნდეს სწორად.

***შენიშვნა**: სრული წრე არის 360°. თითოეული წერტილისთვის ჩვენ 100° მარჯვნივ და 40° მარცხნივ ვტრიალდებით, რაც სულ 60° მარჯვნივ არის.*

*ექვსივე წვერისთვის მარჯვნივ ჯამში 360°-ით ვბრუნდებით.*

**წადი უფრო შორს**: შეეცადეთ სხვადასხვა კაბინაციების კომბინაცია და შეცვალეთ ქულების რაოდენობა.
