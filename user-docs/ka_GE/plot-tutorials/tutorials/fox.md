როდესაც სიუჟეტი იწყება, თითოეული მოძრაობა ისეა ხატული, თითქოს კალმით. ეს არის ხაზები, რომელსაც შემთქმელი მოგვიანებით გაჭრის.

ეს თხისფერი მხოლოდ სწორი ხაზებითაა დამზადებული („გადადგი \_\_\_ ნაბიჯი“) და ბრუნავს.

**საწინააღმდეგო**: ტესტირეთ შენი პროგრამა, სანამ შენ ააშენებთ მას.
