ამ გაკვეთილში ისწავლით, თუ როგორ უნდა შექმნათ ახალი ობიექტი შენს პროექტში და რა შესაძლებლობები გაქვთ ამისათვის.

![ახალი ობიექტი](../../../media/game-tutorials/New-Object.png)\
ამ გაკვეთილში ისწავლით, თუ როგორ უნდა შექმნათ ახალი ობიექტი შენს პროექტში და რა შესაძლებლობები გაქვთ ამისათვის.\
[გახსენი სურათი](../../../media/game-tutorials/New-Object.png)

ამისათვის შენ უნდა გადმოწეროთ Pocket Code აპლიკაცია და იცოდეთ, როგორ შექმნათ ახალი პროექტი. თუ ამ საკითხში დაგჭირდებათ დახმარება, გთხოვთ იხილოთ **[ახალი პროექტი](new-project.md)** -ის გაკვეთილი.

*აქ შეგიძლია ჩამოტვირთოთ მასწავლებელი PDF ფორმატში:*

[გახსენი PDF](../../../media/game-tutorials/New-Object.pdf)

### 1. შექმენი ახალი ობიექტი

თავიდან, უნდა გახსნათ შენი ახალი პროექტი.

შენ ნახავთ მას Pocket Code აპლიკაციის საწყის ეკრანზე. თუ შენ გაქვთ ერთზე მეტი პროექტი, შეგიძლია დააჭიროთ „პროექტები“. მაშინ აირჩიე შენი ახალი პროექტი. თუ შენ არ შექმენი ახალი პროექტი ან გჭირდებათ დამატებითი ინფორმაცია, როგორ გააკეთოთ ეს, იხილეთ **[ახალი პროექტი](new-project.md)** -ს გაკვეთილი.

### 2. შექმენი ახალი ობიექტი

ახლა მზად ხართ შექმნათ ახალი ობიექტი. შენ ნახავთ ახალ ფანჯარს, რომელიც გაძლევთ შვიდ შესაძლებლობას აირჩიოთ.

![ახალი საგანი (1)](../../../media/game-tutorials/New-Object-1.png)\
ამისათვის, დააჭირე ყვითელ პლუს ღილაკს მარჯვენა ქვედა კუთხეში.\
[გახსენი სურათი](../../../media/game-tutorials/New-Object-1.png)

### 3. შექმნის გზები

![ახალი საგანი (2)](../../../media/game-tutorials/New-Object-2.png)\
ეს არის შესაძლებლობები, რომელთაგანაც შეგიძლია აირჩიოთ.\
[გახსენი სურათი](../../../media/game-tutorials/New-Object-2.png)

### 4. სურათი

რომ ეს მაქსიმალურად მარტივი იყოს დასაწყისისთვის, ჩვენ გვინდა გამოვიყენოთ „დახატვა“ ფუნქცია და უბრალოდ დავხატოთ წერტილი. როდესაც შენ შეხატეთ წერტილი Pocket Paint შეგიძლია დატოვოთ იგი (გადადგით ნაბიჯით უკან).

### 5. გადმოვცემ სახელი

ახლა შენ უნდა დაასახელოთ შენი სურათი.

### 6. აწვეთ იგი

ამის შემდეგ შენ უნდა დააყენოთ იგი ვიზუალურად, გადაიტანეთ ის მარცხნივ / მარჯვნივ ან ზევით / ქვემოთ თითით.

![ახალი საგანი (3)](../../../media/game-tutorials/New-Object-3.png)\
უნდა შეინახო ღილაკით მარჯვენა ზედა კუთხეში.\
[გახსენი სურათი](../../../media/game-tutorials/New-Object-3.png)

### 7. შენ შექმენი საკუთარი ახალი ობიექტი.

ახლა შენ გაქვთ პროექტი საგნის საშუალებით, რომლის პროგრამირებაც შეგიძლია!

ამისათვის უნდა იცოდეთ, რა კოდი ბლოკია ხელმისაწვდომი. **[პირველი კოდი ბლოკები](first-bricks.md)** -ს გაკვეთილი გთავაზობთ კოდბლოკების სხვადასხვა კატეგორიის კარგად აღებულ მიმოხილვას. თუმცა, შენ ასევე შეგიძლია პირდაპირ დაიწყოთ შენი პირველი პროექტი. აირჩიე შესაფერისი მასწავლებელი დამწყები სერიიდან.
