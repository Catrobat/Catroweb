ამ გაკვეთილში ისწავლით ყველაფერს, რაც უნდა იცოდეთ Pocket Code შესახებ შენი პირველი პროექტის შექმნის დასაწყისისთვის. ჩვენ გაგიყვანთ ნაბიჯ-ნაბიჯ, როგორ გადმოწეროთ აპლიკაცია, გახსნათ და შექმნათ ახალი პროექტი.

![ახალი პროგრამა](../../../media/game-tutorials/New-Program.png)\
ჩვენ გაგიყვანთ ნაბიჯ-ნაბიჯ, როგორ გადმოწეროთ აპლიკაცია, გახსნათ და შექმნათ ახალი პროექტი.\
[გახსენი სურათი](../../../media/game-tutorials/New-Program.png)

ეს არის პირველი მასწავლებელი და არ გჭირდებათ წინასწარი ცოდნა.

კაკგჲ ჟაკთრვ? ჱაღჲეაპვ ლთფჲნარა ჟთ და ჲბყპქ!

*აქ შეგიძლია ჩამოტვირთოთ მასწავლებელი PDF ფორმატში:*

[გახსენი PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. აპარატის დამონტაჟება Pocket Code

თავდაპირველად, შენ უნდა დააინსტალიროთ აპლიკაცია Pocket Code შენს მოწყობილობაზე. ამ ნაბიჯისთვის Google ანგარიშია საჭირო. ახლა შენი მოწყობილობა აიღებს აპლიკაციას და დააინსტალირებს. ეს ნაბიჯი შეიძლება გარკვეული დრო დასჭირდეს შენი ინტერნეტ კავშირის მიხედვით.

![ახალი პროგრამა (2)](../../../media/game-tutorials/New-Program-2.png)\
აპლიკაცია შეგიძლია მოძებნოთ „Pocket Code“ Google Play Store და ჩამოტვირთოთ „დაყენება“.\
[გახსენი სურათი](../../../media/game-tutorials/New-Program-2.png)

წარმატებით ჩამოტვირთვისა და ინსტალაციის შემდეგ Pocket Code შეგიძლია იპოვოთ აპლიკაცია აპლიკაციის ლანძღაში ან შენი მთავარი ეკრანზე, შენი მოწყობილობის მიხედვით. შეგიძლია აპლიკაცია ადვილად აიღოთ და ჩააყენოთ სადაც გსურთ.

### 2. აპლიკაციის დაწყება

![ახალი პროგრამა (1)](../../../media/game-tutorials/New-Program-1.png)\
აპლიკაციის გახსნისას, სხვადასხვა კატეგორიები ჩანს.\
[გახსენი სურათი](../../../media/game-tutorials/New-Program-1.png)

### 3. შექმნათ ახალი პროექტი

შემდეგი ნაბიჯი არის ახალი პროექტი შექმნა. ახლა შენ უნდა შეასვათ პროექტის სახელი და აირჩიოთ, უნდა იყოს თუ არა შენი პროექტი ლანდშაფტი. დაჭერით „კარგი“ პროექტი შეიქმნება.

![ახალი პროგრამა](../../../media/game-tutorials/New-Program.png)\
ამისათვის შეგიძლია დააჭიროთ ყვითელ პლუს ღილაკს მარჯვენა ქვედა კუთხეში.\
[გახსენი სურათი](../../../media/game-tutorials/New-Program.png)

### 4. რთ ჟვ ჲოპაგთქ!

ახლა შენ დაამონტაჟეთ Pocket Code და იცით, როგორ შექმნათ ახალი პროექტი. ჟვდა მჲდა ეა ოჲოპრგყპნვქ!

ამისათვის შენ უნდა იცოდეთ, როგორ შექმნათ ახალი ობიექტი პროექტში. იხილეთ **[ახალი ობიექტი](new-object.md)** -ის გაკვეთილი, სადაც ყველაფერი ეტაპობრივად განმარტებულია.
