ამ გაკვეთილში ისწავლით, სად უნდა იპოვოთ სხვადასხვა კოდის ბლოკი საგნის პროგრამირებისთვის. გარდა ამისა, ეს სახელმძღვანელო უზრუნველყოფს კოდის ბლოკების კატეგორიების კარგი მიმოხილვას.

კოდის ბლოკების ჩასატანად და ობიექტის გადასაწყებად, შენ უკვე უნდა შექმნათ პროექტი ობიექტთან ერთად. თუ ამ საკითხში დაგჭირდებათ დახმარება, შეგიძლია იხილოთ **[ახალი ობიექტი](new-object.md)** -ის გაკვეთილი.

*აქ შეგიძლია ჩამოტვირთოთ მასწავლებელი PDF ფორმატში:*

[პირველი კოდი ბლოკები](../../../media/game-tutorials/First-Bricks.pdf)

### 1. გახსენი არსებული ობიექტი

თავიდან, უნდა გახსნათ შენი პროექტი. შენ უკვე უნდა შექმნათ ობიექტი (თუ არა, შეამოწმეთ **[ახალი ობიექტი](new-object.md)** -ს გაკვეთილი). ახლა შეგიძლია დააჭიროთ საგნის სახელს.

### 2. არსებული კოდის ბლოკები

ამის შემდეგ შენ ნახავთ, რომ უკვე არსებობს რამდენიმე კოდი ბლოკი. ეს კოდი ბლოკები იქმნებოდა, როდესაც ჩვენ ვიზუალურად განვათავსეთ ობიექტი.

როცა ეპიზოდი დაიწყება, ეს ბლოკები ობიექტს ზუსტად იქ მოათავსებს, სადაც თავიდან დააყენე. ამ ადგილს აქ ნებისმიერ დროს შეგიძლია შეუცვალო.

::brick{type=StartScript}

::brick{type=PlaceAtBrick}

### 3. შეაყენეთ კოდის ბლოკები

ახლა შეგიძლია შექმნათ მეტი კოდი ბლოკი, დააჭირე ყვითელ პლუს ღილაკს მარჯვენა ქვედა კუთხეში. შენ ნახავთ ახალ ფანჯარს, რომელიც გთავაზობთ კოდბლოკების რამდენიმე კატეგორიას. ეს კატეგორიები შემდეგ ეტაპზე აღწერილია.

![პირველი კოდის ბლოკები (1)](../../../media/game-tutorials/First-Bricks-1.png)

### 4. კოდის ბლოკი კატეგორიები

ეს არის სხვადასხვა კოდის ბლოკის კატეგორიები:

![პირველი კოდის ბლოკები (2)](../../../media/game-tutorials/First-Bricks-2.png)

### 5. შეაყენეთ პირველი კოდი ბლოკი

ჩვენი პირველი კოდის ბლოკებისთვის, ჩვენ გვინდა გამოიყენოთ „გასრიალდი 1 წამი წერტილამდე x: Y:“ კოდის ბლოკი. შეგიძლია ნახოთ მოძრაობის კატეგორიაში. ფორმულების რედაქტორი შეგიძლია შეადაროთ წამების რაოდენობა და პოზიცია X და Y.

::brick{type=GlideToBrick}

### 6. ჩადეთ კოდი ბლოკი

კოდი ბლოკი დააყენეთ პროგრამის ბოლო პოზიციაზე და გაუშვით შენი პროგრამა პირველად. მჲზვქ ეა დჲ ნაოპაგთქ ჟ ჟჲ ჟალვ ჟრჟკა.

![პირველი კოდის ბლოკები (3)](../../../media/game-tutorials/First-Bricks-3.png)

### 7. ოჲჟლვეგაქ!

აჱ ნაპროგრამაჳვ ჟთ ოპვრთნარა!

თუ გსურთ შენი პროექტი გაუზიაროთ მეგობრებს, შეგიძლია შეამოწმოთ **[ატვირთეთ და გაზიარეთ](upload-and-share.md)** -ის გაკვეთილი, სადაც ზუსტად განმარტდება, თუ როგორ მუშაობს. წინააღმდეგ შემთხვევაში, უკვე შეგიძლია დაიწყოთ შენი პირველი საკუთარი პროექტი. თუ დაგჭირდებათ დახმარება ან შთაგონება, შეგიძლია შეამოწმოთ ჩვენი მასწავლებლები დამწყები სერიიდან.

შეგიძლია იხილოთ მეტი ინფორმაცია ყველა კოდბლოკის შესახებ [აქ](../../../reference/)!
