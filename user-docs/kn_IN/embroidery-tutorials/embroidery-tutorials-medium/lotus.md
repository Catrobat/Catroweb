ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ನೀನು ಲೋಟಸ್ (64.8 x 64.8mm) ಅನ್ನು ಹೇಗೆ ಕಸೂತಿ ಮಾಡುವುದು ಎಂಬುದನ್ನು ಕಲಿಯುವಿರಿ.

![ಚಿತ್ರ (12)](../../../media/embroidery-tutorials/image-12.png)

ನೀನು ಈಗಾಗಲೇ ಒಂದು ಲೂಪ್ ಏನು ಮತ್ತು ಹೇಗೆ ಕೆಲಸ ತಿಳಿದಿರಬೇಕು.

ನೀನು ಇನ್ನೂ ಯಾವುದನ್ನೂ ಕಸೂತಿ ಮಾಡದಿದ್ದರೆ [ಆರಂಭಿಕ](../embroidery-tutorials-beginner/index.md) ಸರಣಿಯಲ್ಲಿ ಕಸೂತಿ ಬೋಧನೆಗಳನ್ನು ನೋಡಿ.

ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗಾಗಿ ಅಥವಾ ವಿನ್ಯಾಸ ಸಲಹೆಗಳಿಗಾಗಿ ಇತರ ಟ್ಯುಟೋರಿಯಲ್ಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

*ಇಲ್ಲಿ ನೀನು ಟ್ಯುಟೋರಿಯಲ್ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದು PDF-ಫಾರ್ಮ್ಯಾಟ್*:

[ಲೋಟಸ್](../../../media/embroidery-tutorials/Lotus.pdf)

### 2. ಮೂಲ ರಚನೆ

![ಲೋಟಸ್](../../../media/embroidery-tutorials/Lotus.png)

### 3. ಕಂದು ಬಣ್ಣಗಳು

ಈ ಭಾಗವನ್ನು ಪಾದದ ಸಂದೇಶವನ್ನು ಕಳುಹಿಸುವ ಪ್ರತಿ ಬಾರಿ ಕರೆಯಲಾಗುತ್ತದೆ. ಅದನ್ನು ನಿನ್ನ ಪಠ್ಯಕ್ಕೆ ಸೇರಿಸಿಕೊಳ್ಳಿ.
