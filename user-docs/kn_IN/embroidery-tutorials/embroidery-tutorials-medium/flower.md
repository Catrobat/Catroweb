ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ನೀನು ಒಂದು ಹೂವನ್ನು (73 x 74.2mm) ಹೇಗೆ ಕಸೂತಿ ಮಾಡುವುದು ಎಂಬುದನ್ನು ಕಲಿಯುವಿರಿ.

![ಚಿತ್ರ (11)](../../../media/embroidery-tutorials/image-11.png)

ನೀನು ಈಗಾಗಲೇ ಒಂದು ಲೂಪ್ ಏನು ಮತ್ತು ಹೇಗೆ ಕೆಲಸ ತಿಳಿದಿರಬೇಕು.

**[ವಲಯ](../embroidery-tutorials-beginner/circle.md)** - ಟ್ಯುಟೋರಿಯಲ್ ಈ ಟ್ಯುಟೋರಿಯಲ್ಗೆ ಸಹಾಯಕವಾಗಬಹುದು.

ನೀನು ಇನ್ನೂ ಯಾವುದನ್ನೂ ಕಸೂತಿ ಮಾಡದಿದ್ದರೆ [ಆರಂಭಿಕ](../embroidery-tutorials-beginner/index.md) ಸರಣಿಯಲ್ಲಿ ಕಸೂತಿ ಬೋಧನೆಗಳನ್ನು ನೋಡಿ.

ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗಾಗಿ ಅಥವಾ ವಿನ್ಯಾಸ ಸಲಹೆಗಳಿಗಾಗಿ ಇತರ ಟ್ಯುಟೋರಿಯಲ್ಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

*ಇಲ್ಲಿ ನೀನು ಟ್ಯುಟೋರಿಯಲ್ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದು PDF-ಫಾರ್ಮ್ಯಾಟ್*:

[ಹೂವು](../../../media/embroidery-tutorials/Flower.pdf)

### 1. ಹೊಸ ಕಸೂತಿ ವಸ್ತುವನ್ನು ರಚಿಸಿ (ನೋಡಿ [ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ](../embroidery-tutorials-beginner/create-embroidery-objects.md)) ಮತ್ತು ಈ ಕೆಳಗಿನ ಸ್ಕ್ರಿಪ್ಟ್ಗಳನ್ನು ಸೇರಿಸಿಃ:

### 2. ಮೂಲ ರಚನೆ

![ಹೂವು](../../../media/embroidery-tutorials/Flower.png)

### 3. ವಲಯಗಳು

ಈ ಭಾಗವನ್ನು ಪ್ರತಿ ಬಾರಿ ವೃತ್ತ ಸಂದೇಶ ಕಳುಹಿಸಲಾಗುತ್ತದೆ ಕರೆಯಲಾಗುತ್ತದೆ. ಅದನ್ನು ನಿನ್ನ ಪಠ್ಯಕ್ಕೆ ಸೇರಿಸಿಕೊಳ್ಳಿ.

![ಹೂವು (1)](../../../media/embroidery-tutorials/Flower-1.png)

### 4. ನಿನ್ನ ವಿನ್ಯಾಸವನ್ನು ಪ್ರಾರಂಭಿಸಲು ಆಟದ ಟ್ಯಾಪ್ ಮಾಡಿ!
