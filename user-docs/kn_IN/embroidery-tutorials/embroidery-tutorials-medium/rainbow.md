ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ನೀನು ಮಳೆಬಿಲ್ಲು (112 x 57.2mm) ಅನ್ನು ಹೇಗೆ ಕಸೂತಿ ಮಾಡುವುದು ಎಂಬುದನ್ನು ಕಲಿಯುವಿರಿ.

![ರೆಜೆನ್ಬೊಗೆನ್](../../../media/embroidery-tutorials/Regenbogen.webp)

ನೀನು ಈಗಾಗಲೇ ಒಂದು ಲೂಪ್ ಏನು ಮತ್ತು ಹೇಗೆ ಕೆಲಸ ತಿಳಿದಿರಬೇಕು.

**[ಅರ್ಧ ವೃತ್ತ](../embroidery-tutorials-beginner/semicircle.md)** - ಟ್ಯುಟೋರಿಯಲ್ ಈ ಟ್ಯುಟೋರಿಯಲ್ಗೆ ಸಹಾಯಕವಾಗಬಹುದು.

ನೀನು ಇನ್ನೂ ಯಾವುದನ್ನೂ ಕಸೂತಿ ಮಾಡದಿದ್ದರೆ [ಆರಂಭಿಕ](../embroidery-tutorials-beginner/index.md) ಸರಣಿಯಲ್ಲಿ ಕಸೂತಿ ಬೋಧನೆಗಳನ್ನು ನೋಡಿ.

ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗಾಗಿ ಅಥವಾ ವಿನ್ಯಾಸ ಸಲಹೆಗಳಿಗಾಗಿ ಇತರ ಟ್ಯುಟೋರಿಯಲ್ಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

*ಇಲ್ಲಿ ನೀನು ಟ್ಯುಟೋರಿಯಲ್ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದು PDF-ಫಾರ್ಮ್ಯಾಟ್*:

[ಮಳೆಬಿಲ್ಲು](../../../media/embroidery-tutorials/Rainbow.pdf)

### 1. ಹೊಸ ಕಸೂತಿ ವಸ್ತುವನ್ನು ರಚಿಸಿ (ನೋಡಿ [ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![ಮಳೆಬಿಲ್ಲು](../../../media/embroidery-tutorials/Rainbow.png)

### 2. ಈ ಕೆಳಗಿನ ಸ್ಕ್ರಿಪ್ಟ್ ಅನ್ನು ಸೇರಿಸಿಃ:

![ಮಳೆಬಿಲ್ಲು (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. ವಸ್ತು ನಕಲಿಸಿ

ಮುಂದಿನ ದೊಡ್ಡ ಆರ್ಕಿಗಾಗಿ, ನೀನು ರಚಿಸಿದ ವಸ್ತುವನ್ನು ಸರಳವಾಗಿ ನಕಲಿಸಬಹುದು.

ವಸ್ತುಗಳ ಅವಲೋಕನದ ಮೇಲಿನ ಬಲ ಮೂಲೆಯಲ್ಲಿರುವ ಮೂರು ಬಿಂದುಗಳ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡು.

ನಂತರ “ನಕಲಿಸಿ” ಗೆ ಹೋಗಿ ಮತ್ತು ಆಬ್ಜೆಕ್ಟ್ ಅನ್ನು ಆಯ್ಕೆ ಮಾಡು.

![ರೆಜೆನ್ಬೊಗೆನ್ (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

ನೀನು ಪ್ರತಿ ಬಿಲ್ಲುಗೂ ಪ್ರತ್ಯೇಕ ವಸ್ತುಗಳನ್ನು ಬಳಸಿದರೆ, ನಂತರ ಅವುಗಳನ್ನು ವಿವಿಧ ಬಣ್ಣಗಳಲ್ಲಿ ಕಸೂತಿ ಮಾಡಬಹುದು.

### 4. ವಸ್ತುಗಳನ್ನು ಹೊಂದಿಸಿ

ಆಕಾಶದ ಆವರಣಗಳು ಈಗ ವಿಭಿನ್ನ ಗಾತ್ರದಲ್ಲಿರುವುದನ್ನು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಲು, ನಾವು ಕೆಲವು ಮೌಲ್ಯಗಳನ್ನು ಬದಲಾಯಿಸಬೇಕಾಗಿದೆ.

ಇದನ್ನು ಮಾಡಲು, ನಕಲಿಸಿದ ವಸ್ತುವಿನ ಸ್ಕ್ರಿಪ್ಟ್ಗೆ ಹೋಗಿ ಮತ್ತು ಈ ಕೆಳಗಿನ ಮೌಲ್ಯಗಳನ್ನು ಸರಿಹೊಂದಿಸಿಃ:

![ಮಳೆಬಿಲ್ಲು (2)](../../../media/embroidery-tutorials/Rainbow-2.png)

### 5. ಹೆಚ್ಚಿನ ಆರ್ಚುಗಳು ಪಡೆಯಲು ಹಂತ 3 ಮತ್ತು 4 ಅನ್ನು ಪುನರಾವರ್ತಿಸಿ!

### 6. ನಿನ್ನ ವಿನ್ಯಾಸವನ್ನು ಪ್ರಾರಂಭಿಸಲು ಆಟದ ಟ್ಯಾಪ್ ಮಾಡಿ!
