ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ನೀನು ತ್ರಿಕೋನ ಸ್ಪಿರಾಲ್ (50.2 x 58mm) ಅನ್ನು ಹೇಗೆ ಕಸೂತಿ ಮಾಡುವುದು ಎಂದು ಕಲಿಯುವಿರಿ.

![ತ್ರಿಕೋನ-ಸ್ಪಿರಲ್](../../../media/embroidery-tutorials/Triangle-Spiral.png)

ನೀನು ಈಗಾಗಲೇ ಒಂದು ಲೂಪ್ ಏನು ಮತ್ತು ಹೇಗೆ ಕೆಲಸ ತಿಳಿದಿರಬೇಕು.

ನೀನು ಇನ್ನೂ ಯಾವುದನ್ನೂ ಕಸೂತಿ ಮಾಡದಿದ್ದರೆ [ಆರಂಭಿಕ](../embroidery-tutorials-beginner/index.md) ಸರಣಿಯಲ್ಲಿ ಕಸೂತಿ ಬೋಧನೆಗಳನ್ನು ನೋಡಿ.

ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗಾಗಿ ಅಥವಾ ವಿನ್ಯಾಸ ಸಲಹೆಗಳಿಗಾಗಿ ಇತರ ಟ್ಯುಟೋರಿಯಲ್ಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

*ಇಲ್ಲಿ ನೀನು ಟ್ಯುಟೋರಿಯಲ್ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದು PDF-ಫಾರ್ಮ್ಯಾಟ್*:

[ತ್ರಿಕೋನ-ಸ್ಪಿರಲ್](../../../media/embroidery-tutorials/Triangle-Spiral-1.pdf)

### 1. ಹೊಸ ಕಸೂತಿ ವಸ್ತುವನ್ನು ರಚಿಸಿ (ನೋಡಿ [ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ](../embroidery-tutorials-beginner/create-embroidery-objects.md)) ಮತ್ತು ಈ ಕೆಳಗಿನ ಸ್ಕ್ರಿಪ್ಟ್ ಅನ್ನು ಸೇರಿಸಿಃ:

![ತ್ರಿಕೋನ-ಸ್ಪಿರಲ್ (2)](../../../media/embroidery-tutorials/Triangle-Spiral-2.png)

### 2. ನಿನ್ನ ವಿನ್ಯಾಸವನ್ನು ಪ್ರಾರಂಭಿಸಲು ಆಟದ ಟ್ಯಾಪ್ ಮಾಡಿ!

ಹೊಸ ವೇರಿಯೇಬಲ್ ರಚಿಸಲು “ಹೊಸದು…” ಅನ್ನು ಟ್ಯಾಪ್ ಮಾಡು.

![ಚಿತ್ರ (15)](../../../media/embroidery-tutorials/image-15.png)

ನೀನು ಡೇಟಾದಲ್ಲಿ ವೇರಿಯೇಬಲ್ “degree” ಕಾಣಬಹುದು.

![ಸ್ಪಿರಲ್ (1)](../../../media/embroidery-tutorials/Spiral-1.png)
