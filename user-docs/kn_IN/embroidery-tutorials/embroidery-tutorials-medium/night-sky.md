ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ನೀನು ರಾತ್ರಿ ಆಕಾಶವನ್ನು (48.5 x 96.1mm) ಹೇಗೆ ಕಸೂತಿ ಮಾಡುವುದು ಎಂದು ಕಲಿಯುವಿರಿ.

![ನಾಚ್ಥಿಮ್ಮೆಲ್](../../../media/embroidery-tutorials/Nachthimmel.png)

ನೀನು ಈಗಾಗಲೇ ಒಂದು ಲೂಪ್ ಏನು ಮತ್ತು ಹೇಗೆ ಕೆಲಸ ತಿಳಿದಿರಬೇಕು.

**[ನಕ್ಷತ್ರ](../embroidery-tutorials-beginner/star.md)** - ಟ್ಯುಟೋರಿಯಲ್ ಈ ಟ್ಯುಟೋರಿಯಲ್ಗೆ ಸಹಾಯಕವಾಗಬಹುದು.

ಪ್ರಸಾರ ಕಾರ್ಯವನ್ನು ನೀನು ಈಗಾಗಲೇ ತಿಳಿದಿದ್ದರೆ ಅದು ಸಹ ಸಹಾಯಕವಾಗಿದೆ.

ನೀನು ಇನ್ನೂ ಯಾವುದನ್ನೂ ಕಸೂತಿ ಮಾಡದಿದ್ದರೆ [ಆರಂಭಿಕ](../embroidery-tutorials-beginner/index.md) ಸರಣಿಯಲ್ಲಿ ಕಸೂತಿ ಬೋಧನೆಗಳನ್ನು ನೋಡಿ.

ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗಾಗಿ ಅಥವಾ ವಿನ್ಯಾಸ ಸಲಹೆಗಳಿಗಾಗಿ ಇತರ ಟ್ಯುಟೋರಿಯಲ್ಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

*ಇಲ್ಲಿ ನೀನು ಟ್ಯುಟೋರಿಯಲ್ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದು PDF-ಫಾರ್ಮ್ಯಾಟ್*:

[ರಾತ್ರಿ ಆಕಾಶ](../../../media/embroidery-tutorials/Night-Sky.pdf)

### 1. ಹೊಸ ಕಸೂತಿ ವಸ್ತುವನ್ನು ರಚಿಸಿ (ನೋಡಿ [ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ](../embroidery-tutorials-beginner/create-embroidery-objects.md)) ಮತ್ತು ಈ ಕೆಳಗಿನ ಸ್ಕ್ರಿಪ್ಟ್ಗಳನ್ನು ಸೇರಿಸಿಃ:

### 2. ಚಂದ್ರ

![ರಾತ್ರಿ ಆಕಾಶ](../../../media/embroidery-tutorials/Night-Sky.png)

### 3. ಒಂದು ನಕ್ಷತ್ರ

ಈ ಭಾಗವನ್ನು ಪ್ರತಿ ಬಾರಿ ನಕ್ಷತ್ರ ಸಂದೇಶ ಕಳುಹಿಸಲಾಗುತ್ತದೆ. ಅದನ್ನು ನಿನ್ನ ಪಠ್ಯಕ್ಕೆ ಸೇರಿಸಿಕೊಳ್ಳಿ.

![ರಾತ್ರಿ ಆಕಾಶ (1)](../../../media/embroidery-tutorials/Night-Sky-1.png)

### 4. ಎಲ್ಲಾ ನಕ್ಷತ್ರಗಳು

![ರಾತ್ರಿ ಆಕಾಶ (2)](../../../media/embroidery-tutorials/Night-Sky-2.png)

### 5. ನಿನ್ನ ವಿನ್ಯಾಸವನ್ನು ಪ್ರಾರಂಭಿಸಲು ಆಟದ ಟ್ಯಾಪ್ ಮಾಡಿ!
