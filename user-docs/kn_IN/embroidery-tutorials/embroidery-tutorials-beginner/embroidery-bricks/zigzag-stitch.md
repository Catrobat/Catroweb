ನಿರಂತರವಾಗಿ ಬದಲಾಗುವ ಉದ್ದ ಮತ್ತು ಅಗಲದೊಂದಿಗೆ ಹೊಲಿಯಿರಿ.

'ಜಿಗ್ಜಾಕ್' ಮಾದರಿಯಲ್ಲಿ ಹೊಲಿಯಿರಿ.

![ಈ ಉದ್ದದ ಅಂಕುಡೊಂಕು ಹೊಲಿಗೆ ಪ್ರಾರಂಭಿಸಿ: 2 ಮತ್ತು ಅಗಲ: 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಅನ್ನು ತಿಳಿದುಕೊಳ್ಳಲು ಉದ್ದ ಮತ್ತು ಅಗಲಕ್ಕೆ ವಿಭಿನ್ನ ಮೌಲ್ಯಗಳನ್ನು ಪ್ರಯತ್ನಿಸಿ.

![ಈ ಉದ್ದದ ಅಂಕುಡೊಂಕು ಹೊಲಿಗೆ ಪ್ರಾರಂಭಿಸಿ:](../../../../media/embroidery-tutorials/ZigzagStitch.png)

ನೀನು ಝಿಗ್ಜಾಕ್ ಹೊಲಿಗೆಗಳೊಂದಿಗೆ ದಪ್ಪ ಹೊಲಿಗೆಗಳನ್ನು ಹೊಲಿಯಬಹುದು.
