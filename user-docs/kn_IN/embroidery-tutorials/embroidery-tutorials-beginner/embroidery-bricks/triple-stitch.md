ಟ್ರಿಪಲ್ ಸ್ಟಿಚ್ ಪ್ರತಿ ಸ್ಟಿಕ್ ಅನ್ನು ಮೂರು ಬಾರಿ ಹೊಲಿಯುತ್ತದೆ.

ಮೂರು ಬಾರಿ ಹೊಲಿಗೆ ಹಾಕಿದ ನಂತರ ಮತ್ತೆ ಜಿಗಿಯುತ್ತದೆ, ಹೊಲಿಗೆ ಹಾಕುತ್ತದೆ, ನಂತರ ಮತ್ತೆ ಮುಂದಕ್ಕೆ ಜಿಗಿಯುತ್ತದೆ ಮತ್ತು ಮತ್ತೆ ಹೊಲಿಗೆ ಹಾಕುತ್ತದೆ.

![ಈ ಉದ್ದದ ಟ್ರಿಪಲ್ ಹೊಲಿಗೆ ಪ್ರಾರಂಭಿಸಿ: 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

ಇದು [ಓಡುವ ಹೊಲಿಗೆ](running-stitch.md) ನಂತೆಯೇ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.

![ಈ ಉದ್ದದ ಟ್ರಿಪಲ್ ಹೊಲಿಗೆ ಪ್ರಾರಂಭಿಸಿ:](../../../../media/embroidery-tutorials/TripleStitch.png)

ಇದರಿಂದ ಹೊಲಿಗೆ ಹೆಚ್ಚು ಕಾಲ ಉಳಿಯುತ್ತದೆ.
