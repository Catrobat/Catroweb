ಯಂತ್ರವು ನಿರಂತರವಾಗಿ ಬದಲಾಗುವ ಉದ್ದದೊಂದಿಗೆ ಹೊಲಿಗೆ ಮಾಡಲು ಅನುಮತಿಸುತ್ತದೆ.

ಸಾಮಾನ್ಯವಾಗಿ ನೀನು ಚಲಿಸುವ ಹೊಲಿಗೆ ಮತ್ತು ಚಲಿಸುವ ಕೋಡ್ ಬ್ಲಾಕ್ ಅನ್ನು ಸಂಯೋಜಿಸುತ್ತೀರಿ.

![ಈ ಉದ್ದದ ರನ್ನಿಂಗ್ ಹೊಲಿಗೆ ಪ್ರಾರಂಭಿಸಿ: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

ಯಂತ್ರವು ಚಾಲನೆಯಲ್ಲಿರುವ ಹೊಲಿಗೆ ಪ್ರಾರಂಭಿಸುತ್ತದೆ, ಅದು ಪ್ರತಿ **10 ಹಂತಗಳು** ಹೊಲಿಗೆ ಮಾಡುತ್ತದೆ.

ನಂತರ ಯಂತ್ರವು ಚಲಿಸುತ್ತದೆ **200 ಹೆಜ್ಜೆಗಳು**.

ಇದರ ಪರಿಣಾಮವಾಗಿ **20 ಹೊಲಿಗೆಗಳು**.

![ಈ ಉದ್ದದ ರನ್ನಿಂಗ್ ಹೊಲಿಗೆ ಪ್ರಾರಂಭಿಸಿ:](../../../../media/embroidery-tutorials/RunningStitch.png)

ಚಾಲನೆಯಲ್ಲಿರುವ ಹೊಲಿಗೆ ಹೊಲಿಗೆ ಹೊಲಿಯುವುದನ್ನು ಸುಲಭಗೊಳಿಸುತ್ತದೆ ಏಕೆಂದರೆ ನಿನಗೆ ಇನ್ನು ಮುಂದೆ ಲೂಪ್ ಅಗತ್ಯವಿಲ್ಲ.
