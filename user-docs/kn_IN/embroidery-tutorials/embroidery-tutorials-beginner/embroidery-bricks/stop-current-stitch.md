ಈಗಿನ ಹೊಲಿಗೆ ನಿಲ್ಲಿಸಲಿ.

ನೀನು ಓಟ, ಝಿಗ್ಜಾಕ್ ಅಥವಾ ಟ್ರಿಪಲ್ ಸ್ಟಿಕ್ ಪ್ರಾರಂಭಿಸಿದ ನಂತರ ಸೂಜಿಯ ಸ್ಥಾನವನ್ನು ಬದಲಾಯಿಸಲು ಬಯಸಿದರೆ ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ನಿನಗೆ ಬೇಕಾಗುತ್ತದೆ.

![ಪ್ರಸ್ತುತ ಹೊಲಿಗೆಯನ್ನು ನಿಲ್ಲಿಸಿ](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

ಇಲ್ಲದಿದ್ದರೆ ಅನಗತ್ಯ ಮಧ್ಯಂತರ ಹೊಲಿಗೆ ಸಂಭವಿಸುತ್ತದೆ.
