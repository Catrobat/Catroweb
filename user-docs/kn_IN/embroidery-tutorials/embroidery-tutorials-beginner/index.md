ನೀನು ಸೃಜನಶೀಲರಾಗಿರಲು ಮತ್ತು ಅದೇ ಸಮಯದಲ್ಲಿ ಆಟದ ರೀತಿಯಲ್ಲಿ ಕೋಡಿಂಗ್ ಕಲಿಯಲು ಬಯಸುವಿರಾ? ನೀನು ಕೂಡ ಬಳಸಬಹುದಾದ, ಧರಿಸಬಹುದಾದ ಮತ್ತು ನಂತರ ಮೆಚ್ಚಿಸಬಹುದಾದ ವಸ್ತುಗಳನ್ನು ರಚಿಸಲು ಇಷ್ಟಪಡುತ್ತೀರಾ?

Embroidery Designer ನೊಂದಿಗೆ, ಯಾವುದೇ ಪೂರ್ವ ಅನುಭವವಿಲ್ಲದೆ, ನಿನ್ನ ವಿನ್ಯಾಸವನ್ನು ಟಿ ಶರ್ಟ್, ಚೀಲ, ಪ್ಯಾಂಟ್, ಸ್ಮಾರ್ಟ್ಫೋನ್ ಕೇಸ್ ಅಥವಾ ನಿನ್ನ ಬೂಟುಗಳ ಮೇಲೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಕಸೂತಿ ಮಾಡುವ ಕಸೂತಿ ಯಂತ್ರವನ್ನು ನೀನು ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದು. ಬಟ್ಟೆಯಿಂದ ತಯಾರಿಸಲ್ಪಟ್ಟಿರುವ ಎಲ್ಲದರ ಮೇಲೆ ಹೊಲಿಗೆ ಹಾಕುವುದು ಸಾಧ್ಯ. ನಿನ್ನ ಕಲ್ಪನೆ ಮತ್ತು ಸೃಜನಶೀಲತೆಗೆ ಮುಕ್ತವಾಗಿರಿ! ನೀನು ನಮ್ಮ Catrobat ಸಮುದಾಯದಿಂದ ಇತರರಿಂದ ವಿನ್ಯಾಸಗಳನ್ನು ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದು ಮತ್ತು ಸಂಪಾದಿಸಬಹುದು. ಸಹಜವಾಗಿ, ನಿನ್ನ ಯೋಜನೆಗಳನ್ನು ನಿನ್ನ ಸ್ನೇಹಿತರಿಗೆ ಮತ್ತು ಇಡೀ ಜಗತ್ತಿಗೆ ಹಂಚಿಕೊಳ್ಳಬಹುದು!
