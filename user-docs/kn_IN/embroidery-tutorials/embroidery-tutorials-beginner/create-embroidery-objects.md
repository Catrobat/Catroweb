ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ನೀನು ವಸ್ತುಗಳನ್ನು ಹೇಗೆ ರಚಿಸುವುದು ಎಂಬುದನ್ನು ಕಲಿಯುವಿರಿ, ನಂತರ ನಿನ್ನ ಮಾದರಿಗಳನ್ನು ಕಸೂತಿ ಮಾಡಬಹುದು.

ಈ ಟ್ಯುಟೋರಿಯಲ್ಗಾಗಿ, ನೀನು ಈಗಾಗಲೇ ಒಂದು ಯೋಜನೆಯನ್ನು ಹೇಗೆ ರಚಿಸಬೇಕು ಎಂದು ತಿಳಿಯಬೇಕು. ನಿನಗೆ ಸಹಾಯ ಬೇಕಾದರೆ [ಆರಂಭಿಕ ಸರಣಿ](../../game-tutorials/starter-tutorials/index.md) ನ ಟ್ಯುಟೋರಿಯಲ್ಗಳನ್ನು ನೋಡಿ.

ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗಾಗಿ ಅಥವಾ ವಿನ್ಯಾಸ ಸಲಹೆಗಳಿಗಾಗಿ, ಇತರ ಟ್ಯುಟೋರಿಯಲ್ಗಳನ್ನು ಪರಿಶೀಲಿಸಲು ಮುಕ್ತವಾಗಿರಿ.

*ಇಲ್ಲಿ ನೀನು ಟ್ಯುಟೋರಿಯಲ್ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದು PDF-ಫಾರ್ಮ್ಯಾಟ್*:

[ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. ಹೊಸ ವಸ್ತುವನ್ನು ಸೇರಿಸಲು ನಿನ್ನ ಯೋಜನೆಯ ಕೆಳಗಿನ ಬಲಭಾಗದಲ್ಲಿರುವ ಪ್ಲಸ್ ಬಟನ್ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡು.

![ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. ಚಿತ್ರವನ್ನು ಆಯ್ಕೆ ಮಾಡಲು, ಮಾಧ್ಯಮ ಗ್ರಂಥಾಲಯಕ್ಕೆ ಹೋಗಿ.

![ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. ಕಸೂತಿ ವಸ್ತುವು ಕಸೂತಿ ಯಂತ್ರದ ಸೂಜಿಯ ಒಂದು ಮಟ್ಟವನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತದೆ. ಹಲವಾರು ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ಒಂದರ ನಂತರ ಮತ್ತೊಂದು ಕಸೂತಿ ಮಾಡಲಾಗುತ್ತದೆ. ಇದು ಹಲವಾರು ಬಣ್ಣಗಳನ್ನು ಬಳಸುವ ಸಾಧ್ಯತೆಯನ್ನು ನೀಡುತ್ತದೆ.

ನೀನು ಬಯಸುವ ಬಣ್ಣವನ್ನು ಅವಲಂಬಿಸಿ ನಿನ್ನ ವಸ್ತುವನ್ನು ಆಯ್ಕೆ ಮಾಡಬಹುದು.

ಕೆಳಗೆ ಸ್ಕ್ರಾಲ್ ಮಾಡಿ ಮತ್ತು ಸೂಕ್ತವಾದ ಬಾಣವನ್ನು ಹುಡುಕಿ.

![ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. ನಿನ್ನ ಹೊಸ ವಸ್ತುವಿಗೆ ಸೂಕ್ತವಾದ ಹೆಸರನ್ನು ನೀಡಿ ಮತ್ತು ಪತ್ರಿಕಾ ಸರಿ ಅನ್ನು ಒತ್ತು.

![ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. ನೀನು ಈಗ ಹೊಸ ವಸ್ತುವನ್ನು ರಚಿಸಿದ್ದೀರಿ. ನೀನು ಈಗ ಸ್ಕ್ರಿಪ್ಟ್ ಅನ್ನು ಸೇರಿಸಬಹುದು ಮತ್ತು ವಸ್ತುವನ್ನು ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದು.

![ಕಸೂತಿ ವಸ್ತುಗಳನ್ನು ರಚಿಸಿ (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

ಈಗ ನೀನು ಒಂದು ವಸ್ತುವನ್ನು ರಚಿಸಲು ಹೇಗೆ ಗೊತ್ತು. ನೀನು ಬಳಸಲು ಬಯಸುವ ಪ್ರತಿ ಬಣ್ಣಕ್ಕೆ ಹೊಸ ವಸ್ತುವನ್ನು ಸೇರಿಸಿ.

ನೀನು ಪ್ರತಿ ಬಣ್ಣದಲ್ಲಿ ಒಂದು ಸ್ಕ್ರಿಪ್ಟ್ ಅನ್ನು ಸೇರಿಸಬಹುದು ಮತ್ತು ನಿನ್ನ ಸ್ವಂತ ವಿನ್ಯಾಸಗಳನ್ನು ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದು ಮತ್ತು ನಂತರ ಅದನ್ನು ಕಸೂತಿ ಮಾಡಬಹುದು.

ನಿನಗೆ ಸ್ಫೂರ್ತಿ ಅಥವಾ ಸಹಾಯ ಬೇಕೇ? ನಮ್ಮ ಇತರ ಟ್ಯುಟೋರಿಯಲ್ಗಳನ್ನು ನೋಡಿ!
