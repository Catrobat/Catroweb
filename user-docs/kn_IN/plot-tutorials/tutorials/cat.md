[ಬೆಕ್ಕು (PDF, ಜರ್ಮನ್)](../../../media/plot-tutorials/Katze.pdf)

ಕಥಾವಸ್ತುವಿನ ಆರಂಭದಲ್ಲಿ, ಪ್ರತಿ ಚಲನೆಯನ್ನು ಪೆನ್ನಿನಿಂದ ಚಿತ್ರಿಸಲಾಗುತ್ತದೆ. ಈ ಸಾಲುಗಳನ್ನು ಕಥಾವಸ್ತುವಿನ ನಂತರ ಕತ್ತರಿಸುತ್ತದೆ.

ನಮ್ಮ ವಸ್ತು 150 ಡಿಗ್ರಿ ದಿಕ್ಕಿನಲ್ಲಿ ಸೂಚಿಸುತ್ತದೆ.

ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ಬೆಕ್ಕಿನ ತಲೆಯ ಬಲ ಭಾಗವನ್ನು ಮೊದಲು ತಯಾರಿಸಲಾಗುತ್ತದೆ. ನೀನು ಹತ್ತಿರದಿಂದ ನೋಡಿದರೆ, ವಕ್ರತೆಯು ಮೊದಲಿಗೆ ಬಲವಾಗಿರುತ್ತದೆ, ಆದ್ದರಿಂದ ಪ್ರತಿ ಸಣ್ಣ ರೇಖೆಯ ನಂತರ ವಸ್ತು ಹೆಚ್ಚು ತಿರುಗಬೇಕು. ನಂತರ ತಲೆ ಕೆಳಭಾಗದಲ್ಲಿ ತಿರುವುಗಳು ಚಿಕ್ಕದಾಗಿರುತ್ತವೆ. ತಲೆ ಎಡಭಾಗವು ಮತ್ತೆ ಬಲವಾಗಿ ಬಾಗಿದಿದೆ. ಆದ್ದರಿಂದ ತಲೆಯ ಈ ಭಾಗದಲ್ಲಿ ಒಟ್ಟು ಮೂರು ಲೂಪ್ ಗಳು ಇವೆ.

ನಂತರ ಎಡ ಕಿವಿ ಬರುತ್ತದೆ. ಇದು ಕೇವಲ ನೇರ ರೇಖೆಗಳನ್ನಷ್ಟೇ ಒಳಗೊಂಡಿದೆ, ಆದ್ದರಿಂದ ನಾವು ಕೋಡ್ ಬ್ಲಾಕ್ “ಚಲಿಸಿ: \_\_ ಹೆಜ್ಜೆಗಳು” ಅನ್ನು ಬಳಸಬಹುದು.

ಕಿವಿಗಳ ನಡುವಿನ ಭಾಗವು ಮತ್ತೆ ಒಂದು ವಾಯುಮಂಡಲವಾಗಿದೆ ಮತ್ತು ಮತ್ತೊಂದು ಲೂಪ್ನೊಂದಿಗೆ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಲ್ಪಟ್ಟಿದೆ.

ನಂತರ ಬಲ ಕಿವಿ ತಯಾರಿಸಲಾಗುತ್ತದೆ.

ಕಥಾವಸ್ತುವಿನ ಈಗ ಮುಗಿದಿದೆ. ಅದನ್ನು ಕೋಡ್ ಬ್ಲಾಕ್ “ಪ್ಲಾಟ್ ಮಾಡುವುದನ್ನು ನಿಲ್ಲಿಸಿ” ನೊಂದಿಗೆ ಕೊನೆಗೊಳಿಸಿ ಮತ್ತು ಅದನ್ನು ನಿನ್ನ ಫೋನ್ನಲ್ಲಿ “ಪ್ಲಾಟ್ ಅನ್ನು SVG ಆಗಿ ಉಳಿಸಿ: \_\_\_” ನೊಂದಿಗೆ ಉಳಿಸಿ.

ನೀನು ಈಗ SVG ಫೈಲ್ ಅನ್ನು (ಕಟ್) ಪ್ಲಾನೆಟರ್ಗೆ ಕಳುಹಿಸಬಹುದು.
