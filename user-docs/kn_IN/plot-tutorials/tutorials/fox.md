ಕಥಾವಸ್ತುವಿನ ಆರಂಭದಲ್ಲಿ, ಪ್ರತಿ ಚಲನೆಯನ್ನು ಪೆನ್ನಿನಿಂದ ಚಿತ್ರಿಸಲಾಗುತ್ತದೆ. ಈ ಸಾಲುಗಳನ್ನು ಕಥಾವಸ್ತುವಿನ ನಂತರ ಕತ್ತರಿಸುತ್ತದೆ.

ಈ ಚೇಳು ಕೇವಲ ನೇರ ರೇಖೆಗಳು (“ಚಲಿಸಿ: \_\_\_ ಹೆಜ್ಜೆಗಳು”) ಮತ್ತು ತಿರುವುಗಳಿಂದ ಮಾಡಲ್ಪಟ್ಟಿದೆ.

**ಸುಳಿವು**: ನೀನು ಅದನ್ನು ನಿರ್ಮಿಸುವಾಗ ನಿನ್ನ ಪ್ರೋಗ್ರಾಂ ಅನ್ನು ಪರೀಕ್ಷಿಸಿ.
