ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ನಿನ್ನ ಮೊದಲ ಯೋಜನೆಯನ್ನು ರಚಿಸಲು ನೀನು ತಿಳಿದುಕೊಳ್ಳಬೇಕಾದ ಎಲ್ಲವನ್ನೂ ಕಲಿಯುವಿರಿ Pocket Code. ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಡೌನ್ಲೋಡ್ ಮಾಡುವುದು, ಅದನ್ನು ತೆರೆಯುವುದು ಮತ್ತು ಹೊಸ ಯೋಜನೆಯನ್ನು ಹೇಗೆ ರಚಿಸುವುದು ಎಂಬುದರ ಕುರಿತು ನಾವು ನಿನಗೆ ಹಂತ ಹಂತವಾಗಿ ಮಾರ್ಗದರ್ಶನ ನೀಡುತ್ತೇವೆ.

![ಹೊಸ ಕಾರ್ಯಕ್ರಮ](../../../media/game-tutorials/New-Program.png)\
ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಡೌನ್ಲೋಡ್ ಮಾಡುವುದು, ಅದನ್ನು ತೆರೆಯುವುದು ಮತ್ತು ಹೊಸ ಯೋಜನೆಯನ್ನು ಹೇಗೆ ರಚಿಸುವುದು ಎಂಬುದರ ಕುರಿತು ನಾವು ನಿನಗೆ ಹಂತ ಹಂತವಾಗಿ ಮಾರ್ಗದರ್ಶನ ನೀಡುತ್ತೇವೆ.\
[ಚಿತ್ರವನ್ನು ತೆರೆ](../../../media/game-tutorials/New-Program.png)

ಇದು ಮೊದಲ ಟ್ಯುಟೋರಿಯಲ್, ಮತ್ತು ನಿನಗೆ ಯಾವುದೇ ಪೂರ್ವ ಜ್ಞಾನದ ಅಗತ್ಯವಿಲ್ಲ.

ಹಾಗಾದರೆ, ನೀನು ಏನು ಕಾಯುತ್ತಿದ್ದೀರಿ? ನಿನ್ನ ಫೋನ್ ತೆಗೆದುಕೊಂಡು ಈಗ ಪ್ರಾರಂಭಿಸಿ!

*ಇಲ್ಲಿ ನೀನು ಟ್ಯುಟೋರಿಯಲ್ ಅನ್ನು PDF ಸ್ವರೂಪದಲ್ಲಿ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದುಃ:*

[PDF ತೆರೆಯು](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code ಯನ್ನು ಸ್ಥಾಪಿಸುವುದು

ಮೊದಲಿಗೆ, ನಿನ್ನ ಸಾಧನದಲ್ಲಿ Pocket Code ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ನೀನು ಸ್ಥಾಪಿಸಬೇಕಾಗಿದೆ. ಈ ಹಂತಕ್ಕೆ Google ಖಾತೆ ಅಗತ್ಯವಿದೆ. ಈಗ ನಿನ್ನ ಸಾಧನವು ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಡೌನ್ಲೋಡ್ ಮಾಡಿ ಸ್ಥಾಪಿಸುತ್ತದೆ. ನಿನ್ನ ಇಂಟರ್ನೆಟ್ ಸಂಪರ್ಕದ ಪ್ರಕಾರ ಈ ಹಂತವು ಸ್ವಲ್ಪ ಸಮಯ ತೆಗೆದುಕೊಳ್ಳಬಹುದು.

![ಹೊಸ ಕಾರ್ಯಕ್ರಮ (2)](../../../media/game-tutorials/New-Program-2.png)\
ನೀನು Google Play Store ನಲ್ಲಿ “Pocket Code” ಹುಡುಕುವ ಮೂಲಕ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಕಾಣಬಹುದು ಮತ್ತು ಅದನ್ನು “ಸ್ಥಾಪನೆ” ಕ್ಲಿಕ್ ಮಾಡುವ ಮೂಲಕ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದು.\
[ಚಿತ್ರವನ್ನು ತೆರೆ](../../../media/game-tutorials/New-Program-2.png)

ನೀನು ಯಶಸ್ವಿಯಾಗಿ ಡೌನ್ಲೋಡ್ ಮಾಡಿ ಮತ್ತು ಸ್ಥಾಪಿಸಿದ ನಂತರ Pocket Code ನಿನ್ನ ಸಾಧನಕ್ಕೆ ಅನುಗುಣವಾಗಿ ಅಪ್ಲಿಕೇಶನ್ ಡ್ರಾಯರ್ನಲ್ಲಿ ಅಥವಾ ನಿನ್ನ ಹೋಮ್ ಸ್ಕ್ರೀನ್ನಲ್ಲಿ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಕಾಣಬಹುದು. ನೀನು ಸುಲಭವಾಗಿ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ತೆಗೆದುಕೊಂಡು ಅದನ್ನು ಎಲ್ಲಿ ಬೇಕಾದರೂ ಇರಿಸಿ.

### 2. ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಪ್ರಾರಂಭಿಸಿ

![ಹೊಸ ಕಾರ್ಯಕ್ರಮ (1)](../../../media/game-tutorials/New-Program-1.png)\
ನೀನು ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ತೆರೆದಾಗ, ನೀನು ವಿವಿಧ ವರ್ಗಗಳನ್ನು ನೋಡುತ್ತೀರಿಃ.\
[ಚಿತ್ರವನ್ನು ತೆರೆ](../../../media/game-tutorials/New-Program-1.png)

### 3. ಹೊಸ ಯೋಜನೆ ರಚಿಸಿ

ಮುಂದಿನ ಹಂತವೆಂದರೆ ಹೊಸ ಯೋಜನೆಯನ್ನು ರಚಿಸುವುದು. ಈಗ ನೀನು ಒಂದು ಯೋಜನೆಯ ಹೆಸರನ್ನು ನಮೂದಿಸಬೇಕು ಮತ್ತು ನಿನ್ನ ಯೋಜನೆ ಭೂದೃಶ್ಯವಾಗಬೇಕೆ ಅಥವಾ ಬೇಡವೇ ಎಂಬುದನ್ನು ಆಯ್ಕೆಮಾಡು. “ಸರಿ” ಅನ್ನು ಒತ್ತಿ ಯೋಜನೆಯನ್ನು ರಚಿಸಲಾಗುತ್ತದೆ.

![ಹೊಸ ಕಾರ್ಯಕ್ರಮ](../../../media/game-tutorials/New-Program.png)\
ಇದನ್ನು ಮಾಡಲು, ನೀನು ಕೆಳಗಿನ ಬಲ ಮೂಲೆಯಲ್ಲಿರುವ ಹಳದಿ ಪ್ಲಸ್ ಬಟನ್ ಅನ್ನು ಒತ್ತಬಹುದು.\
[ಚಿತ್ರವನ್ನು ತೆರೆ](../../../media/game-tutorials/New-Program.png)

### 4. ನೀನು ಅದನ್ನು ಮಾಡಿದ್ದೀರಿ, ನಿನ್ನ ಸ್ವಂತ ಹೊಸ ಯೋಜನೆಯನ್ನು ರಚಿಸಿದ್ದೀರಿ.

ಈಗ ನೀನು Pocket Code ಸ್ಥಾಪಿಸಿ ಮತ್ತು ಹೊಸ ಯೋಜನೆಯನ್ನು ಹೇಗೆ ರಚಿಸುವುದು ಎಂದು ತಿಳಿದಿದೆ. ಈಗ ನೀನು ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಆರಂಭಿಸಬಹುದು!

ಇದನ್ನು ಮಾಡಲು, ನೀನು ಯೋಜನೆಯಲ್ಲಿ ಹೊಸ ವಸ್ತುವನ್ನು ಹೇಗೆ ರಚಿಸಬೇಕು ಎಂಬುದನ್ನು ತಿಳಿದುಕೊಳ್ಳಬೇಕು. **[ಹೊಸ ವಸ್ತು](new-object.md)** -ನವಪುಸ್ತಕವನ್ನು ನೋಡಿ, ಅಲ್ಲಿ ಎಲ್ಲವನ್ನೂ ಹಂತ ಹಂತವಾಗಿ ವಿವರಿಸಲಾಗುತ್ತದೆ.
