ಈ ಟ್ಯುಟೋರಿಯಲ್ ನಲ್ಲಿ, ನಿನ್ನ ಯೋಜನೆಯಲ್ಲಿ ಹೊಸ ವಸ್ತುವನ್ನು ಹೇಗೆ ರಚಿಸುವುದು ಮತ್ತು ಇದಕ್ಕಾಗಿ ನೀನು ಹೊಂದಿರುವ ವಿಭಿನ್ನ ಸಾಧ್ಯತೆಗಳನ್ನು ನೀನು ಕಲಿಯುವಿರಿ.

![ಹೊಸ ವಸ್ತು](../../../media/game-tutorials/New-Object.png)

ಇದನ್ನು ಮಾಡಲು, ನೀನು ಈಗಾಗಲೇ Pocket Code ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಡೌನ್ಲೋಡ್ ಮಾಡಿರಬೇಕು ಮತ್ತು ಹೊಸ ಯೋಜನೆಯನ್ನು ಹೇಗೆ ರಚಿಸುವುದು ಎಂದು ತಿಳಿಯಬೇಕು. ಈ ವಿಷಯದಲ್ಲಿ ನಿನಗೆ ಸಹಾಯ ಬೇಕಾದರೆ, **[ಹೊಸ ಯೋಜನೆ](new-project.md)** -ನಂಬಿಕೆಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

*ಇಲ್ಲಿ ನೀನು ಟ್ಯುಟೋರಿಯಲ್ ಅನ್ನು PDF ಸ್ವರೂಪದಲ್ಲಿ ಡೌನ್ಲೋಡ್ ಮಾಡಬಹುದುಃ:*

[ಹೊಸ ವಸ್ತು](../../../media/game-tutorials/New-Object.pdf)

### 1. ಹೊಸ ವಸ್ತುವನ್ನು ರಚಿಸಿ

ಮೊದಲಿಗೆ, ನಿನ್ನ ಹೊಸ ಯೋಜನೆಯನ್ನು ನೀನು ತೆರೆಯಬೇಕು.

ನೀನು ಅದನ್ನು Pocket Code ಅಪ್ಲಿಕೇಶನ್ನ ಹೋಮ್ ಸ್ಕ್ರೀನ್ನಲ್ಲಿ ಕಾಣಬಹುದು. ನೀನು ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು ಯೋಜನೆಗಳನ್ನು ಹೊಂದಿದ್ದರೆ, ನೀನು “ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು” ಕ್ಲಿಕ್ ಮಾಡಬಹುದು. ನಂತರ ನಿನ್ನ ಹೊಸ ಯೋಜನೆಯನ್ನು ಆರಿಸು. ನೀನು ಹೊಸ ಯೋಜನೆಯನ್ನು ರಚಿಸದಿದ್ದರೆ ಅಥವಾ ಅದನ್ನು ಹೇಗೆ ಮಾಡಬೇಕೆಂಬುದರ ಕುರಿತು ಹೆಚ್ಚಿನ ಮಾಹಿತಿಯ ಅಗತ್ಯವಿದ್ದರೆ, **[ಹೊಸ ಯೋಜನೆ](new-project.md)** -ಟ್ಯುಟೋರಿಯಲ್ ಅನ್ನು ನೋಡಿ.

### 2. ಹೊಸ ವಸ್ತುವನ್ನು ರಚಿಸಿ

ಈಗ ನೀನು ಹೊಸ ವಸ್ತುವನ್ನು ರಚಿಸಲು ಸಿದ್ಧರಾಗಿದ್ದೀರಿ. ಅದನ್ನು ಮಾಡಲು, ಕೆಳಗಿನ ಬಲ ಮೂಲೆಯಲ್ಲಿರುವ ಹಳದಿ ಪ್ಲಸ್ ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡು. ನೀನು ಹೊಸ ವಿಂಡೋವನ್ನು ನೋಡುತ್ತೀರಿ, ಅದು ನಿನಗೆ ಏಳು ಆಯ್ಕೆಗಳನ್ನು ನೀಡುತ್ತದೆ.

![ಹೊಸ ವಸ್ತು (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. ಸೃಷ್ಟಿ ಮಾಡುವ ವಿಧಾನಗಳು

ನೀನು ಆಯ್ಕೆ ಮಾಡಬಹುದಾದ ಸಾಧ್ಯತೆಗಳು ಇವುಃ:

![ಹೊಸ ವಸ್ತು (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. ಚಿತ್ರವನ್ನು ಚಿತ್ರಿಸಿ

ಆರಂಭದಲ್ಲಿ ಸಾಧ್ಯವಾದಷ್ಟು ಸುಲಭವಾಗಿಸಲು, ನಾವು “ಚಿತ್ರಿಸಿ” ಕಾರ್ಯವನ್ನು ಬಳಸಲು ಮತ್ತು ಕೇವಲ ಒಂದು ಬಿಂದುವನ್ನು ಸೆಳೆಯಲು ಬಯಸುತ್ತೇವೆ. ನೀನು Pocket Paint ನೊಂದಿಗೆ ಬಿಂದುವನ್ನು ಸೆಳೆಯುವಾಗ ಅದನ್ನು ಬಿಟ್ಟುಬಿಡಬಹುದು (ಒಂದು ಹೆಜ್ಜೆ ಹಿಂದಕ್ಕೆ ಹೋಗಿ).

### 5. ಒಂದು ಹೆಸರು ಕೊಡು

ಈಗ ನಿನ್ನ ಚಿತ್ರಕ್ಕೆ ನೀನು ಒಂದು ಹೆಸರನ್ನು ನೀಡಬೇಕಾಗಿದೆ.

### 6. ಅದನ್ನು ಇರಿಸಿ

ನಂತರ ನೀನು ಅದನ್ನು ಎಡ/ಬಲಕ್ಕೆ ಅಥವಾ ನಿನ್ನ ಬೆರಳಿನಿಂದ ಮೇಲಕ್ಕೆ/ಕೆಳಗೆ ಚಲಿಸುವ ಮೂಲಕ ದೃಶ್ಯವಾಗಿ ಇಟ್ಟುಕೊಳ್ಳಬೇಕು. ನೀನು ಅದನ್ನು ಮೇಲಿನ ಬಲ ಮೂಲೆಯಲ್ಲಿರುವ ಬಟನ್ ಮೂಲಕ ಉಳಿಸಬೇಕು.

![ಹೊಸ ವಸ್ತು (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. ನೀನು ಅದನ್ನು ಮಾಡಿದ್ದೀರಿ, ನಿನ್ನದೇ ಹೊಸ ವಸ್ತುಗಳನ್ನು ಸೃಷ್ಟಿಸಿದ್ದೀರಿ.

ಈಗ ನೀನು ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದಾದ ಒಂದು ವಸ್ತುವಿನೊಂದಿಗೆ ಒಂದು ಯೋಜನೆಯನ್ನು ಹೊಂದಿದ್ದೀರಿ!

ಇದನ್ನು ಮಾಡಲು, ಯಾವ ಕೋಡ್ ಬ್ಲಾಕ್ಗಳು ಲಭ್ಯವಿದೆ ಎಂಬುದನ್ನು ನೀನು ತಿಳಿದುಕೊಳ್ಳಬೇಕು. **[ಮೊದಲ ಕೋಡ್ ಬ್ಲಾಕ್ಗಳು](first-bricks.md)** - ಟ್ಯುಟೋರಿಯಲ್ ನಿನಗೆ ವಿವಿಧ ವರ್ಗಗಳ ಕೋಡ್ ಬ್ಲಾಕ್ಗಳ ಬಗ್ಗೆ ಉತ್ತಮ ಅವಲೋಕನವನ್ನು ನೀಡುತ್ತದೆ. ಆದಾಗ್ಯೂ, ನಿನ್ನ ಮೊದಲ ಯೋಜನೆಯೊಂದಿಗೆ ನೀನು ನೇರವಾಗಿ ಪ್ರಾರಂಭಿಸಬಹುದು. ಆರಂಭಿಕರ ಸರಣಿಯಿಂದ ಸೂಕ್ತವಾದ ಟ್ಯುಟೋರಿಯಲ್ ಅನ್ನು ಆರಿಸು.
