![ಇದರ ಕಡೆಗೆ ತಿರುಗಿ:](../../../media/bricks/point_towards_brick.png)

ವಸ್ತುವು ಇನ್ನೊಬ್ಬ ವಸ್ತು ಅಥವಾ ಮೌಸ್ ಪಾಯಿಂಟರ್ ಅನ್ನು ಎದುರಿಸುವಂತೆ ಮಾಡುತ್ತದೆ. ನಿನ್ನ ಪಾತ್ರವು ಯಾವಾಗಲೂ ನಿರ್ದಿಷ್ಟ ಗುರಿ ಅಥವಾ ದಿಕ್ಕಿನಲ್ಲಿ ನೋಡಬೇಕೆಂದು ಹೇಳುವುದನ್ನು ಕಲ್ಪಿಸಿಕೊಳ್ಳಿ.
