![ಈ ಸಂಖ್ಯೆಯ ಹಿನ್ನೆಲೆಯನ್ನು ಹೊಂದಿಸಿ: 1](../../../media/bricks/Set_background_to_number_1_.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಹಿನ್ನೆಲೆಗಳನ್ನು ನಿರ್ದಿಷ್ಟವಾದ ಒಂದು ಹಿನ್ನೆಲೆಗೆ ಬದಲಾಯಿಸುತ್ತದೆ, ಹಿನ್ನೆಲೆಗಳ ಪಟ್ಟಿಯಲ್ಲಿ ಅದರ ಸ್ಥಾನವನ್ನು ಆಧರಿಸಿ. ಇದು ಒಂದು ನಿರ್ದಿಷ್ಟ ದೃಶ್ಯದ ಹಿನ್ನೆಲೆಯನ್ನು ಪಟ್ಟಿಯಿಂದ ಆಯ್ಕೆ ಮಾಡುವಂತೆ.
