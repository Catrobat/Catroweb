![ಕಣಗಳ ಬಣ್ಣವನ್ನು "#ff0000" ಗೆ ಹೊಂದಿಸಿ](../../../media/bricks/Set_particle_colour_to_ff0000.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ನಟನು ಹೊರಸೂಸುವ ಕಣಗಳ ಬಣ್ಣವನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ. ಇದು ಪಾರ್ಟಿ ಪಾಪ್ಪರ್ನಲ್ಲಿ ಕಾನ್ಫೆಟ್ಟಿಯ ಬಣ್ಣವನ್ನು ಬದಲಾಯಿಸುವಂತಿದೆ.

ಹೆಕ್ಸ ಕೋಡ್ ಬಣ್ಣವು ಹೆಕ್ಸಡೆಸಿಮಲ್ ಮೌಲ್ಯಗಳನ್ನು ಬಳಸಿಕೊಂಡು ಬಣ್ಣಗಳನ್ನು ಪ್ರತಿನಿಧಿಸುವ ಒಂದು ಮಾರ್ಗವಾಗಿದೆ. ಇದು ಆರು ಅಕ್ಷರಗಳಿಂದ ಕೂಡಿದೆ, ಅದು ಸಂಖ್ಯೆಗಳು (0-9) ಅಥವಾ ಅಕ್ಷರಗಳು (ಎ-ಎಫ್) ಆಗಿರಬಹುದು. ಕೋಡ್ ಸಾಮಾನ್ಯವಾಗಿ ಆರಂಭದಲ್ಲಿ “#” ನೊಂದಿಗೆ ಬರೆಯಲಾಗುತ್ತದೆ, ಈ ರೀತಿಃ `#RRGGBB`.

- ಮೊದಲ ಎರಡು ಅಕ್ಷರಗಳು (`RR`) ಬಣ್ಣದ ಕೆಂಪು ಅಂಶವನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತವೆ.
- ಮುಂದಿನ ಎರಡು ಅಕ್ಷರಗಳು (`GG`) ಹಸಿರು ಅಂಶವನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತವೆ.
- ಕೊನೆಯ ಎರಡು ಅಕ್ಷರಗಳು (`BB`) ನೀಲಿ ಅಂಶವನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತವೆ.

ಪ್ರತಿ ಜೋಡಿ ಅಕ್ಷರಗಳು `00` (ಅಂದರೆ ಆ ಬಣ್ಣದ ಯಾವುದೂ ಇಲ್ಲ) ನಿಂದ `FF` (ಅಂದರೆ ಆ ಬಣ್ಣದ ಗರಿಷ್ಠ ಪ್ರಮಾಣವನ್ನು ಸೂಚಿಸುತ್ತದೆ) ವರೆಗೆ ಇರಬಹುದು. ಉದಾಹರಣೆಗೆಃ:

`#000000` ಕಪ್ಪು (ಬಣ್ಣವಿಲ್ಲ).

`#FF0000` ಶುದ್ಧ ಕೆಂಪು ಬಣ್ಣ.

`#00FF00` ಶುದ್ಧ ಹಸಿರು ಬಣ್ಣ.

`#0000FF` ಶುದ್ಧ ನೀಲಿ ಬಣ್ಣ.

`#FFFFFF` ಬಿಳಿ (ಮೈಕ್ಸಿಮ್ ಕೆಂಪು, ಹಸಿರು ಮತ್ತು ನೀಲಿ).
