![ಪಾರದರ್ಶಕತೆಯನ್ನು 50%](../../../media/bricks/Set_transparency_to_50_pct_.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಒಂದು ನಟನು ಎಷ್ಟು ಪಾರದರ್ಶಕವಾಗಿದ್ದಾನೆ ಎಂಬುದನ್ನು ನಿರ್ಧರಿಸುತ್ತದೆ, 0% ಸಂಪೂರ್ಣವಾಗಿ ಅಸ್ಪಷ್ಟ ಮತ್ತು 100% ಸಂಪೂರ್ಣವಾಗಿ ಪಾರದರ್ಶಕವಾಗಿದೆ. ಇದು ಚಿತ್ರದ ಅಸ್ಪಷ್ಟತೆಯನ್ನು ಸರಿಹೊಂದಿಸುವಂತೆ.
