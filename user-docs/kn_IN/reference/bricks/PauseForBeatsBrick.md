![1 ಬೀಟ್ಸ್ ಗಾಗಿ ವಿರಾಮ](../../../media/bricks/Pause_for_1_beats.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಸ್ಕ್ರಿಪ್ಟ್ ಮುಂದುವರಿಯುವ ಮೊದಲು ನಿರ್ದಿಷ್ಟ ಸಂಖ್ಯೆಯ ಬೀಟ್ಸ್ ನಿರೀಕ್ಷಿಸಿ ಮಾಡುತ್ತದೆ. ಮುಂದಿನ ನಾಟಕ ಅಥವಾ ಧ್ವನಿಯನ್ನು ಆಡುವ ಮೊದಲು ಒಂದು ಹಾಡಿನಲ್ಲಿ ಸ್ವಲ್ಪ ವಿರಾಮ ತೆಗೆದುಕೊಳ್ಳುವುದು. ನಿನ್ನ ಪ್ರದರ್ಶನವನ್ನು ಒಂದು ಕ್ಷಣ ನಿಲ್ಲಿಸಿ, ಬೀಟ್ಗಳನ್ನು ಎಣಿಸಿ, ನಂತರ ಕ್ರಿಯೆಯನ್ನು ಪುನರಾರಂಭಿಸಿ ಎಂದು ಕಲ್ಪಿಸಿಕೊಳ್ಳಿ.
