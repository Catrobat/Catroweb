![ಧ್ವನಿಯನ್ನು ನಿಲ್ಲಿಸಿ:](../../../media/bricks/Stop_sound_record.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಒಂದು ನಿರ್ದಿಷ್ಟ ಧ್ವನಿಯನ್ನು ಪ್ಲೇ ಮಾಡುವುದನ್ನು ತಡೆಯುತ್ತದೆ. ಇದು ಕೇವಲ ಒಂದು ಹಾಡನ್ನು ನಿಲ್ಲಿಸುವ ಗುಂಡಿಯನ್ನು ಹೊಡೆಯುವಂತೆಯೇ ಇತರ ಧ್ವನಿಗಳು ಅಥವಾ ಸಂಗೀತವು ಆಡುತ್ತಿರುವಾಗ. ನಿನ್ನ ಪಾತ್ರವನ್ನು ಒಂದು ನಿರ್ದಿಷ್ಟ ಧ್ವನಿ ಹಾಡನ್ನು ಆಡುವುದನ್ನು ನಿಲ್ಲಿಸಲು ಹೇಳುವುದನ್ನು ಕಲ್ಪಿಸಿಕೊಳ್ಳಿ.
