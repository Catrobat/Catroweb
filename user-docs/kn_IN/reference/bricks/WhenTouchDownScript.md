![ವೇದಿಕೆಯನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ](../../../media/bricks/When_stage_is_tapped_btn.png)

ಸ್ಕ್ರೀನ್ ಸ್ಪರ್ಶಿಸಿದಾಗ ಸ್ಕ್ರಿಪ್ಟ್ ಚಲಾಯಿಸುತ್ತದೆ.

ಬ್ಲಾಕ್ *“ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ”* ಗೆ ವ್ಯತ್ಯಾಸವೆಂದರೆ, *“ವೇದಿಕೆಯನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ”* ಇಡೀ ಪರದೆಯ ಮೇಲೆ ಅನ್ವಯಿಸುತ್ತದೆ, ಆದರೆ *“ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ”* ಪ್ರತ್ಯೇಕ ಸ್ಪಿರಿಟ್ಗಳು ಅಥವಾ ವಸ್ತುಗಳಿಗೆ ನಿರ್ದಿಷ್ಟವಾಗಿದೆ.
