![ಇಲ್ಲದಿದ್ದರೆ ಕೋಡ್ ಬ್ಲಾಕ್](../../../media/bricks/if_else_brick2.png)

*ಒಂದು ಷರತ್ತು ನಿಜವಾಗಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸುತ್ತದೆ, ಮತ್ತು ಅದು ನಿಜವಾಗಿದ್ದರೆ ಒಂದು ಸೆಟ್ ಸೂಚನೆಗಳನ್ನು ಚಲಾಯಿಸುತ್ತದೆ, ಮತ್ತು ಅದು ಇಲ್ಲದಿದ್ದರೆ ಮತ್ತೊಂದು ಸೆಟ್. ಇದು ಎರಡು ಆಯ್ಕೆಗಳನ್ನು ನೀಡುವಂತೆಯೇಃ “ಇದು ನಿಜವಾಗಿದ್ದರೆ, ಇದನ್ನು ಮಾಡಿ; ಇಲ್ಲದಿದ್ದರೆ ಅದನ್ನು ಮಾಡು.”*

![ದೃಶ್ಯವನ್ನು ಪ್ರಾರಂಭಿಸಿ:](../../../media/bricks/StartScene.png)

ದೃಶ್ಯ ಪ್ರಾರಂಭವಾದಾಗ, ವೇರಿಯಬಲ್ X ಅನ್ನು 0 ಗೆ ಹೊಂದಿಸಲಾಗಿದೆ.

![ಬೇರೆ](../../../media/bricks/IfElse.png)

ಪ್ರಾಣಿಯನ್ನು ಈಗ ಟ್ಯಾಪ್ ಮಾಡಿದರೆ, X ಮಾಡ್ಯುಲೊ 2 ನಿಜವಾಗಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ, ಅಂದರೆ, X ಅಪರೂಪದ ಸಂಖ್ಯೆ.

ಈ ಸಂದರ್ಭದಲ್ಲಿ, ಧ್ವನಿ Tweet1 ಅನ್ನು ಆಡಲಾಗುತ್ತದೆ ಮತ್ತು ವೇರಿಯಬಲ್ X ಅನ್ನು 1 ರಷ್ಟು ಹೆಚ್ಚಿಸಲಾಗುತ್ತದೆ.

ಇಲ್ಲದಿದ್ದರೆ, X ಸಮವಾಗಿದ್ದರೆ, ಕೇವಲ X ಅನ್ನು 1 ರಷ್ಟು ಹೆಚ್ಚಿಸಲಾಗುತ್ತದೆ.

ಈಡೇರಿಸಬೇಕಾದ ಹೇಳಿಕೆಗಳನ್ನು ಷರತ್ತಿನ ಅಂತ್ಯ ಅಕ್ಷರದಿಂದ ಬೇರ್ಪಡಿಸಲಾಗುತ್ತದೆ.
