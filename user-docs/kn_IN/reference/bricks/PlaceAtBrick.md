![ಇಲ್ಲಿ ಇರಿಸಿ:](../../../media/bricks/place_at_x_y_brick.png)

x ಮತ್ತು y ನಿರ್ದೇಶಾಂಕಗಳಿಂದ ವ್ಯಾಖ್ಯಾನಿಸಲ್ಪಟ್ಟಿರುವ ಪರದೆಯ ಮೇಲೆ ನಿರ್ದಿಷ್ಟ ಸ್ಥಾನಕ್ಕೆ ವಸ್ತು ಚಲಿಸುತ್ತದೆ. ನಿನ್ನ ಪಾತ್ರವನ್ನು ನಿಖರವಾದ ಸ್ಥಳಕ್ಕೆ ದೂರವಾಣಿ ಸಾಗಿಸುವಂತೆ.

ಕಾರ್ಟೆಸಿಯನ್ ಸಮತಲದಂತಹ ನಿರ್ದೇಶಾಂಕ ವ್ಯವಸ್ಥೆಯಲ್ಲಿ ಸ್ಥಾನವನ್ನು ಹೊಂದಿಸಲಾಗಿದೆಃ x ಮತ್ತು y ಅಕ್ಷಗಳು ಪರದೆಯ ಮಧ್ಯಭಾಗದಲ್ಲಿ ಚಲಿಸುತ್ತವೆ, ಆದ್ದರಿಂದ x = 0 ಮತ್ತು y = 0 ಪರದೆಯ ಮಧ್ಯಭಾಗವಾಗಿದೆ.
