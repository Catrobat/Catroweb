![ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ](../../../media/bricks/when-tapped2.png)

ವಸ್ತು ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ ಸ್ಕ್ರಿಪ್ಟ್ ಚಲಾಯಿಸುತ್ತದೆ.

ಬ್ಲಾಕ್ *“ವೇದಿಕೆಯನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ”* ಗೆ ವ್ಯತ್ಯಾಸವೆಂದರೆ *“ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ”* ಪ್ರತ್ಯೇಕ ಸ್ಪ್ರೈಟ್ಗಳು ಅಥವಾ ವಸ್ತುಗಳಿಗೆ ನಿರ್ದಿಷ್ಟವಾಗಿದೆ, ಆದರೆ *“ವೇದಿಕೆಯನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿದಾಗ”* ಇಡೀ ಪರದೆಗೆ ಅನ್ವಯಿಸುತ್ತದೆ.
