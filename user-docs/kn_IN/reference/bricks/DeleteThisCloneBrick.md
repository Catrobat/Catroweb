![ಈ ಕ್ಲೋನ್ ಅನ್ನು ಅಳಿಸಿ](../../../media/bricks/delete_clone_brick2.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ “ಇದರ ಕ್ಲೋನ್ ರಚಿಸಿ:” ಕೋಡ್ ಬ್ಲಾಕ್ನೊಂದಿಗೆ ರಚಿಸಲಾದ ಕ್ಲೋನ್ ಅನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ. ಇದು ಹೇಳುವ ಹಾಗೆ, “ಈ ನಕಲನ್ನು ತೆಗೆಯಿರಿ.” ನಿನ್ನ ಯೋಜನೆಯಲ್ಲಿ ಕ್ಲೋನ್ಗಳ ಸಂಖ್ಯೆಯನ್ನು ನಿರ್ವಹಿಸಲು ಮತ್ತು ನಿಯಂತ್ರಿಸಲು ಇದನ್ನು ಬಳಸಿ, ಅವು ಇನ್ನು ಮುಂದೆ ಅಗತ್ಯವಿಲ್ಲದಿದ್ದಾಗ ಅವುಗಳನ್ನು ಅಳಿಸಲಾಗುತ್ತದೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.
