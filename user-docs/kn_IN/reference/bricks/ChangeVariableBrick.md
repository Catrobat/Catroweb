ಒಂದು ವೇರಿಯಬಲ್ನ ಪ್ರಸ್ತುತ ಮೌಲ್ಯದಿಂದ ಸೇರಿಸಲು ಅಥವಾ ಕಡಿತಗೊಳಿಸಲು ಬಯಸುವಿರಾ? ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ನಿನಗೆ ಅದನ್ನು ಮಾಡಲು ಅನುಮತಿಸುತ್ತದೆ. ಅದು ಹೇಳುವುದರಂತೆ, “ನಿನಗೆ ತಿಳಿದಿರುವದನ್ನು ತೆಗೆದುಕೊಂಡು ಇದಕ್ಕೆ ಸೇರಿಸಿಕೊಳ್ಳಿ.”
