![ನೀವು ಕ್ಲೋನ್ ಆಗಿ ಪ್ರಾರಂಭವಾದಾಗ](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

ಅಪೇಕ್ಷಿತ ಕ್ರಿಯೆಗಳನ್ನು ನಿರ್ವಹಿಸಲು ಸೂಚನೆಗಳೊಂದಿಗೆ ರಚಿಸಲಾದ ವಸ್ತುವಿನ ಕ್ಲೋನ್ ಅನ್ನು ನಿರ್ದೇಶಿಸುವುದು. ಈ ಪ್ರಕ್ರಿಯೆಯು ಮೂಲ ವಸ್ತುವಿನ ಕಾರ್ಯವನ್ನು ಪುನರಾವರ್ತಿಸಲು ಅನುವು ಮಾಡಿಕೊಡುತ್ತದೆ, ಆದರೆ ಕ್ಲೋನ್ ಅನ್ನು ಸ್ವತಂತ್ರವಾಗಿ ನಿಯಂತ್ರಿಸುತ್ತದೆ. ನಿರ್ದಿಷ್ಟ ಅವಶ್ಯಕತೆಗಳನ್ನು ಪೂರೈಸಲು ಕ್ಲೋನ್ ವಸ್ತುವಿನ ವಿವಿಧ ನಡವಳಿಕೆಗಳು ಅಥವಾ ಗುಣಲಕ್ಷಣಗಳನ್ನು ನಿರ್ದಿಷ್ಟಪಡಿಸಬಹುದು.
