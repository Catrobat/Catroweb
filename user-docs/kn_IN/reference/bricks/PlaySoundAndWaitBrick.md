![ಧ್ವನಿಯನ್ನು ಪ್ರಾರಂಭಿಸಿ ಮತ್ತು ಕಾಯಿರಿ:](../../../media/bricks/start_sound_and_wait_brick.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಆಯ್ಕೆ ಮಾಡಿದ ಧ್ವನಿಯನ್ನು ಪ್ಲೇ ಮಾಡುತ್ತದೆ ಮತ್ತು ಮುಂದಿನ ಕ್ರಿಯೆಗೆ ಮುಂದುವರಿಯುವ ಮೊದಲು ಅದು ಮುಗಿಯುವವರೆಗೆ ಕಾಯುತ್ತದೆ. ಅದು ಹಾಡಿನ ಮೇಲೆ ಪ್ಲೇ ಒತ್ತಿ ಹಾಡು ಮುಗಿಯುವ ತನಕ ಬೇರೆ ಏನನ್ನೂ ಮಾಡದಿರುವುದು.
