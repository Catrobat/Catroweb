![ಪ್ಲಾಟ್ ಮಾಡುವುದನ್ನು ನಿಲ್ಲಿಸಿ](../../../media/bricks/Stop_to_plot.png)

“ಪ್ಲಾಟ್ ಮಾಡುವುದನ್ನು ನಿಲ್ಲಿಸಿ” ಕೋಡ್ ಬ್ಲಾಕ್ ಪ್ಲಾಸಿಂಗ್ ಪ್ರಕ್ರಿಯೆಯನ್ನು ನಿಲ್ಲಿಸುತ್ತದೆ ಮತ್ತು ನೀನು ನಟನನ್ನು ಹೊಸ ಸ್ಥಾನಕ್ಕೆ ಸ್ಥಳಾಂತರಿಸಲು ಅಥವಾ ಪ್ಲಾಸಿಂಗ್ ಅನ್ನು ಪೂರ್ಣಗೊಳಿಸಲು ಅನುಮತಿಸುತ್ತದೆ. ಅದು ಕಾಗದದಿಂದ ಪೆನ್ ಅನ್ನು ಎತ್ತಿ ಅದನ್ನು ಮರುಸ್ಥಾಪಿಸಲು ಅಥವಾ ಡ್ರಾಯಿಂಗ್ ನಿಲ್ಲಿಸಲು. ನೀನು ಪ್ಲಾಸಿಂಗ್ ಮುಗಿಸಿದ ನಂತರ, ನಿನ್ನ ವಿನ್ಯಾಸವನ್ನು SVG ಫೈಲ್ ಆಗಿ ಉಳಿಸಲು ನೀನು “ಪ್ಲಾಟ್ ಅನ್ನು SVG ಆಗಿ ಉಳಿಸಿ:” ಕೋಡ್ ಬ್ಲಾಕ್ ಅನ್ನು ಬಳಸಬಹುದು.
