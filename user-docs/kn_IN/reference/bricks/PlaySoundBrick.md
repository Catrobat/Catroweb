![ಧ್ವನಿಯನ್ನು ಪ್ರಾರಂಭಿಸಿ:](../../../media/bricks/start_sound_brick2.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ತಕ್ಷಣ ಆಯ್ಕೆ ಧ್ವನಿ ಪ್ಲೇ ಮಾಡುತ್ತದೆ. ನಿನ್ನ ನೆಚ್ಚಿನ ಹಾಡನ್ನು ಪ್ಲೇ ಮಾಡಿ ಎಂದು ಕಲ್ಪಿಸಿಕೊಳ್ಳಿ; ಆ ಕ್ಷಣದಿಂದ ಧ್ವನಿ ನುಡಿಸಲು ಪ್ರಾರಂಭವಾಗುತ್ತದೆ.
