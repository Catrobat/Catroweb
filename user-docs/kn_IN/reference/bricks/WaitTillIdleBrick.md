ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಪ್ರಸ್ತುತ ಸ್ಕ್ರಿಪ್ಟ್ ಅನ್ನು ಯೋಜನೆಯ ಎಲ್ಲಾ ಇತರ ಸ್ಕ್ರಿಪ್ಟ್ಗಳು ಚಾಲನೆಯಲ್ಲಿರುವವರೆಗೆ ನಿಲ್ಲಿಸುತ್ತದೆ. ಎಲ್ಲವು ಮುಗಿಯುವ ತನಕ ನಿನ್ನ ಚಿತ್ರಣವನ್ನು ಕಾಯುವಿರಿ ಎಂದು ಊಹಿಸಿ. ನಿನ್ನ ಪ್ರಸ್ತುತ ಸ್ಕ್ರಿಪ್ಟ್ನಲ್ಲಿ ಮುಂದಿನ ಹಂತಗಳನ್ನು ಮುಂದುವರಿಸುವ ಮೊದಲು ಯಾವುದೇ ಕ್ರಿಯೆಗಳು ನಡೆಯುತ್ತಿಲ್ಲ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಲು ಇದು ಉಪಯುಕ್ತವಾಗಿದೆ.
