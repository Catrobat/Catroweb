![ಕಣ ಪರಿಣಾಮದ ಸೇರ್ಪಡೆ ಕಾರ್ಯವನ್ನು ಆನ್ ಮಾಡಿ](../../../media/bricks/Turn_particle_effect_additivity_on.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಕಣಗಳಿಗೆ ಸೇರ್ಪಡೆ ಮಿಶ್ರಣ ಮೋಡ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ ಅಥವಾ ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ, ಇದು ಕಣಗಳನ್ನು ಹೆಚ್ಚು ಪ್ರಕಾಶಮಾನವಾಗಿ ಮತ್ತು ಹೆಚ್ಚು ತೀವ್ರವಾಗಿ ಕಾಣುವಂತೆ ಮಾಡುತ್ತದೆ. ಇದು ಹೊಳಪಿನ ಹೊಳಪು ಮತ್ತು ಹೊಳಪನ್ನು ಸರಿಹೊಂದಿಸುವಂತೆ ಮಾಡುತ್ತದೆ.
