ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ನಟನು ಬಳಸುವ ಪೆನ್ನ ಬಣ್ಣವನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ. ಇದು ಚಿತ್ರಕಲೆ ಮಾಡುವಾಗ ಬೇರೆ ಬಣ್ಣದ ಪೆನ್ಗೆ ಬದಲಾಯಿಸುವಂತೆ.

**ಕೆಂಪು, ಹಸಿರು, ನೀಲಿ (RGB)**: ಬಣ್ಣದ ಮಾದರಿಯು RGB ವಿವಿಧ ತೀವ್ರತೆಗಳ ಕೆಂಪು, ಹಸಿರು ಮತ್ತು ನೀಲಿ ಬೆಳಕನ್ನು ಬಳಸಿಕೊಂಡು ವಿಶಾಲವಾದ ಬಣ್ಣಗಳನ್ನು ಸೃಷ್ಟಿಸುತ್ತದೆ. ಪ್ರತಿ ಬಣ್ಣದ ಘಟಕ (ಕೆಂಪು, ಹಸಿರು ಮತ್ತು ನೀಲಿ) 0 ರಿಂದ 255 ರ ನಡುವೆ ಮೌಲ್ಯವನ್ನು ಹೊಂದಿರಬಹುದುಃ:

- **ಕೆಂಪು**: ಬಣ್ಣದ ಕೆಂಪು ಅಂಶ. ಹೆಚ್ಚಿನ ಮೌಲ್ಯವು ಹೆಚ್ಚು ಕೆಂಪು ಬಣ್ಣವನ್ನು ಸೂಚಿಸುತ್ತದೆ.
- **ಹಸಿರು**: ಬಣ್ಣದ ಹಸಿರು ಅಂಶ. ಹೆಚ್ಚಿನ ಮೌಲ್ಯವು ಹೆಚ್ಚು ಹಸಿರು ಬಣ್ಣವನ್ನು ಸೂಚಿಸುತ್ತದೆ.
- **ನೀಲಿ**: ಬಣ್ಣದ ನೀಲಿ ಅಂಶ. ಹೆಚ್ಚಿನ ಮೌಲ್ಯವು ಹೆಚ್ಚು ನೀಲಿ ಬಣ್ಣವನ್ನು ಸೂಚಿಸುತ್ತದೆ.

ಕೆಂಪು, ಹಸಿರು ಮತ್ತು ನೀಲಿ ಬಣ್ಣಗಳ ವಿವಿಧ ಮೌಲ್ಯಗಳನ್ನು ಸಂಯೋಜಿಸುವ ಮೂಲಕ ನೀನು ಯಾವುದೇ ಬಣ್ಣವನ್ನು ರಚಿಸಬಹುದು. ಉದಾಹರಣೆಗೆಃ:

- `RGB(255, 0, 0)` ಶುದ್ಧ ಕೆಂಪು ಬಣ್ಣ.
- `RGB(0, 255, 0)` ಶುದ್ಧ ಹಸಿರು ಬಣ್ಣ.
- `RGB(0, 0, 255)` ಶುದ್ಧ ನೀಲಿ ಬಣ್ಣ.
- `RGB(255, 255, 255)` ಬಿಳಿ (ಮೈಕ್ಸಿಮ್ ಕೆಂಪು, ಹಸಿರು ಮತ್ತು ನೀಲಿ).
- `RGB(0, 0, 0)` ಕಪ್ಪು (ಬಣ್ಣವಿಲ್ಲ).

ಈ ಬಣ್ಣಗಳನ್ನು ವಿವಿಧ ಪ್ರಮಾಣಗಳಲ್ಲಿ ಮಿಶ್ರಣ ಮಾಡುವುದರಿಂದ ನೀನು ಡಿಜಿಟಲ್ ಸ್ಕ್ರೀನ್ಗಳಲ್ಲಿ ನೋಡುವ ಎಲ್ಲಾ ಬಣ್ಣಗಳನ್ನು ಸೃಷ್ಟಿಸುತ್ತದೆ.
