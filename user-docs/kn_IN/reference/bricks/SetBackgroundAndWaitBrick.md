ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಹೊಸ ಹಿನ್ನೆಲೆಯನ್ನು ಹೊಂದಿಸುತ್ತದೆ ಮತ್ತು ಸ್ಕ್ರಿಪ್ಟ್ ಮುಂದುವರಿಯುವ ಮೊದಲು ಬದಲಾವಣೆ ಪೂರ್ಣಗೊಳ್ಳುವವರೆಗೆ ಕಾಯುತ್ತದೆ. ಇದು ನಾಟಕದಲ್ಲಿ ದೃಶ್ಯವನ್ನು ಬದಲಾಯಿಸುವುದು ಮತ್ತು ಹೊಸ ದೃಶ್ಯವು ಸಂಪೂರ್ಣವಾಗಿ ಸೆಟ್ ಆಗುವವರೆಗೆ ಕಾಯುವುದು.
