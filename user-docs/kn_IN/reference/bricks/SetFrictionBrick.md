![ಘರ್ಷಣೆಯನ್ನು ಇದಕ್ಕೆ ಹೊಂದಿಸಿ:](../../../media/bricks/set_friction_to_brick2.png)

ವಸ್ತುಕ್ಕೆ ಅನ್ವಯವಾಗುವ ಘರ್ಷಣೆಯ ಪ್ರಮಾಣವನ್ನು ಸರಿಹೊಂದಿಸುತ್ತದೆ, ಅದು ಎಷ್ಟು ಸುಲಭವಾಗಿ ಸ್ಲೈಡ್ ಆಗುತ್ತದೆ ಅಥವಾ ನಿಧಾನಗೊಳ್ಳುತ್ತದೆ ಎಂಬುದರ ಮೇಲೆ ಪರಿಣಾಮ ಬೀರುತ್ತದೆ. ಅದು ನಿನ್ನ ಪಾತ್ರದ ಮೇಲ್ಮೈಯ ಸ್ಲೈಡಿಂಗ್ ಅನ್ನು ಬದಲಾಯಿಸುವಂತೆ- ಹೆಚ್ಚು ಘರ್ಷಣೆ ಎಂದರೆ ಕಡಿಮೆ ನೆಗೆಯುವುದು.
