![ಇಲ್ಲಿಗೆ ಹೋಗಿ:](../../../media/bricks/go_to_brick2.png)

ತಕ್ಷಣವೇ ವಸ್ತುವು ಮತ್ತೊಂದು ವಸ್ತುವಿನ ಸ್ಥಳಕ್ಕೆ ಅಥವಾ ಯಾದೃಚ್ಛಿಕ ಸ್ಥಾನಕ್ಕೆ ಚಲಿಸುತ್ತದೆ. ಇದನ್ನು ಹೇಳುವುದರಂತೆ ಯೋಚಿಸಿ, “ಈ ಇತರ ಪಾತ್ರದ ಸ್ಥಳಕ್ಕೆ ಹೋಗಿ” ಅಥವಾ “ಯಾದೃಚ್ಛಿಕ ಸ್ಥಳಕ್ಕೆ ಹೋಗಿ.”
