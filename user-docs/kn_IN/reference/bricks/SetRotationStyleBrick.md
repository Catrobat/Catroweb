![ತಿರುಗುವ ಶೈಲಿಯನ್ನು ಹೊಂದಿಸಿ:](../../../media/bricks/set_rotation_style_brick2.png)

ವಸ್ತುವಿನ ತಿರುಗುವಿಕೆಯನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ (ಎಲ್ಲಾ ಸುತ್ತಲೂ, ಎಡ-ಬಲ ಮಾತ್ರ, ಅಥವಾ ತಿರುಗುವುದಿಲ್ಲ). ನಿನ್ನ ಪಾತ್ರವು ಸಂಪೂರ್ಣವಾಗಿ ತಿರುಗಲು ಸಾಧ್ಯವೇ ಎಂಬುದನ್ನು ನಿರ್ಧರಿಸುವಂತೆ, ಎಡ ಮತ್ತು ಬಲಕ್ಕೆ ತಿರುಗಿಸಿ ಅಥವಾ ತಿರುಗಿಸದೆ ಇರಲಿ.
