![ವೇರಿಯೇಬಲ್ ಮರೆಮಾಡಿ: new](../../../media/bricks/Hide_variable_new.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಒಂದು ವೇರಿಯಬಲ್ನ ಪ್ರದರ್ಶಿತ ಮೌಲ್ಯವನ್ನು ಪರದೆಯಿಂದ ಕಣ್ಮರೆಯಾಗುತ್ತದೆ. ನಿನ್ನ ಮಾಹಿತಿಯನ್ನು ಇನ್ನು ಮುಂದೆ ಅಗತ್ಯವಿಲ್ಲದಿದ್ದಾಗ ಅದನ್ನು ಬಳಸಿ ನಿನ್ನ ಪ್ರದರ್ಶನವನ್ನು ಸ್ವಚ್ಛಗೊಳಿಸಿ.
