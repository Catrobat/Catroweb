![ಕಣಗಳ ಹೊಳೆಯುವ ಪರಿಣಾಮ](../../../media/bricks/Fade_particle_effect_in.png)

ಈ ಬ್ಲಾಕ್ ನಿನ್ನ ಪಾತ್ರಕ್ಕೆ ಕಣಗಳನ್ನು ಸೇರಿಸುತ್ತದೆ ಮತ್ತು ಕಾಲಾನಂತರದಲ್ಲಿ ಅವುಗಳನ್ನು ನಿಧಾನವಾಗಿ ಕಣ್ಮರೆಯಾಗುತ್ತದೆ. ಉದಾಹರಣೆಗೆ, ಫೈರ್ವರ್ಕ್ ಪ್ರದರ್ಶನ ಮಾಡಲು, ಧೂಮಪಾನವನ್ನು ಸೇರಿಸಲು ಅಥವಾ ನಿನ್ನ ಪಾತ್ರವನ್ನು ತ್ವರಿತವಾಗಿ ತೋರಿಸಲು ಇದನ್ನು ಬಳಸಿ.
