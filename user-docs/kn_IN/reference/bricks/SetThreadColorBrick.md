ಈ ಬ್ಲಾಕ್ ಅನ್ನು ಬಳಸುವುದರ ಮೂಲಕ, ನಿನ್ನ ಹೊಲಿಗೆ ಯೋಜನೆಗಾಗಿ ನೀನು ಥ್ರೆಡ್ನ ಬಣ್ಣವನ್ನು ಬದಲಾಯಿಸಬಹುದು. ನಿನ್ನ ಪ್ರೋಗ್ರಾಂನಲ್ಲಿ ಬಣ್ಣವನ್ನು ತೋರಿಸಲಾಗುತ್ತದೆ. ಇದರರ್ಥ ಕಸೂತಿ ಯಂತ್ರವು ಈ ಬಣ್ಣಗಳನ್ನು ಬಳಸುತ್ತದೆ ಎಂದಲ್ಲ.
