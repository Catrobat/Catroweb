![ಎಲ್ಲಾ ಧ್ವನಿಗಳನ್ನು ನಿಲ್ಲಿಸಿ](../../../media/bricks/Stop_all_sounds.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಪ್ರಸ್ತುತ ಎಲ್ಲಾ ಧ್ವನಿಗಳನ್ನು ಪ್ಲೇ ನಿಲ್ಲಿಸುತ್ತದೆ. ಎಲ್ಲವನ್ನೂ ಮೌನಗೊಳಿಸಲು ಸಂಗೀತ ಪ್ಲೇಯರ್ನಲ್ಲಿರುವ ಸ್ಟಾಪ್ ಬಟನ್ ಅನ್ನು ಒತ್ತುವುದರಂತೆ ಯೋಚಿಸಿ.
