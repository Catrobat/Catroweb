![ಟಿಪ್ಪಣಿ:](../../../media/bricks/note_brick2.png)

ನಿನ್ನ ಸ್ಕ್ರಿಪ್ಟ್ಗೆ ಕಾಮೆಂಟ್ ಅಥವಾ ಟಿಪ್ಪಣಿ ಸೇರಿಸುತ್ತದೆ, ಅದು ನಿನ್ನ ಕೋಡ್ನ ಯಾವ ಭಾಗಗಳನ್ನು ನೆನಪಿನಲ್ಲಿಟ್ಟುಕೊಳ್ಳಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ. ನಿನ್ನ ಯೋಜನೆಯ ಕಾರ್ಯಾಚರಣೆಯ ಮೇಲೆ ಅದು ಪರಿಣಾಮ ಬೀರುವುದಿಲ್ಲ. ಅದು ನಿಮಗಾಗಿ ಒಂದು ಅಂಟಿಕೊಳ್ಳುವ ಟಿಪ್ಪಣಿ ಬಿಟ್ಟು ಹೋಗುವುದರಂತೆ.
