![ಇದರ ಕ್ಲೋನ್ ರಚಿಸಿ:](../../../media/bricks/create_clone_of_brick2.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ನಿರ್ದಿಷ್ಟಪಡಿಸಿದ ವಸ್ತುವಿನ ನಕಲನ್ನು ಮಾಡುತ್ತದೆ, ಇದನ್ನು ಕ್ಲೋನ್ ಎಂದು ಕರೆಯಲಾಗುತ್ತದೆ, ಅದು ಮೂಲದಂತೆಯೇ ವರ್ತಿಸುತ್ತದೆ. ನಿನ್ನ ಆಟದಲ್ಲಿ ಪಾತ್ರ ಅಥವಾ ವಸ್ತುವನ್ನು ನಕಲಿಸಿ. ಕ್ಲೋನ್ ತನ್ನದೇ ಆದ ನಡವಳಿಕೆ ಮತ್ತು ಸ್ಕ್ರಿಪ್ಟ್ಗಳನ್ನು ಹೊಂದಬಹುದು, ಇದು ಸ್ವತಂತ್ರವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ವಸ್ತುವಿನ ಅನೇಕ ನಿದರ್ಶನಗಳನ್ನು ರಚಿಸಲು ನಿನಗೆ ಅನುಮತಿಸುತ್ತದೆ.
