![ಈ ದಿಕ್ಕಿಗೆ ತಿರುಗಿ: ಡಿಗ್ರಿ](../../../media/bricks/point_in_direction__degrees_brick2.png)

ವಸ್ತುವು ನಿರ್ದಿಷ್ಟ ಕೋನಕ್ಕೆ ಮುಖ ಮಾಡುವ ದಿಕ್ಕನ್ನು ಹೊಂದಿಸುತ್ತದೆ. ಇದು ನಿನ್ನ ಪಾತ್ರವನ್ನು ನಿರ್ದಿಷ್ಟ ದಿಕ್ಕಿನಲ್ಲಿ ಮುಖ ಮಾಡಲು ಹೇಳುವುದರಂತೆಯೇ, ಉದಾಹರಣೆಗೆ ಮೇಲಕ್ಕೆ, ಕೆಳಕ್ಕೆ, ಎಡಕ್ಕೆ ಅಥವಾ ಬಲಕ್ಕೆ.
