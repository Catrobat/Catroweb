![ಗ್ರಾಫಿಕ್ ಪರಿಣಾಮಗಳನ್ನು ತೆರವುಗೊಳಿಸಿ](../../../media/bricks/Clear_graphic_effects.png)

ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ನಟನಿಗೆ ಅನ್ವಯವಾಗುವ ಯಾವುದೇ ದೃಶ್ಯ ಪರಿಣಾಮಗಳನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ, ಅದನ್ನು ಅದರ ಮೂಲ ನೋಟಕ್ಕೆ ಮರಳಿಸುತ್ತದೆ. ಅದು ಮತ್ತೆ ಸ್ಪಷ್ಟವಾಗಲು ಕೊಳೆತ ಕಿಟಕಿಯನ್ನು ಸ್ವಚ್ಛಗೊಳಿಸುವುದರಂತಿದೆ.
