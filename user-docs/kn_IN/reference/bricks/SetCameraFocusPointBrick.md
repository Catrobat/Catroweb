ಈ ಕೋಡ್ ಬ್ಲಾಕ್ ಅಡ್ಡ ಮತ್ತು ಲಂಬ ದಿಕ್ಕುಗಳಲ್ಲಿ ನಿರ್ದಿಷ್ಟ ನಮ್ಯತೆಯೊಂದಿಗೆ ಪರದೆಯ ಕೇಂದ್ರಬಿಂದುವಾಗಿ ನಟನನ್ನು ಹೊಂದಿಸುತ್ತದೆ. ಇದು ಕ್ಯಾಮೆರಾವನ್ನು ಒಂದು ಪಾತ್ರವನ್ನು ಅನುಸರಿಸಲು ಹೇಳುವುದರಂತೆಯೇ, ಮಧ್ಯಭಾಗದಲ್ಲಿ ಸ್ವಲ್ಪ ಚಲನೆಯನ್ನು ಅನುಮತಿಸುತ್ತದೆ.
