Pocket Code ಎಂಬುದು ದೃಶ್ಯ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಅಪ್ಲಿಕೇಶನ್ ಆಗಿದ್ದು ಅದು ನಿನ್ನ ಸ್ಮಾರ್ಟ್ಫೋನ್ ಅಥವಾ ಟ್ಯಾಬ್ಲೆಟ್ನಲ್ಲಿ ನೇರವಾಗಿ ಆಟಗಳು, ಅನಿಮೇಷನ್ಗಳು ಮತ್ತು ಸಂವಾದಾತ್ಮಕ ಕಥೆಗಳನ್ನು ರಚಿಸಲು ನಿನಗೆ ಅನುಮತಿಸುತ್ತದೆ. “ಕೋಡ್ ಬ್ಲಾಕ್ಗಳು” (ಕೋಡ್ ಬ್ಲಾಕ್ಗಳು) ನೊಂದಿಗೆ ಅರ್ಥಗರ್ಭಿತ ಎಳೆಯಿರಿ ಮತ್ತು ಬಿಡಿ ಇಂಟರ್ಫೇಸ್ ಬಳಸಿ, ನೀನು ನಿನ್ನ ಯೋಜನೆಗಳನ್ನು ಪೂರ್ವ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಅನುಭವವಿಲ್ಲದೆ ವಿನ್ಯಾಸಗೊಳಿಸಬಹುದು. ನಿನ್ನ ಆಲೋಚನೆಗಳನ್ನು ಜೀವಂತವಾಗಿಡಲು ಸುಲಭವಾಗಿ ಧ್ವನಿ, ಚಿತ್ರಗಳು ಮತ್ತು ಚಲನೆಯನ್ನು ಸೇರಿಸಿ.

ಈ ಮಾರ್ಗದರ್ಶಿ ನಿನಗೆ ಹೇಗೆ ಪ್ರಾರಂಭಿಸಬೇಕು ಎಂಬುದನ್ನು ವಿವರಿಸುತ್ತದೆಃ:

- ಇಂಟರ್ಫೇಸ್ ನ್ಯಾವಿಗೇಟ್,
- ನಿನ್ನ ಮೊದಲ ಯೋಜನೆಯನ್ನು ರಚಿಸಿ,
- ವಸ್ತುಗಳು ಮತ್ತು ಹಿನ್ನೆಲೆಗಳೊಂದಿಗೆ ಕೆಲಸ ಮಾಡಿ,
- ಕ್ರಿಯೆಗಳನ್ನು ಪ್ರೋಗ್ರಾಂ ಮಾಡಲು ಕೋಡ್ ಬ್ಲಾಕ್ಗಳನ್ನು ಬಳಸಿ, ಮತ್ತು
- ನಿನ್ನ ಯೋಜನೆಯನ್ನು ಉಳಿಸಿ.

ಆರಂಭಿಕ ಮತ್ತು ಶಿಕ್ಷಕರಿಗೆ ಪರಿಪೂರ್ಣವಾದ Pocket Code ಸೃಜನಶೀಲತೆ, ಸಮಸ್ಯೆಗಳನ್ನು ಬಗೆಹರಿಸುವಿಕೆ ಮತ್ತು ತಾರ್ಕಿಕ ಚಿಂತನೆಯನ್ನು ಉತ್ತೇಜಿಸುತ್ತದೆ.
