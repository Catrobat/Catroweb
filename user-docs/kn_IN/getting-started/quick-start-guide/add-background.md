ನೀನು ನಿನ್ನ ಯೋಜನೆಗೆ ಹಿನ್ನೆಲೆ ಸೇರಿಸಬಹುದು Catrobat.

ಹಿನ್ನೆಲೆಗಳನ್ನು ವಿವಿಧ ರೀತಿಯಲ್ಲಿ ಬಳಸಬಹುದು. Pocket Code ನಲ್ಲಿ, ಅವುಗಳನ್ನು ದೃಶ್ಯವಾಗಿ ವರ್ಧಿಸಲು **ಆಟಗಳು**, ಹೇಳಲು **ಕಥೆಗಳು**, ಅಥವಾ ನಿನ್ನ ನಟರು ಮತ್ತು ವಸ್ತುಗಳಿಗೆ ಹೆಚ್ಚಿನ ಸಂದರ್ಭವನ್ನು ಒದಗಿಸಲು ಬಳಸಬಹುದು.

**ಸಂಚುಗಾರರು** ಅಥವಾ **ಕಸೂತಿ ಯಂತ್ರಗಳು** ನಂತಹ ಮೇಕರ್ಸ್ ಸ್ಪೇಸ್ ಸಾಧನಗಳಿಗೆ ಹಿನ್ನೆಲೆಗಳು ಕಟ್ಗಳು ಅಥವಾ ಕಸೂತಿ ಮಾದರಿಗಳಂತಹ ವಿನ್ಯಾಸ ಟೆಂಪ್ಲೆಟ್ಗಳಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ.

ಒಂದು ಹಿನ್ನೆಲೆ ಸೇರಿಸಲು, ಯೋಜನೆಯ ವೀಕ್ಷಣೆಯಲ್ಲಿ “ಹಿನ್ನೆಲೆ” ಮೇಲೆ ಟ್ಯಾಪ್ ಮಾಡು.

![ಹಿಂದಿನ ವಿಷಯದ ಸಲಹೆಗಳು](../../../media/getting-started/grafik-16.png)

**ಸ್ಕ್ರಿಪ್ಟ್ ವಿಭಾಗ (2)** ನಲ್ಲಿ ನಿನ್ನ ಹಿನ್ನೆಲೆಯನ್ನು ನೀನು ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದು - ಆದಾಗ್ಯೂ, ಈ ಉದ್ದೇಶಕ್ಕಾಗಿ ಎಲ್ಲಾ ಬ್ಲಾಕ್ಗಳು ಲಭ್ಯವಿಲ್ಲ. ಈ ಕೆಳಗಿನ ಎರಡು ಬ್ಲಾಕ್ಗಳು ವಿಶೇಷವಾಗಿ ಮಹತ್ವದ್ದಾಗಿವೆಃ ![ಪಾರದರ್ಶಕತೆಯನ್ನು 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) ಮತ್ತು ![ಗಾತ್ರವನ್ನು ಇದಕ್ಕೆ ಹೊಂದಿಸಿ: 60%](../../../media/bricks/Set_size_to_60_pct_.png)

**ಕಾಣುತ್ತದೆ ವಿಭಾಗ(1)** ನಲ್ಲಿ ನೀನು ಹಿನ್ನೆಲೆ ಸೇರಿಸುತ್ತೀರಿ. ಇದನ್ನು ಮಾಡಲು, + ಚಿಹ್ನೆಯನ್ನು ಟ್ಯಾಪ್ ಮಾಡು.

![ಹಿನ್ನೆಲೆ ಸೇರಿಸಿ](../../../media/getting-started/grafik-14.png)

ನೀನು ನಿನ್ನ ಸ್ವಂತ ಚಿತ್ರಗಳನ್ನು ಅಪ್ಲೋಡ್ ಮಾಡಬಹುದು, ಪೂರ್ವನಿರ್ಧರಿತ ಹಿನ್ನೆಲೆಗಳನ್ನು ಬಳಸಬಹುದು ಅಥವಾ ಹಿನ್ನೆಲೆಗಳನ್ನು ನೀವೇ ರಚಿಸಬಹುದು.

**ಚಿತ್ರಿಸಿ**: ನೀನು ನಿನ್ನ ಸ್ವಂತ ಹಿನ್ನೆಲೆ ರಚಿಸಬಹುದು **Pocket Paint**. Pocket Paint ಒಂದು ರೇಖಾಚಿತ್ರ ಕಾರ್ಯಕ್ರಮ ([ಬಗ್ಗೆ ಇನ್ನಷ್ಟು Pocket Paint](https://catrobat.org/pocket-paint/))

**ರೂಪಗಳು**: ಪೂರ್ವ-ಸೃಷ್ಟಿಸಿದ ಹಿನ್ನೆಲೆಗಳ ಸಂಗ್ರಹದಿಂದ ಒಂದು ಆಯ್ಕೆಮಾಡಿ ([ಮಾಧ್ಯಮ ಗ್ರಂಥಾಲಯದ ಬಗ್ಗೆ ಇನ್ನಷ್ಟು](../elements/medialibrary.md)).

**ಗ್ಯಾಲರಿ**: ನಿನ್ನ ಸ್ಮಾರ್ಟ್ಫೋನ್ ಗ್ಯಾಲರಿಯಿಂದ ನೀನು ಚಿತ್ರವನ್ನು ಆಯ್ಕೆ ಮಾಡಬಹುದು.

**ಕ್ಯಾಮರಾ**: ನಿನ್ನ ಸಾಧನದ ಕ್ಯಾಮೆರಾವನ್ನು ಬಳಸಿಕೊಂಡು ನೀನು ಫೋಟೋ ತೆಗೆದು ಹಿನ್ನೆಲೆ ಆಗಿ ಸೇರಿಸಬಹುದು.

![ಮಾಧ್ಯಮ ಗ್ರಂಥಾಲಯದಿಂದ ಆಯ್ಕೆಮಾಡಿ](../../../media/getting-started/grafik-17.png)

ನೀನು ಈಗ ಒಂದು ಹಿನ್ನೆಲೆ ಸೇರಿಸಿದ್ದೀರಿ. **ಯೋಜನೆ ವೀಕ್ಷಣೆ** ಗೆ ಹಿಂತಿರುಗಲು ಮೇಲಿನ ಬಲಭಾಗದಲ್ಲಿರುವ ಹಿಂಭಾಗದ ಬಾಣವನ್ನು ಕ್ಲಿಕ್ ಮಾಡು.
