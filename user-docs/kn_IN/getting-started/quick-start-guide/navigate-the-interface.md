ನೀನು ಪ್ರಾರಂಭಿಸಿದಾಗ Pocket Code, ನೀನು ಕೆಳಗಿನ ಮುಖ್ಯ ಪರದೆಯನ್ನು ನೋಡುತ್ತೀರಿ.

![ಮುಖ್ಯ ಪರದೆಯ](../../../media/getting-started/MainScreen-e1732269599192.jpg)

ಮೇಲಿನ ಬಲ ಮೂಲೆಯಲ್ಲಿ, ನೀನು ![ಸಹಾಯ](../../../media/getting-started/Screenshot-2024-11-22-111748.png) ಚಿಹ್ನೆಯನ್ನು ಹೊಂದಿದ್ದೀರಿ ಅದು ನಿನ್ನನ್ನು Catrobat ದಸ್ತಾವೇಜಿಗೆ ಕರೆದೊಯ್ಯುತ್ತದೆ, ಇದು ನಿನಗೆ ಉಪಯುಕ್ತ ಸಲಹೆಗಳನ್ನು ಹೊಂದಿದೆ.

ಅದರ ಪಕ್ಕದಲ್ಲಿ ಮೆನು ![ಮೆನು](../../../media/getting-started/Screenshot-2024-11-22-111804.png) ಇದೆ. ಅಲ್ಲಿಂದ, ನೀನು ಸುಲಭವಾಗಿ ಸೆಟ್ಟಿಂಗ್ಗಳಿಗೆ ಹೋಗಬಹುದು, ಅಲ್ಲಿ ನೀನು ಭಾಷೆಯನ್ನು ಬದಲಾಯಿಸಬಹುದು ಅಥವಾ ಪ್ಲಾಟ್ ಬ್ಲಾಕ್ಗಳಂತಹ ವಿಸ್ತರಣೆಗಳನ್ನು ಆನ್ ಮಾಡಬಹುದು ಮತ್ತು ಹೆಚ್ಚಿನವು.

ಕೆಳಗೆ, ನಿನ್ನ ಇತ್ತೀಚಿನ ಸಂಪಾದಿತ ಯೋಜನೆಯನ್ನು ನೀನು ನೋಡಬಹುದು. ಯೋಜನೆಯ ಪರದೆಯನ್ನು ಪ್ರವೇಶಿಸಲು ಸಂಪಾದನೆ ಐಕಾನ್ ![ಐಕಾನ್ ಸಂಪಾದಿಸಿ](../../../media/getting-started/Screenshot-2024-11-22-111825.png) ಕ್ಲಿಕ್ ಮಾಡಿ, ಅಲ್ಲಿ ನೀನು ನಿನ್ನ ಯೋಜನೆಯನ್ನು ಅಭಿವೃದ್ಧಿಪಡಿಸುವುದನ್ನು ಮುಂದುವರಿಸಬಹುದು.

ನಿನ್ನ ಯೋಜನೆಯನ್ನು ಪ್ರಾರಂಭಿಸಲು ಪ್ಲೇ ಬಟನ್ ![ನಿನ್ನ ಯೋಜನೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ](../../../media/getting-started/Screenshot-2024-11-22-111818.png) ಬಳಸಿ.

ಒಂದು ಕ್ಲಿಕ್ ನಲ್ಲಿ ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು, ನೀನು ಉಳಿಸಿದ ಯೋಜನೆಗಳನ್ನು ಪ್ರವೇಶಿಸಬಹುದು. ![ಸಾಧನಗಳ ಯೋಜನೆಗಳು](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

ನೀನು ಇತರ ಬಳಕೆದಾರರಿಂದ ಹೆಚ್ಚಿನ ಯೋಜನೆಗಳನ್ನು ತಿಳಿದುಕೊಳ್ಳಲು ಮತ್ತು ಕೆಲಸ ಮಾಡಲು ಬಯಸಿದರೆ, ಹಂಚಿಕೆಯ ಮೇಲೆ ಸಮುದಾಯವನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ Catrobat. ಅಲ್ಲಿ ನೀನು ಅನೇಕ ಮಹಾನ್ ಯೋಜನೆಗಳನ್ನು ಕಾಣಬಹುದು. ![Catrobat ಸಮುದಾಯ](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

ನೀನು ಹೊಸ ಯೋಜನೆಯನ್ನು ರಚಿಸಲು ಬಯಸಿದರೆ, ಪ್ಲಸ್ ಐಕಾನ್ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡು. ![ಸೇರಿಸಿ](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
