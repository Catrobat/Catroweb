ನಿನ್ನ ಫೋನ್ ಅಥವಾ ಟ್ಯಾಬ್ಲೆಟ್‌ನಲ್ಲಿ ಆ್ಯಪ್ ತೆರೆಯು. ಹೊಸ ಯೋಜನೆ ಮಾಡಲು + ಗುರುತನ್ನು ಒತ್ತು.

![ಮುಖ್ಯ ಪರದೆಯ ಹೊಸ ಯೋಜನೆ](../../../media/getting-started/MainScreen_NewProject.png)

ಯೋಜನೆಗೆ ಹೆಸರಿಡು (1). ಆಟಕ್ಕೆ ನಿಂತ (ಪೋರ್ಟ್ರೇಟ್) ಅಥವಾ ಅಡ್ಡ (ಲ್ಯಾಂಡ್‌ಸ್ಕೇಪ್) ಪರದೆಯನ್ನು ಆಯ್ಕೆ ಮಾಡು (2). ಖಚಿತಪಡಿಸಲು ಸರಿ ಗುರುತನ್ನು ಒತ್ತು (3).

![ಹೊಸ ಯೋಜನೆ](../../../media/getting-started/NewProject.png)

ಈಗ ನೀನು ನಿನ್ನ ಯೋಜನೆಯ ವೀಕ್ಷಣೆಯಲ್ಲಿರುತ್ತೀರಿ. ಮೇಲಿನ ಭಾಗದಲ್ಲಿ, ನಿನ್ನ ಆಟದ ಹೆಸರನ್ನು ನೀನು ನೋಡುತ್ತೀರಿ.

ಕೆಳಗೆ ನೀನು **ಹಿನ್ನೆಲೆ** ನೋಡಬಹುದು - ಪ್ರಸ್ತುತ, ಹಿನ್ನೆಲೆ ಖಾಲಿ. ನೀನು ಅದನ್ನು ಬದಲಾಯಿಸಲು ಬಯಸಿದರೆ, ಅದರ ಮೇಲೆ ಟ್ಯಾಪ್ ಮಾಡು.

ಹಿನ್ನೆಲೆಯಲ್ಲಿ, ನಿನ್ನ ಆಟಕ್ಕೆ ನೀನು ಸೇರಿಸಿದ ಪ್ರದೇಶ **ನಟರು ಮತ್ತು ವಸ್ತುಗಳು** ಅನ್ನು ನೀನು ನೋಡುತ್ತೀರಿ. ಪ್ರಸ್ತುತ, ಈ ಪ್ರದೇಶವು ಇನ್ನೂ ಖಾಲಿ ಇದೆ.

ಕೆಳಗಿನ ಬಲಭಾಗದಲ್ಲಿ, ನೀನು ಎರಡು ಪ್ರಮುಖ ಗುಂಡಿಗಳನ್ನು ನೋಡುತ್ತೀರಿಃ:

![ಪ್ರಾರಂಭಿಸಿ](../../../media/getting-started/Start.png) ನೀನು ಆಟವನ್ನು ಪ್ರಾರಂಭಿಸಲು **ಪ್ಲೇ ಮಾಡಿ** ಗುಂಡಿಯನ್ನು ಬಳಸುತ್ತೀರಿ.

![ಜೊತೆಗೆ ಬಟನ್](../../../media/getting-started/Screenshot-2024-11-22-143219.png) **ಜೊತೆಗೆ** ಗುಂಡಿಯನ್ನು ಬಳಸಿಕೊಂಡು, ನೀನು ನಿನ್ನ ಆಟಕ್ಕೆ ಹೊಸ ಪಾತ್ರ / ವಸ್ತುವನ್ನು ಸೇರಿಸುತ್ತೀರಿ.
