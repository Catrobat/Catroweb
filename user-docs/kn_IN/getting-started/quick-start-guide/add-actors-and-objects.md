ನಿನ್ನ ಯೋಜನೆಗೆ ಹೊಸ ಅಂಕಿಅಂಶ ಅಥವಾ ವಸ್ತುವನ್ನು ಸೇರಿಸಲು ಪ್ಲಸ್ ಬಟನ್ ಅನ್ನು ಟ್ಯಾಪ್ ಮಾಡು.

![ನಟನನ್ನು ಸೇರಿಸು](../../../media/getting-started/FigurHinzufuegen.png)

Pocket Code ನಲ್ಲಿ, ನಿನ್ನ ಯೋಜನೆಗೆ ನೀನು ಒಂದು ಪಾತ್ರ ಅಥವಾ ವಸ್ತುವನ್ನು ವಿವಿಧ ರೀತಿಯಲ್ಲಿ ಸೇರಿಸಬಹುದುಃ:

**ಚಿತ್ರಿಸಿ**: ನೀನು ನಿನ್ನ ಸ್ವಂತ ಪಾತ್ರವನ್ನು ರಚಿಸಬಹುದು **Pocket Paint**. Pocket Paint ಒಂದು ರೇಖಾಚಿತ್ರ ಕಾರ್ಯಕ್ರಮ ([ಬಗ್ಗೆ ಇನ್ನಷ್ಟು Pocket Paint](https://catrobat.org/pocket-paint/))

**ರೂಪಗಳು**: ಪೂರ್ವ-ಸೃಷ್ಟಿಸಿದ ನಟರು ಮತ್ತು ವಸ್ತುಗಳ ಸಂಗ್ರಹದಿಂದ ಒಂದು ಆಯ್ಕೆಮಾಡಿ ([ಮಾಧ್ಯಮ ಗ್ರಂಥಾಲಯದ ಬಗ್ಗೆ ಇನ್ನಷ್ಟು](../elements/medialibrary.md)).

**ಗ್ಯಾಲರಿ**: ನಿನ್ನ ಸ್ಮಾರ್ಟ್ಫೋನ್ ಗ್ಯಾಲರಿಯಿಂದ ನೀನು ಚಿತ್ರವನ್ನು ಆಯ್ಕೆ ಮಾಡಬಹುದು.

**ಲೈಬ್ರರಿ**: ಗ್ರಂಥಾಲಯದಲ್ಲಿ, ಈಗಾಗಲೇ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಲಾದ ನಟರು ಮತ್ತು ವಸ್ತುಗಳನ್ನು ನೀನು ಕಾಣಬಹುದು, ಅಂದರೆ ಅವುಗಳು ಈಗಾಗಲೇ ಸ್ಕ್ರಿಪ್ಟ್ ಹೊಂದಿವೆ. ನಿನ್ನ ಆಟದಲ್ಲಿ ಸಿದ್ಧವಾದ ಅಂಶಗಳನ್ನು ಬಳಸಲು ನೀನು ಬಯಸಿದರೆ ನೀನು ಅವುಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡಬಹುದು (ಉದಾಹರಣೆಗೆ, ಹಿಮ್ಮುಖ ಎಣಿಕೆ) ([ಗ್ರಂಥಾಲಯದ ಬಗ್ಗೆ ಇನ್ನಷ್ಟು](../elements/medialibrary.md#ಮಾಧ್ಯಮ-ಗ್ರಂಥಾಲಯದಿಂದ-ಒಂದು-ವಸ್ತುವನ್ನು-ಸೇರಿಸಿ)).

**ಕ್ಯಾಮರಾ**: ನಿನ್ನ ಸಾಧನದ ಕ್ಯಾಮೆರಾವನ್ನು ಬಳಸಿಕೊಂಡು ನೀನು ಫೋಟೋ ತೆಗೆದು ಅದನ್ನು ಒಂದು ಪಾತ್ರವಾಗಿ ಸೇರಿಸಬಹುದು.

**ಬ್ಯಾಕ್‌ಪ್ಯಾಕ್**: ಪ್ರಸ್ತುತ, ಬೆನ್ನುಹೊರೆಯು ಖಾಲಿ ಇದೆ. ನಿನ್ನ ಹಿಂಭಾಗದ ಚೀಲದಲ್ಲಿ ನೀನು ಸಂಗ್ರಹಿಸಿದ ನಟರು ಅಥವಾ ವಸ್ತುಗಳನ್ನು ನೀನು ಮರುಬಳಕೆ ಮಾಡಬಹುದು. ಇಡೀ ಸ್ಕ್ರಿಪ್ಟ್ ಅನ್ನು ಅದರೊಂದಿಗೆ ಅನ್ಪಾಕ್ ಮಾಡಲಾಗುತ್ತದೆ ([ಹಿಂಭಾಗದ ಚೀಲದ ಬಗ್ಗೆ ಇನ್ನಷ್ಟು](../elements/backpack.md)).

**ಸಾಧನದಲ್ಲಿರುವ ಪಾತ್ರಗಳು ಮತ್ತು ವಸ್ತುಗಳು**: ನಿನ್ನ ಯೋಜನೆಯಲ್ಲಿ ನೀನು ಬಳಸಬಹುದಾದ ಸಿದ್ಧವಾದ ಪಾತ್ರಗಳನ್ನು ಇಲ್ಲಿ ಕಾಣಬಹುದು. ಸ್ಥಳೀಯ ನಟರು ಮತ್ತು ವಸ್ತುಗಳು ಆಫ್ಲೈನ್ ಮಾಧ್ಯಮ ಗ್ರಂಥಾಲಯದಂತೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ, ಅಂದರೆ ನೀನು ಇಂಟರ್ನೆಟ್ ಸಂಪರ್ಕವನ್ನು ಹೊಂದಿಲ್ಲದಿದ್ದರೂ ಸಹ, ನೀನು ಈ ನಟರಿಗೆ ಪ್ರವೇಶಿಸಬಹುದು.

**ಖಾಲಿ ವಸ್ತು**: ಖಾಲಿ ವಸ್ತುವನ್ನು ಸೇರಿಸಿ, ಅದು ಯಾವುದೇ ನೋಟವನ್ನು ಹೊಂದಿಲ್ಲದ ವಸ್ತುವಾಗಿದೆ. ನೀನು ಈ ವಸ್ತುವನ್ನು ಸಾಮಾನ್ಯ ರೀತಿಯಲ್ಲಿ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದು.

**ಸಾಧನದಲ್ಲಿರುವ ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು**: ನಿನ್ನ ಯೋಜನೆಯಲ್ಲಿ ಮೊದಲ ನಟನನ್ನು ಮತ್ತು ಪಠ್ಯಕ್ರಮವನ್ನು ಸೇರಿಸಲು ಬಯಸುವ ಯೋಜನೆಯನ್ನು ಆಯ್ಕೆಮಾಡು.
