Pocket Code, Catrobat ನ ಮುಖ್ಯ ಆ್ಯಪ್. ಇದು ಉಚಿತ. ಇದರ ಮೂಲ ಕೋಡ್ ಎಲ್ಲರಿಗೂ ತೆರೆದಿದೆ. ನಿನ್ನ ಫೋನ್ ಅಥವಾ ಟ್ಯಾಬ್ಲೆಟ್‌ನಲ್ಲೇ ಆಟಗಳು, ಅನಿಮೇಷನ್‌ಗಳು ಮತ್ತು ನೀನು ಭಾಗವಹಿಸಬಹುದಾದ ಕಥೆಗಳನ್ನು ಮಾಡಬಹುದು. Pocket Code ನಲ್ಲಿ **ಬ್ಲಾಕ್‌ಗಳಿಂದ ಕೋಡ್ ಮಾಡುತ್ತೀಯ**. ಒಗಟಿನ ತುಂಡುಗಳನ್ನು ಜೋಡಿಸುವಂತೆ ಕೋಡ್ ಬ್ಲಾಕ್‌ಗಳನ್ನು ಜೋಡಿಸಿ ಯೋಜನೆ ಮಾಡು. ಮೊದಲೇ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಗೊತ್ತಿರಬೇಕಿಲ್ಲ. ಹೊಸದಾಗಿ ಕಲಿಯುವವರಿಗೂ ಇದು ಸುಲಭ!

Pocket Code ಕೇವಲ ಡಿಜಿಟಲ್ ಯೋಜನೆಗಳನ್ನು ಮೀರಿ ಹೋಗುತ್ತದೆ. ಹೊಸ **ಮೇಕರ್ಸ್ ಸ್ಪೇಸ್ ವೈಶಿಷ್ಟ್ಯಗಳು** ಜೊತೆಗೆ ನೀನು ವಿನ್ಯಾಸ **SVG ಕಡತಗಳನ್ನು ಕತ್ತರಿಸುವ ಪ್ಲಾಟರ್ಗಳಿಗೆ** ಮಾಡಬಹುದು. ಇದರರ್ಥ ನಿನ್ನ ಡಿಜಿಟಲ್ ಸೃಷ್ಟಿಗಳನ್ನು ನೈಜ ಜಗತ್ತಿನ ವಸ್ತುಗಳಾಗಿ ಪರಿವರ್ತಿಸಬಹುದು ಮತ್ತು ಪರದೆಯ ಆಚೆಗಿನ ಸೃಜನಶೀಲ ಸಾಧ್ಯತೆಗಳನ್ನು ಅನ್ವೇಷಿಸಬಹುದು.

ನೀನು ಕೋಡ್ ಮಾಡಲು ಕಲಿಯುತ್ತಿರಲಿ, ಹೊಸ ಆಲೋಚನೆಗಳನ್ನು ಪ್ರಯೋಗಿಸುತ್ತಿರಲಿ ಅಥವಾ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಕಲಿಸುತ್ತಿರಲಿ, Pocket Code ಕೋಡಿಂಗ್ನಲ್ಲಿ ಮುಳುಗಲು ಒಂದು ಆಟದ, ಪ್ರವೇಶಸಾಧ್ಯವಾದ ಮಾರ್ಗವನ್ನು ಒದಗಿಸುತ್ತದೆ
