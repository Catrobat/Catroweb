ತರಗತಿಯಲ್ಲಿ Pocket Code ಬಳಕೆ ಬಗ್ಗೆ ಶಿಕ್ಷಕರು ಮತ್ತು ವಿದ್ಯಾರ್ಥಿಗಳು ಏನು ಹೇಳುತ್ತಾರೆಂದು ನೋಡಿ.

::video{youtube=75i10o_uv0U}

ಈ ವೀಡಿಯೊವು Pocket Code ಅನ್ನು ಹೇಗೆ ಸೃಜನಶೀಲ ರೀತಿಯಲ್ಲಿ ಕಲಿಕೆಗೆ ಬಳಸಬಹುದು ಎಂಬುದರ ಕುರಿತು ನಮ್ಮ ವಿಧಾನವನ್ನು ತೋರಿಸುತ್ತದೆ. ಕಲಿಕೆಯ ಪರಿಸರದಲ್ಲಿ ಶಿಕ್ಷಕ ಮತ್ತು ವಿದ್ಯಾರ್ಥಿಗಳ ಕಾರ್ಯಗಳು ಯಾವುವು Pocket Code?
