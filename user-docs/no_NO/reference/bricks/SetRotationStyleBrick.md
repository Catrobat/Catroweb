![Sett rotasjonsmåte](../../../media/bricks/set_rotation_style_brick2.png)

Endrer hvordan objektet roterer (hele veien rundt, bare venstre–høyre, eller ikke roter). Det er som å bestemme om figuren din kan snu seg helt rundt, bare speile seg venstre og høyre, eller ikke rotere i det hele tatt.
