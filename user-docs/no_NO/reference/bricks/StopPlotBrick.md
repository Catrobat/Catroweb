![Slutt å plotte](../../../media/bricks/Stop_to_plot.png)

Klossen «Slutt å plotte» stanser plottingen og lar deg flytte figuren til en ny posisjon, eller fullføre plottingen. Det er som å løfte pennen fra papiret for å flytte den eller stoppe tegningen. Når du er ferdig med plottingen, kan du bruke klossen «Lagre plott som SVG» for å lagre tegningen som en SVG-fil.
