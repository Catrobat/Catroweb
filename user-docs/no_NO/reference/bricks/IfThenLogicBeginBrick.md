*Sjekker om et vilkår er sant, og hvis det er det, kjøres et sett med instruksjoner. Det er som å si: «Hvis dette er sant, gjør dette.»*

![Start scenen](../../../media/bricks/StartScene.png)

Når scenen starter, settes variabelen X til 0.

![Hvis](../../../media/bricks/If.png)

Hvis dyret nå trykkes på, økes variabelen X med 1.

Programmet sjekker om variabelen X er lik verdien 2.

Hvis dette stemmer, spilles lyden Tweet1 av, og variabelen X settes til 0.
