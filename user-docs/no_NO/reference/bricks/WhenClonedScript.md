![Når du starter som klon](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Gir en opprettet klon av et objekt instruksjoner om å utføre de ønskede handlingene. Denne fremgangsmåten gjør det mulig å kopiere funksjonene til det opprinnelige objektet, samtidig som klonen kan styres uavhengig. Ulike oppførsler eller egenskaper for klonen kan angis for å passe bestemte krav.
