![For hver verdi i listen](../../../media/bricks/for-each-value_brick.png)

Denne klossen kjører et sett med instruksjoner for hvert element i en liste eller et område. Det er som å gå gjennom hvert element ett for ett og gjøre det samme med hvert av dem.

Tenk deg at du har en liste med tall, farger eller andre ting. Med denne klossen kan du ta ett element om gangen fra listen og gjøre noe med det. Hvis du for eksempel har en liste med farger og vil endre bakgrunnsfargen til hver farge i listen, bruker du denne klossen.

Det er som å si: «For hvert element i denne gruppen, gjør disse instruksjonene.»
