Kjører skriptet når objektet blir trykket på.

Forskjellen fra klossen *«Når spilleflaten trykkes på»* er at *«Når du blir trykket på»* gjelder for enkeltstående figurer eller objekter, mens *«Når det trykkes på spilleflaten»* gjelder hele skjermen.
