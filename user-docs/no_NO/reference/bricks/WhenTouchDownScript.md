Kjører skriptet når skjermen berøres.

Forskjellen fra klossen *«Når du blir trykket på»* er at *«Når det trykkes på spilleflaten»* gjelder hele skjermen, mens *«Når du blir trykket på»* gjelder for enkeltstående figurer eller objekter.
