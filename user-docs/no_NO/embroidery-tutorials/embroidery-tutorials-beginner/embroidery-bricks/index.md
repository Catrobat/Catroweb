I denne veiledningen lærer du alt du trenger å vite om broderiklosser!

Du trenger ingen programmeringskunnskaper for dette.

Hver broderikloss forklares med et eksempel.

Hvis du ikke har aktivert broderiklossene ennå, kan du se på veiledningen **[Aktiver broderiklosser](../activate-embroidery-bricks.md)**.

*Her kan du laste ned veiledningen i PDF-format*:

[Broderiklosser](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Klikk på de ulike klossene for å finne ut mer om dem:**

[![Sting](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*Lar maskinen sy inn i stoffet én gang!*

[![Start forsting med lengde 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*Lar maskinen sy hele tiden med en variabel lengde.*

[![Start sikksakksting med lengde 2 og bredde 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Syr hele tiden med variabel lengde og bredde.*

[![Start trippelsting med lengde 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*Trippelstingen syr hvert sting tre ganger.*

[![Stopp gjeldende sting](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Lar det nåværende stinget stoppe.*

Du finner flere broderiklosser og informasjon om dem [her](../../../../reference/#category_embroidery).

For mer informasjon eller designforslag kan du se på de andre veiledningene!
