Trippelstingen syr hvert sting tre ganger.

Trippelstingen hopper tilbake etter det første stinget, syr, hopper så fremover igjen og syr på nytt.

![Start trippelsting med lengde 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Fungerer på samme måte som [forstinget](running-stitch.md).

![Trippelsting](../../../../media/embroidery-tutorials/TripleStitch.png)

Dette gjør at sømmen holder lenger.
