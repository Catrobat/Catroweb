I denne veiledningen lærer du hvordan du lagrer og deler de ferdige designene dine på mobilenheten.

For dette trenger du et ferdig broderidesign som du vil eksportere. Hvis du ikke har et ennå, kan du la deg inspirere av [broderiveiledningene](index.md) våre!

*Her kan du laste ned veiledningen i PDF-format*:

[Eksporter design](../../../media/embroidery-tutorials/Export-Designs.pdf)

### 1. Start prosjektet ditt, og vent til det er helt utfoldet. Ellers blir mønsteret ufullstendig.

### 2. Trykk på tilbake, og trykk deretter på delingsknappen.

![Eksporter design (1)](../../../media/embroidery-tutorials/Export-Designs-1.png)

### 3. Del broderifilen din via e-post, eller lagre den på telefonen.

![Eksporter design (2)](../../../media/embroidery-tutorials/Export-Designs-2.png)

Delingsfunksjonen kan se litt annerledes ut på hver telefon.

Broderidesignet ditt blir lagret som en DST-fil.

Broderimaskinen kjenner dette filformatet og fullfører designet ditt på stoffet.
