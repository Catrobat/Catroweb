Vil du være kreativ og samtidig lære koding på en lekende måte? Liker du også å lage ting som du kan bruke, ha på deg og beundre rett etterpå?

Med Embroidery Designer kan du, uten noen forkunnskaper, programmere en broderimaskin som automatisk broderer designet ditt på en T-skjorte, en veske, bukser, et smarttelefondeksel eller til og med skoene dine. Du kan brodere på alt som er laget av stoff. Slipp fantasien og kreativiteten løs! Du kan laste ned og redigere designene til andre fra Catrobat-fellesskapet. Selvfølgelig kan du også dele prosjektene dine med vennene dine og hele verden!
