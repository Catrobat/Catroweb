I denne veiledningen forklares det hvordan du aktiverer broderiklossene.

![Aktiver broderiklosser5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Du trenger ingen programmeringskunnskaper for dette. Det er det første steget i broderiveiledningene. Senere kan du designe, programmere og til og med brodere dine egne design på et favorittstykke tekstil.

For mer informasjon eller designforslag kan du se på de andre veiledningene.

*Her kan du laste ned veiledningen i PDF-format*:

[AktiverBroderiklosser](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Start appen «Pocket Code». Følg klikkene!

### 2. Åpne menyen (prikkene øverst til høyre).

![Aktiver broderiklosser](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Gå til «Innstillinger».

![Aktiver broderiklosser3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Velg «Broderiutvidelse».

![Aktiver broderiklosser4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Du finner broderiklossene som en egen kategori blant klossene dine!

[![Aktiver broderiklosser5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Nå finner du også alle broderiklossene blant de andre klossene.

For mer informasjon om hver kloss kan du se dokumentasjonen for klossene [her](../../../reference/) eller følge veiledningen **[Broderiklosser](embroidery-bricks/index.md)**.

Nå kan du komme i gang og lage dine egne design!

Hvis du trenger ideer eller hjelp med det, kan du se på de andre veiledningene eller fortsette med veiledningen **[Lag broderiobjekter](create-embroidery-objects.md)**.
