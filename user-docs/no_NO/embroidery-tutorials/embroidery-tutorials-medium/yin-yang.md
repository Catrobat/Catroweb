I denne veiledningen lærer du hvordan du broderer Yin og Yang (78,4 x 78,4 mm).

![Yin und Yang](../../../media/embroidery-tutorials/Yin-und-Yang.png)

Du bør allerede vite hva en løkke er, og hvordan den fungerer.

Veiledningen **[Sirkel](../embroidery-tutorials-beginner/circle.md)** kan være nyttig for denne veiledningen.

Se på broderiveiledningene i [nybegynnerserien](../embroidery-tutorials-beginner/index.md) hvis du ikke har brodert noe ennå.

For mer informasjon eller designforslag kan du se på de andre veiledningene.
