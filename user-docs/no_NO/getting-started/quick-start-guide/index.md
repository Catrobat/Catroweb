Pocket Code er en visuell programmeringsapp som lar deg lage spill, animasjoner og interaktive historier direkte på smarttelefonen eller nettbrettet ditt. Med et intuitivt grensesnitt der du drar og slipper «klosser» (kodeblokker), kan du lage prosjektene dine uten forkunnskaper i programmering. Legg enkelt til lyder, bilder og bevegelse for å gi ideene dine liv.

Denne guiden hjelper deg å komme i gang ved å forklare hvordan du:

- navigerer i grensesnittet,
- lager ditt første prosjekt,
- jobber med objekter og bakgrunner,
- bruker klosser for å programmere handlinger, og
- lagrer prosjektet ditt.

Pocket Code passer perfekt for nybegynnere og lærere, og den oppmuntrer til kreativitet, problemløsning og logisk tenkning.
