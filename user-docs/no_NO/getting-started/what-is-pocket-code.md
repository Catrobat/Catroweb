Pocket Code er Catrobats hovedapp, en gratis og åpen kildekode-basert mobilapp som lar deg lage spill, animasjoner og interaktive historier rett på smarttelefonen eller nettbrettet ditt. Med Pocket Codes **blokkbaserte kodesystem** lager du prosjekter ved å sette sammen kodeklosser, akkurat som å sette sammen biter i et puslespill. Du trenger ingen programmeringserfaring, så appen passer perfekt for nybegynnere!

Pocket Code er mer enn digitale prosjekter. Med nye **makerspace-funksjoner** kan du også designe **SVG-filer til skjæreplottere**. Da kan du gjøre de digitale skapelsene dine om til ting i den virkelige verden og utforske kreative muligheter utenfor skjermen.

Enten du lærer å kode, eksperimenterer med nye ideer eller underviser i programmering, gir Pocket Code deg en leken og lettfattelig måte å komme i gang med koding på.

[Mer informasjon](https://catrobat.org/pocket-code/)
