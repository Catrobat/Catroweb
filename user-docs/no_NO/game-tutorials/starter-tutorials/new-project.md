I denne veiledningen lærer du alt du trenger å vite om Pocket Code for å begynne å lage ditt første prosjekt. Vi viser deg steg for steg hvordan du laster ned appen, åpner den og lager et nytt prosjekt.

![Nytt program](../../../media/game-tutorials/New-Program.png)

Dette er den aller første veiledningen, og du trenger ingen forkunnskaper.

Så hva venter du på? Ta frem telefonen og kom i gang nå!

*Her kan du laste ned veiledningen i PDF-format:*

[Nytt program](../../../media/game-tutorials/New-Program.pdf)

### 1. Installere Pocket Code

Først må du installere Pocket Code-appen på enheten din. Du finner appen ved å søke etter «Pocket Code» i Google Play Butikk og laste den ned ved å trykke på «Installer». For dette trinnet kreves en Google-konto. Enheten din laster nå ned og installerer appen. Dette kan ta litt tid, avhengig av internettforbindelsen din.

![Nytt program (2)](../../../media/game-tutorials/New-Program-2.png)

Når Pocket Code er lastet ned og installert, finner du appen i app-oversikten eller på startskjermen, avhengig av enheten din. Du kan enkelt flytte appen til hvor du vil.

### 2. Start appen

Når du åpner appen, ser du ulike kategorier:

![Nytt program (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Lag et nytt prosjekt

Neste steg er å lage et nytt prosjekt. For å gjøre det trykker du på den gule pluss-knappen nederst til høyre. Nå må du skrive inn et prosjektnavn og velge om prosjektet skal være liggende eller ikke. Når du trykker på «OK», blir prosjektet laget.

![Nytt program](../../../media/game-tutorials/New-Program.png)

### 4. Du klarte det! Du lagde ditt eget nye prosjekt.

Nå har du installert Pocket Code og vet hvordan du lager et nytt prosjekt. Nå kan du begynne å programmere!

For å fortsette må du vite hvordan du lager et nytt objekt i et prosjekt. Se på veiledningen **[Nytt objekt](new-object.md)**, der alt er forklart steg for steg.
