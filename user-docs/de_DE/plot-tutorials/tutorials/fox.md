[Fuchs](../../../media/plot-tutorials/Fuchs.pdf)

Wenn der Plot startet, werden alle Bewegungen wie mit einem Malstift gezeichnet. Das sind die Linien, entlang derer der Plotter später schneidet.

Dieser Fuchs besteht nur aus geraden Linien (Verschiebe um \_\_\_ Schritte) und Drehungen.

**Tipp**: Teste dein Programm während des Erstellens.
