Wenn der Plot startet, werden alle Bewegungen wie mit einem Malstift gezeichnet. Das sind die Linien, entlang derer der Plotter später schneidet.

Unser Objekt zeigt in die Richtung 150 Grad.

Bei diesem Tutorial wird zuerst die rechte Seite des Katzenkopfes erstellt. Bei genauerem Betrachten sieht man, dass wir zuerst eine stärkere Krümmung haben, sich das Objekt also nach jeder kleinen Linie stärker drehen muss. Danach wird die Drehung beim unteren Teil des Katzenkopfes weniger. Die linke Seite des Katzenkopfes hat wieder eine stärkere Krümmung. Daher haben wir für diesen Teil des Kopfes insegsamt drei Schleifen.

Danach folgt das linke Katzenohr. Das besteht nur aus geraden Linien und wir können den Baustein “Verschiebe um \_\_ Schritte” verwenden.

Der Bereich zwischen den Ohren ist wieder ein Bogen und wird mit Hilfe einer weiteren Schleife programmiert.

Anschließend wird das rechte Katzenohr erstellt.

Der Plot ist nun fertig und wird mit dem Baustein “Plotten beenden” beendet und mit “Plot als SVG speichern \_\_\_” auf dem Smartphone gespeichert.

Das SVG File kann nun auf einen (Schneide-)Plotter übertragen werden.
