Speichere den Wert einer Variablen auf deinem Gerät, damit du ihn später verwenden kannst, auch nachdem du die App geschlossen hast. Es ist, als würdest du eine Notiz auf deinem Telefon hinterlassen, um dich später daran zu erinnern.
