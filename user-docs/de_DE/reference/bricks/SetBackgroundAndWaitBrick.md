Dieser Baustein legt einen neuen Hintergrund fest und wartet, bis die Änderung abgeschlossen ist, bevor das Skript fortgesetzt wird. Es ist, als würde man die Szenerie in einem Theaterstück ändern und darauf warten, dass die neue Szene vollständig aufgebaut ist.
