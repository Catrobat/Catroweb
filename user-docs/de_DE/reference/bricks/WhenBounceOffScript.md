Mit diesem Baustein wird das nachfolgende Skript ausgeführt, wenn das Objekt von einer bestimmten Oberfläche oder einem bestimmten Objekt abprallt. Es ist, als würdest du sagen: “Führe diese Aktion aus, wann immer mein Objekt/meine Figur von einer Wand oder einem anderen Objekt abprallt”.
