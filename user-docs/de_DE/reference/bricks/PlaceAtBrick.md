![Setze an Position](../../../media/bricks/Setze_an_Position_x_100___y_200_.png)

Bewegt das Objekt an eine bestimmte Position auf dem Bildschirm, die durch die x- und y-Koordinaten definiert ist. Es ist, als würdest du dein Charakter an einen genauen Ort teleportieren.

Die Position wird in einem Koordinatensystem festgelegt, das der kartesischen Ebene ähnelt: Die x- und y-Achsen verlaufen durch die Mitte des Bildschirms, x = 0 und y = 0 ist also die Mitte des Bildschirms.
