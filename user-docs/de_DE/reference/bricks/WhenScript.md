![Wenn angetippt](../../../media/bricks/Wenn_angetippt.png)

Führt das Skript aus, wenn **das Objekt** angetippt wird.

Der Unterschied zum Block “*Wenn der Bildschirm berührt wird*” ist, dass “*Wenn angetippt*” spezifisch für einzelne Figuren oder Objekte ist, während “*Wenn der Bildschirm berührt wird*” für den gesamten Bildschirm gilt.
