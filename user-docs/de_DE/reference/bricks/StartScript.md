![Wenn Szene startet](../../../media/bricks/Wenn_Szene_startet.png)

Wenn du diesen Block verwendest, startet das Skript sofort, wenn die Szene beginnt. Eine Szene ist der Anfang deines Programms. Eine Szene ist eine neue Ansicht in deinem Programm, in der andere Elemente angezeigt werden können und verschiedene Interaktionen stattfinden können. Du kannst mehrere Szenen für verschiedene Phasen deines Programms haben. Zum Beispiel eine Szene für das Intro, eine Szene für das Hauptmenü, eine für die erste Ebene, eine für die zweite Ebene und so weiter. Bei einfacheren Programmen kann auch eine einzige Szene genügen, dann ist der Anfang deines Programms auch der Anfang der Szene.
