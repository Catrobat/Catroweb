![Setze Aufprallfaktor auf](../../../media/bricks/Setze_Aufprallfaktor_auf_80__pct_.png)

Regelt, wie stark der Gegenstand abprallt, wenn er auf etwas trifft. Ein höherer Prozentsatz bedeutet einen stärkeren Abprall. Es ist, als würdest du entscheiden, wie stark dein Charakter von Wänden oder anderen Objekten abprallt.
