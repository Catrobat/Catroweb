Pocket Code ist eine visuelle Programmier-App, mit der du Spiele, Animationen und interaktive Geschichten direkt auf deinem Smartphone oder Tablet erstellen kannst. Mit einer intuitiven Drag-and-Drop-Oberfläche mit “Bausteinen” (Codeblöcken) kannst du deine Projekte ohne vorherige Programmiererfahrung entwerfen. Füge einfach Sounds, Bilder und Bewegungen hinzu, um deine Ideen zum Leben zu erwecken.

In diesem Leitfaden erfährst du, wie man:

- durch die Benutzeroberfläche navigierst,
- dein erstes Projekt erstellst,
- mit Objekten, Figuren und Hintergründen arbeitest,
- Programmier-Blöcke verwendest, und
- dein Projekt speicherst.

Ideal für Anfänger, Lehrpersonen sowie Workshopleiter:innen fördert Pocket Code Kreativität, Problemlösung und logisches Denken.
