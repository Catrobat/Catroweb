Pocket Code ist die Haupt-App von Catrobat – eine kostenlose und quelloffene mobile Anwendung, mit der du direkt auf deinem Smartphone oder Tablet Spiele, Animationen und interaktive Geschichten erstellen kannst. Mit dem **blockbasierten Codierungssystem** von Pocket Code setzt du einzelne Code-Blöcke zusammen – wie Puzzleteile. Du benötigst keine Vorkenntnisse im Programmieren, was es ideal für Einsteiger\*innen macht!

Pocket Code geht über digitale Projekte hinaus. Mit den neuen **Makerspace-Funktionen** kannst du auch **DST-Dateien für Stickmaschinen** und **SVG-Dateien für Schneideplotter** entwerfen. So kannst du deine digitalen Kreationen in die reale Welt bringen und kreative Möglichkeiten jenseits des Bildschirms entdecken.

Ob du programmieren lernen, neue Ideen ausprobieren oder Programmieren unterrichten möchtest – Pocket Code bietet eine spielerische und zugängliche Möglichkeit, ins Coding einzutauchen.

[Mehr Informationen](https://catrobat.org/de/pocket-code-app/)
