Obre l'app al teu mòbil o tauleta.

![Pantalla principal i nou projecte](../../../media/getting-started/MainScreen_NewProject.png)\
Toca el símbol + per crear un projecte nou.\
[Obre la imatge](../../../media/getting-started/MainScreen_NewProject.png)

Dona un nom al projecte (1) i decideix si vols crear un joc en format vertical o horitzontal (2).

![Nou projecte](../../../media/getting-started/NewProject.png)\
Després confirma amb la marca de verificació (3).\
[Obre la imatge](../../../media/getting-started/NewProject.png)

Ara ets a la vista del projecte. A dalt veus el nom del teu joc.

A sota veus el **fons**. Ara mateix està buit. Si el vols canviar, toca'l.

Sota del fons veus l'àrea dels teus **actors i objectes**, els que hagis afegit al joc. De moment, l'àrea encara està buida.

A la part inferior dreta veus dos botons importants:

![Executa](../../../media/getting-started/Start.png)\
Amb el botó **Executa** comences el teu joc.

![Botó més](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Amb el botó **més** afegeixes un personatge o objecte nou al teu joc.

![Vista del projecte](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
Ara ets a la vista del projecte.\
[Obre la imatge](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
