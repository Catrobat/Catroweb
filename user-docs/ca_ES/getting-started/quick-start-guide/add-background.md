Pots afegir un fons al teu projecte de Catrobat.

Els fons es poden fer servir de moltes maneres. A Pocket Code, serveixen per millorar visualment els **jocs**, explicar **històries** o donar més context als teus actors i objectes.

Per als dispositius de fabricació digital, com les **traçadores** o les **brodadores**, els fons fan de plantilles de disseny, per exemple per a talls o patrons de brodat.

Per afegir un fons, toca «Fons» a la vista del projecte.

![Toca el fons](../../../media/getting-started/grafik-16.png)

A la **secció d'scripts (2)** pots programar el fons, però no tots els blocs estan disponibles. Aquests dos blocs són especialment importants: ![Estableix la transparència al 50 %](../../../media/bricks/Set_transparency_to_50_pct_.png) i ![Estableix la mida al 60 %](../../../media/bricks/Set_size_to_60_pct_.png)

A la **secció d'aparences (1)** afegeixes un fons. Per fer-ho, toca el símbol +.

![Afegeix un fons](../../../media/getting-started/grafik-14.png)

Pots pujar les teves pròpies imatges, fer servir fons predefinits o crear-ne un tu mateix.

**Dibuixa**: Pots crear el teu propi fons amb **Pocket Paint**. Pocket Paint és un programa de dibuix ([més informació sobre Pocket Paint](https://catrobat.org/docs/pocket-paint/))

**Aparences**: Tria-ne un de la col·lecció de fons preparats ([més informació sobre la biblioteca multimèdia](../elements/medialibrary.md)).

**Galeria**: Pots triar una imatge de la galeria del teu mòbil.

**Càmera**: Pots fer servir la càmera del teu dispositiu per fer una foto i afegir-la com a fons.

![Fons](../../../media/getting-started/grafik-17.png)

Ara ja has afegit un fons. Toca la fletxa enrere a dalt a la dreta per tornar a la **vista del projecte**.
