Pocket Code és una app de programació visual que et permet crear jocs, animacions i històries interactives directament al teu mòbil o tauleta. Amb una interfície intuïtiva d'arrossegar i deixar anar amb «blocs» (blocs de codi), pots dissenyar els teus projectes sense cap experiència prèvia en programació. Afegeix fàcilment sons, imatges i moviment per donar vida a les teves idees.

Aquesta guia t'ajudarà a començar explicant com:

- Navegar per la interfície,
- Crear el teu primer projecte,
- Treballar amb objectes i fons,
- Fer servir blocs per programar accions, i
- Desar el teu projecte.

Perfecta per a principiants i educadors, Pocket Code fomenta la creativitat, la resolució de problemes i el pensament lògic.
