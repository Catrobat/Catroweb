A Pocket Code pots afegir un personatge o un objecte al teu projecte de diverses maneres:

**Dibuixa**: Pots crear el teu propi personatge amb **Pocket Paint**. Pocket Paint és un programa de dibuix ([més informació sobre Pocket Paint](https://catrobat.org/pocket-paint/))

**Aparences**: Tria-ne un de la col·lecció d'actors i objectes preparats ([més informació sobre la biblioteca multimèdia](../elements/medialibrary.md)).

**Galeria**: Pots triar una imatge de la galeria del teu mòbil.

**Biblioteca**: A la biblioteca hi trobaràs actors i objectes que ja estan programats, és a dir, que ja tenen un script. Pots escollir-los si vols fer servir elements preparats al teu joc (per exemple, un compte enrere) ([més informació sobre la biblioteca](../elements/medialibrary.md#afegeix-un-objecte-des-de-la-biblioteca-multimèdia)).

**Càmera**: Pots fer servir la càmera del teu dispositiu per fer una foto i afegir-la com a personatge.

**Motxilla**: La motxilla està buida ara mateix. Pots reutilitzar actors o objectes que hagis desat a la motxilla. Amb ells es desempaqueta tot l'script ([més informació sobre la motxilla](../elements/backpack.md)).

**Actors i objectes locals**: Aquí trobaràs personatges preparats que pots fer servir al teu projecte. Els actors i objectes locals funcionen com una biblioteca multimèdia fora de línia, és a dir, que hi pots accedir encara que no tinguis connexió a internet.

**Objecte buit**: Afegeix un objecte buit, és a dir, un objecte que no té aparença. El pots programar amb normalitat.

**Projectes locals**: Selecciona un projecte del qual vols inserir el primer actor juntament amb el script al teu projecte.
