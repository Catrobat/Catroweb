Pocket Code és l'app principal de Catrobat, una app mòbil lliure i de codi obert que et permet crear jocs, animacions i històries interactives directament al teu mòbil o tauleta. Amb el **sistema de programació per blocs** de Pocket Code, pots construir projectes encaixant blocs de codi, com si juguessis amb les peces d'un trencaclosques. No cal experiència en programació, així que és perfecta per a principiants!

Pocket Code va més enllà dels projectes digitals. Amb les noves **funcions de fabricació digital**, també pots dissenyar fitxers **SVG per a traçadores de tall**. Així pots convertir les teves creacions digitals en objectes reals i explorar possibilitats creatives més enllà de la pantalla.

Tant si estàs aprenent a programar, experimentant amb noves idees o ensenyant programació, Pocket Code ofereix una manera divertida i accessible d'endinsar-te en la programació.

[Més informació](https://catrobat.org/pocket-code/)
