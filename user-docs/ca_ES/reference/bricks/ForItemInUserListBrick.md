![Per a cada valor d'una llista](../../../media/bricks/for-each-value_brick.png)

Aquest bloc executa un conjunt d'instruccions per a cada element d'una llista o d'un rang. És com anar-los recorrent un per un i fer la mateixa acció a cadascun.

Imagina que tens una llista de números, colors o qualsevol element. Aquest bloc et permet agafar cada element de la llista i fer-hi alguna cosa. Per exemple, si tens una llista de colors i vols canviar el color de fons per a cada color de la llista, fes servir aquest bloc.

És com dir: «Per a cada element d'aquest grup, fes aquestes instruccions».
