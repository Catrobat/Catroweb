![Espera fins que s'aturin tots els altres scripts](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Aquest bloc atura el script actual fins que acaben d'executar-se tots els altres scripts del projecte. Imagina que poses el teu script en espera fins que tot la resta hagi acabat. És útil per assegurar-te que no passa cap altra acció abans de continuar amb els passos següents del teu script actual.
