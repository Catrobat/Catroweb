![Estableix el color de partícula a '#ff0000'](../../../media/bricks/Set_particle_colour_to_ff0000.png)

Aquest bloc canvia el color de les partícules que emet l'actor. És com canviar el color del confeti d'un petard de festa.

Un codi de color hexadecimal és una manera de representar colors amb valors hexadecimals. Està format per sis caràcters, que poden ser números (0-9) o lletres (A-F). El codi s'escriu normalment amb un «#» al principi, així: `#RRGGBB`.

- Els dos primers caràcters (`RR`) representen el component vermell del color.
- Els dos següents (`GG`) representen el component verd.
- Els dos últims (`BB`) representen el component blau.

Cada parell de caràcters pot anar de `00` (que vol dir gens d'aquell color) a `FF` (que vol dir la quantitat màxima d'aquell color). Per exemple:

`#000000` és negre (sense color).

`#FF0000` és vermell pur.

`#00FF00` és verd pur.

`#0000FF` és blau pur.

`#FFFFFF` és blanc (el màxim de vermell, verd i blau).
