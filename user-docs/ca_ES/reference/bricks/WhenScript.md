Executa l'script quan es toca l'objecte.

La diferència amb el bloc *«Quan es toca l'escenari»* és que *«Quan es toca»* és específic de cada sprite o objecte individual, mentre que *«Quan es toca l'escenari»* s'aplica a tota la pantalla.
