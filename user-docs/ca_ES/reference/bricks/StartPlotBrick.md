![Comença a traçar](../../../media/bricks/Start_to_plot.png)

Aquest bloc comença el procés de traçat mentre l'actor es mou. És semblant a posar un llapis sobre el paper per començar a dibuixar una línia. Si vols aturar el dibuix i moure l'actor a un altre lloc, pots fer servir el bloc «Deixa de traçar» i després tornar a començar el traçat amb «Comença a traçar».
