![Quan comenci l'escena](../../../media/bricks/When_scene_starts_btn2.png)

Si fas servir aquest bloc, l'script començarà de seguida quan comenci l'escena. Una escena és el començament del teu programa. És una nova vista del teu programa on es poden mostrar altres elements i tenir lloc diferents interaccions. Pots tenir moltes escenes per a diferents fases del programa. Per exemple, una escena per a la introducció, una per al menú principal, una per al primer nivell, una per al segon nivell i així successivament. En programes més senzills, una sola escena també pot bastar; aleshores el començament del programa és també el començament de l'escena.

Com tots els scripts, aquest comença amb un bloc d'esdeveniment: l'esdeveniment defineix **quan** comença l'script, i els blocs que hi ha després diuen al programa **què** ha de fer.
