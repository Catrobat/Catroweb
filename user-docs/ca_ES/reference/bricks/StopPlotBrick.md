![Deixa de traçar](../../../media/bricks/Stop_to_plot.png)

El bloc «Deixa de traçar» atura el procés de traçat i et deixa moure l'actor a una posició nova o acabar el traçat. És com aixecar el llapis del paper per col·locar-lo en un altre lloc o per deixar de dibuixar. Quan acabis el traçat, pots fer servir el bloc «Desa el traçat com a SVG» per desar el teu disseny com a fitxer SVG.
