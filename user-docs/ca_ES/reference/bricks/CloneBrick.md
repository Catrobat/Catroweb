![Crea un clon de tu mateix](../../../media/bricks/create_clone_of_brick2.png)

Aquest bloc fa una còpia de l'objecte escollit, anomenada clon, que es comporta com l'original. Imagina que dupliques un personatge o un objecte del teu joc. El clon pot tenir els seus propis comportaments i scripts, i així pots crear diverses versions d'un objecte que actuen de manera independent.
