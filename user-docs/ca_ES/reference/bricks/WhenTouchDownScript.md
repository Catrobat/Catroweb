![Quan es toca l'escenari](../../../media/bricks/When_stage_is_tapped_btn.png)

Executa l'script quan es toca la pantalla.

La diferència amb el bloc *«Quan es toca»* és que *«Quan es toca l'escenari»* s'aplica a tota la pantalla, mentre que *«Quan es toca»* és específic de cada sprite o objecte individual.
