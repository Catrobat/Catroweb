![Activa la additivitat de l'efecte de partícules](../../../media/bricks/Turn_particle_effect_additivity_on.png)

Aquest bloc activa o desactiva el mode de barreja additiu de les partícules, que pot fer que es vegin més brillants i intenses. És com ajustar la brillantor i el resplendor de les espurnes.
