![Estableix el color del llapis a vermell 0, verd 0, blau 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Aquest bloc canvia el color del llapis que fa servir l'actor. És com canviar a un llapis de color diferent mentre dibuixes.

**Vermell, verd, blau (RGB)**: El model de color RGB fa servir diferents intensitats de llum vermella, verda i blava per crear un ampli espectre de colors. Cada component de color (vermell, verd i blau) pot tenir un valor entre 0 i 255:

- **Vermell**: El component vermell del color. Un valor més alt vol dir més vermell.
- **Verd**: El component verd del color. Un valor més alt vol dir més verd.
- **Blau**: El component blau del color. Un valor més alt vol dir més blau.

Combinant diferents valors de vermell, verd i blau, pots crear qualsevol color. Per exemple:

- `RGB(255, 0, 0)` és vermell pur.
- `RGB(0, 255, 0)` és verd pur.
- `RGB(0, 0, 255)` és blau pur.
- `RGB(255, 255, 255)` és blanc (el màxim de vermell, verd i blau).
- `RGB(0, 0, 0)` és negre (sense color).

Barrejar aquests colors en quantitats diferents crea tots els colors que veus a les pantalles digitals.
