En aquest tutorial aprendràs a compartir els teus projectes amb els amics o amb tota la comunitat de Catrobat.

![Pujar i compartir](../../../media/game-tutorials/Upload-and-Share.png)\
En aquest tutorial aprendràs a compartir els teus projectes amb els amics o amb tota la comunitat de Catrobat.\
[Obre la imatge](../../../media/game-tutorials/Upload-and-Share.png)

Per a aquest tutorial, ja has de tenir un projecte propi que vulguis compartir. Si encara no saps crear un projecte, mira el tutorial **[Projecte nou](new-project.md)** per aprendre com funciona.

*Aquí pots descarregar el tutorial en format PDF:*

[Obre el PDF](../../../media/game-tutorials/Upload-and-Share.pdf)

### 1. Opcions del projecte

![Pujar i compartir](../../../media/game-tutorials/Upload-and-Share.png)\
Si vols pujar o compartir el teu projecte, has d'obrir el projecte, tocar els tres punts de la cantonada superior dreta i després tocar «Opcions del projecte».\
[Obre la imatge](../../../media/game-tutorials/Upload-and-Share.png)

### 2. Opcions del projecte

Ara pots canviar el nom, afegir una descripció i fer diverses configuracions.

![Pujar i compartir (1)](../../../media/game-tutorials/Upload-and-Share-1.png)\
També tens dues opcions: «Puja el projecte» i «Exporta el projecte», que s'expliquen en els passos següents.\
[Obre la imatge](../../../media/game-tutorials/Upload-and-Share-1.png)

### 3. Puja el projecte

Si vols pujar el teu projecte a Catrobat Share, perquè tota la comunitat hi tingui accés, tria *Puja el projecte*.

### 4. Puja el projecte

Si fas clic en aquest botó per pujar el teu projecte a Share, has de registrar-te per crear un compte, si encara no ho has fet. També pots iniciar sessió amb Google. Quan hagis iniciat la sessió, has de posar un nom al projecte i escriure'n una descripció. Després has de triar fins a tres categories a les quals pertanyi millor el teu programa.

![Pujar i compartir (2)](../../../media/game-tutorials/Upload-and-Share-2.png)\
Després toca «següent» per pujar el teu programa.\
[Obre la imatge](../../../media/game-tutorials/Upload-and-Share-2.png)

### 5. Exporta el projecte

Si vols compartir el teu projecte amb els amics, tria *Exporta el projecte*.

### 6. Exporta el projecte

Amb aquest botó pots desar un fitxer .catrobat que pots compartir en privat amb els teus amics.

![Pujar i compartir (3)](../../../media/game-tutorials/Upload-and-Share-3.png)\
El pots desar al gestor de fitxers del teu dispositiu i compartir-lo d'aquesta manera.\
[Obre la imatge](../../../media/game-tutorials/Upload-and-Share-3.png)

Ho has aconseguit! Has compartit el teu primer programa!

Si necessites ajuda o inspiració per als projectes que vindran, no dubtis a mirar els nostres tutorials de diferents nivells (Principiant/Mitjà/Pro).
