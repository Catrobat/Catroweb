### 1. Instal·lació de Pocket Code

Primer, has d'instal·lar l'app Pocket Code al teu dispositiu. Per a aquest pas cal un compte de Google. Ara el teu dispositiu descarregarà i instal·larà l'app. Aquest pas pot trigar una mica, depenent de la teva connexió a internet.

![Programa nou (2)](../../../media/game-tutorials/New-Program-2.png)\
Pots trobar l'app buscant «Pocket Code» a Google Play Store i descarregar-la tocant «Instal·la».\
[Obre la imatge](../../../media/game-tutorials/New-Program-2.png)

Després de descarregar i instal·lar Pocket Code amb èxit, trobaràs l'app al calaix d'aplicacions o a la pantalla d'inici, segons el teu dispositiu. Pots moure l'app fàcilment al lloc que vulguis.

### 2. Obre l'app

![Programa nou (1)](../../../media/game-tutorials/New-Program-1.png)\
Quan obris l'app, veuràs diferents categories.\
[Obre la imatge](../../../media/game-tutorials/New-Program-1.png)

### 3. Crea un projecte nou

El següent pas és crear un projecte nou. Ara has d'escriure un nom de projecte i seleccionar si vols que el projecte sigui horitzontal o no. Tocant «D'acord», el projecte es crea.

![Programa nou](../../../media/game-tutorials/New-Program.png)\
Per fer-ho, pots prémer el botó groc més de la cantonada inferior dreta.\
[Obre la imatge](../../../media/game-tutorials/New-Program.png)

### 4. Ho has aconseguit! Has creat el teu projecte nou.

Ara ja has instal·lat Pocket Code i saps crear un projecte nou. Ara pots començar a programar!

Per fer-ho, cal que sàpigues crear un objecte nou en un projecte. Mira el tutorial **[Objecte nou](new-object.md)**, on s'explica tot pas a pas.
