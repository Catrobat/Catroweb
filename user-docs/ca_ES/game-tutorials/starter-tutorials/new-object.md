En aquest tutorial aprendràs a crear un objecte nou al teu projecte i les diferents possibilitats que tens per fer-ho.

![Objecte nou](../../../media/game-tutorials/New-Object.png)

Per fer-ho, ja hauries d'haver descarregat l'app Pocket Code i saber crear un projecte nou. Si necessites ajuda amb això, mira el tutorial **[Projecte nou](new-project.md)**.

*Aquí pots descarregar el tutorial en format PDF:*

[Objecte nou](../../../media/game-tutorials/New-Object.pdf)

### 1. Crea un objecte nou

Primer, has d'obrir el teu projecte nou.

El trobaràs a la pantalla principal de l'app Pocket Code. Si tens més d'un projecte, pots tocar «Projects on device». Després selecciona el teu projecte nou. Si encara no has creat un projecte nou o necessites més informació per fer-ho, mira el tutorial **[Projecte nou](new-project.md)**.

### 2. Crea un objecte nou

Ara ja pots crear un objecte nou. Per fer-ho, toca el botó groc més de la cantonada inferior dreta. Veuràs una finestra nova amb set possibilitats per escollir.

![Objecte nou (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. Maneres de crear

Aquestes són les possibilitats que pots escollir:

![Objecte nou (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. Dibuixa una imatge

Per fer-ho el més fàcil possible al principi, volem fer servir la funció «Dibuixa» i només dibuixar un punt. Quan hagis dibuixat el punt amb Pocket Paint, pots sortir-ne (tornant un pas enrere).

### 5. Dona-li un nom

Ara has de posar un nom a la teva imatge.

### 6. Col·loca-la

Després has de col·locar-la visualment movent-la a l'esquerra, a la dreta, amunt o avall amb el dit. Has de desar-la amb el botó de la cantonada superior dreta.

![Objecte nou (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. Ho has aconseguit! Has creat el teu objecte nou.

Ara tens un projecte amb un objecte que pots programar!

Per fer-ho, cal que sàpigues quins blocs hi ha disponibles. El tutorial **[Primers blocs](first-bricks.md)** et dona una bona visió general de les diferents categories de blocs. Tot i això, també pots començar directament amb el teu primer projecte. Tria un tutorial adequat de la sèrie Principiant.
