En aquest tutorial s'explica com activar els blocs de brodat.

![Activa els blocs de brodat 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

No cal que sàpigues programar per fer-ho. Aquest és el primer pas per començar els tutorials de brodat. Més endavant podràs dissenyar, programar i fins i tot brodar els teus propis dissenys sobre la teva peça de tela preferida.

Per a més informació o suggeriments de disseny, mira els altres tutorials.

*Aquí pots descarregar el tutorial en format PDF*:

[ActivateEmbroideryBricks](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Obre l'app «Pocket Code». Segueix els clics!

### 2. Obre el menú (els punts de la cantonada superior dreta).

![Activa els blocs de brodat](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Ves a «Configuració».

![Activa els blocs de brodat 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Selecciona «Extensió de brodat».

![Activa els blocs de brodat 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Trobaràs els blocs de brodat com a categoria pròpia dins dels teus blocs!

[![Activa els blocs de brodat 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Ara també trobaràs tots els blocs de brodat entre la resta de blocs.

Per a més informació sobre cada bloc, pots consultar la documentació dels blocs [aquí](../../../reference/) o seguir el tutorial **[Blocs de brodat](embroidery-bricks/index.md)**.

Ara pots començar i crear els teus propis dissenys!

Si necessites idees o ajuda, mira els altres tutorials o continua amb el tutorial **[Crea objectes de brodat](create-embroidery-objects.md)**.
