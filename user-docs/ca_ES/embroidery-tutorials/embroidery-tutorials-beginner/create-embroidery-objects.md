En aquest tutorial aprendràs a crear objectes amb els quals després podràs brodar els teus patrons.

Per a aquest tutorial, ja hauries de saber crear un projecte. Si necessites ajuda, mira els tutorials de la [sèrie d'inici](../../game-tutorials/starter-tutorials/index.md).

Per a més informació o suggeriments de disseny, no dubtis a mirar els altres tutorials.

*Aquí pots descarregar el tutorial en format PDF*:

[Crea objectes de brodat](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Toca el botó més de la part inferior dreta del teu projecte per afegir un objecte nou.

![Crea objectes de brodat](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Per seleccionar una imatge, ves a la biblioteca multimèdia.

![Crea objectes de brodat (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Un objecte de brodat representa un nivell de l'agulla de la brodadora. Diversos objectes de brodat es brodaran un darrere l'altre. Això permet fer servir diversos colors.

Pots escollir el teu objecte segons el color que vulguis.

Desplaça't cap avall i busca la fletxa adequada.

![Crea objectes de brodat (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Posa al teu objecte nou un nom adequat i prem D'acord.

![Crea objectes de brodat (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Ara ja has creat un objecte nou. Ara pots afegir-hi un script i programar-lo.

![Crea objectes de brodat (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Ara ja saps crear un objecte. Afegeix un objecte nou per a cada color que vulguis fer servir.

Pots afegir un script a cada color i programar els teus propis dissenys, i fins i tot brodar-los més tard.

Necessites inspiració o ajuda? Mira els nostres altres tutorials!
