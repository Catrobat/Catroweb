Deixa que la màquina cusi de manera constant amb una longitud variable.

Normalment, combines el punt de passada amb un bloc de moviment.

![Punt de passada de longitud 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

La màquina comença un punt de passada que cosirà cada **10 passos**.

Després la màquina es mou **200 passos**.

Això dóna com a resultat **20 punts**.

![Punt de passada](../../../../media/embroidery-tutorials/RunningStitch.png)

El punt de passada facilita cosir una costura, perquè ja no necessites un bucle.
