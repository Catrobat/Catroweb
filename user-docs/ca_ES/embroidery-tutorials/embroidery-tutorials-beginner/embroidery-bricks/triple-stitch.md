El triple punt cus cada puntada tres vegades.

El triple punt retrocedeix després de la primera puntada, cus, després torna a avançar i torna a cosir.

![Triple punt de longitud 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Funciona igual que el [punt de passada](running-stitch.md).

![Triple punt](../../../../media/embroidery-tutorials/TripleStitch.png)

Això fa que la costura duri més.
