Deixa que el punt actual s'aturi.

Necessitaràs aquest bloc si vols canviar la posició de l'agulla després de començar un punt de passada, un punt en zigzag o un triple punt.

![Atura el punt actual](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

Si no, es produiria una costura intermèdia no desitjada.

![Atura el punt actual](../../../../media/embroidery-tutorials/StopCurrentStitch.png)
