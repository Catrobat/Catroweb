[Guineu (PDF, en alemany)](../../../media/plot-tutorials/Fuchs.pdf)

Quan comenci el traçat, cada moviment es dibuixa com si fos amb un llapis. Aquestes són les línies que la traçadora tallarà després.

Aquesta guineu està feta només de línies rectes («Mou-te \_\_\_ passos») i girs.

**Consell**: Prova el teu programa mentre el construeixes.
