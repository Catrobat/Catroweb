Quan comenci el traçat, cada moviment es dibuixa com si fos amb un llapis. Aquestes són les línies que la traçadora tallarà després.

Aquesta flor té 7 pètals. Cada pètal és un arc: dibuixes una línia petita, gires, dibuixes una altra línia petita i tornes a girar (mira el bucle «Repeteix 10 vegades» – «Mou-te 10 passos» – «Gira a la dreta 16 graus»).

Abans que comenci el pètal següent, has de girar una vegada més.
