Ta blok nadaljuje sceno tam, kjer je bila ustavljena. Če je bila tvoja scena prekinjena s premorom ali čakanjem, bo ta blok nadaljeval dejanje natanko tam, kjer je ostalo.

Predstavljaj si, da si ustavil igro ali animacijo, zdaj pa želiš, da se nadaljuje. Ta blok deluje kot gumb „predvajaj“ in vse spet steče od točke, kjer je bilo ustavljeno.
