![Če-sicer blok](../../../media/bricks/if_else_brick2.png)

*Preveri, ali je pogoj resničen, in izvede en niz navodil, če je, ter drugega, če ni. Je kot da daš dve možnosti: „Če je to res, naredi to; sicer naredi tole.“*

![Začetek scene](../../../media/bricks/StartScene.png)

Ko se scena začne, se spremenljivka X nastavi na 0.

![Če-sicer](../../../media/bricks/IfElse.png)

Če se žival zdaj tapne, se preveri, ali je X modulo 2 resničen, to je, ali je X liho število.

Če je tako, se predvaja zvok Tweet1 in spremenljivka X se poveča za 1.

Sicer, če je X sodo, se poveča samo X.

Navodila, ki se izvedejo, so ločena z blokom Konec, če.
