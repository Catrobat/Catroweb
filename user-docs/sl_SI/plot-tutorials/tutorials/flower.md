[Cvet (PDF, nemško)](../../../media/plot-tutorials/Blume.pdf)

Ko se risanje začne, je vsak premik narisan, kot da bi risal s peresom. To so črte, po katerih bo ploter pozneje rezal.

Ta cvet ima 7 listov. Vsak list je lok: narišeš majhno črto, se obrneš, narišeš še eno majhno črto in se spet obrneš (poglej zanko „Ponovi 10-krat“ – „Premakni se za 10 korakov“ – „Obrni se desno za 16 stopinj“).

Preden se začne naslednji list, se moraš še enkrat obrniti.
