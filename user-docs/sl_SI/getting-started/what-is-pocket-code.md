Pocket Code je glavna aplikacija Catrobat, brezplačna in odprtokodna mobilna aplikacija, s katero lahko ustvarjaš igre, animacije in interaktivne zgodbe kar na svojem pametnem telefonu ali tablici. S **sistemom programiranja z bloki** Pocket Code sestavljaš projekte tako, da skupaj spenjaš kodne bloke – kot bi sestavljal koščke sestavljanke. Programerskega znanja ne potrebuješ, zato je idealen za začetnike!

Pocket Code gre onkraj digitalnih projektov. Z novimi **funkcijami za delavnice** lahko oblikuješ tudi **datoteke SVG za rezalne ploterje**. To pomeni, da lahko svoje digitalne stvaritve spremeniš v prave predmete in raziskuješ ustvarjalne možnosti onkraj zaslona.

Ne glede na to, ali se učiš programirati, preizkušaš nove ideje ali poučuješ programiranje, ti Pocket Code ponuja igriv in dostopen način, da se potopiš v programiranje.

[Več informacij](https://catrobat.org/pocket-code/)
