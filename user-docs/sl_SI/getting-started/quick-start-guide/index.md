Pocket Code je aplikacija z vizualnim programiranjem, s katero lahko ustvarjaš igre, animacije in interaktivne zgodbe neposredno na svojem pametnem telefonu ali tablici. Z intuitivnim vmesnikom za povlečenje in spuščanje „blokov“ (kodnih blokov) lahko oblikuješ svoje projekte, tudi če še nimaš izkušenj s programiranjem. Preprosto dodaš zvoke, slike in gibanje ter svoje ideje oživiš.

Ta vodnik ti bo pomagal začeti, tako da ti bo razložil, kako:

- se znajdeš v vmesniku,
- ustvariš svoj prvi projekt,
- delaš s predmeti in ozadji,
- z bloki programiraš dejanja in
- shraniš svoj projekt.

Pocket Code je idealen za začetnike in učitelje ter spodbuja ustvarjalnost, reševanje problemov in logično razmišljanje.
