Trigubas dygsnis kiekvieną dygsnį susiuva tris kartus.

Trigubas dygsnis po pirmojo dygsnio atšoka atgal, susiuva, tada vėl atšoka į priekį ir siuva dar kartą.

![Pradėti trigubą dygsnį, kurio ilgis 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Veikia taip pat kaip [tiesus dygsnis](running-stitch.md).

![Trigubas dygsnis](../../../../media/embroidery-tutorials/TripleStitch.png)

Tai padaro siūlę ilgiau išliekančią.
