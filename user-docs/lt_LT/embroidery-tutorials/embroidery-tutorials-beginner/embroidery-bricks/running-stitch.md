Leidžia mašinai nuolat siūti keičiamo ilgio dygsniais.

Paprastai tiesų dygsnį derini su bloku „Judėti“.

![Pradėti tiesų dygsnį, kurio ilgis 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Mašina pradeda tiesų dygsnį, kuris siuvinėja kas **10 žingsnių**.

Tada mašina pajuda **200 žingsnių**.

Tai duoda **20 dygsnių**.

![Tiesus dygsnis](../../../../media/embroidery-tutorials/RunningStitch.png)

Tiesus dygsnis palengvina siuvinėjimą, nes nebereikia ciklo.

![image](../../../../media/embroidery-tutorials/image.png)
