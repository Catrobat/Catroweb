Blokas „Baigti braižyti“ sustabdo braižymo procesą ir leidžia perkelti veikėją į naują vietą arba užbaigti braižymą. Tai kaip pakelti pieštuką nuo popieriaus, kad jį perdėtum ar nustotum piešti. Baigęs braižyti, gali naudoti bloką „Išsaugoti brėžinį kaip SVG“, kad išsaugotum savo piešinį SVG faile.
