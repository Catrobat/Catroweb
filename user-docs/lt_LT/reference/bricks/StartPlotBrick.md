![Pradėti braižyti](../../../media/bricks/Start_to_plot.png)

Šis blokas pradeda braižymo procesą, kai veikėjas juda. Tai panašu į pieštuko padėjimą ant popieriaus, kad pradėtum brėžti liniją. Jei nori sustabdyti piešimą, perkelti veikėją į kitą vietą ir vėl pradėti braižyti, naudok bloką „Baigti braižyti“, o po to – „Pradėti braižyti“.
