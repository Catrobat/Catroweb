![Padėti ties x: y:](../../../media/bricks/place_at_x_y_brick.png)

Perkelia objektą į konkrečią vietą ekrane, nurodytą x ir y koordinatėmis. Tai kaip akimirksniu nuteleportuoti veikėją į tikslią vietą.

Pozicija nustatoma koordinačių sistemoje, panašioje į Dekarto plokštumą: x ir y ašys eina per ekrano centrą, todėl x = 0 ir y = 0 yra ekrano vidurys.
