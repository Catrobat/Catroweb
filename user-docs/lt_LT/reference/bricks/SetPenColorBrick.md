![Nustatyti pieštuko spalvą į „raudona 0, žalia 0, mėlyna 255“](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Šis blokas pakeičia veikėjo pieštuko spalvą. Tai kaip piešiant perjungti į kitos spalvos pieštuką.

**Raudona, žalia, mėlyna (RGB)**: RGB spalvų modelis naudoja skirtingą raudonos, žalios ir mėlynos šviesos intensyvumą, kad sukurtų platų spalvų spektrą. Kiekviena spalvos dalis (raudona, žalia ir mėlyna) gali turėti reikšmę nuo 0 iki 255:

- **Raudona**: raudonoji spalvos dalis. Didesnė reikšmė reiškia daugiau raudonos.
- **Žalia**: žalioji spalvos dalis. Didesnė reikšmė reiškia daugiau žalios.
- **Mėlyna**: mėlynoji spalvos dalis. Didesnė reikšmė reiškia daugiau mėlynos.

Derindamas skirtingas raudonos, žalios ir mėlynos reikšmes, gali sukurti bet kokią spalvą. Pavyzdžiui:

- `RGB(255, 0, 0)` yra grynai raudona.
- `RGB(0, 255, 0)` yra grynai žalia.
- `RGB(0, 0, 255)` yra grynai mėlyna.
- `RGB(255, 255, 255)` yra balta (didžiausias raudonos, žalios ir mėlynos kiekis).
- `RGB(0, 0, 0)` yra juoda (spalvos nėra).

Maišydami šias spalvas skirtingais kiekiais, sukuriate visas spalvas, kurias matote skaitmeniniuose ekranuose.
