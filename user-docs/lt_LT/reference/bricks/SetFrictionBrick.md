Reguliuoja objekto trintį, kuri lemia, kaip lengvai jis slysta ar sulėtėja. Tai kaip pakeisti paviršiaus, ant kurio stovi tavo veikėjas, slidumą: kuo didesnė trintis, tuo mažiau slysta.
