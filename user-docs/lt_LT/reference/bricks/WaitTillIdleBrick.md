![Laukti, kol visi kiti scenarijai sustos](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Šis blokas sustabdo dabartinį scenarijų, kol visi kiti projekto scenarijai baigs veikti. Įsivaizduok, kad savo scenarijų padedi į laukimo eilę, kol viskas kita baigsis. Tai naudinga, kad prieš atliekant kitus veiksmus dabartiniame scenarijuje nevyktų jokie kiti veiksmai.
