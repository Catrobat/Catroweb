![Jei, tada / kitaip](../../../media/bricks/if_else_brick2.png)

*Patikrina, ar sąlyga teisinga. Jei taip, vykdo vieną instrukcijų rinkinį, o jei ne, – kitą. Tai kaip duoti du pasirinkimus: „Jei tai teisinga, daryk tai, kitaip daryk kita.“*

![Scenos pradžia](../../../media/bricks/StartScene.png)

Kai prasideda scena, kintamasis X nustatomas į 0.

![Jei / kitaip](../../../media/bricks/IfElse.png)

Jei gyvūnas dabar paliečiamas, patikrinama, ar X modulis 2 yra teisingas, t. y. ar X yra nelyginis skaičius.

Jei taip, paleidžiamas garsas Tweet1 ir kintamasis X padidinamas 1.

Kitaip, jei X lyginis, X tiesiog padidinamas 1.

Vykdomi teiginiai atskiriami blokui *Sąlygos pabaiga*.
