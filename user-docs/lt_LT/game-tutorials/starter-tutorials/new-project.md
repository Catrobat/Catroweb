Šioje pamokoje sužinosi viską, ko reikia žinoti apie Pocket Code, kad pradėtum kurti savo pirmąjį projektą. Žingsnis po žingsnio parodysime, kaip atsisiųsti programėlę, ją atidaryti ir sukurti naują projektą.

![Nauja programa](../../../media/game-tutorials/New-Program.png)\
Žingsnis po žingsnio parodysime, kaip atsisiųsti programėlę, ją atidaryti ir sukurti naują projektą.\
[Atverk paveikslėlį](../../../media/game-tutorials/New-Program.png)

Tai pirmoji pamoka, todėl jokių ankstesnių žinių nereikia.

Tad ko laukti? Paimk telefoną ir pradėk dabar!

*Čia gali atsisiųsti pamoką PDF formatu:*

[Atverk PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code įdiegimas

Pirmiausia turi įdiegti Pocket Code programėlę savo įrenginyje. Šiam žingsniui reikalinga Google paskyra. Dabar įrenginys atsisiųs ir įdiegs programėlę. Tam gali užtrukti, priklausomai nuo tavo interneto ryšio.

![Nauja programa (2)](../../../media/game-tutorials/New-Program-2.png)\
Programėlę rasi Google Play parduotuvėje ieškodamas „Pocket Code“ ir ją atsisiųsi paspaudęs „Įdiegti“.\
[Atverk paveikslėlį](../../../media/game-tutorials/New-Program-2.png)

Sėkmingai atsisiuntus ir įdiegus Pocket Code, programėlę rasi programų meniu arba pradiniame ekrane, priklausomai nuo įrenginio. Programėlę gali perkelti ten, kur tau patogu.

### 2. Programėlės paleidimas

![Nauja programa (1)](../../../media/game-tutorials/New-Program-1.png)\
Kai atidarai programėlę, matai įvairias kategorijas.\
[Atverk paveikslėlį](../../../media/game-tutorials/New-Program-1.png)

### 3. Sukurk naują projektą

Kitas žingsnis – sukurti naują projektą. Dabar turi įvesti projekto pavadinimą ir pasirinkti, ar projektas bus horizontalus, ar ne. Paspaudus „OK“, projektas sukuriamas.

![Nauja programa](../../../media/game-tutorials/New-Program.png)\
Tam paspausk geltoną pliuso mygtuką apatiniame dešiniajame kampe.\
[Atverk paveikslėlį](../../../media/game-tutorials/New-Program.png)

### 4. Pavyko! Tu sukūrei savo naują projektą.

Dabar įdiegei Pocket Code ir žinai, kaip sukurti naują projektą. Dabar gali pradėti programuoti!

Norint tai padaryti, reikia žinoti, kaip sukurti naują objektą projekte. Pažvelk į pamoką **[Naujas objektas](new-object.md)**, kurioje viskas paaiškinta žingsnis po žingsnio.
