Nori sukurti savo braižinį? Mūsų pamokos padės naudojant blokus iškirpti nupieštas linijas braižymo staklėmis. Išmok metodus ir įrankius, kurie padės su tikslumu ir kūrybiškumu įgyvendinti tavo dizainus.
