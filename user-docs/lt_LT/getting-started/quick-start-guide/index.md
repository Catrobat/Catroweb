Pocket Code yra vaizdinė programavimo programėlė, leidžianti kurti žaidimus, animacijas ir interaktyvias istorijas tiesiai išmaniajame telefone ar planšetėje. Naudodamas intuityvią tempimo ir padėjimo sąsają su „blokeliais“ (kodo blokais), gali kurti projektus be jokios programavimo patirties. Lengvai pridėk garsus, paveikslėlius ir judesį, kad savo idėjos atgytų.

Šiame vadove sužinosi, kaip:

- naršyti sąsają,
- sukurti pirmąjį projektą,
- dirbti su veikėjais, objektais ir fonais,
- naudoti blokus veiksmams programuoti ir
- išsaugoti savo projektą.

Pocket Code puikiai tinka pradedantiesiems ir mokytojams – ji skatina kūrybiškumą, problemų sprendimą ir loginį mąstymą.
