Pocket Code yra pagrindinė Catrobat programėlė – nemokama programėlė su atviru kodu, kuri leidžia kurti žaidimus, animacijas ir interaktyvias istorijas tiesiai išmaniajame telefone ar planšetėje. Naudodamas Pocket Code **blokais grįstą programavimo sistemą** gali kurti projektus sujungdamas kodo blokus – tarsi dėliodamas dėlionės dalis. Programavimo patirties nereikia, todėl programėlė puikiai tinka pradedantiesiems!

Pocket Code išeina ir už skaitmeninių projektų ribų. Su naujomis **gamybos dirbtuvių** (angl. makerspace) funkcijomis gali kurti **SVG failus braižymo staklėms**. Tai reiškia, kad gali paversti savo skaitmenines kūrybos darbus realiais daiktais ir atrasti kūrybinių galimybių už ekrano ribų.

Ar mokaisi programuoti, bandai naujas idėjas, ar moki kitus programuoti, Pocket Code suteikia žaismingą ir prieinamą būdą pasinerti į programavimą.

[Daugiau informacijos](https://catrobat.org/pocket-code/)
