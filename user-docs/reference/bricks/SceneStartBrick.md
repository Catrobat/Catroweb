This brick switches to a different scene in your project and begins running that scene from the beginning. It’s like changing the chapter in a book or moving to the next level in a game.

Imagine you have multiple scenes in your project, each representing a different part of your story or game. Using this brick, you can jump to any scene and start it from the very start, creating a smooth transition between different parts of your project.
