![place_at_x_y_brick](../../media/bricks/place_at_x_y_brick.png)

Moves the object to a specific position on the screen, defined by the x and y coordinates. It’s like teleporting your character to an exact spot.

The position is set in a coordinate system like the Cartesian plane: the x and y axes run through the center of the screen, so x = 0 and y = 0 is the middle of the screen.
