Pocket Code je glavna aplikacija projekta Catrobat. Besplatna je i ima otvoren izvorni kod. Uz nju možeš praviti igre, animacije i interaktivne priče na telefonu ili tabletu. Pocket Code ima **sistem za programiranje pomoću blokova**. Spoji blokove koda kao dijelove slagalice da napraviš projekat. Ne treba ti iskustvo u programiranju. Možeš početi odmah!

Pocket Code ide izvan samo digitalnih projekata. Sa novim **funkcije makerspace** možeš i dizajnirati **SVG datoteke za rezanje plantera**. To znači da možeš preuzeti svoje digitalne kreacije u stvarne stvari i istražiti kreativne mogućnosti izvan ekrana.

Bilo da ste uče kodiranje, eksperimentiraju sa novim idejama ili predaju programiranja, Pocket Code pruža igrački, pristupačan način za ronjenje u kodiranje

[Više informacija](https://catrobat.org/pocket-code/)
