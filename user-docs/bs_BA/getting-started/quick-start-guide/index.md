Pocket Code je aplikacija za vizualno programiranje koja vam omogućava da kreirate igre, animacije i interaktivne priče direktno na smartfonu ili tabletu. Koristeći intuitivni interfejs povlačenja i odlazanja sa „blokovi koda“ (blokovi koda), možeš dizajnirati svoje projekte bez prethodnog iskustva u programiranju. Jednostavno dodati zvukove, slike i pokrete kako bi tvoje ideje bile u životu.

Ovaj vodič će vam pomoći da počnete sa ovim:

- -Navigirajte interfejsom
- Kreiraj svoj prvi projekat,
- Rad sa predmeti i pozadini,
- Koristite blokove koda za programiranje akcija, i
- Sačuvaj svoj projekat.

Savršen za početnike i nastavnike, Pocket Code potiče kreativnost, rešavanje problema i logično razmišljanje.
