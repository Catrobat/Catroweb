![Kada počneš kao klon](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Usmjeravanje kreirane klone objekta sa uputstvima za obavljanje željenih akcija. Ovaj proces omogućava replikaciju funkcionalnosti prvobitnog objekta, dok samostalno kontrolira klon. Različita ponašanja ili svojstva klonog objekta mogu se odrediti kako bi se zadovoljile specifične zahteve.
