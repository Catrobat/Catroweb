![ako je drugačije blokiranje koda](../../../media/bricks/if_else_brick2.png)

*Proverava je li uslov tačan, i pokreće jedan skup instrukcija ako jeste, a drugi set ako nije: „Ako je ovo istina, uradi ovo; ako nije tako, uradi to.“*

![Pokreni scenu](../../../media/bricks/StartScene.png)

Kada scena počne, promjenljiva X je postavljena na 0.

![Ako je druga](../../../media/bricks/IfElse.png)

Ako je životinja sada napunjena, proverava se da li je X modulo 2 tačan, odnosno da li je X parni broj.

Ako je to slučaj, svira se zvuk Tweet1 i promjenljiva X se povećava za 1.

Inače, ako je X ravnina, samo je X povećao za 1.

Izjavljivanja koje se izvršavaju odvojene su po Kraj uslova.
