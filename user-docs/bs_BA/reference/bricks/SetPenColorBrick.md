Ovaj blok koda menja boju olovke koju koristi glumac. To je kao prebacivanje na pen u drugom boju dok crteš.

**Crvena, Zelenica, Plava (RGB)**: Model boja RGB koristi različite intenzitete crvene, zelene i plave svjetlosti za stvaranje širokog spektra boja. Svaka komponenta boje (crvena, zelena i plava) može imati vrijednost između 0 i 255:

- **Crvena**: Crvena komponenta boje. Viša vrijednost znači više crvene.
- **Zelena**: Zelena komponenta boje. Viša vrednost znači više zelene.
- **Plava**: Plava komponenta boje. Viša vrijednost znači više plave.

Kombinujući različite vrijednosti za crvenu, zelenu i plavu boju, možeš stvoriti bilo koju boju. Na primer:

- `RGB(255, 0, 0)` je čista crvena.
- `RGB(0, 255, 0)` je čisto zeleno.
- `RGB(0, 0, 255)` je čisto plavo.
- `RGB(255, 255, 255)` je bela (maksimalno crvena, zelena i plava).
- `RGB(0, 0, 0)` je crna (bez boje).

Miješajući te boje u različitim količinama stvara sve boje koje vidite na digitalnim ekrana.
