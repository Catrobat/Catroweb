omogućava mašini da se stalno šiva sa promenljivom dužinom.

Obično kombinuješ šav sa blokom za pokretanje.

![Počni ravni bod dužine 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Mašina pokreće radnu šivku koja će se šiti svaki **10 koraka**.

Onda se mašina kreće **200 koraka**.

To rezultira **20 šavova**.

![Počni ravni bod dužine](../../../../media/embroidery-tutorials/RunningStitch.png)

Koristeći šav će lakše šaviti šav jer više nećete trebati petlje.
