U ovom nastavku, naučit ćeš sve što treba da znate o Pocket Code kako biste počeli sa kreiranjem svog prvog projekta. Mi ćemo vam voditi korak po korak kako preuzeti aplikaciju, otvoriti je i kreirati novi projekat.

![Novi program](../../../media/game-tutorials/New-Program.png)

Ovo je prvi tutorial i ne treba ti prethodno znanje.

Pa, šta čekaš? Uzmite telefon i krenite!

*Ovde možeš preuzeti tutorijal u PDF-formatu:*

[Novi program](../../../media/game-tutorials/New-Program.pdf)

### 1. Instalacija Pocket Code

Prvo, morate instalirati aplikaciju Pocket Code na uređaj. Aplikaciju možeš pronaći tražeći „Pocket Code“ u Google Play Store i preuzeti ga udarajući „instalirati“. Za ovaj korak je potreban Google nalog. Sada će tvoj uređaj preuzeti i instalirati aplikaciju. Ovaj korak može potrajati u zavisnosti od tvoje internet veze.

![Novi program (2)](../../../media/game-tutorials/New-Program-2.png)

Nakon uspješnog preuzimanja i instalacije Pocket Code aplikaciju možeš pronaći u ladici aplikacija ili na početnom ekranu, zavisno od uređaja. Možeš lako uzeti aplikaciju i staviti je bilo gde želiš.

### 2. Pokrenite aplikaciju

Kada otvori aplikaciju, vidite različite kategorije:

![Novi program (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Kreirajte novi projekat

Sledeći korak je stvaranje novog projekta. Da biste to uradili, možeš pritisnuti žuti plus dugme u donjem desnom uglu. Sad morate da unesete ime projekta i izaberete da li tvoj projekat treba da bude pejzaž ili ne. Tiskom na „OK“ se projekat kreira.

![Novi program](../../../media/game-tutorials/New-Program.png)

### 4. Napravila si svoj novi projekat.

Sada ste instalirali Pocket Code i znate kako kreirati novi projekat. Sada možeš da počneš sa programiranjem!

Da bi to uradili, morate znati kako da kreirate novi objekat u projektu. Pogledajte u nastavku **[Novi objekat](new-object.md)** - gdje vam sve objašnjava korak po korak.
