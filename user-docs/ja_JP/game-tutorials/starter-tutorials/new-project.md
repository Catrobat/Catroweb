このチュートリアルでは、最初のプロジェクトを作り始めるために、Pocket Code について知っておきたいことを、すべて学べます。アプリのダウンロード、開き方、新しいプロジェクトの作り方を、1 つずつ案内します。

![新しいプログラム](../../../media/game-tutorials/New-Program.png)\
アプリのダウンロード、開き方、新しいプロジェクトの作り方を、1 つずつ案内します。\
[画像を開く](../../../media/game-tutorials/New-Program.png)

これは最初のチュートリアルなので、前に何か知っている必要はありません。

さあ、何を待っているのでしょう？ スマホを手に取って、今すぐ始めましょう！

*このチュートリアルは、PDF 形式でダウンロードできます:*

[PDFを開く](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code をインストールする

はじめに、機器に Pocket Code アプリをインストールします。 「インストール」をタップすると、ダウンロードできます。 この手順には Google アカウントが必要です。 それから、機器がアプリをダウンロードして、インストールします。 インターネットの速さによっては、少し時間がかかります。

![新しいプログラム (2)](../../../media/game-tutorials/New-Program-2.png)\
Google Play ストアで「Pocket Code」を検索すると、アプリが見つかります。\
[画像を開く](../../../media/game-tutorials/New-Program-2.png)

Pocket Code のダウンロードとインストールが終わると、機器によって、アプリ一覧やホーム画面にアプリが見つかります。アプリは、好きな場所に動かせます。

### 2. アプリを開く

![新しいプログラム (1)](../../../media/game-tutorials/New-Program-1.png)\
アプリを開くと、いくつかのカテゴリーが見えます.\
[画像を開く](../../../media/game-tutorials/New-Program-1.png)

### 3. 新しいプロジェクトを作る

次のステップは、実際に新しいプロジェクトを作ることです。 そして、プロジェクトの名前を入力し、横向きにするかどうかを選びます。 「OK」をおすと、プロジェクトができます。

![新しいプログラム](../../../media/game-tutorials/New-Program.png)\
そのためには、右下の黄色い「+」ボタンをおします。\
[画像を開く](../../../media/game-tutorials/New-Program.png)

### 4. できました！ 自分の新しいプロジェクトを作れました。

これで、Pocket Code をインストールして、新しいプロジェクトを作る方法がわかりました。プログラムを始められます！

そのためには、プロジェクトに新しいオブジェクトを作る方法を知っておく必要があります。**[新しいオブジェクト](new-object.md)**のチュートリアルで、1つずつ全部説明されています。
