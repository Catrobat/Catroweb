このチュートリアルでは、オブジェクトをプログラムするためのいろいろなブロックが、どこにあるかを学びます。また、ブロックのカテゴリーの、よい全体像もわかります。

ブロックを入れて、オブジェクトをプログラムするには、オブジェクトのあるプロジェクトを、もう作っている必要があります。やり方がわからないときは、**[新しいオブジェクト](new-object.md)**のチュートリアルを見てください。

*このチュートリアルは、PDF 形式でダウンロードできます:*

[最初のブロック](../../../media/game-tutorials/First-Bricks.pdf)

### 1. 今あるオブジェクトを開く

まず、プロジェクトを開く必要があります。オブジェクトは、もう作ってあるはずです（まだなら、**[新しいオブジェクト](new-object.md)**のチュートリアルを見てください）。オブジェクトの名前をタップしましょう。

### 2. 今あるブロック

すると、もうブロックがいくつか入っているのが見えます。これらのブロックは、オブジェクトを見た目の位置に置いたときに、自動で作られたものです。

これらのブロックは、シーンが始まったときに、オブジェクトを最初に選んだ正確な位置に置くだけのものです。この位置は、いつでもここで変えられます。

::brick{type=StartScript}

::brick{type=PlaceAtBrick}

### 3. ブロックを入れる

次に、右下の黄色い「+」ボタンをタップすると、新しいブロックを作れます。ブロックのカテゴリーがいくつか出てくる、新しい画面が開きます。カテゴリーは次のステップで説明します。

![最初のブロック (1)](../../../media/game-tutorials/First-Bricks-1.png)

### 4. ブロックのカテゴリー

ブロックのカテゴリーは、次のとおりです:

![最初のブロック (2)](../../../media/game-tutorials/First-Bricks-2.png)

### 5. 最初のブロックを入れる

最初のブロックには、「1 秒で x: y: の位置へ滑らかに動かす」ブロックを使いましょう。動きのカテゴリーにあります。数式エディターで、秒数と、位置の x と y を変えられます。

::brick{type=GlideToBrick}

### 6. ブロックを置く

ブロックを、プログラムの一番最後の位置に置いて、初めてプログラムを動かしてみましょう。黄色い再生ボタンで動かせます。

![最初のブロック (3)](../../../media/game-tutorials/First-Bricks-3.png)

### 7. できました！ 最初のブロックを入れられました。

これで、最初のオブジェクトをプログラムできました！

プロジェクトを友だちと共有したいときは、**[アップロードと共有](upload-and-share.md)**のチュートリアルを見てください。使い方が、くわしく説明されています。そうでなければ、すぐに自分の最初のプロジェクトを始められます。助けやヒントがほしいときは、初級シリーズのチュートリアルを見てください。

すべてのブロックについては、[ここ](../../../reference/)でくわしい情報が見られます！
