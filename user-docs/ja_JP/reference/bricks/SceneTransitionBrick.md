![「シーンを続ける」のブロック](../../../media/bricks/continue_scene_brick2.png)

このブロックは、止まっていたシーンを、止まったところから続けます。待ち時間や一時停止でシーンが止まっていたときは、このブロックを使うと、止まったところからすぐに動きが続きます。

ゲームやアニメーションを一時停止して、また動かしたいとします。このブロックは「再生」ボタンのように働いて、止まったところから、すべてを再び動かします。
