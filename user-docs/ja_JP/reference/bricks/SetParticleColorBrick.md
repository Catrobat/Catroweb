![「粒の色を #ff0000 に設定」のブロック](../../../media/bricks/Set_particle_colour_to_ff0000.png)

このブロックは、オブジェクトから出る粒の色を変えます。パーティーのクラッカーから出る紙吹雪の色を変えるようなものです。

16 進数のカラーコードは、16 進数の値を使って色を表す方法です。6 文字でできていて、数字（0〜9）や文字（A〜F）が使われます。ふつう、先頭に「#」を付けて、`#RRGGBB` のように書きます。

- 最初の 2 文字（`RR`）は、赤の強さを表します。
- 次の 2 文字（`GG`）は、緑の強さを表します。
- 最後の 2 文字（`BB`）は、青の強さを表します。

2 文字のそれぞれは、`00`（その色がまったくない）から `FF`（その色が最大）までの値をとります。例えば、次のようになります。

`#000000` は黒（色がない）です。

`#FF0000` は、あざやかな赤です。

`#00FF00` は、あざやかな緑です。

`#0000FF` は、あざやかな青です。

`#FFFFFF` は白（赤、緑、青が最大）です。
