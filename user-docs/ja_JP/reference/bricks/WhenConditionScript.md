![「条件が真になったとき」のブロック](../../../media/bricks/when_brick3.png)

*決めた値や式が真になるまで待ってから、スクリプトを実行します。*

![シーンのスタートのブロック](../../../media/bricks/StartScene.png)

シーンが始まると、変数 X が 0 になります。

![タップされたら・2 で割った余りのブロック](../../../media/bricks/WhenTappedWhenModulo.png)

動物がタップされると、X が 1 増えます。

X を 2 で割った余りが真になると、つまり X が奇数になると、音 Tweet1 が鳴ります。
