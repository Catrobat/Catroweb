![「プロットを止める」のブロック](../../../media/bricks/Stop_to_plot.png)

「プロットを止める」ブロックは、プロットを一時停止して、オブジェクトを新しい位置に動かしたり、プロットを終わらせたりできるようにします。紙からペンを持ち上げて、置きなおしたり、描くのをやめたりするようなものです。プロットが終わったら、「プロットを SVG で保存」ブロックで、デザインを SVG ファイルとして保存できます。
