![「もし 真なら」のブロック](../../../media/bricks/if_brick2.png)

*条件が正しいかどうかを調べて、正しければ決めた動きを実行します。「これが正しければ、こうする」と言っているようなものです。*

![シーンのスタートのブロック](../../../media/bricks/StartScene.png)

シーンが始まると、変数 X が 0 になります。

![もしのブロック](../../../media/bricks/If.png)

動物がタップされると、変数 X が 1 増えます。

プログラムは、変数 X が 2 と同じかどうかを調べます。

そうなら、音 Tweet1 を鳴らして、変数 X を 0 にします。
