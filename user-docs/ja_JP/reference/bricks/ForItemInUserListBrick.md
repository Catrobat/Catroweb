![「リストの項目ごとに」のブロック](../../../media/bricks/for-each-value_brick.png)

このブロックは、リストや範囲の中の項目を、1つずつ順番に使って動きを実行します。1つずつ順番に見ていき、それぞれに同じことをするようなものです。

たとえば、色のリストがあるとします。背景の色を、リストの色に1つずつ変えたいとき、このブロックを使います。

「この中の項目ごとに、この動きをする」と言っているようなものです。
