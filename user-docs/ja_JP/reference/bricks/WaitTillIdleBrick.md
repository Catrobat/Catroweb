![「ほかのすべてのスクリプトが止まるまで待つ」のブロック](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

このブロックは、プロジェクトのほかのすべてのスクリプトが動き終わるまで、今のスクリプトを止めます。ほかのことがすべて終わるまで、スクリプトを待たせるようなものです。次の動きに進む前に、ほかの動きが起きていないことをたしかめたいときに役立ちます。
