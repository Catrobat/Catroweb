![「横 0% 縦 0% の自由さで注目の点になる」のブロック](../../../media/bricks/Become_focus_point_with_0_pct__horizontal_and__0_pct__vertical_flexibility_.png)

このブロックは、オブジェクトを、横と縦の決めた自由さで、画面の注目の点にします。カメラがキャラクターについていき、真ん中の周りを少しだけ動けるようにするようなものです。
