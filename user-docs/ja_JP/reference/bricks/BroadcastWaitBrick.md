![「メッセージを送って待つ」のブロック](../../../media/bricks/brodcast_wait_brick3.png)

プロジェクトのほかの部分にメッセージを送ります。そして、その部分が終わるまで待ってから次に進みます。友だちに頼んで、終わるまで待つようなものです。

**どうしてメッセージを送るの？**

メッセージを使うと、シーンの中の違うオブジェクトどうしが話したり、いっしょに動いたりできます。1つのオブジェクトが、ほかのすべてのオブジェクトにメッセージを送れます。受け取ったオブジェクトは、そのメッセージに合わせて動けます。

このメッセージは画面に**表示されません**。文字を表示したいときは、「見た目」のカテゴリーのブロックを使いましょう。

**どうやって動くの？**

- *送るオブジェクト:* 送るオブジェクトは「メッセージを送る」ブロックを使って、話し始めます。このブロックは、シーンのほかのすべてのオブジェクト（背景も含む）にメッセージを送ります。
- *受け取るオブジェクト:* 受け取るオブジェクトは、メッセージを待って、それに答えます。「メッセージを受け取ったとき」ブロックで、特定のメッセージが届いたことがわかります。
- *メッセージの処理:* 受け取るオブジェクトがメッセージを受け取ると、「メッセージを受け取ったとき」ブロックの下にあるブロックを、すべて実行します。こうして、メッセージを受け取ったときにする動きを決められます。
