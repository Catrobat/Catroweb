![「x: 0 y: 0 の位置を設定」のブロック](../../../media/bricks/place_at_x_y_brick.png)

オブジェクトを、画面の決めた位置に動かします。位置は x と y の座標で決まります。座標は数学の平面のようになっていて、x の軸と y の軸が画面の真ん中を通ります。そのため、x = 0、y = 0 が画面の真ん中になります。キャラクターを、ぴったりの場所にテレポートさせるようなものです。
