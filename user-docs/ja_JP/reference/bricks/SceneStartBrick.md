![「シーンを始める」のブロック](../../../media/bricks/start_scene_brick2.png)

このブロックは、プロジェクトのほかのシーンに切り替えて、そのシーンを最初から始めます。本の章を変えたり、ゲームのつぎのステージに進んだりするようなものです。

プロジェクトに、物語やゲームのそれぞれ違う場面を表すシーンがたくさんあるとします。このブロックを使うと、どのシーンにもジャンプして、最初から始められます。プロジェクトの場面を、なめらかにつなげられます。
