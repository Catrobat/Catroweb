![「ペンの色を 赤 0 緑 0 青 255 に設定」のブロック](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

このブロックは、オブジェクトが使うペンの色を変えます。絵を描いている途中で、ちがう色のペンに持ち替えるようなものです。

**赤・緑・青（RGB）**: RGB の色は、赤、緑、青の光の強さを組み合わせて、たくさんの色を作ります。赤、緑、青のそれぞれの値は、0 から 255 までです。

- **赤**: 色の赤の部分です。値が大きいほど、赤くなります。
- **緑**: 色の緑の部分です。値が大きいほど、緑になります。
- **青**: 色の青の部分です。値が大きいほど、青くなります。

赤、緑、青の値をいろいろ組み合わせると、どんな色でも作れます。例えば、次のようになります。

- `RGB(255, 0, 0)` は、あざやかな赤です。
- `RGB(0, 255, 0)` は、あざやかな緑です。
- `RGB(0, 0, 255)` は、あざやかな青です。
- `RGB(255, 255, 255)` は白（赤、緑、青が最大）です。
- `RGB(0, 0, 0)` は黒（色がない）です。

この 3 つの色を、いろいろな量で混ぜると、デジタルの画面に出るすべての色ができます。
