![「シーンが始まったとき」のブロック](../../../media/bricks/When_scene_starts_btn2.png)

このブロックを使うと、シーンが始まったときに、スクリプトがすぐに動き始めます。シーンは、プログラムの始まりです。シーンは、ほかの要素を表示して、いろいろなやりとりができる新しい画面です。プログラムには、場面ごとにいくつものシーンを作れます。例えば、導入のシーン、メインメニューのシーン、1 つ目のステージのシーン、2 つ目のステージのシーンなどです。簡単なプログラムなら、シーンは1つだけでも十分です。そのときは、プログラムの始まりが、そのままシーンの始まりになります。

どのスクリプトも、イベントのブロックから始まります。イベントは**いつ**スクリプトが始まるかを決め、そのあとのブロックは**何を**するかをプログラムに伝えます。
