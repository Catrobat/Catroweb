![「もし 真なら でなければ」のブロック](../../../media/bricks/if_else_brick2.png)

*条件が正しいかどうかを調べます。正しければ1つ目の動きを、正しくなければ2つ目の動きを実行します。「これが正しければこうして、そうでなければあっちをする」と、2つの選択肢を用意するようなものです。*

![シーンのスタートのブロック](../../../media/bricks/StartScene.png)

シーンが始まると、変数 X が 0 になります。

![もし・でなければのブロック](../../../media/bricks/IfElse.png)

動物がタップされたら、X を 2 で割った余りが 1 かどうか、つまり X が奇数かどうかを調べます。

そうなら、音 Tweet1 を鳴らして、変数 X を 1 増やします。

そうでなければ、X は偶数なので、X を 1 増やすだけです。

実行する動きは、「もしの終わり」で区切ります。
