このチュートリアルでは、できあがったデザインを、スマホに保存して共有する方法を学びます。

そのためには、書き出したい、できあがった刺繍のデザインが必要です。まだないときは、[刺繍チュートリアル](index.md)でアイデアを見つけてみましょう！

*このチュートリアルは、PDF 形式でダウンロードできます*:

[デザインを書き出す](../../../media/embroidery-tutorials/Export-Designs.pdf)

### 1. プロジェクトを始めて、全部ひろがるまで待ちます。そうしないと、模様が不完全になります。

### 2. 戻るをタップして、共有ボタンをおします。

![デザインを書き出す (1)](../../../media/embroidery-tutorials/Export-Designs-1.png)

### 3. 刺繍のファイルを、メールで共有するか、スマホに保存します。

![デザインを書き出す (2)](../../../media/embroidery-tutorials/Export-Designs-2.png)

共有の機能は、スマホによって少し見た目がちがうことがあります。

刺繍のデザインは、DST ファイルとして保存されます。

刺繍マシンはこのファイル形式を知っていて、布の上にデザインを刺繍します。
