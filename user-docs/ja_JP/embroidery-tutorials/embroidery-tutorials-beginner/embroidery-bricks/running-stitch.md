長さを変えられる、つづいた縫い目を、マシンに刺繍させます。

ふつう、ランニングステッチは、移動ブロックといっしょに使います。

![ランニングステッチを始める 長さ 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

マシンは、**10 歩**ごとに縫う、ランニングステッチを始めます。

それから、マシンは **200 歩**動きます。

こうして、**20 針**の縫い目ができます。

![ランニングステッチ](../../../../media/embroidery-tutorials/RunningStitch.png)

ランニングステッチがあると、もうくり返しがいらないので、縫い目を作るのがかんたんになります。

![画像](../../../../media/embroidery-tutorials/image.png)
