長さと幅を変えられる、つづいたジグザグの縫い目を作ります。

「ジグザグ」の模様で縫います。

![ジグザグステッチを始める 長さ 2 幅 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

長さと幅の値をいろいろ変えて、このブロックに慣れましょう。

![ジグザグステッチ](../../../../media/embroidery-tutorials/ZigzagStitch.png)

ジグザグステッチでは、太い縫い目を作れます。
