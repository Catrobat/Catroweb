今の縫い目を止めます。

ランニングステッチ、ジグザグステッチ、トリプルステッチを始めたあとに、針の位置を変えたいときは、このブロックが必要です。

![今のステッチを止める](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

そうしないと、いらない縫い目ができてしまいます。

![今のステッチを止める](../../../../media/embroidery-tutorials/StopCurrentStitch.png)
