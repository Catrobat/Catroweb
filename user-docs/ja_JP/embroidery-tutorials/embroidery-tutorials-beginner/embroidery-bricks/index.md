このチュートリアルでは、刺繍ブロックについて知っておきたいことを、すべて学べます！

プログラムの知識はいりません。

それぞれの刺繍ブロックを、例を使って説明します。

刺繍ブロックをまだ有効にしていないときは、**[刺繍ブロックを有効にする](../activate-embroidery-bricks.md)**のチュートリアルを見てください。

*このチュートリアルは、PDF 形式でダウンロードできます*:

[刺繍ブロック](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**ブロックをタップすると、くわしく知れます:**

[![ステッチ](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*針を布に1回だけ刺します！*

[![ランニングステッチを始める 長さ 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*長さを変えられる、つづいた縫い目を作ります。*

[![ジグザグステッチを始める 長さ 2 幅 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*長さと幅を変えられる、つづいたジグザグの縫い目を作ります。*

[![トリプルステッチを始める 長さ 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*トリプルステッチは、それぞれの縫い目を3回ずつ縫います。*

[![今のステッチを止める](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*今の縫い目を止めます。*

ほかの刺繍ブロックやくわしい情報は、[ここ](../../../../reference/#category_embroidery)にあります。

くわしい情報や、デザインのアイデアは、ほかのチュートリアルも見てください！
