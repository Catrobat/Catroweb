トリプルステッチは、それぞれの縫い目を3回ずつ縫います。

トリプルステッチは、最初の縫い目のあとに後ろへ戻り、縫ってから、また前に戻ってもう一度縫います。

![トリプルステッチを始める 長さ 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

[ランニングステッチ](running-stitch.md)と同じように働きます。

![トリプルステッチ](../../../../media/embroidery-tutorials/TripleStitch.png)

こうすると、縫い目が長持ちします。
