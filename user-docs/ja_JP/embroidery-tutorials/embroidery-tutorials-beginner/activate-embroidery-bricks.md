このチュートリアルでは、刺繍ブロックを有効にする方法を説明します。

![刺繍ブロックを有効にする 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

このチュートリアルに、プログラムの知識はいりません。これは、刺繍チュートリアルを始めるための最初のステップです。あとで、自分のデザインを作ったり、プログラムしたり、お気に入りの布に刺繍したりできるようになります。

くわしい情報や、デザインのアイデアは、ほかのチュートリアルを見てください。

*このチュートリアルは、PDF 形式でダウンロードできます*:

[刺繍ブロックを有効にする](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Pocket Code のアプリを開きます。順番にタップしてください！

### 2. メニューを開きます（右上の点々）。

![刺繍ブロックを有効にする](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. 「設定」に進みます。

![刺繍ブロックを有効にする 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. 「刺繍拡張機能」を選びます。

![刺繍ブロックを有効にする 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. 刺繍ブロックは、ブロックの中に、自分だけのカテゴリーとして出てきます！

[![刺繍ブロックを有効にする 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

これで、刺繍ブロックも、ほかのブロックといっしょに見つかります。

それぞれのブロックについてくわしく知りたいときは、ブロックの説明を[ここ](../../../reference/)で見てください。または、**[刺繍ブロック](embroidery-bricks/index.md)**のチュートリアルを見ましょう。

さあ、始めて、自分だけのデザインを作りましょう！

アイデアやヒントがほしいときは、ほかのチュートリアルを見るか、**[刺繍オブジェクトを作る](create-embroidery-objects.md)**のチュートリアルに進みましょう。
