このチュートリアルでは、あとで模様を刺繍するためのオブジェクトの作り方を学びます。

このチュートリアルの前に、プロジェクトの作り方がわかっている必要があります。わからないときは、[入門シリーズ](../../game-tutorials/starter-tutorials/index.md)を見てください。

くわしい情報や、デザインのアイデアは、ほかのチュートリアルを見てください。

*このチュートリアルは、PDF 形式でダウンロードできます*:

[刺繍オブジェクトを作る](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. プロジェクトの右下にある「+」ボタンをタップして、新しいオブジェクトを追加します。

![刺繍オブジェクトを作る](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. 画像を選ぶには、メディアライブラリに行きます。

![刺繍オブジェクトを作る (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. 刺繍オブジェクトは、刺繍マシンの針の1つの段を表します。いくつかの刺繍オブジェクトが、順番に刺繍されます。そのため、いろいろな色を使えます。

ほしい色に合わせて、オブジェクトを選びましょう。

下にスクロールして、ぴったりの矢印を探します。

![刺繍オブジェクトを作る (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. 新しいオブジェクトに、ぴったりの名前を付けて、「OK」をタップします。

![刺繍オブジェクトを作る (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. 新しいオブジェクトができました。スクリプトを追加して、オブジェクトをプログラムできます。

![刺繍オブジェクトを作る (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

これで、オブジェクトの作り方がわかりました。使いたい色ごとに、新しいオブジェクトを追加しましょう。

それぞれの色でスクリプトを追加して、自分だけのデザインを作れます。あとで刺繍することもできます。
