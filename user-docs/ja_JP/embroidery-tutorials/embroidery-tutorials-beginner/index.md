創造的になりながら、楽しく遊ぶようにプログラミングを学びたいですか？ 作ったものを、すぐに使ったり、身につけたり、眺めたりしたいですか？

Embroidery Designer を使えば、経験がなくても、刺繍マシンをプログラムできます。マシンは、あなたのデザインを、Tシャツ、バッグ、ズボン、スマホケース、くつなどに、自動で刺繍してくれます。布でできたものなら、どれにでも刺繍できます。想像力と創造力を、自由に発揮しましょう！ Catrobat コミュニティには、ほかの人のデザインがあり、ダウンロードして編集できます。もちろん、あなたのプロジェクトを、友だちや世界中の人と共有することもできます！
