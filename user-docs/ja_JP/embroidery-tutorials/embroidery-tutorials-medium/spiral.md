このチュートリアルでは、うずまきを刺繍する方法を学びます（103.9 x 116.6 mm）。

![画像 (14)](../../../media/embroidery-tutorials/image-14.png)

ループ（くり返し）が何か、そして、どう働くかはもうわかっている必要があります。

[円](../embroidery-tutorials-beginner/circle.md)のチュートリアルが役に立つかもしれません。

まだ何も刺繍したことがないときは、[初級](../embroidery-tutorials-beginner/index.md)のシリーズを見てください。

くわしい情報や、デザインのアイデアは、ほかのチュートリアルを見てください。

*このチュートリアルは、PDF 形式でダウンロードできます*:

[うずまき](../../../media/embroidery-tutorials/Spiral.pdf)
