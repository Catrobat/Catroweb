このチュートリアルでは、三角のうずまきを刺繍する方法を学びます（50.2 x 58 mm）。

![三角のうずまき](../../../media/embroidery-tutorials/Triangle-Spiral.png)

ループ（くり返し）が何か、そして、どう働くかはもうわかっている必要があります。

まだ何も刺繍したことがないときは、[初級](../embroidery-tutorials-beginner/index.md)のシリーズを見てください。

くわしい情報や、デザインのアイデアは、ほかのチュートリアルを見てください。

*このチュートリアルは、PDF 形式でダウンロードできます*:

[三角のうずまき](../../../media/embroidery-tutorials/Triangle-Spiral-1.pdf)
