このチュートリアルでは、虹を刺繍する方法を学びます（112 x 57.2 mm）。

![虹](../../../media/embroidery-tutorials/Regenbogen.webp)

ループ（くり返し）が何か、そして、どう働くかはもうわかっている必要があります。

[半円](../embroidery-tutorials-beginner/semicircle.md)のチュートリアルが役に立つかもしれません。

まだ何も刺繍したことがないときは、[初級](../embroidery-tutorials-beginner/index.md)のシリーズを見てください。

くわしい情報や、デザインのアイデアは、ほかのチュートリアルを見てください。

*このチュートリアルは、PDF 形式でダウンロードできます*:

[虹](../../../media/embroidery-tutorials/Rainbow.pdf)

### 1. 新しい刺繍オブジェクトを作ります（[刺繍オブジェクトを作る](../embroidery-tutorials-beginner/create-embroidery-objects.md)）:

![虹](../../../media/embroidery-tutorials/Rainbow.png)

### 2. 次のスクリプトを入れます:

![虹 (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. オブジェクトをコピーする

次のより大きなアーチには、いま作ったオブジェクトをコピーするだけでOKです。

オブジェクトの一覧の右上にある、3つの点をタップします。

それから「コピー」に進み、オブジェクトを選びます。

![虹 (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

アーチごとに別々のオブジェクトを使うと、あとで、それぞれ別の色で刺繍できます。

### 4. オブジェクトを変える

アーチの大きさがちがうように、いくつかの値を変えましょう。

そのためには、コピーしたオブジェクトのスクリプトに行き、次の値を変えます:

![虹 (2)](../../../media/embroidery-tutorials/Rainbow-2.png)

### 5. もっとアーチを作るには、ステップ 3 と 4 をくり返します！

### 6. 再生をタップして、デザインを始めましょう！
