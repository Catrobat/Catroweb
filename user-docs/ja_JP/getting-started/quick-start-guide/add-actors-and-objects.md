「+」ボタンをタップして、プロジェクトに新しいキャラクターやものを追加します。

![キャラクターを追加する](../../../media/getting-started/FigurHinzufuegen.png)

Pocket Code では、いくつかの方法で、プロジェクトにキャラクターやものを追加できます。

**かく**: **Pocket Paint** で、自分のキャラクターを描けます。Pocket Paint は、お絵かきのアプリです（[Pocket Paint について](https://catrobat.org/pocket-paint/)）。

**見た目**: あらかじめ作られたオブジェクトやものの中から、好きなものを選べます（[メディアライブラリについて](../elements/medialibrary.md)）。

**ギャラリー**: スマホのギャラリーから画像を選べます。

**ライブラリ**: ライブラリには、もうプログラムされたオブジェクトやものが入っています。つまり、スクリプトがすでに入っています。ゲームですぐに使える部品（例えば、カウントダウン）を選べます（[ライブラリについて](../elements/medialibrary.md#メディアライブラリからオブジェクトを追加)）。

**カメラ**: 機器のカメラで写真を撮って、キャラクターとして追加できます。

**バックパック**: 今のバックパックは空です。バックパックに保存したオブジェクトやキャラクターを、もう一度使えます。スクリプトも、いっしょに取り出されます（[バックパックについて](../elements/backpack.md)）。

**ローカルのオブジェクトとキャラクター**: ここには、プロジェクトで使える、できあいのキャラクターがあります。ローカルのオブジェクトとキャラクターは、オフラインのメディアライブラリのように働きます。インターネットにつながっていなくても、使えます。

**空のオブジェクト**: 見た目のないオブジェクトを追加します。このオブジェクトも、ふつうにプログラムできます。

**ローカルプロジェクト**: 最初のオブジェクトを、スクリプトといっしょに取り出して、プロジェクトに入れたいプロジェクトを選びます。
