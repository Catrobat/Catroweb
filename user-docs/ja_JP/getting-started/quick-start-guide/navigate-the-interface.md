Pocket Code を起動すると、次のメイン画面が見えます。

![メイン画面](../../../media/getting-started/MainScreen-e1732269599192.jpg)

右上の角には、![ヘルプ](../../../media/getting-started/Screenshot-2024-11-22-111748.png) の記号があります。タップすると、役に立つヒントが書かれた Catrobat のドキュメントが開きます。

その横には、メニュー ![メニュー](../../../media/getting-started/Screenshot-2024-11-22-111804.png) があります。メニューからは、設定に行けます。設定では、言語を変えたり、プロッターのブロックなどの拡張機能をオンにしたりできます。

その下には、最近編集したプロジェクトが見えます。編集の記号 ![編集の記号](../../../media/getting-started/Screenshot-2024-11-22-111825.png) をタップすると、プロジェクト画面に行けます。そこで、プロジェクトの続きを作れます。

再生ボタン ![プロジェクトを始める](../../../media/getting-started/Screenshot-2024-11-22-111818.png) をおすと、プロジェクトが始まります。

**機器内のプロジェクト** をタップすると、保存したプロジェクトが見られます。 ![機器内のプロジェクト](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

ほかのユーザーのプロジェクトを見たり、さわったりしたいときは、共有の中の **Catrobat コミュニティ** をタップします。すてきなプロジェクトがたくさん見つかります。 ![Catrobat コミュニティ](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

新しいプロジェクトを作りたいときは、プラスの記号をタップします。 ![追加](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
