Pocket Code を起動すると、次のメイン画面が見えます。

![メイン画面](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Pocket Code を起動すると、次のメイン画面が見えます。\
[画像を開く](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![ヘルプ](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
右上の角には、 の記号があります。

タップすると、役に立つヒントが書かれた Catrobat のドキュメントが開きます。

![メニュー](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
その横には、メニュー があります。

メニューからは、設定に行けます。 設定では、言語を変えたり、プロッターのブロックなどの拡張機能をオンにしたりできます。

![編集の記号](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
編集の記号 をタップすると、プロジェクト画面に行けます。

その下には、最近編集したプロジェクトが見えます。 そこで、プロジェクトの続きを作れます。

![プロジェクトを始める](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
再生ボタン をおすと、プロジェクトが始まります。

![機器内のプロジェクト](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
**機器内のプロジェクト** をタップすると、保存したプロジェクトが見られます。

![Catrobat コミュニティ](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
ほかのユーザーのプロジェクトを見たり、さわったりしたいときは、共有の中の **Catrobat コミュニティ** をタップします。

すてきなプロジェクトがたくさん見つかります。

![追加](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
新しいプロジェクトを作りたいときは、プラスの記号をタップします。
