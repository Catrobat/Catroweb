スマホやタブレットでアプリを開きます。

![メイン画面と新規プロジェクト](../../../media/getting-started/MainScreen_NewProject.png)\
「+」の記号をタップして、新しいプロジェクトを作ります。\
[画像を開く](../../../media/getting-started/MainScreen_NewProject.png)

プロジェクトに名前を付けて（1）、ゲームを縦向き（たて）か横向き（よこ）のどちらで作るかを決めます（2）。

![新しいプロジェクト](../../../media/getting-started/NewProject.png)\
そのあと、チェックマークをタップして決めます（3）。\
[画像を開く](../../../media/getting-started/NewProject.png)

これでプロジェクト画面に入りました。上のほうに、ゲームの名前が見えます。

その下に、**背景**が見えます。今は、背景は空っぽです。変えたいときは、タップします。

背景の下には、追加したオブジェクトやキャラクターを置く**場所**があります。今はまだ空っぽです。

右下には、大切なボタンが2つあります。

![スタート](../../../media/getting-started/Start.png)\
**再生**ボタンをおすと、ゲームが始まります。

![プラスボタン](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
**プラス**ボタンをおすと、ゲームに新しいキャラクターやものを追加できます。

![プロジェクト画面](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
これでプロジェクト画面に入りました。\
[画像を開く](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
