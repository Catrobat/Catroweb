Pocket Code は、スマホやタブレットで、ゲーム、アニメーション、インタラクティブな物語を直接作れる、ビジュアルプログラミングのアプリです。「ブロック」と呼ばれるコードのブロックを、ドラッグ＆ドロップで使って、プログラムを作ります。プログラミングの経験がなくても、プロジェクトを作れます。音、画像、動きを簡単に追加して、アイデアを形にしましょう。

このガイドでは、次のことを説明します。

- 画面の使い方
- 最初のプロジェクトの作り方
- オブジェクトと背景の使い方
- ブロックを使って動きをプログラムする方法
- プロジェクトの保存の方法

初心者にも、先生にも、ぴったりです。Pocket Code は、創造力、問題を解く力、論理的に考える力を育ててくれます。
