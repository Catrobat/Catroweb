Catrobat は、初心者から上級者まで、だれでもモバイル機器で直接、自分のゲーム、アニメーション、インタラクティブな物語を作れるようにするための、無料でオープンソースの**ビジュアルプログラミング言語**です。**ブロック**を使ったかんたんなしくみで、コードの「ブロック」をドラッグ＆ドロップして、少しずつプロジェクトを組み立てられます。経験はいりません！

Catrobat の主なアプリ **Pocket Code** では、デジタルのプロジェクトを作るだけでなく、画面の外にも広げられます。ふつうのプログラムのプロジェクトに加えて、Catrobat は、ものづくりの創造性を応援します。**刺しゅうマシン用の DST ファイル**や、**カッティングプロッター用の SVG ファイル**を作れます。デジタルのデザインを、布やほかの材料で形にできます！

学生、趣味でやる人、先生など、だれにとっても、Catrobat はプログラミング、問題を解くこと、ものづくりを楽しく体験する方法です。
