Pocket Code の**バックパック**は、オブジェクト（キャラクター）、スクリプト、コスチューム、音などを**保存して**、**ほかのプロジェクトでも使い直せる**便利な機能です。作る時間を節約して、プロジェクトを作りやすくしてくれます。

バックパックは、今のプロジェクトのものを入れておける、デジタルの入れ物のようなものです。バックパックに入れたものは、あとで取り出して、ほかのプロジェクトに入れられます。

### バックパックをオブジェクトに使うには？

**オブジェクトをバックパックに入れる**

バックパックに入れたいオブジェクトがあるプロジェクトの、プロジェクト画面を開きます。

オブジェクト（コスチューム、音、スクリプトを含む）が、バックパックに入ります。

![オブジェクトをバックパックに入れる](../../../media/getting-started/grafik-7.png)\
オブジェクトの横にある3つの点をタップして、メニューを開き、「バックパックに入れる」を選びます。\
[画像を開く](../../../media/getting-started/grafik-7.png)

**バックパックからオブジェクトを追加する**

オブジェクトを入れたいプロジェクトを開きます。

プロジェクト画面で、「+」をタップして、「バックパック」を選びます。

バックパックに入っているオブジェクトが、すべて表示されます。

![バックパックからオブジェクトを取り出す](../../../media/getting-started/grafik-8-e1732702791199.png)\
3つの点をタップして、「取り出す」を選びます。\
[画像を開く](../../../media/getting-started/grafik-8-e1732702791199.png)

***

### バックパックをスクリプトに使うには？

**スクリプトをバックパックに入れる:**

スクリプトがあるオブジェクトを開きます。スクリプトエディターで、入れたいスクリプトを長おしします。

![バックパックに追加](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)\
メニューから「バックパックに追加」を選びます。\
[画像を開く](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

![オブジェクトをバックパックに保存する](../../../media/getting-started/grafik-9.png)\
スクリプトに名前を付けて、「OK」をタップします。\
[画像を開く](../../../media/getting-started/grafik-9.png)

![あなたのバックパック](../../../media/getting-started/grafik-10.png)\
スクリプトが保存されて、ほかのプロジェクトでも使えるようになります。\
[画像を開く](../../../media/getting-started/grafik-10.png)

**バックパックからスクリプトを追加する:**

スクリプトを入れたいオブジェクトをタップします。 スクリプトの画面が開きます。

![バックパックからスクリプトを取り出す](../../../media/getting-started/grafik-11.png)\
3つの点をタップしてメニューを開き、「バックパック」をタップします。\
[画像を開く](../../../media/getting-started/grafik-11.png)

バックパックに入っているスクリプトが、すべて表示されます。

メニューから、もういらないスクリプトを、バックパックから消すこともできます。

![バックパックのスクリプトを取り出す](../../../media/getting-started/grafik-12.png)\
使いたいスクリプトの横にある3つの点をタップして、メニューから「取り出す」を選びます。\
[画像を開く](../../../media/getting-started/grafik-12.png)

***

### バックパックのよいところ

- **ほかのプロジェクトでも使える:** オブジェクト、スクリプト、音、コスチュームは、一度作れば、必要なだけ何度でも使えます。
- **時間の節約:** オブジェクトやスクリプトを、そのたびに作り直さなくてすみます。
- **同じものを使える:** 複数のプロジェクトで必要なとき、同じものをそのまま使えます。
