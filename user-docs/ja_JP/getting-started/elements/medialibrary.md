Catrobat のメディアライブラリは、プロジェクトで使える**オブジェクト**、**背景**、音、ものの集まりです。好きなように変えて、自分のアイデアに合わせられます！

[音](#メディアライブラリから音を追加)

### メディアライブラリから新しいオブジェクトを追加

プロジェクト画面で、「+」の記号を[タップして](../quick-start-guide/add-actors-and-objects.md)、新しいオブジェクトやものを追加します。

![新しいオブジェクト](../../../media/getting-started/NewActor-e1732794461668.jpg)\
「見た目」を選びます。\
[画像を開く](../../../media/getting-started/NewActor-e1732794461668.jpg)

プログラムで使いたいオブジェクトを選びます。

![メディアライブラリ](../../../media/getting-started/grafik-19.png)\
オブジェクトをタップして（1）、ダウンロードします（2）。\
[画像を開く](../../../media/getting-started/grafik-19.png)

オブジェクトに新しい名前を付けて（1）、ゲームの中で見た目どおりの場所に置けます（2）。 つまり、画面の上でオブジェクトを直接動かせます。 プロジェクトのどこにあるかが、すぐにわかります。

![新しいオブジェクトかもの](../../../media/getting-started/grafik-29.png)\
「OK」で決めます。\
[画像を開く](../../../media/getting-started/grafik-29.png)

![オブジェクトを見ながら配置する](../../../media/getting-started/grafik-21.png)\
オブジェクトを置いて（1）、チェックマークをタップします（2）。\
[画像を開く](../../../media/getting-started/grafik-21.png)

### メディアライブラリから背景を追加

プロジェクト画面で、背景を開きます。「見た目」のところに移動して、新しいコスチュームを追加します（[くわしく](../quick-start-guide/add-background.md)）。「見た目」をタップします。

プログラムで使いたい背景を選びます。

![メディアライブラリから背景を選ぶ](../../../media/getting-started/grafik-22.png)\
背景をタップして（1）、ダウンロードします（2）。\
[画像を開く](../../../media/getting-started/grafik-22.png)

### メディアライブラリから音を追加

音は、背景にも、オブジェクトやものにも追加できます。 音を追加したい背景やオブジェクトをタップします。

![音の画面](../../../media/getting-started/grafik-23.png)\
音の画面に行って、「+」の記号をタップします。\
[画像を開く](../../../media/getting-started/grafik-23.png)

![音](../../../media/getting-started/grafik-30.png)\
「音」をタップすると、メディアライブラリが開きます。\
[画像を開く](../../../media/getting-started/grafik-30.png)

プログラムで使いたい音を選びます。

![音を選ぶ](../../../media/getting-started/grafik-25.png)\
音をタップして（1）、ダウンロードします（2）。\
[画像を開く](../../../media/getting-started/grafik-25.png)

### メディアライブラリからオブジェクトを追加

Catrobat では、すぐに使える、できあいのオブジェクトをダウンロードできます。オブジェクトは、カウントダウンのような、ひとつずつのゲームの部品です。すでにスクリプトが入っています。

オブジェクトの追加は、オブジェクトと同じようにします。

プロジェクト画面で、「+」の記号（[くわしく](../quick-start-guide/add-actors-and-objects.md)）をタップして、新しいものを追加します。

![新しいオブジェクト](../../../media/getting-started/NewActor-e1732794461668.jpg)\
「ライブラリ」を選びます。\
[画像を開く](../../../media/getting-started/NewActor-e1732794461668.jpg)

プログラムで使いたいものを探します。

![メディアライブラリのオブジェクト](../../../media/getting-started/grafik-27.png)\
ものをタップして（1）、ダウンロードします（2）。\
[画像を開く](../../../media/getting-started/grafik-27.png)

ものに新しい名前を付けて（1）、ゲームの中で見た目どおりの場所に置けます（2）。 つまり、画面の上でものを直接動かせます。 プロジェクトのどこにあるかが、すぐにわかります。

![新しいオブジェクトかもの](../../../media/getting-started/grafik-29.png)\
「OK」で決めます。\
[画像を開く](../../../media/getting-started/grafik-29.png)

ものを置いて（1）、チェックマークをタップします（2）。
