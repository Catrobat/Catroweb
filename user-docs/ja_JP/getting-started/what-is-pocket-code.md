Pocket Code は Catrobat の主なアプリで、スマホやタブレットの上で、ゲーム、アニメーション、インタラクティブな物語を作れる、無料でオープンソースのアプリです。Pocket Code の**ブロックを使ったしくみ**では、パズルのピースをはめるように、コードのブロックをつなげてプロジェクトを作れます。プログラミングの経験はいりません。初心者にぴったりです！

Pocket Code は、デジタルのプロジェクトだけにとどまりません。ものづくりの新しい機能を使うと、**カッティングプロッター用の SVG ファイル**も作れます。デジタルで作ったものを、実際のものにできます。画面の外にも、創造の可能性が広がります。

プログラミングを学ぶとき、新しいアイデアを試すとき、プログラミングを教えるとき、Pocket Code は、楽しく、だれでも使える方法でプログラミングの世界に入れてくれます。

[くわしい情報](https://catrobat.org/pocket-code/)
