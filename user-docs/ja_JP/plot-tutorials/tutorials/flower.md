プロットが始まると、動きはすべて、ペンで描いたように線になります。これは、あとでプロッターが切りぬく線です。

この花には 7 枚の花びらがあります。それぞれの花びらは弧です。ごく小さな線を引き、回り、もう1つごく小さな線を引き、また回ります（くり返し「10 回」－「10 歩動かす」－「16 度右に回す」のブロックを見てください）。

次の花びらを始める前に、もう一度回す必要があります。
