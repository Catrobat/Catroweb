[キツネ（PDF、ドイツ語）](../../../media/plot-tutorials/Fuchs.pdf)

プロットが始まると、動きはすべて、ペンで描いたように線になります。これは、あとでプロッターが切りぬく線です。

このキツネは、直線（「__ 歩動かす」）と回転だけでできています。

**ヒント**: プログラムを作りながら、こまめに動かしてためしましょう。
