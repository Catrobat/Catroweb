プロットが始まると、動きはすべて、ペンで描いたように線になります。これは、あとでプロッターが切りぬく線です。

この星には 6 つのとがった先があります。1 つの先は、直線（「100 歩動かす」）と、回転、そして先の形を仕上げるもう1本の直線でできています。次の先を作る前に、反対向きに回して、次の先がきれいに出るようにします。

***メモ**: 1 周は 360° です。それぞれの先では、右に 100° 回して、左に 40° 回します。合計で、右に 60° 回ることになります。*

*6 つの先すべてで、右に合計 360° 回ります。*

**もっと先へ**: いろいろな回転の組み合わせをためして、先の数を変えてみましょう。
