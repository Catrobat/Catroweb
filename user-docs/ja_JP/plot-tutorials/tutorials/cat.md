プロットが始まると、動きはすべて、ペンで描いたように線になります。これは、あとでプロッターが切りぬく線です。

わたしたちのオブジェクトは、150 度の向きを向いています。

このチュートリアルでは、まずネコの頭の右側を作ります。よく見ると、はじめはカーブが強いので、小さな線を描くたびに、オブジェクトを大きく回す必要があります。そして、頭の下の部分では、回る角度が小さくなります。頭の左側は、また強くカーブしています。そのため、この部分は全部で3つのくり返しを使います。

次は左の耳です。耳は直線だけでできているので、「__ 歩動かす」ブロックを使えます。

耳の間の部分は、また弧になっているので、別のくり返しでプログラムします。

それから右の耳を作ります。

これで、プロットは完成です。最後に「プロットを止める」ブロックで終わらせて、「プロットを SVG で保存」ブロックで、スマホに保存します。

これで、SVG ファイルを（カッティング）プロッターに送れます。
