Catrobat은 초보자부터 고급 사용자까지 누구나 휴대 기기에서 직접 게임, 애니메이션, 대화형 이야기를 만들 수 있도록 돕는 무료 오픈소스 **시각 프로그래밍 언어**예요. **블록 방식** 코딩 화면을 바탕으로 해서, 코드 “블록”을 끌어다 놓기만 하면 한 단계씩 프로젝트를 만들 수 있어요. 시작하는 데 아무 경험도 필요 없어요!

Catrobat의 대표 앱인 **Pocket Code**로는 화면 밖의 작품도 만들 수 있어요. 일반 코딩 프로젝트뿐 아니라, Catrobat은 메이커스페이스 창작도 지원해요. **자수 기계용 DST 파일**과 **커팅 플로터용 SVG 파일**을 만들 수 있거든요. 그래서 디지털 디자인을 천이나 다른 실제 재료로 만들 수 있어요!

학생이든, 취미로 하는 사람이든, 선생님이든, Catrobat은 코딩, 문제 해결, 디지털 공작을 재미있게 직접 해 볼 수 있게 해 줘요.
