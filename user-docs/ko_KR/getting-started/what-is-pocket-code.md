Pocket Code는 Catrobat의 주력 앱으로, 스마트폰이나 태블릿에서 바로 게임, 애니메이션, 대화형 이야기를 만들 수 있는 무료 오픈소스 모바일 앱이에요. Pocket Code의 **블록 코딩 방식**을 쓰면 코드 블록을 퍼즐 조각처럼 맞춰서 프로젝트를 만들 수 있어요. 프로그래밍 경험이 없어도 괜찮아서 초보자에게 딱 좋아요!

Pocket Code는 디지털 프로젝트에만 머물지 않아요. 새로운 **메이커스페이스 기능**으로 **커팅 플로터용 SVG 파일**도 디자인할 수 있어요. 그래서 디지털 작품을 실제 물건으로 바꾸고, 화면 밖의 창의적인 가능성도 탐험할 수 있어요.

코딩을 배우든, 새로운 아이디어를 실험하든, 프로그래밍을 가르치든, Pocket Code는 재미있고 쉽게 코딩에 빠져들 수 있게 해 줘요.
