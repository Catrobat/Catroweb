Pocket Code의 **백팩** 기능은 오브젝트, 스크립트, 모양, 소리 같은 요소를 **여러 프로젝트에서 저장하고 다시 쓸 수 있게** 해 주는 편리한 기능이에요. 시간을 아끼고 프로젝트를 더 효율적으로 만들 수 있어요.

백팩은 현재 프로젝트의 요소를 넣어 두는 디지털 보관함과 같아요. 백팩에 저장하면 그 요소를 꺼내서 다른 프로젝트에 넣을 수 있어요.

### 백팩을 오브젝트에 어떻게 사용하나요?

**오브젝트를 백팩에 넣기**

백팩에 넣고 싶은 오브젝트가 있는 프로젝트의 프로젝트 화면으로 가세요.

오브젝트 옆의 점 세 개를 누르고 메뉴에서 “백팩에 넣기”를 고르세요.

오브젝트(모양, 소리, 스크립트 포함)가 백팩에 들어가요.

![Pack actor](../../../media/getting-started/grafik-7.png)

**백팩에서 오브젝트 꺼내기**

오브젝트를 넣고 싶은 프로젝트를 여세요.

프로젝트 화면에서 더하기 기호를 누르고 “백팩”을 고르세요.

백팩에 저장해 둔 오브젝트와 모든 오브젝트가 보여요. 점 세 개를 누르고 “백팩에서 꺼내기”를 고르세요.

![Unpack Actor](../../../media/getting-started/grafik-8-e1732702791199.png)

***

### 백팩을 스크립트에 어떻게 사용하나요?

**스크립트를 백팩에 넣기:**

스크립트가 들어 있는 오브젝트로 가세요. 스크립트 편집기에서 원하는 스크립트를 길게 누르세요.

메뉴에서 “백팩에 추가”를 고르세요.

![add to backpack](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

스크립트에 이름을 붙이고 OK로 확인하세요.

![Save actor to backpack](../../../media/getting-started/grafik-9.png)

스크립트가 저장되어 다른 프로젝트에서도 쓸 수 있어요.

![your backpack](../../../media/getting-started/grafik-10.png)

**백팩에서 스크립트 꺼내기:**

스크립트를 넣고 싶은 오브젝트를 누르세요. 스크립트 영역이 보일 거예요. 점 세 개를 눌러 메뉴를 열고 “백팩”을 누르세요.

![UnpackSkript](../../../media/getting-started/grafik-11.png)

백팩에 이미 들어 있는 모든 스크립트가 보여요. 원하는 스크립트 옆의 점 세 개를 누르고 메뉴에서 “꺼내기”를 고르세요.

메뉴에서 백팩에 더 이상 필요 없는 스크립트를 지울 수도 있어요.

![UnpackSkriptBackpack](../../../media/getting-started/grafik-12.png)

***

### 백팩의 장점

- **프로젝트 사이 재사용:** 오브젝트, 스크립트, 소리, 모양은 한 번 만들면 필요할 때마다 여러 번 다시 쓸 수 있어요.
- **시간 절약:** 오브젝트나 스크립트를 매번 새로 만들 필요가 없어요.
- **일관성:** 여러 프로젝트에서 필요할 때 요소가 똑같이 유지돼요.
