스마트폰이나 태블릿에서 앱을 열어요.

![MainScreen_NewProject](../../../media/getting-started/MainScreen_NewProject.png)\
+ 기호를 눌러 새 프로젝트를 만들어요.\
[이미지 열기](../../../media/getting-started/MainScreen_NewProject.png)

프로젝트 이름을 정하고(1), 게임을 세로(수직) 화면으로 만들지 가로(수평) 화면으로 만들지 정하세요(2).

![NewProject](../../../media/getting-started/NewProject.png)\
그다음 체크 표시(3)를 눌러 확인하세요.\
[이미지 열기](../../../media/getting-started/NewProject.png)

이제 프로젝트 화면에 들어왔어요. 맨 위에는 게임 이름이 보여요.

그 아래에는 **배경**이 보여요. 지금은 배경이 비어 있어요. 바꾸고 싶으면 배경을 누르세요.

배경 아래에는 게임에 추가한 **오브젝트** 영역이 보여요. 지금은 아직 비어 있어요.

오른쪽 아래에는 중요한 버튼 두 개가 있어요.

![Start](../../../media/getting-started/Start.png)\
**실행** 버튼을 누르면 게임이 시작돼요.

![Plus Button](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
**더하기** 버튼을 누르면 게임에 새 캐릭터나 오브젝트를 추가할 수 있어요.

![Project Screen](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
이제 프로젝트 화면에 들어왔어요.\
[이미지 열기](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
