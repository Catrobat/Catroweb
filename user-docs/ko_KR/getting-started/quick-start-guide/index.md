Pocket Code는 스마트폰이나 태블릿에서 바로 게임, 애니메이션, 대화형 이야기를 만들 수 있는 시각 프로그래밍 앱이에요. 끌어다 놓기 방식의 “블록”(코드 블록)을 쓰면 프로그래밍 경험이 없어도 프로젝트를 디자인할 수 있어요. 소리, 그림, 움직임도 쉽게 추가해서 아이디어를 살려 보세요.

이 가이드에서는 다음 내용을 설명해요.

- 화면 둘러보기,
- 첫 프로젝트 만들기,
- 오브젝트와 배경 다루기,
- 블록으로 동작 프로그래밍하기,
- 프로젝트 저장하기.

초보자와 선생님 모두에게 알맞아요. Pocket Code는 창의력, 문제 해결력, 논리적 사고력을 키워 줘요.
