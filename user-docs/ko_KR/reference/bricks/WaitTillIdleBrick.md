이 블록은 프로젝트의 다른 모든 스크립트가 실행을 끝낼 때까지 지금 스크립트를 멈춰요. 다른 모든 것이 끝날 때까지 내 스크립트를 잠시 보류하는 것과 같아요. 지금 스크립트의 다음 단계로 넘어가기 전에 다른 동작이 일어나지 않도록 할 때 유용해요.
