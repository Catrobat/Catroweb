![장면이 시작되었을 때](../../../media/bricks/When_scene_starts_btn2.png)

이 블록을 쓰면 장면이 시작되자마자 스크립트가 바로 시작돼요. 장면은 프로그램의 시작 지점이에요. 장면은 다른 요소를 보여 주고 여러 상호작용이 일어날 수 있는 프로그램 속 새 화면이에요. 프로그램의 단계마다 장면을 여러 개 만들 수 있어요. 예를 들어 인트로 장면, 메인 메뉴 장면, 첫 번째 레벨 장면, 두 번째 레벨 장면처럼요. 간단한 프로그램이라면 장면 하나만으로도 충분해요. 그러면 프로그램의 시작이 곧 장면의 시작이 돼요.

모든 스크립트처럼 이 스크립트도 이벤트 블록으로 시작해요. 이벤트는 스크립트가 **언제** 시작할지 정하고, 그 뒤의 블록은 프로그램에게 **무엇을** 할지 알려 줘요.
