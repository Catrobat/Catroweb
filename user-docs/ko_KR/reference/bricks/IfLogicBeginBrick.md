![만약 ~이면 아니면](../../../media/bricks/if_else_brick2.png)

*조건이 참인지 확인해서, 참이면 한 묶음의 명령을 실행하고, 거짓이면 다른 묶음의 명령을 실행해요. “이것이 참이면 이것을 하고, 아니면 저것을 해라”라는 두 가지 선택지를 주는 것과 같아요.*

![StartScene](../../../media/bricks/StartScene.png)

장면이 시작되면 변수 X를 0으로 정해요.

![IfElse](../../../media/bricks/IfElse.png)

이제 동물을 터치하면, X를 2로 나눈 나머지가 참인지, 즉 X가 홀수인지 확인해요.

참이면 소리 Tweet1을 재생하고 변수 X를 1만큼 늘려요.

아니면, X가 짝수이므로 X만 1만큼 늘려요.

실행할 명령들은 “만약 끝”으로 구분해요.
