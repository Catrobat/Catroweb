![펜 색을 빨강 0, 초록 0, 파랑 255로 정하기](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

이 블록은 오브젝트가 쓰는 펜의 색을 바꿔요. 그림을 그리는 도중에 다른 색 펜으로 바꾸는 것과 같아요.

**빨강, 초록, 파랑 (RGB)**: RGB 색 모델은 빨강, 초록, 파랑 빛의 세기를 다르게 섞어서 많은 색을 만들어요. 각 색 성분(빨강, 초록, 파랑)은 0부터 255 사이의 값을 가질 수 있어요:

- **빨강**: 색의 빨강 성분이에요. 값이 클수록 빨간색이 더 많아요.
- **초록**: 색의 초록 성분이에요. 값이 클수록 초록색이 더 많아요.
- **파랑**: 색의 파랑 성분이에요. 값이 클수록 파란색이 더 많아요.

빨강, 초록, 파랑의 값을 서로 다르게 조합하면 어떤 색이든 만들 수 있어요. 예를 들면:

- `RGB(255, 0, 0)`은 순수한 빨간색이에요.
- `RGB(0, 255, 0)`은 순수한 초록색이에요.
- `RGB(0, 0, 255)`는 순수한 파란색이에요.
- `RGB(255, 255, 255)`는 흰색(빨강, 초록, 파랑이 모두 가장 많음)이에요.
- `RGB(0, 0, 0)`은 검은색(색이 없음)이에요.

이 색들을 여러 양으로 섞으면 디지털 화면에서 보는 모든 색이 만들어져요.
