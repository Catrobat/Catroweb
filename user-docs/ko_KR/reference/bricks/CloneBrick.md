이 블록은 정해진 오브젝트의 복사본을 만들어요. 이 복사본을 복제본이라고 해요. 복제본은 원래 오브젝트처럼 움직여요. 게임 속 캐릭터나 오브젝트를 하나 더 만드는 것을 떠올려 보세요. 복제본은 자기만의 동작과 스크립트를 가질 수 있어서, 같은 오브젝트를 여러 개 만들고 각자 따로 움직이게 할 수 있어요.
