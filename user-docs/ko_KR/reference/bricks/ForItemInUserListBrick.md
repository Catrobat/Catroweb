이 블록은 리스트나 범위의 모든 항목마다 정해진 명령을 실행해요. 항목을 하나씩 차례로 가져가서 각각 같은 동작을 하는 것과 같아요.

숫자, 색깔, 또는 다른 무엇이든 담긴 리스트가 있다고 상상해 보세요. 이 블록을 쓰면 리스트의 항목을 하나씩 가져와서 무언가를 할 수 있어요. 예를 들어 색깔 리스트가 있고 배경 색을 리스트의 각 색으로 바꾸고 싶다면, 이 블록을 쓰면 돼요.

“이 무리의 모든 항목에 대해 이 명령들을 실행해라”라고 말하는 것과 같아요.
