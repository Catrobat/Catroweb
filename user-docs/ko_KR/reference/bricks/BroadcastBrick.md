프로젝트의 다른 부분에 메시지를 보내서 각자 자기 스크립트를 시작하라고 알려요. 모두가 듣는 방송을 하는 것과 같아요.

**왜 메시지를 보내나요?**

메시지를 쓰면 한 장면 안의 서로 다른 오브젝트끼리 소통하고 상호작용할 수 있어요. 한 오브젝트가 다른 모든 오브젝트에 메시지를 보낼 수 있고, 메시지를 받은 오브젝트는 그에 반응할 수 있어요.

이 메시지는 화면에 **표시되지 않아요**! 메시지를 보여 주고 싶다면 “모양” 분류의 블록을 쓰세요!

**어떻게 동작하나요?**

- *보내는 오브젝트:* 보내는 오브젝트는 *“메시지 보내기”* 블록을 써서 소통을 시작해요. 이 블록은 장면의 다른 모든 오브젝트(배경도 포함)에 메시지를 보내요.
- *받는 오브젝트:* 받는 오브젝트는 메시지를 듣고 반응하는 오브젝트예요. *“다음 메시지를 받았을 때”* 블록을 써서 특정 메시지가 왔는지 알아차려요.
- *메시지 처리:* 받는 오브젝트가 메시지를 받으면 *“다음 메시지를 받았을 때”* 블록 아래에 있는 모든 블록을 실행해요. 그래서 특정 메시지를 받았을 때 일어날 동작을 직접 정할 수 있어요.
