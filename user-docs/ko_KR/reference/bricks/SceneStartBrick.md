![장면 시작하기](../../../media/bricks/start_scene_brick2.png)

이 블록은 프로젝트의 다른 장면으로 바꾸고, 그 장면을 처음부터 실행해요. 책의 장을 바꾸거나 게임의 다음 단계로 넘어가는 것과 같아요.

프로젝트에 장면이 여러 개 있고, 각 장면이 이야기나 게임의 다른 부분을 나타낸다고 상상해 보세요. 이 블록을 쓰면 어떤 장면이든 골라서 처음부터 시작할 수 있어요. 그래서 프로젝트의 여러 부분이 자연스럽게 이어지게 할 수 있어요.
