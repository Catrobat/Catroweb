### 1. 새 오브젝트 만들기

먼저 새 프로젝트를 열어요.

Pocket Code 앱의 홈 화면에서 찾을 수 있어요. 프로젝트가 여러 개라면 “Projects on device”를 누르세요. 그다음 새 프로젝트를 고르세요. 아직 새 프로젝트를 만들지 않았거나 방법이 궁금하다면 **[새 프로젝트](new-project.md)** 튜토리얼을 확인해 보세요.
