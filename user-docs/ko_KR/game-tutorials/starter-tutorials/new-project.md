이건 가장 첫 번째 튜토리얼이고, 어떤 사전 지식도 필요 없어요.

자, 이제 무엇을 기다리나요? 스마트폰을 들고 지금 바로 시작해 보세요!

*여기에서 튜토리얼을 PDF 형식으로 내려받을 수 있어요:*

[PDF 열기](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code 앱 설치하기

먼저 기기에 Pocket Code 앱을 설치해야 해요. 이 단계에는 Google 계정이 필요해요. 이제 기기가 앱을 내려받아 설치할 거예요. 인터넷 속도에 따라 시간이 조금 걸릴 수 있어요.

![New Program (2)](../../../media/game-tutorials/New-Program-2.png)\
Google Play 스토어에서 “Pocket Code”를 검색하고 “설치”를 누르면 찾을 수 있어요.\
[이미지 열기](../../../media/game-tutorials/New-Program-2.png)

Pocket Code 내려받기와 설치가 끝나면 기기에 따라 앱 서랍이나 홈 화면에서 앱을 찾을 수 있어요. 앱을 원하는 곳에 자유롭게 옮길 수 있어요.

### 2. 앱 시작하기

![New Program (1)](../../../media/game-tutorials/New-Program-1.png)\
앱을 열면 여러 분류가 보여요.\
[이미지 열기](../../../media/game-tutorials/New-Program-1.png)

### 3. 새 프로젝트 만들기

이제 실제로 새 프로젝트를 만들 차례예요. 프로젝트 이름을 입력하고, 프로젝트를 가로 화면으로 만들지 정하세요. “OK”를 누르면 프로젝트가 만들어져요.

![New Program](../../../media/game-tutorials/New-Program.png)\
오른쪽 아래 모서리에 있는 노란색 더하기 버튼을 누르세요.\
[이미지 열기](../../../media/game-tutorials/New-Program.png)

### 4. 해냈어요! 나만의 새 프로젝트를 만들었어요.

이제 Pocket Code를 설치했고, 새 프로젝트를 만드는 방법도 알았어요. 이제 프로그래밍을 시작할 수 있어요!

프로젝트에 새 오브젝트를 만드는 방법도 알아야 해요. 단계별로 모두 설명하는 **[새 오브젝트](new-object.md)** 튜토리얼을 확인해 보세요.
