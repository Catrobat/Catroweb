이 튜토리얼에서는 무지개(112 x 57.2mm)를 수놓는 법을 배워요.

![Regenbogen](../../../media/embroidery-tutorials/Regenbogen.webp)

반복문이 무엇이고 어떻게 동작하는지 이미 알고 있어야 해요.

이 튜토리얼에는 **[반원](../embroidery-tutorials-beginner/semicircle.md)** 튜토리얼이 도움이 될 수 있어요.

아직 자수를 해 본 적이 없다면 [초급](../embroidery-tutorials-beginner/index.md) 시리즈의 자수 튜토리얼을 확인하세요.

더 많은 정보나 디자인 아이디어가 필요하면 다른 튜토리얼도 확인해 보세요.

*여기에서 튜토리얼을 PDF 형식으로 내려받을 수 있어요*:

[무지개](../../../media/embroidery-tutorials/Rainbow.pdf)

### 1. 새 자수 오브젝트를 만드세요 (See [자수 오브젝트 만들기](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![Rainbow](../../../media/embroidery-tutorials/Rainbow.png)

### 2. 다음 스크립트를 넣으세요:

![Rainbow (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. 오브젝트 복사하기

다음으로 더 큰 아치를 만들려면, 방금 만든 오브젝트를 그냥 복사하면 돼요.

오브젝트 목록의 오른쪽 위 모서리에 있는 점 세 개를 누르세요.

그다음 “복사”로 가서 오브젝트를 고르세요.

![Regenbogen (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

아치마다 따로 오브젝트를 쓰면 나중에 아치마다 다른 색으로 수놓을 수 있어요.

### 4. 오브젝트 고치기

아치의 크기가 서로 다르게 되도록 몇 가지 값을 바꿔야 해요.

![Rainbow (2)](../../../media/embroidery-tutorials/Rainbow-2.png)
