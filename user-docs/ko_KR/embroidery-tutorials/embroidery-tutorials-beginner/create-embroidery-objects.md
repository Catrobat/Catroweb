이 튜토리얼에서는 나중에 패턴을 수놓을 때 쓸 오브젝트를 만드는 법을 배워요.

이 튜토리얼을 하려면 프로젝트를 만드는 방법을 이미 알아야 해요. 도움이 필요하면 [스타터 시리즈](../../game-tutorials/starter-tutorials/index.md)의 튜토리얼을 확인하세요.

더 많은 정보나 디자인 아이디어가 필요하면 다른 튜토리얼도 확인해 보세요.

*여기에서 튜토리얼을 PDF 형식으로 내려받을 수 있어요*:

[자수 오브젝트 만들기](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. 프로젝트 오른쪽 아래의 더하기 버튼을 눌러 새 오브젝트를 추가하세요.

![Create Embroidery-Objects](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. 이미지를 고르려면 미디어 라이브러리로 가세요.

![Create Embroidery-Objects (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. 자수 오브젝트는 자수 기계 바늘의 한 층을 나타내요. 여러 자수 오브젝트가 차례로 수놓아져요. 그래서 여러 색을 쓸 수 있어요.

원하는 색에 맞게 오브젝트를 고르세요.

아래로 스크롤해서 알맞은 화살표를 찾으세요.

![Create Embroidery-Objects (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. 새 오브젝트에 알맞은 이름을 붙이고 OK를 누르세요.

![Create Embroidery-Objects (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. 새 오브젝트를 만들었어요. 이제 스크립트를 추가하고 오브젝트를 프로그래밍할 수 있어요.

![Create Embroidery-Objects (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

이제 오브젝트를 만드는 방법을 알았어요. 쓰고 싶은 색마다 새 오브젝트를 추가하세요.

각 색의 오브젝트에 스크립트를 추가해서 나만의 디자인을 프로그래밍하고, 나중에 수놓을 수도 있어요.

영감이나 도움이 필요하세요? 다른 튜토리얼도 확인해 보세요!
