이 튜토리얼에서는 자수 블록을 켜는 방법을 설명해요.

![Activate Embroidery-Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

이 튜토리얼에는 프로그래밍 지식이 필요 없어요. 자수 튜토리얼을 시작하기 위한 첫 단계예요. 나중에는 여러분만의 디자인을 만들고, 프로그래밍하고, 좋아하는 천에 직접 수놓을 수 있어요.

더 많은 정보나 디자인 아이디어가 필요하면 다른 튜토리얼도 확인해 보세요.

*여기에서 튜토리얼을 PDF 형식으로 내려받을 수 있어요*:

[ActivateEmbroideryBricks](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

각 블록에 대해 더 알고 싶으면 [여기](../../../reference/)에 있는 블록 설명서를 확인하거나 **[자수 블록](embroidery-bricks/index.md)** 튜토리얼을 따라 해 보세요.

이제 시작해서 여러분만의 디자인을 만들어 보세요!
