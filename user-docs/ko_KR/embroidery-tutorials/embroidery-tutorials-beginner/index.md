창의적으로 놀면서 동시에 코딩을 배우고 싶나요? 바로 입고, 가지고 놀고, 감탄할 수 있는 물건을 만들어 보고 싶지 않나요?

Embroidery Designer를 쓰면 사전 경험이 없어도 자수 기계를 프로그래밍할 수 있어요. 자수 기계가 티셔츠, 가방, 바지, 스마트폰 케이스, 심지어 신발에도 여러분의 디자인을 자동으로 수놓아 줄 거예요. 천으로 된 것이라면 무엇이든 수를 놓을 수 있어요. 상상력과 창의력을 마음껏 펼쳐 보세요! Catrobat 커뮤니티에서 다른 사람들의 디자인을 내려받아 편집할 수도 있어요. 물론 여러분의 프로젝트를 친구들과 전 세계와 공유할 수도 있어요!
