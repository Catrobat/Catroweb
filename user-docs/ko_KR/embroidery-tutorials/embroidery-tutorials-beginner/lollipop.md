이 튜토리얼에서는 막대 사탕(54.7 x 54.8mm)을 수놓는 법을 배워요.

![image (9)](../../../media/embroidery-tutorials/image-9.png)

새 오브젝트를 만들고 그 안에 블록을 넣을 줄 알아야 해요. 아직 도움이 필요하면 [스타터 시리즈](../../game-tutorials/starter-tutorials/index.md)의 튜토리얼을 확인하세요. 또한 자수 블록이 이미 켜져 있어야 해요. 켜는 방법은 **[자수 블록 켜기](activate-embroidery-bricks.md)** 튜토리얼에서 확인할 수 있어요.

더 많은 정보나 디자인 아이디어가 필요하면 다른 튜토리얼도 확인해 보세요.

*여기에서 튜토리얼을 PDF 형식으로 내려받을 수 있어요*:

[막대 사탕](../../../media/embroidery-tutorials/Lollipop.pdf)

### 1. 새 자수 오브젝트를 만드세요 (See [자수 오브젝트 만들기](create-embroidery-objects.md)).

### 2. 이제 블록을 하나씩 시작하고 스크립트에 넣으세요.

![Lollipop](../../../media/embroidery-tutorials/Lollipop.png)

### 3. 실행 버튼을 눌러 디자인을 시작하세요!

원을 수놓는 방법은 **[원](circle.md)** 튜토리얼에서 더 자세히 확인해 보세요.
