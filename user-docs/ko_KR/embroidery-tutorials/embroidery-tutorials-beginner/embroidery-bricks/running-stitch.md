자수 기계가 정해진 길이로 계속 수놓게 해요.

보통 홈질 블록은 움직이기 블록과 함께 써요.

![Start_running_stitch_with_length_10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

자수 기계는 **10 걸음**마다 한 번씩 수놓는 홈질을 시작해요.

그다음 기계는 **200 걸음**을 움직여요.

이렇게 하면 **20개의 바늘땀**이 나와요.

![RunningStitch](../../../../media/embroidery-tutorials/RunningStitch.png)

홈질은 이제 반복문이 필요 없어서 박음질을 훨씬 쉽게 만들어 줘요.

![image](../../../../media/embroidery-tutorials/image.png)
