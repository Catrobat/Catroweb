플롯이 시작되면 모든 움직임이 펜으로 그린 것처럼 그려져요. 이것이 나중에 플로터가 자를 선이에요.

이 꽃에는 꽃잎이 7개 있어요. 각 꽃잎은 호예요. 아주 짧은 선을 그리고, 돌고, 또 짧은 선을 그리고 다시 도는 방식이에요(“10번 반복하기” – “10 걸음 움직이기” – “16도 오른쪽으로 돌기” 반복을 살펴보세요).

다음 꽃잎을 시작하기 전에 한 번 더 돌아야 해요.
