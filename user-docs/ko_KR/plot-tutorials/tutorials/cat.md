플롯이 시작되면 모든 움직임이 펜으로 그린 것처럼 그려져요. 이것이 나중에 플로터가 자를 선이에요.

우리 오브젝트는 150도 방향을 향해요.

이 튜토리얼에서는 고양이 머리의 오른쪽을 먼저 만들어요. 자세히 보면 곡선이 처음에는 많이 휘어 있어서, 작은 선을 그릴 때마다 오브젝트를 더 많이 돌려야 해요. 그다음 머리 아랫부분으로 가면서 회전이 점점 작아져요. 머리의 왼쪽은 다시 많이 휘어 있어요. 그래서 이 부분은 반복문이 모두 세 개 필요해요.

다음은 왼쪽 귀예요. 귀는 직선으로만 이루어져 있어서 “___ 걸음 움직이기” 블록을 쓸 수 있어요.

두 귀 사이 부분은 다시 호라서, 또 다른 반복문으로 프로그래밍해요.

그다음 오른쪽 귀를 만들어요.

이제 플롯이 끝났어요. “플롯 멈추기” 블록으로 끝내고, “플롯을 SVG로 저장하기 ___”로 휴대폰에 저장하세요.

이제 SVG 파일을 (커팅) 플로터에 보낼 수 있어요.
