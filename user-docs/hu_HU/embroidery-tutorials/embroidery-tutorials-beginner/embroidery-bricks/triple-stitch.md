A hármas öltés minden öltést háromszor varr át.

A hármas öltés az első öltés után visszaugrik, öltést készít, majd újra előreugrik, és ismét öltést készít.

![Start_triple_stitch_with_length_10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Ugyanúgy működik, mint az [előöltés](running-stitch.md).

![TripleStitch](../../../../media/embroidery-tutorials/TripleStitch.png)

Ettől a varrás tovább tart.
