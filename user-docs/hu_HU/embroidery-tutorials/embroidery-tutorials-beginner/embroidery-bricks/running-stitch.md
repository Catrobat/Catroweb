Folyamatosan öltést csináltat a géppel, változtatható hosszal.

Az előöltést általában egy mozgás blokkal kombinálod.

![Start_running_stitch_with_length_10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

A gép előöltést kezd, amely minden **10 lépésenként** öltést készít.

Ezután a gép **200 lépést** mozdul.

Ez **20 öltést** eredményez.

![RunningStitch](../../../../media/embroidery-tutorials/RunningStitch.png)

Az előöltés megkönnyíti a varrást, mert már nem lesz szükséged ciklusra.

![kép](../../../../media/embroidery-tutorials/image.png)
