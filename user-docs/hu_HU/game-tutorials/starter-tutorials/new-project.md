Ebben az oktatóanyagban mindent megtudhatsz a Pocket Code-ról, hogy elkezdhesd az első projektedet. Lépésről lépésre végigvezetünk azon, hogyan töltsd le és nyisd meg az appot, és hogyan hozz létre új projektet.

![Új program](../../../media/game-tutorials/New-Program.png)

Ez az első oktatóanyag, nincs szükséged előzetes tudásra.

Mire vársz? Vedd elő a telefonod, és kezdjünk neki most!

*Az oktatóanyagot PDF-formátumban is letöltheted itt:*

[Új program](../../../media/game-tutorials/New-Program.pdf)

### 1. A Pocket Code telepítése

Először telepítened kell a Pocket Code appot az eszközödre. Az appot a Google Play Áruházban találod, ha rákeresel a „Pocket Code” kifejezésre, majd az „Telepítés” gombra koppintasz. Ehhez Google-fiók szükséges. Ezután az eszközöd letölti és telepíti az appot. Ez a lépés az internetkapcsolatod sebességétől függően eltarthat egy ideig.

![Új program (2)](../../../media/game-tutorials/New-Program-2.png)

A Pocket Code sikeres letöltése és telepítése után az appot az alkalmazások között vagy a főképernyődön találod, az eszköztől függően. Az appot könnyen áthelyezheted bárhova.

### 2. Az app indítása

Amikor megnyitod az appot, különböző kategóriákat látsz:

![Új program (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Új projekt létrehozása

A következő lépés az, hogy tényleg létrehozz egy új projektet. Ehhez nyomd meg a jobb alsó sarokban lévő sárga plusz gombot. Most meg kell adnod a projekt nevét, és ki kell választanod, hogy a projekt fekvő legyen-e. Az „OK” gombra koppintva a projekt létrejön.

![Új program](../../../media/game-tutorials/New-Program.png)

### 4. Sikerült! Létrehoztad az első saját projektedet.

Most már telepítetted a Pocket Code-ot, és tudod, hogyan hozz létre új projektet. Most már elkezdhetsz programozni!

Ehhez tudnod kell, hogyan hozz létre új szereplőt egy projektben. Nézd meg az **[Új szereplő](new-object.md)** oktatóanyagot, amely lépésről lépésre elmagyaráz mindent.
