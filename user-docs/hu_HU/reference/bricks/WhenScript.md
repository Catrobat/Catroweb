Akkor futtatja a szkriptet, amikor rákoppintanak az objektumra.

A „Amikor a színpadra koppintanak” blokktól az különbözik, hogy az „Amikor rám koppintanak” az egyes szereplőkre vagy objektumokra vonatkozik, míg az „Amikor a színpadra koppintanak” az egész képernyőre.
