Ez a blokk megvárja a megadott számú ütemet, mielőtt a szkript folytatódik. Olyan, mintha egy dal közben rövid szünetet tartanál, mielőtt a következő hang vagy hangjegy szólna. Képzeld el, hogy egy pillanatra megállsz, számolod az ütemeket, aztán folytatod a műsort.
