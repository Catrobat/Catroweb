Beállítja az objektumra ható súrlódás mértékét, ami befolyásolja, hogy mennyire könnyen csúszik vagy lassul le. Olyan, mintha megváltoztatnád annak a felületnek a csúszósságát, amelyen a karaktered áll: minél nagyobb a súrlódás, annál kevésbé csúszik.
