![Ha ... igaz, akkor](../../../media/bricks/if_brick2.png)

*Megnézi, hogy egy feltétel igaz-e, és ha igen, lefuttat egy utasításcsoportot. Olyan, mintha azt mondanád: „Ha ez igaz, akkor csináld ezt.”*

![Indítás](../../../media/bricks/StartScene.png)

Amikor a jelenet elindul, az X változó értéke 0-ra áll.

![Ha](../../../media/bricks/If.png)

Ha most rákoppintanak az állatra, az X változó értéke 1-gyel nő.

A program ellenőrzi, hogy az X változó egyenlő-e a 2 értékkel.

Ha ez így van, lejátsszuk a Tweet1 hangot, és az X változó értékét 0-ra állítjuk.
