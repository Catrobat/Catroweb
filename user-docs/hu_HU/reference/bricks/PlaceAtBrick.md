![Helyezd ide: x: 100, y: 100](../../../media/bricks/place_at_x_y_brick.png)

Az objektumot a képernyő egy adott pontjára mozgatja, az x és y koordinátákkal megadva. Olyan, mintha a karaktered egy pontos helyre teleportálnád.

A pozíciót egy Descartes-koordinátarendszerhez hasonló rendszerben adjuk meg: az x és y tengely a képernyő közepén halad át, ezért az x = 0 és y = 0 a képernyő közepe.
