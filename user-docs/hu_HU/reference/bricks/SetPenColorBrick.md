![Állítsd a toll színét erre: piros 0, zöld 0, kék 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Ez a blokk megváltoztatja a szereplő tollának színét. Olyan, mintha rajzolás közben egy másik színű tollra váltanál.

**Vörös, zöld, kék (RGB)**: Az RGB színmodell a vörös, zöld és kék fény különböző erősségeivel hoz létre széles színskálát. Minden színösszetevő (vörös, zöld és kék) értéke 0 és 255 között lehet:

- **Vörös**: A szín vörös összetevője. Minél nagyobb az érték, annál több a piros.
- **Zöld**: A szín zöld összetevője. Minél nagyobb az érték, annál több a zöld.
- **Kék**: A szín kék összetevője. Minél nagyobb az érték, annál több a kék.

A vörös, zöld és kék különböző értékeinek kombinálásával bármilyen színt létrehozhatsz. Például:

- `RGB(255, 0, 0)` tiszta piros.
- `RGB(0, 255, 0)` tiszta zöld.
- `RGB(0, 0, 255)` tiszta kék.
- `RGB(255, 255, 255)` fehér (a maximum piros, zöld és kék).
- `RGB(0, 0, 0)` fekete (nincs szín).

Ezeknek a színeknek különböző mennyiségű keverésével létrehozhatók mindazok a színek, amelyeket a digitális képernyőkön látsz.
