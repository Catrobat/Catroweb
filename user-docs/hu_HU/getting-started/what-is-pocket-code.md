A Pocket Code a Catrobat fő appja: ingyenes, nyílt forráskódú mobilalkalmazás, amellyel játékokat, animációkat és interaktív történeteket készíthetsz közvetlenül az okostelefonodon vagy táblagépeden. A Pocket Code **blokkalapú programozási rendszerével** kódblokkokat illeszthetsz össze, mint a puzzle darabjait. Nincs szükség programozási tapasztalatra, ezért kezdőknek is tökéletes!

A Pocket Code nemcsak digitális projektekre használható. Az új **gyártóműhelyi funkcióknak** köszönhetően **SVG-fájlokat** is tervezhetsz vágóplotterekhez. Ez azt jelenti, hogy a digitális alkotásaidból valódi, kézzelfogható tárgyakat készíthetsz, és a képernyőn túli kreatív lehetőségeket fedezhetsz fel.

Akár programozni tanulsz, új ötleteket próbálgatsz, akár programozást tanítasz, a Pocket Code játékos és könnyen elérhető módot kínál arra, hogy belevágj a programozásba.

[További információk](https://catrobat.org/pocket-code/)
