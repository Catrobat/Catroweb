A Pocket Code egy vizuális programozó app, amellyel játékokat, animációkat és interaktív történeteket készíthetsz közvetlenül az okostelefonodon vagy táblagépeden. Egy intuitív, húzd-és-ejtsd felületen, „blokkok” (kódblokkok) segítségével tervezheted meg a projektjeidet, előzetes programozási tudás nélkül. Könnyen adhatsz hozzá hangokat, képeket és mozgást, hogy az ötleteid életre keljenek.

Ez az útmutató segít elkezdeni, és megmutatja, hogyan:

- kezeld a felületet,
- hozd létre az első projektedet,
- dolgozz szereplőkkel és hátterekkel,
- használj blokkokat műveletek programozására, és
- mentsd el a projektedet.

Kezdőknek és tanároknak egyaránt ideális: a Pocket Code ösztönzi a kreativitást, a problémamegoldást és a logikus gondolkodást.
