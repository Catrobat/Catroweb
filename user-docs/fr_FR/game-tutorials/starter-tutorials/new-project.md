### 1. Installer Pocket Code

D’abord, installe l’appli Pocket Code sur ton appareil. Pour cette étape, il faut un compte Google. Ton appareil télécharge et installe l’appli. Cela peut prendre un moment, selon ta connexion internet.

![Nouveau projet (2)](../../../media/game-tutorials/New-Program-2.png)\
Pour trouver l’appli, cherche « Pocket Code » dans le Google Play Store, puis télécharge-la en touchant « Installer ».\
[Ouvrir l’image](../../../media/game-tutorials/New-Program-2.png)

Quand Pocket Code est téléchargé et installé, tu trouves l’appli dans la liste des applis ou sur ton écran d’accueil, selon ton appareil. Tu peux facilement déplacer l’appli où tu veux.

### 2. Ouvrir l’appli

![Nouveau projet (1)](../../../media/game-tutorials/New-Program-1.png)\
Quand tu ouvres l’appli, tu vois plusieurs catégories .\
[Ouvrir l’image](../../../media/game-tutorials/New-Program-1.png)

### 3. Créer un nouveau projet

Maintenant, tu crées vraiment un nouveau projet. Écris un nom pour ton projet et choisis s’il sera en format paysage ou non. Touche « OK » et le projet est créé.

![Nouveau projet](../../../media/game-tutorials/New-Program.png)\
Pour cela, touche le bouton plus jaune en bas à droite.\
[Ouvrir l’image](../../../media/game-tutorials/New-Program.png)

### 4. Bravo ! Tu as créé ton propre nouveau projet.

Tu as installé Pocket Code et tu sais créer un nouveau projet. Maintenant, tu peux commencer à programmer !

Pour cela, tu dois savoir comment créer un nouvel objet dans un projet. Regarde le tutoriel **[Nouvel objet](new-object.md)**, qui t’explique tout pas à pas.
