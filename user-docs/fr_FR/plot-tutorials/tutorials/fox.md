Quand le tracé commence, chaque mouvement est dessiné comme avec un stylo. Ce sont les lignes que le traceur découpe ensuite.

Ce renard est fait seulement de lignes droites (« Avancer de \_\_\_ pas ») et de virages.

**Astuce** : teste ton programme pendant que tu le construis.
