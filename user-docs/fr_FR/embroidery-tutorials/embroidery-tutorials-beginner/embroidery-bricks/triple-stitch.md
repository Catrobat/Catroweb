Le point triple coud chaque point trois fois.

Après le premier point, le point triple revient en arrière et pique. Puis il repart en avant et pique encore.

![Commencer un point triple de longueur 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Il marche comme le [point droit](running-stitch.md).

![Point triple](../../../../media/embroidery-tutorials/TripleStitch.png)

Comme ça, la couture tient plus longtemps.
