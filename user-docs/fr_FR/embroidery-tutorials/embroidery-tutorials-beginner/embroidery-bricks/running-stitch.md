La machine pique sans arrêt, avec une longueur que tu choisis.

En général, on utilise le point droit avec une brique de déplacement.

![Commencer un point droit de longueur 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

La machine commence un point droit et pique tous les **10 pas**.

Ensuite, la machine avance de **200 pas**.

Ça donne **20 points**.

![Point droit](../../../../media/embroidery-tutorials/RunningStitch.png)

Avec le point droit, coudre une couture est plus facile, car tu n’as plus besoin de boucle.
