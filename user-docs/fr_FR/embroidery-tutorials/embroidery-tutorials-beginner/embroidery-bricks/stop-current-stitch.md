Arrête le point en cours.

Tu as besoin de cette brique si tu veux changer la position de l’aiguille après avoir commencé un point droit, un point zigzag ou un point triple.

![Arrêter le point en cours](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

Sinon, une couture en trop apparaîtrait entre les deux.

![Arrêter le point en cours](../../../../media/embroidery-tutorials/StopCurrentStitch.png)
