Dans ce tutoriel, tu apprends tout ce qu’il faut savoir sur les briques de broderie !

Tu n’as pas besoin de savoir programmer pour ça.

Chaque brique de broderie est expliquée avec un exemple.

Si tu n’as pas encore activé les briques de broderie, regarde le tutoriel **[Activer les briques de broderie](../activate-embroidery-bricks.md)**.

*Ici, tu peux télécharger le tutoriel au format PDF* :

[Briques de broderie](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Clique sur les différentes briques pour en savoir plus :**

[![Faire un point](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*La machine pique une fois dans le tissu !*

[![Commencer un point droit de longueur 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*La machine pique sans arrêt, avec une longueur que tu choisis.*

[![Commencer un point zigzag de longueur 2 et de largeur 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Pique sans arrêt, avec une longueur et une largeur que tu choisis.*

[![Commencer un point triple de longueur 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*Le point triple coud chaque point trois fois.*

[![Arrêter le point en cours](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Arrête le point en cours.*
