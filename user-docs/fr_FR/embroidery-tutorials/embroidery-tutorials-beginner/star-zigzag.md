Dans ce tutoriel, tu apprends à broder une étoile avec le point zigzag (58.2 x 61.2mm).

![image (4)](../../../media/embroidery-tutorials/image-4.png)

Tu dois déjà savoir créer un nouvel objet et y ajouter des briques. Si tu as encore besoin d’aide, regarde les tutoriels de la [série Débutant](../../game-tutorials/starter-tutorials/index.md). Les briques de broderie doivent aussi être activées. Tu découvres comment faire dans le tutoriel **[Activer les briques de broderie](activate-embroidery-bricks.md)**.

Pour plus d’informations ou d’idées de motifs, regarde les autres tutoriels.

*Ici, tu peux télécharger le tutoriel au format PDF* :

[Étoile zigzag](../../../media/embroidery-tutorials/Star-ZigZag.pdf)

### 1. Crée un nouvel objet de broderie (voir [Créer des objets de broderie](create-embroidery-objects.md)).

### 2. Commence maintenant et ajoute les briques une par une à ton script.

![Étoile zigzag](../../../media/embroidery-tutorials/Star-ZigZag.png)

### 3. Appuie sur « Jouer » pour lancer ton motif !
