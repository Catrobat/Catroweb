Dans ce tutoriel, tu apprends à activer les briques de broderie.

![Activer les briques de broderie 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Tu n’as pas besoin de savoir programmer pour ça. C’est la première étape pour commencer les tutoriels de broderie. Ensuite, tu pourras dessiner et programmer tes propres motifs, et même les broder sur ton vêtement préféré.

Pour plus d’informations ou d’idées de motifs, regarde les autres tutoriels.

*Ici, tu peux télécharger le tutoriel au format PDF* :

[ActivateEmbroideryBricks](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Lance l’application « Pocket Code ». Suis les clics !

### 2. Ouvre le menu (les points en haut à droite).

![Activer les briques de broderie](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Va dans « Paramètres ».

![Activer les briques de broderie 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Choisis « Extension Broderie ».

![Activer les briques de broderie 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Tu trouves maintenant les briques de broderie dans leur propre catégorie parmi tes briques !

[![Activer les briques de broderie 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Maintenant, tu trouves aussi toutes les briques de broderie parmi les autres briques.

Pour en savoir plus sur chaque brique, regarde la documentation des briques [ici](../../../reference/) ou suis le tutoriel **[Briques de broderie](embroidery-bricks/index.md)**.

Maintenant, tu peux commencer et créer tes propres motifs !

Si tu as besoin d’idées ou d’aide, regarde les autres tutoriels ou continue avec le tutoriel **[Créer des objets de broderie](create-embroidery-objects.md)**.
