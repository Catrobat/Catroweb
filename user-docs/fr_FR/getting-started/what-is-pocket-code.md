Pocket Code est l’appli principale de Catrobat. C’est une appli mobile gratuite et open source pour créer des jeux, des animations et des histoires interactives directement sur ton smartphone ou ta tablette. Avec le **système de blocs** de Pocket Code, tu construis tes projets en assemblant des blocs de code, comme les pièces d’un puzzle. Pas besoin de savoir programmer : c’est parfait pour les débutants !

Pocket Code ne sert pas qu’aux projets sur écran. Avec les nouvelles **fonctions makerspace**, tu peux aussi créer des **fichiers SVG pour les traceurs de découpe**. Tes créations numériques deviennent alors de vrais objets, et tu découvres plein d’idées en dehors de l’écran.

Que tu apprennes à programmer, que tu testes de nouvelles idées ou que tu enseignes la programmation, Pocket Code est une façon ludique et facile de découvrir le code

[Plus d’infos](https://catrobat.org/pocket-code/)
