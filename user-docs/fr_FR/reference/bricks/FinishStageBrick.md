![Quitter le plateau](../../../media/bricks/finish-stage-brick.png)

Cette brique arrête tous les scripts et termine le plateau ou la scène en cours. C’est comme dire : « Cette partie du projet est finie. » Tout s’arrête, et le projet peut passer à une autre scène ou se terminer complètement. Utilise-la quand tu veux finir un plateau ou un niveau de ton projet.
