![Définir la couleur du fil à « #ff0000 »](../../../media/bricks/Set_thread_color_to_ff0000.png)

Avec ce bloc, tu peux changer la couleur du fil de ton projet de broderie. La couleur s’affiche dans ton programme. Ça ne veut pas dire que la machine à broder utilisera exactement ces couleurs.
