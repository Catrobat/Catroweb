![Faire une pause de 1 battement](../../../media/bricks/Pause_for_1_beats.png)

Cette brique fait attendre le script pendant un certain nombre de battements avant de continuer. C’est comme faire une petite pause dans une chanson avant de jouer la note ou le son suivant. Imagine que tu arrêtes ton spectacle un moment, que tu comptes les battements, puis que tu reprends.
