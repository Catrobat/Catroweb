![Définir la transparence à 50 %](../../../media/bricks/Set_transparency_to_50_pct_.png)

Cette brique choisit à quel point un acteur est transparent : 0 % veut dire pas du tout transparent, 100 % veut dire complètement transparent. C’est comme régler l’opacité d’une image.
