![Si … est vrai, alors … Sinon](../../../media/bricks/if_else_brick2.png)

*Vérifie si une condition est vraie. Si elle est vraie, il exécute un groupe d’instructions, sinon il en exécute un autre. C’est comme donner deux choix : « Si c’est vrai, fais ceci ; sinon, fais cela. »*

![Démarrer la scène](../../../media/bricks/StartScene.png)

Quand la scène démarre, la variable X est mise à 0.

![Si Sinon](../../../media/bricks/IfElse.png)

Si on touche maintenant l’animal, le programme vérifie si X modulo 2 est vrai, c’est-à-dire si X est un nombre impair.

Si c’est le cas, le son Tweet1 est joué et la variable X augmente de 1.

Sinon, si X est pair, X augmente seulement de 1.

Les instructions à exécuter sont séparées par un Fin si.
