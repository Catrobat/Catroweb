![Attendre que tous les autres scripts soient arrêtés](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Cette brique met le script en pause jusqu’à ce que tous les autres scripts du projet soient finis. Imagine que tu mets ton script en attente jusqu’à ce que tout le reste soit terminé. C’est utile pour être sûr qu’aucune autre action ne se passe avant de continuer ton script.
