![Quand la scène démarre](../../../media/bricks/When_scene_starts_btn2.png)

Si tu utilises ce bloc, le script démarre tout de suite quand la scène démarre. Une scène est le début de ton programme. Une scène est un nouvel écran de ton programme, où d’autres éléments peuvent s’afficher et où différentes choses peuvent se passer. Tu peux avoir plusieurs scènes pour les différentes étapes de ton programme. Par exemple une scène pour l’intro, une scène pour le menu principal, une pour le premier niveau, une pour le deuxième niveau, et ainsi de suite. Pour les programmes plus simples, une seule scène peut suffire : le début de ton programme est alors aussi le début de la scène.

Comme tous les scripts, celui-ci commence par une brique d’événement : l’événement dit **quand** le script démarre, et les briques qui suivent disent au programme **quoi** faire.
