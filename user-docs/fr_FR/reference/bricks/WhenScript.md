![Quand on me touche](../../../media/bricks/when-tapped2.png)

Lance le script quand on touche l’objet.

La différence avec le bloc *« Quand on touche le plateau »* : *« Quand on me touche »* concerne un seul lutin ou objet, alors que *« Quand on touche le plateau »* concerne tout l’écran.
