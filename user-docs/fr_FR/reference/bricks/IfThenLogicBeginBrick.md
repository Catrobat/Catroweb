![Si … est vrai, alors](../../../media/bricks/if_brick2.png)

*Vérifie si une condition est vraie. Si elle est vraie, il exécute un groupe d’instructions. C’est comme dire : « Si c’est vrai, alors fais ceci. »*

![Démarrer la scène](../../../media/bricks/StartScene.png)

Quand la scène démarre, la variable X est mise à 0.

![Si](../../../media/bricks/If.png)

Si on touche maintenant l’animal, la variable X augmente de 1.

Le programme vérifie si la variable X est égale à 2.

Si c’est le cas, le son Tweet1 est joué et la variable X est remise à 0.
