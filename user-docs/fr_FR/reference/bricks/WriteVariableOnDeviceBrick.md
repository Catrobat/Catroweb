![Écrire la variable sur l’appareil nouveau](../../../media/bricks/Write_variable_on_device_new.png)

Enregistre la valeur d’une variable sur ton appareil pour pouvoir l’utiliser plus tard, même après avoir fermé l’appli. C’est comme écrire une note sur ton téléphone pour t’en souvenir plus tard.
