![Définir le frottement à](../../../media/bricks/set_friction_to_brick2.png)

Règle le frottement de l’objet. Le frottement change la facilité avec laquelle l’objet glisse ou ralentit. C’est comme rendre plus ou moins glissant le sol sous ton personnage : plus il y a de frottement, moins il glisse.
