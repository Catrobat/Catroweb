![Quand je commence comme clone](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Donne des instructions à un clone d’un objet pour qu’il fasse les actions que tu veux. Le clone peut faire la même chose que l’objet d’origine, mais tu le contrôles séparément. Tu peux choisir différents comportements ou propriétés pour le clone, selon ce dont tu as besoin.
