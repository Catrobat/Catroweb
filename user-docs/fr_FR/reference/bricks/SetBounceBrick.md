![Définir le facteur de rebond à](../../../media/bricks/set_bounce_factor_to_brick.png)

Choisit à quel point l’objet rebondit quand il touche quelque chose. Plus le pourcentage est grand, plus le rebond est fort. C’est comme décider à quel point ton personnage rebondit sur les murs ou sur d’autres objets.
