![Créer un clone de](../../../media/bricks/create_clone_of_brick2.png)

Cette brique fait une copie de l’objet choisi. Cette copie s’appelle un clone et elle se comporte comme l’original. Imagine que tu copies un personnage ou un objet dans ton jeu. Le clone peut avoir ses propres comportements et scripts. Tu peux donc créer plusieurs exemplaires d’un objet, qui agissent chacun de leur côté.
