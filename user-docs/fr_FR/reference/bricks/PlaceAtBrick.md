![Placer à x, y](../../../media/bricks/place_at_x_y_brick.png)

Déplace l’objet à une position précise de l’écran, donnée par les coordonnées x et y. C’est comme téléporter ton personnage à un endroit exact.

La position est donnée dans un repère comme le plan cartésien : les axes x et y passent par le centre de l’écran, donc x = 0 et y = 0, c’est le milieu de l’écran.
