![Arrêter le son](../../../media/bricks/Stop_sound_record.png)

Cette brique arrête un son précis. C’est comme appuyer sur stop pour une seule chanson, pendant que les autres sons ou la musique continuent. Imagine que tu dis à ton personnage d’arrêter de jouer une seule piste sonore.
