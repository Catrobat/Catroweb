![Supprimer ce clone](../../../media/bricks/delete_clone_brick2.png)

Cette brique supprime le clone qui a été créé avec la brique « Créer un clone de ». C’est comme dire : « Enlève cette copie. » Utilise-la pour garder le contrôle sur le nombre de clones dans ton projet, et pour les supprimer quand tu n’en as plus besoin.
