इस ट्यूटोरियल में तुम सीखोगे कि अपने प्रोजेक्ट में नई वस्तु कैसे बनाते हैं और इसके कौन-कौन से तरीके हैं।

![New Object](../../../media/game-tutorials/New-Object.png)\
इस ट्यूटोरियल में तुम सीखोगे कि अपने प्रोजेक्ट में नई वस्तु कैसे बनाते हैं और इसके कौन-कौन से तरीके हैं।\
[चित्र खोलो](../../../media/game-tutorials/New-Object.png)

इसके लिए तुम्हारे पास Pocket Code ऐप पहले से डाउनलोड होना चाहिए और तुम्हें नया प्रोजेक्ट बनाना आता होना चाहिए। अगर इसमें मदद चाहिए, तो **[नया प्रोजेक्ट](new-project.md)**-ट्यूटोरियल देखो।

*यह ट्यूटोरियल PDF फ़ॉर्मैट में यहाँ से डाउनलोड कर सकते हो:*

[PDF खोलो](../../../media/game-tutorials/New-Object.pdf)

### 1. नई वस्तु बनाओ

सबसे पहले अपना नया प्रोजेक्ट खोलो।

वह तुम्हें Pocket Code ऐप की होम स्क्रीन पर मिलेगा। अगर तुम्हारे पास एक से ज़्यादा प्रोजेक्ट हैं, तो "Projects on device" पर टैप करो। फिर अपना नया प्रोजेक्ट चुनो। अगर तुमने अभी तक नया प्रोजेक्ट नहीं बनाया है या इसकी ज़्यादा जानकारी चाहिए, तो **[नया प्रोजेक्ट](new-project.md)**-ट्यूटोरियल देखो।

### 2. नई वस्तु बनाओ

अब तुम नई वस्तु बनाने के लिए तैयार हो। तुम्हें एक नई विंडो दिखेगी, जिसमें सात विकल्प होंगे।

![New Object (1)](../../../media/game-tutorials/New-Object-1.png)\
बस नीचे दाएँ कोने में पीले प्लस-बटन को दबाओ।\
[चित्र खोलो](../../../media/game-tutorials/New-Object-1.png)

### 3. बनाने के तरीके

![New Object (2)](../../../media/game-tutorials/New-Object-2.png)\
ये वे विकल्प हैं जिनमें से तुम चुन सकते हो.\
[चित्र खोलो](../../../media/game-tutorials/New-Object-2.png)

### 4. चित्र बनाओ

शुरुआत को आसान रखने के लिए, हम "बनाएँ" विकल्प इस्तेमाल करेंगे और बस एक बिंदु बनाएँगे। जब Pocket Paint में बिंदु बन जाए, तो तुम उसे बंद कर सकते हो (एक कदम पीछे जाकर)।

### 5. नाम दो

अब अपने चित्र को एक नाम दो।

### 6. जगह तय करो

उसके बाद उँगली से उसे बाएँ/दाएँ या ऊपर/नीचे खिसकाकर देखकर जगह तय करो।

![New Object (3)](../../../media/game-tutorials/New-Object-3.png)\
ऊपर दाएँ कोने के बटन से उसे सहेज लो।\
[चित्र खोलो](../../../media/game-tutorials/New-Object-3.png)

### 7. हो गया! तुमने अपनी नई वस्तु बना ली।

अब तुम्हारे पास एक प्रोजेक्ट है, जिसमें एक वस्तु है और तुम उसे प्रोग्राम कर सकते हो!

ऐसा करने के लिए तुम्हें पता होना चाहिए कि कौन-कौन से ब्लॉक उपलब्ध हैं। **[पहले ब्लॉक](first-bricks.md)**-ट्यूटोरियल में ब्लॉक की अलग-अलग श्रेणियों की अच्छी जानकारी है। लेकिन तुम सीधे अपने पहले प्रोजेक्ट से भी शुरू कर सकते हो। शुरुआती सीरीज़ में से कोई अच्छा ट्यूटोरियल चुन लो।
