इस ट्यूटोरियल में तुम वह सब सीखोगे जो अपना पहला प्रोजेक्ट शुरू करने के लिए Pocket Code के बारे में जानना ज़रूरी है। हम तुम्हें कदम-दर-कदम बताएँगे कि ऐप कैसे डाउनलोड करें, उसे कैसे खोलें और नया प्रोजेक्ट कैसे बनाएँ।

![New Program](../../../media/game-tutorials/New-Program.png)\
हम तुम्हें कदम-दर-कदम बताएँगे कि ऐप कैसे डाउनलोड करें, उसे कैसे खोलें और नया प्रोजेक्ट कैसे बनाएँ।\
[चित्र खोलो](../../../media/game-tutorials/New-Program.png)

यह पहला ट्यूटोरियल है, और इसके लिए तुम्हें किसी पहले के ज्ञान की ज़रूरत नहीं है।

तो देर किस बात की? अपना फ़ोन उठाओ और अभी शुरू करो!

*यह ट्यूटोरियल PDF फ़ॉर्मैट में यहाँ से डाउनलोड कर सकते हो:*

[PDF खोलो](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code इंस्टॉल करो

सबसे पहले तुम्हें अपने डिवाइस पर Pocket Code ऐप इंस्टॉल करना होगा। इस कदम के लिए Google अकाउंट चाहिए। अब तुम्हारा डिवाइस ऐप डाउनलोड करके इंस्टॉल करेगा। इंटरनेट की स्पीड के हिसाब से इसमें थोड़ा समय लग सकता है।

![New Program (2)](../../../media/game-tutorials/New-Program-2.png)\
तुम Google Play Store में "Pocket Code" खोजकर ऐप ढूँढ सकते हो और "इंस्टॉल करें" दबाकर उसे डाउनलोड कर सकते हो।\
[चित्र खोलो](../../../media/game-tutorials/New-Program-2.png)

Pocket Code इंस्टॉल हो जाने के बाद तुम उसे ऐप ड्रॉअर में या होम स्क्रीन पर पा सकते हो, यह तुम्हारे डिवाइस पर निर्भर करता है। तुम ऐप को जहाँ चाहो वहाँ रख सकते हो।

### 2. ऐप शुरू करो

![New Program (1)](../../../media/game-tutorials/New-Program-1.png)\
जब तुम ऐप खोलते हो, तो तुम्हें अलग-अलग श्रेणियाँ दिखती हैं.\
[चित्र खोलो](../../../media/game-tutorials/New-Program-1.png)

### 3. नया प्रोजेक्ट बनाओ

अगला कदम है असल में नया प्रोजेक्ट बनाना। अब तुम्हें प्रोजेक्ट का नाम लिखना होगा और चुनना होगा कि तुम्हारा प्रोजेक्ट लैंडस्केप (आड़ा) हो या नहीं। "OK" दबाने से प्रोजेक्ट बन जाएगा।

![New Program](../../../media/game-tutorials/New-Program.png)\
ऐसा करने के लिए नीचे दाएँ कोने में पीले प्लस-बटन को दबाओ।\
[चित्र खोलो](../../../media/game-tutorials/New-Program.png)

### 4. हो गया! तुमने अपना प्रोजेक्ट बना लिया।

अब तुमने Pocket Code इंस्टॉल कर लिया है और नया प्रोजेक्ट बनाना सीख लिया है। अब तुम प्रोग्राम करना शुरू कर सकते हो!

इसके लिए तुम्हें जानना होगा कि प्रोजेक्ट में नई वस्तु कैसे बनाते हैं। **[नई वस्तु](new-object.md)**-ट्यूटोरियल देखो, जिसमें यह सब कदम-दर-कदम समझाया गया है।
