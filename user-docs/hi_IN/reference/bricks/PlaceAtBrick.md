यह वस्तु को स्क्रीन पर एक खास जगह पर ले जाता है, जो x और y निर्देशांक से तय होती है। यह ऐसा है जैसे अपने किरदार को सीधे एक सटीक जगह पर पहुँचा देना।

जगह एक निर्देशांक प्रणाली में तय होती है, जैसे कार्टेसियन समतल: x और y अक्ष स्क्रीन के बीच से गुज़रते हैं, इसलिए x = 0 और y = 0 स्क्रीन का बीच वाला हिस्सा है।
