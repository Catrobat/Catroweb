![जब आप इससे टकराकर उछलें](../../../media/bricks/when_you_bounce_off_brick2.png)

जब वस्तु किसी तय सतह या वस्तु से टकराकर उछलती है, तो एक प्रतिक्रिया या काम शुरू करने की व्यवस्था करता है। यह ऐसा है जैसे कहना, "जब भी मेरा किरदार दीवार या किसी दूसरी चीज़ से टकराकर उछले, तब यह काम करो।"
