![अगर ... सत्य है तो ... नहीं तो](../../../media/bricks/if_else_brick2.png)

*जाँचता है कि कोई शर्त सही है या नहीं। अगर सही है, तो निर्देशों का एक सेट चलाता है, और अगर नहीं है, तो दूसरा सेट। यह ऐसा है जैसे दो विकल्प देना: "अगर यह सही है, तो यह करो; नहीं तो वह करो।"*

![जब दृश्य शुरू हो](../../../media/bricks/StartScene.png)

जब दृश्य शुरू होता है, तो वेरिएबल X को 0 सेट किया जाता है।

![अगर ... सत्य है तो ... नहीं तो](../../../media/bricks/IfElse.png)

अगर जानवर पर अभी टैप किया जाता है, तो जाँचा जाता है कि X को 2 से भाग देने पर शेषफल सत्य है या नहीं, यानी X विषम संख्या है या नहीं।
अगर ऐसा है, तो ध्वनि Tweet1 चलती है और वेरिएबल X में 1 जोड़ दिया जाता है।
नहीं तो, अगर X सम है, तो सिर्फ़ X में 1 जोड़ा जाता है।
चलने वाले निर्देश "अगर का अंत" से अलग किए जाते हैं।
