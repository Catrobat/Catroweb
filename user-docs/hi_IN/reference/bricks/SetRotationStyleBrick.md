बदलता है कि वस्तु कैसे घूमती है (चारों ओर, केवल बाएँ-दाएँ, या बिलकुल न घूमे)। यह ऐसा है जैसे तय करना कि तुम्हारा किरदार पूरा घूम सकता है, सिर्फ़ बाएँ-दाएँ पलट सकता है, या बिलकुल नहीं घूमेगा।
