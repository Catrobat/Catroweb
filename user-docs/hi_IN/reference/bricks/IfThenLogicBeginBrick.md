![अगर ... सत्य है तो](../../../media/bricks/if_brick2.png)

*जाँचता है कि कोई शर्त सही है या नहीं, और अगर सही है, तो निर्देशों का एक सेट चलाता है। यह ऐसा है जैसे कहना, "अगर यह सही है, तो यह करो।"*

![जब दृश्य शुरू हो](../../../media/bricks/StartScene.png)

जब दृश्य शुरू होता है, तो वेरिएबल X को 0 सेट किया जाता है।

![अगर](../../../media/bricks/If.png)

अगर जानवर पर अभी टैप किया जाता है, तो वेरिएबल X में 1 जोड़ दिया जाता है।
प्रोग्राम जाँचता है कि वेरिएबल X बराबर 2 है या नहीं।
अगर ऐसा है, तो ध्वनि Tweet1 चलती है और वेरिएबल X को 0 सेट किया जाता है।
