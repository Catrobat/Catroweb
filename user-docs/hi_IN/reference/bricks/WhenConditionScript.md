![जब दृश्य शुरू हो](../../../media/bricks/StartScene.png)

जब दृश्य शुरू होता है, तो वेरिएबल X को 0 सेट किया जाता है।

![जब टैप किया जाए](../../../media/bricks/WhenTappedWhenModulo.png)

अगर जानवर पर अभी टैप किया जाता है, तो X में 1 जोड़ दिया जाता है।
जब X को 2 से भाग देने पर शेषफल सत्य हो जाता है, यानी अगर X विषम संख्या है, तो ध्वनि Tweet1 चलती है।
