जब तुम Pocket Code शुरू करते हो, तो तुम्हें यह मुख्य स्क्रीन दिखती है।

![मुख्य स्क्रीन](../../../media/getting-started/MainScreen-e1732269599192.jpg)

ऊपर दाएँ कोने में ![Help](../../../media/getting-started/Screenshot-2024-11-22-111748.png) चिह्न है, जो तुम्हें Catrobat दस्तावेज़ तक ले जाता है, जहाँ तुम्हारे लिए काम की सलाह है।

उसके बगल में मेनू ![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png) है। वहाँ से तुम सेटिंग में जा सकते हो, जहाँ तुम भाषा बदल सकते हो या प्लॉट ब्लॉक जैसे एक्सटेंशन चालू कर सकते हो।

नीचे तुम्हें तुम्हारा सबसे हाल में बदला गया प्रोजेक्ट दिखता है। प्रोजेक्ट स्क्रीन खोलने के लिए एडिट आइकन ![Edit icon](../../../media/getting-started/Screenshot-2024-11-22-111825.png) पर टैप करो, जहाँ तुम अपने प्रोजेक्ट पर काम जारी रख सकते हो।

अपना प्रोजेक्ट चलाने के लिए प्ले बटन ![Start your Project](../../../media/getting-started/Screenshot-2024-11-22-111818.png) दबाओ।

"Projects on device" पर क्लिक करके तुम अपने सहेजे हुए प्रोजेक्ट देख सकते हो। ![Projects on Device](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

अगर तुम दूसरे लोगों के बनाए और प्रोजेक्ट देखना चाहते हो, तो Share पर **Catrobat Community** पर क्लिक करो। वहाँ तुम्हें बहुत सारे बढ़िया प्रोजेक्ट मिलेंगे। ![Catrobat Community](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

अगर तुम नया प्रोजेक्ट बनाना चाहते हो, तो प्लस आइकन पर क्लिक करो। ![Add](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
