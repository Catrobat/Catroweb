මෙම උපදෙස් මඟින්, ඔයා තාරකාවක් (57 x 60mm) සරඹ කරන ආකාරය ඉගෙන ගනු ඇත.

![රූපය (5)](../../../media/embroidery-tutorials/image-5.png)

ඔයා දැනටමත් දන්නවා ඇති අලුත් වස්තුවක් නිර්මාණය කර කේතය ඇතුල් කරන ආකාරය. ඔයාට තවමත් උදව් අවශ් ය නම් [ආරම්භක මාලාව](../../game-tutorials/starter-tutorials/index.md) හි ඇති උපදෙස් පරීක්ෂා කරන්න. ඊට අමතරව, විහිදුම් කේතය දැනටමත් ක් රියාත්මක කළ යුතුයි. ඔයාට මෙය කළ හැකි ආකාරය දැනගත හැකිය **[විහිදුම් කේතය ක් රියාත්මක කරන්න](activate-embroidery-bricks.md)** - නිබන්ධනය.

වැඩි විස්තර හෝ සැලසුම් යෝජනා සඳහා වෙනත් උපදෙස් බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත හැකිය*:

[තරු](../../../media/embroidery-tutorials/Star.pdf)

### 1. නව මැහුම් වස්තුවක් නිර්මාණය කරන්න (බලන්න [විහිදුම් වස්තූන් නිර්මාණය කරන්න](create-embroidery-objects.md)).

### 2. දැන් පටන් ගන්න, ඔයාගේ script එකට පියවරෙන් පියවර code block ඇතුලත් කරන්න.

![තරු](../../../media/embroidery-tutorials/Star.png)

### 3. සෙල්ලම් කරන්න, ඔයාගේ නිර්මාණය පටන් ගන්න!
