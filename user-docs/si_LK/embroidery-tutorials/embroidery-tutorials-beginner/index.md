ඔයාට ඕනද නිර්මාණශීලී වෙන්න ඒ වගේම සෙල්ලම් කරන විදිහකින් කේතකරණය ඉගෙන ගන්න? ඔයාත් කැමතිද, පසුව භාවිතා කරන්න, ඇඳගෙන බලන්න සහ අගය කරන්න පුළුවන් දේවල් නිර්මාණය කරන්න?

Embroidery Designer සමඟ ඔයාට පෙර අත්දැකීම් නොමැතිව, ඔයාගේ මෝස්තරය ටී ෂර්ට් එකක්, බෑග් එකක්, කලිසමක්, ස්මාර්ට්ෆෝන් පෙට්ටියක් හෝ ඔයාගේ සපත්තු මත ස්වයංක් රීයව සරඹා ගන්නා මැෂින් එකක් වැඩසටහන්ගත කළ හැකිය. රෙදි වලින් කරන හැමදේම හයි කරන්න පුළුවන්. ඔයාගේ පරිකල්පනය හා නිර්මාණශීලිත්වය නිදහස් කරන්න! ඔයාට අපගේ Catrobat ප් රජාවෙන් වෙනත් අයගේ නිර්මාණ බාගත කර සංස්කරණය කළ හැකිය. ඇත්තෙන්ම, ඔයාට ඔයාගේ ව් යාපෘති ඔයාගේ මිතුරන් හා මුළු ලෝකයම සමඟ බෙදා ගත හැකිය!
