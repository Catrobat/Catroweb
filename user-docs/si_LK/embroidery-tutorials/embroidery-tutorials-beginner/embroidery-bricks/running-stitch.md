යන්ත් රය දිගින් දිගටම වෙනස් වන දිගකින් සකස් කිරීමට ඉඩ දෙයි.

සාමාන් යයෙන් ඔයා ක් රියාත්මක කරන ස්විචය චලනය කිරීමේ කේතය සමග ඒකාබද්ධ කරනවා.

![මෙම දිගින් ධාවන මැස්ම ආරම්භ කරන්න: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

යන්ත් රය ධාවන සීරීම ආරම්භ කරන අතර එය සෑම **පියවර 10 ක්** සීරීමකින්ම සිදු වේ.

ඊට පස්සේ යන්ත් රය ගමන් කරනවා **පියවර 200ක්**.

මේ නිසා **නියපොතු 20ක්**.

![මෙම දිගින් ධාවන මැස්ම ආරම්භ කරන්න:](../../../../media/embroidery-tutorials/RunningStitch.png)

ධාවන සීරීම මඟින් සීරීම පහසු වේ, මන්ද ඔයාට තවදුරටත් ලූපයක් අවශ් ය නොවනු ඇත.
