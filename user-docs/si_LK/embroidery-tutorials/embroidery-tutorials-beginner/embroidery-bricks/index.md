මෙම උපදේශනය තුළ ඔයා බ් රෝඩරි කේතය blocks ගැන දැන ගැනීමට අවශ්ය සියලු දේ ඉගෙන ගනු ඇත!

ඔයාට මේකට වැඩසටහන්කරණ දැනුමක් ඕන නෑ.

හැම බ් රෝඩරි කේතයකටම උදාහරණයක් එක්ක පැහැදිලි කරන්නම්.

ඔයා තවමත් Embroidery-code block ක් රියාත්මක කර නොමැති නම්, **[විහිදුම් කේතය ක් රියාත්මක කරන්න](../activate-embroidery-bricks.md)** - නිබන්ධනය බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත හැකිය*:

[විහිදුම් කේතය](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**ඒ ගැන වැඩි විස්තර දැනගන්න විවිධ කේත කොටස් මත ක්ලික් කරන්න:**

[![මැස්ම](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*යන්ත් රය එක පාරක් රෙදි එකට හකුලන්න ඉඩ දෙන්න!*

[![මෙම දිගින් ධාවන මැස්ම ආරම්භ කරන්න: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*යන්ත් රය දිගින් දිගටම වෙනස් වන දිගකින් සකස් කිරීමට ඉඩ දෙයි.*

[![මෙම දිගින් සිග්සැග් මැස්ම ආරම්භ කරන්න: 2 සහ පළල: 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*දිග සහ පළල වෙනස්ව නිතරම සකස් කරන්න.*

[![මෙම දිගින් ත්‍රිත්ව මැස්ම ආරම්භ කරන්න: 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*තුන් ගුණයක් තියෙන සයිට් එක හැම සයිට් එකක්ම තුන් පාරක් හයි කරනවා.*

[![වත්මන් මැස්ම නවත්වන්න](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*දැන් තියෙන සීරීම නතර කරන්න.*

ඔයාට තවත් බ් රෝඩරි කේතය සහ ඒවා පිළිබඳ තොරතුරු සොයාගත හැකිය [මෙතනින්](../../../../reference/#category_embroidery).

වැඩි විස්තර හෝ සැලසුම් යෝජනා සඳහා වෙනත් උපදෙස් බලන්න!
