දැන් තියෙන සීරීම නතර කරන්න.

ඔයාට මෙම කේතය අවශ් ය වනු ඇත නියපොතු ස්ථානය වෙනස් කිරීමට ඔයා ධාවනය, සිග්සාක් හෝ ත්රිත්ව ස්ටීච් ආරම්භ කිරීමෙන් පසු.

![වත්මන් මැස්ම නවත්වන්න](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

එහෙම නැත්නම් අනවශ් ය මැදි සීරීමක් වෙනවා.
