දිග සහ පළල වෙනස්ව නිතරම සකස් කරන්න.

සිග්සාග් රටාවකට සකස් කරන්න.

![මෙම දිගින් සිග්සැග් මැස්ම ආරම්භ කරන්න: 2 සහ පළල: 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

මෙම කේතය දන්නා පරිදි දිග සහ පළල සඳහා විවිධ අගයන් උත්සාහ කරන්න.

![මෙම දිගින් සිග්සැග් මැස්ම ආරම්භ කරන්න:](../../../../media/embroidery-tutorials/ZigzagStitch.png)

ඔයාට පුළුවන් සිග්සාක් සීරීමෙන් ඝනම සීරීම් කරන්න.
