මෙම උපදෙස් මඟින් ඔයාට වස්තූන් නිර්මාණය කරන ආකාරය ඉගෙන ගන්න පුළුවන්.

මේ ටියුටෝරල් එක සඳහා, ඔයා දැනටමත් ව් යාපෘතියක් නිර්මාණය කරන ආකාරය දැනගත යුතුයි. ඔයාට උදව්වක් ඕන නම් [ආරම්භක මාලාව](../../game-tutorials/starter-tutorials/index.md) වෙතින් ලැබෙන උපදෙස් බලන්න.

වැඩි විස්තර හෝ සැලසුම් යෝජනා සඳහා, වෙනත් උපදෙස් බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත හැකිය*:

[විහිදුම් වස්තූන් නිර්මාණය කරන්න](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. ඔයාගේ ව් යාපෘතියේ පහළ දකුණු පස ඇති ප්ලස් බොත්තම මත ක්ලික් කරන්න නව වස්තුවක් එකතු කිරීමට.

![විහිදුම් වස්තූන් නිර්මාණය කරන්න](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. පින්තූරයක් තෝරාගන්න, මාධ් ය පුස්තකාලයට යන්න.

![විහිදුම් වස්තූන් නිර්මාණය කරන්න (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. විහිදුම් යන්ත් රයේ ඉඳිකටුවේ එක් මට්ටමක් නියෝජනය කරන විහිදුම් වස්තුවක්. විහිදුම් වස්තූන් කිහිපයක් එකින් එක විහිදුවනු ඇත. මෙය වර්ණ කිහිපයක් භාවිතා කිරීමට ඉඩ සලසයි.

ඔයාට පුළුවන් ඔයාගේ වස්තුව තෝරන්න ඔයා කැමති වර්ණය අනුව.

පහළට පෙරළලා ගැලපෙන ඊතලය හොයන්න.

![විහිදුම් වස්තූන් නිර්මාණය කිරීම (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. ඔයාගේ නව වස්තුවට සුදුසු නම සහ මුද් රණය කරන්න හරි.

![විහිදුම් වස්තූන් සාදන්න (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. දැන් ඔයා අලුත් වස්තුවක් නිර්මාණය කරලා තියෙනවා. ඔයාට දැන් ස්ක් රිප්ට් එකක් එකතු කරලා වස්තුව වැඩසටහන්ගත කරන්න පුළුවන්.

![විහිදුම් වස්තූන් නිර්මාණය කිරීම (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

දැන් ඔයා දන්නවා වස්තුවක් නිර්මාණය කරන්නේ කොහොමද කියලා. ඔයා පාවිච්චි කරන්න කැමති හැම වර්ණයකටම අලුත් වස්තුවක් එකතු කරන්න.

ඔයාට පුළුවන් හැම වර්ණයකම ස්ක් රිප්ට් එකක් එකතු කරලා ඔයාගේම නිර්මාණ වැඩසටහන් කරන්න, ඊට පස්සේ ඒක බඳන්න.

ඔයාට ආශ්වාදයක් හෝ උදව්වක් අවශ් යද? අපේ අනිත් ටියුටෝරියල් බලන්න!
