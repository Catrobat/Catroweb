මෙම උපදෙස් මඟින්, එම්බ් රොයිඩරි කේතය ක් රියාත්මක කිරීම පැහැදිලි කරනු ඇත.

![විහිදුම් ක් රියාත්මක කරන්නBricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

ඔයාට මේකට වැඩසටහන්කරණ දැනුමක් ඕන නෑ. මේක තමයි විහිදුම් උපදෙස් පටන් ගන්න මුල්ම පියවර. පසුව ඔයාට ඔයාගේ ප් රියතම රෙදිපිළි කෑල්ලට ඔයාගේම නිර්මාණ සැලසුම් කර, වැඩසටහන්ගත කර, පවා සරසා ගත හැකිය.

වැඩි විස්තර හෝ සැලසුම් යෝජනා සඳහා වෙනත් උපදෙස් බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත හැකිය*:

[සක් රිය කරන්න බ් රයික්ස්](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. “Pocket Code” -ඇප් එක ඇරඹුනොත් ක්ලික් කරන්න!

### 2. මෙනුව විවෘත කරන්න (ඉහළ දකුණු පැත්තේ තිත්).

![විහිදුම් කේතය ක් රියාත්මක කරන්න](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. “සැකසීම්” වෙත යන්න.

![විහිදුම් ක් රියාත්මක කරන්නBricks3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. තෝරන්න “එම්බ්‍රොයිඩරි දිගුව”.

![විහිදුම් ක් රියාත්මක කරන්නBricks4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. ඔයා ඔයාගේ කේතය කොටස් තුළම විහිදුම් කේතය කොටස් ලෙස සොයා ගනු ඇත!

[![විහිදුම් ක් රියාත්මක කරන්නBricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

දැන් ඔයාලට අනිත් කේත බ්ලොක් වල තියෙන සියලුම එම්බ් රයිඩරි කේත බ්ලොක්ස් හොයාගන්න පුළුවන්.

සෑම කේත කොටසක් ගැනම වැඩි විස්තර සඳහා, කේත කොටස් [මෙතනින්](../../../reference/) පිළිබඳ ලේඛන පරීක්ෂා කිරීමට නිදහස් වන්න හෝ ඒ සඳහා **[විහිදුම් කේතය](embroidery-bricks/index.md)** - නිබන්ධනය අනුගමනය කරන්න.

දැන් ඔයාට පුළුවන් ඔයාගේම නිර්මාණ හදන්න පටන් ගන්න!

ඔයාට අදහස් හෝ උදව් අවශ් ය නම්, වෙනත් උපදෙස් බලන්න **[විහිදුම් වස්තූන් නිර්මාණය කරන්න](create-embroidery-objects.md)** - උපදෙස් සමඟ ඉදිරියට යන්න.
