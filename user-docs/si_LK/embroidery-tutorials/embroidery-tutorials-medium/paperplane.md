මෙම උපදෙස් මඟින්, ඔයා කඩදාසි පුවරුවක් (58.2 x 80.7mm) සරඹ කිරීම ඉගෙන ගනු ඇත.

![පොත් පත් රිකා](../../../media/embroidery-tutorials/Papierflieger.png)

ඔයා තවමත් කිසිවක් සරසා නොමැති නම් [ආරම්භකයා](../embroidery-tutorials-beginner/index.md) මාලාවේ සරසවි නිබන්ධන දෙස බලන්න.

වැඩි විස්තර හෝ සැලසුම් යෝජනා සඳහා වෙනත් උපදෙස් බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත හැකිය*:

[කඩදාසි තලය](../../../media/embroidery-tutorials/Paper-Plane.pdf)

### 1. නව මැහුම් වස්තුවක් නිර්මාණය කරන්න [විහිදුම් වස්තූන් නිර්මාණය කරන්න](../embroidery-tutorials-beginner/create-embroidery-objects.md) බලන්න) සහ පහත සඳහන් script එක ඇතුල් කරන්න:

![කඩදාසි පුවරුව](../../../media/embroidery-tutorials/Paperplane.png)

### 2. සෙල්ලම් කරන්න, ඔයාගේ නිර්මාණය පටන් ගන්න!
