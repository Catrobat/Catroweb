මෙම උපදෙස් මඟින් ඔයා හදවතක් (103.6 x 112.8mm) සරඹ කරන ආකාරය ඉගෙන ගනු ඇත.

![රූපය (10)](../../../media/embroidery-tutorials/image-10.png)

ඔයා දැනටමත් දන්නව ඇති ඒක මොකක්ද කියලා, කොහොමද වැඩ කරන්නේ කියලා.

**[අර්ධ චක් රය](../embroidery-tutorials-beginner/semicircle.md)** - මෙම උපදෙස් සඳහා උපකාරී විය හැකිය.

ඔයා තවමත් කිසිවක් සරසා නොමැති නම් [ආරම්භකයා](../embroidery-tutorials-beginner/index.md) මාලාවේ සරසවි නිබන්ධන දෙස බලන්න.

වැඩි විස්තර හෝ සැලසුම් යෝජනා සඳහා වෙනත් උපදෙස් බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත හැකිය*:

[හදවත](../../../media/embroidery-tutorials/Heart.pdf)

### 1. නව මැහුම් වස්තුවක් නිර්මාණය කරන්න [විහිදුම් වස්තූන් නිර්මාණය කරන්න](../embroidery-tutorials-beginner/create-embroidery-objects.md) බලන්න) පහත සඳහන් ස්ක් රිප්ට් ඇතුලත් කරන්න:

### 2. මූලික ව් යුහය

![හදවත](../../../media/embroidery-tutorials/Heart.png)

### 3. අර්ධ කව

මේ කොටස අර්ධ චක් ර පණිවිඩය යවන හැම අවස්ථාවකදීම කැඳවනවා. ඒක ඔයාගේ ලේඛනයටත් එකතු කරන්න.

![හදවත (1)](../../../media/embroidery-tutorials/Heart-1.png)

### 4. සෙල්ලම් කරන්න, ඔයාගේ නිර්මාණය පටන් ගන්න!
