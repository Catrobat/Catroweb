මෙම උපදෙස් මඟින්, ඔයා මලක් (73 x 74.2mm) සරඹ කරන ආකාරය ඉගෙන ගනු ඇත.

![රූපය (11)](../../../media/embroidery-tutorials/image-11.png)

ඔයා දැනටමත් දන්නව ඇති ඒක මොකක්ද කියලා, කොහොමද වැඩ කරන්නේ කියලා.

**[රවුම](../embroidery-tutorials-beginner/circle.md)** - මෙම උපදෙස් සඳහා උපකාරී විය හැකිය.

ඔයා තවමත් කිසිවක් සරසා නොමැති නම් [ආරම්භකයා](../embroidery-tutorials-beginner/index.md) මාලාවේ සරසවි නිබන්ධන දෙස බලන්න.

වැඩි විස්තර හෝ සැලසුම් යෝජනා සඳහා වෙනත් උපදෙස් බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත හැකිය*:

[මල්](../../../media/embroidery-tutorials/Flower.pdf)

![මල්](../../../media/embroidery-tutorials/Flower.png)

### 3. චක් ර

මේ කොටස කැඳවනවා හැම වෙලාවෙම චක් ර පණිවිඩය යවනකොට. ඒක ඔයාගේ ලේඛනයටත් එකතු කරන්න.

![මල් (1)](../../../media/embroidery-tutorials/Flower-1.png)

### 4. සෙල්ලම් කරන්න, ඔයාගේ නිර්මාණය පටන් ගන්න!
