මෙම උපදෙස් මඟින්, ඔයා රාත් රී අහස (48.5 x 96.1mm) සරඹ කිරීම ඉගෙන ගනු ඇත.

![නයිට්මිම්ල්](../../../media/embroidery-tutorials/Nachthimmel.png)

ඔයා දැනටමත් දන්නව ඇති ඒක මොකක්ද කියලා, කොහොමද වැඩ කරන්නේ කියලා.

**[තරු](../embroidery-tutorials-beginner/star.md)** - මෙම උපදෙස් සඳහා උපකාරී විය හැකිය.

ඔයා දැනටමත් විකාශන කාර්යය ගැන හුරුපුරුදු නම් එය ද ප් රයෝජනවත් වේ.

ඔයා තවමත් කිසිවක් සරසා නොමැති නම් [ආරම්භකයා](../embroidery-tutorials-beginner/index.md) මාලාවේ සරසවි නිබන්ධන දෙස බලන්න.

වැඩි විස්තර හෝ සැලසුම් යෝජනා සඳහා වෙනත් උපදෙස් බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත හැකිය*:

[රාත් රී අහස](../../../media/embroidery-tutorials/Night-Sky.pdf)

මේ කොටස හැම පාරම අහනවා තරු පණිවිඩය යවනකොට. ඒක ඔයාගේ ලේඛනයටත් එකතු කරන්න.
