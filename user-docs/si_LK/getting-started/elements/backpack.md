Pocket Code හි **බෑගය** ලක්ෂණය යනු ක් රියාකාරී කාර්යයක් වන අතර එමඟින් ඔයා නළුන් ( වස්තූන්), පිටපත්, පෙනුම හෝ ශබ්ද **ව් යාපෘති අතර** වැනි අංග **ගබඩා කර නැවත භාවිතා කරන්න** වෙත පිවිසීමට ඉඩ සලසයි. එය ඔයාට කාලය ඉතිරි කර ගැනීමට සහ ඔයාගේ ව් යාපෘති වඩාත් කාර්යක්ෂම කිරීමට උපකාරී වේ.

පසුම්බිය කියන්නේ ඩිජිටල් ගබඩා කිරීමේ ඉඩක් වගේ. එහිදී ඔයාට ඔයාගේ වර්තමාන ව් යාපෘතියේ විවිධ අංග ගබඩා කරන්න පුළුවන්. පසුපසට ගැලවීමෙන් පසුව, ඔයාට මෙම අංගයන් වෙනත් ව් යාපෘති වලට ලබාගෙන ඇතුල් කළ හැකිය.

### මම කොහොමද රංගන ශිල්පීන් (අංග) සඳහා පිටුපස බෑගය භාවිතා කරන්නේ?

**රූප ටික බෑග් එකට දාගන්න**

ව් යාපෘතියේ ව් යාපෘති දර්ශනයට යන්න, ඔයාට අවශ් ය රූපයක් පසුම්බියට බඩු දාන්න.

සංකේත මෙනුව විවෘත කිරීම සඳහා රූපයේ අසල ඇති තිත් තුන මත ක්ලික් කර “බෑගයට දමන්න” තෝරන්න.

රූප (ඇතුළත් පෙනුම, ශබ්ද සහ ලේඛන) පිටුපසට තබා ඇත.

![පැක් නළුවා](../../../media/getting-started/grafik-7.png)

**පිටිපස්සෙන් අංක එකතු කරන්න**

ව් යාපෘතිය විවෘත කරන්න, ඔයාට සංඛ් යා ඇතුලත් කිරීමට අවශ් ය තැන.

ව් යාපෘති දර්ශනයේදී, ප්ලස් සංකේතය තට්ටු කර “බෑගය” තෝරන්න.

දැන් ඔයා ඔයාගේ බෑග් එකේ තියාගෙන තියෙන දේවල් ඔක්කොම පේනවා. තිත් තුන මත තට්ටු කරලා “බෑගයෙන් ගන්න” තෝරන්න.

![විවෘත කරන්න නළුවා](../../../media/getting-started/grafik-8-e1732702791199.png)

***

### මම කොහොමද රූප සටහන් වලට පිටුපෑල පාවිච්චි කරන්නේ?

**පිටිපස්සට ලියුම් දාන්න:**

පිටපත ඇතුලේ තියෙන සංඛ් යාතයට යන්න. අවශ් ය script එක script editor එකේ තබාගන්න.

පරිසර මෙනුවෙන් “බෑගයට එක් කරන්න” තෝරන්න.

![පිටුපසට එකතු කරන්න](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

මේ ලිපියට නම දෙන්න, සහතික කරන්න හරි.

![නළුවෙක්ව බෑග් එකට දාගන්න](../../../media/getting-started/grafik-9.png)

මෙම පිටපත සුරැකෙන අතර අනෙකුත් ව් යාපෘති සඳහා භාවිතා කළ හැකිය.

![ඔයාගේ බෑග් එක](../../../media/getting-started/grafik-10.png)

**පිටිපස්සෙන් ස්ක් රිප්ට් එකතු කරන්න:**

ඔයා ලේඛනය ඇතුල් කරන්න කැමති තැනට නළුවා ටයිප් කරන්න. ඔයාලාට පේනවා මේ පිටපත. අදාළ මෙනුව විවෘත කිරීම සඳහා තිත් තුනක් මත තට්ටු කර “බෑගය” ටට්ටු කරන්න.

![පිටපත අරින්න](../../../media/getting-started/grafik-11.png)

දැන් ඔයාට ඔයාගේ බෑග් එකේ තියෙන හැම තිරයක්ම පේනවා. අවශ් ය script එකට යාබදව ඇති තිත් තුන මත තට්ටු කර පසුබිම් මෙනුවෙන් “බෑගයෙන් ගන්න” තෝරන්න.

සන්දර්භය මෙනුව හරහා, ඔයාට තවදුරටත් ඔයාගේ පසුම්බියේ අවශ් ය නැති ස්ක් රිප්ට් මකා දැමිය හැකිය.

![පිටපත් කරගත් පසුම්බිය](../../../media/getting-started/grafik-12.png)

***

### පසුම්බියේ වාසි

- **ව් යාපෘති හරහා නැවත භාවිතා කළ හැකි වීම:** සංඛ් යා, ලේඛන, ශබ්ද සහ පෙනුම එක් වරක් නිර්මාණය කර අවශ් ය පරිදි නැවත භාවිතා කළ හැකිය.
- **කාලය ඉතිරි කිරීම:** ඔයාට හැම වෙලාවකම අංක හෝ ස්ක් රිප්ට් අලුතින් නිර්මාණය කරන්න ඕනේ නෑ.
- **අනුකූලතාව:** විවිධ ව් යාපෘති වලදී අවශ් ය විට අංග එකිනෙකට සමානයි.
