Pocket Code කියන්නේ Catrobat හි ප්‍රධාන ඇප් එක. ඒක නොමිලේ ගන්න පුළුවන්. ඒකේ කේතයත් ඕනෑම කෙනෙකුට බලන්න පුළුවන්. ඔයාගේ ෆෝන් එකේ හෝ ටැබ්ලට් එකේ ක්‍රීඩා, සජීවිකරණ සහ ඔයාටත් එකතු වෙන්න පුළුවන් කතා හදන්න පුළුවන්. Pocket Code එකේ **කේතය හදන්නේ බ්ලොක් එකට එකතු කරලා**. ප්‍රහේලිකාවක කෑලි එකතු කරනවා වගේ කේත බ්ලොක් එකතු කරලා ව්‍යාපෘතිය හදන්න. පටන් ගන්න කලින් කේත ලියන්න දැනගෙන ඉන්න ඕනෑ නෑ!

Pocket Code යන්න ඩිජිටල් ව් යාපෘති වලට වඩා වැඩි දෙයක්. නව **නිර්මාණකරුවන්ගේ අවකාශයේ විශේෂාංග** සමග ඔයාට සැලසුම් කළ හැකිය **SVG කපන පිම්ම සඳහා ගොනු**. මෙයින් අදහස් කරන්නේ ඔයාට ඔයාගේ ඩිජිටල් නිර්මාණ සැබෑ ලෝකයේ අයිතම බවට පත් කර තිරයෙන් පිටත නිර්මාණාත්මක හැකියාවන් ගවේෂණය කළ හැකි බවයි.

ඔයා කේතය ඉගෙන ගන්නා විට, නව අදහස් අත්හදා බැලීමේදී හෝ වැඩසටහන්කරණය ඉගැන්වීමේදී Pocket Code ක් රමලේඛනය කිරීමට විනෝදජනක හා ප් රවේශ විය හැකි ක් රමයක් සපයයි
