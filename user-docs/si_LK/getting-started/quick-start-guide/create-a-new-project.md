ඔයාගේ ෆෝන් එකේ හෝ ටැබ්ලට් එකේ ඇප් එක අරින්න. අලුත් ව්‍යාපෘතියක් හදන්න + ලකුණ ඔබන්න.

![ප් රධාන තිරය නව ව් යාපෘතිය](../../../media/getting-started/MainScreen_NewProject.png)

ව්‍යාපෘතියට නමක් දෙන්න (1). ක්‍රීඩාවේ තිරය සිරස් අතට ද තිරස් අතට ද කියලා තෝරන්න (2). ඊළඟට හරි ලකුණ ඔබලා තහවුරු කරන්න (3).

![නව ව් යාපෘතිය](../../../media/getting-started/NewProject.png)

ඔයා දැන් ඔයාගේ ව් යාපෘති දර්ශනයක ඉන්නේ. ඉහළින්, ඔයා ඔයාගේ ක් රීඩාවේ නම දකිනවා.

පහත දැක්වෙන්නේ **පසුබිම** - දැනට පසුබිම හිස්. ඔයාට ඒක වෙනස් කරන්න ඕන නම්, ඒකෙ තට්ටු කරන්න.

පසුබිම යටින්, ඔයා ඔයාගේ ක්රීඩාවට එකතු කර ඇති **ක් රීඩකයන් සහ වස්තූන්** සඳහා ප්රදේශය දකිනවා. මේ වන විට එම ප් රදේශය තවමත් හිස්ව පවතී.

පහළ දකුණේ, ඔයාට වැදගත් බොත්තම් දෙකක් පෙනේ:

![ආරම්භ කරන්න](../../../media/getting-started/Start.png) ඔයා ඔයාගේ ක් රීඩාව ආරම්භ කරන්නේ **ධාවනය කරන්න** බොත්තමෙනි.

![ඊට අමතරව බොත්තම](../../../media/getting-started/Screenshot-2024-11-22-143219.png) **ඊට අමතරව** බොත්තම භාවිතයෙන්, ඔයා ඔයාගේ ක් රීඩාවට නව චරිතයක්/ වස්තුවක් එක් කරයි.

![ව් යාපෘති තිරය](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
