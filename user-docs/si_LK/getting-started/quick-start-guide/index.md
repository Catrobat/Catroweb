Pocket Code යනු ඔයාගේ ස්මාර්ට්ෆෝන් හෝ ටැබ්ලටයේ කෙලින්ම ක් රීඩා, සජීවිකරණ සහ අන්තර්ක් රියාකාරී කථා නිර්මාණය කිරීමට ඉඩ සලසන දෘශ් ය වැඩසටහන්කරණ යෙදුමකි. “කේතය” (කේත බ්ලොක්) සමඟ බුද්ධිමත් ඇදීම සහ පහත වැටීමේ අතුරුමුහුණත භාවිතා කරමින්, ඔයාට පෙර වැඩසටහන්කරණ අත්දැකීම් නොමැතිව ඔයාගේ ව් යාපෘති සැලසුම් කළ හැකිය. ඔයාගේ අදහස් සැබෑ කර ගැනීමට පහසුවෙන් ශබ්ද, රූප සහ චලනය එකතු කරන්න.

මෙම මාර්ගෝපදේශය ඔයාට ආරම්භ කිරීමට උපකාරී වනු ඇත:

- අන්තර්ජාලය හරහා ගමන් කරන්න,
- ඔයාගේ පලවෙනි ව් යාපෘතිය හදන්න,
- වස්තූන් සහ පසුබිම් සමග වැඩ කිරීම,
- ක් රියාමාර්ග වැඩසටහන්ගත කිරීම සඳහා කේත බ්ලොක් භාවිතා කරන්න, සහ
- ඔයාගේ ව් යාපෘතිය බේරගන්න.

ආරම්භකයින් සහ අධ් යාපනිකයින් සඳහා පරිපූර්ණ, Pocket Code නිර්මාණශීලීත්වය, ගැටළු විසඳීම සහ තාර්කික චින්තනය දිරිමත් කරයි.
