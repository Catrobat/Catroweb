ඔයා ආරම්භ කරන විට Pocket Code පහත දැක්වෙන ප් රධාන තිරය ඔයාට පෙනේ.

![ප් රධාන තිරය](../../../media/getting-started/MainScreen-e1732269599192.jpg)

දකුණු ඉහළ කොනේ, ![උදව් කරන්න](../../../media/getting-started/Screenshot-2024-11-22-111748.png) සංකේතය ඔයාව ගෙන යයි Catrobat ලේඛනගත කිරීම, ඔයාට ප් රයෝජනවත් උපදෙස් ඇත.

ඊට පස්සෙන් තියෙන්නේ මෙනුව ![මෙනුව](../../../media/getting-started/Screenshot-2024-11-22-111804.png). එතනින්, ඔයාට පහසුවෙන් සැකසුම් වෙත යා හැකිය, එහිදී ඔයාට භාෂාව වෙනස් කළ හැකිය හෝ සැලැස්ම කොටස් වැනි දිගු කිරීම් සක්රිය කළ හැකිය.

පහළින්, ඔයාට ඔයාගේ මෑත කාලීන සංස්කරණය කළ ව් යාපෘතිය දැක ගත හැකිය. ව් යාපෘති තිරය වෙත පිවිසීමට සංස්කරණය කිරීමේ අයිකනය ![සංස්කරණය කිරීමේ අයිකනය](../../../media/getting-started/Screenshot-2024-11-22-111825.png) මත ක්ලික් කරන්න, එහිදී ඔයාට ඔයාගේ ව් යාපෘතිය තවදුරටත් සංවර්ධනය කළ හැකිය.

ඔයාගේ ව් යාපෘතිය ආරම්භ කිරීමට Play බොත්තම ![ඔයාගේ ව් යාපෘතිය පටන් ගන්න](../../../media/getting-started/Screenshot-2024-11-22-111818.png) භාවිතා කරන්න.

ක්ලික් කරන්න ව්‍යාපෘති, ඔයාට ඔයාගේ බේරුණු ව් යාපෘති වලට පිවිසිය හැකියි. ![උපකරණ පිළිබඳ ව් යාපෘති](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

වෙනත් පරිශීලකයන්ගෙන් තවත් ව් යාපෘති දැන ගැනීමට සහ වැඩ කිරීමට ඔයාට අවශ් ය නම්, Catrobat හවුල්කාරිත්වය මත ක්ලික් කරන්න. එතන ඔයාලට ගොඩක් විශිෂ්ට ව් යාපෘති හම්බවෙයි. ![Catrobat ප් රජාව](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

ඔයාට නව ව් යාපෘතියක් නිර්මාණය කිරීමට අවශ් ය නම්, ප්ලස් අයිකනය මත ක්ලික් කරන්න. ![එකතු කරන්න](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
