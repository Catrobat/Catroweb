ඔයාට ඔයාගේ ව් යාපෘතියට පසුබිමක් එකතු කළ හැකිය Catrobat.

පසුබිම් විවිධ ආකාරවලින් භාවිතා කළ හැකිය. Pocket Code හි, ඒවා දෘශ් යමය වශයෙන් වැඩි දියුණු කිරීම සඳහා භාවිතා කළ හැකිය **ක් රීඩා**, කියන්න **කතා**, හෝ ඔයාගේ නළුන් සහ වස්තූන් සඳහා වැඩි සන්දර්භයක් ලබා දෙන්න.

**කුමන්ත් රණකරුවන්** හෝ **අලංකාර යන්ත් ර** වැනි නිෂ්පාදකයන්ගේ අවකාශය සඳහා පසුබිම් සැලසුම් සැකිලි ලෙස සේවය කරයි, උදාහරණයක් ලෙස කපා හෝ මැහුම් රටා සඳහා.

පසුබිමක් එකතු කිරීම සඳහා, ව් යාපෘති දර්ශනයේ “පසුබිම” මත තට්ටු කරන්න.

![පසුබිම ගැන උපදෙස්](../../../media/getting-started/grafik-16.png)

**ස්ක්‍රිප්ට් කොටස (2)** හි ඔයාට ඔයාගේ පසුබිම වැඩසටහන්ගත කළ හැකිය - කෙසේ වෙතත්, මේ සඳහා සියලුම බ්ලොක් ලබා ගත නොහැක. පහත සඳහන් කොටස් දෙක විශේෂයෙන් වැදගත්: ![විනිවිදභාවය 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) සහ ![ප්‍රමාණය මෙයට සකසන්න: 60%](../../../media/bricks/Set_size_to_60_pct_.png)

**පෙනුම කොටස (1)** එකේ ඔයා පසුබිමක් එකතු කරනවා. මේක කරන්න, + සංකේතය ටයිප් කරන්න.

![පසුබිමක් එකතු කරන්න](../../../media/getting-started/grafik-14.png)

ඔයාට ඔයාගේම පින්තූර උඩුගත කරන්න පුළුවන්, කලින් නියමිත පසුබිම් භාවිතා කරන්න පුළුවන්, නැත්නම් ඔයාටම පිටුපසින් නිර්මාණය කරන්න පුළුවන්.

**අඳින්න**: ඔයාට ඔයාගේම පසුබිමක් නිර්මාණය කළ හැකිය **Pocket Paint**. Pocket Paint යනු චිත් රකරණ වැඩසටහනකි ([වැඩි විස්තර Pocket Paint](https://catrobat.org/docs/pocket-paint/))

**පෙනුම්**: පෙර නිමැවුම් පසුබිම් එකතුවකින් එකක් තෝරන්න ([මාධ් ය පුස්තකාලය ගැන වැඩි විස්තර](../elements/medialibrary.md)).

**ගැලරිය**: ඔයාට ඔයාගේ ස්මාර්ට්ෆෝන් එකෙ ගැලරියෙන් පින්තූරයක් තෝරාගන්න පුළුවන්.

**කැමරාව**: ඔයාට ඔයාගේ උපාංගයේ කැමරාව භාවිතයෙන් ඡායාරූපයක් ගැනීමට සහ පසුබිම ලෙස එය එකතු කළ හැකිය.

![මාධ් ය පුස්තකාලයෙන් තෝරන්න](../../../media/getting-started/grafik-17.png)

ඔයා දැන් පිටුපසින් එකතු කරලා තියෙනවා. **ව් යාපෘති දර්ශනය** වෙත නැවත පැමිණීමට ඉහළ දකුණු පසින් ඇති පිටුපස ඊතලය ක්ලික් කරන්න.
