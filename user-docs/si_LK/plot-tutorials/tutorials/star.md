හැම චලනයකම පේන විදියට පේනවා. මේ තමයි ඊළඟට කප්පාදුව කරන්නා කපන රේඛාව.

මේ තරුට ලකුණු 6ක් තියෙනවා. ලක්ෂ් යය යනු කෙළවරක් (“ගමන් කරන්න: 100 පියවර”), වක් රයක් සහ ලක්ෂ් යයේ හැඩය අවසන් කරන තවත් කෙළවරකි. ඊළඟ ස්ථානය පෙර, ඔයා විරුද්ධ දිශාවට හැරී ඇති අතර එමඟින් ඊළඟ ස්ථානය නිවැරදිව පිටතට පැමිණේ.

***සටහන**: සම්පූර්ණ රවුමක් 360°. අපි හැම තැනම හැරෙන එක 100° දකුණු පැත්තට 40° වමට, එනම් 60° සම්පූර්ණයෙන්ම දකුණට.*

*හැම ලකුණු හයකටම අපි විපර්යාසයක් ලබා ගන්නවා 360° දකුණට යන්න.*

**තව දුරටත් යන්න**: විවිධ වක් ර සංයෝජන උත්සාහ කර ලකුණු ගණන වෙනස් කරන්න.
