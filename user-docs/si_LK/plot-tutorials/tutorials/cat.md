හැම චලනයකම පේන විදියට පේනවා. මේ තමයි ඊළඟට කප්පාදුව කරන්නා කපන රේඛාව.

අපේ වස්තුව අංශක 150ක් දිශාවට යොමු වෙනවා.

මේ උපදෙස් වලදි, පූසෙකුගේ හිස දකුණු පැත්ත මුලින්ම හදලා තියෙන්නේ. ඔයා හොදින් බැලුවොත්, මුලදී වක්රය ශක්තිමත් වෙනවා. ඒ නිසා object එක පොඩි රේඛාවක් දාලා තව ගොඩක් වට වෙන්න ඕනේ. ඊට පස්සේ ඔළුව පහළ කොටසේ වක් ර ටික පොඩි වෙනවා. හිස වම් පැත්ත නැවතත් ශක්තිමත්ව වක් ර වී ඇත. ඒකයි මේ හිස කොටසෙ මුලුමනින්ම ලූප් තුනක් පාවිච්චි කරන්නේ.

ඊලඟට එන්නේ වම් කණ. ඒක කෙළින් පේලි වලින් විතරයි හදලා තියෙන්නේ, ඉතින් අපිට පුළුවන් කේතය “ගමන් කරන්න: \_\_ පියවර” භාවිතා කරන්න.

කන් අතර කොටස නැවතත් වාක් ය කලාපයක් වන අතර එය වෙනත් ලූපයකින් වැඩසටහන්ගත කර ඇත.

එතකොට දකුණු කන හදනවා.

දැන් මේ සැලැස්ම ඉවරයි. ඒක ඉවර කරන්න “ප්ලොට් කිරීම නවත්වන්න” කේතය දාලා ඔයාගේ ෆෝන් එකට save කරන්න “ප්ලොට් එක SVG ලෙස සුරකින්න: \_\_\_”.

දැන් ඔයාට පුළුවන් SVG ෆයිල් එක (කපන) කම්කරුවෙකුට යවන්න.
