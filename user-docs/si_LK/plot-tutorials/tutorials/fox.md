[ෆොක්ස් PDF, ජර්මානු භාෂාවෙන්](../../../media/plot-tutorials/Fuchs.pdf)

හැම චලනයකම පේන විදියට පේනවා. මේ තමයි ඊළඟට කප්පාදුව කරන්නා කපන රේඛාව.

මේ සතා හැදෙන්නේ කෙළින් පේළි වලින් “ගමන් කරන්න: \_\_\_ පියවර” සහ වක් ර වලින් විතරයි.

**ඉඟියක්**: ඔයා එය ගොඩනඟන අතරතුර ඔයාගේ වැඩසටහන පරීක්ෂා කරන්න.
