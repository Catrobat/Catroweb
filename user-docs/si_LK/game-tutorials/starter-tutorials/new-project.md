මෙම උපදෙස් මඟින්, ඔයා ඔයාගේ පළමු ව් යාපෘතිය නිර්මාණය කිරීමට පටන් ගැනීමට Pocket Code ගැන දැනගත යුතු සියල්ල ඉගෙන ගනු ඇත. අපි ඔයාට පියවරෙන් පියවර මඟ පෙන්වන්නෙ App එක බාගත කරන, විවෘත කරන සහ නව ව් යාපෘතියක් නිර්මාණය කරන ආකාරයයි.

![නව වැඩසටහන](../../../media/game-tutorials/New-Program.png)\
අපි ඔයාට පියවරෙන් පියවර මඟ පෙන්වන්නෙ App එක බාගත කරන, විවෘත කරන සහ නව ව් යාපෘතියක් නිර්මාණය කරන ආකාරයයි.\
[පින්තූරය අරින්න](../../../media/game-tutorials/New-Program.png)

මේක තමයි මුල්ම ටියුටෝරල් එක, ඔයාට කලින් දැනුමක් අවශ් ය නෑ.

ඉතින්, ඔයා මොනවද බලාගෙන ඉන්නේ? ඔයාගේ ෆෝන් එක අරගෙන දැන්ම පටන් ගන්න!

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත කළ හැකිය:*

### 1. Pocket Code ස්ථාපනය කිරීම

මුලින්ම, ඔයා ඔයාගේ උපාංගයේ Pocket Code යෙදුම ස්ථාපනය කළ යුතුයි. මේ පියවර සඳහා Google ගිණුමක් අවශ් ය වෙනවා. දැන් ඔයාගේ උපාංගය App එක බාගෙන Install කරනවා. මේ පියවරට ඔයාගේ අන්තර්ජාල සම්බන්ධතාවය අනුව කාලයක් ගතවෙන්න පුළුවන්.

![නව වැඩසටහන (2)](../../../media/game-tutorials/New-Program-2.png)\
ඔයාට Google Play Store හි “Pocket Code” සෙවීමෙන් සහ “ස්ථාපනය කිරීම” මත තට්ටු කිරීමෙන් එය බාගත කරගැනීමෙන් යෙදුම සොයා ගත හැකිය.\
[පින්තූරය අරින්න](../../../media/game-tutorials/New-Program-2.png)

Pocket Code බාගත කර ස්ථාපනය කිරීමෙන් පසු ඔයාට යෙදුම ඔයාගේ උපාංගය අනුව යෙදුම් පෙට්ටියේ හෝ ඔයාගේ මුල් තිරයේ සොයා ගත හැකිය. ඔයාට පහසුවෙන්ම ඇප් එක අරගෙන කැමති තැනක දාන්න පුළුවන්.

### 2. App එක ඇරඹීම

![නව වැඩසටහන (1)](../../../media/game-tutorials/New-Program-1.png)\
ඔයා යෙදුම විවෘත කරන විට, ඔයාට විවිධ කාණ්ඩ පෙනේ.\

### 3. නව ව් යාපෘතියක් නිර්මාණය කරන්න

ඊළඟ පියවර තමයි ඇත්තටම අලුත් ව් යාපෘතියක් නිර්මාණය කිරීම. දැන් ඔයාලට ව් යාපෘති නාමයක් ඇතුලත් කරලා තෝරගන්න වෙනවා ඔයාගේ ව් යාපෘතිය භූ දර්ශනයක් වෙන්න ඕනද නැද්ද කියලා. “හරි” ඔයාීමෙන් ව් යාපෘතිය නිර්මාණය වෙනවා.

![නව වැඩසටහන](../../../media/game-tutorials/New-Program.png)\
ඒක කරන්න, ඔයාට පුළුවන් පහළ දකුණු කෙළවරේ තියෙන කහ+බට්න් එක තද කරන්න.\
[පින්තූරය අරින්න](../../../media/game-tutorials/New-Program.png)

### 4. ඔයා ඒක කලා, ඔයා ඔයාගේම අලුත් ව් යාපෘතියක් නිර්මාණය කළා.

දැන් ඔයා Pocket Code ස්ථාපනය කරලා තියෙනවා. අලුත් ව් යාපෘතියක් නිර්මාණය කරන හැටි දන්නවා. දැන් ඔයාට වැඩසටහන් කරන්න පටන් ගන්න පුළුවන්!

මේක කරන්න, ඔයා දැනගන්න ඕනේ කොහොමද ව් යාපෘතියක අලුත් වස්තුවක් නිර්මාණය කරන්නේ කියලා. **[නව වස්තුව](new-object.md)** - ටියුටෝරල් එක බලන්න, එහිදී හැමදේම ඔයාට පියවරෙන් පියවර පැහැදිලි වෙනවා.
