මෙම උපදෙස් මඟින්, ඔයා ඔයාගේ ව් යාපෘතියේ නව වස්තුවක් නිර්මාණය කරන්නේ කෙසේද සහ ඔයාට මේ සඳහා ඇති විවිධ හැකියාවන් ඉගෙන ගනු ඇත.

![නව වස්තුව](../../../media/game-tutorials/New-Object.png)

මෙය සිදු කිරීම සඳහා, ඔයා දැනටමත් Pocket Code යෙදුම බාගත කර ඇති අතර නව ව් යාපෘතියක් නිර්මාණය කරන්නේ කෙසේදැයි දැන සිටිය යුතුය. ඔයාට මේ සඳහා උපකාර අවශ් ය නම්, **[නව ව් යාපෘතිය](new-project.md)** - නිබන්ධනය බලන්න.

*මෙතනින් ඔයාට මෙම උපදෙස් PDF ආකෘතියෙන් බාගත කළ හැකිය:*

[නව වස්තුව](../../../media/game-tutorials/New-Object.pdf)

### 1. අලුත් වස්තුවක් නිර්මාණය කරන්න

මුලින්ම, ඔයා ඔයාගේ අලුත් ව් යාපෘතිය ආරම්භ කරන්න ඕනේ.

Pocket Code යෙදුමේ මුල් තිරයේ ඔයාට එය සොයාගත හැකිය. ඔයාට එක් ව් යාපෘතියක් වඩා තිබේ නම්, ඔයා “ව්‍යාපෘති” මත ක්ලික් කළ හැකිය. එහෙනම් ඔයාගේ අලුත් ව් යාපෘතිය තෝරන්න. ඔයා නව ව් යාපෘතියක් නිර්මාණය කර නොමැති නම් හෝ එය කරන්නේ කෙසේද යන්න පිළිබඳ වැඩි විස්තර අවශ් ය නම්, **[නව ව් යාපෘතිය](new-project.md)** - නිබන්ධනය බලන්න.

### 2. අලුත් වස්තුවක් නිර්මාණය කරන්න

දැන් ඔයාලා ලෑස්ති වෙලා ඉන්නේ අලුත් වස්තුවක් නිර්මාණය කරන්න. ඒක කරන්න පහළ දකුණු කෙළවරේ තියෙන කහ ප්ලස් බොත්තම ක්ලික් කරන්න. ඔයාට තේරෙන්න පුළුවන් අවස්ථා හතක් තියෙන අලුත් කවුළුවකුත් පේනවා.

![නව විෂය (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. නිර්මාණය කිරීමේ ක් රම

මේ තියෙන්නේ ඔයාට තෝරාගන්න පුළුවන් විකල්ප:

![නව වස්තුව (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. පින්තූරයක් ඇඳගන්න

ආරම්භය සඳහා හැකි තරම් පහසු කිරීම සඳහා, අපි “අඳින්න” ක් රියාකාරිත්වය භාවිතා කර තිත් එකක් ඇඳීමට අවශ් ය. Pocket Paint සමග ලකුණු ඇඳීමෙන් පසු ඔයාට එය අතහැර දැමිය හැකිය (එක් පියවරක් ආපසු හැරී).

### 5. නම කියන්න

දැන් ඔයා ඔයාගේ පින්තූරයට නමක් දෙන්න ඕනේ.

### 6. ඒක තියන්න

ඊට පස්සේ ඔයා ඒක දෘශ් යමයව තබාගන්න ඕනේ ඔයාගේ ඇඟිල්ලෙන් වම්/දකුණු පැත්තට හෝ උඩට/පහට හරවාගෙන. ඔයා ඒක උඩ දකුණු කෙළවරේ තියෙන බොත්තමකින් save කරන්න ඕනේ.

![නව වස්තුව (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. ඔයා ඒක කලා, ඔයා ඔයාගේම අලුත් වස්තුවක් නිර්මාණය කළා.

දැන් ඔයාට පුළුවන් ප් රොජෙක්ට් එකක් තියෙන ව් යාපෘතියක් තියෙනවා.

මේක කරන්න, ඔයා දැනගන්න ඕනේ මොන කේත බ්ලොක් එකද තියෙන්නේ කියලා. **[පළමු කේතය](first-bricks.md)** - ටියුටෝරල් මඟින් ඔයාට කේත බ්ලොක්ස් වල විවිධ කාණ්ඩ පිළිබඳ හොඳ දළ විශ්ලේෂණයක් ලබා දෙයි. කෙසේ වෙතත්, ඔයාට ඔයාගේ පළමු ව් යාපෘතියෙන් කෙලින්ම ආරම්භ කළ හැකිය. ආරම්භකයින් මාලාවෙන් සුදුසු උපදෙස් තෝරන්න.
