![තට්ටු කළ විට](../../../media/bricks/when-tapped2.png)

වස්තුවට පහර දෙන විට ස්ක් රිප්ට් එක ක් රියාත්මක වෙනවා.

*“වේදිකාව තට්ටු කළ විට”* කොටසට ඇති වෙනස වන්නේ *“තට්ටු කළ විට”* තනි ස්ප් රයිට් හෝ වස්තූන් සඳහා විශේෂිත වන අතර *“වේදිකාව තට්ටු කළ විට”* සමස්ත තිරයටම අදාළ වේ.
