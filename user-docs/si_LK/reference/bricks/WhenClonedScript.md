අවශ් ය ක් රියා සිදුකිරීමට උපදෙස් සහිත වස්තුවක නිර්මාණය කරන ලද ක්ලෝනයක් මෙහෙයවීම. මෙම ක් රියාවලිය මඟින් මුල් වස්තුවේ ක් රියාකාරිත්වය ප් රතිනිර්මාණය කිරීමට ඉඩ සලසයි, එමෙන්ම ක්ලෝනය ස්වාධීනව පාලනය කරයි. විශේෂිත අවශ් යතා සපුරාලීම සඳහා ක්ලෝන් වස්තුවේ විවිධ හැසිරීම් හෝ ගුණාංග නිශ්චිත කළ හැකිය.
