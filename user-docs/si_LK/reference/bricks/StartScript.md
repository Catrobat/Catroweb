![දර්ශනය ආරම්භ වූ විට](../../../media/bricks/When_scene_starts_btn2.png)

ඔයා මේ බ්ලොක් එක පාවිච්චි කලොත්, සිද්ධිය පටන් ගන්නකොටම ලේඛනය ක්ෂණිකව පටන් ගනීවි. දර්ශනයක් තමයි ඔයාගේ වැඩසටහනේ ආරම්භය. දර්ශනයක් කියන්නේ ඔයාගේ වැඩසටහනේ තියෙන අලුත් දර්ශනයක්. එහිදී වෙනත් අංගයන් පෙන්වන්න පුළුවන්, විවිධ අන්තර් ක් රියා සිදු වෙන්න පුළුවන්. ඔයාට ඔයාගේ වැඩසටහනේ විවිධ අදියර සඳහා බොහෝ දර්ශන තිබිය හැකියි. උදාහරණයක් ලෙස, අමුත්තන් සඳහා එක් දර්ශනයක්, ප් රධාන මෙනුව සඳහා එක් දර්ශනයක්, පළමු මට්ටමේ එකක්, දෙවන මට්ටමේ එකක් සහ යනාදිය. සරල වැඩසටහන් එක්ක, එක සීන් එකක් විතරක් ප් රමාණවත් වෙනවා. එතකොට ඔයාගේ වැඩසටහන ආරම්භය තමයි සිනමාවේ ආරම්භය.

සෑම script එකක්ම වගේ, මේ එක පටන් ගන්නේ event code block එකකින්: event එක අර්ථ දක්වනවා **කවදාද** script එක පටන් ගන්නවා, code එක block වෙනවා ඒක program එකට කියන්නට **මොනව ද** පස්සේ.
