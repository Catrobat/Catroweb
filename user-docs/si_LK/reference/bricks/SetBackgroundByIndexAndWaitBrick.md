මෙම කේතය පිටුපස ඇති පිටුපස ස්ථානයේ පිහිටීම මත පදනම්ව පසුබිම වෙනස් කරන අතර එමඟින් පිටපත දිගටම කරගෙන යාමට පෙර වෙනස් කිරීම සම්පූර්ණ වේ. ඒක හරියට නාට් යයක දර්ශනය වෙනස් කරලා ලැයිස්තුවකින් යම් පසුබිමකට දාලා නව දර්ශනය සම්පූර්ණයෙන්ම සකස් වෙනකම් ක් රියාකාරීත්වය නතර කරනවා වගේ.
