මේ බ්ලොක් එක ඔයාගේ චරිතයට අංශු එකතු කරලා ටිකෙන් ටික ඒවා කාලයත් එක්ක අතුරුදහන් කරනවා. එය භාවිතා කරන්න, උදාහරණයක් ලෙස, ගිනි නිවන සංදර්ශකය නිර්මාණය කිරීම, දුම් එකතු කිරීම හෝ ඔයාගේ චරිතය ඉක්මනින් පෙනෙන්නට සලස්වන්න.
