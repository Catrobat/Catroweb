x සහ y සන්ධි වලින් අර්ථ දක්වා ඇති තිරයේ නිශ්චිත ස්ථානයකට වස්තුව ගෙන යයි. ඒක හරියට ඔයාගේ චරිතය හරියටම තැනකට ගෙනියන්න වගේ.

මෙම ස්ථානය කාට්සියානු තලයේ වැනි සම්බන්ධතා පද්ධතියක සකසා ඇත: x සහ y අක්ෂයන් තිරයේ මධ් යයේ හරහා ගමන් කරයි, එබැවින් x = 0 සහ y = 0 තිරයේ මැද වේ.
