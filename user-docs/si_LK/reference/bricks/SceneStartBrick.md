![දර්ශනය ආරම්භ කරන්න:](../../../media/bricks/start_scene_brick2.png)

මෙම කේතය ඔයාගේ ව් යාපෘතියේ වෙනස් ස්ථානයකට මාරු වී එම ස්ථානය මුල සිටම ක් රියාත්මක කිරීමට පටන් ගනී. ඒක හරියට පොතක පරිච්ඡේදයක් වෙනස් කරනවා වගේ, නැත්නම් සෙල්ලමක් කරනකොට ඊළඟ මට්ටමට යනවා වගේ.

හිතන්න ඔයා ඔයාගේ ව් යාපෘතියේ විවිධ දර්ශන තියෙනවා කියලා, ඒ හැම එකක්ම ඔයාගේ කතාවේ හෝ ගේම් එකේ වෙනම කොටසක් නියෝජනය කරනවා. මෙම කේතය භාවිතා කරමින්, ඔයාට ඕනෑම අවස්ථාවකට පැන එය ආරම්භයේ සිටම ආරම්භ කළ හැකිය. ඔයාගේ ව් යාපෘතියේ විවිධ කොටස් අතර සුමට සංක් රාන්තියක් නිර්මාණය කිරීම.
