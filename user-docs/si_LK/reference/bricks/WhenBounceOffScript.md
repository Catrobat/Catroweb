යම් පෘෂ්ඨයක් හෝ වස්තුවක් මත පැනෙන විට සිදුවීමට ප් රතික් රියාවක් හෝ ක් රියාකාරීත්වයක් සකසයි. ඒක හරියට කියන්නේ, “මගේ චරිතය බිත්තියක් හෝ වෙනත් වස්තුවක් මතට පනිද්දී මේ ක් රියාව කරන්න.”
