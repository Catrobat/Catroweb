![1 ක් ගහන එකකට විවේකයක්](../../../media/bricks/Pause_for_1_beats.png)

මෙම කේතය ක් රියාත්මක වන විට, එම පිටපත දිගටම ක් රියා කිරීමට පෙර නියමිත වේග ගණනක් බලා සිටීමට සිදු වේ. ඒක හරියට ඊළඟ නෝට් එක හෝ ශබ්දය වාදනය කරන්න කලින් ගීතයක කෙටි විවේකයක් ගන්න වගේ. හිතන්න ඔයාගේ ප් රදර්ශනය මොහොතකට නතර කරලා, පීඩන ගණන් කරලා, නැවත ක් රියාත්මක වෙනවා කියලා.
