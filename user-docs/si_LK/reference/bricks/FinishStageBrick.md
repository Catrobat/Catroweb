![අවසාන අදියර කේතය](../../../media/bricks/finish-stage-brick.png)

මේ කේතය අවහිර කරන එක සියලුම ස්ක් රිප්ට් නතර කරලා වත්මන් වේදිකාව හෝ දර්ශනය අවසන් කරනවා. ඒක හරියට කියන්නේ, “ව් යාපෘතියේ මේ කොටස ඉවරයි.” හැමදේම නතර වෙනවා, සහ ව් යාපෘතියට එක්කෝ වෙනම ස්ථානයට යන්න පුළුවන් නැත්නම් සම්පූර්ණයෙන්ම ඉවර වෙන්න පුළුවන්. ඔයාගේ ව් යාපෘතියේ යම් අදියරක් හෝ මට්ටමක් අවසන් කිරීමට අවශ් ය වූ විට මෙය භාවිතා කරන්න.
