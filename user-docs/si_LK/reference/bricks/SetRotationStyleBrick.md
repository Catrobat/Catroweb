![භ්‍රමණ විලාසය සකසන්න:](../../../media/bricks/set_rotation_style_brick2.png)

වස්තුව භ් රමණය වන ආකාරය වෙනස් කරයි (සියලුම වටා, වමේ සිට දකුණට පමණක් හෝ භ් රමණය නොවන්න). ඒක හරියට ඔයාගේ චරිතයට හැම තැනම හැරෙන්න පුළුවන්ද කියලා තීරණය කරන්න වගේ, වමට දකුණට හැරෙන්න, නැත්නම් කිසිම දෙයක් කරන්ඩ බෑ.
