ඔයාගේ කේතයේ කොටස් මොනවාද කියලා මතක තියාගන්න උදව් වෙන්න ඔයාගේ ලේඛනයට comment එකක් හෝ note එකක් එකතු කරනවා. ඒක ඔයාගේ ව් යාපෘතියේ ක් රියාකාරිත්වයට බලපාන්නේ නෑ. ඒක හරියට ඔයාටම ලියුමක් දාලා යන එක වගේ.
