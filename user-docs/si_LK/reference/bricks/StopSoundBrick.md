මේ කේතය බාධා කරනවා යම් ශබ්දයක් වාදනය වීම නවත්වනවා. ඒක හරියට එක ගීතයක් වෙනුවෙන් ස්ටොප් බොත්තම තට්ටු කරන එක වගේ අනිත් ශබ්ද හෝ සංගීතය දිගටම වාදනය වෙන අතරේ. හිතන්න ඔයාගේ චරිතයට කියන්න එක සවුන්ඩ් ට් රැක් එකක් ගහන එක නවත්වන්න කියලා.
