වස්තුවට යොදන ලද ඝර්ෂණ ප් රමාණය සකසයි, එය පහසුවෙන් ලිස්සා යන හෝ මන්දගාමී වන ආකාරයට බලපායි. ඒක හරියට ඔයාගේ චරිතය පෘෂ්ඨයේ ලිස්සා යන බව වෙනස් කරනවා වගේ. වැඩිපුර ගබඩා කිරීමෙන් අදහස් කරන්නේ අඩුම ලිස්සා යාමක්.
