ඒකෙන් පේනවා වස්තුව මොකක් හරි දෙයක් පහර දුන්නොත් කොච්චර පනින්නද කියලා. වැඩි ප් රතිශතයක් කියන්නේ ශක්තිමත් පනින්නක්. ඒක හරියට ඔයාගේ චරිතය බිත්ති වලින් හෝ වෙනත් වස්තූන් වලින් කොපමණ ප් රමාණයක් පනින්නේද කියලා තීරණය කිරීම වගේ.
