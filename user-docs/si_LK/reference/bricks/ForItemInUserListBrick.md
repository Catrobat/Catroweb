මෙම කේතය ලැයිස්තුවක හෝ පරාසයක සෑම අංගයක් සඳහාම උපදෙස් කට්ටලයක් ක් රියාත්මක කරයි. ඒක හරියට හැම දෙයක්ම එකින් එක කරගෙන ගිහින් එකම ක් රියාවන් කරන්න වගේ.

ඔයාට අංක, වර්ණ හෝ ඕනෑම දෙයක් ලැයිස්තුවක් තියෙනවා කියලා හිතන්න. මේ කේතය ඔයාට එම ලැයිස්තුවෙන් සෑම අයිතමයක්ම ගෙන ඒ සමග යමක් කිරීමට ඉඩ සලසයි. උදාහරණයක් ලෙස, ඔයාට වර්ණ ලැයිස්තුවක් තිබේ නම් සහ ඔයාට අවශ් ය වන්නේ පසුබිම් වර්ණය ලැයිස්තුවේ සෑම වර්ණයකටම වෙනස් කිරීමට නම්, ඔයා මෙම කේතය භාවිතා කරනු ඇත.

ඒක හරියට කියන්නේ, “මේ කණ්ඩායමේ හැම දෙයක්ම සඳහාම, පහත උපදෙස් කරන්න.”
