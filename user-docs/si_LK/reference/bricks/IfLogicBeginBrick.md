![වෙනත් කේතයක් වසා දැමීම](../../../media/bricks/if_else_brick2.png)

*කොන්දේසිය හරිද කියලා පරීක්ෂා කරලා, ඒක හරි නම් උපදෙස් එකතුවක් ක් රියාත්මක කරනවා. එහෙම නැත්නම් තවත් උපදෙස් එකතුවක් ක් රියාත්මක කරනවා: “මේක ඇත්ත නම් මේක කරන්න, නැත්තම් ඒක කරන්න.”*

![දර්ශනය ආරම්භ කරන්න:](../../../media/bricks/StartScene.png)

සිද්ධිය ආරම්භ වන විට, විචල්ය X 0 ලෙස සකසා ඇත.

![වෙනත් අය නම්](../../../media/bricks/IfElse.png)

දැන් සතුන් ටැප් කර ඇත්නම්, X මොඩියුල 2 සත් යද යන්න පරීක්ෂා කිරීම සිදු කරනු ලැබේ, එනම් X අද්විතීය සංඛ් යාවක්ද යන්න.

මේ තත්ත්වය නම්, ශබ්දය Tweet1 වාදනය කරනු ලබන අතර විචල් යය X 1 කින් වැඩි කරනු ලැබේ.

එසේ නොමැතිනම්, X සම වේ නම්, පමණක් X 1 කින් වැඩි වේ.

විභාගයට ලක් වෙන්න ඕන ප් රකාශන නම් අවසානය අංකයකින් වෙන් කරලා තියෙන්නේ.
