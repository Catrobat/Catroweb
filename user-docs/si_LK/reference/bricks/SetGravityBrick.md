ව් යාපෘතියේ සියලුම වස්තූන් වලට යොදන ලද ගුරුත්වය සකසයි. ඒක හරියට දේවල් ගුරුත්වාකර්ෂණය මගින් පහළට හෝ පැත්තකට ඇදගෙන යන ආකාරය වෙනස් කරනවා වගේ, ඒවා වැටෙන විදිහටත්, ගමන් කරන විදිහටත් බලපානවා වගේ.
