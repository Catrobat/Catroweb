මෙම කේතය block “ක්ලෝනයක් සාදන්න:” කේතය block සමග නිර්මාණය කරන ලද clone ඉවත් කරයි. ඒක හරියට කියන්නේ, “මේ පිටපත ඉවත් කරන්න.” මේක පාවිච්චි කරලා ඔයාගේ ව් යාපෘතියේ ක්ලෝන ගණන පාලනය කරන්න, ඒවා තවදුරටත් අවශ් ය නැති වෙලාවට ඒවා මකා දමන එක.
