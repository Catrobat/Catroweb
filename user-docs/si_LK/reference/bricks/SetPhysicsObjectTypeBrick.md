වස්තුවක් ගමන් කරන ආකාරය වෙනස් කරයි, එනම් එය ග් රැවීටීෂන් යටතේ ගමන් කිරීමට හා පනින්න ඉඩ දීම, ග් රැවීටීෂන් යටතේ නොපෙනේ නමුත් අනෙක් අය ඔයාෙන් පනින්න හෝ ග් රැවීටීෂන් යටතේ නොපෙනේ. ඒක හරියට චරිතය හැසිරෙන ආකාරය තෝරා ගැනීම වගේ.
