තිරය ස්පර්ශ කරනකොට ලේඛනය ක් රියාත්මක වෙනවා.

*“තට්ටු කළ විට”* කොටසට ඇති වෙනස වන්නේ *“වේදිකාව තට්ටු කළ විට”* මුළු තිරයටම අදාළ වන අතර *“තට්ටු කළ විට”* තනි ස්ප් රයිට් හෝ වස්තූන් සඳහා විශේෂ වේ.
