![ප්ලොට් කිරීම නවත්වන්න](../../../media/bricks/Stop_to_plot.png)

“ප්ලොට් කිරීම නවත්වන්න” කේතය වාරණය කිරීමේ ක් රියාවලිය නතර කරන අතර ඔයාට නළුවා නව ස්ථානයකට ගෙනයාමට හෝ සැලසුම අවසන් කිරීමට ඉඩ සලසයි. ඒක හරියට කඩදාසි පිටින් පෑනක් උස්සලා ඒක නැවත ස්ථානගත කරන්න හෝ චිත් ර ඇඳීම නවත්වන්න වගේ. ඔයා සැලසුම් කිරීම අවසන් කළ පසු, ඔයාට ඔයාගේ සැලසුම SVG ගොනුවක් ලෙස සුරැකීමට “ප්ලොට් එක SVG ලෙස සුරකින්න:” කේතය භාවිතා කළ හැකිය.
