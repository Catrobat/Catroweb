මේ කේතය නළුවා පාවිච්චි කරන පෑනක පාට වෙනස් කරනවා. ඒක හරියට චිත් ර ඇඳගෙන යනකොට වෙනස් පාටකින් ලියන පෑනකට මාරුවෙනවා වගේ.

**රතු, කොළ, නිල් (RGB)**: - ප් රදේශයේ RGB වර්ණ ආකෘතිය රතු, කොළ සහ නිල් පැහැති විවිධ තරමක ආලෝකය භාවිතා කරමින් වර්ණ වර්ග රාශියක් නිර්මාණය කරයි. සෑම වර්ණ සංරචකයකටම (රතු, කොළ සහ නිල්) 0 සිට 255 අතර අගයක් තිබිය හැකිය:

- **රතු**: වර්ණයේ රතු අංගය. වැඩිපුර අගය කියන්නේ රතු පාටයි.
- **කොළ පාට**: වර්ණයේ කොළ පාට අංගය. වැඩිපුර වටිනාකම කියන්නේ හරිතයි.
- **නිල් පාට**: නිල් පාටේ සංරචකය. වැඩිපුර අගය කියන්නේ නිල් පාටයි.

රතු, කොළ සහ නිල් වර්ණ සඳහා විවිධ අගයන් ඒකාබද්ධ කිරීමෙන් ඔයාට ඕනෑම වර්ණයක් නිර්මාණය කළ හැකිය. උදාහරණයක් ලෙස:

- `RGB(255, 0, 0)` පාට රතුයි.
- `RGB(0, 255, 0)` කියන්නේ හරිත පාටයි.
- `RGB(0, 0, 255)` නිල් පාටයි.
- `RGB(255, 255, 255)` සුදු (උපරිම රතු, කොළ සහ නිල්).
- `RGB(0, 0, 0)` කළු (අභරණ නැහැ).

විවිධ ප් රමාණයේ මේ වර්ණ මිශ් ර කිරීමෙන් ඔයාට ඩිජිටල් තිර වල පෙනෙන සියලුම වර්ණ නිර්මාණය වෙනවා.
