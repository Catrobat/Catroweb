![ප්ලොට් කිරීම ආරම්භ කරන්න](../../../media/bricks/Start_to_plot.png)

මේ කේතය ක් රියාත්මක වන විට, නළුවාගේ චලනය ආරම්භ වෙනවා. එය කඩදාසි මත පෑනක් තැබීම හා සමානයි. ඔයාට මෙම ඇඳීම නතර කර වෙනත් ස්ථානයකට ගෙනයාමට අවශ් ය නම් “ප්ලොට් කිරීම නවත්වන්න” කේතය භාවිතා කළ හැකිය. පසුව නැවතත් “ප්ලොට් කිරීම ආරම්භ කරන්න” සමඟ කූටය ආරම්භ කරන්න.
