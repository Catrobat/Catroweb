![මුද්‍රාව තබන්න](../../../media/bricks/Stamp_.png)

මේ කේතය භාවිතා කිරීමෙන්, ඔයා ඔයාගේ චරිතයේ පෙනුම පිටපතක් තිරයට තබනවා. ඒක හරියට කඩදාසි මත වර්ණවත් මුද්දරයක් තැබීම හා මුද්දර සැලසුමේ පිටපතක් ඉතිරි කිරීම වගේ. මේ විදිහට ඔයා ඔයාගේ පසුබිම වැඩි දියුණු කරනවා - ඔයා ක්ලෝන එකක් හදන්නේ නැහැ!
