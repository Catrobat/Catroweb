![කේතය block වලින් for-values](../../../media/bricks/for-values-from-brick.png)

මෙම කේතය සංකේතයක් ලෙස, එක් අගයකින් ආරම්භ වන සහ තවත් අගයක් මත අවසන් වන කවුන්ටරයක් භාවිතා කරමින් නිශ්චිත සංඛ් යාවක් වරක් උපදෙස් මාලාවක් ක් රියාත්මක කරයි. ඒක හරියට ලූප් එකක් සකස් කරන එක වගේ, ඔයාට හරියටම දැනගන්න පුළුවන් ඔයා කොච්චර වාරයක් මේක ක් රියාත්මක කරන්න ඕනද කියලා.

හිතන්න ඔයාට අයිතම ලැයිස්තුවක් තියෙනවා කියලා, ඒ හැම එකක් එක්කම ඔයාට මොකක් හරි කරන්න ඕන කියල. මේ බ්ලොක් එකෙන් ඔයාට පුළුවන් හැම අයිතමයම එකින් එක හරහා යන්න, එකකට එකම දේ කරන්න.
