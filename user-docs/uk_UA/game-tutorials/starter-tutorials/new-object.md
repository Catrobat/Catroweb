У цьому уроці ти навчишся створювати новий об’єкт у своєму проєкті та дізнаєшся про різні можливості для цього.

![Новий об’єкт](../../../media/game-tutorials/New-Object.png)

Для цього ти маєш уже завантажити застосунок Pocket Code і вміти створювати новий проєкт. Якщо потрібна допомога, загляни до уроку **[Новий проєкт](new-project.md)**.

*Ось ти можеш завантажити цей урок у форматі PDF:*

[Новий об’єкт](../../../media/game-tutorials/New-Object.pdf)

### 1. Створи новий об’єкт

Спочатку треба відкрити свій новий проєкт.

Знайти його можна на головному екрані застосунку Pocket Code. Якщо в тебе більше одного проєкту, натисни «Проєкти на пристрої». Потім вибери свій новий проєкт. Якщо ти ще не створив новий проєкт або потрібні додаткові пояснення, як це зробити, подивися урок **[Новий проєкт](new-project.md)**.

### 2. Створи новий об’єкт

Тепер можна створити новий об’єкт. Для цього натисни жовту кнопку «плюс» у правому нижньому куті. Побачиш нове вікно із сімома варіантами на вибір.

![Новий об’єкт (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. Способи створення

Ось варіанти, які можна вибрати:

![Новий об’єкт (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. Намалювати зображення

Щоб на початку було якомога простіше, використаємо функцію «Намалювати» і просто намалюємо крапку. Коли намалюєш крапку в Pocket Paint, можна вийти з неї (повернувшись на крок назад).

### 5. Дай назву

Тепер треба дати своєму зображенню назву.

### 6. Розмісти його

Після цього треба розмістити його візуально: пересунь пальцем ліворуч, праворуч, угору або вниз. Збережи, натиснувши кнопку у правому верхньому куті.

![Новий об’єкт (3)](../../../media/game-tutorials/New-Object-3.png)

::brick{type=PlaceAtBrick}

### 7. Готово! Ти створив свій новий об’єкт.

Тепер у тебе є проєкт з об’єктом, який можна запрограмувати!

Для цього варто знати, які блоки доступні. Урок **[Перші блоки](first-bricks.md)** дає гарний огляд різних категорій блоків. Проте можна почати й одразу з першого проєкту. Вибери відповідний урок із серії для початківців.
