![Розмістити на x: y:](../../../media/bricks/place_at_x_y_brick.png)

Переміщує об’єкт на певне місце на екрані, яке задають координати x і y. Це як телепортувати твого персонажа в точно вказане місце.

Положення задається в системі координат, схожій на декартову площину: осі x і y проходять через центр екрана, тож x = 0 і y = 0 — це середина екрана.
