![Коли епізод починається](../../../media/bricks/When_scene_starts_btn2.png)

Якщо ти використовуєш цей блок, скрипт почне працювати одразу, коли починається епізод. Епізод — це початок твоєї програми. Епізод — це новий вигляд у твоїй програмі, на якому можна показувати інші елементи та де можуть відбуватися різні взаємодії. Можна створити багато епізодів для різних етапів програми. Наприклад, один епізод для вступу, один для головного меню, один для першого рівня, один для другого рівня і так далі. У простіших програмах достатньо одного епізоду, тоді початок програми одночасно є початком епізоду.

Як і кожен скрипт, цей починається з блоку події: подія визначає, **коли** починається скрипт, а блоки після неї кажуть програмі, **що** робити.
