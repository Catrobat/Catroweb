![Коли запускається як клон](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Дає створеному клону об’єкта інструкції для потрібних дій. Так можна повторити функції початкового об’єкта, але керувати клоном незалежно. Можна задати різну поведінку або властивості клона, щоб вони відповідали потрібним вимогам.
