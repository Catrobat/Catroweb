**Червоний, зелений, синій (RGB)**: Модель кольорів RGB використовує різну інтенсивність червоного, зеленого і синього світла, щоб створити широкий спектр кольорів. Кожна складова кольору (червона, зелена і синя) може мати значення від 0 до 255:

- **Червоний**: червона складова кольору. Більше значення означає більше червоного.
- **Зелений**: зелена складова кольору. Більше значення означає більше зеленого.
- **Синій**: синя складова кольору. Більше значення означає більше синього.

Комбінуючи різні значення червоного, зеленого й синього, можна створити будь-який колір. Наприклад:

- `RGB(255, 0, 0)` — чисто червоний.
- `RGB(0, 255, 0)` — чисто зелений.
- `RGB(0, 0, 255)` — чисто синій.
- `RGB(255, 255, 255)` — білий (максимум червоного, зеленого й синього).
- `RGB(0, 0, 0)` — чорний (без кольору).

Змішуючи ці кольори в різних пропорціях, можна отримати всі кольори, які ти бачиш на цифрових екранах.
