![Створити клон](../../../media/bricks/create_clone_of_brick2.png)

Цей блок створює копію вказаного об’єкта, яка називається клоном. Клон поводиться як оригінал. Уяви, що ти дублюєш персонажа в своїй грі. Клон може мати власну поведінку й скрипти, тож можна створити кілька копій об’єкта, які діятимуть незалежно одна від одної.
