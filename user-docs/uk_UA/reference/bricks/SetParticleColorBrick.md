![Установити колір частинок на «#ff0000»](../../../media/bricks/Set_particle_colour_to_ff0000.png)

Цей блок змінює колір частинок, які випускає актор. Це як змінити колір конфетті в хлопавці.

Шістнадцятковий код кольору — це спосіб записати колір за допомогою шістнадцяткових значень. Він складається з шести символів, які можуть бути цифрами (0–9) або літерами (A–F). Код зазвичай записують із символом «#» на початку, наприклад так: `#RRGGBB`.

- Перші два символи (`RR`) визначають червону складову кольору.
- Наступні два символи (`GG`) визначають зелену складову.
- Останні два символи (`BB`) визначають синю складову.

Кожна пара символів може бути від `00` (означає, що цього кольору немає) до `FF` (означає максимальну кількість цього кольору). Наприклад:

`#000000` — чорний (без кольору).

`#FF0000` — чисто червоний.

`#00FF00` — чисто зелений.

`#0000FF` — чисто синій.

`#FFFFFF` — білий (максимум червоного, зеленого й синього).
