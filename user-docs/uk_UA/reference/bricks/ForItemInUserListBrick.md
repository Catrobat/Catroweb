![Для кожного значення від](../../../media/bricks/for-each-value_brick.png)

Цей блок виконує набір інструкцій для кожного елемента списку або діапазону. Це як пройтися по кожному елементу по черзі й зробити з ним одне й те саме.

Уяви, що в тебе є список чисел, кольорів або будь-яких інших елементів. Цей блок дозволяє взяти кожен елемент зі списку й щось із ним зробити. Наприклад, якщо в тебе є список кольорів і ти хочеш по черзі змінювати колір тла на кожен із них, використай саме цей блок.

Це як сказати: «Для кожного елемента в цій групі виконай ці інструкції».
