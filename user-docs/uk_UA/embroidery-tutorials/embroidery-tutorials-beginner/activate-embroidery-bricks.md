У цьому уроці пояснюється, як активувати блоки вишивки.

![Активувати блоки вишивки 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Для цього не потрібні знання програмування. Це перший крок, з якого варто почати уроки з вишивання. Пізніше ти зможеш створювати, програмувати і навіть вишивати власні дизайни на улюбленій тканині.

Щоб дізнатися більше або отримати ідеї для дизайнів, подивися інші уроки.

*Ось ти можеш завантажити цей урок у форматі PDF*:

[Активувати блоки вишивки](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Відкрий застосунок «Pocket Code». Іди за кліками!

### 2. Відкрий меню (крапки праворуч угорі).

![Активувати блоки вишивки 1](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Перейди в «Налаштування».

![Активувати блоки вишивки 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Вибери «Розширення вишивки».

![Активувати блоки вишивки 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Блоки вишивки з’являться як окрема категорія серед твоїх блоків!

[![Активувати блоки вишивки 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Тепер ти знайдеш усі блоки вишивки серед інших блоків.

Щоб дізнатися більше про кожен блок, перегляньте документацію блоків [тут](../../../reference/) або пройди урок **[Блоки вишивки](embroidery-bricks/index.md)**.

Тепер можна починати й створювати власні дизайни!

Якщо потрібні ідеї чи допомога, подивися інші уроки або переходь до уроку **[Створити об’єкти для вишивки](create-embroidery-objects.md)**.
