Вишиває без перерви зі змінною довжиною та шириною.

Вишиває зигзагом.

![Почати шов зигзаг із довжиною 2 і шириною 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

Спробуй різні значення довжини й ширини, щоб познайомитися з цим блоком.

![Зигзагоподібний шов](../../../../media/embroidery-tutorials/ZigzagStitch.png)

Зигзагоподібним швом можна вишивати товщі шви.
