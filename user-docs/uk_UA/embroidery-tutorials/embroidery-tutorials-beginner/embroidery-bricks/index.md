У цьому уроці ти дізнаєшся все, що треба знати про блоки вишивки!

Для цього не потрібні знання програмування.

Кожен блок вишивки пояснюється на прикладі.

Якщо ти ще не активував блоки вишивки, подивися урок **[Активувати блоки вишивки](../activate-embroidery-bricks.md)**.

*Ось ти можеш завантажити цей урок у форматі PDF*:

[Блоки вишивки](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Натискай на різні блоки, щоб дізнатися про них більше:**

[![Стібок](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*Змушує машину зробити один стібок у тканину!*

[![Почати прямий шов із довжиною 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*Змушує машину вишивати без перерви зі змінною довжиною стібка.*

[![Почати шов зигзаг із довжиною 2 і шириною 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Вишиває без перерви зі змінною довжиною та шириною.*

[![Почати потрійний шов із довжиною 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*Потрійний шов прошиває кожен стібок тричі.*

[![Зупинити поточний шов](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Зупиняє поточний стібок.*

Більше блоків вишивки та інформацію про них можна знайти [тут](../../../../reference/#category_embroidery).

Щоб дізнатися більше або отримати ідеї для дизайнів, подивися інші уроки!
