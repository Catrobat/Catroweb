Змушує машину вишивати без перерви зі змінною довжиною стібка.

Зазвичай прямий шов комбінують із блоком «Перемістити на».

![Почати прямий шов із довжиною 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Машина починає прямий шов, який вишиває кожні **10 кроків**.

Потім машина пересувається на **200 кроків**.

У результаті виходить **20 стібків**.

![Прямий шов](../../../../media/embroidery-tutorials/RunningStitch.png)

Прямий шов спрощує вишивання шва, бо тобі більше не потрібен цикл.
