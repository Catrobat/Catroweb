Потрійний шов прошиває кожен стібок тричі.

Потрійний шов після першого стібка відстрибує назад, робить стібок, потім знову стрибає вперед і робить ще один стібок.

![Почати потрійний шов із довжиною 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Працює так само, як [прямий шов](running-stitch.md).

![Потрійний шов](../../../../media/embroidery-tutorials/TripleStitch.png)

Так шов служить довше.
