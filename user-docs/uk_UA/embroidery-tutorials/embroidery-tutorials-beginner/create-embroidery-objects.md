У цьому уроці ти навчишся створювати об’єкти, за допомогою яких пізніше вишиватимеш свої візерунки.

Для цього уроку ти маєш уже вміти створювати проєкт. Якщо потрібна допомога, подивися уроки з [серії для початківців](../../game-tutorials/starter-tutorials/index.md).

Щоб дізнатися більше або отримати ідеї для дизайнів, подивися інші уроки.

*Ось ти можеш завантажити цей урок у форматі PDF*:

[Створити об’єкти для вишивки](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Натисни кнопку «плюс» у правому нижньому куті проєкту, щоб додати новий об’єкт.

![Створити об’єкти для вишивки](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Щоб вибрати зображення, перейди до медіатеки.

![Створити об’єкти для вишивки (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Вишивальний об’єкт — це один рівень голки вишивальної машини. Кілька вишивальних об’єктів вишиваються один за одним. Так можна використати кілька кольорів.

Вибери об’єкт залежно від кольору, який хочеш.

Прокрути вниз і знайди відповідну стрілку.

![Створити об’єкти для вишивки (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Дай своєму новому об’єкту відповідну назву і натисни «ОК».

![Створити об’єкти для вишивки (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Тепер ти створив новий об’єкт. Можна додати скрипт і запрограмувати його.

![Створити об’єкти для вишивки (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Тепер ти знаєш, як створити об’єкт. Додавай новий об’єкт для кожного кольору, який хочеш використати.

Для кожного кольору можна додати скрипт і запрограмувати власний дизайн, а потім навіть вишити його.

Потрібні натхнення чи допомога? Подивися наші інші уроки!
