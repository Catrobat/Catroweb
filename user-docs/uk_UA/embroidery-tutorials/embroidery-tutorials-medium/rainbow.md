У цьому уроці ти навчишся вишивати веселку (112 x 57.2 мм).

![Веселка](../../../media/embroidery-tutorials/Regenbogen.webp)

Ти вже маєш знати, що таке цикл і як він працює.

Урок **[Півколо](../embroidery-tutorials-beginner/semicircle.md)** може стати в пригоді для цього уроку.

Подивися уроки з вишивання в серії [для початківців](../embroidery-tutorials-beginner/index.md), якщо ти ще нічого не вишивав.

Щоб дізнатися більше або отримати ідеї для дизайнів, подивися інші уроки.

*Ось ти можеш завантажити цей урок у форматі PDF*:

[Веселка](../../../media/embroidery-tutorials/Rainbow.pdf)

### 1. Створи новий вишивальний об’єкт (див. [Створити об’єкти для вишивки](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![Веселка](../../../media/embroidery-tutorials/Rainbow.png)

### 2. Встав такий скрипт:

![Веселка (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. Копіювати об’єкт

Для наступної, більшої дуги можна просто скопіювати щойно створений об’єкт.

Натисни на три крапки у правому верхньому куті огляду об’єктів.

Потім перейди до «Копіювати» й вибери об’єкт.

![Веселка (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Якщо ти використовуєш окремий об’єкт для кожної дуги, пізніше їх можна буде вишити різними кольорами.

### 4. Змінити об’єкт

Щоб дуги стали різного розміру, треба змінити кілька значень.

Для цього відкрий скрипт скопійованого об’єкта і налаштуй такі значення:

![Веселка (2)](../../../media/embroidery-tutorials/Rainbow-2.png)

### 5. Повтори кроки 3 і 4 для більшої кількості дуг!

### 6. Натисни «Запустити», щоб почати свій дизайн!
