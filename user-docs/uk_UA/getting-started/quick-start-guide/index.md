Pocket Code — це застосунок візуального програмування, який дає змогу створювати ігри, анімації та інтерактивні історії прямо на смартфоні або планшеті. Використовуючи зрозумілий інтерфейс «перетягни й відпусти» з «блоками» (блоками коду), ти можеш створювати проєкти без попереднього досвіду програмування. Легко додавай звуки, зображення й рух, щоб оживити свої ідеї.

Цей посібник допоможе тобі почати роботу, пояснивши, як:

- орієнтуватися в інтерфейсі,
- створити свій перший проєкт,
- працювати з об’єктами й тлом,
- використовувати блоки, щоб програмувати дії, і
- зберегти свій проєкт.

Pocket Code ідеально підходить для початківців і вчителів: він розвиває творчість, вміння розв’язувати задачі та логічне мислення.
