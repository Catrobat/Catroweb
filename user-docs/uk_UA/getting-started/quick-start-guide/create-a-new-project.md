Відкрий застосунок на смартфоні або планшеті.

![MainScreen_NewProject](../../../media/getting-started/MainScreen_NewProject.png)\
Натисни символ +, щоб створити новий проєкт.\
[Відкрити зображення](../../../media/getting-started/MainScreen_NewProject.png)

Дай проєкту назву (1) і вибери, хочеш ти створити гру у вертикальному (портретному) чи горизонтальному (альбомному) форматі (2).

![NewProject](../../../media/getting-started/NewProject.png)\
Потім підтверди галочкою (3).\
[Відкрити зображення](../../../media/getting-started/NewProject.png)

Тепер ти в перегляді проєкту. Угорі ти бачиш назву своєї гри.

Нижче видно **тло** — зараз воно порожнє. Щоб його змінити, натисни на нього.

Під тлом є область для твоїх **акторів і об’єктів**, які ти додав до гри. Зараз ця область ще порожня.

Унизу праворуч є дві важливі кнопки:

![Старт](../../../media/getting-started/Start.png)\
Кнопкою **«Запустити»** ти запускаєш свою гру.

![Кнопка плюс](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Кнопкою **«плюс»** ти додаєш до гри нового персонажа або об’єкт.

![Екран проєкту](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
Тепер ти в перегляді проєкту.\
[Відкрити зображення](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
