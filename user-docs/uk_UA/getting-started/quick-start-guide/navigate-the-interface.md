Коли ти запускаєш Pocket Code, бачиш таке головне екранне вікно.

![Головний екран](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Коли ти запускаєш Pocket Code, бачиш таке головне екранне вікно.\
[Відкрити зображення](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Довідка](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
У правому верхньому куті є символ, який веде до документації Catrobat з корисними порадами для тебе.

![Меню](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Поруч розташоване меню.

Звідти легко перейти до налаштувань, де можна змінити мову або увімкнути розширення, як-от блоки плотера та інші.

![Значок редагування](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Натисни на значок редагування, щоб відкрити екран проєкту й продовжити роботу над ним.

Нижче видно твій останній відредагований проєкт.

![Запустити проєкт](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Натисни кнопку запуску, щоб запустити свій проєкт.

![Проєкти на пристрої](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Натиснувши «Проєкти на пристрої», ти відкриєш збережені проєкти.

![Спільнота Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Якщо хочеш ознайомитися з проєктами інших користувачів і попрацювати з ними, натисни «Спільнота Catrobat» у розділі Share.

Там ти знайдеш багато чудових проєктів.

![Додати](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Якщо хочеш створити новий проєкт, натисни значок плюс.
