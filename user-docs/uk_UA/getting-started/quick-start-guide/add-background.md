Тло можна додати до свого проєкту в Catrobat.

Тло можна використовувати по-різному. У Pocket Code воно може візуально прикрасити **ігри**, розповісти **історії** або дати твоїм акторам і об’єктам більше контексту.

Для пристроїв із майстерень, таких як **плотери** або **вишивальні машини**, тло слугує шаблоном дизайну, наприклад для вирізання або вишивки.

![Натиснути на Тло](../../../media/getting-started/grafik-16.png)\
Щоб додати тло, натисни «Тло» в перегляді проєкту.\
[Відкрити зображення](../../../media/getting-started/grafik-16.png)

У **розділі скриптів (2)** можна запрограмувати тло, але не всі блоки тут доступні. Особливо важливі два такі блоки: ![Установити прозорість на 50 %](../../../media/bricks/Set_transparency_to_50_pct_.png) і ![Установити розмір на 60 %](../../../media/bricks/Set_size_to_60_pct_.png)

У **розділі виглядів (1)** ти додаєш тло.

![Додати тло](../../../media/getting-started/grafik-14.png)\
Для цього натисни символ +.\
[Відкрити зображення](../../../media/getting-started/grafik-14.png)

Можна завантажити власні зображення, використати готові тла або створити тло самому.

**Намалювати**: Можна створити власне тло в **Pocket Paint**. Pocket Paint — це програма для малювання ([більше про Pocket Paint](https://catrobat.org/pocket-paint/))

**Вигляди**: Вибери одне з готової колекції тел ([більше про медіатеку](../elements/medialibrary.md)).

**Галерея**: Можна вибрати зображення з галереї твого смартфона.

**Камера**: Можна використати камеру пристрою, щоб зробити фото і додати його як тло.

![Тло](../../../media/getting-started/grafik-17.png)\
Натисни стрілку назад угорі праворуч, щоб повернутися до **перегляду проєкту**.\
[Відкрити зображення](../../../media/getting-started/grafik-17.png)

Тло додано.
