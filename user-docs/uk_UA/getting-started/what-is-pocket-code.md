Pocket Code — це головний застосунок Catrobat, безкоштовний застосунок із відкритим кодом, який дає змогу створювати ігри, анімації та інтерактивні історії прямо на смартфоні чи планшеті. Використовуючи **блочну систему** Pocket Code, ти можеш будувати проєкти, складаючи блоки з кодом, як пазли. Досвід програмування не потрібен, тож застосунок ідеально підходить для початківців!

Pocket Code виходить за межі цифрових проєктів. З новими **функціями для майстерень** ти також можеш створювати **файли SVG для плотерів для різання**. Так твої цифрові задуми стають речами з реального світу, і ти відкриваєш творчі можливості поза екраном.

Ти вчишся програмувати, експериментуєш із новими ідеями чи викладаєш програмування: Pocket Code дає весело й доступно зануритися в програмування.
