Коли малюнок починається, кожен рух малюється так, ніби ручкою. Це лінії, по яких плотер згодом різатиме.

Наш об’єкт повертається в напрямку 150 градусів.

У цьому уроці спочатку малюється права сторона голови кота. Якщо придивитися, спершу крива сильна, тож після кожної маленької лінії об’єкт має повертатися сильніше. Далі повороти стають меншими для нижньої частини голови. Ліва сторона голови знову сильно вигнута. Тому ця частина голови використовує три цикли загалом.

Далі йде ліве вухо. Воно складається лише з прямих ліній, тож можна використати блок «Перемістити на __ кроків».

Частина між вухами знову є дугою, і її програмують іншим циклом.

Потім малюється праве вухо.

Малюнок тепер готовий. Заверши його блоком «Зупинити плотер» і збережи на телефоні блоком «Зберегти малюнок плотера як SVG___».

Тепер ти можеш надіслати файл SVG на (різальний) плотер.
