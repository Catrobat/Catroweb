Pocket Code là ứng dụng lập trình trực quan giúp bạn tạo trò chơi, hoạt hình và câu chuyện tương tác ngay trên điện thoại hoặc máy tính bảng. Với giao diện kéo và thả trực quan cùng các “khối lệnh” (khối mã), bạn có thể thiết kế dự án mà không cần kinh nghiệm lập trình. Bạn dễ dàng thêm âm thanh, hình ảnh và chuyển động để biến ý tưởng thành hiện thực.

Hướng dẫn này sẽ giúp bạn bắt đầu bằng cách giải thích cách:

- Làm quen với giao diện,
- Tạo dự án đầu tiên,
- Làm việc với nhân vật và phông nền,
- Dùng khối lệnh để lập trình hành động, và
- Lưu dự án của bạn.

Pocket Code rất phù hợp cho người mới bắt đầu và giáo viên, khuyến khích sự sáng tạo, khả năng giải quyết vấn đề và tư duy logic.
