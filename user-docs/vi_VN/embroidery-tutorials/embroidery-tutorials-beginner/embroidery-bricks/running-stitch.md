Cho máy thêu liên tục với độ dài thay đổi được.

Thường thì bạn kết hợp mũi chạy với khối di chuyển.

![Bắt đầu mũi chạy với độ dài 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Máy bắt đầu một mũi chạy, cứ mỗi **10 bước** lại thêu một mũi.

Sau đó máy di chuyển **200 bước**.

Kết quả là **20 mũi thêu**.

![Mũi chạy](../../../../media/embroidery-tutorials/RunningStitch.png)

Mũi chạy giúp việc thêu đường may dễ hơn vì bạn không cần vòng lặp nữa.
