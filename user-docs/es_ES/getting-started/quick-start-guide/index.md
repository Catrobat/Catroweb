Pocket Code es una app de programación visual. Con ella creas juegos, animaciones e historias interactivas en tu móvil o tableta. Arrastras y sueltas “bricks” (bloques de código), así que puedes crear tus proyectos aunque nunca hayas programado. Añade sonidos, imágenes y movimiento de forma fácil y haz realidad tus ideas.

Esta guía te ayuda a empezar. Te explica cómo:

- moverte por la app,
- crear tu primer proyecto,
- trabajar con objetos y fondos,
- usar bricks para programar acciones y
- guardar tu proyecto.

Pocket Code es perfecta para principiantes y profesores. Te ayuda a ser creativo, a resolver problemas y a pensar con lógica.
