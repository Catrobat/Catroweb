Cuando abres Pocket Code, ves esta pantalla principal.

![Pantalla principal](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Cuando abres Pocket Code, ves esta pantalla principal.\
[Abrir imagen](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Ayuda](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Arriba a la derecha hay un símbolo.

Te lleva a la documentación de Catrobat, donde encuentras consejos útiles.

![Menú](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Al lado está el menú.

Desde ahí llegas a los ajustes. Allí puedes cambiar el idioma o activar extensiones, por ejemplo los bloques para plotter.

![Icono de editar](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Toca el icono de editar para ir a la pantalla del proyecto y seguir trabajando en él.

Debajo ves el último proyecto que editaste.

![Inicia tu proyecto](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Con el botón de jugar inicias tu proyecto.

![Proyectos en el dispositivo](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Toca “Proyectos” para ver los proyectos guardados en tu dispositivo.

![Catrobat Community](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
¿Quieres conocer proyectos de otras personas y trabajar con ellos?

Toca Catrobat Community en Share. Allí hay muchos proyectos geniales.

![Añadir](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Para crear un proyecto nuevo, toca el símbolo +.
