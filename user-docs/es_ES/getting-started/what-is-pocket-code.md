Pocket Code es la app principal de Catrobat. Es una app gratis y libre (de código abierto). Con ella creas juegos, animaciones e historias interactivas en tu móvil o tableta. Pocket Code usa **bloques de código**: juntas los bloques para montar tu proyecto, como las piezas de un puzle. No necesitas saber programar, así que es perfecta para empezar.

Con Pocket Code no solo haces proyectos en la pantalla. Con las nuevas **funciones para makerspaces** también puedes diseñar **archivos SVG para plotters de corte**. Así conviertes lo que creas en cosas reales y descubres muchas ideas nuevas fuera de la pantalla.

Si aprendes a programar, pruebas ideas nuevas o enseñas programación, Pocket Code te ofrece una forma divertida y fácil de empezar a programar.

[Más información](https://catrobat.org/pocket-code/)
