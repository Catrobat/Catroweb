Hace que la máquina dé puntadas sin parar, con una longitud que tú eliges.

Normalmente juntas la puntada recta con un bloque de movimiento.

![Iniciar puntada recta con longitud 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

La máquina empieza una puntada recta que da una puntada cada **10 pasos**.

Después la máquina se mueve **200 pasos**.

Así salen **20 puntadas**.

![Puntada recta](../../../../media/embroidery-tutorials/RunningStitch.png)

Con la puntada recta es más fácil coser una costura, porque ya no necesitas un bucle.
