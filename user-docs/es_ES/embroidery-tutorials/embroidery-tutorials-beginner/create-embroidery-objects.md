En este tutorial aprendes a crear objetos. Con ellos podrás bordar tus diseños más tarde.

Para este tutorial ya deberías saber cómo crear un proyecto. Si necesitas ayuda, mira los tutoriales de la [serie Starter](../../game-tutorials/starter-tutorials/index.md).

Si quieres más información o ideas para diseños, mira los otros tutoriales.

*Aquí puedes descargar el tutorial en PDF*:

[Crear objetos de bordado](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Toca el botón + abajo a la derecha de tu proyecto para añadir un objeto nuevo.

![Crear objetos de bordado](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Para elegir una imagen, ve a la librería de medios.

![Crear objetos de bordado (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Un objeto de bordado es un nivel de la aguja de la máquina de bordar. La máquina borda varios objetos de bordado uno detrás de otro. Así puedes usar varios colores.

Puedes elegir tu objeto según el color que quieras.

Baja en la lista y busca la flecha que te sirva.

![Crear objetos de bordado (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Dale a tu objeto nuevo un nombre que encaje y toca OK.

![Crear objetos de bordado (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Ya has creado un objeto nuevo. Ahora puedes añadirle un script y programar el objeto.

![Crear objetos de bordado (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Ya sabes cómo crear un objeto. Añade un objeto nuevo para cada color que quieras usar.

En cada color puedes añadir un script, programar tus propios diseños y hasta bordarlos después.
