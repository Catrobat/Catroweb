### 3. Copiar el objeto

Para el siguiente arco, que es más grande, puedes copiar el objeto que acabas de crear.

Toca los tres puntos arriba a la derecha en la lista de objetos.

Luego ve a “Copiar” y elige el objeto.

![Arcoíris (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Si usas un objeto distinto para cada arco, después puedes bordarlos en colores diferentes.

Para que los arcos tengan tamaños distintos, tenemos que cambiar algunos valores.
