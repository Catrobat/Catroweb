![Continuar escena](../../../media/bricks/continue_scene_brick2.png)

Este bloque sigue con la escena desde donde se quedó parada. Si tu escena se paró por una pausa o una espera, con este bloque la acción sigue justo donde se quedó.

Imagina que pausaste un juego o una animación y ahora quieres que siga. Este bloque es como el botón de “play”: todo sigue desde donde se paró.
