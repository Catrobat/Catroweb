![Para valores de](../../../media/bricks/for-values-from-brick.png)

Este bloque hace unas instrucciones un número concreto de veces. Usa un contador que empieza en un valor y termina en otro. Es como preparar un bucle cuando ya sabes cuántas veces tiene que repetirse.

Imagina que tienes una lista de cosas y quieres hacer algo con cada una. Con este bloque vas por las cosas una por una y haces lo mismo con cada una.
