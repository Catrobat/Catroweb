![Fijar color del lápiz a rojo 0 verde 0 azul 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Este bloque cambia el color del lápiz que usa el actor. Es como coger un lápiz de otro color mientras dibujas.

**Rojo, verde, azul (RGB)**: El modelo de color RGB mezcla luz roja, verde y azul con distinta fuerza. Así salen muchísimos colores. Cada parte del color (rojo, verde y azul) puede tener un valor entre 0 y 255:

- **Rojo**: la parte roja del color. Un valor más alto significa más rojo.
- **Verde**: la parte verde del color. Un valor más alto significa más verde.
- **Azul**: la parte azul del color. Un valor más alto significa más azul.

Si combinas distintos valores de rojo, verde y azul, puedes crear cualquier color. Por ejemplo:

- `RGB(255, 0, 0)` es rojo puro.
- `RGB(0, 255, 0)` es verde puro.
- `RGB(0, 0, 255)` es azul puro.
- `RGB(255, 255, 255)` es blanco (lo máximo de rojo, verde y azul).
- `RGB(0, 0, 0)` es negro (nada de color).

Al mezclar estos colores en distintas cantidades salen todos los colores que ves en las pantallas.
