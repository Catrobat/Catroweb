![Convertirse en punto de enfoque con 0 % de flexibilidad horizontal y 0 % de flexibilidad vertical](../../../media/bricks/Become_focus_point_with_0_pct__horizontal_and__0_pct__vertical_flexibility_.png)

Este bloque hace que el actor sea el punto de enfoque de la pantalla. Tú decides cuánta flexibilidad hay en horizontal y en vertical. Es como decirle a la cámara que siga a un personaje, pero dejando que se mueva un poco alrededor del centro.
