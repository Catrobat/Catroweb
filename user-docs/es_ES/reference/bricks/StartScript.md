![Al iniciar la escena](../../../media/bricks/When_scene_starts_btn2.png)

Si usas este bloque, el script empieza en cuanto empieza la escena. Una escena es el comienzo de tu programa. Una escena es una vista nueva de tu programa. En ella se pueden mostrar otros elementos y pueden pasar cosas distintas. Puedes tener muchas escenas para las distintas partes de tu programa. Por ejemplo, una escena para la introducción, una para el menú principal, una para el primer nivel, una para el segundo nivel y así. En programas más sencillos basta con una sola escena. Entonces el comienzo de tu programa es también el comienzo de la escena.

Como todos los scripts, este empieza con un bloque de evento: el evento decide **cuándo** empieza el script y los bloques que vienen después le dicen al programa **qué** tiene que hacer.
