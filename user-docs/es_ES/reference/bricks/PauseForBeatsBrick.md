![Pausar durante 1 pulsos](../../../media/bricks/Pause_for_1_beats.png)

Este bloque hace que el script espere un número de pulsos antes de seguir. Es como hacer una pausa corta en una canción antes de tocar la siguiente nota o sonido. Imagina que paras tu actuación un momento, cuentas los pulsos y luego sigues.
