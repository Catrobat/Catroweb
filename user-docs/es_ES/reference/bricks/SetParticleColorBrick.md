![Fijar color de partículas a ’#ff0000′](../../../media/bricks/Set_particle_colour_to_ff0000.png)

Este bloque cambia el color de las partículas que suelta el actor. Es como cambiar el color del confeti de un lanzador de fiesta.

Un código de color hexadecimal es una forma de escribir colores con valores hexadecimales. Tiene seis caracteres. Pueden ser números (0-9) o letras (A-F). Normalmente el código empieza con “#”, así: `#RRGGBB`.

- Los dos primeros caracteres (`RR`) son la parte roja del color.
- Los dos siguientes (`GG`) son la parte verde.
- Los dos últimos (`BB`) son la parte azul.

Cada pareja de caracteres va de `00` (nada de ese color) a `FF` (lo máximo de ese color). Por ejemplo:

`#000000` es negro (nada de color).

`#FF0000` es rojo puro.

`#00FF00` es verde puro.

`#0000FF` es azul puro.

`#FFFFFF` es blanco (lo máximo de rojo, verde y azul).
