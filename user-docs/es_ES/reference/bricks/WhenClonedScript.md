![Al comenzar como clon](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Con este bloque le das instrucciones a un clon de un objeto para que haga lo que tú quieres. El clon puede hacer lo mismo que el objeto original, pero tú lo controlas por separado. Puedes decidir distintos comportamientos o propiedades del clon, según lo que necesites.
