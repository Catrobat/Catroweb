![Iniciar escena](../../../media/bricks/start_scene_brick2.png)

Este bloque cambia a otra escena de tu proyecto y la empieza desde el principio. Es como pasar a otro capítulo de un libro o ir al siguiente nivel de un juego.

Imagina que tu proyecto tiene varias escenas. Cada una es una parte distinta de tu historia o de tu juego. Con este bloque puedes saltar a cualquier escena y empezarla desde el principio. Así el paso de una parte a otra de tu proyecto queda suave.
