![Empezar a trazar](../../../media/bricks/Start_to_plot.png)

Este bloque empieza a trazar mientras el actor se mueve. Es como poner un lápiz sobre el papel para empezar a dibujar una línea. Si quieres parar el dibujo y mover el actor a otro sitio, usa el bloque “Dejar de trazar”. Después puedes volver a trazar con “Empezar a trazar”.
