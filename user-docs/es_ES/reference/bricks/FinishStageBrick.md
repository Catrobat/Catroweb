Este bloque para todos los scripts y termina el escenario o la escena actual. Es como decir: “Esta parte del proyecto se acabó”. Todo se para. Después el proyecto puede pasar a otra escena o terminar del todo. Úsalo cuando quieras terminar una parte o un nivel de tu proyecto.
