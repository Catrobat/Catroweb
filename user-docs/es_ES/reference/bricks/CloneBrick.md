![Crear clon de](../../../media/bricks/create_clone_of_brick2.png)

Este bloque hace una copia del objeto que eliges. La copia se llama clon y se comporta como el original. Imagina que copias un personaje u objeto de tu juego. El clon puede tener sus propios comportamientos y scripts. Así puedes tener muchas copias de un objeto que actúan cada una por su cuenta.
