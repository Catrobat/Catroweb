![Si es verdadero, entonces / Si no](../../../media/bricks/if_else_brick2.png)

*Mira si una condición es verdadera. Si lo es, hace unas instrucciones. Si no lo es, hace otras. Es como dar dos opciones: “Si esto es verdad, haz esto; si no, haz aquello”.*

![Al iniciar la escena](../../../media/bricks/StartScene.png)

Cuando empieza la escena, la variable X se pone a 0.

![Si / Si no](../../../media/bricks/IfElse.png)

Cuando alguien toca el animal, el programa mira si X módulo 2 es verdadero, es decir, si X es un número impar.

Si es así, suena el sonido Tweet1 y la variable X sube en 1.

Si no, es decir, si X es par, solo sube X en 1.

Las instrucciones que se hacen están separadas por un “Fin del si”.
