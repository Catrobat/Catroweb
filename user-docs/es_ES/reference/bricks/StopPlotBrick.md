![Dejar de trazar](../../../media/bricks/Stop_to_plot.png)

El bloque “Dejar de trazar” para el trazado. Así puedes mover el actor a otro sitio o terminar el trazado. Es como levantar el lápiz del papel para ponerlo en otro sitio o dejar de dibujar. Cuando termines de trazar, puedes usar el bloque “Guardar trazado como SVG” para guardar tu diseño como archivo SVG.
