![Para cada valor de](../../../media/bricks/for-each-value_brick.png)

Este bloque hace unas instrucciones para cada elemento de una lista o de un rango. Es como ir mirando los elementos uno por uno y hacer lo mismo con cada uno.

Imagina que tienes una lista de números, de colores o de otras cosas. Con este bloque tomas cada elemento de la lista y haces algo con él. Por ejemplo: tienes una lista de colores y quieres poner el fondo de cada color de la lista. Para eso usas este bloque.

Es como decir: “Para cada cosa de este grupo, haz estas instrucciones”.
