![Activar la aditividad del efecto de partículas](../../../media/bricks/Turn_particle_effect_additivity_on.png)

Este bloque activa o desactiva la mezcla aditiva de las partículas. Con ella, las partículas se ven más brillantes y más fuertes. Es como cambiar el brillo y el resplandor de unas chispas.
