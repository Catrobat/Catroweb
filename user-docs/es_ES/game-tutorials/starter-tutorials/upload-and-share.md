En este tutorial aprendes a compartir tus proyectos con tus amigos o con toda la comunidad de Catrobat.

![Subir y compartir](../../../media/game-tutorials/Upload-and-Share.png)

Para este tutorial ya necesitas un proyecto propio que quieras compartir. Si todavía no sabes crear un proyecto, mira el tutorial **[Nuevo proyecto](new-project.md)**.

*Aquí puedes descargar el tutorial en PDF:*

[Subir y compartir](../../../media/game-tutorials/Upload-and-Share.pdf)

### 1. Opciones del proyecto

Si quieres subir o compartir tu proyecto, abre tu proyecto. Toca los tres puntos arriba a la derecha y después “Opciones del proyecto”.

![Subir y compartir](../../../media/game-tutorials/Upload-and-Share.png)

### 2. Opciones del proyecto

Aquí puedes cambiar el nombre, escribir una descripción y cambiar varios ajustes.

También tienes dos opciones: “Subir proyecto” y “Exportar proyecto”. Te las explicamos en los siguientes pasos.

![Subir y compartir (1)](../../../media/game-tutorials/Upload-and-Share-1.png)

### 3. Subir proyecto

Si quieres subir tu proyecto a Catrobat Share para que toda la comunidad lo vea, elige *Subir proyecto*.

### 4. Subir proyecto

Cuando tocas este botón para subir tu proyecto, necesitas una cuenta. Si todavía no tienes una, regístrate. También puedes entrar con Google. Cuando ya entraste, dale un nombre a tu proyecto y escribe una descripción. Después elige hasta tres categorías que vayan bien con tu proyecto.

Luego toca “Siguiente” para subir tu proyecto.

![Subir y compartir (2)](../../../media/game-tutorials/Upload-and-Share-2.png)

### 5. Exportar proyecto

Si quieres compartir tu proyecto con tus amigos, elige *Exportar proyecto*.

### 6. Exportar proyecto

Con este botón guardas un archivo .catrobat. Puedes enviárselo a tus amigos. Guárdalo en la carpeta de archivos de tu dispositivo y compártelo desde allí.

![Subir y compartir (3)](../../../media/game-tutorials/Upload-and-Share-3.png)

¡Lo lograste! ¡Compartiste tu primer proyecto!

Si necesitas ayuda o ideas para tus próximos proyectos, mira nuestros tutoriales de distintos niveles (principiante, medio, pro).
