### 1. Crear un objeto nuevo

Primero abre tu proyecto nuevo.

Lo encuentras en la pantalla de inicio de la app Pocket Code. Si tienes más de un proyecto, toca “Projects on device”. Después elige tu proyecto nuevo. Si todavía no creaste un proyecto o quieres saber más, mira el tutorial **[Nuevo proyecto](new-project.md)**.

### 2. Crear un objeto nuevo

Ahora puedes crear un objeto nuevo. Se abre una ventana nueva con siete opciones.

![Nuevo objeto (1)](../../../media/game-tutorials/New-Object-1.png)\
Toca el botón amarillo con el signo + abajo a la derecha.\
[Abrir imagen](../../../media/game-tutorials/New-Object-1.png)

### 3. Formas de crear un objeto

![Nuevo objeto (2)](../../../media/game-tutorials/New-Object-2.png)\
Estas son las opciones que puedes elegir.\
[Abrir imagen](../../../media/game-tutorials/New-Object-2.png)

### 4. Dibujar una imagen

Para empezar de la forma más fácil, usamos “Dibujar” y solo dibujamos un punto. Cuando tengas el punto en Pocket Paint, sal de Pocket Paint (vuelve un paso atrás).

### 5. Dar un nombre

Ahora dale un nombre a tu imagen.

### 6. Colocar el objeto

Después coloca el objeto en la pantalla. Muévelo con el dedo a la izquierda o a la derecha, hacia arriba o hacia abajo.

![Nuevo objeto (3)](../../../media/game-tutorials/New-Object-3.png)\
Guárdalo con el botón de arriba a la derecha.\
[Abrir imagen](../../../media/game-tutorials/New-Object-3.png)

### 7. ¡Lo lograste! Creaste tu propio objeto.

¡Ahora tienes un proyecto con un objeto que puedes programar!

Para eso tienes que saber qué bloques hay. El tutorial **[Primeros bloques](first-bricks.md)** te da un buen resumen de las categorías de bloques. También puedes empezar directamente con tu primer proyecto. Elige un tutorial de la serie para principiantes.
