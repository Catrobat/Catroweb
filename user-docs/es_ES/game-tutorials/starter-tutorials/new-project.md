En este tutorial aprendes todo lo que necesitas saber de Pocket Code para crear tu primer proyecto. Te mostramos paso a paso cómo descargar la app, abrirla y crear un proyecto nuevo.

![Nuevo programa](../../../media/game-tutorials/New-Program.png)

Este es el primer tutorial de todos. No necesitas saber nada antes.

¿A qué esperas? ¡Toma tu móvil y empieza ya!

*Aquí puedes descargar el tutorial en PDF:*

[Nuevo programa](../../../media/game-tutorials/New-Program.pdf)

### 1. Instalar Pocket Code

Primero instala la app Pocket Code en tu dispositivo. Busca “Pocket Code” en Google Play Store y toca “Instalar”. Para esto necesitas una cuenta de Google. Tu dispositivo descarga e instala la app. Esto puede tardar un poco, depende de tu conexión a internet.

![Nuevo programa (2)](../../../media/game-tutorials/New-Program-2.png)

Cuando Pocket Code está instalado, encuentras la app en la lista de apps o en tu pantalla de inicio. Depende de tu dispositivo. Puedes mover la app al lugar que más te guste.

### 2. Abrir la app

Cuando abres la app, ves distintas categorías:

![Nuevo programa (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Crear un proyecto nuevo

Ahora creas un proyecto nuevo. Toca el botón amarillo con el signo + abajo a la derecha. Escribe un nombre para el proyecto y elige si debe estar en horizontal o no. Toca “OK” y el proyecto está creado.

![Nuevo programa](../../../media/game-tutorials/New-Program.png)

### 4. ¡Lo lograste! Creaste tu propio proyecto.

Ya instalaste Pocket Code y sabes crear un proyecto nuevo. ¡Ahora puedes empezar a programar!

Para eso tienes que saber crear un objeto nuevo en un proyecto. Mira el tutorial **[Nuevo objeto](new-object.md)**. Allí te lo explicamos todo paso a paso.
