Cuando empieza el trazado, cada movimiento se dibuja como con un lápiz. Por estas líneas corta después el plotter.

Esta flor tiene 7 pétalos. Cada pétalo es un arco: dibujas una línea muy pequeña, giras, dibujas otra línea muy pequeña y vuelves a girar (mira el bucle “Repetir 10 veces” – “Mover 10 pasos” – “Girar a la derecha 16 grados”).

Antes de empezar el siguiente pétalo, tienes que girar una vez más.
