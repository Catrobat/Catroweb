وقتی شروع می کنید Pocket Code صفحه اصلی زیر را مشاهده می کنید.

![صفحه اصلی](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
وقتی شروع می کنید Pocket Code صفحه اصلی زیر را مشاهده می کنید.\
[تصویر را باز کن](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![کمک ها](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
در گوشه بالا سمت راست، نماد وجود دارد که شما را به اسناد Catrobat می برد، که راهنمایی های مفید برای شما دارد.

![مینو ها](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
در کنار آن، مینو است.

از آنجا، می‌توانی به راحتی به تنظیمات بروید، جایی که می‌توانی زبان را تغییر دهید یا افزونه هایی مانند بلوک های نقشه و موارد دیگر را فعال کنید.

![آیکون ها را ویرایش کنید](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
برای دسترسی به صفحه پروژه روی آیکون ویرایش کلیک کن، جایی که می‌توانی توسعه پروژه خود را ادامه دهید.

زیر، می‌توانی آخرین پروژه های ویرایش شده خود را ببینید.

![پروژه خود را شروع کنید](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
برای شروع پروژه خود از دکمه بازی استفاده کنید.

![پروژه های دستگاه](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
با کلیک کردن روی پروژه‌ها می‌توانی به پروژه های ذخیره شده خود دسترسی داشته باشید.

![Catrobat جامعه](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
اگر می خواهید پروژه های بیشتری را از کاربران دیگر بشناسید و روی آن کار کنید، فقط بر روی Catrobat جامعه در اشتراک کلیک کن.

اونجا پروژه های خیلی خوبی رو پیدا میکنی.

![اضافه کردن](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
اگر می خواهید یک پروژه جدید ایجاد کنید، روی آیکون جمع کلیک کن.
