وقتی شروع می کنید Pocket Code صفحه اصلی زیر را مشاهده می کنید.

![صفحه اصلی](../../../media/getting-started/MainScreen-e1732269599192.jpg)

در گوشه بالا سمت راست، نماد ![کمک ها](../../../media/getting-started/Screenshot-2024-11-22-111748.png) وجود دارد که شما را به اسناد Catrobat می برد، که راهنمایی های مفید برای شما دارد.

در کنار آن، مینو ![مینو ها](../../../media/getting-started/Screenshot-2024-11-22-111804.png) است. از آنجا، می‌توانی به راحتی به تنظیمات بروید، جایی که می‌توانی زبان را تغییر دهید یا افزونه هایی مانند بلوک های نقشه و موارد دیگر را فعال کنید.

زیر، می‌توانی آخرین پروژه های ویرایش شده خود را ببینید. برای دسترسی به صفحه پروژه روی آیکون ویرایش ![آیکون ها را ویرایش کنید](../../../media/getting-started/Screenshot-2024-11-22-111825.png) کلیک کن، جایی که می‌توانی توسعه پروژه خود را ادامه دهید.

برای شروع پروژه خود از دکمه بازی ![پروژه خود را شروع کنید](../../../media/getting-started/Screenshot-2024-11-22-111818.png) استفاده کنید.

با کلیک کردن روی پروژه‌ها می‌توانی به پروژه های ذخیره شده خود دسترسی داشته باشید. ![پروژه های دستگاه](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

اگر می خواهید پروژه های بیشتری را از کاربران دیگر بشناسید و روی آن کار کنید، فقط بر روی Catrobat جامعه در اشتراک کلیک کن. اونجا پروژه های خیلی خوبی رو پیدا میکنی. ![Catrobat جامعه](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

اگر می خواهید یک پروژه جدید ایجاد کنید، روی آیکون جمع کلیک کن. ![اضافه کردن](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
