Pocket Code یک برنامه نویسی بصری است که به شما اجازه می دهد بازی ها، انیمیشن ها و داستان های تعاملی را مستقیماً در موبایل هوشمند یا تبلت خود ایجاد کنید. با استفاده از یک رابط کشیدن و رها کردن بدیهی با «بلاک های کد» (بلاک‌های کود) ، می‌توانی پروژه های خود را بدون تجربه برنامه نویسی قبلی طراحی کنید. به راحتی صدا، تصاویر و حرکات را اضافه کنید تا ایده های خود را به زندگی برساند.

این راهنما به شما کمک می کند که شروع کنید با توضیح اینکه چگونه:

- روی رابط حرکت کنید
- اولین پروژه ات رو بساز
- با اشیاء و پس زمینه ها کار کنید
- برای برنامه ریزی اقدامات از بلاک‌های کود استفاده کنید و
- پروژه ات رو حفظ کن.

برای مبتدی ها و معلمان عالی است، Pocket Code خلاقیت، حل مشکلات و تفکر منطقی را تشویق می کند.
