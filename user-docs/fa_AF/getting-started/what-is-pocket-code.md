Pocket Code برنامهٔ اصلی Catrobat است. این برنامه رایگان است و کود منبع آن باز است. با آن می‌توانی در موبایل هوشمند یا تبلت خود بازی، انیمیشن و داستان تعاملی بسازی. در Pocket Code با **بلاک‌های کود** برنامه می‌سازی. بلاک‌ها را مثل تکه‌های یک پازل به هم وصل کن تا پروژه‌ات ساخته شود. برای آغاز لازم نیست از پیش برنامه‌نویسی بلد باشی!

Pocket Code فراتر از پروژه های دیجیتال است. با جدید **ویژگی های فضای سازنده** می‌توانی طراحی **SVG فایل‌های برای برش با پلاتر** را هم انجام دهید. این بدان معنی است که می‌توانی خلاقیت های دیجیتال خود را به اشیاء دنیای واقعی تبدیل کنید و امکانات خلاقانه را فراتر از سکرین کشف کنید.

چه شما در حال یادگیری کد، آزمایش با ایده های جدید یا آموزش برنامه نویسی هستید، Pocket Code یک راه باز و قابل دسترسی برای غرق شدن در کد را فراهم می کند
