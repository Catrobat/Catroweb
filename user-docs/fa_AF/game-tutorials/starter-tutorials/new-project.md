در این آموزش، همه چیز را که باید درباره Pocket Code بدانید برای شروع به ایجاد اولین پروژه خود یاد خواهید گرفت. ما به شما در مورد چگونگی دانلود اپلیکیشن، باز کردن آن و ایجاد یک پروژه جدید قدم به قدم راهنمایی خواهیم کرد.

![برنامه جدید](../../../media/game-tutorials/New-Program.png)\

[تصویر را باز کن](../../../media/game-tutorials/New-Program.png)

این اولین آموزش است و شما نیازی به هیچ دانشی قبلی ندارید.

خوب، منتظر چی هستی؟ موبایل خود را بگیرید و شروع به همین حالا!

*در اینجا می‌توانی آموزش را در PDF-فورمت دانلود کنید:*

[فایل PDF را باز کن](../../../media/game-tutorials/New-Program.pdf)

### 1. نصب Pocket Code

در ابتدا، باید اپلیکیشن Pocket Code را روی دستگاه خود نصب کنید. برای این مرحله یک حساب گوگل مورد نیاز است. حالا دستگاه شما اپلیکیشن را دانلود و نصب می کند. این مرحله ممکن است به لحاظ اتصال اینترنت شما مدتی طول بکشد.

![برنامه جدید (2)](../../../media/game-tutorials/New-Program-2.png)\
می‌توانی اپلیکیشن را با جستجوی «Pocket Code» در Google Play Store و دانلود آن با ضربه زدن به «نصب کردن» پیدا کنید.\
[تصویر را باز کن](../../../media/game-tutorials/New-Program-2.png)

بعد از اینکه به طور موفقیت آمیز دانلود و نصب Pocket Code برنامه را می‌توانی در کشش اپلیکیشن یا روی صفحه اصلی خود پیدا کنید، بسته به دستگاه شما. می‌توانی به راحتی اپلیکیشن را بردارید و آن را هر کجا که دوست دارید قرار دهید.

### 2. برنامه را شروع کنید

![برنامه جدید (1)](../../../media/game-tutorials/New-Program-1.png)\
وقتی اپلیکیشن را باز می کنید دسته های مختلف را مشاهده می کنید.\
[تصویر را باز کن](../../../media/game-tutorials/New-Program-1.png)

### 3. ایجاد یک پروژه جدید

مرحله بعدی این است که یک پروژه جدید را ایجاد کنیم. حالا باید یک نام پروژه را وارد کنید و انتخاب کن که آیا پروژه باید منظره باشد یا نه. با فشار دادن «تأیید» پروژه ایجاد می شود.

![برنامه جدید](../../../media/game-tutorials/New-Program.png)\
برای انجام این کار می‌توانی روی دکمه زرد اضافه در گوشه پایین سمت راست فشار دهید.\
[تصویر را باز کن](../../../media/game-tutorials/New-Program.png)

### 4. تو موفق شدی پروژه ی جدیدت رو ساختی.

حالا شما نصب کرده اید Pocket Code و می دانید که چگونه یک پروژه جدید ایجاد کنید. حالا میتونید برنامه ریزی کنید!

برای انجام این کار، باید بدانید که چگونه یک شی جدید را در یک پروژه ایجاد کنید. در آموزش **[مواردی جدید](new-object.md)** ، همه چیز به شما مرحله به مرحله توضیح داده می شود.
