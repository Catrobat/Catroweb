در این آموزش، یاد می‌گیری که چگونه یک شی جدید را در پروژه خود ایجاد کنید و امکانات مختلفی که برای این کار دارید.

![مواردی جدید](../../../media/game-tutorials/New-Object.png)

برای انجام این کار، باید قبلاً اپلیکیشن Pocket Code را دانلود کرده و بدانید که چگونه یک پروژه جدید ایجاد کنید. اگر به کمک در این مورد نیاز دارید، از نظر آزادانه در آموزش **[پروژه جدید](new-project.md)** مراجعه کنید.

*در اینجا می‌توانی آموزش را در PDF-فورمت دانلود کنید:*

[مواردی جدید](../../../media/game-tutorials/New-Object.pdf)

### 1. یک شی جدید ایجاد کنید

اول، باید پروژه جدید خود را باز کن.

شما آن را در صفحه اصلی اپلیکیشن Pocket Code پیدا خواهید کرد. اگر بیش از یک پروژه دارید، می‌توانی روی «پروژه‌ها» کلیک کن. پس پروژه جدیدت رو انتخاب کن. اگر پروژه جدیدی ایجاد نکرده اید یا به اطلاعات بیشتری در مورد چگونگی انجام آن نیاز دارید، نگاهی به آموزش **[پروژه جدید](new-project.md)** بیندازید.

### 2. یک شی جدید ایجاد کنید

حالا شما آماده ای برای ایجاد یک شی جدید هستید. برای انجام این کار فقط روی دکمه زرد جمع در گوشه پایین سمت راست کلیک کن. شما یک پنجره جدید را خواهی دید که به شما هفت گزینه برای انتخاب می دهد.

![مواردی جدید (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. راه های ایجاد

این ها گزینه هایی هستند که می‌توانی از بین آنها انتخاب کن:

![مواردی جدید (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. تصویر را رسم کنید

برای ساده تر کردن شروع، می خواهیم از تابع «نقاشی» استفاده کنیم و فقط یک نقطه را بکشیم. وقتی نقطه را با Pocket Paint کشیده اید می‌توانی آن را ترک کنید (به یک قدم عقب رفتن).

### 5. اسمش رو بزنی

حالا باید به عکستون یه اسم بدید.

### 6. قرار دادن آن را

بعد از آن باید با دست خود به سمت چپ/حق یا بالا/ پایین حرکت کنید. باید با دکمه سمت راست بالا آن را ذخیره کنید.

![مواردی جدید (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. تو موفق شدی، تو یه جسم جدید خودت رو پیدا کردی.

حالا شما یک پروژه با یک شی دارید که می‌توانی برنامه ریزی کنید!

برای انجام این کار باید بدانید که چه بلاک کود هایی در دسترس است. آموزش **[اولین بلاک‌های کود](first-bricks.md)** به شما یک مرور کلی خوب از دسته های مختلف بلاک‌های کود می دهد. با این حال، می‌توانی مستقیماً از پروژه اول خود شروع کنید. یک آموزش مناسب از مجموعه مبتدی را انتخاب کن.
