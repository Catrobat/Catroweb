یک نظر یا یادداشت را در اسکریپت شما اضافه می کند تا به شما کمک کند که به یاد داشته باشید قسمت های کد شما چه کار می کنند. این روی چگونگی اجرای پروژه شما تاثیر نمی گذارد. مثل اینکه یه یادداشت پیچک رو برای خودت بذاری.
