*بررسی می کند که آیا یک شرط درست است و اگر اینطور است، مجموعه ای از دستورالعمل ها را اجرا می کند. این مثل گفتن «اگه این درست باشه، پس اینو بکن.»*

![شروع سکانس](../../../media/bricks/StartScene.png)

وقتی صحنه شروع می شود، متغیر X به 0 تنظیم می شود.

![اگر](../../../media/bricks/If.png)

اگر حیوان حالا ضربه خورده باشد، متغیر X با 1 افزایش می یابد.

برنامه بررسی می کند که آیا متغیر X برابر با ارزش 2 است یا خیر.

اگر این مورد باشد، صدا Tweet1 پخش می شود و متغیر X به 0 تنظیم می شود.
