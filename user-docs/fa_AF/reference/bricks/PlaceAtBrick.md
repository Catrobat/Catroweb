اشیا را به موقعیت مشخصی در سکرین منتقل می کند که توسط مختصات x و y تعریف شده است. مثل انتقال شخصیت به یک نقطه دقیق.

موقعیت در یک سیستم هماهنگی مانند خط کارتزیو تنظیم شده است: محور های x و y از طریق مرکز سکرین حرکت می کنند، بنابراین x = 0 و y = 0 وسط سکرین است.
