![رسم با پلاتر را متوقف کن](../../../media/bricks/Stop_to_plot.png)

بلاک کود «رسم با پلاتر را متوقف کن» پروسه رسم با پلاتر را متوقف می کند و به شما اجازه می دهد تا بازیگر را به موقعیت جدیدی منتقل کنید یا رسم با پلاتر را تمام کنید. مثل اونه که قلم رو از کاغذ بلند کنی تا دوباره جایگاهش بگیری یا دیگه رسم نکن. بعد از اینکه رسم با پلاتر را تمام کردید، می‌توانی از بلاک کود «طرح را به‌صورت SVG ذخیره کن با نام» برای ذخیره طراحی خود به عنوان یک فایل SVG استفاده کنید.
