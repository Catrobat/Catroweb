![وقتی به‌عنوان کلون شروع شدی](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

هدایت یک کلون ایجاد شده از یک شی با دستورالعمل برای انجام اقدامات مورد نیاز. این پروسه اجازه می دهد تا قابلیت های موجودی اصلی را تکرار کند، در حالی که کلون را به طور مستقل کنترل می کند. رفتارهای مختلف یا خواص اجسام کلون می توانند برای برآورده کردن الزامات خاص مشخص شوند.
