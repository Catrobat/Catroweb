![این کلون را حذف کن](../../../media/bricks/delete_clone_brick2.png)

این بلاک کود کلون را که با بلاک کود «کلون بساز از» ایجاد شده است حذف می کند. مثل گفتن «این دوپلاژ رو حذف کن.» این را برای مدیریت و کنترل تعداد کلون ها در پروژه خود استفاده کنید، اطمینان حاصل کنید که وقتی دیگر مورد نیاز نیستند حذف می شوند.
