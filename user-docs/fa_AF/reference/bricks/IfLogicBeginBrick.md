![اگر غیر از این کد بلاک شود](../../../media/bricks/if_else_brick2.png)

*بررسی می کند که آیا یک شرط درست است و یک مجموعه دستورالعمل ها را اجرا می کند اگر درست است و یک مجموعه دیگر اگر درست نیست. این مانند دادن دو گزینه است: «اگر این درست است، این کار را انجام دهید؛ اگر نه، آن کار را انجام دهید.»*

![شروع سکانس](../../../media/bricks/StartScene.png)

وقتی صحنه شروع می شود، متغیر X به 0 تنظیم می شود.

![اگر غیر از این](../../../media/bricks/IfElse.png)

اگر حیوان را حالا لمس کنید، چک برای دیدن اینکه آیا X modulo 2 درست است، یعنی اگر X یک عدد عجیب است انجام می شود.

در این صورت، صدا Tweet1 پخش می شود و متغیر X با 1 افزایش می یابد.

در غیر اینصورت، اگر X برابر باشد، تنها X با 1 افزایش می یابد.

اظهارات که باید اجرا شود با یک پایان اگر جدا شده است.
