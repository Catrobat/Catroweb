![صدا را متوقف کن](../../../media/bricks/Stop_sound_record.png)

این بلاک کود یک صدا خاص را از پخش متوقف می کند. مثل اینکه فقط یک آهنگ را برای توقف بزنید در حالیکه صداها یا موسیقی های دیگر همچنان پخش می شوند. تصور کنید که به شخصیت خود می گویید تا از یک آهنگ خاص استفاده نکنند.
