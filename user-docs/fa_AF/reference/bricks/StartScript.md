اگه از این بلوک استفاده کنی، اسکریپ بلافاصله وقتی صحنه شروع میشه شروع می شه. صحنه شروع برنامه شماه. یک صحنه یک نمای جدید در برنامه شما است که در آن عناصر دیگر می توانند نمایش داده شوند و تعاملات مختلف ممکن است رخ دهد. می‌توانی صحنه های زیادی برای مراحل مختلف برنامه خود داشته باشید. مثلا یک صحنه برای معرفی، یک صحنه برای مینو اصلی، یک صحنه برای سطح اول، یک صحنه برای سطح دوم و غیره. با برنامه های ساده تر، یک صحنه هم می تواند کافی باشد، پس شروع برنامه شما نیز آغاز صحنه است.

مانند هر اسکریپت، این یکی با یک بلاک کود رویداد آغاز می شود: رویداد تعریف می کند **زمانیکه** اسکریپت شروع می شود، کد بعد از اینکه به برنامه **چی شده** بگوید انجام دهد، بلاک می شود.
