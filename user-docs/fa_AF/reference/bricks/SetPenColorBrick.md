![رنگ قلم را بگذار برابر o قرمز 0 سبز 0 آبی 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

این بلاک کود رنگ قلمی را که توسط بازیگر استفاده می شود تغییر می دهد. مثل تغییر رنگ به قلم مختلف در حالیکه نقاشی می کنید.

**سرخ، سبز، آبی (RGB)**: مدل رنگ RGB از شدت های مختلف نور قرمز، سبز و آبی برای ایجاد طیف گسترده ای از رنگ ها استفاده می کند. هر عنصر رنگی (خمرا، سبز و آبی) می تواند دارای یک مقدار بین 0 تا 255 باشد:

- **سرخ ها**: بخش قرمز رنگ. ارزش بالاتر به معنی قرمز بیشتر است.
- **سبز ها**: بخش سبز رنگ. ارزش بالاتر به معنی سبز تر است.
- **آبی ها**: بخش آبی رنگ. ارزش بالاتر به معنی آبی بیشتر است.

با ترکیب ارزش های مختلف برای قرمز، سبز و آبی، می‌توانی هر رنگ را ایجاد کنید. به عنوان مثال:

- `RGB(255, 0, 0)` خالص قرمز است.
- `RGB(0, 255, 0)` سبز خالص است.
- `RGB(0, 0, 255)` آبی خالص است.
- `RGB(255, 255, 255)` سفید است (زیاترین حد قرمز، سبز و آبی).
- `RGB(0, 0, 0)` سیاه (هیچ رنگ) است.

ترکیب این رنگ ها در مقدار های مختلف تمام رنگ هایی را که روی صفحه های دیجیتال می بینید ایجاد می کند.
