![نختممل](../../../media/embroidery-tutorials/Nachthimmel.png)

باید قبلاً بدانید که یک حلقه چیست و چگونه کار می کند.

آموزش **[ستاره ها](../embroidery-tutorials-beginner/star.md)** ممکن است برای این آموزش مفید باشد.

اگر شما قبلاً با عملکرد پخش آشنا هستید، هم مفید است.

اگر هنوز چیزی را نخوردید، آموزش های گلدوزی در سری [شروع کننده ها](../embroidery-tutorials-beginner/index.md) را ببینید.

برای اطلاعات بیشتر یا پیشنهادات طراحی در سایر آموزش ها مراجعه کنید.
