Pocket Code Catrobat-ın əsas tətbiqidir. O, pulsuzdur və açıq mənbəlidir. Telefonunda və ya planşetində oyunlar, animasiyalar və interaktiv hekayələr hazırlaya bilərsən. Pocket Code-un **blok əsaslı kodlaşdırma sistemi** var. Kod bloklarını bir tapmacanın parçaları kimi birləşdirib layihələr yarada bilərsən. Əvvəlcədən kod yazmağı bilməyinə ehtiyac yoxdur. Yeni başlayanlar üçün çox əlverişlidir!

Pocket Code yalnız rəqəmsal layihələrdən kənarda gedir. Yeni **makerspace xüsusiyyətləri** ilə sən də dizayn edə bilərsən **SVG kəsici planterlər üçün sənədlər**. Bu o deməkdir ki, sən rəqəmsal yaradıcılıqlarınızı real dünya əşyalarına çevirə və ekrandan kənarda yaradıcı imkanları araşdırırsınız.

Kodlaşdırmağı öyrənirsinizsə, yeni fikirlərlə təcrübə edirsinizsə və ya proqramlaşdırma öyrədirsinizsə Pocket Code kodlama ilə məşğul olmaq üçün əyləncəli və əlçatan bir yol təqdim edir
