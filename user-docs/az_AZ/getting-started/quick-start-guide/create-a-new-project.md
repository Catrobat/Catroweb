Tətbiqi telefonunda və ya planşetində aç.

![Baş ekran Yeni layihə](../../../media/getting-started/MainScreen_NewProject.png)\
Yeni layihə yaratmaq üçün + işarəsinə toxun.\
[Şəkli aç](../../../media/getting-started/MainScreen_NewProject.png)

Layihənə ad ver (1). Oyunun ekranını şaquli (portret) və ya üfüqi (landşaft) seç (2).

![Yeni layihə](../../../media/getting-started/NewProject.png)\
Sonra təsdiq işarəsinə toxun (3).\
[Şəkli aç](../../../media/getting-started/NewProject.png)

İndi layihənizdədir. Yuxarıda oyunun adını görürsən.

Aşağıda **Arxa fon** - hazırda, arxa planı boşdur görə bilərsiniz. Əgər dəyişmək istəyirsənsə, bas.

Arxa planda oyununuza əlavə etdiyiniz **aktyorlar və obyektlər** sahəni görürsünüz. Hal-hazırda sahə hələ də boşdur.

Aşağı sağda iki vacib düyməni görürsünüz:

![Başlayın](../../../media/getting-started/Start.png)\
**Başla** düyməsini istifadə edərək oyununa başlayın.

![Əlavə Button](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
**Üstəlik** düyməsi ilə oyununuza yeni bir xarakter / obyekt əlavə edirsiniz.

![Layihə Ekranı](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
İndi layihənizdədir.\
[Şəkli aç](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
