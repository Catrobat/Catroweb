Pocket Code bir video proqramlaşdırma tətbiqidir ki, sənə birbaşa smartfonunuz və ya planşetinizlə oyunlar, animasiyalar və interaktiv hekayələr yaratmağa imkan verir. «kod blokları» (kod blokları) ilə intuitiv sürükləmə və buraxma interfeysindən istifadə edərək, əvvəlki proqramlaşdırma təcrübəsi olmadan layihələrinizi hazırlaya bilərsiniz. Fikirlərinizi həyata keçirmək üçün asanlıqla səs, şəkil və hərəkət əlavə edin.

Bu təlimat sənə aşağıdakıları izah edərək kömək edəcək:

- Araşdırma interfeysini idarə edin
- İlk layihənizi yaratın
- obyektlər və arxa planlarla işləmək,
- Proqramlaşdırma hərəkətləri üçün kod bloklarından istifadə edin və
- Layihənizi qoruyun.

Yeni başlayanlar və müəllimlər üçün mükəmməl Pocket Code yaradıcılığı, problemlərin həllini və məntiqi düşüncəni təşviq edir.
