Bu dərslikdə ilk layihənizi yaratmaq üçün bilməli olduğunuz hər şeyi öyrənəcəksiniz Pocket Code. Biz sənə tətbiqi necə yükləyəcəyinizi, açdığınızı və yeni bir layihə yaratdığınızı addım-addım göstərəcəyik.

Bu, ilk dərsdir və əvvəlki biliklərə ehtiyac yoxdur.

Bəs nə gözləyirsən? Telefonunu götür və indi başla!

[PDF-i aç](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code quraşdırılması

İlk olaraq cihazınıza Pocket Code tətbiqini quraşdırmalısınız. Bu addım üçün Google hesabı tələb olunur. İndi cihazınız tətbiqi yükləyəcək və quraşdırır. Bu addım internet bağlantınıza görə bir müddət çəkə bilər.

![Yeni proqram (2)](../../../media/game-tutorials/New-Program-2.png)\
Tətbiq axtarış yolu ilə tapıla bilər «Pocket Code» İndiki Google Play Store və vuraraq yüklə «yükləmək».\
[Şəkli aç](../../../media/game-tutorials/New-Program-2.png)

İndirmə və quraşdırma uğurla baş tutduqdan sonra Pocket Code tətbiqi cihazınıza görə tətbiq çekicisində və ya ev ekranınızda tapa bilərsiniz. Tətbiqi asanlıqla götürüb istədiyiniz yerə yerləşdirə bilərsiniz.

### 2. Əlavə tətbiq başlat

![Yeni proqram (1)](../../../media/game-tutorials/New-Program-1.png)\
Tətbiq açıldıqda müxtəlif kateqoriyalar görünür.\
[Şəkli aç](../../../media/game-tutorials/New-Program-1.png)

### 3. Yeni bir layihə yaratın

Növbəti addım yeni bir layihə yaratmaqdır. İndi layihənin adını daxil edin və layihənizin mənzərəli olması və ya olmaması barədə seç. «Oldu» basaraq layihə yaradılır.

![Yeni proqram](../../../media/game-tutorials/New-Program.png)\
Bunu etmək üçün sağ alt küncdəki sarı plus düyməsini basın.\
[Şəkli aç](../../../media/game-tutorials/New-Program.png)

### 4. Öz yeni layihənizi yaratdın.

İndi sən quraşdırdığınız Pocket Code və yeni bir layihə yaratmağı bilirsiniz. İndi proqramlaşdırmağa başlaya bilərsiniz!

Bunu etmək üçün layihədə yeni bir obyekt yaratmağı bilməlisiniz. Hər şey sənə addım-addım izah edilən **[Yeni obyekt](new-object.md)** -tədrisini nəzərdən keçirin.
