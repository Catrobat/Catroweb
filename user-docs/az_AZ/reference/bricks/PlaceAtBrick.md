![Yerləş:](../../../media/bricks/place_at_x_y_brick.png)

Objetin x və y koordinatları ilə müəyyən edilmiş ekranda müəyyən bir yerə köçürülür. Bu, xarakterinizi tam bir yerə teleport etmək kimi.

Poziciyası Kartesian düzlüyünə bənzər koordinat sistemində müəyyən edilir: x və y oxu ekrandanın mərkəzində keçir, belə ki x = 0 və y = 0 ekrinin ortasıdır.
