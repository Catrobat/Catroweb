![Qələmin rəngini təyin et: o qırmızı 0 yaşıl 0 mavi 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Bu kod bloku aktyorun istifadə etdiyi qələm rəngini dəyişir. Bu, rəsm çəkərkən fərqli rəngli qələməyə keçmək kimi bir şeydir.

**Qırmızı, Yaşıl, Mavi (RGB)**: RGB rəng modeli geniş bir rəng spektrini yaratmaq üçün müxtəlif qırmızı, yaşıl və mavi işıq intensivliklərindən istifadə edir. Hər rəng komponentinin (qırmızı, yaşıl və mavi) 0 ilə 255 arasında bir dəyəri ola bilər:

- **Qırmızı**: Rəngin qırmızı tərkib hissəsi. Daha yüksək qiymət daha çox qırmızı deməkdir.
- **Yaşıl**: Rəngin yaşıl tərkib hissəsi. Daha yüksək qiymət daha yaşıl deməkdir.
- **Mavi**: Rəngin mavi komponentini. Daha yüksək qiymət daha mavi deməkdir.

Qırmızı, yaşıl və mavi üçün müxtəlif qiymətləri birləşdirərək hər hansı bir rəng yarada bilərsən. Məsələn:

- `RGB(255, 0, 0)` saf qırmızıdır.
- `RGB(0, 255, 0)` saf yaşıldır.
- `RGB(0, 0, 255)` saf mavi.
- `RGB(255, 255, 255)` ağdır (maksimum qırmızı, yaşıl və mavi).
- `RGB(0, 0, 0)` qara rəngdə (rəng yoxdur).

Bu rəngləri müxtəlif miqdarda qarışdırmaq rəqəmsal ekranlarda gördüyünüz bütün rəngləri yaradır.
