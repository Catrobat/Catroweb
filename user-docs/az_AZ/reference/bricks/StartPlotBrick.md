![Çertyoj çəkməyə başla](../../../media/bricks/Start_to_plot.png)

Bu kod bloku aktyor hərəkət edərkən planlaşdırma prosesini başlayır. Bu, bir xətt çəkməyə başlamaq üçün qələmi kağız üzərində qoymaqla oxşardır. Çizimi dayandırmaq və aktyoru başqa bir yerə köçürmək istəyirsənsə, «Çertyoj çəkməyi dayandır» kod blokundan istifadə edə bilərsən və sonra yenidən planı «Çertyoj çəkməyə başla» ilə başlaya bilərsiniz.
