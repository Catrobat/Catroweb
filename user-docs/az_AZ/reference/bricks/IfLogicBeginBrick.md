*Bir şərtin doğru olub olmadığını yoxlayır və əgər doğru deyilsə, bir sıra təlimatları işlədirir: «Əgər bu doğru deyilsə, bunu edin; əks halda, onu edin.»*

![Epizodu başlat:](../../../media/bricks/StartScene.png)

Səhnə başlayanda dəyişən X 0-a təyin olunur.

![Əgər başqa](../../../media/bricks/IfElse.png)

Əgər heyvan indi vurulursa, X modulo 2 doğru olub olmadığını yoxlamaq üçün yoxlanılır, yəni X nadir bir rəqəmdir.

Bu halda səs Tweet1 oynanılır və dəyişən X 1 ilə artırılır.

Əks halda, əgər X düzdürsə, yalnız X 1 ilə artırılır.

Təsvir ediləcək ifadələr Şərtin sonu ilə ayrılır.
