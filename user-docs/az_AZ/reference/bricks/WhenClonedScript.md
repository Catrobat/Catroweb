![Klon kimi başlayanda](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

İstənilən hərəkətləri yerinə yetirmək üçün təlimatlar ilə obyektin yaradılmış klonunu yönləndirmək. Bu proses, klonu müstəqil olaraq idarə edərkən orijinal obyektin funksiyasını təkrarlamağa imkan verir. Klon obyektinin müxtəlif davranışları və ya xüsusiyyətləri müəyyən tələblərə cavab vermək üçün təyin edilə bilər.
