Əhvalat başlayanda hər hərəkət qələmlə çəkilmiş kimi çəkilir. Bu xəttlər daha sonra komplotçunun kəsdiyi bir cəhətdir.

Bu tilki yalnız düz xətlərdən («Hərəkət et: \_\_\_ addım») və dönmələrdən ibarətdir.

**Dərs**: Proqramı qurarkən yoxlayın.
