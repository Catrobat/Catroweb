Objektua pantailan kokapen jakin batera mugitzen da, x eta y koordenatuek definituta. Zure pertsonaia leku zehatzara teleportatzea bezala da.

Postua koordinatu sisteman kokatzen da, plano kartesiarraren antzera: x eta y ardatzak pantailako erdian zehar doaz, beraz x = 0 eta y = 0 pantailako erdian daude.
