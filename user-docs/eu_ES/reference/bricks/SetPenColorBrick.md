![Ezarri arkatzaren kolorea: O gorria 0 berdea 0 urdina 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Kode bloke honek aktoreak erabiltzen duen boligrafoaren kolorea aldatzen du. Marrazten ari zarenean kolore desberdineko boligrafo batera pasatzea bezala da.

**Gorria, berdea eta urdina (RGB)**: Kolore-ereduak RGB argi gorri, berdea eta urdina indargarritasun desberdinekin erabiltzen du kolore espektro zabala sortzeko. Kolore osagai bakoitzak (gorria, berdea eta urdina) 0 eta 255 arteko balioa izan dezake:

- **Gorria**: Kolorearen osagai gorria. Balio handiagoa gorriagoa da.
- **Berdea**: Kolorearen osagai berdea. Balio handiagoa berdeagoa da.
- **Urdina**: Kolorearen osagai urdina. Balio handiagoak urdinagoa esan nahi du.

Gorria, berdea eta urdina konbinatuz edozein kolore sor daiteke. Adibidez:

- `RGB(255, 0, 0)` gorria da.
- `RGB(0, 255, 0)` berde garbia da.
- `RGB(0, 0, 255)` urdina da.
- `RGB(255, 255, 255)` zuria da (gorria, berdea eta urdina gehienez).
- `RGB(0, 0, 0)` beltza da (kolorarik gabe).

Kolore horiek kopuru ezberdinetan nahastuz, pantaila digital batean ikusten diren kolore guztiak sortzen dira.
