![Hasi trazatzen](../../../media/bricks/Start_to_plot.png)

Kode bloke honek eragileak mugitzen diren bitartean hasten du konspirazio prozesua. Linea bat marrazten hasteko, luma paperean jartzea bezalakoa da. Erabili «Gelditu trazatzea» kode blokea marrazkia geldiarazi nahi baduzu eta aktorea leku desberdin batera mugitu, eta ondoren berriro hasi plotekin «Hasi trazatzen».
