![Jarraitu eszena honekin:](../../../media/bricks/continue_scene_brick2.png)

Kodea blokeatuz, eszenaren kokapena berreskuratzen da. Zure eszena geldialdi batek eteten bazaitu edo itxaron, kode bloke hau erabiliz ekintza bertan hasiko da.

Imajinatu joko bat edo animazio bat geldiarazi duzula eta orain jarraitzea nahi duzula. Kode bloke hau «Abiarazi» botoia bezala jarduten da, dena jarrai dezan geldiarazi zenetik.
