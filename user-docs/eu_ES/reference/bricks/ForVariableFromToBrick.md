!["for-values" kodeko bloke batetik](../../../media/bricks/for-values-from-brick.png)

Kode bloke honek zenbait aldiz martxan jartzen ditu agindu multzo bat, balio batean hasten den kontadore batekin eta bestean amaitzen dena. Zirkuitu bat sortzea bezala da, zehazki zenbat aldiz nahi duzun martxan jarri.

Imajinatu zerrenda bat duzula eta gauza bakoitzarekin zerbait egin nahi duzula. Bloke honek gauza bakoitza banan-banan aztertzen uzten dizu, eta gauza bera egiten diezu bakoitzari.
