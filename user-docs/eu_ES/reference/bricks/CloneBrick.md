Kode bloke honek objektu zehaztutakoaren kopia egiten du, klona deitzen dena, eta jatorrizkoaren antzekoa da. Imajinatu zure jokoan pertsonaia edo objektu bat kopiatzen ari zarela. Klonak bere portaera eta gidoia izan ditzake, objektu baten instantzia anitzak sortzeko aukera ematen dizkizuna.
