![Gelditu trazatzea](../../../media/bricks/Stop_to_plot.png)

«Gelditu trazatzea» kode blokeak eten egiten du grabazioa eta aktorea posizio berri batera mugitzen uzten dizu edo grabazioa amaitzen. Paperean boligrafoa altxatzea bezala da, berriro kokatzea edo marraztea uztea. Plotatu ondoren, kode blokea erabil dezakezu «Gorde trazatua SVG gisa» diseinua artxibo gisa gordetzeko SVG.
