Tutorial honetan, ikasiko duzu nola bordatu ortzadarra (112 x 57,2 mm).

![Regenbogen](../../../media/embroidery-tutorials/Regenbogen.webp)

Jakin beharko zenuke zer den buelta bat eta nola funtzionatzen duen.

**[Zirkulu erdia](../embroidery-tutorials-beginner/semicircle.md)** tutoriala lagungarria izan daiteke.

Begiratu sorta honetako bordatu-tutorialak [Hasiberriak](../embroidery-tutorials-beginner/index.md) oraindik ez baduzu bordatu.

Informazio gehiago edo diseinu-aholkuak beste tutorialetan ikus daitezke.

*Hemen, tutoriala deskarga dezakezu PDF formatua*:

[Arkua](../../../media/embroidery-tutorials/Rainbow.pdf)

![Arkua](../../../media/embroidery-tutorials/Rainbow.png)

### 2. Jarri eskritura hau:

![Arkua (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. Kopia egin objektuari

Hurrengo arku handiagoa egiteko, sortu berri duzun objektuaren kopia egin dezakezu.

Sakatu objektuaren ikuspegi orokorrean goiko eskuineko txokoan dauden hiru puntuetan.

Gero «Kopiatu» eta objektu hautatu.

![Regenbogen (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Arku bakoitzeko objektu berezia erabiliz gero, kolore ezberdinetan bordatu ditzakezu.

### 4. Objektuari egokitu

Arkuak tamaina desberdinetan daudela ziurtatzeko, zenbait balio aldatu behar ditugu.

Horretarako, joan kopiatutako objektuaren gidoia eta egokitu ondorengo balioak:

![Arkua (2)](../../../media/embroidery-tutorials/Rainbow-2.png)
