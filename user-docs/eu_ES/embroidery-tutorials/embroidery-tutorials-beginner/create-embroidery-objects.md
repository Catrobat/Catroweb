Tutorial honetan, objektuak nola sortzen diren ikasiko duzu.

Tutorial honetarako, proiektu bat nola sortu jakin beharko zenuke. Begiratu tutorialak [Hasierako seriea](../../game-tutorials/starter-tutorials/index.md)Laguntza behar baduzu.

Informazio gehiago edo diseinuaren gomendioak nahi badituzu, begiratu beste tutorialei.

*Hemen, tutoriala deskarga dezakezu PDF formatua*:

[Sortu ehungintza objektuak](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Sakatu zure proiektuaren beheko eskuineko aldean dagoen botoia eta objektu berria gehitu.

![Sortu ehungintza objektuak](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Irudi bat aukeratzeko, joan komunikabideen liburutegira.

![Larrua jotzeko objektuak egin (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Brodura-objektu batek brodura-makinen orratz maila bat irudikatzen du.

Zure objektuak nahi duzun kolorearen arabera aukeratu ditzakezu.

Desbideratu eta bilatu gezia.

![Jantzi objektuak (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Eman zure objektu berriari izen egokia eta sakatu Ados.

![Hortz-arotzeko objektuak egin (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Objektu berria sortu duzu eta orain gidoia gehitu eta programa dezakezu.

![Larrua jotzeko objektuak sortu (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Orain badakizu nola sortu objektu bat. Erabili nahi duzun kolore bakoitzeko objektu berri bat gehitu.

Kolore bakoitzean idazlana gehitu eta zure diseinuak programatu ditzakezu, baita geroago bordatu ere.

Inspirazio edo laguntza behar duzu? Begiratu gure beste tutorialak!
