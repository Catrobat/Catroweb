Tutorial honetan, liluragarri bat (54,7 x 54,8 mm) bordatzen ikasiko duzu.

![irudia (9)](../../../media/embroidery-tutorials/image-9.png)

Jakin beharko zenuke nola sortu objektu berri bat eta bertan kode blokeak sartu. Ez kezkatu [Hasierako seriea](../../game-tutorials/starter-tutorials/index.md) atalean dagoen tutoriala ikusita, oraindik laguntza behar baduzu. Gainera, bordatzeko kode-blokeak aktibatu behar dira. Hau nola egin jakin dezakezu **[Jarri aktibatzen Embroidery-kodeak](activate-embroidery-bricks.md)** -tutorial-an.

Informazio gehiago edo diseinu-aholkuak beste tutorialetan ikus daitezke.

[-Lolipoak](../../../media/embroidery-tutorials/Lollipop.pdf)
