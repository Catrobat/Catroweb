Makinak luzera aldakorra duen makina bat josten uzten du.

Normalean, josteko puntuak mugimendu-kodea duen blokearekin konbinatzen dira.

![Hasi josteko luzera 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Makinak josteko martxan jarri zuen **10 urrats**.

Gero, makina mugitzen da **200 urrats**.

Horrek **20 josturak** emaitza du.

![Hasi puntada zuzena, luzera:](../../../../media/embroidery-tutorials/RunningStitch.png)

Jarraitzen duen josturak errazagoa egiten du jostuna josteko, ez baituzu gehiago buztanik behar.
