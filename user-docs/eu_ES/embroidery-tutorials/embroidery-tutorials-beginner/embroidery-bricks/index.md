Tutorial honetan, Embroidery-kodeen blokeei buruz jakin beharreko guztia ikasiko duzu!

Ez duzu programatzeko ezagutzarik behar.

Broderiako kode-bloke bakoitza adibide batekin azalduko da.

Oraindik ez baduzu aktibatzen Embroidery-kode blokeak, begiratu **[Jarri aktibatzen Embroidery-kodeak](../activate-embroidery-bricks.md)** -tutorial.

*Hemen, tutoriala deskarga dezakezu PDF formatua*:

["Barkatu"](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Sakatu kode bloke desberdinetan horietaz gehiago jakiteko:**

[![Egin puntada](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*Utzi makinak oihalera sartzen!*

[![Hasi josteko luzera 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*Makinak luzera aldakorra duen makina bat josten uzten du.*

[![Hasten zig-zag josturak luzera 2 eta zabalera 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Luzera eta zabalera aldagaiekin josiko da.*

[![Hiru puntuak josi behar dira 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*Hirukoitza hiru aldiz josten da.*

[![Gelditu uneko puntada](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Utzi korrontea gelditzen.*

Horri buruzko informazio gehiago eta Embroidery-kodeen blokeak [Hemen dago](../../../../reference/#category_embroidery) aurkituko dituzu.

Informazio gehiago edo diseinu-aholkuak beste tutorialetan!
