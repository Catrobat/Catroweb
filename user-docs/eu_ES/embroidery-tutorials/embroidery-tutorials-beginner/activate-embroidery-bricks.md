Tutorial honetan, Broderia kode blokeak aktibatzea azalduko da.

![-Saiatu BrodurakoBricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Ez duzu programatzeko ezagutzarik behar. Hau da hasierako urratsa bordura-tutorialekin. Gero, zure diseinuak diseinatu, programatu eta zure gustukoeneko ehungintzazko pieza batean bordatu dezakezu.

Informazio gehiago edo diseinu-aholkuak beste tutorialetan ikus daitezke.

*Hemen, tutoriala deskarga dezakezu PDF formatua*:

[Jarri martxan bordadura](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

[![-Saiatu BrodurakoBricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Orain, beste kode blokeen artean aurkituko dituzu bordatu-kodeko bloke guztiak.

Kode bloke bakoitzaren inguruko informazio gehiago eskuratzeko, begiratu kode blokeetako dokumentazioa [Hemen dago](../../../reference/) edo jarraitu **["Barkatu"](embroidery-bricks/index.md)** -tutorial hori.

Orain hasi eta zure diseinuak egin ditzakezu!

Ideiak edo laguntza behar baduzu, begiratu beste tutorialei edo jarraitu **[Sortu ehungintza objektuak](create-embroidery-objects.md)** -tutorialarekin.
