Ireki aplikazioa zure smartphone edo tabletan.

![Pantaila nagusia Proiektu berria](../../../media/getting-started/MainScreen_NewProject.png)\
Sakatu + ikurra proiektu berri bat sortzeko.\
[Ireki irudia](../../../media/getting-started/MainScreen_NewProject.png)

Jarri izena proiektuari (1). Aukeratu jokorako formatu bertikala (erretratua) edo horizontala (paisaia) (2).

![Proiektu berria](../../../media/getting-started/NewProject.png)\
Ondoren, berretsi hautamarka sakatuta (3).\
[Ireki irudia](../../../media/getting-started/NewProject.png)

Zure proiektuaren ikuspegia duzu orain. Goiko aldean, zure jokoaren izena ikusten da.

Honen azpian **Atzeko planoa** ikus dezakezu - momentuz, atzeko planoak hutsik dago. Aldatu nahi baduzu, sakatu.

Atzean, zure **Aktoreak eta objektuak** jokoan gehitu duzun eremua ikusten da. Gaur egun, eremua hutsik dago.

Beheko eskuinean, bi botoi garrantzitsu ikusten dira:

![Hasiera](../../../media/getting-started/Start.png)\
- Zer **Abiarazi** Botoia, hasi zure jokoa.

![Eta botoia ere bai](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
- Zer **Gainera** Botoia, pertsonaia/objektu berria gehitzen duzu zure jokoan.
