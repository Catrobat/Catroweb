Pocket Code programazio ikusizko aplikazioa da, jokoak, animazioak eta istorio interaktiboak zuzenean zure smartphone edo tableta-n sortzeko aukera ematen dizun. «Kodea blokeatzen» (kode blokeak) interfaze intuiziozko bat erabiliz, zure proiektuak diseinatu ahal izango dituzu aurreko programazio esperientziarik gabe. Soinuak, irudiak eta mugimenduak gehitu erraz zure ideiak bizirauteko.

Gidari honek honako hauek azaltzen ditu:

- Navigatu interfazean
- Zure lehen proiektua sortu,
- Objektu eta atzeko planoekin lan egitea
- Kode blokeak erabili ekintzak programatzeko, eta
- Gorde zure proiektua.

Hasiberri eta hezitzaileentzat perfektua, Pocket Code sormena, arazoak konpontzea eta pentsamendu logikoa bultzatzen ditu.
