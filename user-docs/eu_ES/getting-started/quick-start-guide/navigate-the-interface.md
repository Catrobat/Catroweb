Hasieran Pocket Code pantaila nagusia ikusten da.

![Pantaila nagusia](../../../media/getting-started/MainScreen-e1732269599192.jpg)

Eskuineko goiko txokorrean, ![Laguntza](../../../media/getting-started/Screenshot-2024-11-22-111748.png) Sinboloak eramango zaitu Catrobat Dokumentazioa, aholku onak dituena.

Horren ondoan dago menua ![Menu bat](../../../media/getting-started/Screenshot-2024-11-22-111804.png). Hortik, erraz joan zaitezke ezarpenetara, non hizkuntza alda dezakezun edo luzapenak aktibatu ditzakezu, hala nola plot blokeak eta gehiago.

Azpian, zure azkenengo egitasmoa ikus dezakezu. Sakatu ![Editatu ikonoa](../../../media/getting-started/Screenshot-2024-11-22-111825.png) ikonaren gainean proiektuaren pantailara sartzeko, non zure proiektua garatzen jarraitu ahal izango duzun.

Erabili jolasteko botoia ![Hastu zure proiektua](../../../media/getting-started/Screenshot-2024-11-22-111818.png) proiektua hasteko.

Bultza egin ProiektuakZure gorde diren proiektuetara sar zaitezke. ![Tresna-proiektuak](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Beste erabiltzaile batzuen proiektu gehiago ezagutu eta lantzeko, sakatu Catrobat Komunitatea partekatzean. Han proiektu handi asko aurkituko dituzu. ![Catrobat Batasuneko](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Proiektu berri bat sortu nahi baduzu, sakatu ikonoa. ![Gehitu](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
