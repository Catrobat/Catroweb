Hasieran Pocket Code pantaila nagusia ikusten da.

![Pantaila nagusia](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Hasieran Pocket Code pantaila nagusia ikusten da.\
[Ireki irudia](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Laguntza](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Eskuineko goiko txokorrean, Sinboloak eramango zaitu Catrobat Dokumentazioa, aholku onak dituena.

![Menu bat](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Horren ondoan dago menua.

Hortik, erraz joan zaitezke ezarpenetara, non hizkuntza alda dezakezun edo luzapenak aktibatu ditzakezu, hala nola plot blokeak eta gehiago.

![Editatu ikonoa](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Sakatu ikonaren gainean proiektuaren pantailara sartzeko, non zure proiektua garatzen jarraitu ahal izango duzun.

Azpian, zure azkenengo egitasmoa ikus dezakezu.

![Hastu zure proiektua](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Erabili jolasteko botoia proiektua hasteko.

![Tresna-proiektuak](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Bultza egin ProiektuakZure gorde diren proiektuetara sar zaitezke.

![Catrobat Batasuneko](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Beste erabiltzaile batzuen proiektu gehiago ezagutu eta lantzeko, sakatu Catrobat Komunitatea partekatzean.

Han proiektu handi asko aurkituko dituzu.

![Gehitu](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Proiektu berri bat sortu nahi baduzu, sakatu ikonoa.
