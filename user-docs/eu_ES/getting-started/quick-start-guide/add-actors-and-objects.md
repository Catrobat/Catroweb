Sakatu gehien botoia zure proiektuari figura edo objektu berri bat gehitzeko.

![Aktore bat gehitu](../../../media/getting-started/FigurHinzufuegen.png)

Pocket Code -n, zure proiektuari pertsonaia edo objektu bat gehitu ahal izango duzu hainbat era:

**Marraztu**: Zure pertsonaia propioa sortzeko ahal izango duzu **Pocket Paint**. Pocket Paint marrazketa programa da ([Gehiago Pocket Paint](https://catrobat.org/pocket-paint/))

**Itxurak**: Aukeratu bat aurretik egindako aktore eta objektuen bilduma batetik ([Informazio gehiago](../elements/medialibrary.md)).

**Galeria**: Zure smartphonearen galeriatik irudi bat aukeratu dezakezu.

**Liburutegia**: Liburutegian, antzezleak eta objektuak dagoeneko programatuak aurkituko dituzu. Zure jokoan prest dauden elementuak erabili nahi badituzu hautatu ahal izango dituzu (adibidez, kontatzeko) ([Liburutegiari buruz gehiago](../elements/medialibrary.md#media-liburutegitik-objektu-bat-gehitu)).

**Kamera**: Zure gailuaren kamera erabili dezakezu argazki bat egiteko eta pertsonaia gisa gehitzeko.

**Motxila**: Motxila hutsik dago. Atzeko poltsan gordetako aktoreak edo objektuak berriro erabili ditzakezu. Gidoi osoa deskargatuko da berarekin ([Motxilari buruz gehiago](../elements/backpack.md)).

**Gailuko aktoreak eta objektuak**: Hemen, zure proiektuan erabil ditzakezun pertsonaia prestaketa aurkituko dituzu. Tokiko eragileek eta objektuek komunikabide libreria bat bezala funtzionatzen dute, hau da, interneteko konexiorik ez baduzu ere, aktore horietara sar zaitezke.

**Objektu hutsa**: Objektu huts bat gehitu, itxura gabeko objektua. Objektu hau programatu dezakezu.

**Gailuko proiektuak**: Aukeratu zure proiektuan lehen aktorea eta gidoia sartu nahi dituzun proiektu bat.
