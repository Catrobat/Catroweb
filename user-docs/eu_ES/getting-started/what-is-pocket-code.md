Pocket Code Catrobat aplikazio nagusia da, software askea eta doakoa. Honekin, jokoak, animazioak eta istorio interaktiboak sortzen ahal izango dituzu zure smartphone edo tableta bidez. **blokeetan oinarritutako kodetze sistema** eta Pocket Code artean, proiektuak eraiki ditzakezu kode blokeak elkartuz. Ez da programatzeko esperientziarik behar, hasiberrientzat perfektua!

Pocket Code proiektu digitalak baino gehiago da. Berria **Makerspace-ren ezaugarriak** erabiliz, diseinatu dezakezu **SVG artxiboak mozteko plotters**. Horrek esan nahi du zure sorkuntzak munduko gauzak bihur ditzakezula eta pantailatik harantzago sortzeko aukerak aztertu.

Kodeatzen ikasten ari zarenean, ideiak lantzen edo programazioa irakasten ari zarenean, Pocket Code modu dibertigarri eta irisgarria eskaintzen du kodean murgiltzeko
