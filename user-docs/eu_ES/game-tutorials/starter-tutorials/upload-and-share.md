Tutorial honetan, zure sortutako proiektuak lagunekin edo guztiekin nola partekatu ikasiko duzu Catrobat Komunitatea.

![Sartu eta partekatu](../../../media/game-tutorials/Upload-and-Share.png)\
Tutorial honetan, zure sortutako proiektuak lagunekin edo guztiekin nola partekatu ikasiko duzu Catrobat Komunitatea.\
[Ireki irudia](../../../media/game-tutorials/Upload-and-Share.png)

Tutorial honetarako, zure proiektua behar duzu eta partekatu nahi duzu. Oraindik ez badakizu nola sortu proiektua, begiratu **[Proiektu berria](new-project.md)**-Horrela ikasiko duzu.

*Hemen, tutoriala deskarga dezakezu PDF formatua:*

[Ireki PDFa](../../../media/game-tutorials/Upload-and-Share.pdf)

### 1. Proiektuen aukerak

![Sartu eta partekatu](../../../media/game-tutorials/Upload-and-Share.png)\
Zure proiektua igo edo partekatu nahi baduzu, zure proiektua ireki behar duzu, gero eskuineko goiko izkinako hiru puntuetan klikatu eta ondoren «Proiektuaren aukerak» sakatu\
[Ireki irudia](../../../media/game-tutorials/Upload-and-Share.png)

### 2. Proiektuen aukerak

Orain izena alda dezakezu, deskribapena gehitu eta ezarpenak egin.

![Sartu eta partekatu (1)](../../../media/game-tutorials/Upload-and-Share-1.png)\
Bi aukera ere dituzu: «Igo proiektua» eta «Esportatu proiektua» hurrengo urratsetan azaltzen dira.\
[Ireki irudia](../../../media/game-tutorials/Upload-and-Share-1.png)

### 3. Sartu programa

Zure proiektua partekatzeko Catrobat igo nahi baduzu, komunitate osoak bertan eskura dezan, aukeratu *Igo proiektua*.

### 4. Sartu programa

Botoi honetan klik egiten baduzu zure proiektua Partekatzeko, kontu baterako izena eman behar duzu oraindik egin ez baduzu. Bestela, Google-rekin sar zaitezke. Sarreran izena ematerakoan, izen bat eman behar zaio egitasmoari eta deskribapena idatzi. Orduan hiru kategoriaraino aukeratu behar duzu zure programa onena den.

![Kargatu eta partekatu (2)](../../../media/game-tutorials/Upload-and-Share-2.png)\
Orduan sakatu «Hurrengoa» zure programa igortzeko.\
[Ireki irudia](../../../media/game-tutorials/Upload-and-Share-2.png)

### 5. Exportazio proiektua

Zure proiektua lagunekin partekatu nahi baduzu, *Esportatu proiektua* aukeratu.

### 6. Exportazio proiektua

Botoi honekin .catrobat fitxategi bat gorde dezakezu eta lagunekin partekatu.

![Sartu eta partekatu (3)](../../../media/game-tutorials/Upload-and-Share-3.png)\
Zure gailuaren fitxategi-aztergailuan gorde eta horrela partekatu dezakezu.\
[Ireki irudia](../../../media/game-tutorials/Upload-and-Share-3.png)

Lortu duzu! Lehenengo programa partekatu zenuen!

Laguntza edo inspirazioa behar baduzu hurrengo proiektuetarako, begiratu gure tutorialei maila ezberdinekin (hasiberria/artekoak/pro).
