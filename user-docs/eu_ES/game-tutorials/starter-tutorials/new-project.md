Tutorial honetan, zure lehen proiektua sortzen hasteko behar duzun guztia ikasiko duzu Pocket Code. Aplikazioa nola deskargatu, ireki eta proiektu berri bat sortzeko pausoz pauso gidatuko zaitugu.

![Programa berria](../../../media/game-tutorials/New-Program.png)

Hau da lehen tutoriala, eta ez duzu aurretiko ezagutzarik behar.

Zeren zain zaude? Hartu telefonoa eta hasi orain!

*Hemen, tutoriala deskarga dezakezu PDF formatua:*

[Programa berria](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code instalazioa

Hasieran, Pocket Code aplikazioa instalatu behar duzu zure gailuan. Bilatu aplikazioa «Pocket Code» - Zer Google Play Store eta deskargatu kolpe bat «instalatzeko». Pauso horretarako Google Kontua behar da. Orain zure gailuak deskargatuko du eta aplikazioa instalatuko du. Pauso honek denbora behar du, Interneteko konexioa kontuan hartuz.

![Programa berria (2)](../../../media/game-tutorials/New-Program-2.png)

Behin deskargatu eta instalatutako Pocket Code aplikazioa bilatu ahal izango duzu aplikazioen tiraderan edo zure etxeko pantailan, gailuaren arabera. Erraz eraman dezakezu aplikazioa eta nahi duzun lekuan jarri.

### 2. Abiatu aplikazioa

Aplikazioa irekitzean, kategoria desberdinak ikusten dira:

![Programa berria (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Proiektu berri bat sortzea

Hurrengo pausoa proiektu berri bat sortzea da. Horretarako, sakatu botoi horia eskuineko beheko txokoan. Orain proiektu baten izena sartu behar da eta aukeratu zure proiektua paisaia izan nahi duen edo ez. «Ados» sakatuz, proiektua sortzen da.

![Programa berria](../../../media/game-tutorials/New-Program.png)

### 4. Zure proiektu berria sortu duzu.

Orain Pocket Code instalatu duzu eta badakizu nola sortu proiektu berria. Orain programazioari ekin diezaiokezu!

Horretarako, objektu berri bat nola sortu jakin behar da proiektu batean. Begiratu **[Objektu berria](new-object.md)** tutoriala, non dena azaltzen zaizun urrats-urrats.
