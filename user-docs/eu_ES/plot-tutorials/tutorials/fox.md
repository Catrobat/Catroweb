Kontua hasten denean, mugimendu guztiak boligrafo batekin marrazten dira. Horiek dira konspiratzaileak geroago ebaki dituen lerroak.

Zizare hau lerro zuzenetatik bakarrik osatzen da («Mugitu \_\_\_ urrats») eta birak.

**Topa egin**: Probatu zure programa eraikitzen ari zaren bitartean.
