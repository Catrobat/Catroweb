In this tutorial, you will learn how to embroider a rainbow (112 x 57.2mm).

![Regenbogen](../../../media/embroidery-tutorials/Regenbogen.webp)

You should already know what a loop is and how it works.

The **[Semicircle](../embroidery-tutorials-beginner/semicircle.md)**-tutorial may be helpful for this tutorial.

Take a look at the embroidery tutorials in the [Beginner](../embroidery-tutorials-beginner/index.md) series if you haven’t embroidered anything yet.

For more information or design suggestions check out the other tutorials.

### 3. Copy Object

For the next larger arch, you can simply copy the object you have just created.

Click on the three dots in the top right-hand corner of the object overview.

Then go to “Copy” and select the object.

![Regenbogen (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

If you use a separate object for each arch, you can later embroider them in different colors.
