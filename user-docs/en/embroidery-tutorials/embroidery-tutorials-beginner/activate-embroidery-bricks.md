In this Tutorial, activating Embroidery Bricks will be explained.

![Activate Embroidery-Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

You don’t need any programming knowledge for this. This is the first step to start with the embroidery tutorials. Later, you can design, program, and even embroider your own designs onto your favorite textile piece.

For more information or design suggestions check out the other tutorials.

*Here you can download the tutorial in PDF-format*:

[ActivateEmbroideryBricks](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Start the “Pocket Code”-App. Follow the clicks!

### 2. Open the menu (dots on the right top).

![Activate Embroidery-Bricks](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Go to “Settings”.

![Activate Embroidery-Bricks3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Select “Embroidery extension”.

![Activate Embroidery-Bricks4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. You will find the Embroidery-Bricks as an own category within your bricks!

[![Activate Embroidery-Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../bricks/embroidery.md)

Now you will also find all embroidery bricks among the other bricks.

For more information about each brick, feel free to check the documentation of the bricks [here](../../bricks/index.md) or follow the **[Embroidery-Bricks](embroidery-bricks/index.md)**-tutorial for that.

Now you can get started and create your own designs!

If you need ideas or help with that, check out the other tutorials or continue with the **[Create Embroidery-Objects](create-embroidery-objects.md)**-tutorial.
