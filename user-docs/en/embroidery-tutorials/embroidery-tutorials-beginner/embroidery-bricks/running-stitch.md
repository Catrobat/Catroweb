Lets the machine stitch constantly with a variable length.

Usually you combine running stitch with a move-brick.

![Start_running_stitch_with_length_10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

The machine start a running stitch which will stitch every **10 steps**.

Then the machine moves **200 steps**.

This results in **20 stitches**.

![RunningStitch](../../../../media/embroidery-tutorials/RunningStitch.png)

The running stitch makes stitching a seam easier because you won’t need a loop any more.
