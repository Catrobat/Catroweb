Lets the current stitch stop.

You will need this brick if you want to change the position of the needle after starting a running, zigzag or triple stitch.

![Stop_current_stitch](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

Otherwise an unwanted intermediate seam would occur.

![StopCurrentStitch](../../../../media/embroidery-tutorials/StopCurrentStitch.png)
