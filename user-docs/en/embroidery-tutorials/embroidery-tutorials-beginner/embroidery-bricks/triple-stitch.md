The triple stitch sews up every stitch three times.

The triple stitch jumps back after the first stitch, stitches, then jumps back forward again and stitches again.

![Start_triple_stitch_with_length_10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Works the same as the [running stitch](running-stitch.md).

![TripleStitch](../../../../media/embroidery-tutorials/TripleStitch.png)

This makes the seam last longer.
