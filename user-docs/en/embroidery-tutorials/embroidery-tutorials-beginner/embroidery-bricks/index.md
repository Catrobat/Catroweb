In this Tutorial you will learn everything you need to know about Embroidery-Bricks!

You don’t need any programming knowledge for this.

Every Embroidery-Brick will be explained with an example.

If you have not yet activated the Embroidery-Bricks, have a look at the **[Activate Embroidery-Bricks](../activate-embroidery-bricks.md)**-tutorial.
