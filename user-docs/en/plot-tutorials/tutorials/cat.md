When the plot starts, every movement is drawn as if with a pen. These are the lines the plotter cuts along later.

Our object points in direction 150 degrees.

In this tutorial, the right side of the cat's head is made first. If you look closely, the curve is strong at first, so the object has to turn more after each small line. Then the turns get smaller for the lower part of the head. The left side of the head is curved strongly again. That is why this part of the head uses three loops in total.

Next comes the left ear. It is made only of straight lines, so we can use the brick "Move \_\_ steps".

The part between the ears is an arc again and is programmed with another loop.

Then the right ear is made.

The plot is now finished. End it with the brick "Stop to plot" and save it on your phone with "Save plot as SVG \_\_\_".

You can now send the SVG file to a (cutting) plotter.
