To do this, you should already have downloaded the Pocket Code app and know how to create a new project. If you need assistance with this, feel free to have a look at the **[New Project](new-project.md)**-tutorial.

### 1. Create a new Object

At first, you need to open your new project.

You will find it on the homescreen of the Pocket Code app. If you have more than one project, you can click on “Projects on device”. Then select your new project. If you have not created a new project or need further information how to do that, have a look at the **[New Project](new-project.md)**-tutorial.

### 2. Create a new Object

Now you are ready to create a new object. You will see a new window giving you seven possibilities to choose from.

![New Object (1)](../../../media/game-tutorials/New-Object-1.png)\
To do that just click on the yellow plus-button on the bottom right corner.\
[Open image](../../../media/game-tutorials/New-Object-1.png)

### 3. Ways to Create

![New Object (2)](../../../media/game-tutorials/New-Object-2.png)\
This are the possibilities you can choose from.\

### 4. Draw Image

To make it as easy as possible for the beginning, we want to use the “Draw image” function and just draw a dot. When you have drawn the dot with Pocket Paint you can quit it (by going one step back).

### 5. Give a name

Now you have to give your picture a name.

### 6. Place it

After that you have to place it visually by shifting it to the left/right or up/down with your finger.

![New Object (3)](../../../media/game-tutorials/New-Object-3.png)\
You have to save it with the button in the top right corner.\
[Open image](../../../media/game-tutorials/New-Object-3.png)

### 7. You made it! You created your own new object.

Now you have a project with an object that you can program!

To do this, you should know what brick are available. The **[First Bricks](first-bricks.md)**-tutorial gives you a good overview of the different categories of bricks. However, you can also start directly with your first project. Choose a suitable tutorial from the Beginner series.
