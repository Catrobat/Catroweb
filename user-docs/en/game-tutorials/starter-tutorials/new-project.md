So, what are you waiting for? Grab your phone and get started now!

### 1. Installation of Pocket Code

At first, you need to install the Pocket Code app on your device. For this step a Google Account is required. Now your device will download and install the app. This step may take a while according to your internet connection.

![New Program (2)](../../../media/game-tutorials/New-Program-2.png)\
You can find the app by searching “Pocket Code” in the Google Play Store and download it by hitting “install”.\
[Open image](../../../media/game-tutorials/New-Program-2.png)

After successfully downloading and installing Pocket Code you can find the app in the app drawer or on your home screen, depending on your device. You can easily take the app and place it anywhere you like.

### 2. Start the App

![New Program (1)](../../../media/game-tutorials/New-Program-1.png)\
When you open the app, you see different categories.\
[Open image](../../../media/game-tutorials/New-Program-1.png)

### 3. Create a new Project

The next step is to actually create a new project. Now you have to enter a project name and select whether your project should be landscape or not. By pressing “OK” the project is created.

![New Program](../../../media/game-tutorials/New-Program.png)\
To do that, you can press on the yellow plus-Button at the bottom right corner.\
[Open image](../../../media/game-tutorials/New-Program.png)

### 4. You made it! You created your own new project.

Now you have installed Pocket Code and know how to create a new project. Now you can start programming!

To do this, you need to know how to create a new object in a project. Have a look at the **[New Object](new-object.md)**-tutorial, where everything is explained to you step by step.
