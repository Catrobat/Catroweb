The **backpack** feature in Pocket Code is a practical function that allows you to **save and reuse** elements like actors (objects), scripts, looks, or sounds **across projects**. It helps you save time and make your projects more efficient.

The backpack is like a digital storage space where you can store various elements from your current project. Once saved in the backpack, you can retrieve and insert these elements into other projects.

### How do I use the backpack for actors (objects)?

**Pack figures into the backpack**

Go to the project view of the project from which you want to pack a figure into the backpack.

The figure (including its looks, sounds, and scripts) will be packed into the backpack.

![Pack actor](../../../media/getting-started/grafik-7.png)\
Click on the three dots next to the figure to open the context menu and select “Pack.”\
[Open image](../../../media/getting-started/grafik-7.png)

**Add figures from the backpack**

Open the project where you want to insert the figure.

In the project view, tap the plus symbol and select “Backpack.”

You will now see all the figures and objects you have saved in your backpack.

![Unpack Actor](../../../media/getting-started/grafik-8-e1732702791199.png)\
Tap on the three dots and select “unpack.”\
[Open image](../../../media/getting-started/grafik-8-e1732702791199.png)

### How do I use the backpack for scripts?

**Put scripts in the backpack:**

Go to the figure that contains the script. Hold down the desired script in the script editor.

![add to backpack](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)\
Select “Add to backpack” from the context menu.\
[Open image](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

![Save actor to backpack](../../../media/getting-started/grafik-9.png)\
Give the script a name and confirm with OK.\
[Open image](../../../media/getting-started/grafik-9.png)

![your backpack](../../../media/getting-started/grafik-10.png)\
The script is saved and can be used in other projects.\
[Open image](../../../media/getting-started/grafik-10.png)

**Add scripts from the backpack:**

Tap on the actor where you want to insert the script. You will see the script area.

![UnpackSkript](../../../media/getting-started/grafik-11.png)\
Tap on the three dots to open the context menu and tap on “Backpack”.\
[Open image](../../../media/getting-started/grafik-11.png)

You can now see all the scripts that are already in your backpack.

Through the context menu, you can delete scripts that you no longer need in your backpack.

![UnpackSkriptBackpack](../../../media/getting-started/grafik-12.png)\
Tap on the three dots next to the desired script and select “Unpack” from the context menu.\
[Open image](../../../media/getting-started/grafik-12.png)

***

### Benefits of the Backpack

- **Cross-Project Reusability:** Figures, scripts, sounds, and looks can be created once and reused as often as needed.
- **Time saving:** You don’t have to create figures or scripts anew each time.
- **Consistency:** Elements remain consistent when you need them across multiple projects.
