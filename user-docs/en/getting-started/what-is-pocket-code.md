Pocket Code is Catrobat’s main app, a free and open-source mobile app that lets you create games, animations, and interactive stories right on your smartphone or tablet. Using Pocket Code’s **block-based coding system**, you can build projects by snapping together code blocks – like putting together pieces of a puzzle. No programming experience is needed, making it perfect for beginners!

Pocket Code goes beyond just digital projects. With new **makerspace features**, you can also design **SVG files for cutting plotters**. This means you can turn your digital creations into real-world items and explore creative possibilities beyond the screen.

Whether you’re learning to code, experimenting with new ideas, or teaching programming, Pocket Code provides a playful, accessible way to dive into coding

[More information](https://catrobat.org/pocket-code/)
