When you start Pocket Code, you see the following main screen.

![Main Screen](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
When you start Pocket Code, you see the following main screen.\
[Open image](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Help](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
In the top right corner, there’s a symbol that takes you to the Catrobat documentation, which has helpful tips for you.

![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Next to that is the menu.

From there, you can easily go to the settings, where you can change the language or turn on extensions like the plot blocks and more.

![Edit icon](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Click on the edit icon to access the project screen, where you can continue developing your project.

Underneath, you can see your most recently edited project.

![Start your Project](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Use the play button to start your project.

![Projects on Device](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
With a click on Projects on device, you can access your saved projects.

![Catrobat Community](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
If you want to get to know and work on more projects from other users, just click on Catrobat Community on the Share.

There you’ll find many great projects.

![Add](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
If you want to create a new project, click on the plus icon.
