Tämä on ensimmäinen ohje, eikä sinun tarvitse tietää mitään etukäteen.

Mitä siis odotat? Ota puhelin ja aloita heti!

*Voit ladata tämän ohjeen PDF-muodossa:*

[Avaa PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Coden asentaminen

Ensin sinun pitää asentaa Pocket Code -sovellus laitteeseesi. Tätä vaihetta varten tarvitset Google-tilin. Laitteesi lataa ja asentaa sovelluksen nyt. Tähän voi mennä hetki, riippuen internetyhteydestäsi.

![Uusi ohjelma (2)](../../../media/game-tutorials/New-Program-2.png)\
Löydät sovelluksen hakemalla Google Play -kaupasta „Pocket Code“ ja lataamalla sen painamalla „Asenna“.\
[Avaa kuva](../../../media/game-tutorials/New-Program-2.png)

Kun Pocket Code on latautunut ja asentunut, löydät sovelluksen sovellusvalikosta tai aloitusnäytöltä laitteesi mukaan. Voit siirtää sovelluksen minne tahansa haluat.

### 2. Käynnistä sovellus

![Uusi ohjelma (1)](../../../media/game-tutorials/New-Program-1.png)\
Kun avaat sovelluksen, näet eri kategorioita.\
[Avaa kuva](../../../media/game-tutorials/New-Program-1.png)

### 3. Luo uusi projekti

Seuraavaksi luodaan uusi projekti. Anna sitten projektille nimi ja valitse, onko projekti vaaka- vai pystymuodossa. Kun painat „OK“, projekti luodaan.

![Uusi ohjelma](../../../media/game-tutorials/New-Program.png)\
Napauta siihen oikeassa alakulmassa olevaa keltaista plus-painiketta.\
[Avaa kuva](../../../media/game-tutorials/New-Program.png)

### 4. Onnistuit! Loit oman uuden projektin.

Nyt olet asentanut Pocket Coden ja tiedät, miten luodaan uusi projekti. Nyt voit alkaa ohjelmoida!

Sitä varten sinun pitää tietää, miten projektiin luodaan uusi objekti. Katso ohje **[Uusi objekti](new-object.md)**, jossa kaikki selitetään sinulle vaihe vaiheelta.
