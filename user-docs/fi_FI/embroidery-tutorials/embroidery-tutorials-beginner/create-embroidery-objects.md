Tässä ohjeessa opit luomaan objekteja, joilla voit myöhemmin brodeerata kuvioitasi.

Tätä ohjetta varten sinun pitää jo osata luoda projekti. Katso tarvittaessa ohjeet [Aloitussarjasta](../../game-tutorials/starter-tutorials/index.md).

Lisätietoja tai kuviovinkkejä saat muista ohjeista.

*Voit ladata tämän ohjeen PDF-muodossa*:

[Luo brodeerausobjekteja](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Napauta projektisi oikeassa alakulmassa olevaa plus-painiketta lisätäksesi uuden objektin.

![Luo brodeerausobjekteja](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Valitse kuva siirtymällä medianäkymään.

![Luo brodeerausobjekteja (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Brodeerausobjekti edustaa yhtä tason neulaa brodeerauskoneessa. Useat brodeerausobjektit brodeeraantuvat yksi toisensa jälkeen. Tämän ansiosta voit käyttää useita värejä.

Valitse objekti sen värin mukaan, jonka haluat.

Selaa alas ja etsi sopiva nuoli.

![Luo brodeerausobjekteja (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Anna uudelle objektillesi sopiva nimi ja paina OK.

![Luo brodeerausobjekteja (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Olet nyt luonut uuden objektin. Voit nyt lisätä skriptin ja ohjelmoida objektin.

![Luo brodeerausobjekteja (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Nyt tiedät, miten objekti luodaan. Lisää uusi objekti jokaista käyttämääsi väriä varten.

Voit lisätä skriptin jokaiseen väriin ja ohjelmoida omat kuviosi. Myöhemmin voit brodeerata ne.
