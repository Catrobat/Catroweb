Kolmoispisto ompelee jokaisen pisto kolme kertaa.

Kolmoispisto hyppää ensimmäisen pistonsa jälkeen taaksepäin, ompelee, hyppää taas eteenpäin ja ompelee uudelleen.

![Aloita kolmoispisto, pituus 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Toimii samalla tavalla kuin [etupisto](running-stitch.md).

![Kolmoispisto](../../../../media/embroidery-tutorials/TripleStitch.png)

Tämä tekee saumasta kestävämmän.
