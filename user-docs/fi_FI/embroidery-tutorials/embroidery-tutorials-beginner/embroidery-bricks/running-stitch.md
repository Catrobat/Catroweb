Antaa koneen ommella jatkuvasti vaihtuvan pituisia pistoja.

Etupistoa yhdistetään yleensä liikuta-palikkaan.

![Aloita etupisto, pituus 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Kone aloittaa etupiston, joka ompelee joka **10 askeleen** välein.

Sen jälkeen kone liikkuu **200 askelta**.

Tuloksena on **20 pistoa**.

![Etupisto](../../../../media/embroidery-tutorials/RunningStitch.png)

Etupisto helpottaa saumojen ompelua, koska silmukkaa ei tarvita enää.
