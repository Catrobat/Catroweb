Tässä ohjeessa opit ottamaan brodeerauspalikat käyttöön.

![Brodeerauspalikoiden käyttöönotto 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Tähän ei tarvita ohjelmointitaitoja. Tämä on ensimmäinen askel brodeerausohjeissa. Myöhemmin voit suunnitella, ohjelmoida ja jopa brodeerata omia kuvioitasi lempitekstiilillesi.

Lisätietoja tai kuviovinkkejä saat muista ohjeista.

*Voit ladata tämän ohjeen PDF-muodossa*:

[Ota brodeerauspalikat käyttöön](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Käynnistä Pocket Code -sovellus. Seuraa napsautuksia!

### 2. Avaa valikko (oikeassa yläkulmassa olevat pisteet).

![Ota brodeerauspalikat käyttöön](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Siirry kohtaan „Asetukset“.

![Ota brodeerauspalikat käyttöön 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Valitse „Brodeerauslaajennus“.

![Ota brodeerauspalikat käyttöön 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Löydät brodeerauspalikat omana kategorianaan palikoistasi!

[![Ota brodeerauspalikat käyttöön 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Nyt löydät kaikki brodeerauspalikat myös muiden palikoiden joukosta.

Lisätietoja jokaisesta palikasta löydät palikkojen ohjeista [täältä](../../../reference/) tai seuraamalla **[Brodeerauspalikat](embroidery-bricks/index.md)**-ohjetta.

Nyt voit aloittaa ja luoda omia kuvioitasi!

Jos tarvitset ideoita tai apua, katso muut ohjeet tai jatka **[Luo brodeerausobjekteja](create-embroidery-objects.md)**-ohjeeseen.
