Haluatko olla luova ja samalla oppia koodaamaan leikkisällä tavalla? Pidätkö myös siitä, että voit tehdä asioita, joita voi heti käyttää, pitää päällä tai ihailla?

Brodeerauksen suunnittelijalla voit ohjelmoida brodeerauskoneen ilman aiempaa kokemusta. Kone brodeeraa kuviosi automaattisesti T-paitaan, laukkuun, housuihin, älypuhelimen kuoreen tai vaikkapa kenkiin. Ompelu onnistuu kaikkeen, mikä on kangasta. Anna mielikuvituksesi ja luovuutesi vapaasti valloilleen! Voit ladata ja muokata muiden tekemiä kuvioita Catrobat-yhteisöstämme. Voit tietysti myös jakaa omat projektisi ystäviesi ja koko maailman kanssa!
