![Jos on tosi, niin muuten](../../../media/bricks/if_else_brick2.png)

*Tarkistaa, onko ehto tosi. Jos on, suoritetaan yksi joukko ohjeita. Jos ei, suoritetaan toinen joukko. Se on kuin antaisit kaksi vaihtoehtoa: „Jos tämä on tosi, tee tämä, muuten tee tuo.“*

![Kun kohtaus alkaa](../../../media/bricks/StartScene.png)

Kun kohtaus alkaa, muuttujan X arvoksi asetetaan 0.

![Jos-muuten](../../../media/bricks/IfElse.png)

Jos eläintä napautetaan, tarkistetaan, onko X jaettuna kahdella jakojäännös tosi, eli onko X pariton luku.

Jos näin on, soitetaan ääni Tweet1 ja muuttujan X arvoa kasvatetaan yhdellä.

Muuten, jos X on parillinen, kasvatetaan vain X:n arvoa yhdellä.

Suoritettavat ohjeet erotetaan toisistaan palikalla Jos-ehdon loppu.
