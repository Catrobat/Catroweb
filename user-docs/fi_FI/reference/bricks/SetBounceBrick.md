Asettaa, kuinka paljon objekti pomppii osuessaan johonkin. Suurempi prosenttiluku tarkoittaa voimakkaampaa pomppua. Se on kuin päättäisit, kuinka paljon hahmosi pomppii seinistä tai muista objekteista.
