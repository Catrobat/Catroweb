![Kun aloitat kloonina](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Antaa luodulle objektin kloonille ohjeet, joiden mukaan se toimii. Näin klooni voi tehdä samat asiat kuin alkuperäinen objekti, mutta sitä voi ohjata itsenäisesti. Kloonin eri ominaisuuksia ja käyttäytymistä voi määrittää omien tarpeidesi mukaan.
