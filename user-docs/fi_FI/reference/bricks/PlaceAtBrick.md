![Sijoita kohtaan x y](../../../media/bricks/place_at_x_y_brick.png)

Siirtää objektin tiettyyn kohtaan näytöllä x- ja y-koordinaattien mukaan. Se on kuin teleporttaisit hahmosi täsmälleen oikeaan paikkaan.

Paikka määritellään koordinaatistossa, kuten tasokoordinaatistossa: x- ja y-akselit kulkevat näytön keskikohdan kautta, joten x = 0 ja y = 0 on näytön keskellä.
