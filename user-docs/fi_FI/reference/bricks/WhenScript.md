Suorittaa skriptin, kun objektia napautetaan.

Ero palikkaan *„Kun esiintymislavaa napautetaan“* on se, että *„Kun minua napautetaan“* koskee yksittäisiä hahmoja tai objekteja, kun taas *„Kun esiintymislavaa napautetaan“* koskee koko näyttöä.
