![Aseta liiketyypiksi](../../../media/bricks/set_your_motion_type_brick.png)

Muuttaa tapaa, jolla objekti liikkuu. Objekti voi esimerkiksi liikkua ja pomppia painovoiman vaikutuksesta, olla liikkumatta painovoiman vaikutuksesta mutta muiden pomppiessa sinusta, tai olla liikkumatta eikä pomppia. Se on kuin päättäisit, miten hahmosi käyttäytyy liikkuessaan ja vuorovaikuttaessaan muiden kanssa.
