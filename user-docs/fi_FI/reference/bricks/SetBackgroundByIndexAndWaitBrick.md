Tämä palikka vaihtaa taustan tiettyyn taustaan sen paikan perusteella taustalistassa. Se odottaa, kunnes muutos on valmis, ennen kuin skripti jatkuu. Se on kuin valitsisit näytelmässä tietyn taustakankaan listasta ja pysäyttäisit toiminnan, kunnes uusi kohtaus on kokonaan valmis.
