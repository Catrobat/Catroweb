![Pysäytä ääni](../../../media/bricks/Stop_sound_record.png)

Tämä palikka pysäyttää tietyn äänen soimisen. Se on kuin painaisit pysäytysnappia vain yhdelle kappaleelle, kun muut äänet tai musiikki jatkavat soimista. Kuvittele, että käsket hahmoasi lopettamaan yhden tietyn äänen soittamisen.
