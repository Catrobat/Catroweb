![Toista jokaiselle arvolle listasta](../../../media/bricks/for-each-value_brick.png)

Tämä palikka suorittaa joukon ohjeita jokaiselle listan tai välin alkiolle. Se on kuin kävisit jokaisen alkion läpi yksi kerrallaan ja tekisit jokaiselle saman asian.

Kuvittele, että sinulla on lista lukuja, värejä tai mitä tahansa muita alkioita. Tämän palikan avulla voit ottaa jokaisen alkion listasta ja tehdä sillä jotain. Jos sinulla on esimerkiksi lista värejä ja haluat vaihtaa taustan väriä jokaiseksi listan väriksi, käytät tätä palikkaa.

Se on kuin sanoisit: „Tämän ryhmän jokaiselle alkiolle tee nämä ohjeet.“
