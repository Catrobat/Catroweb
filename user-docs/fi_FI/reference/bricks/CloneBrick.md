Tämä palikka tekee kopion valitusta objektista, jota kutsutaan kloonaksi. Klooni toimii kuten alkuperäinen. Kuvittele, että monistat hahmon tai objektin pelissäsi. Klooni voi saada omia toimintoja ja skriptejä, joten voit luoda useita saman objektin kopioita, jotka toimivat itsenäisesti.
