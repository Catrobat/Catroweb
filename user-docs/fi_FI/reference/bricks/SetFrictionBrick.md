![Aseta kitkaksi](../../../media/bricks/set_friction_to_brick2.png)

Säätää objektiin kohdistuvan kitkan määrää. Se vaikuttaa siihen, kuinka helposti objekti liukuu tai hidastuu. Se on kuin muuttaisit sen pinnan liukkautta, jolla hahmosi seisoo. Mitä enemmän kitkaa, sitä vähemmän hahmo liukuu.
