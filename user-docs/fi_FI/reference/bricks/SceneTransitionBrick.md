![Jatka kohtausta](../../../media/bricks/continue_scene_brick2.png)

Tämä palikka jatkaa kohtausta siitä kohdasta, johon se pysäytettiin. Jos kohtaus keskeytyi tauon tai odotuksen takia, tämä palikka jatkaa toimintaa juuri siitä, mihin jäätiin.

Kuvittele, että pysäytit pelin tai animaation ja haluat sen jatkuvan. Tämä palikka toimii kuin toistopainike, ja kaikki jatkuu siitä kohdasta, jossa se pysäytettiin.
