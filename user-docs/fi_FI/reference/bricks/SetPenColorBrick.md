![Aseta kynän väriksi punainen 0, vihreä 0, sininen 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Tämä palikka muuttaa hahmon kynän värin. Se on kuin vaihtaisit piirtäessäsi toiseen värikynään.

**Punainen, vihreä, sininen (RGB)**: RGB-värimallissa käytetään punaisen, vihreän ja sinisen valon eri voimakkuuksia, joiden avulla syntyy laaja kirjo värejä. Jokaisen värikomponentin (punainen, vihreä ja sininen) arvo voi olla väliltä 0–255:

- **Punainen**: värin punainen osuus. Suurempi arvo tarkoittaa enemmän punaista.
- **Vihreä**: värin vihreä osuus. Suurempi arvo tarkoittaa enemmän vihreää.
- **Sininen**: värin sininen osuus. Suurempi arvo tarkoittaa enemmän sinistä.

Yhdistämällä punaisen, vihreän ja sinisen eri arvoja voit luoda minkä tahansa värin. Esimerkiksi:

- `RGB(255, 0, 0)` on puhdas punainen.
- `RGB(0, 255, 0)` on puhdas vihreä.
- `RGB(0, 0, 255)` on puhdas sininen.
- `RGB(255, 255, 255)` on valkoinen (punaista, vihreää ja sinistä on kaikkein eniten).
- `RGB(0, 0, 0)` on musta (ei väriä).

Eri määrien sekoittaminen luo kaikki värit, joita näet digitaalisilla näytöillä.
