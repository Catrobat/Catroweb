![Odota, kunnes kaikki muut skriptit ovat pysähtyneet](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Tämä palikka pysäyttää nykyisen skriptin, kunnes kaikki muut projektin skriptit ovat päättyneet. Kuvittele, että laitat skriptisi tauolle, kunnes kaikki muu on valmis. Se on hyödyllinen, kun haluat varmistaa, ettei mitään muuta tapahdu ennen seuraavien vaiheiden jatkamista.
