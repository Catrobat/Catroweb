![Lopeta piirtäminen](../../../media/bricks/Stop_to_plot.png)

Palikka „Lopeta piirtäminen“ keskeyttää piirtämisen ja antaa sinun siirtää hahmon uuteen paikkaan tai lopettaa piirtämisen. Se on kuin nostaisit kynän paperilta, jotta voit asettaa sen uudelleen tai lopettaa piirtämisen. Kun piirtäminen on valmis, voit tallentaa piirroksen SVG-tiedostona palikalla „Tallenna piirros SVG-tiedostoon“.
