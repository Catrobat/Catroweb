![Aseta massaksi 1 kilogramma](../../../media/bricks/set_mass_to__kilogram_brick.png)

Määrittää objektin painon kilogrammoina. Se vaikuttaa siihen, miten objekti liikkuu ja vuorovaikuttaa muiden objektien kanssa. Raskaampaa objektia on vaikeampi liikuttaa, ja sen suunnan muuttamiseen tarvitaan enemmän voimaa.
