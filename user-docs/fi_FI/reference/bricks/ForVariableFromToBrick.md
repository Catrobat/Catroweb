Tämä palikka suorittaa joukon ohjeita tietyn määrän kertoja. Laskuri alkaa yhdestä arvosta ja päättyy toiseen. Se on kuin tekisit silmukan, jossa tiedät tarkalleen, kuinka monta kertaa se käy läpi.

Kuvittele, että sinulla on lista asioita ja haluat tehdä jotain jokaiselle niistä. Tämän palikan avulla käyt jokaisen läpi yksi kerrallaan ja teet jokaiselle saman asian.
