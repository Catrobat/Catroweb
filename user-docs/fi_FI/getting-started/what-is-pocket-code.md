Pocket Code on Catrobatin pääsovellus. Se on ilmainen ja avoimen lähdekoodin mobiilisovellus, jonka avulla voit tehdä pelejä, animaatioita ja interaktiivisia tarinoita suoraan älypuhelimellasi tai tabletillasi. Pocket Coden **palikkapohjaisella koodausjärjestelmällä** voit rakentaa projekteja yhdistämällä koodipalikoita. Se on kuin palapelin palojen kokoamista. Ohjelmointikokemusta ei tarvita, joten sovellus sopii täydellisesti aloittelijoille!

Pocket Code ulottuu digitaalisten projektien ulkopuolellekin. Uusien **tekemisen kulttuurin ominaisuuksien** avulla voit suunnitella myös **SVG-tiedostoja leikkuriplottereille**. Näin digitaalisista luomuksistasi voi tulla todellisia esineitä ja voit tutkia luovia mahdollisuuksia ruudun ulkopuolella.

Olitpa sitten oppimassa koodaamista, kokeilemassa uusia ideoita tai opettamassa ohjelmointia, Pocket Code tarjoaa leikkisän ja helppokäyttöisen tavan päästä koodauksen makuun.
