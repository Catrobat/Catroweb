Pocket Code on visuaalinen ohjelmointisovellus, jonka avulla voit tehdä pelejä, animaatioita ja interaktiivisia tarinoita suoraan älypuhelimellasi tai tabletillasi. Helppokäyttöisen vedä ja pudota -liittymän avulla voit suunnitella projektejasi „palikoilla“ (koodipalikat), eikä ohjelmointikokemusta tarvita. Lisää helposti ääniä, kuvia ja liikettä, jotta ideasi tulevat eloon.

Tämä opas auttaa sinua alkuun. Opit seuraavat asiat:

- Liikkumaan käyttöliittymässä,
- Tekemään ensimmäisen projektisi,
- Työskentelemään hahmojen ja taustojen kanssa,
- Käyttämään palikoita toimintojen ohjelmoimiseen ja
- Tallentamaan projektisi.

Pocket Code sopii täydellisesti aloittelijoille ja opettajille, ja se kannustaa luovuuteen, ongelmanratkaisuun ja loogiseen ajatteluun.
