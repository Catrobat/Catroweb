Avaa sovellus älypuhelimellasi tai tabletillasi. Napauta +-merkkiä, jotta voit luoda uuden projektin.

![Päänäkymä, uusi projekti](../../../media/getting-started/MainScreen_NewProject.png)

Anna projektille nimi (1) ja päätä, haluatko tehdä pelin pystysuuntaisessa (pysty) vai vaakasuuntaisessa (vaaka) muodossa (2). Vahvista sitten valintasi valintamerkillä (3).

![Uusi projekti](../../../media/getting-started/NewProject.png)

Olet nyt projektinäkymässä. Ylhäällä näet pelisi nimen.

Alla näet **taustan**. Tausta on tällä hetkellä tyhjä. Jos haluat vaihtaa sen, napauta sitä.

Taustan alla on alue **hahmoillesi ja objekteillesi**, jotka olet lisännyt peliisi. Alue on vielä tyhjä.

Oikeassa alakulmassa on kaksi tärkeää painiketta:

![Käynnistä](../../../media/getting-started/Start.png) **Toista**-painikkeella käynnistät pelisi.

![Plus-painike](../../../media/getting-started/Screenshot-2024-11-22-143219.png) **Plus**-painikkeella lisäät peliisi uuden hahmon tai objektin.
