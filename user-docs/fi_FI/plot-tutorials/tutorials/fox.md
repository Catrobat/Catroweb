Kun piirros alkaa, jokainen liike piirretään kuin kynällä. Nämä ovat viivat, jotka plotteri leikkaa myöhemmin.

Tämä kettu koostuu vain suorista viivoista („Liiku __ askelta“) ja käännöksistä.

**Vinkki**: Testaa ohjelmaasi jo rakentaessasi sitä.
