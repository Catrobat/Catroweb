جب تم شروع کرتے ہو Pocket Code ، تم مندرجہ ذیل مرکزی اسکرین دیکھتے ہیں۔.

![مرکزی اسکرین](../../../media/getting-started/MainScreen-e1732269599192.jpg)

سب سے اوپر دائیں کونے میں، ایک ![مدد](../../../media/getting-started/Screenshot-2024-11-22-111748.png) علامت ہے جو تمہیں Catrobat دستاویزات پر لے جاتا ہے، جس میں تمہارے لئے مفید تجاویز ہیں.

اس کے ساتھ مینو ہے ![مینو](../../../media/getting-started/Screenshot-2024-11-22-111804.png) ۔. وہاں سے، تم آسانی سے ترتیبات میں جا سکتے ہیں، جہاں تم زبان کو تبدیل کرسکتے ہیں یا توسیع جیسے پلاٹ بلاکس اور زیادہ کو چالو کرسکتے ہیں.

ذیل میں تم اپنے تازہ ترین ترمیم شدہ پروجیکٹ دیکھ سکتے ہیں۔. پروجیکٹ اسکرین تک رسائی کے لئے ترمیم آئکن ![آئکن میں ترمیم کرو](../../../media/getting-started/Screenshot-2024-11-22-111825.png) پر کلک کرو، جہاں تم اپنے منصوبے کی ترقی جاری رکھ سکتے ہیں۔.

اپنے منصوبے کو شروع کرنے کے لئے پلے بٹن ![اپنا پروجیکٹ شروع کرو](../../../media/getting-started/Screenshot-2024-11-22-111818.png) کا استعمال کرو.

ایک کلک کے ساتھ پروجیکٹس، تمہیں محفوظ کردہ منصوبوں تک رسائی حاصل کر سکتے ہو. ![آلات پر منصوبے](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

اگر تم دوسرے صارفین سے مزید منصوبوں پر جاننا اور کام کرنا چاہتے ہو تو ، صرف Catrobat کمیونٹی آن شیئر پر کلک کرو۔. وہاں تمہیں بہت سے عظیم منصوبوں کو تلاش کرو گے. ![Catrobat کمیونٹی](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

اگر تم ایک نیا منصوبہ بنانا چاہتے ہو تو، پلس آئکن پر کلک کرو. ![شامل کرو](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
