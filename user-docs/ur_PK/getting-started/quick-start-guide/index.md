Pocket Code ایک بصری پروگرامنگ ایپ ہے جو تمہیں اپنے اسمارٹ فون یا ٹیبلٹ پر براہ راست کھیل ، حرکت پذیری اور انٹرایکٹو کہانیاں تخلیق کرنے کی اجازت دیتی ہے۔. ”کوڈ بلاک“ (کوڈ بلاک) کے ساتھ ایک بدیہی ڈریگ اور ڈراپ انٹرفیس کا استعمال کرتے ہوئے، تم اپنے منصوبوں کو بغیر کسی پروگرامنگ تجربے کے ڈیزائن کرسکتے ہیں. اپنے خیالات کو عملی جامہ پہنانے کے لیے آسانی سے آوازیں، تصاویر اور حرکتیں شامل کرو۔.

یہ گائیڈ تمہیں شروع کرنے میں مدد دے گا کہ کس طرح:

- انٹرفیس نیویگیشن،
- اپنا پہلا پروجیکٹ بنائیں،
- اشیاء اور پس منظر کے ساتھ کام کرنا،
- پروگرامنگ کے لیے کوڈ بلاک استعمال کرو، اور
- اپنے منصوبے کو بچائیں.

ابتدائی اور اساتذہ کے لئے بہترین، Pocket Code تخلیقی صلاحیتوں، مسائل کو حل کرنے، اور منطقی سوچ کی حوصلہ افزائی کرتا ہے.
