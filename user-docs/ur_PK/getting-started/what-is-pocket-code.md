Pocket Code Catrobat کی بنیادی ایپ ہے ، ایک مفت اور اوپن سورس موبائل ایپ جو تمہیں اپنے اسمارٹ فون یا ٹیبلٹ پر کھیل ، حرکت پذیری اور انٹرایکٹو کہانیاں بنانے دیتی ہے۔. **بلاک پر مبنی کوڈنگ سسٹم** ان Pocket Code کے ساتھ، تمہیںڈ بلاکس کو ایک دوسرے کے ساتھ توڑ کر منصوبے تعمیر کر سکتے ہو - جیسے پزل کے ٹکڑے مل کر. پروگرامنگ کا کوئی تجربہ نہیں ہے، جو کہ ابتدائیوں کے لئے بہترین بنا دیتا ہے!

Pocket Code صرف ڈیجیٹل منصوبوں سے باہر ہے. نئے **makerspace خصوصیات** کے ساتھ تمہیں بھی ڈیزائن کر سکتے ہو **SVG کٹائی کرنے والے پلسٹرز کے لئے فائلیں**. اس کا مطلب یہ ہے کہ تم اپنی ڈیجیٹل تخلیقات کو حقیقی دنیا کے اشیاء میں تبدیل کر سکتے ہو اور اسکرین سے باہر تخلیقی امکانات کی تلاش کرسکتے ہیں۔.

چاہے تمہیںڈ کرنا سیکھ رہے ہوں، نئے خیالات کے ساتھ تجربہ کر رہے ہوں یا پروگرامنگ سکھا رہے ہوں، Pocket Code کوڈنگ میں گہرے انداز میں ڈوبنے کا ایک کھیلنا آسان اور قابل رسائی طریقہ فراہم کرتا ہے
