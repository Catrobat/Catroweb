![یہاں جائیں:](../../../media/bricks/go_to_brick2.png)

فوری طور پر کسی اور چیز کی جگہ یا بے ترتیب پوزیشن پر اعتراض کو منتقل کرتا ہے۔. اس کے بارے میں سوچو جیسے کہ، ”جہاں یہ دوسرا کردار ہے جانے“ یا ”کسی بے ترتیب جگہ پر جاؤ.“
