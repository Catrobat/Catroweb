![1 دھڑک کے لئے وقفہ](../../../media/bricks/Pause_for_1_beats.png)

اس کوڈ بلاک سے اسکرپٹ جاری رکھنے سے پہلے ایک مخصوص تعداد میں دھڑکنوں کا انتظار کرتا ہے۔. یہ کسی گانے میں ایک مختصر وقفے سے پہلے اگلے نوٹ یا آواز کو کھیلنے کی طرح ہے. تصور کرو کہ تم اپنی کارکردگی کو ایک لمحے کے لئے روکتے ہیں، دھڑکنوں کی گنتی کرتے ہو، اور پھر عمل دوبارہ شروع کرتے ہو۔.
