![آواز بند کریں:](../../../media/bricks/Stop_sound_record.png)

یہ کوڈ بلاک کسی مخصوص آواز کی پلے آؤٹ روکتا ہے۔. یہ ایک گانے کے لیے اسٹاپ بٹن پر دبانے کی طرح ہے جبکہ دیگر آوازیں یا موسیقی کھیلتی رہیں۔. تصور کرو کہ تم اپنے کردار کو ایک خاص ساؤنڈ ٹریک کھیلنا بند کرنے کے لئے کہہ رہے ہیں.
