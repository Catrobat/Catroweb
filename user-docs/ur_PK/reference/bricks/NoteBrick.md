تمہارے اسکرپٹ میں ایک تبصرہ یا نوٹ شامل کرتا ہے تاکہ تمہیں یاد رکھنے میں مدد ملے کہ تمہارے کوڈ کے کون سے حصے کرتے ہو. یہ تمہارے منصوبے کی کارکردگی کو متاثر نہیں کرتا. یہ تمہارے لئے ایک چپکنے والے نوٹ چھوڑنے کی طرح ہے.
