![جب آپ اس سے ٹکرا کر اچھلیں:](../../../media/bricks/when_you_bounce_off_brick2.png)

ایک مخصوص سطح یا اعتراض سے اچھلنے پر ہونے والی رد عمل یا کارروائی کا تعین کرتا ہے۔. یہ کہنا ہے کہ کی طرح ہے، ”جب بھی میرا کردار دیوار یا کسی اور چیز سے اچھلتا ہے تو یہ عمل کرو.“
