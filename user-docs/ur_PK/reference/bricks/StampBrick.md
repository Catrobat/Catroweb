![ٹھپا لگائیں](../../../media/bricks/Stamp_.png)

اس کوڈ بلاک کا استعمال کرتے ہوئے تم اپنے کردار کی شکل کی ایک کاپی اسکرین پر چھوڑ دیتے ہیں۔. یہ کاغذ پر رنگین ٹکٹ پر چھاپے مارنے اور ٹکٹ کے ڈیزائن کی ایک کاپی چھوڑنے کی طرح ہے. اس طرح تم اپنے پس منظر کو بہتر بناتے ہیں - تم کلون نہیں بنا رہے ہیں!
