![دھاگے کا رنگ اس پر سیٹ کریں: ’#ff0000′](../../../media/bricks/Set_thread_color_to_ff0000.png)

اس بلاک کا استعمال کرتے ہوئے، تم اپنے سلائی کے منصوبے کے لئے دھاگے کا رنگ تبدیل کر سکتے ہو. رنگ تمہارے پروگرام میں دکھایا جائے گا. اس کا مطلب یہ نہیں کہ کڑھائی کی مشین پھر ان رنگوں کو استعمال کرے گی.
