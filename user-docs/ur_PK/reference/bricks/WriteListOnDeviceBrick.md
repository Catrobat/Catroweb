![فہرست ڈیوائس پر لکھیں: نیا](../../../media/bricks/Write_list_on_device_new.png)

اپنی فہرست کو اپنے آلہ پر محفوظ کرو تاکہ تم اسے بعد میں استعمال کرسکیں، یہاں تک کہ ایپ بند ہونے کے بعد بھی۔. اس کے بارے میں سوچو جیسے تم اپنی پسندیدہ ترکیبیں ڈیجیٹل باورچی خانے کی کتاب میں محفوظ کر رہے ہیں۔.
