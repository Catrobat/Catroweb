![یہاں رکھیں:](../../../media/bricks/place_at_x_y_brick.png)

اسکرین پر ایک مخصوص پوزیشن پر اعتراض کو منتقل کرتا ہے، جو ایکس اور وائی نقاط کی طرف سے بیان کیا جاتا ہے. یہ تمہارے کردار کو ایک عین مطابق جگہ پر منتقل کرنے کی طرح ہے.

پوزیشن کو کارٹیسیئن کی طرح ہم آہنگی کے نظام میں مقرر کیا جاتا ہے: ایکس اور وائی محور اسکرین کے مرکز سے گزرتے ہیں، لہذا x = 0 اور y = 0 اسکرین کا وسط ہے۔.
