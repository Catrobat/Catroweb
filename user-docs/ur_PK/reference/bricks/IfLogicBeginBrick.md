![اگر دوسری صورت میں کوڈ بلاک](../../../media/bricks/if_else_brick2.png)

*چیک کرو کہ آیا ایک شرط درست ہے، اور ہدایات کا ایک سیٹ چلاتا ہے اگر یہ ہے تو، اور ایک اور سیٹ اگر نہیں ہے. یہ دو اختیارات دینے کی طرح ہے: ”اگر یہ سچ ہے تو ایسا کرو، ورنہ ایسا کرو۔.“*

![یہ منظر شروع کریں:](../../../media/bricks/StartScene.png)

جب منظر شروع ہوتا ہے تو، متغیر X 0 پر مقرر کیا جاتا ہے.

![اگر دوسری صورت میں](../../../media/bricks/IfElse.png)

اب جانور پر ٹیپ کرو تو بلاک دیکھتا ہے کہ آیا X ماڈیولو 2 درست ہے۔ یعنی کیا X ایک طاق عدد ہے۔.

اگر ایسا ہے تو، آواز Tweet1 ادا کی جاتی ہے اور متغیر X 1 سے بڑھایا جاتا ہے.

دوسری صورت میں، اگر X برابر ہے تو، صرف X 1 سے بڑھایا جاتا ہے.

عملدرآمد کے لیے بیانات کو ایک اگر کا اختتام سے الگ کیا گیا ہے۔.
