![انتظار-تک-تمام دیگر سکرپٹ-بند کوڈ بلاک](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

اس کوڈ بلاک موجودہ سکرپٹ کو روکتا ہے جب تک کہ منصوبے میں موجود تمام دیگر سکرپٹس چلنے کے مکمل نہ ہو جاؤ۔. تصور کرو کہ تم اپنا سکرپٹ انتظار میں رکھیں جب تک باقی سب کچھ نہیں ہو جاتا۔. یہ اس بات کو یقینی بنانے کے لئے مفید ہے کہ تمہارے موجودہ سکرپٹ میں اگلے مراحل پر آگے بڑھنے سے پہلے کوئی اور کارروائی نہیں ہو رہی ہے.
