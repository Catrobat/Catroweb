![پلاٹ کرنا شروع کریں](../../../media/bricks/Start_to_plot.png)

یہ کوڈ بلاک اس عمل کا آغاز کرتا ہے جب اداکار حرکت میں آتا ہے۔. یہ خط لکھنے کے لیے قلم کو کاغذ پر ڈالنے کی طرح ہے۔. تمہیںڈ بلاک ”پلاٹ کرنا بند کریں“ استعمال کر سکتے ہو اگر تم ڈرائنگ روکنا چاہتے ہو اور اداکار کو ایک مختلف جگہ پر منتقل کرو اور پھر دوبارہ پلاٹ شروع کرو ”پلاٹ کرنا شروع کریں“.
