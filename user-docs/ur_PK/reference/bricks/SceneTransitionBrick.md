![یہ منظر جاری رکھیں:](../../../media/bricks/continue_scene_brick2.png)

یہ کوڈ بلاک اس منظر کو دوبارہ شروع کرتا ہے جہاں سے اسے روک دیا گیا تھا. اگر تمہارا منظر ایک وقفے یا انتظار کے ذریعے مداخلت کی گئی تو، اس کوڈ بلاک کا استعمال کرتے ہوئے عمل کو شروع کرے گا جہاں یہ رک گیا تھا.

تصور کرو کہ تم نے کسی کھیل یا حرکت پذیری کو روک دیا ہے، اور اب تم چاہتے ہو کہ وہ جاری رہے۔. یہ کوڈ بلاک ”چلائیں“ بٹن کی طرح کام کرتا ہے، جس سے ہر چیز کو اس مقام سے دوبارہ شروع کیا جاتا ہے جہاں اسے روک دیا گیا تھا.
