![قلم کا رنگ اس پر سیٹ کریں: o سرخ 0 سبز 0 نیلے 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

یہ کوڈ بلاک اداکار کی طرف سے استعمال قلم کا رنگ تبدیل کرتا ہے. یہ ڈرائنگ کے دوران ایک مختلف رنگ قلم پر سوئچ کرنے کی طرح ہے.

**سرخ، سبز، نیلے (RGB)**: رنگین ماڈل RGB رنگوں کی وسیع رینج پیدا کرنے کے لئے سرخ، سبز اور نیلے رنگ کی روشنی کی مختلف شدت کا استعمال کرتا ہے۔. ہر رنگ کے اجزاء (سرخ، سبز اور نیلے) کی 0 سے 255 کے درمیان قدر ہو سکتی ہے:

- **سرخ**: رنگ کا سرخ حصہ۔. ایک اعلی قیمت کا مطلب زیادہ سرخ ہے.
- **سبز**: رنگ کا سبز حصہ۔. ایک اعلی قیمت کا مطلب زیادہ سبز ہے.
- **نیلے رنگ**: رنگ کا نیلا جزو۔. ایک اعلی قیمت کا مطلب زیادہ نیلے رنگ ہے.

سرخ، سبز اور نیلے رنگ کے مختلف اقدار کو یکجا کرکے تمہیںئی بھی رنگ بنا سکتے ہیں۔. مثال کے طور پر:

- `RGB(255, 0, 0)` خالص سرخ ہے۔.
- `RGB(0, 255, 0)` خالص سبز ہے۔.
- `RGB(0, 0, 255)` خالص نیلے رنگ کا ہے۔.
- `RGB(255, 255, 255)` سفید (زیادہ سے زیادہ سرخ، سبز اور نیلے رنگ) ہے.
- `RGB(0, 0, 0)` سیاہ ہے (کوئی رنگ نہیں).

ان رنگوں کو مختلف مقدار میں ملا کر تم ڈیجیٹل اسکرینز پر دیکھے جانے والے تمام رنگ پیدا ہوتے ہیں۔.
