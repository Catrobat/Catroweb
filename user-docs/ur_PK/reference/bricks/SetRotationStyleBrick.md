![گھومنے کا انداز سیٹ کریں:](../../../media/bricks/set_rotation_style_brick2.png)

اس سے یہ تبدیل ہوتا ہے کہ اعتراض کس طرح گھومتا ہے (تمام گرد، صرف بائیں دائیں، یا گھومنے نہیں دیتا). یہ فیصلہ کرنے کی طرح ہے کہ آیا تمہارا کردار پورے راستے کو گھوم سکتا ہے، صرف بائیں اور دائیں موڑ سکتا ہے، یا بالکل بھی نہیں گھوم سکتا.
