*چیک کرتا ہے کہ آیا ایک شرط درست ہے، اور اگر یہ ہے تو، ہدایات کا ایک سیٹ چلاتا ہے. یہ کہنا کی طرح ہے، ”اگر یہ سچ ہے تو، پھر یہ کرو.“*

![یہ منظر شروع کریں:](../../../media/bricks/StartScene.png)

جب منظر شروع ہوتا ہے تو، متغیر X 0 پر مقرر کیا جاتا ہے.

![اگر](../../../media/bricks/If.png)

اگر جانور کو اب ٹاپ کیا جاتا ہے تو، متغیر X 1 سے بڑھایا جاتا ہے.

پروگرام چیک کرتا ہے کہ آیا متغیر X قدر 2 کے برابر ہے۔.

اگر یہ معاملہ ہے تو، آواز Tweet1 ادا کی جاتی ہے اور متغیر X 0 پر مقرر کیا جاتا ہے.
