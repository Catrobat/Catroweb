*اسکرپٹ کو چلانے کے بعد مقررہ قدر یا فنکشن درست ہونے تک انتظار کرتا ہے۔.*

![یہ منظر شروع کریں:](../../../media/bricks/StartScene.png)

جب منظر شروع ہوتا ہے تو، متغیر X 0 پر مقرر کیا جاتا ہے.

![جب ٹیپ کیا جائے جب Modulo](../../../media/bricks/WhenTappedWhenModulo.png)

اگر جانور کو اب ٹاپ کیا جاتا ہے تو، X 1 سے بڑھایا جاتا ہے.

جب X ماڈیول 2 سچ ہو جاتا ہے، یعنی اگر X ایک غیر معمولی تعداد ہے تو، آواز Tweet1 ادا کی جاتی ہے.
