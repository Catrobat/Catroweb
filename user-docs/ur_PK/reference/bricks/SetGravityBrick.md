![سیٹ گراوٹی کوڈ بلاک](../../../media/bricks/set-gravity-brick.png)

منصوبے میں تمام اشیاء پر لاگو شدّت کو ایڈجسٹ کرتا ہے۔. یہ اس طرح ہے کہ چیزوں کو کس طرح مضبوطی سے نیچے یا طرف کی طرف کشش ثقل کے ذریعے کھینچ لیا جاتا ہے، جس سے وہ گرنے یا منتقل ہونے کا طریقہ متاثر ہوتا ہے۔.
