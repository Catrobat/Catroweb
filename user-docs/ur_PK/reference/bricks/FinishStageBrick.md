![اختتام مرحلے کوڈ بلاک](../../../media/bricks/finish-stage-brick.png)

یہ کوڈ بلاک تمام اسکرپٹ روکتا ہے اور موجودہ مرحلے یا منظر ختم. یہ کہنے کی طرح ہے، ”اس منصوبے کا یہ حصہ ختم ہو گیا ہے.“ سب کچھ رک جاتا ہے، اور منصوبہ یا تو ایک اور منظر میں منتقل کر سکتے ہو یا مکمل طور پر ختم ہو. اس کا استعمال جب تم اپنے منصوبے کے کسی خاص مرحلے یا سطح کو ختم کرنا چاہتے ہو.
