![پلاٹ کرنا بند کریں](../../../media/bricks/Stop_to_plot.png)

”پلاٹ کرنا بند کریں“ کوڈ بلاک پلاٹنگ کے عمل کو روکتا ہے اور تمہیں ایکٹر کو کسی نئی پوزیشن میں منتقل کرنے یا پلاٹنگ ختم کرنے کی اجازت دیتا ہے۔. یہ کاغذ سے قلم اٹھاتے ہوئے اسے دوبارہ پوزیشن دینے یا ڈرائنگ بند کرنے کی طرح ہے. تمہاری منصوبہ بندی ختم ہو گیا ہے کے بعد، تمہیں ایک SVG فائل کے طور پر اپنے ڈیزائن کو محفوظ کرنے کے لئے کوڈ بلاک ”پلاٹ کو SVG فائل میں محفوظ کریں:“ استعمال کر سکتے ہو.
