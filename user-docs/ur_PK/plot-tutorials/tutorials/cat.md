جب کہانی شروع ہوتی ہے تو ہر حرکت کو قلم سے لگایا جاتا ہے۔. یہ وہ لائنیں ہیں جو سازش کرنے والے بعد میں کاٹتے ہیں۔.

ہمارا اعتراض 150 ڈگری کی سمت میں اشارہ کرتا ہے.

اس سبق میں، پہلے بلی کے سر کا دائیں طرف بنایا گیا ہے. اگر تم قریب سے دیکھو تو، یہ منحنی خطوط پہلے مضبوط ہیں، لہذا ہر چھوٹی لائن کے بعد اعتراض کو زیادہ گھومنا پڑتا ہے. پھر سر کے نیچے والے حصے میں موڑ چھوٹے ہوتے ہیں۔. سر کا بائیں حصہ پھر مضبوطی سے منحنی ہے۔. اس لیے سر کے اس حصے میں مجموعی طور پر تین لوپ ہوتے ہیں۔.

اگلا بائیں کان آتا ہے۔. یہ صرف سیدھی لائنوں سے بنا ہے، لہذا ہم کوڈ بلاک ”حرکت کریں: \_\_ قدم“ استعمال کرسکتے ہیں.

کانوں کے درمیان حصہ ایک بار پھر قوس ہے اور اسے دوسرے لوپ سے پروگرام کیا جاتا ہے۔.

پھر دائیں کان بنایا جاتا ہے.

اب پلاٹ ختم ہو گیا ہے. اسے کوڈ بلاک ”پلاٹ کرنا بند کریں“ کے ساتھ ختم کرو اور اسے اپنے فون پر ”پلاٹ کو SVG فائل میں محفوظ کریں: \_\_\_“ کے ساتھ محفوظ کرو۔.

اب تمہیں ایک (کاٹنے) plotter کے لئے فائل SVG بھیج سکتے ہیں.
