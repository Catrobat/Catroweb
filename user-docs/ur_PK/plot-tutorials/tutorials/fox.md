جب کہانی شروع ہوتی ہے تو ہر حرکت کو قلم سے لگایا جاتا ہے۔. یہ وہ لائنیں ہیں جو سازش کرنے والے بعد میں کاٹتے ہیں۔.

یہ لُوٹا صرف سیدھی لائنوں (”حرکت کریں: \_\_\_ قدم“) اور موڑ سے بنا ہے۔.

**ٹپ**: جب تم اسے بناتے ہیں تو اپنے پروگرام کی جانچ کرو۔.
