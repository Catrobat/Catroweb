اس سبق میں، تمہیں اپنے پہلے منصوبے کی تخلیق شروع کرنے کے لئے جاننے کی ضرورت ہے سب کچھ سیکھیں گے Pocket Code. ہم تمہیں ایپ ڈاؤن لوڈ کرنے، اسے کھولنے اور ایک نیا پروجیکٹ بنانے کے بارے میں قدم بہ قدم رہنمائی کرو گے.

![نیا پروگرام](../../../media/game-tutorials/New-Program.png)

یہ پہلا سبق ہے، اور تمہیں کسی پیشگی علم کی ضرورت نہیں ہے.

تو، تمہیں کیا انتظار کر رہے ہیں؟ اپنا فون پکڑو اور شروع کرو!

*یہاں تم ٹیوٹوریل کو PDF فارمیٹ میں ڈاؤن لوڈ کرسکتے ہیں:*

[نیا پروگرام](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code کی تنصیب

پہلے تمہیں اپنے آلہ پر Pocket Code ایپ انسٹال کرنے کی ضرورت ہے۔. تم Google Play Store میں ”Pocket Code“ تلاش کرکے ایپ کو تلاش کرسکتے ہیں اور اسے ”تنصیب“ پر تھپتھپاتے ہوئے ڈاؤن لوڈ کرسکتے ہیں۔. اس مرحلے کے لیے گوگل اکاؤنٹ کی ضرورت ہے۔. اب تمہارا آلہ ایپ ڈاؤن لوڈ اور انسٹال کرے گا. تمہارے انٹرنیٹ کنکشن کے مطابق یہ قدم کچھ وقت لگ سکتا ہے۔.

![نیا پروگرام (2)](../../../media/game-tutorials/New-Program-2.png)

تمہیں کامیابی سے ڈاؤن لوڈ اور انسٹال کرنے کے بعد Pocket Code تم اپنے آلہ پر منحصر ہے، ایپ ڈرائر یا ہوم اسکرین میں ایپ تلاش کر سکتے ہو. تم آسانی سے ایپ لے کر اسے جہاں چاہیں رکھ سکتے ہیں۔.

### 2. ایپ شروع کرو

جب تم ایپ کھولتے ہیں تو، تم مختلف زمرے دیکھتے ہیں:

![نیا پروگرام (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. ایک نیا پروجیکٹ بنائیں

اگلا قدم ایک نیا پروجیکٹ بنانا ہے. ایسا کرنے کے لئے، تم نیچے دائیں کونے میں پیلے رنگ کے پلس بٹن پر دباؤ. اب تمہیں ایک پروجیکٹ کا نام درج کرنا ہے اور منتخب کرو کہ آیا تمہارے منصوبے زمین کی تزئین کی ہونا چاہئے یا نہیں. ”ٹھیک ہے“ پر دبا کر پروجیکٹ پیدا کیا جاتا ہے۔.

![نیا پروگرام](../../../media/game-tutorials/New-Program.png)

### 4. تم نے اسے بنایا! تم نے اپنا نیا منصوبہ بنایا.

اب تم نے انسٹال کیا ہے Pocket Code اور جانتے ہیں کہ کس طرح ایک نیا منصوبہ بنانے کے لئے. اب تم پروگرامنگ شروع کر سکتے ہو!

اس کے لیے تمہیں جاننے کی ضرورت ہے کہ کسی پروجیکٹ میں نیا اعتراض کیسے بنایا جائے۔. **[نیا اعتراض](new-object.md)** - ٹیوٹوریل کو دیکھو، جہاں تمہیں قدم بہ قدم سب کچھ سمجھایا جاتا ہے۔.
