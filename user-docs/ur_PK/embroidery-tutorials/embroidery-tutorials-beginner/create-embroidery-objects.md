اس سبق میں تم سیکھیں گے کہ کس طرح اشیاء بنانا ہے، جس کے ساتھ تم بعد میں اپنے پیٹرن کو بنا سکتے ہیں۔.

اس سبق کے لئے، تمہیں پہلے سے ہی ایک منصوبے بنانے کا طریقہ معلوم ہونا چاہئے. اگر تمہیں کچھ مدد کی ضرورت ہو تو [سٹارٹر سیریز](../../game-tutorials/starter-tutorials/index.md) سے سبق ملاحظہ کرو۔.

مزید معلومات یا ڈیزائن کے تجاویز کے لیے دیگر سبق ملاحظہ کرو۔.

*یہاں تمہیں ٹیوٹوریل میں ڈاؤن لوڈ کر سکتے ہو PDF فارمیٹ*:

[کڑھائی کے اشیاء بنائیں](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. اپنے منصوبے کے نیچے دائیں جانب پلس بٹن پر کلک کرو ایک نیا اعتراض شامل کرنے کے لئے.

![کڑھائی کے اشیاء بنائیں](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. کسی تصویر کا انتخاب کرنے کے لیے میڈیا لائبریری میں جاؤ۔.

![کڑھائی کے اشیاء بنائیں (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. ایک کڑھائی کا اعتراض کڑھائی کی مشین کے سوئی کے ایک سطح کو ظاہر کرتا ہے۔ کئی کڑھائی کے اشیاء ایک کے بعد ایک کڑھائی کی جاؤ گی۔ اس سے متعدد رنگوں کا استعمال کرنے کا امکان پیدا ہوتا ہے۔.

تم اپنی پسند کے رنگ پر منحصر ہے کہ تم اپنے اعتراض کو منتخب کر سکتے ہو.

نیچے سکرول کرو اور مناسب تیر تلاش کرو۔.

![کڑھائی کے لیے اشیاء بنائیں (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. اپنے نئے اعتراض کو مناسب نام اور پریس ٹھیک ہے دیں۔.

![کڑھائی کے لیے اشیاء بنائیں (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. تم نے اب ایک نیا اعتراض پیدا کیا ہے. اب تمہیں ایک اسکرپٹ شامل کر سکتے ہو اور اعتراض پروگرام.

![کڑھائی کے لیے اشیاء بنائیں (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

اب تم جانتے ہیں کہ کس طرح ایک اعتراض پیدا کرنے کے لئے. ہر رنگ کے لیے ایک نیا اعتراض شامل کرو جسے تم استعمال کرنا چاہتے ہو۔.

تم ہر رنگ میں ایک اسکرپٹ شامل کر سکتے ہو اور اپنے ڈیزائن کو پروگرام کرسکتے ہیں اور بعد میں بھی اسے بنا سکتے ہیں۔.

کیا تمہیں حوصلہ افزائی یا مدد کی ضرورت ہے؟ ہمارے دیگر سبق کو دیکھو!
