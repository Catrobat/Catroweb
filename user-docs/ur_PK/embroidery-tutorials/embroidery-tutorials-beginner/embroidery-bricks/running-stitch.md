مشین مسلسل متغیر لمبائی کے ساتھ سلائی کرنے دیتا ہے.

عام طور پر تمہیں ایک حرکت کوڈ بلاک کے ساتھ چلانے سلائی کا مجموعہ.

![لمبائی 10 کے ساتھ سلائی چلانے شروع کرو](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

مشین ایک چلنے والا سلائی شروع کرے گا جو ہر **10 اقدامات** سلائی کرے گا.

پھر مشین حرکت کرتی ہے **200 قدم** ۔.

اس کے نتیجے میں **20 سلاخ**.

![سیدھا ٹانکا شروع کریں، لمبائی:](../../../../media/embroidery-tutorials/RunningStitch.png)

چلنے والی سلائی سلائی کو آسان بنا دیتی ہے کیونکہ تمہیں اب کوئی لوپ کی ضرورت نہیں ہوگی۔.
