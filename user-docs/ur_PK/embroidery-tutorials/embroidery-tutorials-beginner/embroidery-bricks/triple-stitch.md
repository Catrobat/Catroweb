تینوں چھتیں ہر چھت کو تین بار سلائی کرتی ہیں۔.

ٹرپل سائیچ پہلے سائیچ کے بعد پیچھے کودتا ہے، سائیچ کرتا ہے، پھر دوبارہ آگے بڑھتا ہے اور دوبارہ سائیچ کرتا ہے۔.

![لمبائی 10 کے ساتھ تینوں سلائی شروع کرو](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

کام کرتا ہے [چلنے والی چھڑی](running-stitch.md) کی طرح ہی.

![تہرا ٹانکا شروع کریں، لمبائی:](../../../../media/embroidery-tutorials/TripleStitch.png)

اس سے سلائی زیادہ دیر تک چلتی ہے۔.
