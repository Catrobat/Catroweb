![Ituloy ang eksena](../../../media/bricks/continue_scene_brick2.png)

Ang bloke ng code na ito ay nag-reprise ng eksena mula sa lugar kung saan ito ay nakatayo. Kung ang iyong eksena ay na-interrupt sa pamamagitan ng isang pause o maghintay, gamit ang block code na ito ay magsisimula ng aksyon sa tama kung saan ito tumigil.

Ipagpalagay mo na pinahinto mo ang isang laro o animasyon, at ngayon gusto mong magpatuloy ito. Ang block ng code na ito ay gumaganap tulad ng pindutan “I-play”, na gumagawa ng lahat ng bagay upang muling magsimula mula sa punto na iniwan nito.
