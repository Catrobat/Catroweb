![Kapag nagsimula ang eksena](../../../media/bricks/When_scene_starts_btn2.png)

Kung gamitin mo ang bloke na ito, magsisimula agad ang script kapag nagsimula ang eksena. Ang isang eksena ay simula ng iyong programa. Ang isang eksena ay isang bagong pananaw sa iyong programa kung saan maaaring maipakita ang iba pang mga elemento at maaaring mangyari ang iba't ibang pakikipag-ugnayan. Maaari kang magkaroon ng maraming eksena para sa iba't ibang yugto sa iyong programa. Halimbawa, isang eksena para sa intro, isang eksena para sa pangunahing menu, isa para sa unang antas, isa para sa ikalawang antas at iba pa. Sa mas simpleng mga programa, ang isang eksena ay sapat din, kung gayon ang simula ng iyong programa ay ang simula rin ng eksena.

Tulad ng bawat script, ang isa na ito ay nagsisimula sa isang block ng code ng kaganapan: ang kaganapan ay nagtatakda **kung kailan** ang script ay nagsisimula, ang code ay nasisira pagkatapos sabihin nito sa programa **ano** upang gawin.
