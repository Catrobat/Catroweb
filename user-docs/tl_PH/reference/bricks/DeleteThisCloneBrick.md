![I-delete ang clone na ito](../../../media/bricks/delete_clone_brick2.png)

Ang block ng code na ito ay nagtatanggal ng clone na nilikha sa block ng code “Gumawa ng clone ng”. Ito ay tulad ng pagsasabi, “I-exclude ang duplikat na ito.” Gamitin ito upang pamahalaan at kontrolin ang bilang ng mga klones sa iyong proyekto, tiyaking sila ay tinanggal kapag hindi na nila kailangan.
