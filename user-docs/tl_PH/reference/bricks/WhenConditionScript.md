*Naghintay hanggang sa ang tinukoy na halaga o function ay maging totoo at pagkatapos ay magpatupad ng script.*

![Simulan ang eksena](../../../media/bricks/StartScene.png)

Kapag nagsimula ang eksena, ang variable X ay isetel sa 0.

![Kapag na-tap Kapag Modulo](../../../media/bricks/WhenTappedWhenModulo.png)

Kung ang hayop ay ngayon tap, X ay inkrementado sa 1.

Kapag X modulo 2 ay nagiging totoo, iyon ay, kung X ay isang odd na numero, ang tunog Tweet1 ay pinalalaro.
