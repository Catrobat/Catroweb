![Itakda ang kulay ng sinulid sa ’#ff0000′](../../../media/bricks/Set_thread_color_to_ff0000.png)

Sa pamamagitan ng paggamit ng bloke na ito, maaari mong baguhin ang kulay ng thread para sa iyong proyekto sa pag-stitch. Ang kulay ay ipapakita sa iyong programa. Hindi nangangahulugan ito na ang makina ng pag-uukit ay gagamitin sa gayon ang eksaktong kulay.
