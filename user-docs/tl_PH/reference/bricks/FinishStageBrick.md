Ang block ng code na ito ay nagtatapos sa lahat ng mga script at nagtatapos sa kasalukuyang yugto o eksena. Ito ay tulad ng pagsasabi, “Ang bahagi na ito ng proyekto ay tapos na.” Ang lahat ay tumigil, at ang proyekto ay maaaring magpatuloy sa ibang eksena o matapos na ganap. Gamitin ito kapag nais mong tapusin ang isang partikular na yugto o antas sa iyong proyekto.
