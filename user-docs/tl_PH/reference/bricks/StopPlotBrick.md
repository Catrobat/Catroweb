![Ihinto ang pag-plot](../../../media/bricks/Stop_to_plot.png)

Ang “Ihinto ang pag-plot” code block ay nagpigil sa proseso ng pag-plotting at nagbibigay-daan sa iyo na ilipat ang aktor sa isang bagong posisyon o tapusin ang pag-plotting. Para bang mag-alis ng isang puler sa papel upang muling isama ito o huminto sa pagguhit. Pagkatapos mo matapos ang pag-plotting, maaari mong gamitin ang “I-save ang plot bilang SVG” code block upang i-save ang iyong disenyo bilang isang SVG file.
