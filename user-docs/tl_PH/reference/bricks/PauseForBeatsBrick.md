Ang block ng code na ito ay gumagawa ng script upang maghintay para sa isang tiyak na bilang ng mga beat bago ituloy. Para bang magpahinga ng isang kanta bago maglaro ng susunod na nota o tunog. Isipin mo na pawisin mo ang iyong pagganap sa sandali, i-count ang mga beat, at pagkatapos ay muling magsagawa.
