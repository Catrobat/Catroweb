Naglipat ng bagay sa isang tiyak na posisyon sa screen, tinukoy sa pamamagitan ng mga koordinata ng x at y. Para bang teleport mo ang character mo sa eksaktong lugar.

Ang posisyon ay itinatag sa isang sistema ng koordinate tulad ng plano ni Cartesian: ang x at y axes ay lumilipat sa gitna ng screen, kaya x = 0 at y = 0 ay ang gitna ng screen.
