![Simulan ang pag-plot](../../../media/bricks/Start_to_plot.png)

Ang bloke ng code na ito ay nagsisimula sa proseso ng pag-plot habang nagmamaneho ang aktor. Ito'y katulad ng paglalagay ng isang pulong sa papel upang simulan ang pag-draw ng linya. Maaari mong gamitin ang “Ihinto ang pag-plot” code block kung nais mong pause ang drawing at ilipat ang aktor sa isang ibang lugar at pagkatapos ay muli simulan ang plot na may “Simulan ang pag-plot”.
