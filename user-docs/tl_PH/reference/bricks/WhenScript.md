Naglalaro ng script kapag ang bagay ay taped.

Ang pagkakaiba sa bloke *“Kapag na-tap ang entablado”* ay na ang *“Kapag na-tap”* ay partikular sa mga indibidwal na sprite o bagay, habang ang *“Kapag na-tap ang entablado”* ay may kaugnayan sa buong screen.
