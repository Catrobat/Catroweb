![Para sa bawat value mula sa](../../../media/bricks/for-each-value_brick.png)

Ang block ng code na ito ay naglalayong isang hanay ng mga tagubilin para sa bawat item sa isang listahan o range. Para bang mag-aralan ng bawat item at gawin ang parehong aksyon sa bawat isa.

Ipagpalagay mo na mayroon kang listahan ng mga numero, kulay, o anumang bagay. Pinapayagan ka ng bloke ng code na ito na kumuha ng bawat item mula sa listahan at gumawa ng isang bagay gamit ito. Halimbawa, kung mayroon kang isang listahan ng mga kulay at nais mong baguhin ang kulay sa background sa bawat kulay sa listahan, gagamitin mo ang block na ito.

Ito ay tulad ng pagsasabing, “Para sa bawat item sa grupo na ito, gawin ang mga tagubilin na ito.”
