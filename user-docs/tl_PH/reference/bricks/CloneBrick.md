Ang bloke ng code na ito ay gumagawa ng kopya ng itinakda na bagay, na tinatawag na isang klon, na kumikilos tulad ng orihinal. Isipin na nag- duplicate ka ng isang character o bagay sa iyong laro. Ang klon ay maaaring magkaroon ng sariling mga pag-uugali at script, na nagpapahintulot sa iyo na lumikha ng maraming mga instansya ng isang bagay na maaaring kumikilos nang malaya.
