*Sinuri kung ang isang kondisyon ay totoo, at tumatakbo sa isang hanay ng mga tagubilin kung ito ay, at isa pang hanay kung hindi. Ito ay tulad ng pagbibigay ng dalawang pagpipilian: “Kung totoo ito, gawin mo ito; kung hindi, gawin mo iyon.”*

![Simulan ang eksena](../../../media/bricks/StartScene.png)

Kapag nagsimula ang eksena, ang variable X ay isetel sa 0.

![Kung Iba](../../../media/bricks/IfElse.png)

Kapag tinapik mo ang hayop, susuriin ng bloke kung totoo ang X modulo 2. Ibig sabihin, susuriin nito kung odd na numero ang X.

Kung ito ang kaso, ang tunog Tweet1 ay ipinapalabas at ang variable X ay pinalaki ng 1.

Kung hindi, kung X ay pares, lamang X ay pinalaki ng 1.

Ang mga pahayag na dapat ipatupad ay hiwalay ng isang Katapusan ng kung.
