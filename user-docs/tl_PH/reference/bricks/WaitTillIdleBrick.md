![maghintay- hanggang sa lahat ng iba pang mga script-stop code block](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Ang block ng code na ito ay nag-pause sa kasalukuyang script hanggang matapos ang lahat ng iba pang mga script sa proyekto. Isipin na mag-iwan ng script mo hanggang sa tapos ang lahat. Ito ay kapaki-pakinabang upang matiyak na walang iba pang mga aksyon na nangyayari bago magpatuloy sa susunod na hakbang sa iyong kasalukuyang script.
