Ang block ng code na ito ay nagbabago ng kulay ng pen na ginamit ng aktor. Para bang mag-switch sa ibang kulay na pen habang naglulukis.

**Pula, Buhay, Asul (RGB)**: Ang modelo ng kulay RGB ay gumagamit ng iba't ibang intensidad ng pulang, berde, at asul na liwanag upang lumikha ng isang malawak na spektrum ng mga kulay. Ang bawat bahagi ng kulay (mamaring, berde, at asul) ay maaaring magkaroon ng isang halaga sa pagitan ng 0 at 255:

- **Pula**: Ang pula na bahagi ng kulay. Ang mas mataas na halaga ay nangangahulugang higit pang pula.
- **Lumalas**: Ang berde na bahagi ng kulay. Ang mas mataas na halaga ay nangangahulugang mas berde.
- **Lumalaw**: Ang kulay ng asul. Ang mas mataas na halaga ay nangangahulugang higit pang asul.

Sa pamamagitan ng pagsasama ng iba't ibang mga halaga para sa pulang, berde, at asul, maaari mong lumikha ng anumang kulay. Halimbawa:

- `RGB(255, 0, 0)` ay purong pula.
- `RGB(0, 255, 0)` ay purong berde.
- `RGB(0, 0, 255)` ay purong asul.
- `RGB(255, 255, 255)` ay puti (mahigit na pulang, berde, at asul).
- `RGB(0, 0, 0)` ay itim (walang kulay).

Ang pag-aalinlangan ng mga kulay na ito sa iba't ibang halaga ay lumilikha ng lahat ng mga kulay na nakikita mo sa digital na screen.
