Mag-stitch nang patuloy sa isang variable na haba at lapad.

Mag-stitch sa isang pattern ng 'zigzag'.

![Magsimula ng zigzag stitch sa haba 2 at lapad 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

Subukan ang iba't ibang mga halaga para sa haba at lapad upang malaman ang block ng code na ito.

![Simulan ang zigzag stitch na may haba na](../../../../media/embroidery-tutorials/ZigzagStitch.png)
