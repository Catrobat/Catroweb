Sa Tutorial na ito matututunan mo ang lahat ng kailangan mong malaman tungkol sa mga bloke ng code ng Embroidery!

Hindi mo kailangan ng anumang kaalaman sa pag-program para dito.

Ang bawat bloke ng code ng Embroidery ay ipaliwanag sa pamamagitan ng isang halimbawa.

Kung hindi mo pa pinapatupad ang mga bloke ng code ng Embroidery, tingnan ang tutorial **[I-activate ang mga block ng code ng Embroidery](../activate-embroidery-bricks.md)**.

*Dito maaari mong i-download ang tutorial sa PDF -format*:

[Mga bloke ng code sa pagsusuot](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Mag-click sa iba't ibang mga bloke ng code upang malaman ang higit pa tungkol dito:**

[![Tumahi](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*Hayaan ang makina na mag-sewing sa tela minsan!*

[![Magsimula sa pag-andar ng stitch na may haba 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*Hayaan ang makina na mag-stitch nang patuloy sa isang variable length.*

[![Magsimula ng zigzag stitch sa haba 2 at lapad 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Mag-stitch nang patuloy sa isang variable na haba at lapad.*

[![Magsimula ng triple stitch sa haba 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*Ang triple stitch ay nag-uutos ng bawat stitch tatlong beses.*

[![Ihinto ang kasalukuyang tahi](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Hayaan ang kasalukuyang pag-aayos na tumigil.*

Maaari mong mahanap ang higit pang mga bloke ng code ng Embroidery at impormasyon tungkol sa kanila [dito](../../../../reference/#category_embroidery).

Para sa karagdagang impormasyon o mga suhestiyon para sa disenyo, tingnan ang iba pang mga tutorial!
