Sa Tutorial na ito, ipaliwanag ang pag-activate ng mga block ng code ng Embroidery.

![I-activate ang Embroidery-Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Hindi mo kailangan ng anumang kaalaman sa pag-program para dito. Ito ang unang hakbang upang simulan ang mga tutorial sa pagsusuot. Pagkatapos, maaari mong mag-design, mag-program, at maging mag-embroider ng iyong sariling mga disenyo sa iyong paboritong piraso ng tela.

Para sa karagdagang impormasyon o mga suhestiyon para sa disenyo, tingnan ang iba pang mga tutorial.

*Dito maaari mong i-download ang tutorial sa PDF -format*:

[I-activate ang mga brick ng pagbubukod](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Magsimula ng “Pocket Code”-App. Sundin ang mga pag-click!

### 2. Buksan ang menu (mga dot sa kanang tuktok).

![I-activate ang mga block ng code ng Embroidery](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Pumunta sa “Mga Setting”.

![I-activate ang Embroidery-Bricks3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Pumili ng “Extension para sa pagbuburda”.

![I-activate ang Embroidery-Bricks4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Makikita mo ang mga bloke ng code ng Embroidery bilang isang sariling kategorya sa loob ng iyong mga bloke ng code!

[![I-activate ang Embroidery-Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Ngayon makikita mo rin ang lahat ng mga bloke ng code ng embroidery sa gitna ng iba pang block ng code.

Para sa karagdagang impormasyon tungkol sa bawat bloke ng code, mag-ingat na suriin ang dokumentasyon ng mga block ng code [dito](../../../reference/) o sundin ang **[Mga bloke ng code sa pagsusuot](embroidery-bricks/index.md)**- Tutorial para sa iyon.

Ngayon ay maaari kang magsimula at lumikha ng iyong sariling mga disenyo!

Kung kailangan mo ng mga ideya o tulong sa iyon, tingnan ang iba pang mga tutorial o magpatuloy sa **[Gumawa ng mga bagay na mag-embroidery](create-embroidery-objects.md)**-tutorial.
