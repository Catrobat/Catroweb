Sa tutorial na ito, matututunan mo kung paano mag-embroider ng isang rainbow (112 x 57.2mm).

![Regenbogen](../../../media/embroidery-tutorials/Regenbogen.webp)

Dapat mong alam na ang isang loop ay ano at kung paano ito gumagana.

Ang **[Semicircle](../embroidery-tutorials-beginner/semicircle.md)**-tutorial ay maaaring makatulong sa tutorial na ito.

Tingnan ang mga tutorial sa pagpapalagay sa serye [Mga nagsisimula](../embroidery-tutorials-beginner/index.md) kung wala ka pa nang naka-embroider.

Para sa karagdagang impormasyon o mga suhestiyon para sa disenyo, tingnan ang iba pang mga tutorial.

*Dito maaari mong i-download ang tutorial sa PDF -format*:

[Rainbow](../../../media/embroidery-tutorials/Rainbow.pdf)

### 1. Gumawa ng isang bagong bagay sa pagsusuot (tingnan ang [Gumawa ng mga bagay na mag-embroidery](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![Rainbow](../../../media/embroidery-tutorials/Rainbow.png)

### 2. I-insert ang sumusunod na script:

![Rainbow (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. I-copy ang Object

Para sa susunod na mas malaking arco, maaari mo lamang i-copy ang bagay na iyong nilikha.

I-click ang tatlong dot sa kanang tuktok ng pangkalahatang-ideya ng bagay.

Pagkatapos pumunta sa “Kopyahin” at piliin ang bagay.

![Regenbogen (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Kung gagamitin mo ang isang hiwalay na bagay para sa bawat arko, maaari mong mag-embroider ng mga ito sa ibang kulay.

### 4. I-adapte ang Object

Upang matiyak na ang mga arches ay iba't ibang sukat ngayon, kailangan nating baguhin ang ilang halaga.

Upang gawin ito, pumunta sa script ng kopya na bagay at ayusin ang mga sumusunod na halaga:

![Rainbow (2)](../../../media/embroidery-tutorials/Rainbow-2.png)

### 5. Ulitin ang hakbang 3 at 4 para sa higit pang mga arko!
