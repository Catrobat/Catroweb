Pocket Code ay ang pangunahing app mula sa Catrobat, isang libreng at open-source mobile app na nagbibigay-daan sa iyo upang lumikha ng mga laro, animasyon, at interactive na kuwento sa iyong smartphone o tablet. Sa **sistema ng pag-code na batay sa block** sa Pocket Code, maaari kang bumuo ng mga proyekto sa pamamagitan ng pag-sniping ng code blocks - tulad ng pagbuo ng mga piraso ng isang puzzle. Walang kinalaman sa pag-program, kaya ito'y perpekto para sa mga nagsisimula!

Pocket Code ay higit pa sa mga digital lamang na proyekto. Sa bagong **mga tampok ng makerspace**, maaari mo ring disenyo **SVG mga file para sa pag-aakyat ng plots**. Nangangahulugan ito na maaari mong ilipat ang iyong mga digital na paglikha sa mga bagay ng totoong mundo at suriin ang mga posibleng malikhalik sa labas ng screen.

Kung ikaw ay natututo sa pag-code, pagsusubok sa mga bagong ideya, o pagtuturo ng pag-programming, ang Pocket Code ay nagbibigay ng isang maligayang, madaling gamitin na paraan upang dalhin sa pag-code
