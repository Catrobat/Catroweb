Buksan ang app sa iyong smartphone o tablet. I-tap ang + simbolo upang lumikha ng isang bagong proyekto.

![Main Screen Bagong Proyekto](../../../media/getting-started/MainScreen_NewProject.png)

Bigyan ng pangalan ang proyekto (1). Piliin kung patayo (portrait) o pahiga (landscape) ang laro (2). Pagkatapos, pindutin ang tsek para kumpirmahin (3).

![Bagong Proyekto](../../../media/getting-started/NewProject.png)

Ikaw ay nasa iyong proyekto view ngayon. Sa tuktok, makikita mo ang pangalan ng iyong laro.

Sa ibaba makikita mo ang **Background** - sa kasalukuyan, ang background ay walang laman. Kung gusto mo itong baguhin, mag-tap ka dito.

Sa ilalim ng background, makikita mo ang lugar para sa iyong **mga aktor at bagay** na iyong idinagdag sa iyong laro. Sa kasalukuyan, walang tao sa lugar.

Sa kanang bahagi ng ibaba, makikita mo ang dalawang mahalagang pindutan:

![Magsimula](../../../media/getting-started/Start.png) Sa pindutan ng **I-play**, simulan mo ang iyong laro.

![Plus Button](../../../media/getting-started/Screenshot-2024-11-22-143219.png) Sa pamamagitan ng pindutan **At higit pa**, nagdaragdag ka ng isang bagong character/object sa iyong laro.
