Pocket Code ay isang visual programming app na nagbibigay-daan sa iyo upang lumikha ng mga laro, animasyon, at interactive na kuwento nang direkta sa iyong smartphone o tablet. Gamit ang isang intuitibong drag-and-drop interface na may “mga bloke ng code” (code blocks), maaari mong disenyo ang iyong mga proyekto nang walang nakaraang karanasan sa pagprograma. Madali na magdagdag ng mga tunog, imahe, at paggalaw upang maging buhay ang iyong mga ideya.

Matutulungan ka ng gabay na ito sa pagsisimula sa pamamagitan ng pagpapaliwanag kung paano:

- Mag-navigate sa interface,
- Gumawa ng iyong unang proyekto,
- Gawin sa mga bagay at background,
- Gamitin ang mga block ng code upang i-program ang mga aksyon, at
- I-save ang iyong proyekto.

Perpektong para sa mga nagsisimula at tagapagturo, Pocket Code ay nagsasagisagis sa pagkamalikhain, paglutas ng problema, at lohikal na pag-iisip.
