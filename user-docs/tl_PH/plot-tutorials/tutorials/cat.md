Kapag nagsimula ang plot, ang bawat paggalaw ay inilalarawan na parang may isang pulong. Ito ang mga linya na pinatatakbo ng tagapag-aalsa sa huli.

Ang ating bagay ay tumutukoy sa direksyon ng 150 degrees.

Sa tutorial na ito, ang kanang bahagi ng ulo ng pusa ay ginawa muna. Kung tumingin ka nang mabuti, ang curve ay malakas sa una, kaya dapat na mag-ikot ng bagay pagkatapos ng bawat maliit na linya. Pagkatapos ay nagiging mas maliit ang mga pakikipagsapalaran sa ilalim ng ulo. Ang kaliwang bahagi ng ulo ay malakas na nakulong muli. Kaya ang bahagi ng ulo na ito ay gumagamit ng tatlong loop sa kabuuan.

Pagkatapos ay ang kaliwang tainga. Ito ay binubuo lamang ng mga tuwid na linya, kaya maaari naming gamitin ang code block “Gumalaw nang \_\_ hakbang”.

Ang bahagi sa pagitan ng mga tainga ay isang arko muli at nag-program gamit ang isa pang loop.

Pagkatapos ay ginawa ang kanang tainga.

Natapos na ang komplot. I-end ito sa code block “Ihinto ang pag-plot” at i-save ito sa iyong telepono sa “I-save ang plot bilang SVG \_\_\_”.

Maaari mo na ngayon ipadala ang file SVG sa isang (cutting) plotter.
