Sa tutorial na ito, matututunan mo kung paano lumikha ng isang bagong bagay sa iyong proyekto at ang iba't ibang mga posibilidad na mayroon kang para dito.

![Bagong Objekto](../../../media/game-tutorials/New-Object.png)

Upang gawin ito, dapat mong mai-download na ang Pocket Code app at malaman kung paano lumikha ng isang bagong proyekto. Kung kailangan mo ng tulong sa bagay na ito, mag-ingat kang tingnan ang tutorial **[Bagong Proyekto](new-project.md)**.

*Dito maaari mong i-download ang tutorial sa PDF -format:*

[Bagong Objekto](../../../media/game-tutorials/New-Object.pdf)

### 1. Maglikha ng Bagong Object

Sa una, kailangan mong buksan ang iyong bagong proyekto.

Makikita mo ito sa home screen ng Pocket Code app. Kung mayroon kang higit sa isang proyekto, maaari mong i-click ang “Mga proyekto”. Pagkatapos ay piliin ang iyong bagong proyekto. Kung hindi mo pa nilikha ang isang bagong proyekto o kailangan ng karagdagang impormasyon kung paano ito gawin, tingnan ang tutorial **[Bagong Proyekto](new-project.md)**.

### 2. Maglikha ng Bagong Object

Ngayon handa ka na gumawa ng isang bagong bagay. Upang gawin iyon, i-click lamang ang yellow plus button sa kanang sulok ng ibaba. Makikita mo ang isang bagong bintana na nagbibigay sa iyo ng pitong posibilidad upang pumili.

![Bagong Object (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. Mga Paan ng Paglikha

Ito ang mga posibilidad na maaari mong piliin:

![Bagong Object (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. I-draw Image

Upang gawin ito pinaka-madali para sa simula, nais naming gamitin ang “Gumuhit” function at lamang magsuyat ng isang dot. Kapag ikaw ay drawn ang dot sa Pocket Paint maaari mong i-stop ito (sa pamamagitan ng pagpunta isang hakbang pabalik).

### 5. Magbigay ng pangalan

Ngayon kailangan mong bigyan ng pangalan ang iyong larawan.

### 6. I-install ito

Pagkatapos nito kailangan mong ilagay ito sa visual na paraan sa pamamagitan ng paglilipat nito sa kaliwa/haking o up/down sa iyong daliri. Kailangan mong i-save ito sa pindutan sa kanang tuktok ng itaas.

![Bagong Object (3)](../../../media/game-tutorials/New-Object-3.png)

::brick{type=PlaceAtBrick}

### 7. Naglikha ka ng iyong sariling bagong bagay.

Ngayon mayroon kang isang proyekto na may isang bagay na maaari mong i-program!

Upang gawin ito, dapat mong malaman kung anong mga block ng code ang magagamit. Ang **[Unang mga block ng code](first-bricks.md)**-tutorial ay nagbibigay sa iyo ng isang mahusay na pangkalahatang ideya ng iba't ibang mga kategorya ng code blocks. Gayunman, maaari mo ring magsimula nang direkta sa iyong unang proyekto. Pumili ng isang angkop na tutorial mula sa serye ng Mga Nagsimula.
