Sa tutorial na ito, matututunan mo ang lahat ng kailangan mong malaman tungkol sa Pocket Code upang simulan ang paglikha ng iyong unang proyekto. Gagawin namin ang hakbang-hakbang na pag-aalaga sa iyo kung paano mag-download ng app, buksan ito, at lumikha ng isang bagong proyekto.

![Bagong Programa](../../../media/game-tutorials/New-Program.png)

Ito ang unang tutorial, at hindi mo kailangan ng anumang advance knowledge.

Kaya, ano ang hinihintay mo? Kunin ang iyong telepono at magsimula ngayon!

*Dito maaari mong i-download ang tutorial sa PDF -format:*

[Bagong Programa](../../../media/game-tutorials/New-Program.pdf)

### 1. Pag-install ng Pocket Code

Sa simula, kailangan mong mag-install ng Pocket Code app sa iyong aparato. Maaari mong mahanap ang app sa pamamagitan ng paghahanap “Pocket Code” sa Google Play Store at i-download ito sa pamamagitan ng pagtukoy “pag-install”. Para sa hakbang na ito ay kinakailangan ang isang Google Account. Ngayon ang iyong aparato ay mag-download at mag-install ng app. Maaaring tumagal ng ilang sandali ang hakbang na ito depende sa iyong koneksyon sa internet.

![Bagong Programa (2)](../../../media/game-tutorials/New-Program-2.png)

Pagkatapos matagumpay na i-download at i-install Pocket Code maaari mong mahanap ang app sa drawer ng app o sa iyong home screen, depende sa iyong aparato. Maaari mong madaling kumuha ng app at ilagay ito sa kahit saan mo gusto.

### 3. Maglikha ng isang bagong proyekto

Ang susunod na hakbang ay talagang lumikha ng isang bagong proyekto. Upang gawin iyon, maaari mong pindutin ang bulaklak na plus-button sa kanang sulok ng ibaba. Ngayon kailangan mong mag-type ng pangalan ng proyekto at piliin kung ang iyong proyekto ay dapat na landasye o hindi. Sa pamamagitan ng pag-press “OK” ang proyekto ay nilikha.

![Bagong Programa](../../../media/game-tutorials/New-Program.png)

### 4. Nagtayo ka ng iyong sariling bagong proyekto.

Ngayon mayroon kang naka-install Pocket Code at alam kung paano lumikha ng isang bagong proyekto. Ngayon maaari mong simulan ang pag-program!

Upang gawin ito, kailangan mong malaman kung paano lumikha ng isang bagong bagay sa isang proyekto. Tingnan ang tutorial **[Bagong Objekto](new-object.md)** - kung saan ipaliwanag sa iyo ang lahat ng bagay hakbang-hakbang.
