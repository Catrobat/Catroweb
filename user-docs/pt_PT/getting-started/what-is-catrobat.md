A Catrobat é uma **linguagem de programação visual** gratuita e de código aberto, criada para ajudar qualquer pessoa, desde principiantes até utilizadores avançados, a criar os seus próprios jogos, animações e histórias interativas diretamente nos seus dispositivos móveis. Baseada numa interface de programação **por blocos** simples, a Catrobat usa blocos de código que podes arrastar e largar facilmente para construir os teus projetos passo a passo, sem ser preciso experiência prévia!

Com a aplicação principal da Catrobat, o **Pocket Code**, podes criar projetos digitais que vão além do ecrã: para além dos projetos de programação tradicionais, a Catrobat também apoia a criatividade dos espaços makerspace, permitindo-te criar **ficheiros DST para máquinas de bordar** e **ficheiros SVG para plotters de corte**. Isto significa que podes dar vida aos teus desenhos digitais em tecido e noutros materiais físicos!

Sejas estudante, entusiasta ou educador, a Catrobat oferece uma forma divertida e prática de explorar a programação, a resolução de problemas e a fabricação digital.
