O Pocket Code é a aplicação principal da Catrobat, uma aplicação móvel gratuita e de código aberto que te permite criar jogos, animações e histórias interativas diretamente no teu telemóvel ou tablet. Com o sistema de programação **por blocos** do Pocket Code, podes construir projetos juntando blocos de código, como peças de um puzzle. Não é preciso experiência em programação, o que o torna perfeito para principiantes!

O Pocket Code vai além dos projetos digitais. Com as novas funcionalidades de **makerspace**, também podes desenhar **ficheiros SVG para plotters de corte**. Isto significa que podes transformar as tuas criações digitais em objetos do mundo real e explorar possibilidades criativas para lá do ecrã.

Quer estejas a aprender a programar, a experimentar ideias novas ou a ensinar programação, o Pocket Code oferece uma forma divertida e acessível de mergulhar na programação.

[Mais informações](https://catrobat.org/pocket-code/)
