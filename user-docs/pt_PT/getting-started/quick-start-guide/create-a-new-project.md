Abre a aplicação no teu telemóvel ou tablet. Carrega no símbolo de mais para criar um projeto novo.

![MainScreen_NewProject](../../../media/getting-started/MainScreen_NewProject.png)

Dá um nome ao projeto (1) e decide se queres criar um jogo em formato vertical (retrato) ou horizontal (paisagem) (2). Depois confirma com o visto (3).

![NewProject](../../../media/getting-started/NewProject.png)

Agora estás na vista do teu projeto. No topo, vês o nome do teu jogo.

Por baixo, vês o **fundo** — neste momento, o fundo está vazio. Se o quiseres mudar, carrega nele.

Por baixo do fundo, vês a área dos teus **atores e objetos** que adicionaste ao teu jogo. Neste momento, a área ainda está vazia.

No canto inferior direito, vês dois botões importantes:

![Início](../../../media/getting-started/Start.png) Com o botão **Play**, começas o teu jogo.

![Botão de mais](../../../media/getting-started/Screenshot-2024-11-22-143219.png) Com o botão **Mais**, adicionas um novo personagem/objeto ao teu jogo.
