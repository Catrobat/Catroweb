O Pocket Code é uma aplicação de programação visual que te permite criar jogos, animações e histórias interativas diretamente no teu telemóvel ou tablet. Com uma interface intuitiva de arrastar e largar com “blocos” (blocos de código), podes criar os teus projetos sem experiência prévia em programação. Adiciona facilmente sons, imagens e movimento para dar vida às tuas ideias.

Este guia vai ajudar-te a começar, explicando como:

- Navegar na interface,
- Criar o teu primeiro projeto,
- Trabalhar com objetos e fundos,
- Usar blocos para programar ações, e
- Guardar o teu projeto.

Perfeito para principiantes e educadores, o Pocket Code incentiva a criatividade, a resolução de problemas e o pensamento lógico.
