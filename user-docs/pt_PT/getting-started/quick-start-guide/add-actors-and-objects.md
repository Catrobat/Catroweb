No Pocket Code, podes adicionar uma personagem ou um objeto ao teu projeto de várias formas:

**Desenhar**: Podes criar a tua própria personagem com o **Pocket Paint**. O Pocket Paint é um programa de desenho ([mais sobre o Pocket Paint](https://catrobat.org/pocket-paint/))

**Aparências**: Escolhe uma entre uma coleção de atores e objetos pré-feitos ([mais sobre a biblioteca de multimédia](../elements/medialibrary.md)).

**Galeria**: Podes escolher uma imagem da galeria do teu telemóvel.

**Biblioteca**: Na biblioteca, encontras atores e objetos que já estão programados, ou seja, já têm um script. Podes selecioná-los se quiseres usar elementos prontos no teu jogo (por exemplo, uma contagem decrescente) ([mais sobre a biblioteca](../elements/medialibrary.md#adicionar-um-objeto-a-partir-da-biblioteca-de-multimédia)).

**Câmara**: Podes usar a câmara do teu dispositivo para tirar uma fotografia e adicioná-la como personagem.

**Mochila**: A mochila está, neste momento, vazia. Podes reutilizar atores ou objetos que guardaste na tua mochila. O script inteiro é desempacotado com eles ([mais sobre a mochila](../elements/backpack.md)).

**Atores e objetos locais**: Aqui encontras personagens pré-feitas que podes usar no teu projeto. Os atores e objetos locais funcionam como uma biblioteca de multimédia offline, ou seja, mesmo sem ligação à internet, podes aceder a estes atores.

**Objeto vazio**: Adiciona um objeto vazio, que é um objeto sem aparência. Podes programar este objeto normalmente.

**Projetos locais**: Seleciona um projeto do qual queres inserir o primeiro ator, juntamente com o script, no teu projeto.
