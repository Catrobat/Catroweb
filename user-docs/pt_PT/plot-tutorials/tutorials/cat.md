Quando o plot começa, cada movimento é desenhado como se fosse com uma caneta. Estas são as linhas que o plotter vai cortar mais tarde.

O nosso objeto aponta na direção de 150 graus.

Neste tutorial, a parte direita da cabeça do gato é feita primeiro. Se olhares com atenção, a curva é forte no início, por isso o objeto tem de virar mais depois de cada pequena linha. Depois, as voltas ficam mais pequenas na parte inferior da cabeça. O lado esquerdo da cabeça volta a ter uma curva forte. Por isso, esta parte da cabeça usa três ciclos ao todo.

Depois vem a orelha esquerda. É feita apenas de linhas retas, por isso podemos usar o bloco “Mover \_\_ passos”.

A parte entre as orelhas é outra vez um arco e é programada com outro ciclo.

Depois faz-se a orelha direita.

O plot está agora terminado. Acaba-o com o bloco “Parar de desenhar com o plotter” e guarda-o no teu telemóvel com “Guardar desenho do plotter como SVG \_\_\_”.

Agora podes enviar o ficheiro SVG para um plotter (de corte).
