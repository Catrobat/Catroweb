Quando o plot começa, cada movimento é desenhado como se fosse com uma caneta. Estas são as linhas que o plotter vai cortar mais tarde.

Esta estrela tem 6 pontas. Uma ponta é uma linha reta (“Mover 100 passos”), uma volta e outra linha reta que termina a forma da ponta. Antes da ponta seguinte, tens de rodar no sentido oposto, para que a ponta seguinte fique bem.

***Nota**: Um círculo completo tem 360°. Em cada ponta rodamos 100° para a direita e 40° para a esquerda, o que dá 60° para a direita no total.*

*Para as seis pontas, obtemos uma rotação de 360° para a direita.*

**Vai mais longe**: Experimenta combinações diferentes de voltas e muda o número de pontas.
