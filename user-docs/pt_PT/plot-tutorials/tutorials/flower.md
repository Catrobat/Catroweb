Quando o plot começa, cada movimento é desenhado como se fosse com uma caneta. Estas são as linhas que o plotter vai cortar mais tarde.

Esta flor tem 7 pétalas. Cada pétala é um arco: desenhas uma linha muito pequena, rodas, desenhas outra linha muito pequena e voltas a rodar (vê o ciclo “Repetir 10 vezes” – “Mover 10 passos” – “Virar à direita 16 graus”).

Antes de começar a pétala seguinte, tens de rodar mais uma vez.
