Neste tutorial, vais aprender a partilhar os teus projetos com os teus amigos ou com toda a comunidade Catrobat.

![Carregar e partilhar](../../../media/game-tutorials/Upload-and-Share.png)\
Neste tutorial, vais aprender a partilhar os teus projetos com os teus amigos ou com toda a comunidade Catrobat.\
[Abrir imagem](../../../media/game-tutorials/Upload-and-Share.png)

Para este tutorial, já precisas de ter o teu próprio projeto que queres partilhar. Se ainda não sabes criar um projeto, vê o tutorial **[Projeto novo](new-project.md)** para aprender como funciona.

*Aqui podes descarregar o tutorial em formato PDF:*

[Abrir PDF](../../../media/game-tutorials/Upload-and-Share.pdf)

### 1. Opções do projeto

![Carregar e partilhar](../../../media/game-tutorials/Upload-and-Share.png)\
Se quiseres carregar ou partilhar o teu projeto, tens de abrir o teu projeto, depois carregar nos três pontos no canto superior direito e, em seguida, carregar em “Opções do projeto”.\
[Abrir imagem](../../../media/game-tutorials/Upload-and-Share.png)

### 2. Opções do projeto

Agora podes mudar o nome, adicionar uma descrição e fazer várias definições.

![Carregar e partilhar (1)](../../../media/game-tutorials/Upload-and-Share-1.png)\
Tens também duas opções: “Carregar programa” e “Exportar projeto”, que são explicadas nos passos seguintes.\
[Abrir imagem](../../../media/game-tutorials/Upload-and-Share-1.png)

### 3. Carregar programa

Se quiseres carregar o teu projeto para a Partilha Catrobat, para que toda a comunidade tenha acesso, escolhe *Carregar programa*.

### 4. Carregar programa

Se carregares neste botão para enviar o teu projeto para a Partilha, tens de criar uma conta, caso ainda não o tenhas feito. Em alternativa, podes iniciar sessão com a Google. Depois de iniciares sessão, tens de dar um nome ao teu projeto e escrever uma descrição. Depois tens de escolher até três categorias que descrevam melhor o teu programa.

![Carregar e partilhar (2)](../../../media/game-tutorials/Upload-and-Share-2.png)\
Depois carrega em “Seguinte” para carregar o teu programa.\
[Abrir imagem](../../../media/game-tutorials/Upload-and-Share-2.png)

### 5. Exportar projeto

Se quiseres partilhar o teu projeto com os teus amigos, escolhe *Exportar projeto*.

### 6. Exportar projeto

Com este botão, podes guardar um ficheiro .catrobat que podes partilhar em privado com os teus amigos.

![Carregar e partilhar (3)](../../../media/game-tutorials/Upload-and-Share-3.png)\
Podes guardá-lo no explorador de ficheiros do dispositivo e partilhá-lo desta forma.\
[Abrir imagem](../../../media/game-tutorials/Upload-and-Share-3.png)

Conseguiste! Partilhaste o teu primeiro programa!

Se precisares de ajuda ou de inspiração para os próximos projetos, vê os nossos tutoriais de diferentes níveis (Principiante/Intermédio/Avançado).
