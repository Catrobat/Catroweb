Neste tutorial, vais aprender tudo o que precisas de saber sobre o Pocket Code para começar a criar o teu primeiro projeto. Vamos guiar-te passo a passo para transferires a aplicação, a abrires e criares um projeto novo.

Então, o que estás a esperar? Pega no telemóvel e começa já!

### 1. Instalar o Pocket Code

Primeiro, tens de instalar a aplicação Pocket Code no teu dispositivo. Para este passo é necessária uma conta Google. Agora o teu dispositivo vai descarregar e instalar a aplicação. Este passo pode demorar um pouco, dependendo da tua ligação à internet.

![Programa novo (2)](../../../media/game-tutorials/New-Program-2.png)\
Podes encontrar a aplicação pesquisando “Pocket Code” na Google Play Store e descarregá-la carregando em “instalar”.\
[Abrir imagem](../../../media/game-tutorials/New-Program-2.png)

Depois de transferires e instalares o Pocket Code com sucesso, encontras a aplicação na gaveta de aplicações ou no ecrã inicial, consoante o teu dispositivo. Podes mover a aplicação para onde quiseres.

### 2. Abrir a aplicação

![Programa novo (1)](../../../media/game-tutorials/New-Program-1.png)\
Quando abres a aplicação, vês diferentes categorias.\
[Abrir imagem](../../../media/game-tutorials/New-Program-1.png)

### 3. Criar um projeto novo

O passo seguinte é criar mesmo um projeto novo. Agora tens de escrever um nome para o projeto e escolher se o projeto deve ser na horizontal ou não. Ao carregar em “OK”, o projeto é criado.

![Programa novo](../../../media/game-tutorials/New-Program.png)\
Para isso, podes carregar no botão amarelo de mais, no canto inferior direito.\
[Abrir imagem](../../../media/game-tutorials/New-Program.png)

### 4. Conseguiste! Criaste o teu próprio projeto novo.

Agora já instalaste o Pocket Code e sabes criar um projeto novo. Agora podes começar a programar!

Para isso, precisas de saber como criar um objeto novo num projeto. Vê o tutorial **[Objeto novo](new-object.md)**, onde se explica tudo passo a passo.
