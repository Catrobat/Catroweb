![Continuar cena](../../../media/bricks/continue_scene_brick2.png)

Este bloco retoma a cena a partir de onde ficou em pausa. Se a tua cena foi interrompida por uma pausa ou uma espera, usar este bloco faz a ação continuar exatamente onde parou.

Imagina que pausaste um jogo ou uma animação e agora queres que continue a correr. Este bloco funciona como o botão de “play”, fazendo tudo retomar desde o ponto em que ficou em pausa.
