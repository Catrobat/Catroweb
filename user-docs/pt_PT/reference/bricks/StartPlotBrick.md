![Começar a desenhar com o plotter](../../../media/bricks/Start_to_plot.png)

Este bloco começa o processo de desenho com o plotter enquanto o ator se move. É parecido com pousar uma caneta no papel para começar a desenhar uma linha. Podes usar o bloco “Parar de desenhar com o plotter” se quiseres fazer uma pausa no desenho, mover o ator para outro sítio e depois começar outra vez com “Começar a desenhar com o plotter”.
