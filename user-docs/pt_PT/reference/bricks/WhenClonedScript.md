![Quando começar como clone](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Dá instruções a um clone criado de um objeto para executar as ações desejadas. Este processo permite replicar a função do objeto original, controlando o clone de forma independente. Podem ser definidos vários comportamentos ou propriedades do objeto clone para cumprir requisitos específicos.
