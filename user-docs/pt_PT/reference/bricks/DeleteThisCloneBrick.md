![Eliminar este clone](../../../media/bricks/delete_clone_brick2.png)

Este bloco remove o clone que foi criado com o bloco “Criar clone de”. É como dizer: “Remove este duplicado.” Usa-o para gerir e controlar o número de clones do teu projeto, garantindo que são eliminados quando já não são precisos.
