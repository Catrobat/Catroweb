![Definir massa para quilograma](../../../media/bricks/set_mass_to__kilogram_brick.png)

Define o peso do objeto em quilogramas, afetando a forma como se move e interage com outros objetos. Os objetos mais pesados são mais difíceis de mover e precisam de mais força para mudar de direção.
