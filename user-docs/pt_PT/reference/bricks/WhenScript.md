![Quando for tocado](../../../media/bricks/when-tapped2.png)

Executa o script quando o objeto é tocado.

A diferença para o bloco *“Quando o palco for tocado”* é que *“Quando for tocado”* é específico de cada personagem ou objeto, enquanto *“Quando o palco for tocado”* se aplica ao ecrã inteiro.
