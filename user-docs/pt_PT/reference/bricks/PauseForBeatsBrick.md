![Pausa de 1 batidas](../../../media/bricks/Pause_for_1_beats.png)

Este bloco faz o script esperar um número definido de batidas antes de continuar. É como fazer uma pequena pausa numa música antes de tocar a nota ou o som seguinte. Imagina parar a atuação por um momento, contar as batidas e depois retomar a ação.
