![Definir cor das partículas para "#ff0000"](../../../media/bricks/Set_particle_colour_to_ff0000.png)

Este bloco muda a cor das partículas que o ator emite. É como mudar a cor dos confetis de um canhão de confetis.

Um código de cor hexadecimal é uma forma de representar cores com valores hexadecimais. É formado por seis caracteres, que podem ser números (0-9) ou letras (A-F). O código costuma começar por “#”, assim: `#RRGGBB`.

- Os dois primeiros caracteres (`RR`) representam a componente vermelha da cor.
- Os dois seguintes (`GG`) representam a componente verde.
- Os dois últimos (`BB`) representam a componente azul.

Cada par de caracteres pode ir de `00` (que significa nada dessa cor) até `FF` (que significa a quantidade máxima dessa cor). Por exemplo:

`#000000` é preto (sem cor).

`#FF0000` é vermelho puro.

`#00FF00` é verde puro.

`#0000FF` é azul puro.

`#FFFFFF` é branco (o máximo de vermelho, verde e azul).
