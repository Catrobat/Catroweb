![Quando a cena começar](../../../media/bricks/When_scene_starts_btn2.png)

Se usares este bloco, o script começa de imediato quando a cena começa. Uma cena é o início do teu programa. É uma nova vista do teu programa, onde outros elementos podem aparecer e podem acontecer diferentes interações. Podes ter muitas cenas para diferentes fases do programa. Por exemplo, uma cena para a introdução, uma para o menu principal, uma para o primeiro nível, uma para o segundo nível e assim por diante. Em programas mais simples, uma única cena também pode chegar; nesse caso, o início do programa é também o início da cena.

Como todos os scripts, este também começa com um bloco de evento: o evento define **quando** o script começa, e os blocos a seguir dizem ao programa **o que** deve fazer.
