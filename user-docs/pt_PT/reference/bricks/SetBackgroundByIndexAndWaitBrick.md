Este bloco muda o fundo para um fundo específico, escolhido pela sua posição na lista de fundos, e espera que a mudança fique completa antes de continuar o script. É como trocar o cenário de uma peça por um cenário específico da lista e parar a ação até a cena nova ficar pronta.
