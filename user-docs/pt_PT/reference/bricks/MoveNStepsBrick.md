![Mover](../../../media/bricks/move-brick.png)

Move o objeto um número definido de passos na direção para onde está virado. É como dizer a uma personagem para dar um certo número de passos em frente. Ao usar o Desenhador de bordados, 10 passos correspondem a 2 mm (1 cm são 50 passos).
