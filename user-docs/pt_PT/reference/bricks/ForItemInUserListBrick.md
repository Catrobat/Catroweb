![Para cada valor de](../../../media/bricks/for-each-value_brick.png)

Este bloco executa um conjunto de instruções para cada item de uma lista ou de um intervalo. É como percorrer cada item, um a um, e fazer a mesma ação em cada um.

Imagina que tens uma lista de números, cores ou outros itens. Este bloco permite pegar em cada item da lista e fazer alguma coisa com ele. Por exemplo, se tiveres uma lista de cores e quiseres mudar o fundo para cada cor da lista, usas este bloco.

É como dizer: “Para cada item deste grupo, faz estas instruções.”
