![Quando o palco for tocado](../../../media/bricks/When_stage_is_tapped_btn.png)

Executa o script quando o ecrã é tocado.

A diferença para o bloco *“Quando for tocado”* é que *“Quando o palco for tocado”* se aplica ao ecrã inteiro, enquanto *“Quando for tocado”* é específico de cada personagem ou objeto.
