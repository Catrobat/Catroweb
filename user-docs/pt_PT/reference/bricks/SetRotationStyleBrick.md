![Definir estilo de rotação](../../../media/bricks/set_rotation_style_brick2.png)

Muda a forma como o objeto roda (em todas as direções, só esquerda-direita ou sem rodar). É como decidir se a tua personagem pode dar a volta toda, apenas virar para a esquerda e para a direita, ou não rodar de todo.
