![Colocar em x y](../../../media/bricks/place_at_x_y_brick.png)

Move o objeto para uma posição específica do ecrã, definida pelas coordenadas x e y. É como teletransportar a tua personagem para um sítio exato.

A posição define-se num sistema de coordenadas como o plano cartesiano: os eixos x e y passam pelo centro do ecrã, por isso x = 0 e y = 0 é o meio do ecrã.
