![Se é verdadeiro, então, senão](../../../media/bricks/if_else_brick2.png)

*Verifica se uma condição é verdadeira e executa um conjunto de instruções se for, e outro conjunto se não for. É como dar duas opções: “Se isto for verdade, faz isto; senão, faz aquilo.”*

![Iniciar cena](../../../media/bricks/StartScene.png)

Quando a cena começa, a variável X é definida como 0.

![Se senão](../../../media/bricks/IfElse.png)

Se o animal for agora tocado, verifica-se se X módulo 2 é verdadeiro, ou seja, se X é um número ímpar.

Se for o caso, o som Tweet1 é reproduzido e a variável X aumenta 1.

Senão, se X for par, só X aumenta 1.

As instruções a executar são separadas por um Fim se.
