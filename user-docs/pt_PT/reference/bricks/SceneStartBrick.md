![Iniciar cena](../../../media/bricks/start_scene_brick2.png)

Este bloco passa para outra cena do teu projeto e começa a executá-la desde o início. É como mudar de capítulo num livro ou passar para o nível seguinte de um jogo.

Imagina que tens várias cenas no teu projeto, cada uma com uma parte diferente da tua história ou do teu jogo. Com este bloco, podes saltar para qualquer cena e começá-la desde o princípio, criando uma transição suave entre as partes do teu projeto.
