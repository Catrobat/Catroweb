![Para valores de](../../../media/bricks/for-values-from-brick.png)

Este bloco executa um conjunto de instruções um número específico de vezes, usando um contador que começa num valor e acaba noutro. É como criar um ciclo em que sabes exatamente quantas vezes queres que ele corra.

Imagina que tens uma lista de itens e queres fazer alguma coisa com cada um. Este bloco deixa-te percorrer cada item, um a um, fazendo a mesma coisa a cada um.
