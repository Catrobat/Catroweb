![Parar de desenhar com o plotter](../../../media/bricks/Stop_to_plot.png)

O bloco “Parar de desenhar com o plotter” faz uma pausa no processo de desenho e deixa-te mover o ator para uma nova posição ou terminar o desenho. É como levantar a caneta do papel para a reposicionar ou parar de desenhar. Depois de terminares o desenho, podes usar o bloco “Guardar desenho do plotter como SVG” para guardar o teu desenho num ficheiro SVG.
