Este bloco muda a cor da caneta usada pelo ator. É como trocar para uma caneta de outra cor enquanto desenhas.

**Vermelho, Verde, Azul (RGB)**: O modelo de cores RGB usa diferentes intensidades de luz vermelha, verde e azul para criar um grande espetro de cores. Cada componente de cor (vermelho, verde e azul) pode ter um valor entre 0 e 255:

- **Vermelho**: A componente vermelha da cor. Um valor mais alto significa mais vermelho.
- **Verde**: A componente verde da cor. Um valor mais alto significa mais verde.
- **Azul**: A componente azul da cor. Um valor mais alto significa mais azul.

Combinando valores diferentes de vermelho, verde e azul, podes criar qualquer cor. Por exemplo:

- `RGB(255, 0, 0)` é vermelho puro.
- `RGB(0, 255, 0)` é verde puro.
- `RGB(0, 0, 255)` é azul puro.
- `RGB(255, 255, 255)` é branco (o máximo de vermelho, verde e azul).
- `RGB(0, 0, 0)` é preto (sem cor).

Misturar estas cores em quantidades diferentes cria todas as cores que vês nos ecrãs digitais.
