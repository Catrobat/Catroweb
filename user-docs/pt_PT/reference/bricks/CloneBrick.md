![Criar clone de](../../../media/bricks/create_clone_of_brick2.png)

Este bloco faz uma cópia do objeto indicado, chamada clone, que se comporta como o original. Imagina duplicar uma personagem ou um objeto do teu jogo. O clone pode ter os seus próprios comportamentos e scripts, por isso podes criar várias cópias de um objeto que agem de forma independente.
