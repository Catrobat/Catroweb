Neste tutorial, vais aprender tudo o que precisas de saber sobre os blocos de bordado!

Não precisas de saber programar para isto.

Cada bloco de bordado é explicado com um exemplo.

Se ainda não ativaste os blocos de bordado, vê o tutorial **[Ativar os blocos de bordado](../activate-embroidery-bricks.md)**.

[![Iniciar ponto corrido com comprimento 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

[![Iniciar ponto em ziguezague com comprimento 2 e largura 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Borda continuamente com um comprimento e uma largura variáveis.*

[![Iniciar ponto triplo com comprimento 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)
