Deixa a máquina bordar continuamente com um comprimento variável.

Normalmente, combinas o ponto corrido com um bloco de mover.

![Iniciar ponto corrido com comprimento 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

A máquina inicia um ponto corrido que borda a cada **10 passos**.

Depois, a máquina move-se **200 passos**.

Isto resulta em **20 pontos**.

![Ponto corrido](../../../../media/embroidery-tutorials/RunningStitch.png)

O ponto corrido facilita a costura de uma linha, porque já não precisas de um ciclo.
