Neste tutorial, vais ver como ativar os blocos de bordado.

![Ativar blocos de bordado 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Não precisas de saber programar para isto. Este é o primeiro passo para começar os tutoriais de bordado. Mais tarde, podes desenhar, programar e até bordar os teus próprios desenhos no teu tecido favorito.

Para mais informações ou sugestões de desenhos, vê os outros tutoriais.

*Aqui podes descarregar o tutorial em formato PDF*:

[ActivateEmbroideryBricks](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Abre a aplicação “Pocket Code”. Segue os cliques!

### 2. Abre o menu (os pontos no canto superior direito).

![Ativar blocos de bordado](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Vai a “Definições”.

![Ativar blocos de bordado 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Seleciona “Extensão de bordado”.

![Ativar blocos de bordado 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Vais encontrar os blocos de bordado como uma categoria própria dentro dos teus blocos!

[![Ativar blocos de bordado 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Agora também vais encontrar todos os blocos de bordado juntamente com os outros blocos.

Para mais informações sobre cada bloco, consulta a documentação dos blocos [aqui](../../../reference/) ou segue o tutorial **[Blocos de bordado](embroidery-bricks/index.md)**.

Agora podes começar e criar os teus próprios desenhos!

Se precisares de ideias ou de ajuda, vê os outros tutoriais ou continua com o tutorial **[Criar objetos de bordado](create-embroidery-objects.md)**.
