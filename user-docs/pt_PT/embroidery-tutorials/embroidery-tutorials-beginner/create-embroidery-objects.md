Neste tutorial, vais aprender a criar objetos com os quais podes bordar os teus padrões mais tarde.

Para este tutorial, deves já saber criar um projeto. Vê os tutoriais da série [Iniciação](../../game-tutorials/starter-tutorials/index.md), se precisares de ajuda.

Para mais informações ou sugestões de desenhos, vê os outros tutoriais.

*Aqui podes descarregar o tutorial em formato PDF*:

[Criar objetos de bordado](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Clica no botão de mais no canto inferior direito do teu projeto para adicionar um objeto novo.

![Criar objetos de bordado](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Para escolher uma imagem, vai à biblioteca de multimédia.

![Criar objetos de bordado (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Um objeto de bordado representa um nível da agulha da máquina de bordar. Vários objetos de bordado são bordados um a seguir ao outro. Isto permite usar várias cores.

Podes escolher o teu objeto consoante a cor que queres.

Desce e procura a seta adequada.

![Criar objetos de bordado (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Dá ao teu objeto novo um nome adequado e carrega em OK.

![Criar objetos de bordado (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Acabaste de criar um objeto novo. Agora podes adicionar um script e programar o objeto.

![Criar objetos de bordado (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Agora já sabes criar um objeto. Adiciona um objeto novo para cada cor que queres usar.

Podes adicionar um script em cada cor e programar os teus próprios desenhos, e até bordá-los mais tarde.

Precisas de inspiração ou de ajuda? Vê os nossos outros tutoriais!
