![Saat adegan dimulai](../../../media/bricks/When_scene_starts_btn2.png)

Kalau kamu memakai blok ini, skrip akan langsung dimulai saat adegan dimulai. Adegan adalah awal dari programmu. Adegan adalah tampilan baru di programmu tempat elemen lain bisa ditampilkan dan berbagai interaksi bisa terjadi. Kamu bisa punya banyak adegan untuk tahap berbeda di programmu. Misalnya, satu adegan untuk pembuka, satu adegan untuk menu utama, satu untuk level pertama, satu untuk level kedua, dan seterusnya. Untuk program yang lebih sederhana, satu adegan saja sudah cukup, jadi awal programmu juga menjadi awal adegannya.

Seperti setiap skrip, skrip ini dimulai dengan blok peristiwa: peristiwa menentukan **kapan** skrip dimulai, dan blok-blok sesudahnya memberi tahu program **apa** yang harus dilakukan.
