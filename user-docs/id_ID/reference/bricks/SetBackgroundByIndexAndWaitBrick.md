![Atur latar belakang ke nomor 1 dan tunggu](../../../media/bricks/Set_background_to_number_1_and_wait_.png)

Blok ini mengubah latar belakang ke latar belakang tertentu berdasarkan posisinya dalam daftar latar belakang, dan menunggu sampai perubahannya selesai sebelum skrip dilanjutkan. Ini seperti mengganti pemandangan dalam pertunjukan ke latar tertentu dari daftar, dan menghentikan aksi sampai adegan baru sudah siap sepenuhnya.
