![Atur gesekan ke](../../../media/bricks/set_friction_to_brick2.png)

Mengatur seberapa besar gesekan yang diterapkan pada objek, yang memengaruhi seberapa mudah objek itu meluncur atau melambat. Ini seperti mengubah seberapa licin permukaan tempat karaktermu berdiri. Makin besar gesekan, makin sedikit meluncur.
