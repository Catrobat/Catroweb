Blok ini menghentikan semua skrip dan mengakhiri panggung atau adegan saat ini. Ini seperti berkata, “Bagian proyek ini sudah selesai.” Semuanya berhenti, dan proyek bisa pindah ke adegan lain atau berakhir sepenuhnya. Pakai blok ini saat kamu ingin menyelesaikan tahap atau level tertentu di proyekmu.
