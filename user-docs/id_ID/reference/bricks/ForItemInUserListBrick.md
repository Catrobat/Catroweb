![Untuk setiap nilai dari](../../../media/bricks/for-each-value_brick.png)

Blok ini menjalankan serangkaian instruksi untuk setiap item dalam daftar atau rentang. Ini seperti memeriksa setiap item satu per satu dan melakukan aksi yang sama pada setiap item.

Bayangkan kamu punya daftar angka, warna, atau item lainnya. Blok ini membuatmu mengambil setiap item dari daftar itu dan melakukan sesuatu dengannya. Misalnya, kalau kamu punya daftar warna dan ingin mengubah warna latar belakang ke setiap warna di daftar, kamu bisa memakai blok ini.

Ini seperti berkata, “Untuk setiap item di kelompok ini, lakukan instruksi ini.”
