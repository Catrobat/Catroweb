![Berhenti memplot](../../../media/bricks/Stop_to_plot.png)

Blok “Berhenti memplot” menjeda proses memplot dan membiarkanmu memindahkan aktor ke posisi baru atau menyelesaikan plot. Ini seperti mengangkat pena dari kertas untuk memposisikan ulang atau berhenti menggambar. Setelah selesai memplot, kamu bisa memakai blok “Simpan plot sebagai SVG” untuk menyimpan desainmu sebagai file SVG.
