![Nyalakan aditivitas efek partikel](../../../media/bricks/Turn_particle_effect_additivity_on.png)

Blok ini mengaktifkan atau menonaktifkan mode pencampuran aditif untuk partikel, yang bisa membuat partikel tampak lebih terang dan lebih kuat. Ini seperti mengatur kecerahan dan kilau kilauan.
