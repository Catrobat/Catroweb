*Memeriksa apakah suatu kondisi benar, dan menjalankan satu set instruksi jika benar, dan set lain jika tidak. Ini seperti memberi dua pilihan: “Jika ini benar, lakukan ini; kalau tidak, lakukan itu.”*

![Mulai adegan](../../../media/bricks/StartScene.png)

Saat adegan dimulai, variabel X diatur ke 0.

![Jika-tidak](../../../media/bricks/IfElse.png)

Jika hewan itu sekarang diketuk, dilakukan pemeriksaan apakah X modulo 2 benar, yaitu apakah X adalah bilangan ganjil.

Kalau iya, suara Tweet1 dimainkan dan variabel X ditambah 1.

Kalau tidak, jika X genap, hanya X yang ditambah 1.

Pernyataan yang akan dijalankan dipisahkan dengan End if.
