Blok ini membuat salinan objek yang kamu tentukan, yang disebut klon, dan klon itu berperilaku seperti aslinya. Bayangkan menggandakan karakter atau objek di gamemu. Klon bisa punya perilaku dan skripnya sendiri, sehingga kamu bisa membuat banyak salinan objek yang bekerja sendiri-sendiri.
