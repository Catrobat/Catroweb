![Mulai adegan](../../../media/bricks/start_scene_brick2.png)

Blok ini berpindah ke adegan lain di proyekmu dan mulai menjalankan adegan itu dari awal. Ini seperti mengganti bab dalam buku atau pindah ke level berikutnya dalam game.

Bayangkan kamu punya beberapa adegan di proyekmu, masing-masing mewakili bagian berbeda dari ceritamu atau gamemu. Dengan blok ini, kamu bisa melompat ke adegan mana pun dan memulainya dari awal, sehingga perpindahan antarbagian proyekmu terasa mulus.
