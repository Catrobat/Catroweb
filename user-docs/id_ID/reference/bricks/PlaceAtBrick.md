![Tempatkan di x y](../../../media/bricks/place_at_x_y_brick.png)

Memindahkan objek ke posisi tertentu di layar, yang ditentukan oleh koordinat x dan y. Ini seperti memindahkan karaktermu secara instan ke tempat yang tepat.

Posisinya diatur dalam sistem koordinat seperti bidang Cartesius: sumbu x dan y melewati tengah layar, jadi x = 0 dan y = 0 adalah tengah layar.
