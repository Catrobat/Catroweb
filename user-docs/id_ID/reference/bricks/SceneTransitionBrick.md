![Lanjutkan adegan](../../../media/bricks/continue_scene_brick2.png)

Blok ini melanjutkan adegan dari tempat adegan itu dijeda. Kalau adegannya terganggu oleh jeda atau tunggu, blok ini akan melanjutkan aksinya tepat dari tempat berhenti.

Bayangkan kamu menjeda game atau animasi, dan sekarang kamu ingin melanjutkannya. Blok ini bekerja seperti tombol “play”, sehingga semuanya kembali berjalan dari titik ketika dijeda.
