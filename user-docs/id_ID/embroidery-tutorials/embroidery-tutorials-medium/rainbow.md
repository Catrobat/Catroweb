Dalam tutorial ini, kamu akan belajar cara membordir pelangi (112 x 57,2 mm).

![Regenbogen](../../../media/embroidery-tutorials/Regenbogen.webp)

Kamu sebaiknya sudah tahu apa itu loop dan cara kerjanya.

Tutorial **[Setengah lingkaran](../embroidery-tutorials-beginner/semicircle.md)** mungkin berguna untuk tutorial ini.

Lihat tutorial bordir dari seri [Pemula](../embroidery-tutorials-beginner/index.md) kalau kamu belum pernah membordir apa pun.

Untuk informasi lebih lanjut atau saran desain, lihat tutorial lainnya.

*Di sini kamu bisa mengunduh tutorial dalam format PDF*:

[Pelangi](../../../media/embroidery-tutorials/Rainbow.pdf)

### 1. Buat Objek Bordir baru (lihat [Buat Objek Bordir](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![Pelangi](../../../media/embroidery-tutorials/Rainbow.png)

### 2. Masukkan skrip berikut:

![Pelangi (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. Salin objek

Untuk lengkung yang lebih besar berikutnya, kamu bisa langsung menyalin objek yang baru saja kamu buat.
Ketuk tiga titik di pojok kanan atas ikhtisar objek.
Lalu buka “Salin” dan pilih objeknya.

![Regenbogen (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Kalau kamu memakai objek terpisah untuk setiap lengkung, kamu bisa membordirnya nanti dengan warna yang berbeda.

### 4. Ubah objek

Supaya lengkungnya sekarang berukuran berbeda, kita perlu mengubah beberapa nilai.
Untuk itu, buka skrip objek yang disalin dan sesuaikan nilai berikut:

![Pelangi (2)](../../../media/embroidery-tutorials/Rainbow-2.png)

### 5. Ulangi langkah 3 dan 4 untuk lebih banyak lengkung!

### 6. Ketuk play untuk memulai desainmu!
