Dalam tutorial ini, kamu akan belajar cara membordir spiral (103,9 x 116,6 mm).

![image (14)](../../../media/embroidery-tutorials/image-14.png)

Kamu sebaiknya sudah tahu apa itu loop dan cara kerjanya.

Tutorial **[Lingkaran](../embroidery-tutorials-beginner/circle.md)** mungkin berguna untuk tutorial ini.

Lihat tutorial bordir dari seri [Pemula](../embroidery-tutorials-beginner/index.md) kalau kamu belum pernah membordir apa pun.

Untuk informasi lebih lanjut atau saran desain, lihat tutorial lainnya.

*Di sini kamu bisa mengunduh tutorial dalam format PDF*:

[Spiral](../../../media/embroidery-tutorials/Spiral.pdf)

### 1. Buat Objek Bordir baru (lihat [Buat Objek Bordir](../embroidery-tutorials-beginner/create-embroidery-objects.md)) dan masukkan skrip berikut:

![Spiral](../../../media/embroidery-tutorials/Spiral.png)

### 2. Ketuk play untuk memulai desainmu!

Ketuk “baru” untuk membuat variabel baru.

![image (15)](../../../media/embroidery-tutorials/image-15.png)

Kamu akan menemukan variabel “degree” di data.

![Spiral (1)](../../../media/embroidery-tutorials/Spiral-1.png)
