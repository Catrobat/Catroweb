Jahitan tiga lapis menjahit setiap jahitan tiga kali.

Jahitan tiga lapis mundur sedikit setelah jahitan pertama, menjahit, lalu maju lagi dan menjahit lagi.

![Mulai jahitan tiga lapis dengan panjang 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Cara kerjanya sama seperti [jahitan jelujur](running-stitch.md).

![Jahitan tiga lapis](../../../../media/embroidery-tutorials/TripleStitch.png)

Ini membuat sambungan lebih awet.
