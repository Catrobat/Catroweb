Membuat mesin menjahit terus-menerus dengan panjang yang bisa diatur.

Biasanya kamu menggabungkan jahitan jelujur dengan blok gerak.

![Mulai jahitan jelujur dengan panjang 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Mesin memulai jahitan jelujur yang akan menjahit setiap **10 langkah**.

Lalu mesin bergerak **200 langkah**.

Hasilnya adalah **20 jahitan**.

![Jahitan jelujur](../../../../media/embroidery-tutorials/RunningStitch.png)

Jahitan jelujur membuat menjahit sambungan lebih mudah karena kamu tidak perlu loop lagi.
