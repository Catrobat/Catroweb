Dalam tutorial ini, kamu akan belajar cara membordir lolipop (54,7 x 54,8 mm).

![image (9)](../../../media/embroidery-tutorials/image-9.png)

Kamu sebaiknya sudah tahu cara membuat objek baru dan memasukkan blok di sana. Silakan lihat tutorial di [seri Dasar](../../game-tutorials/starter-tutorials/index.md) kalau kamu masih butuh bantuan. Selain itu, blok bordir harus sudah diaktifkan. Kamu bisa mengetahui caranya di tutorial **[Aktifkan blok bordir](activate-embroidery-bricks.md)**.

Untuk informasi lebih lanjut atau saran desain, lihat tutorial lainnya.

*Di sini kamu bisa mengunduh tutorial dalam format PDF*:

[Permen lolipop](../../../media/embroidery-tutorials/Lollipop.pdf)

### 1. Buat Objek Bordir baru (lihat [Buat Objek Bordir](create-embroidery-objects.md)).

### 2. Sekarang mulai dan masukkan blok langkah demi langkah ke skripmu.

![Permen lolipop](../../../media/embroidery-tutorials/Lollipop.png)

### 3. Ketuk play untuk memulai desainmu!

Lihat tutorial **[Lingkaran](circle.md)** untuk informasi lebih lanjut tentang cara membordir lingkaran.
