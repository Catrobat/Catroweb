Dalam tutorial ini, cara mengaktifkan blok bordir akan dijelaskan.

![Aktifkan blok bordir5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Kamu tidak perlu pengetahuan coding untuk ini. Ini adalah langkah pertama untuk memulai tutorial bordir. Nanti, kamu bisa mendesain, memprogram, dan bahkan membordir desainmu sendiri di kain favoritmu.

Untuk informasi lebih lanjut atau saran desain, lihat tutorial lainnya.

*Di sini kamu bisa mengunduh tutorial dalam format PDF*:

[AktifkanBlokBordir](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Buka aplikasi “Pocket Code”. Ikuti klik-kliknya!

### 2. Buka menu (titik-titik di kanan atas).

![Aktifkan blok bordir](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Buka “Pengaturan”.

![Aktifkan blok bordir3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Pilih “Ekstensi bordir”.

![Aktifkan blok bordir4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Kamu akan menemukan blok bordir sebagai kategori sendiri di antara bloknya!

[![Aktifkan blok bordir5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Sekarang kamu juga akan menemukan semua blok bordir di antara blok lainnya.

Untuk informasi lebih lanjut tentang setiap blok, silakan lihat dokumentasi blok [di sini](../../../reference/) atau ikuti tutorial **[Blok Bordir](embroidery-bricks/index.md)**.

Sekarang kamu bisa mulai dan membuat desainmu sendiri!

Kalau kamu butuh ide atau bantuan, lihat tutorial lainnya atau lanjutkan dengan tutorial **[Buat Objek Bordir](create-embroidery-objects.md)**.
