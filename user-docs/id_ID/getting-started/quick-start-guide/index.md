Pocket Code adalah aplikasi pemrograman visual yang membuatmu bisa membuat game, animasi, dan cerita interaktif langsung di ponsel atau tablet. Dengan antarmuka seret-dan-lepas yang mudah dipakai dan “blok” (blok kode), kamu bisa mendesain proyekmu tanpa pengalaman coding. Dengan mudah kamu bisa menambahkan suara, gambar, dan gerakan untuk menghidupkan idemu.

Panduan ini membantumu memulai dengan menjelaskan cara untuk:

- Menjelajahi antarmuka,
- Membuat proyek pertamamu,
- Bekerja dengan objek dan latar belakang,
- Memakai blok untuk memprogram aksi, dan
- Menyimpan proyekmu.

Cocok untuk pemula dan guru, Pocket Code mendorong kreativitas, pemecahan masalah, dan cara berpikir logis.
