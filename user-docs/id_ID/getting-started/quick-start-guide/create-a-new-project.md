Buka aplikasi di ponsel atau tablet kamu.

![MainScreen_NewProject](../../../media/getting-started/MainScreen_NewProject.png)\
Ketuk simbol + untuk membuat proyek baru.\
[Buka gambar](../../../media/getting-started/MainScreen_NewProject.png)

Beri nama proyekmu (1) dan pilih apakah kamu ingin membuat game dengan format potret (vertikal) atau lanskap (horizontal) (2).

![NewProject](../../../media/getting-started/NewProject.png)\
Lalu konfirmasi dengan tanda centang (3).\
[Buka gambar](../../../media/getting-started/NewProject.png)

Sekarang kamu ada di tampilan proyek. Di bagian atas, kamu melihat nama gamemu.

Di bawahnya kamu bisa melihat **latar belakang** – saat ini latar belakangnya masih kosong. Kalau ingin mengubahnya, ketuk latar belakang itu.

Di bawah latar belakang, kamu melihat area untuk **aktor dan objek** yang sudah kamu tambahkan ke gamemu. Saat ini area itu masih kosong.

Di kanan bawah, ada dua tombol penting:

![Mulai](../../../media/getting-started/Start.png)\
Dengan tombol **Mainkan**, kamu memulai gamemu.

![Tombol Plus](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Dengan tombol **Plus**, kamu menambahkan karakter/objek baru ke gamemu.

Sekarang kamu ada di tampilan proyek.\
