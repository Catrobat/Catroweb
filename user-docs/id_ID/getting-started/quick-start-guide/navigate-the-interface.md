Saat kamu membuka Pocket Code, kamu melihat layar utama berikut.

![Layar Utama](../../../media/getting-started/MainScreen-e1732269599192.jpg)

Di pojok kanan atas, ada simbol ![Bantuan](../../../media/getting-started/Screenshot-2024-11-22-111748.png) yang membawamu ke dokumentasi Catrobat, yang berisi tips berguna untukmu.

Di sebelahnya ada menu ![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png). Dari sana, kamu bisa dengan mudah membuka pengaturan, tempat kamu bisa mengubah bahasa atau mengaktifkan ekstensi seperti blok plot dan lainnya.

Di bawahnya, kamu melihat proyek yang terakhir kamu ubah. Ketuk ikon edit ![Ikon edit](../../../media/getting-started/Screenshot-2024-11-22-111825.png) untuk membuka layar proyek, tempat kamu bisa melanjutkan mengembangkan proyekmu.

Pakai tombol mainkan ![Mulai proyekmu](../../../media/getting-started/Screenshot-2024-11-22-111818.png) untuk memulai proyekmu.

Dengan mengetuk Projects on device, kamu bisa membuka proyek yang sudah kamu simpan. ![Proyek di perangkat](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Kalau kamu ingin mengenal dan mengerjakan lebih banyak proyek dari pengguna lain, cukup ketuk Catrobat Community di Bagikan. Di sana kamu akan menemukan banyak proyek keren. ![Komunitas Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Kalau kamu ingin membuat proyek baru, ketuk ikon plus. ![Tambah](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
