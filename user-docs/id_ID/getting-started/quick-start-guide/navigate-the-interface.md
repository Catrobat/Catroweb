Saat kamu membuka Pocket Code, kamu melihat layar utama berikut.

![Layar Utama](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Saat kamu membuka Pocket Code, kamu melihat layar utama berikut.\
[Buka gambar](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Bantuan](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Di pojok kanan atas, ada simbol yang membawamu ke dokumentasi Catrobat, yang berisi tips berguna untukmu.

![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Di sebelahnya ada menu.

Dari sana, kamu bisa dengan mudah membuka pengaturan, tempat kamu bisa mengubah bahasa atau mengaktifkan ekstensi seperti blok plot dan lainnya.

![Ikon edit](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Ketuk ikon edit untuk membuka layar proyek, tempat kamu bisa melanjutkan mengembangkan proyekmu.

Di bawahnya, kamu melihat proyek yang terakhir kamu ubah.

![Mulai proyekmu](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Pakai tombol mainkan untuk memulai proyekmu.

![Proyek di perangkat](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Dengan mengetuk Projects on device, kamu bisa membuka proyek yang sudah kamu simpan.

![Komunitas Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Kalau kamu ingin mengenal dan mengerjakan lebih banyak proyek dari pengguna lain, cukup ketuk Catrobat Community di Bagikan.

Di sana kamu akan menemukan banyak proyek keren.

![Tambah](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Kalau kamu ingin membuat proyek baru, ketuk ikon plus.
