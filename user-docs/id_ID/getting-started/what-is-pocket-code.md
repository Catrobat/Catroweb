Pocket Code adalah aplikasi utama Catrobat, aplikasi seluler gratis dan open-source yang membuatmu bisa membuat game, animasi, dan cerita interaktif langsung di ponsel atau tablet. Dengan **sistem coding berbasis blok** di Pocket Code, kamu membuat proyek dengan menyambungkan blok kode – seperti menyusun potongan puzzle. Tidak perlu bisa coding, jadi cocok sekali untuk pemula!

Pocket Code tidak hanya untuk proyek digital. Dengan fitur **makerspace** yang baru, kamu juga bisa membuat desain **file SVG untuk plotter pemotong**. Artinya, kreasi digitalmu bisa jadi benda nyata dan kamu bisa menjelajahi kemungkinan kreatif di luar layar.

Entah kamu sedang belajar coding, mencoba ide baru, atau mengajar pemrograman, Pocket Code memberi cara yang menyenangkan dan mudah untuk mulai belajar coding

[Informasi lebih lanjut](https://catrobat.org/pocket-code/)
