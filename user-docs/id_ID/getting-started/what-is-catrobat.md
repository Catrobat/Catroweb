Catrobat adalah **bahasa pemrograman visual** yang gratis dan open-source. Tujuannya membantu siapa saja – dari pemula sampai pengguna mahir – membuat game, animasi, dan cerita interaktif langsung di ponsel mereka. Dengan tampilan coding berbasis **blok**, Catrobat memakai “blok” kode yang bisa kamu seret dan lepas untuk membuat proyek langkah demi langkah – tidak perlu pengalaman sebelumnya!

Lewat aplikasi utama Catrobat, **Pocket Code**, kamu bisa membuat proyek digital yang keluar dari layar. Selain proyek coding biasa, Catrobat juga mendukung kreativitas makerspace. Kamu bisa membuat file **DST untuk mesin bordir** dan file **SVG untuk plotter pemotong**. Jadi, desainmu bisa hidup di kain dan bahan fisik lainnya!

Kamu siswa, hobi, atau guru? Catrobat menawarkan cara yang seru dan langsung praktik untuk belajar coding, memecahkan masalah, dan fabrikasi digital.
