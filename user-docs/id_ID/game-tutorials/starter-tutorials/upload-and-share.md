Dalam tutorial ini, kamu akan belajar cara membagikan proyek yang sudah kamu buat ke teman atau seluruh komunitas Catrobat.

![Unggah dan Bagikan](../../../media/game-tutorials/Upload-and-Share.png)

Untuk tutorial ini, kamu harus sudah punya proyekmu sendiri yang ingin kamu bagikan. Kalau kamu belum tahu cara membuat proyek, lihat tutorial **[Proyek Baru](new-project.md)** untuk belajar caranya.

*Di sini kamu bisa mengunduh tutorial dalam format PDF:*

[Unggah dan Bagikan](../../../media/game-tutorials/Upload-and-Share.pdf)

### 1. Opsi proyek

Kalau kamu ingin mengunggah atau membagikan proyekmu, kamu harus membuka proyekmu, lalu ketuk tiga titik di pojok kanan atas dan ketuk “Opsi proyek”

![Unggah dan Bagikan](../../../media/game-tutorials/Upload-and-Share.png)

### 2. Opsi proyek

Sekarang kamu bisa mengubah nama, menambahkan deskripsi, dan melakukan berbagai pengaturan.

Kamu juga punya dua pilihan: “Unggah proyek” dan “Ekspor proyek”, yang dijelaskan di langkah-langkah berikutnya.

![Unggah dan Bagikan (1)](../../../media/game-tutorials/Upload-and-Share-1.png)

### 3. Unggah proyek

Kalau kamu ingin mengunggah proyekmu ke Catrobat Share, supaya seluruh komunitas bisa mengaksesnya, pilih *Unggah proyek*.

### 4. Unggah proyek

Kalau kamu mengetuk tombol ini untuk mengunggah proyekmu ke Share, kamu harus mendaftar akun jika belum punya. Kamu juga bisa masuk dengan Google. Setelah masuk, kamu harus memberi nama proyekmu dan menulis Deskripsi. Lalu, kamu harus memilih hingga tiga kategori yang paling cocok untuk programmu.

Lalu ketuk “berikutnya” untuk mengunggah programmu.

![Unggah dan Bagikan (2)](../../../media/game-tutorials/Upload-and-Share-2.png)

### 5. Ekspor proyek

Kalau kamu ingin membagikan proyekmu ke teman-temanmu, pilih *Ekspor proyek*.

### 6. Ekspor proyek

Dengan tombol ini kamu bisa menyimpan file .catrobat yang bisa kamu bagikan secara pribadi ke teman-temanmu. Kamu bisa menyimpannya di penjelajah file di perangkatmu dan membagikannya dengan cara ini.

![Unggah dan Bagikan (3)](../../../media/game-tutorials/Upload-and-Share-3.png)

Berhasil! Kamu sudah membagikan program pertamamu!

Kalau kamu butuh bantuan atau inspirasi untuk proyek berikutnya, silakan lihat tutorial kami dengan berbagai tingkat (Pemula/Menengah/Lanjut).
