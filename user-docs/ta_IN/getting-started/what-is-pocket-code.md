Pocket Code என்பது Catrobat இன் முக்கிய பயன்பாடு ஆகும், இது உன் ஸ்மார்ட்போன் அல்லது டேப்லெட்டில் விளையாட்டுகள், அனிமேஷன் மற்றும் ஊடாடும் கதைகளை உருவாக்க அனுமதிக்கும் இலவச மற்றும் திறந்த மூல மொபைல் பயன்பாடாகும். **தொகுதி அடிப்படையிலான குறியீட்டு அமைப்பு** இன் Pocket Code மூலம், நீ ஒரு புதிரின் துண்டுகளை ஒன்றாக இணைப்பது போன்ற குறியீட்டு தொகுப்புகளை ஒன்றாக பிளவுபடுத்துவதன் மூலம் திட்டங்களை உருவாக்கலாம். எந்த நிரலாக்க அனுபவமும் தேவையில்லை, எனவே ஆரம்பநிலைக்கு இது சரியானது!

Pocket Code என்பது வெறும் டிஜிட்டல் திட்டங்களைத் தாண்டிச் செல்கிறது. புதிய **makerspace அம்சங்கள்** உடன் நீ வடிவமைக்க முடியும் **SVG வெட்டுக் கம்பளிகள்**. இதன் பொருள் உன் டிஜிட்டல் படைப்புகளை நிஜ உலகப் பொருட்களாக மாற்றலாம் மற்றும் திரைக்கு அப்பால் உள்ள படைப்பு சாத்தியங்களை ஆராயலாம்.

நீ குறியீட்டைக் கற்றுக்கொள்கிறீர்களா, புதிய யோசனைகளை பரிசோதிக்கிறீர்களா அல்லது நிரலாக்கத்தை கற்பிக்கிறீர்களா, Pocket Code குறியீட்டில் மூழ்கும் ஒரு வேடிக்கையான, அணுகக்கூடிய வழியை வழங்குகிறது
