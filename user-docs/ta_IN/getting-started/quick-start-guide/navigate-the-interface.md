நீ தொடங்கும் போது Pocket Code, பின்வரும் பிரதான திரையை காணலாம்.

![முதன்மை திரை](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
நீ தொடங்கும் போது Pocket Code, பின்வரும் பிரதான திரையை காணலாம்.\
[படத்தைத் திற](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![உதவி](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
மேல் வலது மூலையில், ஒரு சின்னம் உள்ளது, இது உன்னை Catrobat ஆவணத்திற்கு அழைத்துச் செல்கிறது, இது உனக்கு உதவியாக இருக்கும் உதவிக்குறிப்புகளைக் கொண்டுள்ளது.

![மெனு](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
அதன்பின் மெனு உள்ளது.

அங்கிருந்து, நீ எளிதாக அமைப்புகள் செல்லலாம், அங்கு நீ மொழியை மாற்றலாம் அல்லது புதிர் தொகுதிகள் போன்ற நீட்டிப்புகளை இயக்குங்கள் மற்றும் பல.

![ஐகானை திருத்தவும்](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
திட்டத் திரையில் அணுக, திருத்த ஐகானை கிளிக் செய்யவும், அங்கு நீ உன் திட்டத்தை தொடர்ந்து உருவாக்கலாம்.

கீழே, நீ உன் சமீபத்திய தொகுப்பு திட்டத்தை பார்க்க முடியும்.

![உன் திட்டத்தைத் தொடங்குங்கள்](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
உன் திட்டத்தைத் தொடங்க ப்ளே பொத்தானைப் பயன்படுத்தவும்.

![சாதனத் திட்டங்கள்](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
ஒரு கிளிக் மூலம் திட்டங்கள், நீ உன் சேமிக்கப்பட்ட திட்டங்கள் அணுக முடியும்.

![Catrobat சமுதாயம்](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
மற்ற பயனர்களிடமிருந்து மேலும் திட்டங்களை அறிந்து கொள்ளவும், அதில் பணியாற்றவும் விரும்பினால், Catrobat சமூகத்தில் பகிர்ந்து கொள்ளுங்கள்.

அங்கே பல பெரிய திட்டங்களைக் காணலாம்.

![சேர்க்கவும்](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
நீ ஒரு புதிய திட்டத்தை உருவாக்க விரும்பினால், பிளஸ் ஐகானை கிளிக் செய்யவும்.
