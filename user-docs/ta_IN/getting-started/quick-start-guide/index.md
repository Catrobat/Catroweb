Pocket Code என்பது ஒரு காட்சி நிரலாக்க பயன்பாடாகும், இது உன் ஸ்மார்ட்போன் அல்லது டேப்லெட்டில் நேரடியாக விளையாட்டுகள், அனிமேஷன் மற்றும் ஊடாடும் கதைகளை உருவாக்க உன்னை அனுமதிக்கிறது. “குறியீடு தொகுதிகள்” (குறியீடு தொகுதிகள்) உடன் உள்ளுணர்வு இழுத்தல் மற்றும் கைவிட இடைமுகத்தைப் பயன்படுத்தி, நீ முந்தைய நிரலாக்க அனுபவம் இல்லாமல் உன் திட்டங்களை வடிவமைக்க முடியும். உன் கருத்துக்களை நன்கு உணர எளிதாக ஒலிகள், படங்கள் மற்றும் இயக்கங்களை சேர்க்கவும்.

இந்த வழிகாட்டி உனக்கு எப்படி தொடங்குவது என்பதை விளக்குகிறதுஃ:

- இடைமுகம் செல்லவும்,
- உன் முதல் திட்டம் உருவாக்க,
- பொருள்களுடனும் பின்னணியுடனும் வேலை செய்
- செயல்களை நிரலாக்க குறியீடு தொகுதிகள் பயன்படுத்தவும், மற்றும்
- உன் திட்டம் காப்பாற்ற.

ஆரம்ப மற்றும் கல்வியாளர்களுக்கு சரியான, Pocket Code படைப்பாற்றல், சிக்கல்களைத் தீர்ப்பது மற்றும் தர்க்கரீதியான சிந்தனையை ஊக்குவிக்கிறது.
