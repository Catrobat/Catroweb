உன் ஸ்மார்ட்போன் அல்லது டேப்லெட்டில் பயன்பாட்டைத் திறக்கவும். புதிய திட்டத்தை உருவாக்க + சின்னத்தை தட்டவும்.

![பிரதான திரை புதிய திட்டம்](../../../media/getting-started/MainScreen_NewProject.png)

திட்டத்துக்கு ஒரு பெயர் கொடு (1). உன் விளையாட்டு செங்குத்துத் திரையிலா (போர்ட்ரெய்ட்) அல்லது கிடைமட்டத் திரையிலா (லேண்ட்ஸ்கேப்) இருக்க வேண்டும் என்று தேர்ந்தெடு (2). பிறகு சரிக்குறியைத் தட்டி உறுதிசெய் (3).

![புதிய திட்டம்](../../../media/getting-started/NewProject.png)

நீ இப்போது உன் திட்ட பார்வையில் இருக்கிறீர்கள். மேலே, உன் விளையாட்டின் பெயரைக் காணலாம்.

கீழே நீ **பின்னணி** பார்க்க முடியும் - தற்போது, பின்னணி காலியாக உள்ளது. நீ அதை மாற்ற விரும்பினால், அது மீது தட்டவும்.

பின்னணியில், நீ உன் விளையாட்டில் சேர்த்துள்ள **நடிகர்கள் மற்றும் பொருள்கள்** பகுதியை காணலாம். தற்போது, இப்பகுதி இன்னும் காலியாக உள்ளது.

வலதுபுறத்தில் கீழே, இரண்டு முக்கியமான பொத்தான்களை நீ காணலாம்ஃ:

![தொடங்கு](../../../media/getting-started/Start.png) நீ விளையாட்டைத் தொடங்குவதற்கு, **இயக்கு** பொத்தானை பயன்படுத்தி.

![பிளஸ் பொத்தானை](../../../media/getting-started/Screenshot-2024-11-22-143219.png) **கூடுதலாக** பொத்தானை பயன்படுத்தி, நீ உன் விளையாட்டு ஒரு புதிய கதாபாத்திரம் / பொருள் சேர்க்க.
