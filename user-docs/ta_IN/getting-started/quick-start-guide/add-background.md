நீ உன் திட்டத்திற்கு பின்னணியை Catrobat இல் சேர்க்கலாம்.

பின்னணிகளை பல்வேறு வழிகளில் பயன்படுத்தலாம். Pocket Code இல், அவை காட்சிக்கு மேம்படுத்தப்படலாம் **விளையாட்டுகள்**, சொல்லுங்கள் **கதைகள்**, அல்லது உன் நடிகர்கள் மற்றும் பொருள்களுக்கு அதிக சூழலை வழங்கலாம்.

**சதித்திட்டம்** அல்லது **எம்பிராய்டரி இயந்திரங்கள்** போன்ற தயாரிப்பாளர் இட சாதனங்களுக்கு, பின்னணிகள் வெட்டுக்கள் அல்லது எம்பிராய்டரி வடிவமைப்புகளுக்கான வடிவமைப்பு வார்ப்புருக்களாக செயல்படுகின்றன.

![பின்னணி பற்றிய உதவிக்குறிப்பு](../../../media/getting-started/grafik-16.png)\
ஒரு பின்னணியைச் சேர்க்க, திட்டக் காட்சியில் “பின்னணி” என்பதைத் தட்டவும்.\
[படத்தைத் திற](../../../media/getting-started/grafik-16.png)

**எழுத்துத் துறை(2)** இல், நீ உன் பின்னணியை நிரலாக்கலாம் - இருப்பினும், இதற்காக அனைத்து தொகுதிகளும் கிடைக்கவில்லை. பின்வரும் இரண்டு தொகுதிகள் மிகவும் முக்கியம்ஃ ![வெளிப்படைத்தன்மையை 50 சதவீதமாக அமைக்கவும்](../../../media/bricks/Set_transparency_to_50_pct_.png) மற்றும் ![60 சதவிகிதத்திற்கு அமைக்கப்பட்ட அளவு](../../../media/bricks/Set_size_to_60_pct_.png)

**பார்வை பிரிவு(1)** இல், நீ ஒரு பின்னணியை சேர்க்கிறீர்கள்.

![பின்னணி சேர்க்கவும்](../../../media/getting-started/grafik-14.png)\
இதை செய்ய, + சின்னத்தை தட்டவும்.\
[படத்தைத் திற](../../../media/getting-started/grafik-14.png)

நீ உன் சொந்த படங்களை பதிவேற்றலாம், முன்பே வரையறுக்கப்பட்ட பின்னணிகளைப் பயன்படுத்தலாம் அல்லது ஒரு பின்னணியை நீங்களே உருவாக்கலாம்.

**வரை**: நீ உன் சொந்த பின்னணி உருவாக்க முடியும் **Pocket Paint**. Pocket Paint ஒரு வரைதல் திட்டம் ([பற்றி மேலும் Pocket Paint](https://catrobat.org/pocket-paint/))

**தோற்றங்கள்**: முன்பே தயாரிக்கப்பட்ட பின்னணிகளின் தொகுப்பிலிருந்து ஒன்றைத் தேர்ந்தெடுக்கவும் ([மீடியா நூலகம் பற்றி மேலும்](../elements/medialibrary.md)).

**படத்தொகுப்பு**: உன் ஸ்மார்ட்போனின் கேலரியில் இருந்து ஒரு படத்தை நீ தேர்வு செய்யலாம்.

**கேமரா**: உன் சாதனத்தின் கேமராவைப் பயன்படுத்தி ஒரு புகைப்படத்தை எடுத்து பின்னணியாக சேர்க்கலாம்.

![ஊடக நூலகத்திலிருந்து தேர்வு செய்யவும்](../../../media/getting-started/grafik-17.png)\
பின்புற அம்பு மேல் வலது பக்கத்தில் கிளிக் செய்து **திட்டக் காட்சி** ஐ திரும்பவும்.\
[படத்தைத் திற](../../../media/getting-started/grafik-17.png)

நீ இப்போது ஒரு பின்னணியைச் சேர்த்துள்ளீர்கள்.
