இந்த பயிற்சியில், உன் முதல் திட்டத்தை உருவாக்கத் தொடங்க நீ தெரிந்து கொள்ள வேண்டிய அனைத்தையும் Pocket Code கற்றுக் கொள்வீர்கள். பயன்பாட்டை எவ்வாறு பதிவிறக்கம் செய்வது, அதைத் திறப்பது மற்றும் புதிய திட்டத்தை உருவாக்குவது ஆகியவற்றை படிப்படியாக நாங்கள் உனக்கு வழிகாட்டுவோம்.

இது முதல் பயிற்சி, உனக்கு எந்த முந்தைய அறிவும் தேவையில்லை.

எனவே, நீ என்ன காத்திருக்கிறீர்கள்? உன் தொலைபேசி எடுத்து இப்போது தொடங்க!

*இங்கே நீ பயிற்சி பதிவிறக்க முடியும் PDF-பார்மாட்டில்ஃ:*

[PDFஐத் திற](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code இன் நிறுவல்

முதலில், நீ உன் சாதனத்தில் Pocket Code பயன்பாட்டை நிறுவ வேண்டும். இந்த படிக்கு Google கணக்கு தேவை. இப்போது உன் சாதனம் பயன்பாட்டை பதிவிறக்கி நிறுவும். உன் இணைய இணைப்பைப் பொறுத்து இந்த படி சிறிது நேரம் ஆகலாம்.

![புதிய திட்டம் (2)](../../../media/game-tutorials/New-Program-2.png)\
நீ Google Play Store என்ற இடத்தில் “Pocket Code” தேடுவதன் மூலம் பயன்பாட்டைக் காணலாம் மற்றும் “நிறுவ” என்ற எண்ணில் அழுத்தி அதை பதிவிறக்கம் செய்யலாம்.\
[படத்தைத் திற](../../../media/game-tutorials/New-Program-2.png)

நீ வெற்றிகரமாக பதிவிறக்கம் செய்து நிறுவிய பின் Pocket Code பயன்பாட்டை உன் சாதனத்தின் அடிப்படையில், பயன்பாட்டு அட்டையில் அல்லது உன் முகப்பு திரையில் காணலாம். நீ எளிதாக பயன்பாட்டை எடுத்து அதை நீ விரும்பும் எந்த இடத்திலும் வைக்கலாம்.

### 2. பயன்பாட்டைத் தொடங்கவும்

![புதிய திட்டம் (1)](../../../media/game-tutorials/New-Program-1.png)\
நீ பயன்பாட்டைத் திறக்கும்போது, பல்வேறு வகைகளை காணலாம்ஃ.\
[படத்தைத் திற](../../../media/game-tutorials/New-Program-1.png)

### 3. புதிய திட்டத்தை உருவாக்குதல்

அடுத்த படி, ஒரு புதிய திட்டத்தை உருவாக்குவது. இப்போது நீ ஒரு திட்டத்தின் பெயரை உள்ளிட்டு உன் திட்டம் நிலப்பரப்பு அல்லது இல்லை என்பதைத் தேர்ந்தெடுக்க வேண்டும். “சரி” ஐ அழுத்தி, திட்டம் உருவாக்கப்படுகிறது.

![புதிய திட்டம்](../../../media/game-tutorials/New-Program.png)\
அதைச் செய்ய, நீ வலது கீழ் மூலையில் உள்ள மஞ்சள் பிளஸ் பொத்தானை அழுத்தலாம்.\
[படத்தைத் திற](../../../media/game-tutorials/New-Program.png)

### 4. நீ அதை செய்தாய்!

இப்போது நீ நிறுவியுள்ளீர்கள் Pocket Code மற்றும் ஒரு புதிய திட்டத்தை எவ்வாறு உருவாக்குவது என்பதை அறிவீர்கள். இப்போது நீ நிரலாக்க தொடங்க முடியும்!

இதைச் செய்ய, ஒரு திட்டத்தில் புதிய பொருளை எவ்வாறு உருவாக்குவது என்பதை நீ அறிந்து கொள்ள வேண்டும். **[புதிய பொருள்](new-object.md)** - பயிற்சியைப் பார், அங்கு எல்லாம் படிப்படியாக உனக்கு விளக்கப்படும்.
