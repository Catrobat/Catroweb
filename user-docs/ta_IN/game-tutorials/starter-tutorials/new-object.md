இந்த பயிற்சியில், உன் திட்டத்தில் ஒரு புதிய பொருளை எவ்வாறு உருவாக்குவது மற்றும் இதற்கான பல்வேறு சாத்தியங்கள் என்ன என்பதை நீ கற்றுக் கொள்வீர்கள்.

![புதிய பொருள்](../../../media/game-tutorials/New-Object.png)

இதைச் செய்ய, நீ ஏற்கனவே Pocket Code பயன்பாட்டை பதிவிறக்கம் செய்து புதிய திட்டத்தை எவ்வாறு உருவாக்குவது என்பதை அறிந்து கொள்ள வேண்டும். இதற்கு உனக்கு உதவி தேவைப்பட்டால், **[புதிய திட்டம்](new-project.md)** - பயிற்சியைப் பார்க்கலாம்.

*இங்கே நீ பயிற்சி பதிவிறக்க முடியும் PDF-பார்மாட்டில்ஃ:*

[புதிய பொருள்](../../../media/game-tutorials/New-Object.pdf)

### 1. புதிய பொருளை உருவாக்கு

முதலில், உன் புதிய திட்டத்தைத் திறக்க வேண்டும்.

Pocket Code பயன்பாட்டின் முகப்புத் திரையில் நீ அதைக் காண்பீர்கள். நீ ஒன்றுக்கு மேற்பட்ட திட்டங்களை வைத்திருந்தால், “திட்டங்கள்” என்பதை கிளிக் செய்யலாம். பின்னர் உன் புதிய திட்டத்தைத் தேர்ந்தெடுக்கவும். நீ ஒரு புதிய திட்டத்தை உருவாக்கவில்லை அல்லது அதை எப்படி செய்வது என்பது குறித்த கூடுதல் தகவல்கள் தேவைப்பட்டால், **[புதிய திட்டம்](new-project.md)** - பயிற்சியைப் பார்.

### 2. புதிய பொருளை உருவாக்கு

இப்போது நீ ஒரு புதிய பொருளை உருவாக்க தயாராக இருக்கிறீர்கள். அதை செய்ய வலது மூலையில் உள்ள மஞ்சள் பிளஸ் பொத்தானை கிளிக் செய்யவும். நீ தேர்ந்தெடுக்கக்கூடிய ஏழு சாத்தியங்களை வழங்கும் ஒரு புதிய ஜன்னலைக் காண்பீர்கள்.

![புதிய பொருள் (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. படைப்புகளை உருவாக்குவதற்கான வழிகள்

நீ தேர்வு செய்யக்கூடிய சாத்தியக்கூறுகள்ஃ:

![புதிய பொருள் (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. படத்தை வரைதல்

ஆரம்பத்தில் இதை எளிதாக்குவதற்கு, நாம் “வரை” செயல்பாட்டைப் பயன்படுத்தி ஒரு புள்ளியை வரைந்து கொள்ள வேண்டும். நீ Pocket Paint உடன் புள்ளியை வரைந்தவுடன் அதை விட்டுவிடலாம் (ஒரு படி பின்னால் சென்று).

### 5. ஒரு பெயர் சொல்லுங்கள்

இப்போது உன் படத்திற்கு ஒரு பெயரை கொடுக்க வேண்டும்.

### 6. அதை வைக்க

அதன் பிறகு, அதை இடது/வலது அல்லது மேல்/குறுக்கு விரலால் நகர்த்துவதன் மூலம் பார்வைக்கு வைக்க வேண்டும். நீ அதை மேல் வலது மூலையில் உள்ள பொத்தானை கொண்டு சேமிக்க வேண்டும்.

![புதிய பொருள் (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. நீ அதை செய்தாய்!

இப்போது நீ நிரலாக்கக்கூடிய ஒரு பொருளுடன் ஒரு திட்டம் உள்ளது!

இதைச் செய்ய, எந்த குறியீடு தொகுதிகள் கிடைக்கின்றன என்பதை நீ அறிந்து கொள்ள வேண்டும். **[முதல் குறியீடு தொகுதிகள்](first-bricks.md)** - பயிற்சி குறியீடு தொகுதிகளின் பல்வேறு வகைகளை நன்கு கண்ணோட்டமாக்குகிறது. எனினும், நீ உன் முதல் திட்டத்துடன் நேரடியாக தொடங்கலாம். தொடக்கத்தில் இருந்து பொருத்தமான பயிற்சியைத் தேர்ந்தெடுக்கவும்.
