வகுப்பில் Pocket Code பயன்படுத்துவது குறித்து ஆசிரியர்களும் மாணவர்களும் என்ன சொல்கிறார்கள் என்பதைப் பார்.

::video{youtube=75i10o_uv0U}

இந்த வீடியோ Pocket Code எவ்வாறு கற்றல் முறையில் கட்டமைக்கப்படலாம் என்பதைக் காட்டும். ஒரு கற்றல் சூழலில் ஆசிரியர் மற்றும் மாணவர்கள் என்ன பணிகளைச் செய்கிறார்கள் Pocket Code?
