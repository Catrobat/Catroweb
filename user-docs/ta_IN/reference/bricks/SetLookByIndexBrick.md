இந்த குறியீட்டு தொகுதி ஒரு நடிகரின் தோற்றத்தை தோற்றங்களின் பட்டியலில் அதன் நிலை அடிப்படையில் ஒரு தோற்றமாக மாற்றுகிறது. அது ஒரு எண் அலமாரி இருந்து ஒரு ஆடை தேர்வு போன்றது.
