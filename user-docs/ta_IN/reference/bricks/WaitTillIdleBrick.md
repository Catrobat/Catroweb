![காத்திருங்கள்-மற்ற அனைத்து எழுத்துக்கள் நிறுத்தப்பட்டது வரை குறியீடு தொகுதி](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

இந்த குறியீடு தொகுதி தற்போதைய ஸ்கிரிப்டை திட்டத்தில் உள்ள மற்ற அனைத்து ஸ்கிரிப்ட்களும் இயங்குவதை முடிக்கும் வரை நிறுத்துகிறது. மற்றவை எல்லாம் முடிவடையும் வரை உங்களது திரைக்கதைகளை நிறுத்தி வைப்பதை கற்பனை செய்து பார். இது உன் தற்போதைய ஸ்கிரிப்டில் அடுத்த படிகளை தொடங்குவதற்கு முன் வேறு எந்த செயல்களும் நடக்காது என்பதை உறுதிப்படுத்த பயனுள்ளதாக இருக்கும்.
