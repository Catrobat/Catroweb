![இந்தத் திசையை நோக்கு: பட்டங்கள்](../../../media/bricks/point_in_direction__degrees_brick2.png)

பொருள் ஒரு குறிப்பிட்ட கோணத்திற்கு நோக்கிய திசையை அமைக்கிறது. அது உன் கதாபாத்திரத்திற்கு ஒரு குறிப்பிட்ட திசையை நோக்கிச் செல்லச் சொல்வது போன்றது, அதாவது மேல், கீழ், இடது அல்லது வலது.
