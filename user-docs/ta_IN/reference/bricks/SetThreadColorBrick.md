![நூலின் நிறத்தை இதற்கு அமை: ’#ff0000′](../../../media/bricks/Set_thread_color_to_ff0000.png)

இந்த தொகுதியைப் பயன்படுத்தி, உன் தையல் திட்டத்திற்கான நூலின் நிறத்தை மாற்றலாம். உன் நிரலில் நிறம் காண்பிக்கப்படும். இதன் பொருள், இந்த நிறங்களைத் தான் எம்பிராய்டரி பயன்படுத்தும் என்று அல்ல.
