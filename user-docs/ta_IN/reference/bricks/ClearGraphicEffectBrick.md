![வரைகலை விளைவுகளை நீக்கு](../../../media/bricks/Clear_graphic_effects.png)

இந்த குறியீட்டு தொகுதி ஒரு நடிகருக்கு பயன்படுத்தப்படும் எந்தவொரு காட்சி விளைவுகளையும் நீக்குகிறது, அதை அதன் அசல் தோற்றத்திற்கு திருப்பித் தருகிறது. அது ஒரு புழுதி ஜன்னலை சுத்தம் செய்வது போல் மீண்டும் தெளிவாக இருக்கும்.
