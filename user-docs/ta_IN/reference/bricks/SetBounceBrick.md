![துள்ளல் காரணியை இதற்கு அமை:](../../../media/bricks/set_bounce_factor_to_brick.png)

பொருள் எதையாவது தாக்கும்போது எவ்வளவு குதிக்கிறது என்பதை அமைக்கிறது. அதிக சதவீதம் என்றால், அதிக உயர்வு. அது உன் கதாபாத்திரம் சுவர்கள் அல்லது பிற பொருள்களை எவ்வளவு தூரம் தாக்கும் என்பதை தீர்மானிப்பது போன்றது.
