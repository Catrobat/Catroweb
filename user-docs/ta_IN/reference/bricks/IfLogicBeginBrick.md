![இல்லையெனில் குறியீடு தொகுதி](../../../media/bricks/if_else_brick2.png)

*ஒரு நிபந்தனை உண்மைதானா என்று சரிபார்க்கிறது, அது இருந்தால் ஒரு தொகுப்பு அறிவுறுத்தல்களை இயக்குகிறது, அது இல்லையென்றால் மற்றொரு தொகுப்பை இயக்குகிறது. இது இரண்டு விருப்பங்களை வழங்குவது போன்றதுஃ “இது உண்மை என்றால் இதைச் செய்; இல்லையெனில் அதைச் செய்.”*

![காட்சியைத் தொடங்கு:](../../../media/bricks/StartScene.png)

காட்சி தொடங்கும் போது, மாறி X 0 ஆக அமைக்கப்படுகிறது.

![வேறு](../../../media/bricks/IfElse.png)

இப்போது விலங்கைத் தட்டினால், X மாடுலோ 2 உண்மையா என்று கட்டளைத் தொகுதி பார்க்கும். அதாவது, X ஓர் ஒற்றை எண்ணா என்று பார்க்கும்.

இதுபோன்ற நிலையில், ஒலி Tweet1 இயங்கவும், மாறி X 1 அதிகரிக்கவும்.

இல்லையெனில், X சமமாக இருந்தால், மட்டுமே X 1 அதிகரிக்கிறது.

நிறைவேற்றப்பட வேண்டிய அறிக்கைகள் நிபந்தனையின் முடிவு என்ற எண்ணால் பிரிக்கப்பட்டுள்ளன.
