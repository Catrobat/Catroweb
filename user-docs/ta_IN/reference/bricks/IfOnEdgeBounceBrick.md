![ஓரத்தைத் தொட்டால், துள்ளு](../../../media/bricks/edge_bounce_brick.png)

அது திரையின் விளிம்பில் விழுந்தால் பொருள் மீண்டும் குதிக்கிறது. உன் கதாபாத்திரம் விளையாட்டுப் பகுதியின் விளிம்பில் விழுந்து பந்தைப்போல பின்னோக்கி குதித்துச் செல்லும் என்பதை கற்பனை செய்து பார்.
