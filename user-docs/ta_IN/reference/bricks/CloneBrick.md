![இதன் குளோனை உருவாக்கு:](../../../media/bricks/create_clone_of_brick2.png)

இந்த குறியீடு தொகுதி, ஒரு கிளோன் எனப்படும் குறிப்பிட்ட பொருளின் நகலை உருவாக்குகிறது. இது அசல் போலவே செயல்படுகிறது. உன் விளையாட்டில் ஒரு கதாபாத்திரம் அல்லது பொருளின் நகலை கற்பனை செய்து பார். குளோன் அதன் சொந்த நடத்தை மற்றும் எழுத்துக்களைக் கொண்டிருக்கலாம், இது ஒரு பொருளின் பல நிகழ்வுகளை உருவாக்க உன்னை அனுமதிக்கிறது.
