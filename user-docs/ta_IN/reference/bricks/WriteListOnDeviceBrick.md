உன் சாதனத்தில் பட்டியலை சேமிக்கவும், பின்னர் பயன்பாட்டை மூடிய பின்பு அதைப் பயன்படுத்தலாம். இதை உன் பிடித்த சமையல் குறிப்புகளை டிஜிட்டல் உணவுப் புத்தகத்தில் சேமிப்பது போல நினைத்துப் பார்.
