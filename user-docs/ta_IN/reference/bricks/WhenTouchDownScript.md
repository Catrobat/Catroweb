![மேடை தட்டப்படும்போது](../../../media/bricks/When_stage_is_tapped_btn.png)

திரை தொடுவதன் போது ஸ்கிரிப்ட் இயங்குகிறது.

தொகுதி *“தட்டப்படும்போது”* இன் வித்தியாசம் என்னவென்றால், முழு திரையிலும் *“மேடை தட்டப்படும்போது”* பொருந்தும், அதே நேரத்தில் *“தட்டப்படும்போது”* தனிப்பட்ட ஸ்ப்ரீட் அல்லது பொருள்களுக்கு குறிப்பிட்டது.
