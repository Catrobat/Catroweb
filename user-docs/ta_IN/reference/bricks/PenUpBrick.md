![பேனாவை மேலே தூக்கு](../../../media/bricks/Pen_up_.png)

இந்த குறியீடு தொகுப்பு நடிகர் வரைதல் நிறுத்த போது அது நகரும் செய்கிறது. அது ஒரு பேனாவை காகிதத்திலிருந்து எடுத்துக்கொள்வது போல் இருக்கிறது, அதனால் அது இனி வரைவதில்லை.
