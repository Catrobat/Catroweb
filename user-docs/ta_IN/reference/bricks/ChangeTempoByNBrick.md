இந்த குறியீட்டு தொகுதி ஒரு நிமிடத்திற்கு குறிப்பிட்ட எண் துடிப்புகளால் இசையின் வேகத்தை மாற்றுகிறது. அது ஒரு பாடலின் வேகத்தை அதிகரிப்பது அல்லது குறைப்பது போன்றது.
