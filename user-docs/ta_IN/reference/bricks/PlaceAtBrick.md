![இங்கே வை:](../../../media/bricks/place_at_x_y_brick.png)

x மற்றும் y ஆயத்தொகுப்புகள் மூலம் வரையறுக்கப்பட்ட திரையில் ஒரு குறிப்பிட்ட இடத்திற்கு பொருளை நகர்த்துகிறது. அது உன் கதாபாத்திரத்தை ஒரு சரியான இடத்திற்கு தொலைதூரமாக்குவது போன்றது.

கார்த்தெசியன் தரை போன்ற ஒரு ஆயத்த அமைப்பில் நிலை அமைக்கப்பட்டுள்ளதுஃ x மற்றும் y அச்சுகள் திரையின் மையத்தை கடந்து செல்லும், எனவே x = 0 மற்றும் y = 0 என்பது திரையின் நடுவில் உள்ளது.
