![பின்னணியை அமைத்துக் காத்திரு: புதியது](../../../media/bricks/Set_background_and_wait_new.png)

இந்த குறியீடு தொகுப்பு ஒரு புதிய பின்னணியை அமைக்கிறது மற்றும் ஸ்கிரிப்டை தொடங்குவதற்கு முன் மாற்றம் முடிக்கப்படும் வரை காத்திருக்கிறது. அது ஒரு நாடகத்தில் இயற்கையை மாற்றிவிட்டு, புதிய காட்சியை முழுமையாக அமைக்க காத்திருப்பது போன்றது.
