![நீ குளோனாகத் தொடங்கும்போது](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

விரும்பிய செயல்களைச் செய்ய அறிவுறுத்தல்களுடன் ஒரு பொருளின் உருவாக்கப்பட்ட குளோனை இயக்குதல். இந்த செயல்முறை மூல பொருளின் செயல்பாட்டை பிரதிபலிக்கும், அதே நேரத்தில் குளோனை சுயாதீனமாக கட்டுப்படுத்தும். குறிப்பிட்ட தேவைகளை பூர்த்தி செய்ய குளோன் பொருளின் பல்வேறு நடத்தைகள் அல்லது பண்புகள் குறிப்பிடப்படலாம்.
