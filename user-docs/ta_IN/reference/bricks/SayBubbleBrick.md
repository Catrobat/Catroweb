இந்த குறியீட்டு தொகுப்பு நடிகருக்கு ஒரு உரையாடல் பொம்பலை வரையறுக்கப்படாத காலத்திற்கு காண்பிக்கும். உன் கதாபாத்திரம் பேசுகிறது போல் இருக்கிறது நீ அவர்களை நிறுத்தச் சொல்லும் வரை அது தொடரும்.
