இந்த குறியீட்டு தொகுதி அனைத்து ஒலிகளின் அளவை ஒரு குறிப்பிட்ட சதவீதத்திற்கு சரிசெய்கிறது. அது ஒலிகளின் சத்தத்தை அமைக்க, ஒலிகளின் அளவை அமைப்பது போன்றது.
