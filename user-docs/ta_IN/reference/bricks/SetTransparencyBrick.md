இந்த குறியீட்டு தொகுதி ஒரு நடிகரின் வெளிப்படைத்தன்மையை நிர்ணயிக்கிறது, 0% முழுமையாக வெளிப்படையானது மற்றும் 100% முழுமையாக வெளிப்படையானது. அது ஒரு படத்தின் ஒளிச்சோலை சரிசெய்வது போன்றது.
