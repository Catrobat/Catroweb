![இதை நோக்கித் திரும்பு:](../../../media/bricks/point_towards_brick.png)

பொருள் மற்றொரு பொருளின் முகத்தை அல்லது எலி-பாயிண்டரை நோக்கிச் செல்லும். உன் கதாபாத்திரத்திற்கு எப்போதும் ஒரு குறிப்பிட்ட இலக்கை அல்லது திசையை பார்க்கச் சொல்லுங்கள் என்று கற்பனை செய்து பார்.
