*குறிப்பிட்ட மதிப்பு அல்லது செயல்பாடு உண்மை ஆகும் வரை காத்திருக்கிறது, பின்னர் ஸ்கிரிப்டை இயக்குகிறது.*

![காட்சியைத் தொடங்கு:](../../../media/bricks/StartScene.png)

காட்சி தொடங்கும் போது, மாறி X 0 ஆக அமைக்கப்படுகிறது.

![தட்டப்படும்போது Modulo](../../../media/bricks/WhenTappedWhenModulo.png)

விலங்கு இப்போது தட்டுகிறது என்றால், X 1 அதிகரிக்கிறது.

X modulo 2 உண்மை எனும் போது, அதாவது X ஒரு வித்தியாசமான எண்ணாக இருந்தால், Tweet1 ஒலி விளையாடப்படுகிறது.
