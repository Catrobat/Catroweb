![திசைவேகத்தை இதற்கு அமை: x y](../../../media/bricks/set_velocity_to_x__y__brick.png)

பொருளின் வேகத்தையும் திசையையும் அமைக்கிறது. இது உன் கதாபாத்திரத்திற்கு எவ்வளவு வேகமாகவும் எந்த திசையில் செல்ல வேண்டும் என்பதை ஆரம்பத்தில் இருந்து சொல்லும் மாதிரி.
