![உராய்வை இதற்கு அமை:](../../../media/bricks/set_friction_to_brick2.png)

பொருளின் மீது செலுத்தப்படும் சிரமத்தின் அளவை சரிசெய்கிறது, இது எவ்வளவு எளிதாக உருகி அல்லது மெதுவாகிறது என்பதை பாதிக்கிறது. அது உன் கதாபாத்திரம் மேற்பரப்பு மிதமான மாற்றுவது போன்றது - மேலும் சிராய்ப்பு குறைவாக நகரும் பொருள்.
