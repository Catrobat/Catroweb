![1 துடிப்புகளுக்கு இடைவெளி](../../../media/bricks/Pause_for_1_beats.png)

இந்த குறியீடு தொகுப்பு தொடங்குவதற்கு முன் உரை ஒரு குறிப்பிட்ட எண்ணிக்கையிலான துடிப்புகள் காத்திருக்க செய்கிறது. அடுத்த இசையை அல்லது ஒலியை இயக்குவதற்கு முன் ஒரு பாடலில் சிறிது இடைவெளி எடுப்பது போன்றது. உன் செயல்திறனை ஒரு நிமிடம் நிறுத்தி, துடிப்புகளை எண்ணி, பின்னர் மீண்டும் தொடங்குவதை கற்பனை செய்து பார்.
