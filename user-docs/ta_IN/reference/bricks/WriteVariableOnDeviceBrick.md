![மாறியைச் சாதனத்தில் எழுது: புதியது](../../../media/bricks/Write_variable_on_device_new.png)

ஒரு மாறி மதிப்பை உன் சாதனத்தில் சேமித்து, பயன்பாட்டை மூடிய பின்பு அதை பின்னர் பயன்படுத்தலாம். அது உன் தொலைபேசியில் ஒரு குறிப்பை எழுதி பின்னர் நினைவில் கொள்வது போன்றது.
