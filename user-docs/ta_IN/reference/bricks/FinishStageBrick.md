![இறுதி கட்டம் குறியீடு தொகுதி](../../../media/bricks/finish-stage-brick.png)

இந்த குறியீடு தொகுப்பு அனைத்து ஸ்கிரிப்டுகள் நிறுத்துகிறது மற்றும் தற்போதைய நிலை அல்லது காட்சி முடிவுக்கு. இது, “இந்தத் திட்டத்தின் பகுதி முடிந்துவிட்டது.” எல்லாம் நிறுத்தப்படும் என்று சொல்வது போன்றது, மற்றும் திட்டம் வேறு காட்சியில் செல்லலாம் அல்லது முற்றிலும் முடிவடையும். உன் திட்டத்தின் ஒரு குறிப்பிட்ட கட்டத்தை அல்லது நிலைகளை முடிக்க விரும்பும் போது இதைப் பயன்படுத்தவும்.
