![இதன்மீது மோதித் துள்ளும்போது:](../../../media/bricks/when_you_bounce_off_brick2.png)

ஒரு குறிப்பிட்ட மேற்பரப்பு அல்லது பொருளிலிருந்து object bounces போது ஏற்படும் ஒரு எதிர்வினை அல்லது நடவடிக்கை அமைக்கிறது. அது சொல்லும் போன்றது, “என் கதாபாத்திரம் ஒரு சுவரில் அல்லது வேறு பொருளில் இருந்து குதிக்கும் போதெல்லாம் இந்த செயலைச் செய்.”
