![அமை-ஈர்ப்பு குறியீடு தொகுதி](../../../media/bricks/set-gravity-brick.png)

திட்டத்தில் உள்ள அனைத்து பொருள்களுக்கும் பொருந்தும் ஈர்ப்பை சரிசெய்கிறது. அது ஈர்ப்பு மூலம் பொருள்கள் எவ்வாறு கீழே அல்லது பக்கவாட்டில் இழுக்கப்படுகின்றன என்பதை மாற்றுவது போன்றது, அவை எப்படி விழுகின்றன அல்லது நகர்கின்றன என்பதை பாதிக்கிறது.
