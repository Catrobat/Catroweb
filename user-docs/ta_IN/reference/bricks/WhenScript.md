![தட்டப்படும்போது](../../../media/bricks/when-tapped2.png)

பொருள் தட்டுவதற்குள் ஸ்கிரிப்ட் இயங்குகிறது.

தொகுதி *“மேடை தட்டப்படும்போது”* வித்தியாசம் என்னவென்றால், *“தட்டப்படும்போது”* தனிப்பட்ட ஸ்ப்ரீட் அல்லது பொருள்களுக்கு குறிப்பிட்டது, அதே நேரத்தில் *“மேடை தட்டப்படும்போது”* முழு திரையுக்கும் பொருந்தும்.
