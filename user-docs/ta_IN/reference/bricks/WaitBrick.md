அடுத்த கட்டத்திற்கு செல்லும் முன், உன் எழுத்துருவை ஒரு குறிப்பிட்ட காலத்திற்கு நிறுத்தி வைக்கவும். ஒரு டைமர் அமைத்து, அடுத்ததைச் செய்வதற்குள் அது வெடிக்கும் வரை காத்திருப்பதாக கற்பனை செய்து பார்.
