![ஒலியைத் தொடங்கு:](../../../media/bricks/start_sound_brick2.png)

இந்த குறியீடு தொகுப்பு தேர்ந்தெடுக்கப்பட்ட ஒலியை உடனடியாக இயக்குகிறது. உனக்கு பிடித்த பாடலை அழுத்தி விளையாடுவதை கற்பனை செய்து பார்; அந்த தருணத்தில் இருந்து ஒலி இசைக்கத் தொடங்குகிறது.
