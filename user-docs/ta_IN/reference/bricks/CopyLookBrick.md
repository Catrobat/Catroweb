![தோற்றத்தை நகலெடுத்து இப்பெயரிடு: "பிரதி பெயர்"](../../../media/bricks/Copy_look_and_name_it_name_of_copy_.png)

இந்த குறியீடு தொகுதி ஏற்கனவே இருக்கும் தோற்றத்தை இரட்டை மற்றும் அது ஒரு புதிய பெயர் கொடுக்கிறது. அது ஒரு வரைபடத்தை நகலெடுத்து அதை வேறு விதமாக குறிப்பது போன்றது.
