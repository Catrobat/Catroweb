இந்த குறியீடு தொகுதி நடிகர் பயன்படுத்திய பேனாவின் நிறத்தை மாற்றுகிறது. அது வரைவதற்குள் வேறு நிற பேனாவை மாற்றுவது போல.

**சிவப்பு, பச்சை, நீலம் (RGB)**: நிறங்கள் பரந்த அளவிலான நிறங்களை உருவாக்க, சிவப்பு, பச்சை மற்றும் நீல ஒளியின் வெவ்வேறு தீவிரங்களை RGB நிற மாதிரி பயன்படுத்துகிறது. ஒவ்வொரு நிற உறுப்பு (சிவப்பு, பச்சை மற்றும் நீலம்) 0 முதல் 255 வரை மதிப்பைக் கொண்டிருக்கலாம்ஃ:

- **சிவப்பு**: நிறத்தின் சிவப்பு கூறு. அதிக மதிப்பு என்பது சிவப்பு நிறத்தை அதிகரிக்கும்.
- **பச்சை**: நிறத்தின் பச்சை கூறு. அதிக மதிப்பு என்றால் பசுமை.
- **நீல நிறம்**: நீல நிறத்தின் உறுப்பு. அதிக மதிப்பு என்றால் நீல நிறம் அதிகம்.

சிவப்பு, பச்சை மற்றும் நீல நிறத்திற்கான வெவ்வேறு மதிப்புகளை இணைப்பதன் மூலம் நீ எந்த நிறத்தையும் உருவாக்கலாம். உதாரணமாகஃ:

- `RGB(255, 0, 0)` என்பது தூய சிவப்பு நிறம்.
- `RGB(0, 255, 0)` என்பது பச்சை நிறம்.
- `RGB(0, 0, 255)` என்பது வெறும் நீல நிறம்.
- `RGB(255, 255, 255)` வெள்ளை நிறம் (அதிகபட்சம் சிவப்பு, பச்சை மற்றும் நீலம்).
- `RGB(0, 0, 0)` கருப்பு (படங்கள் இல்லை).

இந்த நிறங்களை வெவ்வேறு அளவுகளில் கலப்பது டிஜிட்டல் திரையில் நீ காணும் அனைத்து வண்ணங்களையும் உருவாக்குகிறது.
