![நிபந்தனை:](../../../media/bricks/if_brick2.png)

*ஒரு நிபந்தனை உண்மைதானா என்று சரிபார்க்கிறது, அது இருந்தால், அறிவுறுத்தல்களை இயக்குகிறது. இது சொல்வது போல, “இது உண்மை என்றால், இதைச் செய்.”*

![காட்சியைத் தொடங்கு:](../../../media/bricks/StartScene.png)

காட்சி தொடங்கும் போது, மாறி X 0 ஆக அமைக்கப்படுகிறது.

![நிபந்தனை:](../../../media/bricks/If.png)

விலங்கு இப்போது தட்டுகிறது என்றால், மாறி X 1 அதிகரிக்கிறது.

நிரல் மாறி X மதிப்பு 2க்கு சமமா என்பதை சரிபார்க்கிறது.

இது நடந்தால், ஒலி Tweet1 இயங்கும் மற்றும் மாறி X 0 ஆக அமைக்கப்படும்.
