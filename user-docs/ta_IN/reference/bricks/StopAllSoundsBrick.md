![எல்லா ஒலிகளையும் நிறுத்து](../../../media/bricks/Stop_all_sounds.png)

இந்த குறியீடு தடுப்பு தற்போது ஒலிகளை இயக்குவதை நிறுத்துகிறது. அதை ஒரு இசை இயக்கி மீது நிறுத்த பொத்தானை அழுத்தி அனைத்தையும் அமைதியாக வைத்திருப்பதைப் போல நினைத்துப் பார்.
