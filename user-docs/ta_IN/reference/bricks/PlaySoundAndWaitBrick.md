![ஒலியைத் தொடங்கிக் காத்திரு:](../../../media/bricks/start_sound_and_wait_brick.png)

இந்த குறியீடு தொகுதி தேர்ந்தெடுக்கப்பட்ட ஒலியை இயக்குகிறது மற்றும் அடுத்த செயலுக்கு செல்லும் முன் அது முடிவடையும் வரை காத்திருக்கிறது. அது ஒரு பாடலை அழுத்தி விளையாடுவது போலவும், பாடல் முடிவடையும் வரை வேறு எதுவும் செய்யாமல் இருப்பது போலவும் இருக்கிறது.
