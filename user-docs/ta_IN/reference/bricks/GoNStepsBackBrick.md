![பின்னோக்கிச் செல் அடுக்கு](../../../media/bricks/go_back__layer_brick2.png)

பார்வை வரிசையில் ஒரு குறிப்பிட்ட எண்ணிக்கையிலான அடுக்குகளை மீண்டும் கொண்டு செல்லும். இது உன் கதாபாத்திரத்தை திரையில் உள்ள மற்ற பொருள்களுக்கு பின்னால் அனுப்புவது போன்றது.
