![காட்சி தொடங்கும்போது](../../../media/bricks/When_scene_starts_btn2.png)

நீ இந்த தொகுதி பயன்படுத்தினால், திரைக்கதை காட்சி தொடங்கும் போது உடனடியாக தொடங்குகிறது. ஒரு காட்சி உன் நிகழ்ச்சியின் ஆரம்பம். ஒரு காட்சி என்பது உன் திட்டத்தில் புதிய காட்சியாகும், அதில் மற்ற கூறுகள் காட்டப்பட்டு வேறுபட்ட தொடர்புகள் ஏற்படலாம். உன் நிகழ்ச்சியில் பல்வேறு கட்டங்களுக்கு பல காட்சிகள் இருக்கலாம். உதாரணமாக ஒரு காட்சி அறிமுகத்திற்கு, ஒரு காட்சி பிரதான மெனுவுக்கு, ஒன்று முதல் நிலைக்கு, ஒன்று இரண்டாவது நிலைக்கு மற்றும் பல. எளிமையான நிகழ்ச்சிகளில், ஒரு காட்சி போதும், பின்னர் உன் நிகழ்ச்சியின் ஆரம்பம் கூட காட்சியின் தொடக்கமாகும்.

ஒவ்வொரு எழுத்துக்களையும் போலவே, இது ஒரு நிகழ்வு குறியீடு தொகுதி மூலம் தொடங்குகிறதுஃ நிகழ்வு வரையறுக்கிறது **எப்போ** ஸ்கிரிப்ட் தொடங்குகிறது, குறியீடு தடுப்புகள் அது நிரலுக்கு **என்ன** செய்யச் சொன்ன பிறகு.
