![பனிப்பொழிவு விளைவு](../../../media/bricks/Fade_particle_effect_in.png)

இந்த தொகுதி உன் கதாபாத்திரத்திற்கு துகள்களை சேர்க்கிறது மற்றும் படிப்படியாக அவற்றை காலப்போக்கில் மறைக்க செய்கிறது. உதாரணமாக, ஒரு துப்பாக்கிச் சூடு காட்சியை உருவாக்கவும், புகை சேர்க்கவும் அல்லது உன் கதாபாத்திரத்தை விரைவாகக் காட்டவும் இதைப் பயன்படுத்தவும்.
