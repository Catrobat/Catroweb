![பின்னணியை இந்த எண்ணுக்கு அமை: 1](../../../media/bricks/Set_background_to_number_1_.png)

இந்த குறியீட்டு தொகுதி பின்னணியை ஒரு குறிப்பிட்ட பின்னணியாக மாற்றும், இது பின்னணிகளின் பட்டியலில் அதன் இடத்தை அடிப்படையாகக் கொண்டது. அது ஒரு பட்டியலில் இருந்து ஒரு குறிப்பிட்ட காட்சியைத் தேர்ந்தெடுப்பது போன்றது.
