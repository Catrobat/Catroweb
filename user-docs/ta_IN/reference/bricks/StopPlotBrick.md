“வரைவதை நிறுத்து” குறியீடு தொகுதி வரைதல் செயல்முறையை நிறுத்துகிறது மற்றும் நீ ஒரு புதிய நிலைக்கு நடிகரை நகர்த்த அல்லது வரைதல் முடிவடைய அனுமதிக்கிறது. அது ஒரு பேனாவை காகிதத்திலிருந்து தூக்கி எறிவது போல் உள்ளது அல்லது வரைவதை நிறுத்துவது போல. நீ வரைபடத்தை முடித்த பிறகு, நீ ஒரு SVG கோப்பாக உன் வடிவமைப்பு சேமிக்க “வரைவை SVG ஆகச் சேமி:” குறியீடு தொகுதி பயன்படுத்த முடியும்.
