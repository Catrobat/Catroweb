இந்த குறியீடு தொகுதி ஒரு நடிகரின் பிரகாசத்தை அதிகரிக்கிறது அல்லது குறைக்கிறது. இது உன் தொலைபேசி திரையில் ஒளிப்பதிவை படிப்படியாக உயர்த்தி அல்லது குறைப்பது போன்றது.
