![வரையத் தொடங்கு](../../../media/bricks/Start_to_plot.png)

இந்த குறியீடு தொகுப்பு நடிகர் நகரும் போது திட்டமிடல் செயல்முறை தொடங்குகிறது. ஒரு வரி வரைவதற்கு காகிதத்தில் பேனாவை வைப்பது போன்றது. நீ வரைபடத்தை நிறுத்திவிட்டு, நடிகரை வேறு இடத்திற்கு நகர்த்த விரும்பினால் “வரைவதை நிறுத்து” குறியீட்டு தொகுப்பைப் பயன்படுத்தலாம், பின்னர் மீண்டும் “வரையத் தொடங்கு” உடன் புதிரைத் தொடங்கவும்.
