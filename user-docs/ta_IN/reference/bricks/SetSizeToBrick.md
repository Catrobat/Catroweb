இந்த குறியீடு தொகுதி ஒரு நடிகரின் அளவை குறிப்பிட்ட சதவீதமாக அமைக்கிறது. அது ஒரு புகைப்படத்தின் உயரத்தை பெரியதாக அல்லது சிறியதாக மாற்றும் அளவுக்கு மாற்றுவது போன்றது.
