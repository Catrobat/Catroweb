![தையலை முடி](../../../media/bricks/Sew_up.png)

உன் நூலின் முடிவை உறுதிப்படுத்தவும், அது உடைந்துவிடாமல் தடுக்கவும் முன்னும் பின்னுமாக நகருங்கள். அது உன் தையல்கள் இடத்தில் இருக்க உறுதி செய்ய ஒரு முனை பிணைப்பது போன்றது.
