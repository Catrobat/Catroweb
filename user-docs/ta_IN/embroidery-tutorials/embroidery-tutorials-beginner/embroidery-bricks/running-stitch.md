இயந்திரம் ஒரு மாறி நீளத்துடன் தொடர்ந்து தையல் செய்ய அனுமதிக்கிறது.

பொதுவாக நீ ஒரு நகர்வு குறியீடு தொகுதி இயங்கும் தையல் இணைக்க.

![10 நீளத்துடன் துடிப்பு தொடங்குங்கள்](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

இயந்திரம் ஒரு இயங்கும் தையலைத் தொடங்குகிறது, இது ஒவ்வொரு **10 படிகள்** தையலையும் துடைக்கும்.

பின்னர் இயந்திரம் நகரும் **200 படிகள்**.

இதன் விளைவாக **20 தையல்கள்**.

![இந்த நீளத்தில் ஓட்டத் தையலைத் தொடங்கு:](../../../../media/embroidery-tutorials/RunningStitch.png)

ஓடும் தையல் ஒரு தையலை எளிதாக்குகிறது, ஏனென்றால் உனக்கு இனி சுழற்சி தேவையில்லை.
