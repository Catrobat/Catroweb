தற்போதைய தையல் நிறுத்தட்டும்.

நீ ஒரு ஓட்டம், zigzag அல்லது மூன்று முறை தையல் தொடங்கும் பிறகு ஊசியின் நிலையை மாற்ற விரும்பினால் இந்த குறியீடு தொகுப்பு தேவைப்படும்.
