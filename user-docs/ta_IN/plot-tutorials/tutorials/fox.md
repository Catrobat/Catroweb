கதை ஆரம்பிக்கும் போது, ஒவ்வொரு நகரும் ஒரு பேனாவுடன் வரைவது போலவே இருக்கும். இவைதான் சதித்திட்டம் செய்பவர் பின்னர் அறுக்கும் வரிகள்.

இந்த நாய்க்குட்டி நேரான கோடுகளால் மட்டுமே தயாரிக்கப்படுகிறது (“நகர் \_\_\_ படிகள்”) மற்றும் திருப்பங்கள்.

**குறிப்பு**: நீ அதை உருவாக்கும் போது உன் நிரலை சோதிக்கவும்.
