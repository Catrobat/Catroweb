في هذا الدرس ستتعلم كل ما تحتاج إلى معرفته عن Pocket Code لتبدأ بإنشاء أول مشروع لك. سنرشدك خطوة بخطوة إلى كيفية تنزيل التطبيق وفتحه وإنشاء مشروع جديد.

![برنامج جديد](../../../media/game-tutorials/New-Program.png)\
سنرشدك خطوة بخطوة إلى كيفية تنزيل التطبيق وفتحه وإنشاء مشروع جديد.\
[افتح الصورة](../../../media/game-tutorials/New-Program.png)

هذا هو أول درس، ولا تحتاج إلى أي معرفة سابقة.

إذًا، ماذا تنتظر؟ أمسك هاتفك وابدأ الآن!

*يمكنك تنزيل الدرس بصيغة PDF هنا:*

[افتح ملف PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. تثبيت Pocket Code

أولًا، تحتاج إلى تثبيت تطبيق Pocket Code على جهازك. تحتاج إلى حساب Google لهذه الخطوة. بعد ذلك سيبدأ جهازك بتنزيل التطبيق وتثبيته. قد تستغرق هذه الخطوة بعض الوقت حسب سرعة الإنترنت لديك.

![برنامج جديد (2)](../../../media/game-tutorials/New-Program-2.png)\
يمكنك إيجاد التطبيق بالبحث عن "Pocket Code" في متجر Google Play، ثم تنزيله بالنقر على "تثبيت".\
[افتح الصورة](../../../media/game-tutorials/New-Program-2.png)

بعد تنزيل Pocket Code وتثبيته بنجاح، يمكنك إيجاد التطبيق في درج التطبيقات أو على الشاشة الرئيسية، حسب جهازك. ويمكنك نقل التطبيق إلى أي مكان تريده بسهولة.

### 2. تشغيل التطبيق

![برنامج جديد (1)](../../../media/game-tutorials/New-Program-1.png)\
عندما تفتح التطبيق، سترى فئات مختلفة.\
[افتح الصورة](../../../media/game-tutorials/New-Program-1.png)

### 3. أنشئ مشروعًا جديدًا

الخطوة التالية هي إنشاء مشروع جديد فعلًا. عليك الآن أن تكتب اسمًا للمشروع وأن تختار إن كان مشروعك أفقيًا أم لا. بالضغط على "موافق" يُنشأ المشروع.

![برنامج جديد](../../../media/game-tutorials/New-Program.png)\
لفعل ذلك، اضغط على زر الزائد الأصفر في الزاوية اليمنى السفلى.\
[افتح الصورة](../../../media/game-tutorials/New-Program.png)

### 4. أحسنت! أنشأت مشروعك الخاص.

الآن قمت بتثبيت Pocket Code وعرفت كيف تنشئ مشروعًا جديدًا. يمكنك الآن أن تبدأ البرمجة!

لتفعل ذلك، عليك أن تعرف كيف تنشئ كائنًا جديدًا في المشروع. اطلع على درس **[كائن جديد](new-object.md)**، ففيه يُشرح كل شيء لك خطوة بخطوة.
