يجعل الآلة تغرز باستمرار بطول متغيّر.

عادةً ما تجمع الغرزة الجارية مع مكعب "تحرّك".

![ابدأ الغرزة الجارية بطول 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

تبدأ الآلة غرزة جارية تغرز كل **10 خطوات**.

ثم تتحرك الآلة **200 خطوة**.

النتيجة **20 غرزة**.

![الغرزة الجارية](../../../../media/embroidery-tutorials/RunningStitch.png)

الغرزة الجارية تجعل خياطة الدرزة أسهل، لأنك لن تحتاج إلى حلقة بعد الآن.

![صورة](../../../../media/embroidery-tutorials/image.png)
