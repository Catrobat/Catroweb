Pocket Code هو التطبيق الرئيسي لـ Catrobat، وهو تطبيق مجاني ومفتوح المصدر على الهاتف يتيح لك إنشاء ألعاب ورسوم متحركة وقصص تفاعلية مباشرة على هاتفك الذكي أو جهازك اللوحي. باستخدام **نظام البرمجة بالكتل** في Pocket Code، يمكنك بناء مشاريعك بتركيب كتل البرمجة معًا، مثل تركيب قطع الأحجية. لا تحتاج إلى أي خبرة في البرمجة، لذلك فهو مناسب جدًا للمبتدئين!

لا يقتصر Pocket Code على المشاريع الرقمية. مع **ميزات ورش الصنع** الجديدة، يمكنك أيضًا تصميم **ملفات SVG لآلات القص بالراسمات**. وهذا يعني أنك تستطيع تحويل إبداعاتك الرقمية إلى أشياء حقيقية، واستكشاف إمكانيات إبداعية تتجاوز الشاشة.

سواء كنت تتعلم البرمجة، أو تجرب أفكارًا جديدة، أو تعلّم البرمجة، يوفّر لك Pocket Code طريقة ممتعة وسهلة للدخول إلى عالم البرمجة.
