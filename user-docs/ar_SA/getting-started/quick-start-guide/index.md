Pocket Code تطبيق برمجة مرئية يتيح لك إنشاء ألعاب ورسوم متحركة وقصص تفاعلية مباشرة على هاتفك الذكي أو جهازك اللوحي. باستخدام واجهة سحب وإفلات سهلة مع "المكعبات" (كتل البرمجة)، يمكنك تصميم مشاريعك دون أي خبرة سابقة في البرمجة. أضف الأصوات والصور والحركة بسهولة لتحيي أفكارك.

سيساعدك هذا الدليل على البدء، بشرح كيفية:

- التنقل في الواجهة،
- إنشاء أول مشروع لك،
- العمل مع الكائنات والخلفيات،
- استخدام المكعبات لبرمجة الأفعال، و
- حفظ مشروعك.

مناسب تمامًا للمبتدئين والمعلمين، فـ Pocket Code يشجع على الإبداع وحل المشكلات والتفكير المنطقي.
