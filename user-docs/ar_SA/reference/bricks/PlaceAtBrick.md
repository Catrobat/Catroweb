ينقل هذا المكعب الكائن إلى موضع محدد على الشاشة، يُحدَّد بالإحداثيات س وص. يشبه نقل شخصيتك فورًا إلى مكان دقيق.
يُحدَّد الموضع في نظام إحداثيات مثل المستوى الديكارتي: محورا س وص يمران بمركز الشاشة، لذلك فإن س = 0 و ص = 0 هما منتصف الشاشة.
