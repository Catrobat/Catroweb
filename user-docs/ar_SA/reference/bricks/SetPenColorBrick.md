![اضبط لون القلم على أحمر 0 أخضر 0 أزرق 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

يغيّر هذا المكعب لون القلم الذي تستخدمه الشخصية. يشبه التبديل إلى قلم بلون مختلف أثناء الرسم.

**أحمر وأخضر وأزرق (RGB)**: يستخدم نموذج RGB شدات مختلفة من الضوء الأحمر والأخضر والأزرق لإنشاء مجموعة واسعة من الألوان. يمكن أن تتراوح قيمة كل مكوّن (أحمر وأخضر وأزرق) بين 0 و255:

- **أحمر**: مكوّن اللون الأحمر. كلما زادت القيمة زاد الأحمر.
- **أخضر**: مكوّن اللون الأخضر. كلما زادت القيمة زاد الأخضر.
- **أزرق**: مكوّن اللون الأزرق. كلما زادت القيمة زاد الأزرق.

بدمج قيم مختلفة للأحمر والأخضر والأزرق يمكنك إنشاء أي لون. مثلًا:

- `RGB(255, 0, 0)` أحمر خالص.
- `RGB(0, 255, 0)` أخضر خالص.
- `RGB(0, 0, 255)` أزرق خالص.
- `RGB(255, 255, 255)` أبيض (أقصى قدر من الأحمر والأخضر والأزرق).
- `RGB(0, 0, 0)` أسود (لا لون).

مزج هذه الألوان بكميات مختلفة يُنشئ كل الألوان التي تراها على الشاشات الرقمية.
