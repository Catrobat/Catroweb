![মন্তব্য:](../../../media/bricks/note_brick2.png)

তোমার স্ক্রিপ্টের মধ্যে একটি মন্তব্য বা নোট যোগ করে যাতে তুমি তোমার কোডের কোন অংশগুলি মনে রাখতে পারো। এটা তোমার প্রকল্পের গতির উপর কোনো প্রভাব ফেলে না। এটা তোমার জন্য একটা আঠালো নোট রেখে যাওয়ার মতো।
