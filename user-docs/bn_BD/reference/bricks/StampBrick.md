এই কোড ব্লক ব্যবহার করে তুমি তোমার চরিত্রের চেহারাটির একটি অনুলিপি পর্দায় রেখে যাও। এটা কাগজে একটি রঙিন স্ট্যাম্প ছাপার মত এবং স্ট্যাম্প ডিজাইনের একটি অনুলিপি ছেড়ে দেওয়া। এইভাবে, তুমি তোমার ব্যাকগ্রাউন্ড উন্নত করবে - তুমি একটি ক্লোন তৈরি করছেন না!
