![যখন মঞ্চে আলতো চাপা হয়](../../../media/bricks/When_stage_is_tapped_btn.png)

স্ক্রিন স্পর্শ করার সময় স্ক্রিপ্টটি চালায়।

ব্লকের পার্থক্য *“যখন আপনাকে আলতো চাপা হয়”* হল যে *“যখন মঞ্চে আলতো চাপা হয়”* পুরো পর্দার জন্য প্রযোজ্য, যখন *“যখন আপনাকে আলতো চাপা হয়”* পৃথক স্প্রাইট বা বস্তুর জন্য নির্দিষ্ট।
