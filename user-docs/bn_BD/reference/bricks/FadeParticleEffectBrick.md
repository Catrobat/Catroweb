এই ব্লকটি তোমার চরিত্রের কণা যোগ করে এবং ধীরে ধীরে সময় অনুযায়ী সেগুলো অদৃশ্য হয়ে যায়। উদাহরণস্বরূপ, এটি ব্যবহার করে ফায়ারওয়ার্ক প্রদর্শন করো, ধোঁয়া যোগ করো বা তোমার চরিত্রটি দ্রুত উপস্থিত করো।
