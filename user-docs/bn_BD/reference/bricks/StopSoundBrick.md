![শব্দ বন্ধ করুন:](../../../media/bricks/Stop_sound_record.png)

এই কোড ব্লকটি একটি নির্দিষ্ট শব্দ বাজানো বন্ধ করে দেয়। এটা যেন একটা গান শোনাতে থামার বোতাম চাপানো, অন্য শব্দ বা সঙ্গীত বাজানো অব্যাহত রাখার মত। কল্পনা করো তোমার চরিত্রকে একটি নির্দিষ্ট সাউন্ড ট্র্যাক বাজানো বন্ধ করতে বলুন।
