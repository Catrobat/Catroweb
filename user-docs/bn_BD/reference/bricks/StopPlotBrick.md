![প্লট করা বন্ধ করুন](../../../media/bricks/Stop_to_plot.png)

“প্লট করা বন্ধ করুন” কোড ব্লকটি প্লটিং প্রক্রিয়াকে বিরতি দেয় এবং তোমাকে অভিনেতাটিকে নতুন অবস্থানে সরিয়ে নিতে বা প্লটিং শেষ করতে দেয়। এটা কাগজ থেকে কলম তুলে নেওয়ার মতো, সেটাকে পুনরায় অবস্থান করতে বা আঁকা বন্ধ করতে। তুমি প্লটিং শেষ করার পরে, তুমি তোমার নকশাটি একটি SVG ফাইল হিসাবে সংরক্ষণ করতে “প্লট SVG হিসেবে সংরক্ষণ করুন:” কোড ব্লক ব্যবহার করতে পারো।
