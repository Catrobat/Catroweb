![যখন আপনি এতে লেগে ফিরে আসেন:](../../../media/bricks/when_you_bounce_off_brick2.png)

একটি নির্দিষ্ট পৃষ্ঠ বা বস্তুর উপর থেকে object bounces যখন ঘটতে একটি প্রতিক্রিয়া বা কর্ম সেট। এটা বলার মতো, “আমার চরিত্র যখনই দেয়াল বা অন্য কোনো বস্তু থেকে লাফিয়ে পড়ে তখন এই কাজটি করো।”
