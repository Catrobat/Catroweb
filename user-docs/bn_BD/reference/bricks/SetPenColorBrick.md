![কলমের রং সেট করুন: o লাল 0 সবুজ 0 নীল 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

এই কোড ব্লকটি অভিনেতা ব্যবহার করা কলমের রঙ পরিবর্তন করে। এটা তো একটা ভিন্ন রঙের কলমে স্যুইচ করার মতো।

**লাল, সবুজ, নীল (RGB)**: রঙিন মডেলটি RGB বিভিন্ন বর্ণের বিস্তৃত বর্ণালী তৈরি করতে লাল, সবুজ এবং নীল আলোর বিভিন্ন তীব্রতা ব্যবহার করে। প্রতিটি রঙের উপাদান (লাল, সবুজ এবং নীল) 0 থেকে 255 এর মধ্যে একটি মান থাকতে পারেঃ:

- **লাল**: রঙের লাল উপাদান। উচ্চ মান মানে আরও লাল।
- **সবুজ**: রঙের সবুজ উপাদান। উচ্চ মানের অর্থ হল সবুজ।
- **নীল**: রঙের নীল উপাদান। উচ্চ মান মানে আরো নীল।

লাল, সবুজ এবং নীল রঙের বিভিন্ন মান একত্রিত করে তুমি যে কোন রং তৈরি করতে পারো। উদাহরণস্বরূপঃ:

- `RGB(255, 0, 0)` হলুদ।
- `RGB(0, 255, 0)` হলুদ।
- `RGB(0, 0, 255)` হলুদ।
- `RGB(255, 255, 255)` হল সাদা (সর্বোচ্চ লাল, সবুজ এবং নীল) ।
- `RGB(0, 0, 0)` কালো (কোন রঙ নেই) ।

এই রংগুলোকে বিভিন্ন পরিমাণে মিশ্রিত করে তুমি ডিজিটাল স্ক্রিনে দেখতে পাচ্ছেন এমন সব রঙ তৈরি করেন।
