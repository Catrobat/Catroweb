এক্স এবং ওয়াই স্থানাঙ্ক দ্বারা সংজ্ঞায়িত পর্দায় একটি নির্দিষ্ট অবস্থানে বস্তু স্থানান্তর করে। এটা ঠিক ঠিক তোমার চরিত্রকে সঠিক জায়গায় টেলিপোর্ট করার মতো।

স্থিতিটি কার্টেসিয়ান সমতল মত একটি সমন্বয় সিস্টেমে সেট করা হয়ঃ এক্স এবং ওয়াই অক্ষগুলি স্ক্রিনের কেন্দ্র দিয়ে যায়, তাই x = 0 এবং y = 0 স্ক্রিনের মাঝখানে।
