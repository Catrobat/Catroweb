![যখন আপনাকে আলতো চাপা হয়](../../../media/bricks/when-tapped2.png)

বস্তুর ট্যাপ করার সময় স্ক্রিপ্ট চালায়।

ব্লকের পার্থক্য *“যখন মঞ্চে আলতো চাপা হয়”* হল যে *“যখন আপনাকে আলতো চাপা হয়”* পৃথক স্প্রাইট বা বস্তুর জন্য নির্দিষ্ট, যখন *“যখন মঞ্চে আলতো চাপা হয়”* পুরো পর্দায় প্রযোজ্য।
