Pocket Code হল Catrobat এর প্রধান অ্যাপ্লিকেশন, একটি বিনামূল্যে এবং ওপেন সোর্স মোবাইল অ্যাপ যা তোমাকে তোমার স্মার্টফোন বা ট্যাবলেটে সরাসরি গেম, অ্যানিমেশন এবং ইন্টারেক্টিভ গল্প তৈরি করতে দেয়। **ব্লক ভিত্তিক কোডিং সিস্টেম** in Pocket Code দিয়ে তুমি কোড ব্লকগুলি একসাথে কেটে প্রকল্প তৈরি করতে পারো - যেমন একটি পাজল টুকরা একসাথে করা। প্রোগ্রামিংয়ের কোন অভিজ্ঞতা প্রয়োজন হয় না, তাই এটি নতুনদের জন্য নিখুঁত!

Pocket Code শুধু ডিজিটাল প্রকল্পের বাইরে চলে যায়। নতুন **makerspace বৈশিষ্ট্য** দিয়ে তুমি ডিজাইন করতে পারো **SVG কাটার প্লাটারের ফাইল** । এর অর্থ হল তুমি তোমার ডিজিটাল সৃষ্টিগুলিকে বাস্তব-বিশ্বের আইটেমগুলিতে রূপান্তর করতে পারো এবং স্ক্রিনের বাইরে সৃজনশীল সম্ভাবনাগুলি অন্বেষণ করতে পারো।

তুমি কোডিং শিখছেন, নতুন ধারণা নিয়ে পরীক্ষা করছেন বা প্রোগ্রামিং শেখাতে যাচ্ছেন, Pocket Code কোডিংয়ের জন্য একটি খেলোয়াড় এবং সহজলভ্য উপায় প্রদান করে
