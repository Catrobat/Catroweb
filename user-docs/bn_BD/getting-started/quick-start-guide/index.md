Pocket Code একটি ভিজ্যুয়াল প্রোগ্রামিং অ্যাপ্লিকেশন যা তোমাকে সরাসরি তোমার স্মার্টফোন বা ট্যাবলেটে গেম, অ্যানিমেশন এবং ইন্টারেক্টিভ গল্প তৈরি করতে দেয়। “কোড ব্লক” (কোড ব্লক) এর সাথে একটি স্বজ্ঞাত ড্রাগ-এন্ড-ড্রপ ইন্টারফেস ব্যবহার করে, তুমি তোমার প্রকল্পগুলি প্রাক প্রোগ্রামিং অভিজ্ঞতা ছাড়াই ডিজাইন করতে পারো। তোমার চিন্তাভাবনাকে বাস্তবে রূপ দিতে সহজেই শব্দ, চিত্র এবং আন্দোলন যুক্ত করো।

এই গাইড তোমাকে কিভাবে শুরু করতে হবে তা ব্যাখ্যা করে সাহায্য করবেঃ:

- ইন্টারফেস নেভিগেট করো,
- তোমার প্রথম প্রকল্প তৈরি করো,
- বস্তুর সাথে কাজ করা এবং পটভূমি,
- প্রোগ্রামিং কর্মের জন্য কোড ব্লক ব্যবহার করো, এবং
- তোমার প্রকল্পটা সংরক্ষণ করো।

নতুনদের এবং শিক্ষকদের জন্য নিখুঁত, Pocket Code সৃজনশীলতা, সমস্যা সমাধান এবং যৌক্তিক চিন্তাভাবনাকে উত্সাহিত করে।
