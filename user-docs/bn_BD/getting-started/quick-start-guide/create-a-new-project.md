তোমার স্মার্টফোন বা ট্যাবলেটে অ্যাপটি খুলুন।

![মূল পর্দা নতুন প্রকল্প](../../../media/getting-started/MainScreen_NewProject.png)\
নতুন প্রকল্প তৈরি করতে + চিহ্নটি আলতো চাপো।\
[ছবি খোলো](../../../media/getting-started/MainScreen_NewProject.png)

প্রকল্পের একটা নাম দাও (1)। ঠিক করো, গেমটা খাড়া (পোর্ট্রেট) নাকি আড়াআড়ি (ল্যান্ডস্কেপ) হবে (2)।

![নতুন প্রকল্প](../../../media/getting-started/NewProject.png)\
তারপর টিক চিহ্নে চাপ দিয়ে নিশ্চিত করো (3)।\
[ছবি খোলো](../../../media/getting-started/NewProject.png)

তুমি এখন তোমার প্রকল্পের দৃশ্য। উপরের অংশে, তুমি তোমার খেলার নাম দেখতে পাবে।

নীচে তুমি দেখতে পারো **পটভূমি** - বর্তমানে, ব্যাকগ্রাউন্ডটি খালি। যদি তুমি এটা পরিবর্তন করতে চাও, তাহলে তা চাপো।

পটভূমিতে, তুমি তোমার খেলায় যুক্ত করেছ এমন তোমার **অভিনেতা ও বস্তু** এর জন্য এলাকা দেখতে পাবে। বর্তমানে, এই এলাকাটি এখনও খালি।

নীচের ডানদিকে, তুমি দুটি গুরুত্বপূর্ণ বোতাম দেখতে পাবেঃ:

![শুরু করো](../../../media/getting-started/Start.png)\
সঙ্গে **চালান** বোতাম, তুমি তোমার খেলা শুরু করো।

![প্লাস বোতাম](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
সঙ্গে **প্লাস** বোতাম, তুমি তোমার গেম একটি নতুন চরিত্র / বস্তু যোগ.

![প্রকল্পের স্ক্রিন](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
