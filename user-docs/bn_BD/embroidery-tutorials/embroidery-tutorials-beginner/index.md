তুমি কি সৃজনশীল হতে চাও এবং একই সময়ে খেলনাপূর্ণভাবে কোডিং শিখতে চাও? তুমি কি এমন কিছু তৈরি করতে পছন্দ করেন যা পরে ব্যবহার, পরিধান এবং প্রশংসা করতে পারো?

Embroidery Designer এর সাহায্যে তুমি পূর্বের অভিজ্ঞতা ছাড়াই একটি বোনা মেশিন প্রোগ্রাম করতে পারো যা তোমার ডিজাইনটি স্বয়ংক্রিয়ভাবে টি-শার্ট, ব্যাগ, প্যান্ট, স্মার্টফোন কেস বা এমনকি তোমার জুতাতে বোনা করবে। কাপড়ের সব কিছুতে সেলাই করা সম্ভব। তোমার কল্পনাশক্তি ও সৃজনশীলতার জন্য মুক্ত হাত দাও! তুমি আমাদের Catrobat কমিউনিটি থেকে অন্যদের ডিজাইন ডাউনলোড এবং সম্পাদনা করতে পারো। অবশ্যই, তুমি তোমার প্রকল্পগুলি বন্ধুদের এবং পুরো বিশ্বের সাথে ভাগ করতে পারো!
