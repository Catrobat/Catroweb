এই টিউটোরিয়ালটিতে, তুমি তোমার প্রথম প্রকল্প তৈরি শুরু করতে Pocket Code সম্পর্কে যা জানা দরকার তা শিখবে। আমরা তোমাকে ধাপে ধাপে অ্যাপটি ডাউনলোড করতে, এটি খুলতে এবং একটি নতুন প্রকল্প তৈরি করার নির্দেশাবলী দেব।

![নতুন কর্মসূচি](../../../media/game-tutorials/New-Program.png)\

[ছবি খোলো](../../../media/game-tutorials/New-Program.png)

এটা প্রথম টিউটোরিয়াল, এবং তোমাকে কোন পূর্ব জ্ঞান প্রয়োজন হয় না।

তাহলে, তুমি কিসের জন্য অপেক্ষা করছ? তোমার ফোনটা ধরো আর এখনই শুরু করো!

*এখানে তুমি PDF-ফরম্যাটে টিউটোরিয়ালটি ডাউনলোড করতে পারোঃ:*

[PDF খোলো](../../../media/game-tutorials/New-Program.pdf)

### 1. ইনস্টলেশন Pocket Code

প্রথমে তোমার ডিভাইসে Pocket Code অ্যাপ ইনস্টল করতে হবে। এই পদক্ষেপের জন্য একটি গুগল অ্যাকাউন্ট প্রয়োজন। এখন তোমার ডিভাইস অ্যাপটি ডাউনলোড করে ইনস্টল করবে। তোমার ইন্টারনেট সংযোগ অনুযায়ী এই পদক্ষেপটি কিছুটা সময় নিতে পারে।

![নতুন কর্মসূচি (2)](../../../media/game-tutorials/New-Program-2.png)\
তুমি Google Play Store এ “Pocket Code” অনুসন্ধান করে অ্যাপটি খুঁজে পেতে পারো এবং এটি ডাউনলোড করে “ইনস্টল করা” টিপুন।\
[ছবি খোলো](../../../media/game-tutorials/New-Program-2.png)

তুমি সফলভাবে ডাউনলোড এবং ইনস্টল করার পরে Pocket Code তুমি অ্যাপ্লিকেশন ড্রয়ার বা তোমার হোম স্ক্রিনে খুঁজে পেতে পারো, তোমার ডিভাইসের উপর নির্ভর করে। তুমি সহজেই অ্যাপটি নিয়ে যেখানেই চাও তা স্থাপন করতে পারো।

### 2. অ্যাপ্লিকেশন শুরু করো

![নতুন কর্মসূচি (1)](../../../media/game-tutorials/New-Program-1.png)\
তুমি যখন অ্যাপটি খুলবেন, তখন বিভিন্ন বিভাগ দেখতে পাবেঃ.\
[ছবি খোলো](../../../media/game-tutorials/New-Program-1.png)

### 3. একটি নতুন প্রকল্প তৈরি করো

পরবর্তী পদক্ষেপ হচ্ছে নতুন প্রকল্প তৈরি করা। এখন তোমাকে একটি প্রকল্পের নাম লিখতে হবে এবং নির্বাচন করতে হবে তোমার প্রকল্পটি ল্যান্ডস্কেপ হওয়া উচিত কিনা। চাপ দিয়ে “ঠিক আছে” প্রকল্পটি তৈরি করা হয়।

![নতুন কর্মসূচি](../../../media/game-tutorials/New-Program.png)\
এটি করার জন্য, তুমি নীচের ডান কোণার হলুদ প্লাস বোতামটি টিপতে পারো।\
[ছবি খোলো](../../../media/game-tutorials/New-Program.png)

### 4. তুমি এটা করেছ, তোমার নিজের নতুন প্রকল্প তৈরি করেছে।

এখন তুমি ইনস্টল করেছ Pocket Code এবং জানেন কিভাবে একটি নতুন প্রকল্প তৈরি করতে হয়। এখন তুমি প্রোগ্রামিং শুরু করতে পারো!

এটি করার জন্য, তোমাকে একটি প্রকল্পে নতুন বস্তু তৈরি করতে জানতে হবে। দেখো **[নতুন বস্তু](new-object.md)**- টিউটোরিয়াল, যেখানে তোমাকে ধাপে ধাপে সবকিছু ব্যাখ্যা করা হয়।
