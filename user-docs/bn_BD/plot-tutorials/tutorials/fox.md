যখন প্লট শুরু হয়, প্রতিটি আন্দোলন কলম দিয়ে আঁকা হয়। এই লাইনগুলো পরবর্তীতে চক্রান্তকারী কাটবে।

এই চিতাবাঘটি কেবলমাত্র সোজা লাইন (“চলুন: \_\_\_ ধাপ”) এবং বাঁক দিয়ে তৈরি।

**টিপ**: তুমি যখন এটি তৈরি করছেন তখন তোমার প্রোগ্রামটি পরীক্ষা করো।
