繪圖開始後，每一個移動都會像用筆畫出來一樣。這些線條就是之後繪圖機要切割的路徑。

我們的角色面向 150 度的方向。

在這個教學中，我們先做貓頭的右側。仔細看會發現，一開始的弧度很大，所以角色每畫完一小段線，就必須多轉一點。接著，轉彎的幅度會變小，用來畫頭的下半部。貓頭的左側弧度又很大，所以這個部分總共要用三次迴圈。

接下來是左耳。左耳只由直線組成，所以我們可以使用「移動 \_\_ 步」積木。

兩耳之間的部分又是一段弧線，要用另一個迴圈來寫程式。

然後畫右耳。

繪圖現在完成了。用「停止繪圖」積木來結束，再用「將繪圖儲存為 SVG \_\_\_」把它存到你的手機上。

現在你可以把 SVG 檔案傳送給（切割）繪圖機了。
