![將粒子顏色設為「#ff0000」](../../../media/bricks/Set_particle_colour_to_ff0000.png)

這個積木會改變角色發出的粒子顏色。就像改變派對禮炮裡五彩紙屑的顏色。

十六進位色碼是用十六進位數值來表示顏色的方法。它由六個字元組成，可以是數字（0-9）或字母（A-F）。色碼通常以「#」開頭，寫成這樣：`#RRGGBB`。

- 前兩個字元（`RR`）代表顏色的紅色成分。
- 接下來的兩個字元（`GG`）代表綠色成分。
- 最後兩個字元（`BB`）代表藍色成分。

每一組字元的範圍是從 `00`（表示完全沒有那個顏色）到 `FF`（表示那個顏色的最大量）。例如：

`#000000` 是黑色（沒有任何顏色）。

`#FF0000` 是純紅色。

`#00FF00` 是純綠色。

`#0000FF` 是純藍色。

`#FFFFFF` 是白色（紅、綠、藍都是最大量）。
