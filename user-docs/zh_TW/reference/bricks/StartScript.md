![當場景開始時](../../../media/bricks/When_scene_starts_btn2.png)

如果使用這個積木，腳本會在場景開始時立即執行。場景就是你程式的開頭。場景是程式中的一個新畫面，裡面可以顯示其他元素，並發生不同的互動。你可以為程式的不同階段建立很多場景。例如，一個場景做開場，一個場景做主選單，一個場景做第一關，一個場景做第二關，依此類推。如果是比較簡單的程式，只用一個場景也可以，這時程式的開頭也就是場景的開頭。

和所有腳本一樣，這個腳本也是從事件積木開始的：事件決定腳本**何時**開始，後面的積木則告訴程式要**做什麼**。
