![將畫筆顏色設為 紅 0 綠 0 藍 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

這個積木會改變角色所使用的畫筆顏色。就像在繪圖時換成另一支不同顏色的筆。

**紅、綠、藍（RGB）**：RGB 色彩模式會用不同強度的紅光、綠光和藍光，組合出各種顏色。每一個顏色成分（紅、綠、藍）的值可以在 0 到 255 之間：

- **紅**：顏色中的紅色成分。數值越高，紅色就越多。
- **綠**：顏色中的綠色成分。數值越高，綠色就越多。
- **藍**：顏色中的藍色成分。數值越高，藍色就越多。

把紅、綠、藍的不同數值組合起來，就能做出任何顏色。例如：

- `RGB(255, 0, 0)` 是純紅色。
- `RGB(0, 255, 0)` 是純綠色。
- `RGB(0, 0, 255)` 是純藍色。
- `RGB(255, 255, 255)` 是白色（紅、綠、藍都是最大量）。
- `RGB(0, 0, 0)` 是黑色（沒有任何顏色）。

用不同的份量混合這些顏色，就能做出你在數位螢幕上看到的所有顏色。
