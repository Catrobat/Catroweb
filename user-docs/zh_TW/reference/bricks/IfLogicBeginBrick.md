![如果為真，那麼……否則……](../../../media/bricks/if_else_brick2.png)

*檢查條件是否為真。如果為真，就執行一組指令；如果不為真，就執行另一組指令。就像給出兩個選項：「如果這件事為真，就做這個；否則，就做那個。」*

![開始場景](../../../media/bricks/StartScene.png)

場景開始時，變數 X 會設為 0。

![如果否則](../../../media/bricks/IfElse.png)

如果現在輕觸了動物，程式會檢查 X 除以 2 的餘數是否為真，也就是 X 是否為奇數。

如果是奇數，就會播放音效 Tweet1，並把變數 X 增加 1。

否則，如果 X 是偶數，就只把 X 增加 1。

要執行的各個陳述會用「如果結束」分隔開。
