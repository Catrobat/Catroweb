![如果為真，那麼](../../../media/bricks/if_brick2.png)

*檢查條件是否為真，如果為真，就執行一組指令。就像說：「如果這件事為真，那就做這個。」*

![開始場景](../../../media/bricks/StartScene.png)

場景開始時，變數 X 會設為 0。

![如果](../../../media/bricks/If.png)

如果現在輕觸了動物，變數 X 會增加 1。

程式會檢查變數 X 是否等於 2。

如果是，就會播放音效 Tweet1，並把變數 X 設為 0。
