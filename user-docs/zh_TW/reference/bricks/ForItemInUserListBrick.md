![對每個值，取自清單](../../../media/bricks/for-each-value_brick.png)

這個積木會對清單或範圍中的每一個項目，執行一組指令。就像一個一個檢查項目，並對每一個項目做同樣的動作。

想像你有一份數字、顏色或其他項目的清單。這個積木可以讓你取出清單中的每個項目，並對它做些什麼。例如，如果你有一份顏色清單，而你想把背景顏色依序換成清單中的每一種顏色，就可以使用這個積木。

這就像說：「對這個群組中的每一個項目，都執行這些指令。」
