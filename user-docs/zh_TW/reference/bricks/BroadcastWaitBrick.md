![廣播訊息並等待](../../../media/bricks/brodcast_wait_brick3.png)

把訊息傳送給專案的其他部分，然後等待它們完成工作，才繼續往下執行。就像請朋友幫忙做一件事，等他做完，你才繼續進行。

**為什麼要傳送廣播訊息？**

透過訊息，你可以讓同一個場景中的不同物件彼此溝通、互動。它讓一個物件可以把訊息傳給所有其他物件，而接收到訊息的物件就能做出反應或回應。

這些訊息**不會顯示**在螢幕上！如果你想顯示文字，請使用「外觀」類別中的積木！

**運作方式是什麼？**

- *傳送的物件：* 傳送物件使用「廣播訊息」積木，開始和其他物件溝通。這個積木會把訊息傳給場景中的所有其他物件（也包括背景）。
- *接收的物件：* 接收物件會聆聽並回應訊息。它使用「當收到訊息」積木，來偵測何時收到特定的訊息。
- *處理訊息：* 當接收物件收到訊息時，會執行「當收到訊息」積木下方的所有積木。這讓你能定義，當收到特定訊息時要發生的自訂行為或動作。
