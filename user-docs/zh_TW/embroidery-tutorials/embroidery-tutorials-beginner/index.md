你想要有創意，同時又能用好玩的方式學習寫程式嗎？你也喜歡製作能立刻使用、穿戴或欣賞的東西嗎？

使用 Embroidery Designer，你不需要任何先備經驗，就能為刺繡機寫程式，讓它自動把你的設計繡在 T 恤、包包、褲子、手機殼，甚至是鞋子上。只要是布料做的東西，都能繡上圖案。盡情發揮你的想像力和創意吧！你也可以下載並編輯 Catrobat 社群中其他人的設計。當然，你也可以把你的專案分享給朋友，甚至全世界！
