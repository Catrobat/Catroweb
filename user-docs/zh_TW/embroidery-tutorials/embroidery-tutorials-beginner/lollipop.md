在這個教學中，你會學到如何繡出一支棒棒糖（54.7 x 54.8 公釐）。

![圖片 (9)](../../../media/embroidery-tutorials/image-9.png)

你應該已經知道如何建立新物件，並在裡面加入積木。如果還需要協助，歡迎參考[入門系列](../../game-tutorials/starter-tutorials/index.md)的教學。此外，刺繡積木必須已經開啟。你可以在**[開啟刺繡積木](activate-embroidery-bricks.md)**教學中了解如何開啟。

如需更多資訊或設計建議，請看看其他教學。

*你可以在這裡下載 PDF 格式的教學*：

[棒棒糖](../../../media/embroidery-tutorials/Lollipop.pdf)

### 1. 建立新的刺繡物件（請參考[建立刺繡物件](create-embroidery-objects.md)）。

### 2. 現在，一步一步把積木加入你的腳本。

![棒棒糖](../../../media/embroidery-tutorials/Lollipop.png)

### 3. 點選開始，開始繡出你的設計！
