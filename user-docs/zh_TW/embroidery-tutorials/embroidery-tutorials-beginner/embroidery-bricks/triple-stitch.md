三重縫會把每一針縫三次。

三重縫在第一針之後會往回跳，縫一次，然後再往前跳回去，再縫一次。

![開始三重縫，針距 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

用法和[平針縫](running-stitch.md)相同。

![三重縫](../../../../media/embroidery-tutorials/TripleStitch.png)

這樣可以讓接縫更耐用。
