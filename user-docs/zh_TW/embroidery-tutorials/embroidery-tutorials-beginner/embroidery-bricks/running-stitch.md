讓機器以可調整的針距持續縫製。

平針縫通常會和移動積木一起使用。

![開始平針縫，針距 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

機器會開始平針縫，每隔 **10 步**縫一針。

接著，機器會移動 **200 步**。

這樣就會得到 **20 針**。

![平針縫](../../../../media/embroidery-tutorials/RunningStitch.png)

平針縫讓縫合接縫變得更容易，因為你不再需要用迴圈來縫。

![圖片](../../../../media/embroidery-tutorials/image.png)
