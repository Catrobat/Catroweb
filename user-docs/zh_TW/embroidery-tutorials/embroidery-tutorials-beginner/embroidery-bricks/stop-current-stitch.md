讓目前的縫法停止。

如果你在開始平針縫、鋸齒縫或三重縫之後，想要改變針的位置，就需要這個積木。

![停止目前的縫法](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

否則，會多出一段不想要的接縫。

![停止目前的縫法](../../../../media/embroidery-tutorials/StopCurrentStitch.png)
