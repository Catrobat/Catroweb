在這個教學中，你會學到如何繡出一個正方形（60 x 60 公釐）。

![圖片 (3)](../../../media/embroidery-tutorials/image-3.png)

你應該已經知道如何建立新物件，並在裡面加入積木。如果還需要協助，歡迎參考[入門系列](../../game-tutorials/starter-tutorials/index.md)的教學。此外，刺繡積木必須已經開啟。你可以在**[開啟刺繡積木](activate-embroidery-bricks.md)**教學中了解如何開啟。

如需更多資訊或設計建議，請看看其他教學。

*你可以在這裡下載 PDF 格式的教學*：

[正方形](../../../media/embroidery-tutorials/Square.pdf)

### 1. 建立新的刺繡物件（請參考[建立刺繡物件](create-embroidery-objects.md)）。

### 2. 現在，一步一步把積木加入你的腳本。

![正方形](../../../media/embroidery-tutorials/Square.png)

正方形由四條線組成，每條線之間的角度都是 90°。

一開始，腳本會執行平針縫。之後，它會讓針移動 300 步，然後轉 90°。這個動作會重複 4 次。

如果你改變角度或步數，會發生什麼事呢？**試試看吧！**

### 3. 點選開始，開始繡出你的設計！
