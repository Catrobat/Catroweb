在這個教學中，你會學到如何繡出一顆星星（57 x 60 公釐）。

![圖片 (5)](../../../media/embroidery-tutorials/image-5.png)

你應該已經知道如何建立新物件，並在裡面加入積木。如果還需要協助，歡迎參考[入門系列](../../game-tutorials/starter-tutorials/index.md)的教學。此外，刺繡積木必須已經開啟。你可以在**[開啟刺繡積木](activate-embroidery-bricks.md)**教學中了解如何開啟。

如需更多資訊或設計建議，請看看其他教學。
