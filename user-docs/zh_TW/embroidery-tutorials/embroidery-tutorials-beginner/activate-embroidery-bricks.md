在這個教學中，會說明如何開啟刺繡積木。

![開啟刺繡積木5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

這個步驟不需要任何程式知識。這是刺繡教學的第一步。之後，你就能設計、寫程式，甚至把自己的設計繡在你喜歡的布料上。

如需更多資訊或設計建議，請看看其他教學。

*你可以在這裡下載 PDF 格式的教學*：

[開啟刺繡積木](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. 打開「Pocket Code」應用程式，照著點擊步驟操作！

### 2. 打開選單（右上角的三個點）。

![開啟刺繡積木](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. 前往「設定」。

![開啟刺繡積木3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. 選擇「刺繡擴充功能」。

![開啟刺繡積木4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. 你會在積木中找到獨立的刺繡積木類別！

[![開啟刺繡積木5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

現在，你也會在其他積木中看到所有刺繡積木。

如需了解每個積木的更多資訊，歡迎在[這裡](../../../reference/)查看積木說明文件，或是跟著**[刺繡積木](embroidery-bricks/index.md)**教學學習。

現在你可以開始，製作你自己的設計了！

如果你需要點子或協助，請看看其他教學，或繼續做**[建立刺繡物件](create-embroidery-objects.md)**教學。
