在這個教學中，你會學到如何建立物件，之後就能用它們繡出你的圖樣。

在這個教學之前，你應該已經知道如何建立專案。如果需要協助，請參考[入門系列](../../game-tutorials/starter-tutorials/index.md)的教學。

如需更多資訊或設計建議，歡迎看看其他教學。

*你可以在這裡下載 PDF 格式的教學*：

[建立刺繡物件](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. 輕觸專案右下角的加號按鈕，新增一個物件。

![建立刺繡物件](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. 若要選擇圖片，請前往素材庫。

![建立刺繡物件（1）](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. 一個刺繡物件代表刺繡機針的一個高度層級。多個刺繡物件會一個接一個地繡出來，因此可以使用多種顏色。

你可以依照想要的顏色來選擇物件。

向下捲動，找到合適的箭頭。

![建立刺繡物件（5）](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. 為你的新物件取一個合適的名字，然後按「確定」。

![建立刺繡物件（3）](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. 你已經建立了一個新物件。現在可以加入腳本，為物件寫程式了。

![建立刺繡物件（4）](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

現在你知道如何建立物件了。每種你想使用的顏色，都要新增一個物件。

你可以為每種顏色加入腳本，設計屬於你自己的圖樣，之後甚至可以把它繡出來。
