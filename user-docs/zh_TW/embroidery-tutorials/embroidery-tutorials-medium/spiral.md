在這個教學中，你會學到如何繡出一個螺旋（103.9 x 116.6 公釐）。

![圖片 (14)](../../../media/embroidery-tutorials/image-14.png)

你應該先知道什麼是迴圈，以及迴圈如何運作。

**[圓形](../embroidery-tutorials-beginner/circle.md)**教學可能會對這個教學有幫助。

如果你還沒繡過任何東西，請看看[初級](../embroidery-tutorials-beginner/index.md)系列的刺繡教學。

如需更多資訊或設計建議，請看看其他教學。

*你可以在這裡下載 PDF 格式的教學*：

[螺旋](../../../media/embroidery-tutorials/Spiral.pdf)

### 1. 建立新的刺繡物件（請參考[建立刺繡物件](../embroidery-tutorials-beginner/create-embroidery-objects.md)），並加入以下腳本：

![螺旋](../../../media/embroidery-tutorials/Spiral.png)

### 2. 點選開始，開始繡出你的設計！

點選「新增」來建立新變數。

![圖片 (15)](../../../media/embroidery-tutorials/image-15.png)

你會在資料中找到變數「degree」。

![螺旋（1）](../../../media/embroidery-tutorials/Spiral-1.png)
