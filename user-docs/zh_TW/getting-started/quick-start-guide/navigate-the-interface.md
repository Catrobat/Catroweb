開啟 Pocket Code 時，你會看到下面這個主畫面。

![主畫面](../../../media/getting-started/MainScreen-e1732269599192.jpg)

在右上角有一個![說明](../../../media/getting-started/Screenshot-2024-11-22-111748.png)符號，點它就會帶你到 Catrobat 說明文件，那裡有很多實用的小技巧。

旁邊是選單![選單](../../../media/getting-started/Screenshot-2024-11-22-111804.png)。從那裡你可以輕鬆前往設定，在設定中更改語言，或開啟積木和其他擴充功能，例如繪圖積木等。

下面可以看到你最近編輯過的專案。點一下編輯圖示![編輯圖示](../../../media/getting-started/Screenshot-2024-11-22-111825.png)，就能進入專案畫面，繼續開發你的專案。

使用播放按鈕![開始你的專案](../../../media/getting-started/Screenshot-2024-11-22-111818.png)，就能開始執行你的專案。

點一下「裝置上的專案」，就能看到你已儲存的專案。![裝置上的專案](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

如果想認識並體驗其他使用者的專案，只要在分享頁面點選「Catrobat 社群」。那裡有很多很棒的專案。![Catrobat 社群](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

如果想建立新專案，請點一下加號圖示。![新增](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
