Pocket Code 是一款視覺化程式應用程式，讓你直接在智慧型手機或平板上製作遊戲、動畫和互動故事。只要使用直覺的拖放介面和「積木」（程式積木），你就能在沒有任何程式經驗的情況下設計專案。你也可以輕鬆加入聲音、圖片和動作，讓你的想法動起來。

這份指南會教你以下事情：

- 瀏覽介面，
- 建立你的第一個專案，
- 使用角色和背景，
- 使用積木來設計動作，以及
- 儲存你的專案。

Pocket Code 很適合初學者和教育工作者，能激發創意、解決問題和邏輯思考的能力。
