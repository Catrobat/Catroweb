在 Pocket Code 中，你可以用很多方式在專案裡新增角色或物件：

**繪圖**：你可以用 **Pocket Paint** 畫出自己的角色。Pocket Paint 是一款繪圖程式（[更多關於 Pocket Paint](https://catrobat.org/pocket-paint/)）。

**造型**：從預先做好的角色和物件中選一個（[更多關於素材庫](../elements/medialibrary.md)）。

**相簿**：你可以從手機的相簿中選一張圖片。

**素材庫**：在素材庫中，你會找到已經寫好程式的角色和物件，也就是它們已經有腳本了。如果你想使用現成的元素（例如倒數計時器），就可以選擇它們（[更多關於素材庫](../elements/medialibrary.md#從素材庫新增物件)）。

**相機**：你可以用裝置的相機拍一張照片，把它加成角色。

**背包**：背包目前是空的。你可以重複使用之前存在背包裡的角色或物件。使用時，整段腳本也會一起取出（[更多關於背包](../elements/backpack.md)）。

**本機角色和物件**：在這裡你會找到可以用在專案中的現成角色。本機角色和物件就像離線的素材庫，即使沒有網路，也能使用這些角色。

**空白物件**：新增一個沒有外觀的空白物件。你可以像平常一樣為它寫程式。

**本機專案**：選擇一個專案，把它的第一個角色連同腳本一起加進你的專案。
