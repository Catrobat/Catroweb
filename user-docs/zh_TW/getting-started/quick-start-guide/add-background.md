你可以在 Catrobat 中為專案新增背景。

背景有很多用法。在 Pocket Code 中，背景可以讓**遊戲**的畫面更漂亮、用來講述**故事**，或是替你的角色和物件提供更多情境。

對於**雕刻機**或**刺繡機**等創客空間裝置來說，背景可以當作設計範本，例如切割或刺繡的圖樣。

若要新增背景，請在專案畫面中輕觸「背景」。

![輕觸背景](../../../media/getting-started/grafik-16.png)

在**腳本區（2）**，你可以為背景寫程式，不過並不是所有積木都能用。以下兩個積木特別重要：![將透明度設為 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) 和 ![將尺寸設為 60%](../../../media/bricks/Set_size_to_60_pct_.png)

在**造型區（1）**，你可以新增背景。請輕觸 + 符號。

![新增背景](../../../media/getting-started/grafik-14.png)

你可以上傳自己的圖片、使用預先做好的背景，或是自己畫一個背景。

**繪圖**：你可以用 **Pocket Paint** 畫出自己的背景。Pocket Paint 是一款繪圖程式（[更多關於 Pocket Paint](https://catrobat.org/pocket-paint/)）。

**造型**：從預先做好的背景中選一個（[更多關於素材庫](../elements/medialibrary.md)）。

**相簿**：你可以從手機的相簿中選一張圖片。

**相機**：你可以用裝置的相機拍一張照片，把它加成背景。

![背景](../../../media/getting-started/grafik-17.png)

現在你已經新增好背景了。點一下右上角的返回箭頭，就能回到**專案畫面**。
