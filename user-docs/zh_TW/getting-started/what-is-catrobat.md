Catrobat 是一種免費且開放原始碼的**視覺化程式語言**，讓每個人（從初學者到進階使用者）都能直接在行動裝置上製作自己的遊戲、動畫和互動故事。它使用簡單的**積木式**程式介面，你只要把程式「積木」拖放在一起，就能一步一步完成你的專案。不需要任何經驗！

透過 Catrobat 的主要應用程式 **Pocket Code**，你可以製作超越螢幕的數位專案。除了一般的程式專案，Catrobat 還支援創客空間的創意：你可以製作給**刺繡機**用的 **DST 檔案**，也可以製作給**雕刻機**用的 **SVG 檔案**。這表示你可以把數位設計變成布料和其他實體材料上的作品！

不論你是學生、愛好者或教育工作者，Catrobat 都提供有趣又能動手做的方式，讓你探索程式設計、解決問題和數位製作。
