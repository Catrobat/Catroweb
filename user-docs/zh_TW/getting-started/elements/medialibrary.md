Catrobat 素材庫是一個收藏區，裡面有**角色**、**背景**、音效和物件，可以用在你的專案中。你可以依照自己的想法，自由調整所有內容！

[角色](#從素材庫新增角色)

[背景](#從素材庫新增背景)

[音效](#從素材庫新增音效)

[物件](#從素材庫新增物件)

***

### 從素材庫新增角色

在專案畫面中，輕觸 + 符號（[更多資訊](../quick-start-guide/add-actors-and-objects.md)）來新增角色或物件。

![新增角色](../../../media/getting-started/NewActor-e1732794461668.jpg)\
選擇「造型」。\
[開啟圖片](../../../media/getting-started/NewActor-e1732794461668.jpg)

選擇你想在程式中使用的角色。

![素材庫](../../../media/getting-started/grafik-19.png)\
輕觸角色（1），然後下載（2）。\
[開啟圖片](../../../media/getting-started/grafik-19.png)

現在你可以為角色取一個新名字（1），並把它放到遊戲中的適當位置（2）。 這表示你可以直接在螢幕上移動角色，馬上就能看到它在專案中的位置。

![新增角色或物件](../../../media/getting-started/grafik-29.png)\
按「確定」完成。\
[開啟圖片](../../../media/getting-started/grafik-29.png)

![視覺化放置角色](../../../media/getting-started/grafik-21.png)\
放好角色（1），然後按勾勾符號確認（2）。\
[開啟圖片](../../../media/getting-started/grafik-21.png)

### 從素材庫新增背景

前往專案畫面中的背景。切換到造型區，然後新增一個造型（[更多資訊](../quick-start-guide/add-background.md)）。輕觸「造型」。

選擇你想在程式中使用的背景。

![從素材庫選擇背景](../../../media/getting-started/grafik-22.png)\
輕觸背景（1），然後下載（2）。\
[開啟圖片](../../../media/getting-started/grafik-22.png)

![音效](../../../media/getting-started/grafik-30.png)\

![選擇音效](../../../media/getting-started/grafik-25.png)\

### 從素材庫新增物件

Catrobat 讓你可以下載現成的物件。物件是獨立的遊戲元素，例如倒數計時器，它已經包含了腳本。

新增物件的方式和新增角色很像。

在專案畫面中，輕觸 + 符號（[更多資訊](../quick-start-guide/add-actors-and-objects.md)）來新增物件。

![新增角色](../../../media/getting-started/NewActor-e1732794461668.jpg)\
選擇「素材庫」。\
[開啟圖片](../../../media/getting-started/NewActor-e1732794461668.jpg)

搜尋你想在程式中使用的物件。

![素材庫中的物件](../../../media/getting-started/grafik-27.png)\
輕觸物件（1），然後下載（2）。\
[開啟圖片](../../../media/getting-started/grafik-27.png)

現在你可以為物件取一個新名字（1），並把它放到遊戲中的適當位置（2）。 這表示你可以直接在螢幕上移動物件，馬上就能看到它在專案中的位置。

![新增角色或物件](../../../media/getting-started/grafik-29.png)\
按「確定」完成。\
[開啟圖片](../../../media/getting-started/grafik-29.png)

放好物件（1），然後按勾勾符號確認（2）。
