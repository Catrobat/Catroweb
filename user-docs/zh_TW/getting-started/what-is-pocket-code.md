Pocket Code 是 Catrobat 的主要應用程式，這是一款免費且開放原始碼的行動應用程式，讓你直接在智慧型手機或平板上製作遊戲、動畫和互動故事。使用 Pocket Code 的**積木式程式系統**，你可以把程式積木一塊一塊接起來做出專案，就像拼圖一樣。不需要任何程式經驗，很適合初學者！

Pocket Code 不只能做數位專案。透過全新的**創客空間功能**，你還可以設計給**雕刻機**用的 **SVG 檔案**。這表示你可以把數位創作變成現實中的物品，探索螢幕以外的創意可能性。

不論你是在學寫程式、嘗試新點子，還是在教程式設計，Pocket Code 都提供輕鬆又容易上手的方式，讓你開始學習程式設計。
