在這個教學中，你會學到開始製作第一個專案前，需要知道的 Pocket Code 所有事情。我們會一步一步帶你下載應用程式、打開它，並建立新專案。

![新程式](../../../media/game-tutorials/New-Program.png)\
我們會一步一步帶你下載應用程式、打開它，並建立新專案。\
[開啟圖片](../../../media/game-tutorials/New-Program.png)

這是最前面的教學，你不需要任何先備知識。

那還等什麼？拿起你的手機，現在就開始吧！

*你可以在這裡下載 PDF 格式的教學：*

[開啟 PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. 安裝 Pocket Code

首先，你需要在裝置上安裝 Pocket Code 應用程式。 這個步驟需要 Google 帳號。 接著，你的裝置會下載並安裝應用程式。 依照你的網路速度，這個步驟可能需要一點時間。

![新程式（2）](../../../media/game-tutorials/New-Program-2.png)\
你可以在 Google Play 商店搜尋「Pocket Code」，然後點選「安裝」來下載。\
[開啟圖片](../../../media/game-tutorials/New-Program-2.png)

成功下載並安裝 Pocket Code 後，你可以在應用程式列表或主畫面中找到它，要看你的裝置而定。你可以把應用程式移到任何你喜歡的位置。

### 2. 開啟應用程式

![新程式（1）](../../../media/game-tutorials/New-Program-1.png)\
打開應用程式時，你會看到不同的類別：\
[開啟圖片](../../../media/game-tutorials/New-Program-1.png)

### 3. 建立新專案

接下來就是建立新專案。 現在，你要輸入專案名稱，並選擇專案要用橫式還是直式。 點選「確定」後，專案就會建立好了。

![新程式](../../../media/game-tutorials/New-Program.png)\
點一下右下角的黃色加號按鈕即可。\
[開啟圖片](../../../media/game-tutorials/New-Program.png)

### 4. 你做到了！你建立了自己的新專案。

現在你已經安裝好 Pocket Code，也知道怎麼建立新專案了。接下來就可以開始寫程式了！

要做到這一點，你需要知道如何在專案中建立新物件。請看看**[新增物件](new-object.md)**教學，裡面會一步一步解說。
