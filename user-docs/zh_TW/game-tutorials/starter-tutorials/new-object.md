在這個教學中，你會學到如何在專案中建立新物件，以及你有哪些不同的方式可以做到。

![新增物件](../../../media/game-tutorials/New-Object.png)

若要這樣做，你應該已經下載 Pocket Code 應用程式，並且知道怎麼建立新專案。如果需要協助，歡迎看看**[新增專案](new-project.md)**教學。

*你可以在這裡下載 PDF 格式的教學：*

[新增物件](../../../media/game-tutorials/New-Object.pdf)

### 1. 建立新物件

首先，你需要打開你的新專案。

你可以在 Pocket Code 應用程式的主畫面找到它。如果你有好幾個專案，可以點一下「裝置上的專案」，然後選擇你的新專案。如果你還沒建立新專案，或是需要更多相關資訊，請看看**[新增專案](new-project.md)**教學。

### 2. 建立新物件

現在你已經準備好建立新物件了。點一下右下角的黃色加號按鈕，就會出現一個新視窗，裡面有七種可以選擇的方式。

![新增物件（1）](../../../media/game-tutorials/New-Object-1.png)

### 4. 繪製圖片

為了讓一開始盡量簡單，我們使用「繪圖」功能，只畫一個點。用 Pocket Paint 畫好點之後，退回一步就可以離開。

### 5. 取名字

現在，你需要為你的圖片取一個名字。

### 6. 放置物件

接著，你要用手指把它往左右或上下移動，以視覺方式放好。然後按右上角的按鈕來儲存。

![新增物件（3）](../../../media/game-tutorials/New-Object-3.png)

### 7. 你做到了！你建立了自己的新物件。

現在，你有一個含有物件的專案，可以為它寫程式了！

要這樣做，你應該先知道有哪些積木可以用。**[第一批積木](first-bricks.md)**教學能讓你很快了解各種積木類別。不過，你也可以直接開始你的第一個專案，從入門系列中挑選一個合適的教學。
