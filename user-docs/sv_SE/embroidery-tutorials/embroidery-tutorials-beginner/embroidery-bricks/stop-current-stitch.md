Låter det aktuella stygnet avslutas.

Du behöver det här blocket om du vill ändra nålens position efter att du har startat en raksöm, sicksacksöm eller trestegssöm.

![Avsluta aktuell söm](../../../../media/embroidery-tutorials/Stop_current_stitch.png)
