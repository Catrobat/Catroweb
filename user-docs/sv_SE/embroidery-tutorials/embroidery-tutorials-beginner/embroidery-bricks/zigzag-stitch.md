Sy i ett ”sicksack”-mönster.

![Starta sicksacksöm med längden 2 och bredden 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

Prova olika värden för längd och bredd för att lära dig det här blocket.

![Sicksacksöm](../../../../media/embroidery-tutorials/ZigzagStitch.png)
