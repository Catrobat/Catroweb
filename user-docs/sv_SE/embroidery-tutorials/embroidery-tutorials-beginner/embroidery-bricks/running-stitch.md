Låter maskinen sy hela tiden med en varierbar längd.

Vanligtvis kombinerar du raksöm med ett flyttblock.

![Starta raksöm med längden 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Maskinen startar en raksöm som syr var **10 steg**.
Sedan flyttar sig maskinen **200 steg**.
Det ger **20 stygn**.

![Raksöm](../../../../media/embroidery-tutorials/RunningStitch.png)

Raksömmen gör det enklare att sy en söm, eftersom du inte behöver någon loop längre.

![Bild](../../../../media/embroidery-tutorials/image.png)
