Trestegssömmen syr varje stygn tre gånger.

Trestegssömmen hoppar tillbaka efter det första stygnet, syr, hoppar sedan framåt igen och syr en gång till.

![Starta trestegssöm med längden 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Fungerar på samma sätt som [raksöm](running-stitch.md).

![Trestegssöm](../../../../media/embroidery-tutorials/TripleStitch.png)

Det här gör att sömmen håller längre.
