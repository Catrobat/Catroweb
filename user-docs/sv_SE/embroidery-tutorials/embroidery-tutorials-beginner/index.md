Vill du vara kreativ och samtidigt lära dig koda på ett lekfullt sätt? Gillar du också att skapa saker som du kan använda, bära och beundra direkt efteråt?

Med Embroidery Designer kan du, utan några förkunskaper, programmera en broderimaskin som automatiskt broderar din design på en t-shirt, en väska, byxor, ett mobilskal eller till och med dina skor. Du kan brodera på allt som är gjort av tyg. Låt din fantasi och kreativitet flöda fritt! Du kan ladda ner och redigera andras designer från vår Catrobat-gemenskap. Självklart kan du också dela dina projekt med dina vänner och hela världen!
