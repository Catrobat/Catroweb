I den här tutorialen lär du dig hur du skapar objekt som du senare kan brodera dina mönster med.

För den här tutorialen bör du redan kunna skapa ett projekt. Titta på tutorialerna i [startserien](../../game-tutorials/starter-tutorials/index.md) om du behöver hjälp.

För mer information eller designförslag kan du gärna titta på de andra tutorialerna.

*Här kan du ladda ner tutorialen i PDF-format*:

[Skapa broderiobjekt](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Klicka på plusknappen längst ner till höger i ditt projekt för att lägga till ett nytt objekt.

![Skapa broderiobjekt](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. För att välja en bild går du till mediebiblioteket.

![Skapa broderiobjekt (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Ett broderiobjekt representerar en nivå av broderimaskinens nål. Flera broderiobjekt broderas efter varandra. Då går det att använda flera färger.

Du kan välja ditt objekt beroende på vilken färg du vill ha.

Scrolla nedåt och sök efter rätt pil.

![Skapa broderiobjekt (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Ge ditt nya objekt ett passande namn och tryck på OK.

![Skapa broderiobjekt (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Nu har du skapat ett nytt objekt. Nu kan du lägga till ett skript och programmera objektet.

![Skapa broderiobjekt (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Nu vet du hur du skapar ett objekt. Lägg till ett nytt objekt för varje färg du vill använda.

Du kan lägga till ett skript i varje färg och programmera dina egna designer och till och med brodera dem senare.

Behöver du inspiration eller hjälp? Titta på våra andra tutorials!
