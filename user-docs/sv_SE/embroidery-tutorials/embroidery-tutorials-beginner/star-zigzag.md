I den här tutorialen lär du dig att brodera en stjärna med sicksacksömmen (58,2 x 61,2 mm).

![Bild (4)](../../../media/embroidery-tutorials/image-4.png)

Du bör redan veta hur man skapar ett nytt objekt och lägger in block där. Titta gärna på tutorialerna i [startserien](../../game-tutorials/starter-tutorials/index.md) om du fortfarande behöver hjälp. Dessutom måste broderiblocken redan vara aktiverade. Du kan ta reda på hur du gör det i tutorialen **[Aktivera broderiblock](activate-embroidery-bricks.md)**.

För mer information eller designförslag kan du titta på de andra tutorialerna.

*Här kan du ladda ner tutorialen i PDF-format*:

[Stjärna sicksack](../../../media/embroidery-tutorials/Star-ZigZag.pdf)

### 1. Skapa ett nytt broderiobjekt (se [Skapa broderiobjekt](create-embroidery-objects.md)).

### 2. Starta nu och lägg in blocken steg för steg i ditt skript.

![Stjärna sicksack](../../../media/embroidery-tutorials/Star-ZigZag.png)

### 3. Tryck på play för att starta din design!
