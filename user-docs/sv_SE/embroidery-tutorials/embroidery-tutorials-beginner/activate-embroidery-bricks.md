I den här tutorialen förklaras hur du aktiverar broderiblock.

![Aktivera broderiblock 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Du behöver inga programmeringskunskaper för det här. Det här är första steget för att börja med broderitutorialerna. Senare kan du designa, programmera och till och med brodera dina egna mönster på ditt favorittyg.

För mer information eller designförslag kan du titta på de andra tutorialerna.

*Här kan du ladda ner tutorialen i PDF-format*:

[AktiveraBroderiblock](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Starta appen ”Pocket Code”. Följ klickarna!

### 2. Öppna menyn (prickarna uppe till höger).

![Aktivera broderiblock](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Gå till ”Inställningar”.

![Aktivera broderiblock 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Välj ”Broderitillägg”.

![Aktivera broderiblock 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Du hittar broderiblocken som en egen kategori bland dina block!

[![Aktivera broderiblock 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Nu hittar du också alla broderiblock bland de andra blocken.

Mer information om varje block hittar du i dokumentationen för blocken [här](../../../reference/) eller i tutorialen **[Broderiblock](embroidery-bricks/index.md)**.

Nu kan du börja och skapa dina egna designer!

Om du behöver idéer eller hjälp kan du titta på de andra tutorialerna eller fortsätta med tutorialen **[Skapa broderiobjekt](create-embroidery-objects.md)**.
