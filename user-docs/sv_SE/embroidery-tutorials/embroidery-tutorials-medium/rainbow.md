I den här tutorialen lär du dig att brodera en regnbåge (112 x 57,2 mm).

![Regnbåge](../../../media/embroidery-tutorials/Regenbogen.webp)

Du bör redan veta vad en loop är och hur den fungerar.

Tutorialen **[Halvcirkel](../embroidery-tutorials-beginner/semicircle.md)** kan vara till hjälp för den här tutorialen.

Titta på broderitutorialerna i [nybörjarserien](../embroidery-tutorials-beginner/index.md) om du inte har broderat något än.

För mer information eller designförslag kan du titta på de andra tutorialerna.

### 3. Kopiera objektet

För nästa större båge kan du helt enkelt kopiera objektet du just har skapat.
Klicka på de tre prickarna uppe till höger i objektöversikten.
Gå sedan till ”Kopiera” och välj objektet.

![Regnbåge (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Om du använder ett eget objekt för varje båge kan du senare brodera dem i olika färger.

### 4. Anpassa objektet

För att bågarna ska bli olika stora måste vi ändra några värden.
Gå till skriptet för det kopierade objektet och justera följande värden:

![Regnbåge (2)](../../../media/embroidery-tutorials/Rainbow-2.png)
