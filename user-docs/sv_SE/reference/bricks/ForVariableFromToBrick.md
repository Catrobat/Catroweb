![För värden från 1 till 10](../../../media/bricks/for-values-from-brick.png)

Det här blocket kör en serie instruktioner ett visst antal gånger, med en räknare som börjar på ett värde och slutar på ett annat. Det är som att göra en loop där du vet exakt hur många gånger den ska köras.

Tänk dig att du har en lista med saker och vill göra något med var och en. Det här blocket låter dig gå igenom varje sak ett i taget och göra samma sak med varje en.
