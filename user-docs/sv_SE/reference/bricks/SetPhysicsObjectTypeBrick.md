![Sätt rörelsetypen till rör sig och studsar med tyngdkraft](../../../media/bricks/set_your_motion_type_brick.png)

Ändrar hur objektet rör sig. Det kan till exempel röra sig och studsa med tyngdkraften, inte röra sig med tyngdkraften men låta andra studsa mot det, eller inte röra sig och inte studsa alls. Det är som att välja hur din karaktär ska bete sig när det gäller rörelse och samspel med andra.
