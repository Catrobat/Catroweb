![För varje värde i listan](../../../media/bricks/for-each-value_brick.png)

Det här blocket kör en serie instruktioner för varje element i en lista eller ett intervall. Det är som att gå igenom varje element ett i taget och göra samma sak med varje ett.

Tänk dig att du har en lista med siffror, färger eller andra saker. Med det här blocket kan du ta varje element från listan och göra något med det. Om du till exempel har en lista med färger och vill byta bakgrundsfärg till varje färg i listan, använder du det här blocket.

Det är som att säga: ”För varje sak i den här gruppen, gör de här instruktionerna.”
