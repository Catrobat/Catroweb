![Sätt massan till 1 kilogram](../../../media/bricks/set_mass_to__kilogram_brick.png)

Anger hur tung objektet är i kilogram, vilket påverkar hur det rör sig och hur det påverkas av andra objekt. Tyngre objekt är svårare att flytta och kräver mer kraft för att ändra riktning.
