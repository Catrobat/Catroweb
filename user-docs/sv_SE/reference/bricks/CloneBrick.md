![Skapa klon av dig själv](../../../media/bricks/create_clone_of_brick2.png)

Det här blocket gör en kopia av det valda objektet, som kallas en klon. Klonen beter sig likadant som originalet. Tänk dig att du duplicerar en karaktär eller ett objekt i ditt spel. Klonen kan ha egna beteenden och skript, så att du kan skapa flera exemplar av ett objekt som agerar på egen hand.
