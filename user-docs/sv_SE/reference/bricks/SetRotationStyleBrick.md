![Sätt rotationsstil till runt om](../../../media/bricks/set_rotation_style_brick2.png)

Ändrar hur objektet roterar (runt om, bara vänster–höger eller rotera inte alls). Det är som att bestämma om din karaktär kan vända sig helt runt, bara spegla sig vänster och höger eller inte rotera alls.
