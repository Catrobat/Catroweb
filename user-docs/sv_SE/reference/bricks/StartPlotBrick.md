![Börja plotta](../../../media/bricks/Start_to_plot.png)

Det här blocket startar plottningen medan figuren rör sig. Det är likt att sätta en penna mot papperet för att börja rita en linje. Du kan använda blocket ”Sluta plotta” om du vill pausa ritandet, flytta figuren till en annan plats och sedan börja plotta igen med ”Börja plotta”.
