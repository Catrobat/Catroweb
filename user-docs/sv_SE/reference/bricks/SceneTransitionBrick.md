![Fortsätt scenen](../../../media/bricks/continue_scene_brick2.png)

Det här blocket fortsätter scenen där den var pausad. Om din scen avbröts av en paus eller ett uppehåll fortsätter det här blocket precis där det slutade.

Tänk dig att du har pausat ett spel eller en animation och nu vill att den ska fortsätta köra. Det här blocket fungerar som knappen ”spela”. Allt fortsätter från den punkt där det pausades.
