![Slå på additiv blandning för partiklar](../../../media/bricks/Turn_particle_effect_additivity_on.png)

Det här blocket slår på eller av additiv blandning för partiklar, vilket kan göra partiklarna ljusare och starkare. Det är som att justera ljusstyrkan och glansen på gnistor.
