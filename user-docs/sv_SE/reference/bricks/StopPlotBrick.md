![Sluta plotta](../../../media/bricks/Stop_to_plot.png)

Blocket ”Sluta plotta” pausar plottningen och låter dig flytta figuren till en ny position eller avsluta plottningen. Det är som att lyfta pennan från papperet för att flytta den eller sluta rita. När du är klar med plottningen kan du använda blocket ”Spara plotten som SVG” för att spara din design som en SVG-fil.
