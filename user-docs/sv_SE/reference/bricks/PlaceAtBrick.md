![Sätt x till 0 och y till 0](../../../media/bricks/place_at_x_y_brick.png)

Flyttar objektet till en viss plats på skärmen, bestämd av x- och y-koordinaterna. Det är som att teleportera din karaktär till en exakt plats.

Positionen anges i ett koordinatsystem som liknar ett koordinatplan: x- och y-axlarna går genom mitten av skärmen, så x = 0 och y = 0 är mitten av skärmen.
