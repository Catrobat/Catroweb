![Sätt pennans färg till RGB 0, 0, 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Det här blocket ändrar färgen på pennan som figuren ritar med. Det är som att byta till en annan färgpenna när du ritar.

**Röd, grön, blå (RGB)**: RGB-färgmodellen använder olika styrkor av rött, grönt och blått ljus för att skapa ett brett spektrum av färger. Varje färgdel (rött, grönt och blått) kan ha ett värde mellan 0 och 255:

- **Röd**: Hur mycket rött färgen innehåller. Ett högre värde betyder mer rött.
- **Grön**: Hur mycket grönt färgen innehåller. Ett högre värde betyder mer grönt.
- **Blå**: Hur mycket blått färgen innehåller. Ett högre värde betyder mer blått.

Genom att kombinera olika värden för rött, grönt och blått kan du skapa vilken färg som helst. Till exempel:

- `RGB(255, 0, 0)` är ren röd.
- `RGB(0, 255, 0)` är ren grön.
- `RGB(0, 0, 255)` är ren blå.
- `RGB(255, 255, 255)` är vit (mest av rött, grönt och blått).
- `RGB(0, 0, 0)` är svart (ingen färg).

Genom att blanda de här färgerna i olika mängder skapas alla färger du ser på digitala skärmar.
