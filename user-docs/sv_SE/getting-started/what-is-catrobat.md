Catrobat är ett gratis och öppen källkod-**programmeringsspråk med block** som hjälper alla – från nybörjare till avancerade användare – att skapa egna spel, animationer och interaktiva berättelser direkt i mobilen. Med Catrobats byggsten, **block**, som du enkelt kan dra och släppa för att bygga dina projekt steg för steg, behöver du inga förkunskaper alls!

Med Catrobats flaggskeppsapp, **Pocket Code**, kan du skapa digitala projekt som går längre än skärmen: utöver vanliga kodprojekt kan Catrobat användas för skapande i makerspace genom att du kan skapa **DST-filer till broderimaskiner** och **SVG-filer till skärplotter**. Det betyder att du kan ta dina digitala designer och förverkliga dem i tyg och andra fysiska material!

Oavsett om du är elev, hobbyist eller lärare erbjuder Catrobat ett roligt och praktiskt sätt att utforska programmering, problemlösning och digital tillverkning.
