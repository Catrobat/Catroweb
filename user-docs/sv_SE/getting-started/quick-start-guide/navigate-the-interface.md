När du startar Pocket Code ser du följande huvudskärm.

![Huvudskärm](../../../media/getting-started/MainScreen-e1732269599192.jpg)

Uppe till höger finns en ![Hjälp](../../../media/getting-started/Screenshot-2024-11-22-111748.png)-symbol som tar dig till Catrobats dokumentation, där du hittar bra tips.

Bredvid den finns menyn ![Meny](../../../media/getting-started/Screenshot-2024-11-22-111804.png). Där kommer du enkelt till inställningarna, där du kan byta språk eller slå på tillägg som plotterblocken och mycket mer.

Nedanför ser du ditt senast redigerade projekt. Klicka på redigeringsikonen ![Redigeringsikon](../../../media/getting-started/Screenshot-2024-11-22-111825.png) för att öppna projektvyn, där du kan fortsätta utveckla ditt projekt.

Använd knappen Spela ![Starta ditt projekt](../../../media/getting-started/Screenshot-2024-11-22-111818.png) för att starta ditt projekt.

Genom att klicka på Projekt på enheten kommer du åt dina sparade projekt. ![Projekt på enheten](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Om du vill se och arbeta med fler projekt från andra användare klickar du på Catrobat-gemenskapen under Dela. Där hittar du många fantastiska projekt. ![Catrobat-gemenskapen](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Om du vill skapa ett nytt projekt klickar du på plusikonen. ![Lägg till](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
