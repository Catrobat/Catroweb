När du startar Pocket Code ser du följande huvudskärm.

![Huvudskärm](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
När du startar Pocket Code ser du följande huvudskärm.\
[Öppna bilden](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Hjälp](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Uppe till höger finns en -symbol som tar dig till Catrobats dokumentation, där du hittar bra tips.

![Meny](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Bredvid den finns menyn.

Där kommer du enkelt till inställningarna, där du kan byta språk eller slå på tillägg som plotterblocken och mycket mer.

![Redigeringsikon](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Klicka på redigeringsikonen för att öppna projektvyn, där du kan fortsätta utveckla ditt projekt.

Nedanför ser du ditt senast redigerade projekt.

![Starta ditt projekt](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Använd knappen Spela för att starta ditt projekt.

![Projekt på enheten](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Genom att klicka på Projekt på enheten kommer du åt dina sparade projekt.

![Catrobat-gemenskapen](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Om du vill se och arbeta med fler projekt från andra användare klickar du på Catrobat-gemenskapen under Dela.

Där hittar du många fantastiska projekt.

![Lägg till](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Om du vill skapa ett nytt projekt klickar du på plusikonen.
