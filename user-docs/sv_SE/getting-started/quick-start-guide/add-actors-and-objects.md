I Pocket Code kan du lägga till en karaktär eller ett objekt i ditt projekt på flera sätt:

**Rita**: Du kan skapa en egen karaktär med **Pocket Paint**. Pocket Paint är ett ritprogram ([mer om Pocket Paint](https://catrobat.org/pocket-paint/))

**Utseenden**: Välj en av de färdiga figurerna och objekten i en samling ([mer om mediebiblioteket](../elements/medialibrary.md)).

**Galleri**: Du kan välja en bild från din smartphones galleri.

**Bibliotek**: I biblioteket hittar du figurer och objekt som redan är programmerade, alltså de har redan ett skript. Du kan välja dem om du vill använda färdiga delar i ditt spel (till exempel en nedräkning) ([mer om biblioteket](../elements/medialibrary.md#lägg-till-ett-objekt-från-mediebiblioteket)).

**Kamera**: Du kan använda enhetens kamera för att ta ett foto och lägga till det som en karaktär.

**Ryggsäck**: Ryggsäcken är just nu tom. Du kan återanvända figurer eller objekt som du har sparat i din ryggsäck. Hela skriptet packas upp med dem ([mer om ryggsäcken](../elements/backpack.md)).

**Lokala figurer och objekt**: Här hittar du färdiga karaktärer som du kan använda i ditt projekt. Lokala figurer och objekt fungerar som ett bibliotek utan internet, så du kommer åt dem även om du inte har någon internetanslutning.

**Tomt objekt**: Lägg till ett tomt objekt, alltså ett objekt utan utseende. Du kan programmera det här objektet som vanligt.

**Lokala projekt**: Välj ett projekt som du vill infoga den första figuren från, tillsammans med skriptet, i ditt projekt.
