Pocket Code är en visuell programmeringsapp som låter dig skapa spel, animationer och interaktiva berättelser direkt i din smartphone eller surfplatta. Med ett enkelt gränssnitt där du drar och släpper ”block” (kodblock) kan du designa dina projekt utan att kunna programmera sedan tidigare. Lägg enkelt till ljud, bilder och rörelse så att dina idéer blir levande.

Den här guiden hjälper dig att komma igång genom att visa hur du:

- Navigerar i gränssnittet,
- Skapar ditt första projekt,
- Arbetar med figurer, objekt och bakgrunder,
- Använder block för att programmera handlingar, och
- Sparar ditt projekt.

Pocket Code passar bra för nybörjare och lärare och uppmuntrar kreativitet, problemlösning och logiskt tänkande.
