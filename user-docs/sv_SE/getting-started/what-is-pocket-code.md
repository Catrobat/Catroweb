Pocket Code är Catrobats huvudapp, en gratis och öppen källkod-app som låter dig skapa spel, animationer och interaktiva berättelser direkt i din smartphone eller surfplatta. Med Pocket Codes **blockbaserade kodsystem** bygger du projekt genom att klicka ihop kodblock – precis som att lägga ihop bitar i ett pussel. Du behöver ingen programmeringserfarenhet, så appen passar perfekt för nybörjare!

Pocket Code går längre än bara digitala projekt. Med nya **makerspace-funktioner** kan du också designa **SVG-filer till skärplotter**. Det betyder att du kan förvandla dina digitala skapelser till saker i verkligheten och utforska kreativa möjligheter bortom skärmen.

Oavsett om du lär dig koda, testar nya idéer eller undervisar i programmering ger Pocket Code ett lekfullt och lättillgängligt sätt att dyka ner i kodning.

[Mer information](https://catrobat.org/pocket-code/)
