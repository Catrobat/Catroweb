I den här tutorialen lär du dig var du hittar olika block för att programmera ett objekt. Dessutom får du en bra överblick över blockkategorierna.

![Första blocken](../../../media/game-tutorials/First-Bricks.png)\
Dessutom får du en bra överblick över blockkategorierna.\
[Öppna bilden](../../../media/game-tutorials/First-Bricks.png)

För att lägga till block och programmera ditt objekt behöver du redan ha skapat ett projekt med ett objekt. Om du behöver hjälp med det kan du titta på tutorialen **[Nytt objekt](new-object.md)**.

*Här kan du ladda ner tutorialen i PDF-format:*

[Öppna PDF](../../../media/game-tutorials/First-Bricks.pdf)

### 1. Öppna ett befintligt objekt

Först behöver du öppna ditt projekt. Du borde redan ha skapat ett objekt (om inte, titta på tutorialen **[Nytt objekt](new-object.md)**). Klicka nu på objektets namn.

### 2. Befintliga block

Efter det ser du att det redan finns några block. De här blocken skapades när vi placerade objektet visuellt.

De här blocken gör inget annat än att placera vårt objekt på exakt den position vi valde i början när projektet startar.

![Första blocken (1)](../../../media/game-tutorials/First-Bricks-1.png)\
Du kan också ändra positionen här när du vill.\
[Öppna bilden](../../../media/game-tutorials/First-Bricks-1.png)

### 3. Lägg till block

Nu kan du skapa fler block genom att klicka på den gula plusknappen längst ner till höger. Då öppnas ett nytt fönster med flera kategorier av block. Kategorierna beskrivs i nästa steg.

### 4. Blockkategorier

![Första blocken (2)](../../../media/game-tutorials/First-Bricks-2.png)\
Det här är de olika blockkategorierna.\
[Öppna bilden](../../../media/game-tutorials/First-Bricks-2.png)

### 5. Lägg till första blocket

För vårt första block vill vi använda blocket ”Glid 1 sekund till x: y:”. Du hittar det i kategorin för rörelse. Med formelredigeraren kan du ändra antalet sekunder och positionen X och Y.

### 6. Placera blocket

Placera blocket på den sista platsen i ditt program och kör programmet för första gången.

![Första blocken (3)](../../../media/game-tutorials/First-Bricks-3.png)\
Det gör du med den gula play-knappen.\
[Öppna bilden](../../../media/game-tutorials/First-Bricks-3.png)

### 7. Du klarade det! Du lade till ditt första block.

Nu har du programmerat ditt första objekt!

Om du vill dela ditt projekt med dina vänner kan du titta på tutorialen **[Ladda upp och dela](upload-and-share.md)**, där det förklaras exakt hur det fungerar. Annars kan du redan börja med ditt första eget projekt. Om du behöver hjälp eller inspiration kan du titta på våra tutorials i nybörjarserien.

Du hittar mer information om alla block [här](../../../reference/)!
