I den här tutorialen lär du dig allt du behöver veta om Pocket Code för att börja skapa ditt första projekt. Vi guidar dig steg för steg genom hur du laddar ner appen, öppnar den och skapar ett nytt projekt.

![Nytt program](../../../media/game-tutorials/New-Program.png)\
Vi guidar dig steg för steg genom hur du laddar ner appen, öppnar den och skapar ett nytt projekt.\
[Öppna bilden](../../../media/game-tutorials/New-Program.png)

Det här är allra första tutorialen, och du behöver inga förkunskaper.

Så vad väntar du på? Ta fram telefonen och kom igång nu!

*Här kan du ladda ner tutorialen i PDF-format:*

[Öppna PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Installera Pocket Code

Först behöver du installera appen Pocket Code på din enhet. För det här steget krävs ett Google-konto. Nu laddar din enhet ner och installerar appen. Det här steget kan ta en stund beroende på din internetanslutning.

![Nytt program (2)](../../../media/game-tutorials/New-Program-2.png)\
Du hittar appen genom att söka på ”Pocket Code” i Google Play Butik och ladda ner den genom att trycka på ”Installera”.\
[Öppna bilden](../../../media/game-tutorials/New-Program-2.png)

När Pocket Code har laddats ner och installerats hittar du appen i appmenyn eller på startskärmen, beroende på din enhet. Du kan enkelt flytta appen dit du vill.

### 2. Starta appen

![Nytt program (1)](../../../media/game-tutorials/New-Program-1.png)\
När du öppnar appen ser du olika kategorier.\
[Öppna bilden](../../../media/game-tutorials/New-Program-1.png)

### 3. Skapa ett nytt projekt

Nästa steg är att faktiskt skapa ett nytt projekt. Nu måste du skriva ett projektnamn och välja om ditt projekt ska vara liggande eller inte. När du trycker på ”OK” skapas projektet.

![Nytt program](../../../media/game-tutorials/New-Program.png)\
Det gör du genom att trycka på den gula plusknappen längst ner till höger.\
[Öppna bilden](../../../media/game-tutorials/New-Program.png)

### 4. Du klarade det! Du skapade ditt eget nya projekt.

Nu har du installerat Pocket Code och vet hur du skapar ett nytt projekt. Nu kan du börja programmera!

För att göra det behöver du veta hur du skapar ett nytt objekt i ett projekt. Titta på tutorialen **[Nytt objekt](new-object.md)**, där allt förklaras steg för steg.
