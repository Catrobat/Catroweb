આ ટ્યુટોરીયલમાં, તું તારા પ્રોજેક્ટમાં નવું ઑબ્જેક્ટ કેવી રીતે બનાવવું તે શીખી શકશો અને તારી પાસે આ માટે વિવિધ શક્યતાઓ છે.

![નવી વસ્તુ](../../../media/game-tutorials/New-Object.png)\
આ ટ્યુટોરીયલમાં, તું તારા પ્રોજેક્ટમાં નવું ઑબ્જેક્ટ કેવી રીતે બનાવવું તે શીખી શકશો અને તારી પાસે આ માટે વિવિધ શક્યતાઓ છે.\
[ચિત્ર ખોલ](../../../media/game-tutorials/New-Object.png)

આ કરવા માટે, તમારે પહેલેથી જ Pocket Code એપ્લિકેશન ડાઉનલોડ કરવી જોઈએ અને નવું પ્રોજેક્ટ કેવી રીતે બનાવવું તે જાણવું જોઈએ. જો તને આમાં મદદની જરૂર હોય, તો **[નવો પ્રોજેક્ટ](new-project.md)** -ટ્યુટોરિયલ પર એક નજર નાખો.

*અહીં તું PDF ફોર્મેટમાં ટ્યુટોરીયલ ડાઉનલોડ કરી શકે છેઃ:*

[PDF ખોલ](../../../media/game-tutorials/New-Object.pdf)

### 1. નવી વસ્તુ બનાવો

શરૂઆતમાં, તમારે તારા નવા પ્રોજેક્ટને ખોલવાની જરૂર છે.

તું તેને Pocket Code એપ્લિકેશનના હોમસ્ક્રીન પર શોધી શકશો. જો તારી પાસે એકથી વધુ પ્રોજેક્ટ છે, તો તું “પ્રોજેક્ટ” પર ક્લિક કરી શકે છે. પછી તમારો નવો પ્રોજેક્ટ પસંદ કર. જો તું કોઈ નવો પ્રોજેક્ટ બનાવ્યો નથી અથવા તે કેવી રીતે કરવું તે વિશે વધુ માહિતીની જરૂર છે, તો **[નવો પ્રોજેક્ટ](new-project.md)** -ટ્યુટોરિયલ પર એક નજર નાખો.

### 2. નવી વસ્તુ બનાવો

હવે તું એક નવી વસ્તુ બનાવવા માટે તૈયાર છો. તને નવી વિંડો દેખાશે જે તને પસંદ કરવા માટે સાત શક્યતાઓ આપે છે.

![નવી વસ્તુ (1)](../../../media/game-tutorials/New-Object-1.png)\
તે કરવા માટે જમણી તળિયે પીળા પ્લસ બટન પર ક્લિક કર.\
[ચિત્ર ખોલ](../../../media/game-tutorials/New-Object-1.png)

### 3. રચના કરવાની રીતો

![નવી વસ્તુ (2)](../../../media/game-tutorials/New-Object-2.png)\
આ શક્યતાઓમાંથી તું પસંદ કરી શકે છેઃ.\
[ચિત્ર ખોલ](../../../media/game-tutorials/New-Object-2.png)

### 4. ચિત્ર દોરો

શરૂઆત માટે શક્ય તેટલું સરળ બનાવવા માટે, અમે “દોરો” ફંક્શનનો ઉપયોગ કરવા માંગીએ છીએ અને ફક્ત એક બિંદુ દોરવા માંગીએ છીએ. જ્યારે તું Pocket Paint સાથે બિંદુ દોર્યું છે, તો તું તેને છોડી શકો છો (એક પગલું પાછળ જઈને).

### 5. એક નામ આપો

હવે તમારે તારા ચિત્રને નામ આપવું પડશે.

### 6. તેને મૂકો

ત્યારબાદ તમારે તેને ડાબે/જમણે અથવા ઉપર/નીચે આંગળીથી ખસેડીને દૃષ્ટિની રીતે મૂકવું પડશે.

![નવી વસ્તુ (3)](../../../media/game-tutorials/New-Object-3.png)\
તમારે તેને ઉપર જમણા ખૂણામાં બટન સાથે સાચવવું પડશે.\
[ચિત્ર ખોલ](../../../media/game-tutorials/New-Object-3.png)

### 7. તું તેને બનાવી છે! તું તારા પોતાના નવા પદાર્થ બનાવ્યો.

હવે તારી પાસે એક પ્રોજેક્ટ છે જેમાં તું પ્રોગ્રામ કરી શકે છે!

આ કરવા માટે, તમારે જાણવું જોઈએ કે કયા કોડ બ્લોક ઉપલબ્ધ છે. **[પ્રથમ કોડ બ્લોક્સ](first-bricks.md)** - ટ્યુટોરીયલ તને કોડ બ્લોક્સની વિવિધ શ્રેણીઓની સારી ઝાંખી આપે છે. જો કે, તું તારા પ્રથમ પ્રોજેક્ટથી સીધા જ પ્રારંભ પણ કરી શકે છે. પ્રારંભિક શ્રેણીમાંથી યોગ્ય ટ્યુટોરીયલ પસંદ કર.
