આ ટ્યુટોરીયલમાં, તું તારા પ્રથમ પ્રોજેક્ટ બનાવવા માટે તમારે જાણવાની જરૂર છે તે બધું શીખશો Pocket Code. અમે તને એપ્લિકેશન ડાઉનલોડ કેવી રીતે કરવી, તેને ખોલવી અને એક નવો પ્રોજેક્ટ બનાવવો તે વિશે પગલું દ્વારા પગલું માર્ગદર્શન આપીશું.

![નવો કાર્યક્રમ](../../../media/game-tutorials/New-Program.png)\
અમે તને એપ્લિકેશન ડાઉનલોડ કેવી રીતે કરવી, તેને ખોલવી અને એક નવો પ્રોજેક્ટ બનાવવો તે વિશે પગલું દ્વારા પગલું માર્ગદર્શન આપીશું.\
[ચિત્ર ખોલ](../../../media/game-tutorials/New-Program.png)

આ પ્રથમ ટ્યુટોરીયલ છે, અને તમારે કોઈ પૂર્વ જ્ઞાનની જરૂર નથી.

તો, તું શું રાહ જોઈ રહ્યા છો? તમારો ફોન પકડી અને હવે શરૂ કરો!

*અહીં તું PDF ફોર્મેટમાં ટ્યુટોરીયલ ડાઉનલોડ કરી શકે છેઃ:*

[PDF ખોલ](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code ની સ્થાપન

પ્રથમ, તમારે તારા ઉપકરણ પર Pocket Code એપ્લિકેશન ઇન્સ્ટોલ કરવાની જરૂર છે. આ પગલા માટે ગૂગલ એકાઉન્ટની જરૂર છે. હવે તારા ઉપકરણ એપ્લિકેશન ડાઉનલોડ અને ઇન્સ્ટોલ કરશે. તારા ઇન્ટરનેટ કનેક્શનના આધારે આ પગલું થોડો સમય લાગી શકે છે.

![નવો કાર્યક્રમ (2)](../../../media/game-tutorials/New-Program-2.png)\
તું Google Play Store માં “Pocket Code” શોધ કરીને એપ્લિકેશન શોધી શકો છો અને તેને “સ્થાપિત કરો” પર દબાવતા ડાઉનલોડ કરી શકે છે.\
[ચિત્ર ખોલ](../../../media/game-tutorials/New-Program-2.png)

સફળતાપૂર્વક ડાઉનલોડ અને ઇન્સ્ટોલ કર્યા પછી Pocket Code તું તારા ઉપકરણ પર આધાર રાખીને એપ્લિકેશન ડ્રોવરમાં અથવા તારી હોમ સ્ક્રીન પર શોધી શકો છો. તું સરળતાથી એપ્લિકેશન લઈ શકો છો અને તેને ગમે ત્યાં મૂકી શકો છો.

### 2. એપ્લિકેશન શરૂ કરો

![નવો કાર્યક્રમ (1)](../../../media/game-tutorials/New-Program-1.png)\
જ્યારે તું એપ્લિકેશન ખોલો છો, ત્યારે તું વિવિધ શ્રેણીઓ જુઓ છોઃ.\
[ચિત્ર ખોલ](../../../media/game-tutorials/New-Program-1.png)

### 3. એક નવો પ્રોજેક્ટ બનાવો

આગળનું પગલું એ છે કે ખરેખર એક નવો પ્રોજેક્ટ બનાવવો. હવે તમારે પ્રોજેક્ટનું નામ દાખલ કરવું પડશે અને પસંદ કરવું પડશે કે તમારો પ્રોજેક્ટ લેન્ડસ્કેપ હોવું જોઈએ કે નહીં. “ઠીક છે” દબાવીને પ્રોજેક્ટ બનાવવામાં આવે છે.

![નવો કાર્યક્રમ](../../../media/game-tutorials/New-Program.png)\
તે કરવા માટે, તું નીચે જમણા ખૂણે પીળા પ્લસ બટન દબાવો કરી શકે છે.\
[ચિત્ર ખોલ](../../../media/game-tutorials/New-Program.png)

### 4. તું તેને બનાવી છે! તું તારા પોતાના નવા પ્રોજેક્ટ બનાવ્યો.

હવે તું Pocket Code સ્થાપિત કરી છે અને જાણો છો કે કેવી રીતે એક નવો પ્રોજેક્ટ બનાવવા માટે. હવે તું પ્રોગ્રામિંગ શરૂ કરી શકે છે!

આ કરવા માટે, તમારે પ્રોજેક્ટમાં નવું ઑબ્જેક્ટ કેવી રીતે બનાવવું તે જાણવાની જરૂર છે. **[નવી વસ્તુ](new-object.md)** - ટ્યુટોરીયલ પર એક નજર નાખો, જ્યાં તને બધું પગલું દ્વારા પગલું સમજાવે છે.
