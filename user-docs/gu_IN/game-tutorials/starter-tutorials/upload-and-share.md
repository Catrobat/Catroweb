આ ટ્યુટોરીયલમાં, તું તારા મિત્રો અથવા સમગ્ર Catrobat સમુદાય સાથે તારા બનાવેલા પ્રોજેક્ટ્સ કેવી રીતે શેર કરવા તે શીખી શકશો.

![અપલોડ કરો અને શેર કરો](../../../media/game-tutorials/Upload-and-Share.png)

આ ટ્યુટોરીયલ માટે, તમારે પહેલેથી જ તારી પોતાની પ્રોજેક્ટની જરૂર છે જે તું શેર કરવા માંગો છો. જો તું હજુ સુધી પ્રોજેક્ટ કેવી રીતે બનાવવો તે જાણતા નથી, તો તે કેવી રીતે કાર્ય કરે છે તે જાણવા માટે **[નવો પ્રોજેક્ટ](new-project.md)** -ટ્યુટોરિયલ તપાસો.

*અહીં તું PDF ફોર્મેટમાં ટ્યુટોરીયલ ડાઉનલોડ કરી શકે છેઃ:*

[અપલોડ કરો અને શેર કરો](../../../media/game-tutorials/Upload-and-Share.pdf)

### 1. પ્રોજેક્ટ વિકલ્પો

જો તું તારા પ્રોજેક્ટને અપલોડ કરવા અથવા શેર કરવા માંગો છો, તો તમારે તમારો પ્રોજેક્ટ ખોલવો પડશે, પછી ઉપર જમણા ખૂણામાં ત્રણ બિંદુઓ પર ક્લિક કરો અને પછી “પ્રોજેક્ટ વિકલ્પો” ક્લિક કરો

![અપલોડ કરો અને શેર કરો](../../../media/game-tutorials/Upload-and-Share.png)

### 2. પ્રોજેક્ટ વિકલ્પો

હવે તું નામ બદલી શકો છો, વર્ણન ઉમેરો અને વિવિધ સેટિંગ્સ બનાવી શકો છો.

તારી પાસે બે વિકલ્પો પણ છે: “પ્રોજેક્ટ અપલોડ કરો” અને “પ્રોજેક્ટ નિકાસ કરો” જે નીચેના પગલાઓમાં સમજાવાયેલ છે.

![અપલોડ કરો અને શેર કરો (1)](../../../media/game-tutorials/Upload-and-Share-1.png)

### 3. કાર્યક્રમ અપલોડ કરો

જો તું તારા પ્રોજેક્ટને Catrobat શેર પર અપલોડ કરવા માંગો છો, જેથી સમગ્ર સમુદાયને તેની ઍક્સેસ મળે, તો તું પસંદ કરો *પ્રોજેક્ટ અપલોડ કરો*.

### 4. કાર્યક્રમ અપલોડ કરો

જો તું તારા પ્રોજેક્ટને શેર કરવા માટે આ બટન પર ક્લિક કરો છો, તો તમારે એકાઉન્ટ માટે સાઇન અપ કરવું પડશે, જો તું હજી સુધી કર્યું નથી. વૈકલ્પિક રીતે તું ગૂગલ સાથે સાઇન ઇન કરી શકે છે. જ્યારે તું સાઇન ઇન કરો છો ત્યારે તમારે તારા પ્રોજેક્ટનું નામ આપવું પડશે અને વર્ણન લખવું પડશે. પછી તમારે ત્રણ કેટેગરીઓ સુધી પસંદ કરવી પડશે જેમાં તમારો પ્રોગ્રામ શ્રેષ્ઠ છે.

પછી તારા કાર્યક્રમ અપલોડ કરવા માટે “આગળ” પર ક્લિક કર.

![અપલોડ કરો અને શેર કરો (2)](../../../media/game-tutorials/Upload-and-Share-2.png)

### 5. નિકાસ પ્રોજેક્ટ

જો તું તારા પ્રોજેક્ટને તારા મિત્રો સાથે શેર કરવા માંગતા હો, તો તું પસંદ કરો *પ્રોજેક્ટ નિકાસ કરો*.

### 6. નિકાસ પ્રોજેક્ટ

આ બટન સાથે તું એક .catrobat ફાઇલ સાચવી શકો છો કે જે તું ખાનગી રીતે તારા મિત્રો સાથે શેર કરી શકે છે. તું તેને તારા ઉપકરણ પર ફાઇલ એક્સપ્લોરરમાં સાચવી શકો છો અને આ રીતે શેર કરી શકે છે.

![અપલોડ કરો અને શેર કરો (3)](../../../media/game-tutorials/Upload-and-Share-3.png)

તું તેને કર્યું! તું તારા પ્રથમ કાર્યક્રમ શેર કર્યો!

જો તને આગામી પ્રોજેક્ટ્સ માટે મદદ અથવા પ્રેરણાની જરૂર હોય, તો વિવિધ સ્તરો (બિગિનર / મીડિયમ / પ્રો) સાથેના અમારા ટ્યુટોરીયલ્સ તપાસવા માટે મફત લાગે.
