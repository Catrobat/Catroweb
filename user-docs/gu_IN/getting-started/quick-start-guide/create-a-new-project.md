તારા ફોન કે ટૅબ્લેટમાં એપ ખોલ.

![મુખ્ય સ્ક્રીન નવી પ્રોજેક્ટ](../../../media/getting-started/MainScreen_NewProject.png)\
નવો પ્રોજેક્ટ બનાવવા માટે + ચિહ્ન પર ટૅપ કર.\
[ચિત્ર ખોલ](../../../media/getting-started/MainScreen_NewProject.png)

પ્રોજેક્ટનું નામ આપ (1). રમત માટે ઊભી (પોર્ટ્રેટ) કે આડી (લૅન્ડસ્કેપ) સ્ક્રીન પસંદ કર (2).

![નવો પ્રોજેક્ટ](../../../media/getting-started/NewProject.png)\
પછી ખાતરી કરવા માટે સાચાની નિશાની પર ટૅપ કર (3).\
[ચિત્ર ખોલ](../../../media/getting-started/NewProject.png)

તું હવે તારા પ્રોજેક્ટ દૃશ્યમાં છો. ટોચ પર, તું તારી રમતનું નામ જુઓ છો.

નીચે તું **પૃષ્ઠભૂમિ** જોઈ શકો છો - હાલમાં, પૃષ્ઠભૂમિ ખાલી છે. જો તું તેને બદલવા માંગો છો, તે પર ટેપ કર.

પૃષ્ઠભૂમિ હેઠળ, તું તારા **અભિનેતાઓ અને વસ્તુઓ** માટે વિસ્તાર જુઓ છો કે જે તું તારી રમતમાં ઉમેર્યા છે. હાલમાં, વિસ્તાર હજુ પણ ખાલી છે.

નીચે જમણે, તું બે મહત્વપૂર્ણ બટનો જુઓ છોઃ:

![શરૂ કરો](../../../media/getting-started/Start.png)\
બટન સાથે **ચલાવો** તું તારી રમત શરૂ કર.

![પ્લસ બટન](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
**વધુમાં** બટન સાથે, તું તારી રમતમાં એક નવો પાત્ર / પદાર્થ ઉમેરો.

![પ્રોજેક્ટ સ્ક્રીન](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
તું હવે તારા પ્રોજેક્ટ દૃશ્યમાં છો.\
[ચિત્ર ખોલ](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
