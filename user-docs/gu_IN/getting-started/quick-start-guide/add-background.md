તું તારા પ્રોજેક્ટમાં પૃષ્ઠભૂમિ ઉમેરી શકો છો Catrobat.

પૃષ્ઠભૂમિનો ઉપયોગ વિવિધ રીતે થઈ શકે છે. Pocket Code માં, તેનો ઉપયોગ દ્રશ્ય રીતે વધારવા માટે થઈ શકે છે **રમતો**, જણાવો **વાર્તાઓ**, અથવા તારા અભિનેતાઓ અને પદાર્થોને વધુ સંદર્ભ સાથે પ્રદાન કર.

**કાવતરું કરનારાઓ** અથવા **કણક મશીનો** જેવા મેકર સ્પેસ ઉપકરણો માટે, પૃષ્ઠભૂમિ ડિઝાઇન નમૂનાઓ તરીકે સેવા આપે છે, જેમ કે કટ અથવા ભરતકામ પેટર્ન માટે.

![પૃષ્ઠભૂમિ પર ટિપ](../../../media/getting-started/grafik-16.png)\
પૃષ્ઠભૂમિ ઉમેરવા માટે, પ્રોજેક્ટ દૃશ્યમાં “પૃષ્ઠભૂમિ” પર ટેપ કર.\
[ચિત્ર ખોલ](../../../media/getting-started/grafik-16.png)

**સ્ક્રિપ્ટ વિભાગ(2)** માં તું તારી પૃષ્ઠભૂમિ પ્રોગ્રામ કરી શકે છે - જો કે, આ માટે બધા બ્લોક્સ ઉપલબ્ધ નથી. નીચેના બે બ્લોક્સ ખાસ કરીને મહત્વપૂર્ણ છેઃ ![પારદર્શિતા 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) અને ![કદને આ પર સેટ કરો: 60%](../../../media/bricks/Set_size_to_60_pct_.png)

**જુએ વિભાગ(1)** માં, તું પૃષ્ઠભૂમિ ઉમેરો.

![પૃષ્ઠભૂમિ ઉમેરો](../../../media/getting-started/grafik-14.png)\
આ કરવા માટે, + પ્રતીક પર ટેપ કર.\
[ચિત્ર ખોલ](../../../media/getting-started/grafik-14.png)

તું તારી પોતાની છબીઓ અપલોડ કરી શકે છે, પૂર્વવ્યાખ્યાયિત પૃષ્ઠભૂમિનો ઉપયોગ કરી શકે છે અથવા જાતે પૃષ્ઠભૂમિ બનાવી શકો છો.

**દોરો**: તું તારી પોતાની પૃષ્ઠભૂમિ બનાવી શકો છો સાથે **Pocket Paint**. Pocket Paint એક ચિત્ર કાર્યક્રમ ([વિશે વધુ Pocket Paint](https://catrobat.org/pocket-paint/))

**દેખાવ**: પૂર્વ-નિર્માણ પૃષ્ઠભૂમિ ([મીડિયા લાઇબ્રેરી વિશે વધુ](../elements/medialibrary.md)) ની સંગ્રહમાંથી એક પસંદ કર.

**ગૅલેરી**: તું તારા સ્માર્ટફોન ગેલેરીમાંથી એક છબી પસંદ કરી શકે છે.

**કૅમેરા**: તું તારા ઉપકરણના કેમેરાનો ઉપયોગ ફોટો લેવા અને તેને પૃષ્ઠભૂમિ તરીકે ઉમેરી શકો છો.

![મીડિયા લાઇબ્રેરીમાંથી પસંદ કરો](../../../media/getting-started/grafik-17.png)\
**પ્રોજેક્ટ દૃશ્ય** પર પાછા જવા માટે ઉપર જમણે પાછળના તીર પર ક્લિક કર.\
[ચિત્ર ખોલ](../../../media/getting-started/grafik-17.png)

તું હવે પૃષ્ઠભૂમિ ઉમેર્યું છે.
