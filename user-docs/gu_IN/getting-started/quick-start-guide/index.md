Pocket Code એ વિઝ્યુઅલ પ્રોગ્રામિંગ એપ્લિકેશન છે જે તને તારા સ્માર્ટફોન અથવા ટેબ્લેટ પર સીધા રમતો, એનિમેશન અને ઇન્ટરેક્ટિવ વાર્તાઓ બનાવવા દે છે. “કોડ બ્લોક્સ” (કોડ બ્લોક્સ) સાથે એક સાહજિક ખેંચો અને છોડો ઇન્ટરફેસનો ઉપયોગ કરીને, તું તારા પ્રોજેક્ટ્સને અગાઉના પ્રોગ્રામિંગ અનુભવ વિના ડિઝાઇન કરી શકે છે. તારા વિચારોને જીવંત બનાવવા માટે સરળતાથી અવાજો, છબીઓ અને હલનચલન ઉમેરો.

આ માર્ગદર્શિકા તને કેવી રીતે શરૂ કરવું તે સમજાવશેઃ:

- ઇન્ટરફેસ નેવિગેટ કરો,
- તારા પ્રથમ પ્રોજેક્ટ બનાવો,
- વસ્તુઓ અને પૃષ્ઠભૂમિ સાથે કામ કરો,
- ક્રિયાઓ પ્રોગ્રામ કરવા માટે કોડ બ્લોક્સનો ઉપયોગ કરો, અને
- તારા પ્રોજેક્ટ સાચવો.

નવા નિશાળીયા અને શિક્ષકો માટે સંપૂર્ણ, Pocket Code સર્જનાત્મકતા, સમસ્યાનું સમાધાન અને તાર્કિક વિચારને પ્રોત્સાહન આપે છે.
