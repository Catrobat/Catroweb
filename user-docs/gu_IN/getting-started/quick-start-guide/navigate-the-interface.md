જ્યારે તું પ્રારંભ કરો છો Pocket Code, ત્યારે તને નીચેની મુખ્ય સ્ક્રીન દેખાય છે.

![મુખ્ય સ્ક્રીન](../../../media/getting-started/MainScreen-e1732269599192.jpg)

ઉપર જમણા ખૂણે, ત્યાં એક ![મદદ](../../../media/getting-started/Screenshot-2024-11-22-111748.png) પ્રતીક છે જે તને Catrobat દસ્તાવેજીકરણ પર લઈ જાય છે, જેમાં તારા માટે ઉપયોગી ટીપ્સ છે.

તેની બાજુમાં મેનુ છે ![મેનુ](../../../media/getting-started/Screenshot-2024-11-22-111804.png). ત્યાંથી, તું સરળતાથી સેટિંગ્સ પર જઈ શકો છો, જ્યાં તું ભાષા બદલી શકો છો અથવા પ્લોટ બ્લોક્સ જેવા એક્સ્ટેન્શન્સને સક્ષમ કરી શકે છે અને વધુ.

નીચે, તું તારા તાજેતરના સંપાદિત પ્રોજેક્ટ જોઈ શકો છો. પ્રોજેક્ટ સ્ક્રીન પર ઍક્સેસ કરવા માટે સંપાદન ચિહ્ન ![આયકન સંપાદિત કરો](../../../media/getting-started/Screenshot-2024-11-22-111825.png) પર ક્લિક કરો, જ્યાં તું તારા પ્રોજેક્ટને વિકસિત કરવાનું ચાલુ રાખી શકો છો.

તારા પ્રોજેક્ટ શરૂ કરવા માટે પ્લે બટન ![તારા પ્રોજેક્ટ શરૂ કરો](../../../media/getting-started/Screenshot-2024-11-22-111818.png) નો ઉપયોગ કર.

પર ક્લિક સાથે પ્રોજેક્ટ, તું તારા સાચવેલ પ્રોજેક્ટ્સ ઍક્સેસ કરી શકે છે. ![ઉપકરણ પરના પ્રોજેક્ટ્સ](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

જો તું અન્ય વપરાશકર્તાઓ પાસેથી વધુ પ્રોજેક્ટ્સ પર કામ કરવા અને જાણવા માંગતા હો, તો ફક્ત Catrobat સમુદાય પર ક્લિક કરો શેર. ત્યાં તને ઘણા મહાન પ્રોજેક્ટ્સ મળશે. ![Catrobat સમુદાય](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

જો તું એક નવો પ્રોજેક્ટ બનાવવા માંગો છો, તો વત્તા ચિહ્ન પર ક્લિક કર. ![ઉમેરો](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
