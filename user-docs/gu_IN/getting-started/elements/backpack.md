**બૅકપૅક** લક્ષણ Pocket Code માં એક વ્યવહારુ કાર્ય છે જે તને **સાચવો અને ફરીથી ઉપયોગ કરો** તત્વો જેમ કે અભિનેતાઓ (ઑબ્જેક્ટ્સ), સ્ક્રિપ્ટ્સ, દેખાવ અથવા અવાજો **વિવિધ પ્રોજેક્ટ્સ** માટે પરવાનગી આપે છે. તે તને સમય બચાવવામાં અને તારા પ્રોજેક્ટ્સને વધુ કાર્યક્ષમ બનાવવામાં મદદ કરે છે.

બેકપેક ડિજિટલ સ્ટોરેજ સ્પેસ જેવું છે જ્યાં તું તારા વર્તમાન પ્રોજેક્ટના વિવિધ ઘટકોને સંગ્રહિત કરી શકે છે. એકવાર બેકપેકમાં સાચવવામાં આવે, તું આ તત્વોને અન્ય પ્રોજેક્ટ્સમાં મેળવી અને દાખલ કરી શકે છે.

### હું અભિનેતાઓ (ઓબ્જેક્ટ્સ) માટે બેકપેકને કેવી રીતે ઉપયોગ કરું?

**બેકપેકમાં આંકડા પેક કરો**

પ્રોજેક્ટના પ્રોજેક્ટ વ્યૂ પર જાઓ જ્યાંથી તું બેકપેકમાં આકૃતિ પેક કરવા માંગો છો.

સંદર્ભ મેનુ ખોલવા માટે આકૃતિની બાજુમાં ત્રણ બિંદુઓ પર ક્લિક કરો અને પસંદ કરો “બૅકપૅકમાં મૂકો”.

આ આંકડો (તેના દેખાવ, અવાજો અને સ્ક્રિપ્ટો સહિત) બેકપેકમાં પેક કરવામાં આવશે.

![પેક અભિનેતા](../../../media/getting-started/grafik-7.png)

**બેકપેકમાંથી આંકડા ઉમેરો**

પ્રોજેક્ટ ખોલો જ્યાં તું આકૃતિ દાખલ કરવા માંગો છો.

પ્રોજેક્ટ દૃશ્યમાં, પ્લસ પ્રતીક પર ટેપ કરો અને પસંદ કરો “બૅકપૅક”.

હવે તું તારા બેકપેકમાં સંગ્રહિત કરેલી બધી આકૃતિઓ અને વસ્તુઓ જોશો. ત્રણ બિંદુઓ પર ટેપ કરો અને પસંદ કરો “બૅકપૅકમાંથી કાઢો”.

![અનપેક અભિનેતા](../../../media/getting-started/grafik-8-e1732702791199.png)

***

### હું સ્ક્રિપ્ટો માટે બેકપેકને કેવી રીતે ઉપયોગ કરું?

**બેકપેકમાં સ્ક્રિપ્ટો મૂકોઃ:**

સ્ક્રિપ્ટ સમાવતી આકૃતિ પર જાઓ. સ્ક્રિપ્ટ એડિટરમાં ઇચ્છિત સ્ક્રિપ્ટને નીચે રાખો.

સંદર્ભ મેનૂમાંથી “બૅકપૅકમાં ઉમેરો” પસંદ કર.

![બેકપેકમાં ઉમેરો](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

સ્ક્રિપ્ટનું નામ આપો અને ઠીક છે પર પુષ્ટિ કર.

![બેકપેકમાં અભિનેતા સાચવો](../../../media/getting-started/grafik-9.png)

સ્ક્રિપ્ટ સાચવવામાં આવે છે અને અન્ય પ્રોજેક્ટ્સમાં ઉપયોગ કરી શકાય છે.

![તારા બેકપેક](../../../media/getting-started/grafik-10.png)

**બેકપેક માંથી સ્ક્રિપ્ટો ઉમેરોઃ:**

જ્યાં તું સ્ક્રિપ્ટ દાખલ કરવા માંગો છો ત્યાં અભિનેતા પર ટેપ કર. તું સ્ક્રિપ્ટ વિસ્તાર જોશો. સંદર્ભ મેનુ ખોલવા માટે ત્રણ બિંદુઓ પર ટેપ કરો અને “બૅકપૅક” પર ટેપ કર.

![સ્ક્રિપ્ટને અનપેક કરો](../../../media/getting-started/grafik-11.png)

હવે તું તારી બેકપેકમાં પહેલેથી જ રહેલી બધી સ્ક્રિપ્ટો જોઈ શકો છો. ઇચ્છિત સ્ક્રિપ્ટની બાજુમાં ત્રણ બિંદુઓ પર ટેપ કરો અને સંદર્ભ મેનૂમાંથી “બૅકપૅકમાંથી કાઢો” પસંદ કર.

સંદર્ભ મેનુ મારફતે, તું સ્ક્રિપ્ટો કાઢી શકો છો કે જે તું તારા બેકપેકમાં હવે જરૂર નથી.

![સ્ક્રીપ્ટ બેકપેક અનપેક](../../../media/getting-started/grafik-12.png)

***

### બેકપેકની લાભો

- **પ્રોજેક્ટ્સ વચ્ચે ફરીથી ઉપયોગઃ:** આંકડા, સ્ક્રિપ્ટો, અવાજો અને દેખાવ એકવાર બનાવી શકાય છે અને જરૂરીયાત મુજબ વારંવાર ફરીથી ઉપયોગ કરી શકાય છે.
- **સમય બચતઃ:** તમારે દર વખતે આંકડા અથવા સ્ક્રિપ્ટને ફરીથી બનાવવાની જરૂર નથી.
- **સુસંગતતાઃ:** જ્યારે તને બહુવિધ પ્રોજેક્ટ્સમાં તેમની જરૂર હોય ત્યારે તત્વો એકસરખા રહે છે.
