Pocket Code એ Catrobat ની મુખ્ય એપ છે. તે મફત છે અને તેનો સોર્સ કોડ ખુલ્લો છે. તું ફોન કે ટૅબ્લેટ પર રમતો, એનિમેશન અને એવી વાર્તાઓ બનાવી શકે છે જેમાં વાચક ભાગ લઈ શકે. Pocket Code માં **બ્લોક વડે કોડ લખવાની રીત** છે. પઝલના ટુકડા જોડે તેમ કોડના બ્લોક જોડીને પોતાનો પ્રોજેક્ટ બનાવ. શરૂઆત કરવા પ્રોગ્રામિંગનો અનુભવ જરૂરી નથી!

Pocket Code માત્ર ડિજિટલ પ્રોજેક્ટ્સથી આગળ વધે છે. નવા **makerspace લક્ષણો** સાથે તું પણ ડિઝાઇન કરી શકે છે **SVG કટીંગ પ્લોટર માટે ફાઇલો**. આનો અર્થ એ થાય કે તું તારી ડિજિટલ રચનાઓને વાસ્તવિક દુનિયાની વસ્તુઓમાં ફેરવી શકો છો અને સ્ક્રીનથી આગળ સર્જનાત્મક શક્યતાઓનું અન્વેષણ કરી શકે છે.

તું કોડિંગ શીખતા હોવ, નવા વિચારો સાથે પ્રયોગ કરતા હોવ અથવા પ્રોગ્રામિંગ શીખવતા હોવ, Pocket Code કોડિંગમાં ડૂબવાની એક રમતિયાળ, સુલભ રીત પ્રદાન કરે છે
