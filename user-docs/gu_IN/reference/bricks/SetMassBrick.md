કિલોગ્રામમાં પદાર્થનું વજન વ્યાખ્યાયિત કરે છે, જે અન્ય પદાર્થો સાથે કેવી રીતે ખસેડવું અને ક્રિયાપ્રતિક્રિયા કરવી તે અસર કરે છે. ભારે વસ્તુઓ ખસેડવાનું મુશ્કેલ છે અને તેમની દિશા બદલવા માટે વધુ બળ લે છે.
