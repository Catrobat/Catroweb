![નોંધ](../../../media/bricks/note_brick2.png)

તારા કોડના ભાગો શું કરે છે તે યાદ રાખવામાં સહાય માટે તારી સ્ક્રિપ્ટમાં ટિપ્પણી અથવા નોંધ ઉમેરે છે. તે તારા પ્રોજેક્ટની કામગીરીને અસર કરતું નથી. તે તારા માટે એક સ્ટીકી નોટ છોડીને જેવું છે.
