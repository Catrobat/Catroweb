![1 ધબકારા માટે વિરામ](../../../media/bricks/Pause_for_1_beats.png)

આ કોડ બ્લોક સ્ક્રિપ્ટ ચાલુ રાખતા પહેલા ચોક્કસ સંખ્યામાં ધબકારાની રાહ જોવે છે. તે આગામી નોટ અથવા અવાજ રમતા પહેલા ગીતમાં થોડો વિરામ લેવાનું જેવું છે. કલ્પના કરો કે તું તારા પ્રદર્શનને થોડુંક અટકાવી, ધબકારાની ગણતરી કરી અને પછી ક્રિયા ફરી શરૂ કરી.
