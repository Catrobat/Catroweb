![રાહ જુઓ-ત્યાં સુધી-બધા અન્ય સ્ક્રિપ્ટો-સ્ટોપ કોડ બ્લોક](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

આ કોડ બ્લોક વર્તમાન સ્ક્રિપ્ટને અટકી જાય છે જ્યાં સુધી પ્રોજેક્ટમાં અન્ય તમામ સ્ક્રિપ્ટ્સ ચાલી રહ્યા ન હોય. કલ્પના કરો કે તું તારી સ્ક્રિપ્ટને રાહ જોવી જોઈએ જ્યાં સુધી બાકીનું બધું પૂર્ણ ન થાય. તે ખાતરી કરવા માટે ઉપયોગી છે કે તારી વર્તમાન સ્ક્રિપ્ટમાં આગળના પગલાંઓ સાથે આગળ વધતા પહેલા કોઈ અન્ય ક્રિયાઓ થતી નથી.
