આ કોડ બ્લોક કણો માટે ઉમેરા મિશ્રણ મોડને સક્ષમ અથવા નિષ્ક્રિય કરે છે, જે કણોને વધુ તેજસ્વી અને વધુ તીવ્ર દેખાડી શકે છે. તે ચમકતા અને ઝગઝગાટને સમાયોજિત કરવા જેવું છે.
