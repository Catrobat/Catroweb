![પેનનો રંગ આ પર સેટ કરો: ઓ લાલ 0 લીલો 0 વાદળી 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

આ કોડ બ્લોક અભિનેતા દ્વારા ઉપયોગમાં લેવાતી પેનની રંગ બદલી નાખે છે. તે ચિત્રકામ કરતી વખતે અલગ રંગની પેન પર સ્વિચ કરવા જેવું છે.

**લાલ, લીલો, વાદળી (RGB)**: રંગોના વિશાળ સ્પેક્ટ્રમ બનાવવા માટે RGB રંગ મોડેલ લાલ, લીલા અને વાદળી પ્રકાશની વિવિધ તીવ્રતાનો ઉપયોગ કરે છે. દરેક રંગ ઘટક (લાલ, લીલો અને વાદળી) 0 થી 255 વચ્ચેનું મૂલ્ય હોઈ શકે છેઃ:

- **લાલ**: રંગનો લાલ ઘટક. ઊંચા મૂલ્યનો અર્થ વધુ લાલ થાય છે.
- **લીલો**: રંગનું લીલું ઘટક. ઊંચા મૂલ્યનો અર્થ વધુ લીલા થાય છે.
- **વાદળી**: રંગનો વાદળી ઘટક. ઊંચા મૂલ્યનો અર્થ વધુ વાદળી થાય છે.

લાલ, લીલા અને વાદળી માટે વિવિધ મૂલ્યોને જોડીને, તું કોઈપણ રંગ બનાવી શકો છો. ઉદાહરણ તરીકેઃ:

- `RGB(255, 0, 0)` શુદ્ધ લાલ છે.
- `RGB(0, 255, 0)` શુદ્ધ લીલા છે.
- `RGB(0, 0, 255)` શુદ્ધ વાદળી છે.
- `RGB(255, 255, 255)` સફેદ (મહત્તમ લાલ, લીલો અને વાદળી) છે.
- `RGB(0, 0, 0)` કાળી છે (કોઈ રંગ નથી).

આ રંગોને વિવિધ માત્રામાં મિશ્રિત કરવાથી ડિજિટલ સ્ક્રીનો પર તું જોઈ શકો છો તે બધા રંગો બનાવવામાં આવે છે.
