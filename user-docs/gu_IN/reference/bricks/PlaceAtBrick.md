ઓબ્જેક્ટને સ્ક્રીન પર ચોક્કસ સ્થિતિ પર ખસેડે છે, જે x અને y કોઓર્ડિનેટ્સ દ્વારા વ્યાખ્યાયિત કરવામાં આવે છે. તે તારા પાત્રને ચોક્કસ સ્થાન પર ટેલિપોર્ટ કરવા જેવું છે.

પોઝિશન કાર્ટેસિયન પ્લેન જેવી કોઓર્ડિનેટ સિસ્ટમમાં સેટ કરવામાં આવે છેઃ x અને y ધરીઓ સ્ક્રીનના કેન્દ્રમાંથી પસાર થાય છે, તેથી x = 0 અને y = 0 સ્ક્રીનની મધ્યમાં છે.
