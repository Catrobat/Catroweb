![પ્લૉટ કરવાનું બંધ કરો](../../../media/bricks/Stop_to_plot.png)

“પ્લૉટ કરવાનું બંધ કરો” કોડ બ્લોક પ્લોટિંગ પ્રક્રિયાને અટકાવે છે અને તને અભિનેતાને નવી સ્થિતિ પર ખસેડવા અથવા પ્લોટિંગ સમાપ્ત કરવાની મંજૂરી આપે છે. તે પેપર પરથી પેન ઉઠાવીને તેને ફરીથી સ્થાનાંતરિત કરવા અથવા ડ્રો કરવાનું બંધ કરવા જેવું છે. તું પ્લાનિંગ પૂર્ણ કર્યા પછી, તું તારા ડિઝાઇનને SVG ફાઇલ તરીકે સાચવવા માટે કોડ બ્લોક “પ્લૉટ SVG તરીકે સાચવો:” નો ઉપયોગ કરી શકે છે.
