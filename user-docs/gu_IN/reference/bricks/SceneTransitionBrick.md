![આ દૃશ્ય ચાલુ રાખો:](../../../media/bricks/continue_scene_brick2.png)

આ કોડ બ્લોક દ્રશ્યને જ્યાં તે બંધ કરવામાં આવ્યું હતું ત્યાંથી પુનઃસ્થાપિત કરે છે. જો તારી દ્રશ્ય વિરામ અથવા રાહ દ્વારા વિક્ષેપિત કરવામાં આવી હતી, આ કોડ બ્લોકનો ઉપયોગ ક્રિયાને જ્યાં બંધ થઈ ત્યાં જ શરૂ કરશે.

કલ્પના કરો કે તું કોઈ રમત અથવા એનિમેશનને અટકાવી દીધું છે, અને હવે તું તેને ચાલુ રાખવા માંગો છો. આ કોડ બ્લોક “ચલાવો” બટન જેવી કાર્ય કરે છે, જે બધું વિરામથી શરૂ કરે છે.
