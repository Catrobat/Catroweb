![આનો ક્લોન બનાવો:](../../../media/bricks/create_clone_of_brick2.png)

આ કોડ બ્લોક ઉલ્લેખિત ઑબ્જેક્ટની નકલ કરે છે, જેને ક્લોન કહેવામાં આવે છે, જે મૂળની જેમ વર્તે છે. તારી રમતમાં કોઈ પાત્ર અથવા પદાર્થને ડુપ્લિકેટ કરવાનું કલ્પના કર. ક્લોન પાસે તેના પોતાના વર્તન અને સ્ક્રિપ્ટ્સ હોઈ શકે છે, જે તને એક પદાર્થના બહુવિધ ઉદાહરણો બનાવવા માટે પરવાનગી આપે છે જે સ્વતંત્ર રીતે કાર્ય કરી શકે છે.
