![છાપ પાડો](../../../media/bricks/Stamp_.png)

આ કોડ બ્લોકનો ઉપયોગ કરીને, તું સ્ક્રીન પર તારા પાત્રના દેખાવની નકલ છોડો છો. તે કાગળ પર રંગીન સ્ટેમ્પ મુકવા અને સ્ટેમ્પ ડિઝાઇનની નકલ છોડીને જેવું છે. આ રીતે, તું તારી પૃષ્ઠભૂમિને વધારશો - તું ક્લોન બનાવી રહ્યાં નથી!
