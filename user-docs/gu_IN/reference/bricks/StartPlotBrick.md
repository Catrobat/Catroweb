![પ્લૉટ કરવાનું શરૂ કરો](../../../media/bricks/Start_to_plot.png)

આ કોડ બ્લોક અભિનેતાની ચાલ સાથે પ્લોટિંગ પ્રક્રિયા શરૂ કરે છે. આ કાગળ પર પેન મૂકવા જેવું છે. તું કોડ બ્લોક “પ્લૉટ કરવાનું બંધ કરો” નો ઉપયોગ કરી શકે છે જો તું ડ્રોઇંગને થોભો અને અભિનેતાને અન્ય સ્થાન પર ખસેડો અને પછી ફરીથી પ્લોટ શરૂ કરો “પ્લૉટ કરવાનું શરૂ કરો”.
