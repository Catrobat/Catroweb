![અંતિમ તબક્કા કોડ બ્લોક](../../../media/bricks/finish-stage-brick.png)

આ કોડ બ્લોક તમામ સ્ક્રિપ્ટો બંધ કરે છે અને વર્તમાન તબક્કા અથવા દ્રશ્ય સમાપ્ત થાય છે. તે કહેવા જેવું છે, “પ્રોજેક્ટનો આ ભાગ સમાપ્ત થયો છે.” બધું બંધ થાય છે, અને પ્રોજેક્ટ ક્યાં તો અન્ય દ્રશ્ય પર ખસેડી શકે છે અથવા સંપૂર્ણપણે સમાપ્ત થઈ શકે છે. જ્યારે તું તારા પ્રોજેક્ટના ચોક્કસ તબક્કા અથવા સ્તરને સમાપ્ત કરવા માંગતા હો ત્યારે આનો ઉપયોગ કર.
