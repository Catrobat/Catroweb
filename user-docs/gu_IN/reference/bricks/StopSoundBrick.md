![અવાજ બંધ કરો:](../../../media/bricks/Stop_sound_record.png)

આ કોડ બ્લોક ચોક્કસ અવાજને રમીને અટકાવે છે. તે એક ગીત માટે સ્ટોપ બટન દબાવવું જેવું છે જ્યારે અન્ય અવાજો અથવા સંગીત વગાડવાનું ચાલુ રાખે છે. કલ્પના કરો કે તું તારા પાત્રને એક ચોક્કસ સાઉન્ડટ્રેક રમવાનું બંધ કરવા કહો છો.
