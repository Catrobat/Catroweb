![દોરાનો રંગ આ પર સેટ કરો: ’#ff0000′](../../../media/bricks/Set_thread_color_to_ff0000.png)

આ બ્લોકનો ઉપયોગ કરીને, તું તારા સીવણ પ્રોજેક્ટ માટે થ્રેડનો રંગ બદલી શકો છો. રંગ તારા કાર્યક્રમમાં પ્રદર્શિત થશે. આનો અર્થ એ નથી કે ભરતકામ મશીન પછી આ ચોક્કસ રંગોનો ઉપયોગ કરશે.
