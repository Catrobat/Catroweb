![પૃષ્ઠભૂમિ બદલીને આ કરો અને રાહ જુઓ: નવી](../../../media/bricks/Set_background_and_wait_new.png)

આ કોડ બ્લોક નવી પૃષ્ઠભૂમિ સેટ કરે છે અને સ્ક્રિપ્ટ ચાલુ રાખતા પહેલા ફેરફાર પૂર્ણ થાય ત્યાં સુધી રાહ જુએ છે. તે એક નાટકમાં લેન્ડસ્કેપ બદલવા અને નવા દ્રશ્યને સંપૂર્ણ સેટ થવાની રાહ જોવી જેવું છે.
