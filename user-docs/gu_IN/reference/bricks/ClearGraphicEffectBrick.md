![ગ્રાફિક અસરો દૂર કરો](../../../media/bricks/Clear_graphic_effects.png)

આ કોડ બ્લોક એક્ટરને લાગુ પડેલી કોઈપણ દ્રશ્ય અસરોને દૂર કરે છે, તેને તેના મૂળ દેખાવમાં પાછો આપે છે. તે ફરીથી સ્પષ્ટ કરવા માટે એક સ્પોટ વિન્ડો સાફ કરવા જેવું છે.
