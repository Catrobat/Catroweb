જ્યારે પદાર્થ ચોક્કસ સપાટી અથવા પદાર્થ પરથી બૂમ પાડે ત્યારે પ્રતિક્રિયા અથવા ક્રિયા થાય છે. તે કહેવા જેવું છે, “આ ક્રિયા કરો જ્યારે પણ મારો પાત્ર દિવાલ અથવા અન્ય પદાર્થ પરથી બૂમ પાડે છે.”
