*ઉલ્લેખિત મૂલ્ય અથવા કાર્ય સાચું થાય ત્યાં સુધી રાહ જુએ છે અને પછી સ્ક્રિપ્ટ ચલાવે છે.*

![આ દૃશ્ય શરૂ કરો:](../../../media/bricks/StartScene.png)

જ્યારે દ્રશ્ય શરૂ થાય છે, ત્યારે ચલ X 0 પર સેટ કરવામાં આવે છે.

![જ્યારે ટૅપ કરવામાં આવે જ્યારે મોડ્યુલો](../../../media/bricks/WhenTappedWhenModulo.png)

જો પ્રાણીને હવે ટેપ કરવામાં આવે તો X 1 દ્વારા વધે છે.

જ્યારે X મોડ્યુલો 2 સાચું બને છે, એટલે કે જો X એક વિચિત્ર સંખ્યા છે, ત્યારે અવાજ Tweet1 રમાય છે.
