![જ્યારે તમે ક્લોન તરીકે શરૂ થાઓ](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

ઇચ્છિત ક્રિયાઓ કરવા માટેની સૂચનાઓ સાથે કોઈ પદાર્થનો બનાવેલો ક્લોન નિર્દેશિત કરવો. આ પ્રક્રિયા ક્લોનને સ્વતંત્ર રીતે નિયંત્રિત કરતી વખતે મૂળ પદાર્થની કાર્યક્ષમતાને નકલ કરવાની મંજૂરી આપે છે. ચોક્કસ જરૂરિયાતોને પૂર્ણ કરવા માટે ક્લોન ઑબ્જેક્ટના વિવિધ વર્તન અથવા ગુણધર્મોને સ્પષ્ટ કરી શકાય છે.
