![જો અન્યથા કોડ બ્લોક](../../../media/bricks/if_else_brick2.png)

*જો કોઈ શરત સાચું છે કે નહીં તે તપાસે છે, અને સૂચનાઓનો એક સેટ ચલાવે છે જો તે સાચું છે, અને અન્ય સેટ જો તે ન હોય તો. તે બે વિકલ્પો આપવાની જેમ છેઃ “જો આ સાચું છે, તો આ કરો; અન્યથા, તે કર.”*

![આ દૃશ્ય શરૂ કરો:](../../../media/bricks/StartScene.png)

જ્યારે દ્રશ્ય શરૂ થાય છે, ત્યારે ચલ X 0 પર સેટ કરવામાં આવે છે.

![જો અન્ય](../../../media/bricks/IfElse.png)

જો પ્રાણીને હવે ટેપ કરવામાં આવે તો, તપાસ કરવામાં આવે છે કે શું X મોડ્યુલો 2 સાચું છે, એટલે કે, જો X એક વિચિત્ર સંખ્યા છે.

જો આ કેસ છે, તો ધ્વનિ Tweet1 રમાય છે અને ચલ X 1 દ્વારા વધે છે.

અન્યથા, જો X યથાવત છે, તો માત્ર X 1 દ્વારા વધે છે.

અમલમાં મૂકવા માટેના નિવેદનો જો-શરતનો અંત દ્વારા અલગ કરવામાં આવે છે.
