આ ટ્યુટોરીયલમાં, તું શીખી શકશો કે કેવી રીતે લોલિપૉપ (124.6 x 65.6mm) ને ભરતકામ કરવું.

![લોલીપોપ (2)](../../../media/embroidery-tutorials/Lollipop-2.png)

તમારે પહેલેથી જ જાણવું જોઈએ કે લૂપ શું છે અને તે કેવી રીતે કાર્ય કરે છે.

આ ટ્યુટોરીયલ માટે **[વર્તુળ](../embroidery-tutorials-beginner/circle.md)**-ટ્યુટોરીયલ મદદરૂપ થઈ શકે છે.

જો તું હજી સુધી કશું જ ગૂંથ્યું નથી તો [શરુઆત](../embroidery-tutorials-beginner/index.md) શ્રેણીમાં ગૂંથણ ટ્યુટોરિયલ્સ પર એક નજર નાખો.

વધુ માહિતી અથવા ડિઝાઇન સૂચનો માટે અન્ય ટ્યુટોરિયલ્સ તપાસો.

*અહીં તું ટ્યુટોરીયલ ડાઉનલોડ કરી શકે છે PDF-ફોર્મેટ*:

[લોલિપૉપપ્રો](../../../media/embroidery-tutorials/LollipopPro.pdf)

### 2. મૂળભૂત માળખું

![લોલીપોપ (5)](../../../media/embroidery-tutorials/Lollipop-5.png)

### 3. વર્તુળો

આ ભાગ દરેક વખતે જ્યારે વર્તુળ સંદેશ મોકલવામાં આવે છે કૉલ કરવામાં આવે છે. તેને તારી સ્ક્રિપ્ટમાં પણ ઉમેરો.

### 4. તારી ડિઝાઇન શરૂ કરવા માટે રમતને ટેપ કરો!
