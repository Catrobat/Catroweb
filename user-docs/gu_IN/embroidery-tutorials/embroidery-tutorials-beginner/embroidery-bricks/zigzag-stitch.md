સતત ચલ લંબાઈ અને પહોળાઈ સાથે સીવણ.

'ઝિગઝૅગ' પેટર્નમાં સીવણ.

![આટલી લંબાઈ સાથે ઝિગઝૅગ ટાંકો શરૂ કરો: 2 અને પહોળાઈ: 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

આ કોડ બ્લોકને જાણવા માટે લંબાઈ અને પહોળાઈ માટેના વિવિધ મૂલ્યોનો પ્રયાસ કર.

![આટલી લંબાઈ સાથે ઝિગઝૅગ ટાંકો શરૂ કરો:](../../../../media/embroidery-tutorials/ZigzagStitch.png)

તું ઝિગાઝક સીવણ સાથે જાડા સીવણો સીવવા કરી શકે છે.
