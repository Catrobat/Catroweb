મશીન સતત ચલ લંબાઈ સાથે સીવણ પરવાનગી આપે છે.

સામાન્ય રીતે તું ચાલતા સીવણ સાથે ખસેડવાની કોડ બ્લોક ભેગા કર.

![આટલી લંબાઈ સાથે સીધો ટાંકો શરૂ કરો: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

મશીન ચાલી ગયેલી સીવણ શરૂ કરે છે જે દરેક **10 પગલાં** સીવણ કરશે.

પછી મશીન ખસેડે છે **200 પગલાં**.

આ પરિણામે **20 સીવણ** છે.

![આટલી લંબાઈ સાથે સીધો ટાંકો શરૂ કરો:](../../../../media/embroidery-tutorials/RunningStitch.png)

ચાલી રહેલ સીવણ સીવણ સરળ બનાવે છે કારણ કે તને હવે લૂપની જરૂર રહેશે નહીં.
