વર્તમાન સીવણ બંધ કરવા દો.

જો તું ચાલી, ઝિગાઝ અથવા ટ્રીપલ સીવણ શરૂ કર્યા પછી સોયની સ્થિતિ બદલવા માંગતા હો તો તને આ કોડ બ્લોકની જરૂર પડશે.

![વર્તમાન ટાંકો બંધ કરો](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

નહિંતર અનિચ્છનીય મધ્યવર્તી સીવણ થશે.
