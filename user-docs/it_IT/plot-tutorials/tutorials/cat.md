Quando il tracciato parte, ogni movimento viene disegnato come con una penna. Lungo queste linee il plotter taglia dopo.

Il nostro oggetto guarda in direzione 150 gradi.

In questo tutorial facciamo prima il lato destro della testa del gatto. Se guardi bene, all'inizio la curva è forte: dopo ogni piccola linea l'oggetto deve girare di più. Poi, per la parte bassa della testa, le curve diventano più piccole. Il lato sinistro della testa è di nuovo molto curvo. Per questo questa parte della testa usa in tutto tre cicli.

Poi viene l'orecchio sinistro. È fatto solo di linee dritte, quindi possiamo usare il blocco “Muovi \_\_ passi”.

La parte tra le orecchie è di nuovo un arco e la programmiamo con un altro ciclo.

Poi facciamo l'orecchio destro.

Il tracciato è finito. Chiudilo con il blocco “Smetti di tracciare” e salvalo sul tuo telefono con “Salva il tracciato come SVG \_\_\_”.

Ora puoi mandare il file SVG a un plotter (da taglio).
