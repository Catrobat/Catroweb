Apri l'app sul tuo smartphone o tablet.

![Schermata principale, nuovo progetto](../../../media/getting-started/MainScreen_NewProject.png)\
Tocca il simbolo + per creare un nuovo progetto.\
[Apri l’immagine](../../../media/getting-started/MainScreen_NewProject.png)

Dai un nome al progetto (1) e scegli se vuoi creare un gioco in formato verticale o orizzontale (2).

![Nuovo progetto](../../../media/getting-started/NewProject.png)\
Poi conferma con il segno di spunta (3).\
[Apri l’immagine](../../../media/getting-started/NewProject.png)

Ora sei nella vista del progetto. In alto vedi il nome del tuo gioco.

Sotto vedi lo **sfondo**. Per ora lo sfondo è vuoto. Se vuoi cambiarlo, toccalo.

Sotto lo sfondo vedi la parte con gli **attori e oggetti** che hai aggiunto al tuo gioco. Per ora questa parte è ancora vuota.

In basso a destra vedi due pulsanti importanti:

![Avvia](../../../media/getting-started/Start.png)\
Con il pulsante **Esegui** fai partire il tuo gioco.

![Pulsante più](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Con il pulsante **più** aggiungi un nuovo personaggio o oggetto al tuo gioco.

![Vista del progetto](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
Ora sei nella vista del progetto.\
[Apri l’immagine](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
