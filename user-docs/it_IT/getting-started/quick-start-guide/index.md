Pocket Code è un'app di programmazione visuale. Con Pocket Code crei giochi, animazioni e storie interattive direttamente sul tuo smartphone o tablet. Trascini e lasci cadere dei "mattoncini" (blocchi di codice) in modo semplice, così puoi creare i tuoi progetti anche se non hai mai programmato. Aggiungi facilmente suoni, immagini e movimenti per dare vita alle tue idee.

Questa guida ti aiuta a iniziare. Ti spiega come:

- muoverti nell'app,
- creare il tuo primo progetto,
- lavorare con oggetti e sfondi,
- usare i mattoncini per programmare azioni e
- salvare il tuo progetto.

Pocket Code è perfetto per chi inizia e per gli insegnanti. Aiuta a essere creativi, a risolvere problemi e a pensare in modo logico.
