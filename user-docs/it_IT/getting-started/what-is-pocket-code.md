Pocket Code è l'app principale di Catrobat. È un'app gratuita e open source che ti permette di creare giochi, animazioni e storie interattive sul tuo smartphone o tablet. Pocket Code usa un **sistema di programmazione a blocchi**: costruisci i tuoi progetti unendo blocchi di codice, come i pezzi di un puzzle. Non serve sapere già programmare, quindi è perfetta per chi inizia!

Con Pocket Code non crei solo progetti digitali. Con le nuove **funzioni da makerspace** puoi anche disegnare **file SVG per plotter da taglio**. Così le tue creazioni digitali diventano oggetti veri e puoi scoprire tante idee nuove oltre lo schermo.

Che tu stia imparando a programmare, provando nuove idee o insegnando la programmazione, Pocket Code ti offre un modo semplice e giocoso per iniziare a programmare

[Altre informazioni](https://catrobat.org/pocket-code/)
