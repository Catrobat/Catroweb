Questo blocco fa una copia dell’oggetto che scegli. La copia si chiama clone e si comporta come l’originale. Immagina di duplicare un personaggio o un oggetto nel tuo gioco. Il clone può avere i suoi comportamenti e i suoi script. Così puoi avere tante copie di un oggetto che si muovono ognuna per conto suo.
