![Inizia a tracciare](../../../media/bricks/Start_to_plot.png)

Questo mattoncino fa iniziare a tracciare mentre l'attore si muove. È come appoggiare una penna sulla carta per iniziare a disegnare una linea. Puoi usare il mattoncino "Smetti di tracciare" se vuoi mettere in pausa il disegno e spostare l'attore in un altro punto. Poi puoi ricominciare a tracciare con "Inizia a tracciare".
