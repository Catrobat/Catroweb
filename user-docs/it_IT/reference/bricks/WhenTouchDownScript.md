Fa partire lo script quando tocchi lo schermo.

La differenza con il blocco *"Quando vieni toccato"* è questa: *"Quando lo Stage viene toccato"* vale per tutto lo schermo, mentre *"Quando vieni toccato"* vale solo per un singolo sprite o oggetto.
