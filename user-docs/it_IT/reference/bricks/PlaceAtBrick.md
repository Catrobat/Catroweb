Sposta l’oggetto in un punto preciso dello schermo, dato dalle coordinate x e y. È come teletrasportare il tuo personaggio in un punto esatto.

La posizione si indica in un sistema di coordinate come il piano cartesiano: gli assi x e y passano per il centro dello schermo, quindi x = 0 e y = 0 è il centro dello schermo.
