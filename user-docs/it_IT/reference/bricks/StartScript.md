Se usi questo blocco, lo script parte subito quando inizia la scena. Una scena è l'inizio del tuo programma. Una scena è una nuova vista del tuo programma: lì puoi mostrare altri elementi e possono succedere cose diverse. Puoi avere tante scene per le diverse parti del tuo programma. Per esempio una scena per l'introduzione, una per il menu principale, una per il primo livello, una per il secondo livello e così via. Nei programmi più semplici basta anche una sola scena: allora l'inizio del programma è anche l'inizio della scena.

Come ogni script, anche questo inizia con un mattoncino evento: l'evento decide **quando** parte lo script, i mattoncini che vengono dopo dicono al programma **cosa** fare.
