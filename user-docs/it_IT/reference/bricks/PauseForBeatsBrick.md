Questo blocco fa aspettare lo script per un certo numero di battiti prima di andare avanti. È come fare una piccola pausa in una canzone prima di suonare la nota o il suono successivo. Immagina di fermarti un attimo durante lo spettacolo, contare i battiti e poi ricominciare.
