![Smetti di tracciare](../../../media/bricks/Stop_to_plot.png)

Il mattoncino "Smetti di tracciare" mette in pausa il tracciato. Così puoi spostare l'attore in un nuovo punto o finire il tracciato. È come alzare la penna dalla carta per spostarla o smettere di disegnare. Quando hai finito di tracciare, puoi usare il mattoncino "Salva il tracciato come SVG" per salvare il tuo disegno come file SVG.
