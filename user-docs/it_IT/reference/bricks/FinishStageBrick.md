Questo blocco ferma tutti gli script e chiude lo stage o la scena di adesso. È come dire: “Questa parte del progetto è finita.” Tutto si ferma, e il progetto può passare a un’altra scena o finire del tutto. Usalo quando vuoi chiudere uno stage o un livello del tuo progetto.
