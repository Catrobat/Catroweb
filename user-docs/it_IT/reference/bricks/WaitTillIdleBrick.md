![wait-until-all-other-scripts-stopped-brick](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Questo mattoncino mette in pausa lo script finché tutti gli altri script del progetto non hanno finito. Immagina di mettere in attesa il tuo script finché tutto il resto non è finito. È utile per essere sicuro che non stia succedendo nient'altro prima di fare i passi successivi del tuo script.
