![for-each-value_brick](../../../media/bricks/for-each-value_brick.png)

Questo blocco esegue un gruppo di istruzioni per ogni elemento di una lista o di un intervallo. È come prendere ogni elemento, uno alla volta, e fare la stessa cosa con ognuno.

Immagina di avere una lista di numeri, di colori o di altre cose. Con questo blocco prendi ogni elemento della lista e ci fai qualcosa. Per esempio, se hai una lista di colori e vuoi colorare lo sfondo con ogni colore della lista, usi questo blocco.

È come dire: “Per ogni elemento di questo gruppo, esegui queste istruzioni.”
