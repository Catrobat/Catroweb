*Controlla se una condizione è vera. Se è vera, esegue un gruppo di istruzioni; se non lo è, ne esegue un altro. È come dare due possibilità: “Se questo è vero, fai questo; altrimenti fai quello.”*

![StartScene](../../../media/bricks/StartScene.png)

Quando la scena parte, la variabile X diventa 0.

![IfElse](../../../media/bricks/IfElse.png)

Se adesso tocchi l’animale, il programma controlla se X modulo 2 è vero, cioè se X è un numero dispari.

Se è così, parte il suono Tweet1 e la variabile X aumenta di 1.

Altrimenti, se X è pari, X aumenta solo di 1.

Le istruzioni da eseguire finiscono con un “Fine se”.
