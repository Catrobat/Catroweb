In questo tutorial impari tutto quello che ti serve sapere su Pocket Code per creare il tuo primo progetto. Ti mostriamo passo dopo passo come scaricare l'app, aprirla e creare un nuovo progetto.

![Nuovo programma](../../../media/game-tutorials/New-Program.png)\

[Apri l’immagine](../../../media/game-tutorials/New-Program.png)

Questo è il primissimo tutorial e non devi sapere niente prima.

Allora, cosa aspetti? Prendi il tuo telefono e inizia subito!

*Qui puoi scaricare il tutorial in formato PDF:*

[Apri il PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Installa Pocket Code

Per prima cosa installa l'app Pocket Code sul tuo dispositivo. Per questo passo ti serve un account Google. Ora il tuo dispositivo scarica e installa l'app. Può volerci un po', dipende dalla tua connessione a internet.

![Nuovo programma (2)](../../../media/game-tutorials/New-Program-2.png)\
Cerca “Pocket Code” nel Google Play Store e scaricala toccando “Installa”.\
[Apri l’immagine](../../../media/game-tutorials/New-Program-2.png)

Quando Pocket Code è scaricato e installato, trovi l'app nell'elenco delle app o nella schermata home, dipende dal tuo dispositivo. Puoi prendere l'app e metterla dove vuoi.

### 2. Avvia l'app

![Nuovo programma (1)](../../../media/game-tutorials/New-Program-1.png)\
Quando apri l'app, vedi diverse categorie.\
[Apri l’immagine](../../../media/game-tutorials/New-Program-1.png)

### 3. Crea un nuovo progetto

Ora crei davvero un nuovo progetto. Scrivi il nome del progetto e scegli se il progetto deve essere orizzontale oppure no. Tocca “OK” e il progetto è creato.

![Nuovo programma](../../../media/game-tutorials/New-Program.png)\
Tocca il pulsante giallo con il più in basso a destra.\
[Apri l’immagine](../../../media/game-tutorials/New-Program.png)

### 4. Ce l'hai fatta! Hai creato il tuo nuovo progetto.

Ora hai installato Pocket Code e sai come creare un nuovo progetto. Puoi iniziare a programmare!

Per farlo, devi sapere come creare un nuovo oggetto in un progetto. Guarda il tutorial **[Nuovo oggetto](new-object.md)**: lì ti spieghiamo tutto passo dopo passo.
