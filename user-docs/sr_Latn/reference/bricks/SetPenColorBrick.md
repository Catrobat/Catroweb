Ovaj blok menja boju olovke kojom lik crta. To je kao kada u crtanju pređeš na olovku druge boje.

**Crvena, zelena, plava (RGB)**: RGB model boja koristi različite jačine crvene, zelene i plave svetlosti da napravi širok spektar boja. Svaka komponenta boje (crvena, zelena i plava) može imati vrednost od 0 do 255:

- **Crvena**: Crvena komponenta boje. Veća vrednost znači više crvene.
- **Zelena**: Zelena komponenta boje. Veća vrednost znači više zelene.
- **Plava**: Plava komponenta boje. Veća vrednost znači više plave.

Kombinovanjem različitih vrednosti za crvenu, zelenu i plavu možeš da napraviš bilo koju boju. Na primer:

- `RGB(255, 0, 0)` je čista crvena.
- `RGB(0, 255, 0)` je čista zelena.
- `RGB(0, 0, 255)` je čista plava.
- `RGB(255, 255, 255)` je bela (najviše crvene, zelene i plave).
- `RGB(0, 0, 0)` je crna (nema boje).

Mešanjem ovih boja u različitim količinama dobijaju se sve boje koje vidiš na digitalnim ekranima.
