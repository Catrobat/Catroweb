![Postavi na x y](../../../media/bricks/place_at_x_y_brick.png)

Pomera objekat na određeni položaj na ekranu, zadat koordinatama x i y. To je kao kada svog lika teleportuješ na tačno određeno mesto.

Položaj se zadaje u koordinatnom sistemu kao Dekartova ravan: ose x i y prolaze kroz središte ekrana, pa su x = 0 i y = 0 sredina ekrana.
