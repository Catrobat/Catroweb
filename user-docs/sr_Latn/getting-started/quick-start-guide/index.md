Pocket Code je aplikacija za vizuelno programiranje koja ti omogućava da praviš igre, animacije i interaktivne priče direktno na svom telefonu ili tabletu. Uz intuitivan prevlačenje-i-spuštanje interfejs sa „blokovima“ (blokovima koda), možeš da osmisliš svoje projekte bez prethodnog iskustva u programiranju. Lako dodaj zvukove, slike i kretanje da bi tvoje ideje oživele.

Ovaj vodič će ti pomoći da počneš tako što objašnjava kako da:

- se snalaziš u interfejsu,
- napraviš svoj prvi projekat,
- radiš sa objektima i pozadinama,
- koristiš blokove da programiraš radnje i
- sačuvaš svoj projekat.

Pocket Code je idealan za početnike i nastavnike i podstiče kreativnost, rešavanje problema i logično razmišljanje.
