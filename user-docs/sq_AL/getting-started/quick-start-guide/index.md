Pocket Code është një aplikacion programimi vizual që ju lejon të krijoni lojëra, animacione dhe histori interaktive direkt në smartphone ose tablet. Duke përdorur një ndërfaqe intuitive tërheqje dhe hedhje me «bloket e kodit» (blloqet e kodit), mund të projektoheni projektet tuaja pa përvojë të mëparshme programimi. Përshkruani lehtë tinguj, imazhe dhe lëvizje për të sjellë ide në jetë.

Ky udhëzues do t'ju ndihmojë të filloni duke shpjeguar se si:

- Navigoni në ndërfaqe,
- Krijoni projektin tuaj të parë,
- Punoni me objekte dhe sfonda,
- Përdorni blokë kod për të programuar veprimet, dhe
- Shpëto projektin tënd.

Perfekt për fillestarët dhe edukatorët, Pocket Code inkurajon krijimtarinë, zgjidhjen e problemeve dhe mendimin logjik.
