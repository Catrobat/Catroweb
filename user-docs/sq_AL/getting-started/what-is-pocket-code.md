Pocket Code është aplikacioni kryesor nga Catrobat, një aplikacion i lirë dhe me burim të hapur për celularë që ju lejon të krijoni lojëra, animacione dhe histori interaktive direkt në smartphone ose tablet. Me **Sistem i kodimit në bazë të blokëve** në Pocket Code, ju mund të ndërtoni projekte duke copëtuar blloqet e kodit - si të vendosni pjesë të një puzzle. Nuk ka nevojë për eksperiencë programimi, duke e bërë atë të përsosur për fillestarët!

Pocket Code shkon përtej vetëm projekteve dixhitale. Me të re **karakteristika të hapësirës së krijuesit**, ju gjithashtu mund të projektojnë **SVG skedarë për ndërtimin e plotës**. Kjo do të thotë që mund t'i ktheheni krijesa tuaja dixhitale në objekte të botës reale dhe të eksploroni mundësitë krijuese përtej ekranit.

Nëse jeni duke mësuar të kodoni, duke eksperimentuar me ide të reja ose mësim programimi, Pocket Code ofron një mënyrë lojëruese dhe të arritshme për të zhytur në kodim
