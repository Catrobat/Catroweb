Shton një koment ose shënim në skenarën tuaj për t'ju ndihmuar të mbani mend se çfarë pjesë të kodit tuaj bëjnë. Nuk ndikon në mënyrën se si funksionon projekti yt. Është si të lë një shënim të ngjitur për veten.
