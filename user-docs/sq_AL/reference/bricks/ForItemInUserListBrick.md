![Për çdo vlerë nga](../../../media/bricks/for-each-value_brick.png)

Ky bllok kodi ka një grup udhëzime për secilin element në një listë ose gamë. Është si të shqyrtojmë secilin objekt një pas tjetrit dhe të bëjmë të njëjtën veprim në secilën.

Imagjinoni se keni një listë me numra, ngjyra ose ndonjë gjë. Ky bllok kodi ju lejon të merrni çdo element nga ajo listë dhe të bëni diçka me të. Për shembull, nëse keni një listë ngjyrash dhe dëshironi të ndryshoni ngjyrën e sfondit në secilin ngjyrë në listë, do ta përdorni këtë bllok kod.

Është si të thuash, «Për secilin objekt në këtë grup, bëni këto udhëzime.»
