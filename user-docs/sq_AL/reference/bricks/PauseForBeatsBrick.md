Ky bllok kod bën që skripti të presë një numër të caktuar rrahjeve para se të vazhdojë. Është si të bësh një pushim të shkurtër në një këngë para se të luajë nota ose tingull tjetër. Imagjinoni se e keni ndalur për një moment performancën tuaj, duke numëruar ritmet dhe pastaj të rifilloheni veprimin.
