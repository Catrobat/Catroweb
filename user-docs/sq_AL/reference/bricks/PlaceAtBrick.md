![Vendos në](../../../media/bricks/place_at_x_y_brick.png)

Shëton objektin në një pozicion specifik në ekran, të përcaktuar nga koordinatat x dhe y. Është si të teleportojmë karakterin tënd në një vend të saktë.

Pozicioni është vendosur në një sistem koordinate si aeroplani kartesian: akset x dhe y kalojnë nëpër qendër të ekranit, kështu që x = 0 dhe y = 0 është mes i ekranit.
