Shpelet skenar kur ekrani është prekur.

Dallimi për bllokun *«Kur prekesh»* është se *«Kur preket skena»* zbatohet në të gjithë ekranin, ndërsa *«Kur prekesh»* është specifik për sprite ose objekte individuale.
