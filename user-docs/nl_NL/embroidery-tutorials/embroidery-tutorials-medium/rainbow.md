![Regenbogen](../../../media/embroidery-tutorials/Regenbogen.webp)

Je moet al weten wat een lus is en hoe die werkt.

De tutorial **[Halve cirkel](../embroidery-tutorials-beginner/semicircle.md)** kan bij deze tutorial helpen.

Bekijk de borduurtutorials uit de reeks [voor beginners](../embroidery-tutorials-beginner/index.md) als je nog nooit iets hebt geborduurd.

Voor meer informatie of ontwerpsuggesties kun je de andere tutorials bekijken.

### 3. Object kopiëren

Voor de volgende, grotere boog kun je het object dat je net hebt gemaakt gewoon kopiëren.

Tik op de drie puntjes rechtsboven in het overzicht van de objecten.

Ga dan naar “Kopiëren” en kies het object.

![Regenbogen (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Als je voor elke boog een apart object gebruikt, kun je ze later in verschillende kleuren borduren.

### 4. Object aanpassen
