In deze tutorial leer je hoe je een vierkant borduurt (60 x 60 mm).

![afbeelding (3)](../../../media/embroidery-tutorials/image-3.png)

Je moet al weten hoe je een nieuw object maakt en er bricks in zet. Bekijk de tutorials in de [Starterreeks](../../game-tutorials/starter-tutorials/index.md) als je nog hulp nodig hebt. Verder moeten de borduurbricks al geactiveerd zijn. Hoe dat werkt, lees je in de tutorial **[Borduurbricks activeren](activate-embroidery-bricks.md)**.

Voor meer informatie of ontwerpsuggesties kun je de andere tutorials bekijken.

*Hier kun je de tutorial als PDF downloaden*:

[Vierkant](../../../media/embroidery-tutorials/Square.pdf)

### 1. Maak een nieuw borduurobject (zie [Borduurobjecten maken](create-embroidery-objects.md)).

### 2. Start nu en voeg de bricks stap voor stap aan je script toe.

![Vierkant](../../../media/embroidery-tutorials/Square.png)

Een vierkant bestaat uit vier lijnen die elkaar in een hoek van 90° ontmoeten.

Eerst voert het script de rijgsteek uit. Daarna verplaatst het de naald 300 stappen en draait het 90°. Dit wordt 4 keer herhaald.

Wat gebeurt er als je de hoek of de stappen aanpast? **Probeer het uit!**

### 3. Tik op afspelen om je ontwerp te starten!
