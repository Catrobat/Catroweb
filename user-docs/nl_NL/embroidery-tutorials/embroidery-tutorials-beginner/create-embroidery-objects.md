In deze tutorial leer je hoe je objecten maakt waarmee je later je patronen kunt borduren.

Voor deze tutorial moet je al weten hoe je een project maakt. Bekijk de tutorials uit de [Starterreeks](../../game-tutorials/starter-tutorials/index.md) als je hulp nodig hebt.

Voor meer informatie of ontwerpsuggesties kun je de andere tutorials bekijken.

*Hier kun je de tutorial als PDF downloaden*:

[Borduurobjecten maken](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Tik rechtsonder in je project op de plusknop om een nieuw object toe te voegen.

![Borduurobjecten maken](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Om een afbeelding te kiezen, ga je naar de mediabibliotheek.

![Borduurobjecten maken (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Een borduurobject staat voor één laag van de naald van de borduurmachine. Meerdere borduurobjecten worden na elkaar geborduurd. Zo kun je meerdere kleuren gebruiken.

Kies je object op basis van de kleur die je wilt.

Scroll naar beneden en zoek de passende pijl.

![Borduurobjecten maken (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Geef je nieuwe object een passende naam en tik op OK.

![Borduurobjecten maken (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Je hebt nu een nieuw object gemaakt. Je kunt nu een script toevoegen en het object programmeren.

![Borduurobjecten maken (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Nu weet je hoe je een object maakt. Voeg een nieuw object toe voor elke kleur die je wilt gebruiken.

Je kunt in elke kleur een script toevoegen en zo je eigen ontwerpen programmeren en ze later zelfs borduren.
