In deze tutorial leer je hoe je je afgemaakte ontwerpen op je mobiele apparaat opslaat en deelt.

Hiervoor heb je een afgemaakt borduurontwerp nodig dat je wilt exporteren. Heb je er nog geen? Laat je dan inspireren door onze [borduurtutorials](index.md)!

*Hier kun je de tutorial als PDF downloaden*:

[Ontwerpen exporteren](../../../media/embroidery-tutorials/Export-Designs.pdf)

### 1. Start je project en wacht tot het helemaal is uitgevouwen. Anders is het patroon onvolledig.

### 2. Tik op terug en druk op de deelknop.

![Ontwerpen exporteren (1)](../../../media/embroidery-tutorials/Export-Designs-1.png)

### 3. Deel je borduurbestand per e-mail of sla het op je telefoon op.

![Ontwerpen exporteren (2)](../../../media/embroidery-tutorials/Export-Designs-2.png)

De deelfunctie kan er op elke telefoon een beetje anders uitzien.

Je borduurontwerp wordt opgeslagen als DST-bestand.

De borduurmachine kent dit bestandsformaat en maakt je ontwerp af op je stof.
