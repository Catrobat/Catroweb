Laat de machine steeds steken met een instelbare lengte.

Meestal combineer je de rijgsteek met een verplaats-brick.

![Begin_rijgsteek_met_lengte_10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

De machine start een rijgsteek die elke **10 stappen** steekt.

Daarna beweegt de machine **200 stappen**.

Dat levert **20 steken** op.

![Rijgsteek](../../../../media/embroidery-tutorials/RunningStitch.png)

De rijgsteek maakt het naaien van een naad makkelijker, omdat je geen lus meer nodig hebt.
