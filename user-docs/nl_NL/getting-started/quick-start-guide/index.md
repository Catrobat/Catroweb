Pocket Code is een visuele programmeerapp waarmee je games, animaties en interactieve verhalen direct op je smartphone of tablet maakt. Met een makkelijke sleep-en-zet-omgeving met “bricks” (codeblokjes) ontwerp je je projecten zonder dat je al kunt programmeren. Voeg makkelijk geluiden, afbeeldingen en beweging toe om je ideeën tot leven te brengen.

In deze gids leer je:

- de omgeving gebruiken,
- je eerste project maken,
- met objecten en achtergronden werken,
- bricks gebruiken om acties te programmeren, en
- je project opslaan.

Pocket Code is perfect voor beginners en docenten. De app stimuleert creativiteit, probleemoplossend denken en logisch denken.
