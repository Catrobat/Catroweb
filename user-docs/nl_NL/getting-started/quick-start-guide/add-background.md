Je kunt een achtergrond aan je project toevoegen in Catrobat.

Achtergronden kun je op veel manieren gebruiken. In Pocket Code kun je ze gebruiken om **games** mooier te maken, om **verhalen** te vertellen, of om je figuren en objecten meer context te geven.

Voor makerspace-apparaten zoals **plotters** of **borduurmachines** dienen achtergronden als ontwerpsjabloon, bijvoorbeeld voor snijwerk of borduurpatronen.

![Tik op achtergrond](../../../media/getting-started/grafik-16.png)\
Om een achtergrond toe te voegen, tik je in de projectweergave op “Achtergrond”.\
[Afbeelding openen](../../../media/getting-started/grafik-16.png)

In het **scriptgedeelte (2)** programmeer je je achtergrond. Niet alle bricks zijn daarvoor beschikbaar. De volgende twee blokken zijn vooral belangrijk: ![Zet_transparantie_op_50_pct](../../../media/bricks/Set_transparency_to_50_pct_.png) en ![Zet_grootte_op_60_pct](../../../media/bricks/Set_size_to_60_pct_.png)

In het **uiterlijkengedeelte (1)** voeg je een achtergrond toe.

![Achtergrond toevoegen](../../../media/getting-started/grafik-14.png)\
Tik daarvoor op het plusteken.\
[Afbeelding openen](../../../media/getting-started/grafik-14.png)

Je kunt je eigen afbeeldingen uploaden, vooraf gemaakte achtergronden gebruiken of zelf een achtergrond maken.

**Tekenen**: Je kunt je eigen achtergrond maken met **Pocket Paint**. Pocket Paint is een tekenprogramma ([meer over Pocket Paint](https://catrobat.org/pocket-paint/))

**Uiterlijken**: Kies er één uit een verzameling kant-en-klare achtergronden ([meer over de mediabibliotheek](../elements/medialibrary.md)).

**Galerij**: Je kunt een afbeelding uit de galerij van je smartphone kiezen.

**Camera**: Je kunt de camera van je apparaat gebruiken om een foto te maken en die als achtergrond toe te voegen.

![grafik](../../../media/getting-started/grafik-17.png)\
Tik rechtsboven op de pijl terug om naar de **projectweergave** te gaan.\
[Afbeelding openen](../../../media/getting-started/grafik-17.png)

Je hebt nu een achtergrond toegevoegd.
