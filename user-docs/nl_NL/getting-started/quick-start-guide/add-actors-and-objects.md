In Pocket Code kun je op verschillende manieren een personage of een object aan je project toevoegen:

**Tekenen**: Je kunt je eigen personage maken met **Pocket Paint**. Pocket Paint is een tekenprogramma ([meer over Pocket Paint](https://catrobat.org/pocket-paint/))

**Uiterlijken**: Kies er één uit een verzameling kant-en-klare figuren en objecten ([meer over de mediabibliotheek](../elements/medialibrary.md)).

**Galerij**: Je kunt een afbeelding uit de galerij van je smartphone kiezen.

**Bibliotheek**: In de bibliotheek vind je figuren en objecten die al geprogrammeerd zijn, dat wil zeggen dat ze al een script hebben. Je kunt ze kiezen als je kant-en-klare onderdelen voor je spel wilt gebruiken (bijvoorbeeld een aftelklok) ([meer over de bibliotheek](../elements/medialibrary.md#een-object-toevoegen-uit-de-mediabibliotheek)).

**Camera**: Je kunt de camera van je apparaat gebruiken om een foto te maken en die als personage toe te voegen.

**Rugzak**: De rugzak is nu leeg. Je kunt figuren of objecten hergebruiken die je in je rugzak hebt opgeslagen. Het hele script wordt daarbij ook uitgepakt ([meer over de rugzak](../elements/backpack.md)).

**Lokale figuren en objecten**: Hier vind je kant-en-klare personages die je in je project kunt gebruiken. Lokale figuren en objecten werken als een offline mediabibliotheek. Dat betekent dat je deze figuren ook zonder internetverbinding kunt gebruiken.

**Leeg object**: Voeg een leeg object toe. Dat is een object zonder uiterlijk. Je kunt dit object gewoon programmeren.

**Lokale projecten**: Kies een project waaruit je de eerste figuur samen met het script in je project wilt zetten.
