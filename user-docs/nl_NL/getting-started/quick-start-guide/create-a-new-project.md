Open de app op je smartphone of tablet. Tik op het plusteken om een nieuw project te maken.

![MainScreen_NewProject](../../../media/getting-started/MainScreen_NewProject.png)

Geef het project een naam (1) en kies of je je game in staand (verticaal) of liggend (horizontaal) formaat wilt maken (2). Bevestig daarna met het vinkje (3).

![NewProject](../../../media/getting-started/NewProject.png)

Je bent nu in je projectweergave. Bovenaan zie je de naam van je game.

Daaronder zie je de **achtergrond**. Die is nu nog leeg. Wil je hem veranderen, tik er dan op.

Onder de achtergrond zie je het gebied voor je **figuren en objecten** die je aan je game hebt toegevoegd. Dit gebied is nu nog leeg.

Rechtsonder zie je twee belangrijke knoppen:

![Start](../../../media/getting-started/Start.png) Met de **Afspeelknop** start je je game.

![Plusknop](../../../media/getting-started/Screenshot-2024-11-22-143219.png) Met de **Plusknop** voeg je een nieuw personage of object aan je game toe.

![Projectscherm](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
