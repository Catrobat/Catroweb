Wanneer je Pocket Code opent, zie je het volgende hoofdscherm.

![Hoofdscherm](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Wanneer je Pocket Code opent, zie je het volgende hoofdscherm.\
[Afbeelding openen](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Help](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Rechtsboven zie je een symbool.

Daarmee ga je naar de Catrobat-documentatie, met handige tips voor jou.

![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Daarnaast zie je het menu.

Daar ga je makkelijk naar de instellingen. Daar kun je de taal veranderen of extensies aanzetten, zoals de plotterblokken en meer.

![Bewerkpictogram](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Klik op het bewerkpictogram om naar het projectscherm te gaan.

Onderaan zie je je laatst bewerkte project. Daar kun je verder werken aan je project.

![Start je project](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Gebruik de afspeelknop om je project te starten.

![Projecten op apparaat](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Als je op Projecten op apparaat klikt, kom je bij je opgeslagen projecten.

![Catrobat-gemeenschap](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Wil je meer projecten van andere gebruikers bekijken en ermee werken?

Klik dan op de Catrobat-gemeenschap op Share. Daar vind je veel leuke projecten.

![Toevoegen](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Klik dan op het plusicoon.

Wil je een nieuw project maken?
