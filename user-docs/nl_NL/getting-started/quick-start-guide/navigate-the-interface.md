Wanneer je Pocket Code opent, zie je het volgende hoofdscherm.

![Hoofdscherm](../../../media/getting-started/MainScreen-e1732269599192.jpg)

Rechtsboven zie je een ![Help](../../../media/getting-started/Screenshot-2024-11-22-111748.png) symbool. Daarmee ga je naar de Catrobat-documentatie, met handige tips voor jou.

Daarnaast zie je het menu ![Menu](../../../media/getting-started/Screenshot-2024-11-22-111804.png). Daar ga je makkelijk naar de instellingen. Daar kun je de taal veranderen of extensies aanzetten, zoals de plotterblokken en meer.

Onderaan zie je je laatst bewerkte project. Klik op het bewerkpictogram ![Bewerkpictogram](../../../media/getting-started/Screenshot-2024-11-22-111825.png) om naar het projectscherm te gaan. Daar kun je verder werken aan je project.

Gebruik de afspeelknop ![Start je project](../../../media/getting-started/Screenshot-2024-11-22-111818.png) om je project te starten.

Als je op Projecten op apparaat klikt, kom je bij je opgeslagen projecten. ![Projecten op apparaat](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Wil je meer projecten van andere gebruikers bekijken en ermee werken? Klik dan op de Catrobat-gemeenschap op Share. Daar vind je veel leuke projecten. ![Catrobat-gemeenschap](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Wil je een nieuw project maken? Klik dan op het plusicoon. ![Toevoegen](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
