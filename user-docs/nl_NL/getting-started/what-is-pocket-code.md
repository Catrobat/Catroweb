Pocket Code is de belangrijkste app van Catrobat. Het is een gratis en open-source mobiele app waarmee je games, animaties en interactieve verhalen direct op je smartphone of tablet maakt. Met het **blokgebaseerde programmeersysteem** van Pocket Code zet je codeblokjes aan elkaar, net als puzzelstukjes. Je hebt geen programmeerervaring nodig. Dat maakt de app perfect voor beginners!

Pocket Code gaat verder dan alleen digitale projecten. Met nieuwe **makerspace-functies** kun je ook **SVG-bestanden voor snijplotters** ontwerpen. Zo maak je van je digitale creaties echte voorwerpen en ontdek je nieuwe creatieve mogelijkheden buiten het scherm.

Of je nu leert programmeren, nieuwe ideeën uitprobeert of programmeren onderwijst, Pocket Code biedt een speelse en toegankelijke manier om met programmeren aan de slag te gaan.

[Meer informatie](https://catrobat.org/pocket-code/)
