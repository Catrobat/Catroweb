In deze tutorial leer je alles wat je over Pocket Code moet weten om je eerste project te maken. We helpen je stap voor stap om de app te downloaden, te openen en een nieuw project te maken.

![Nieuw programma](../../../media/game-tutorials/New-Program.png)

Dit is de allereerste tutorial. Je hebt geen voorkennis nodig.

Dus wat wacht je nog? Pak je telefoon en begin nu!

*Hier kun je de tutorial als PDF downloaden:*

[Nieuw programma](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code installeren

Eerst moet je de Pocket Code-app op je apparaat installeren. Je vindt de app door “Pocket Code” te zoeken in de Google Play Store. Tik daarna op “Installeren”. Voor deze stap heb je een Google-account nodig. Je apparaat downloadt en installeert de app nu. Dat kan even duren, afhankelijk van je internetverbinding.

![Nieuw programma (2)](../../../media/game-tutorials/New-Program-2.png)

Nadat Pocket Code is gedownload en geïnstalleerd, vind je de app in de app-lade of op je startscherm, afhankelijk van je apparaat. Je kunt de app makkelijk naar elke plek verplaatsen die je wilt.

### 2. De app starten

Wanneer je de app opent, zie je verschillende categorieën:

![Nieuw programma (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Een nieuw project maken

De volgende stap is een nieuw project maken. Druk daarvoor op de gele plusknop rechtsonder. Nu moet je een projectnaam invoeren en kiezen of je project liggend moet zijn. Door op “OK” te tikken wordt het project gemaakt.

![Nieuw programma](../../../media/game-tutorials/New-Program.png)

### 4. Gelukt! Je hebt je eigen nieuwe project gemaakt.

Nu heb je Pocket Code geïnstalleerd en weet je hoe je een nieuw project maakt. Nu kun je beginnen met programmeren!

Om verder te gaan, moet je weten hoe je een nieuw object in een project maakt. Bekijk de tutorial **[Nieuw object](new-object.md)**. Daarin wordt alles stap voor stap uitgelegd.
