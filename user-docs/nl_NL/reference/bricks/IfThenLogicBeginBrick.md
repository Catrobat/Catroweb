*Controleert of een voorwaarde waar is. Als dat zo is, voert het een reeks instructies uit. Het is alsof je zegt: “Als dit waar is, doe dan dit.”*

![StartScene](../../../media/bricks/StartScene.png)

Wanneer de scène start, wordt de variabele X op 0 gezet.

![If](../../../media/bricks/If.png)

Als het dier nu wordt aangetikt, wordt de variabele X met 1 verhoogd.

Het programma controleert of de variabele X gelijk is aan de waarde 2.

Als dat zo is, wordt het geluid Tweet1 afgespeeld en wordt de variabele X op 0 gezet.
