Geeft een gemaakte kloon van een object instructies om de gewenste acties uit te voeren. Zo kan de kloon de functies van het origineel nabootsen, terwijl je de kloon los van het origineel bestuurt. Je kunt verschillende gedragingen of eigenschappen van de kloon instellen om aan specifieke eisen te voldoen.
