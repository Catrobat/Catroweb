![Maak_kloon_van_brick](../../../media/bricks/create_clone_of_brick2.png)

Dit blok maakt een kopie van het gekozen object. Die kopie heet een kloon en gedraagt zich net als het origineel. Stel je voor dat je een personage in je spel kopieert. De kloon kan eigen gedrag en eigen scripts hebben. Zo kun je meerdere exemplaren van een object maken die elk apart kunnen handelen.
