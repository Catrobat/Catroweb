Als je dit blok gebruikt, start het script meteen wanneer de scène begint. Een scène is het begin van je programma. Een scène is een nieuw beeld in je programma, waarin andere onderdelen getoond kunnen worden en verschillende dingen kunnen gebeuren. Je kunt veel scènes hebben voor verschillende fases van je programma. Bijvoorbeeld één scène voor de intro, één scène voor het hoofdmenu, één voor het eerste level, één voor het tweede level, enzovoort. Bij eenvoudige programma's is één scène genoeg. Dan is het begin van je programma ook het begin van de scène.

Net als elk script begint dit script met een gebeurtenisblok. De gebeurtenis bepaalt **wanneer** het script start, de blokken erna vertellen het programma **wat** het moet doen.
