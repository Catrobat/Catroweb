![voor-waarden-van-blok](../../../media/bricks/for-values-from-brick.png)

Dit blok voert een reeks instructies een vast aantal keer uit. Een teller begint bij de ene waarde en stopt bij de andere. Het is alsof je een herhaling maakt waarbij je precies weet hoe vaak die moet draaien.

Stel je voor dat je een lijst met items hebt en er iets mee wilt doen. Met dit blok loop je elk item één voor één langs, en doe je bij elk item hetzelfde.
