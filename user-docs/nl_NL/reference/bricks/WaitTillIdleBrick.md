![wacht-tot-alle-andere-scripts-gestopt-blok](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Dit blok pauzeert het huidige script totdat alle andere scripts in het project klaar zijn. Stel je voor dat je je script in de wacht zet tot alles anders klaar is. Dat is handig om zeker te zijn dat er geen andere acties meer lopen voordat je de volgende stappen in je huidige script uitvoert.
