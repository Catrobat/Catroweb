Start het script wanneer het object wordt aangetikt.

Het verschil met het blok *“Wanneer speelveld getikt”* is dat *“Wanneer erop getikt wordt”* alleen geldt voor het eigen figuur of object, terwijl *“Wanneer op het speelveld getikt wordt”* voor het hele scherm geldt.
