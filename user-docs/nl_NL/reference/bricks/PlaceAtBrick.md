![plaats_op_x_y_blok](../../../media/bricks/place_at_x_y_brick.png)

Verplaatst het object naar een bepaalde plek op het scherm, bepaald door de x- en y-coördinaten. Het is alsof je je personage naar precies die plek teleporteert.

De positie wordt ingesteld in een coördinatenstelsel, zoals een grafiek: de x-as en y-as lopen door het midden van het scherm. Dus x = 0 en y = 0 is het midden van het scherm.
