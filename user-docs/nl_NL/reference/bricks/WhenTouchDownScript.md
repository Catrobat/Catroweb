![Wanneer_op_het_speelveld_getikt_wordt_knop](../../../media/bricks/When_stage_is_tapped_btn.png)

Start het script wanneer het scherm wordt aangeraakt.

Het verschil met het blok *“Wanneer erop getikt wordt”* is dat *“Wanneer op het speelveld getikt wordt”* voor het hele scherm geldt, terwijl *“Wanneer erop getikt wordt”* alleen geldt voor een bepaald figuur of object.
