![Begin_met_plotten](../../../media/bricks/Start_to_plot.png)

Dit blok start het plotten terwijl het figuur beweegt. Het lijkt op een pen op papier zetten om een lijn te tekenen. Gebruik het blok “Stop met plotten” als je het tekenen even wilt pauzeren, het figuur naar een andere plek wilt verplaatsen en daarna met “Begin met plotten” weer wilt starten.
