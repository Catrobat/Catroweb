Dit blok schakelt over naar een andere scène in je project en start die scène helemaal opnieuw. Het is alsof je in een boek naar het volgende hoofdstuk gaat of in een spel naar het volgende level.

Stel je voor dat je project meerdere scènes heeft, en elke scène is een ander deel van je verhaal of spel. Met dit blok spring je naar een scène en start je die vanaf het begin. Zo ontstaat een vloeiende overgang tussen de verschillende delen van je project.
