![מקם במיקום x: y:](../../../media/bricks/place_at_x_y_brick.png)

מזיזה את האובייקט למיקום מסוים על המסך, לפי הקואורדינטות x ו־y. זה כמו להעביר את הדמות שלך בבת אחת למקום מדויק.

המיקום נקבע במערכת קואורדינטות כמו במישור הקרטזי: הצירים x ו־y עוברים דרך מרכז המסך, כך שהמיקום x = 0 ו־y = 0 הוא מרכז המסך.
