הלבנה הזו עוצרת את כל התסריטים וסוגרת את השלב או הסצנה הנוכחיים. זה כמו לומר: „החלק הזה של הפרויקט נגמר.” הכול נעצר, והפרויקט יכול לעבור לסצנה אחרת או להסתיים לגמרי. השתמש בה כשאתה רוצה לסיים שלב או רמה מסוימים בפרויקט.
