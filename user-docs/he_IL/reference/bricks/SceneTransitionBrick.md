![המשך סצנה](../../../media/bricks/continue_scene_brick2.png)

הלבנה הזו ממשיכה את הסצנה מהמקום שבו היא הושהתה. אם הסצנה נקטעה בגלל השהיה או המתנה, השימוש בלבנה הזו ימשיך את הפעולה בדיוק מהנקודה שבה עצרה.

תארו לעצמכם שהשהיתם משחק או אנימציה, ועכשיו אתם רוצים שהם ימשיכו לפעול. הלבנה הזו פועלת כמו כפתור „נגן”, וגורמת לכול להמשיך מהנקודה שבה הושהה.
