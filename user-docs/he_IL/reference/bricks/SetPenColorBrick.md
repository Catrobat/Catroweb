הלבנה הזו משנה את הצבע של העט שהדמות משתמשת בו. זה כמו לעבור לעט בצבע אחר בזמן הציור.

**אדום, ירוק, כחול (RGB)**: מודל הצבעים RGB משתמש בעוצמות שונות של אור אדום, ירוק וכחול כדי ליצור מגוון רחב של צבעים. לכל רכיב צבע (אדום, ירוק וכחול) יכול להיות ערך בין 0 ל־255:

- **אדום**: רכיב האדום של הצבע. ערך גבוה יותר פירושו יותר אדום.
- **ירוק**: רכיב הירוק של הצבע. ערך גבוה יותר פירושו יותר ירוק.
- **כחול**: רכיב הכחול של הצבע. ערך גבוה יותר פירושו יותר כחול.

בשילוב ערכים שונים של אדום, ירוק וכחול אפשר ליצור כל צבע. לדוגמה:

- `RGB(255, 0, 0)` הוא אדום טהור.
- `RGB(0, 255, 0)` הוא ירוק טהור.
- `RGB(0, 0, 255)` הוא כחול טהור.
- `RGB(255, 255, 255)` הוא לבן (אדום, ירוק וכחול במקסימום).
- `RGB(0, 0, 0)` הוא שחור (אין צבע).

ערבוב של הצבעים האלה בכמויות שונות יוצר את כל הצבעים שרואים במסכים דיגיטליים.
