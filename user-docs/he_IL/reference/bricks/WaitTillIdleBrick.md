הלבנה הזו משהה את התסריט הנוכחי עד שכל שאר התסריטים בפרויקט מסיימים לפעול. דמיינו ששמים את התסריט שלכם בהמתנה, עד שכל השאר מסתיים. זה שימושי כדי לוודא שלא קורות פעולות אחרות לפני שממשיכים לשלבים הבאים בתסריט הנוכחי.
