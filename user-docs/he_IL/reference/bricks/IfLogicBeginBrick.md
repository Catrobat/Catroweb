![אם מתקיים אז אחרת](../../../media/bricks/if_else_brick2.png)

*בודקת אם תנאי מתקיים. אם כן, מריצה קבוצה אחת של הוראות, ואם לא, מריצה קבוצה אחרת. זה כמו לתת שתי אפשרויות: „אם זה נכון, עשה את זה; אחרת, עשה את זה.”*

![התחלת הסצנה](../../../media/bricks/StartScene.png)

כשהסצנה מתחילה, המשתנה X מוגדר ל־0.

![אם־אחרת](../../../media/bricks/IfElse.png)

אם לוחצים על החיה, בודקים אם השארית של X חלקי 2 נכונה, כלומר אם X הוא מספר אי־זוגי.

אם זה המצב, מנגנים את הצליל Tweet1 ומגדילים את המשתנה X ב־1.

אחרת, אם X הוא זוגי, רק מגדילים את X ב־1.

ההוראות שצריך לבצע מופרדות על ידי „סוף אם”.
