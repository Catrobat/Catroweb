הלבנה הזו מתחילה את תהליך השרטוט כשהדמות זזה. זה דומה להנחת עט על הנייר כדי להתחיל לצייר קו. אפשר להשתמש בלבנה „עצור שרטוט” אם רוצים להשהות את הציור, להזיז את הדמות למקום אחר ואז להתחיל שוב לשרטט עם „התחל לשרטט”.
