![עצור לשרטוט](../../../media/bricks/Stop_to_plot.png)

הלבנה „עצור לשרטוט” משהה את תהליך השרטוט, ומאפשרת להזיז את הדמות למיקום חדש או לסיים את השרטוט. זה כמו להרים את העט מהנייר כדי למקם אותו מחדש או להפסיק לצייר. אחרי שסיימתם לשרטט, אפשר להשתמש בלבנה „שמור שרטוט ל־SVG” כדי לשמור את העיצוב שלכם כקובץ SVG.
