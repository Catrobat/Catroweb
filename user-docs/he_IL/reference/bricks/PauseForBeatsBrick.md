הלבנה הזו גורמת לתסריט לחכות מספר פעימות שקבעת לפני שהוא ממשיך. זה כמו הפסקה קצרה בשיר לפני הנגינה של התו או הצליל הבא. תארו לעצמכם שאתם עוצרים את ההופעה לרגע, סופרים את הפעימות ואז ממשיכים.
