כשפותחים את Pocket Code, רואים את המסך הראשי הבא.

![מסך ראשי](../../../media/getting-started/MainScreen-e1732269599192.jpg)

בפינה הימנית העליונה יש סמל ![עזרה](../../../media/getting-started/Screenshot-2024-11-22-111748.png) שמוביל אתכם לתיעוד של Catrobat, שבו יש טיפים מועילים בשבילכם.

לידו נמצא התפריט ![תפריט](../../../media/getting-started/Screenshot-2024-11-22-111804.png). משם אפשר להגיע בקלות להגדרות, שבהן אפשר לשנות את השפה או להפעיל הרחבות כמו בלוקי השרטוט ועוד.

מתחת לכך רואים את הפרויקט שערכתם לאחרונה. לחצו על סמל העריכה ![סמל עריכה](../../../media/getting-started/Screenshot-2024-11-22-111825.png) כדי להיכנס למסך הפרויקט, ולהמשיך לפתח את הפרויקט שלכם.

השתמשו בכפתור ההפעלה ![הפעלת הפרויקט שלכם](../../../media/getting-started/Screenshot-2024-11-22-111818.png) כדי להפעיל את הפרויקט שלכם.

לחיצה על „פרויקטים במכשיר” תפתח את הפרויקטים ששמרתם. ![פרויקטים במכשיר](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

אם תרצו להכיר ולעבוד על פרויקטים נוספים של משתמשים אחרים, פשוט לחצו על „קהילת Catrobat” ב־Share. שם תמצאו הרבה פרויקטים מעולים. ![קהילת Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

אם תרצו ליצור פרויקט חדש, לחצו על סמל הפלוס. ![הוספה](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
