כשפותחים את Pocket Code, רואים את המסך הראשי הבא.

![מסך ראשי](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
כשפותחים את Pocket Code, רואים את המסך הראשי הבא.\
[פתיחת תמונה](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![עזרה](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
בפינה הימנית העליונה יש סמל שמוביל אתכם לתיעוד של Catrobat, שבו יש טיפים מועילים בשבילכם.

![תפריט](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
לידו נמצא התפריט.

משם אפשר להגיע בקלות להגדרות, שבהן אפשר לשנות את השפה או להפעיל הרחבות כמו בלוקי השרטוט ועוד.

![סמל עריכה](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
לחצו על סמל העריכה כדי להיכנס למסך הפרויקט, ולהמשיך לפתח את הפרויקט שלכם.

מתחת לכך רואים את הפרויקט שערכתם לאחרונה.

![הפעלת הפרויקט שלכם](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
השתמשו בכפתור ההפעלה כדי להפעיל את הפרויקט שלכם.

![פרויקטים במכשיר](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
לחיצה על „פרויקטים במכשיר” תפתח את הפרויקטים ששמרתם.

![קהילת Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
אם תרצו להכיר ולעבוד על פרויקטים נוספים של משתמשים אחרים, פשוט לחצו על „קהילת Catrobat” ב־Share.

שם תמצאו הרבה פרויקטים מעולים.

![הוספה](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
אם תרצו ליצור פרויקט חדש, לחצו על סמל הפלוס.
