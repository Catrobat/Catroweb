הקישו על כפתור הפלוס כדי להוסיף דמות או אובייקט חדשים לפרויקט שלכם.

![הוספת דמות](../../../media/getting-started/FigurHinzufuegen.png)

ב־Pocket Code אפשר להוסיף דמות או אובייקט לפרויקט שלכם בכמה דרכים:

**ציור**: אפשר ליצור דמות משלכם עם **Pocket Paint**. Pocket Paint היא תוכנת ציור ([מידע נוסף על Pocket Paint](https://catrobat.org/pocket-paint/))

**מראות**: בחרו אחת מתוך אוסף של דמויות ואובייקטים מוכנים ([מידע נוסף על הספרייה למדיה](../elements/medialibrary.md)).

**גלריה**: אפשר לבחור תמונה מהגלריה בסמארטפון שלכם.

**ספרייה**: בספרייה תמצאו דמויות ואובייקטים שכבר תוכנתו, כלומר יש להם כבר תסריט. אפשר לבחור אותם אם אתם רוצים להשתמש באלמנטים מוכנים במשחק שלכם (למשל ספירה לאחור) ([מידע נוסף על הספרייה](../elements/medialibrary.md#הוספת-אובייקט-מהספרייה-למדיה)).

**מצלמה**: אפשר להשתמש במצלמה של המכשיר כדי לצלם תמונה ולהוסיף אותה כדמות.

**תרמיל**: התרמיל ריק כרגע. אפשר להשתמש מחדש בדמויות או באובייקטים ששמרתם בתרמיל. התסריט כולו יוצא מהתרמיל יחד איתם ([מידע נוסף על התרמיל](../elements/backpack.md)).

**דמויות ואובייקטים מקומיים**: כאן תמצאו דמויות מוכנות שאפשר להשתמש בהן בפרויקט שלכם. דמויות ואובייקטים מקומיים פועלים כמו ספרייה למדיה במצב לא מקוון, כלומר גם בלי חיבור לאינטרנט אפשר לגשת אליהם.

**אובייקט ריק**: הוספת אובייקט ריק, כלומר אובייקט שאין לו מראה. אפשר לתכנת את האובייקט הזה כרגיל.

**פרויקטים מקומיים**: בחרו פרויקט שממנו תרצו להכניס את הדמות הראשונה יחד עם התסריט שלה לפרויקט שלכם.
