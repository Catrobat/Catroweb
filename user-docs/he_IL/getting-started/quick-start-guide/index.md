Pocket Code היא אפליקציית תכנות ויזואלי שמאפשרת ליצור משחקים, אנימציות וסיפורים אינטראקטיביים ישירות בסמארטפון או בטאבלט. בעזרת ממשק גרירה ושחרור פשוט עם „לבנים” (בלוקים של קוד), אפשר לתכנן את הפרויקטים שלכם בלי ניסיון קודם בתכנות. אפשר בקלות להוסיף צלילים, תמונות ותנועה, ולהביא את הרעיונות שלכם לחיים.

המדריך הזה יעזור לכם להתחיל, ויסביר איך:

- לנווט בממשק,
- ליצור את הפרויקט הראשון שלכם,
- לעבוד עם דמויות ורקעים,
- להשתמש בלבנים כדי לתכנת פעולות, ו
- לשמור את הפרויקט שלכם.

Pocket Code מתאימה במיוחד למתחילים ולמורים, והיא מעודדת יצירתיות, פתרון בעיות וחשיבה לוגית.
