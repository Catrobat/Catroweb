Pocket Code היא האפליקציה המרכזית של Catrobat, אפליקציה ניידת חינמית וקוד פתוח שמאפשרת ליצור משחקים, אנימציות וסיפורים אינטראקטיביים ישירות בסמארטפון או בטאבלט. בעזרת **מערכת התכנות בלבנים** של Pocket Code, אפשר לבנות פרויקטים על ידי חיבור בלוקים של קוד, כמו הרכבה של חלקי פאזל. אין צורך בניסיון בתכנות, וזה מושלם למתחילים!

Pocket Code הולכת מעבר לפרויקטים דיגיטליים בלבד. עם **תכונות של מעבדת יצירה** חדשות, אפשר גם לעצב **קובצי SVG למכונות חיתוך לשרטוט**. זה אומר שאפשר להפוך את היצירות הדיגיטליות שלכם לדברים ממשיים, ולחקור אפשרויות יצירה שמעבר למסך.

בין אם אתם לומדים לתכנת, מנסים רעיונות חדשים או מלמדים תכנות, Pocket Code מציעה דרך משחקית ונגישה להיכנס לעולם התכנות.
