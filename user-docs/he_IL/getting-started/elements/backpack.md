**התרמיל** ב־Pocket Code היא פונקציה מעשית שמאפשרת **לשמור ולהשתמש מחדש** באלמנטים כמו דמויות (אובייקטים), תסריטים, מראות או צלילים, **בין פרויקטים**. היא עוזרת לחסוך זמן ולהפוך את הפרויקטים שלכם ליעילים יותר.

התרמיל דומה לאחסון דיגיטלי שבו אפשר לשמור אלמנטים שונים מהפרויקט הנוכחי. אחרי ששמרתם אותם בתרמיל, אפשר לשלוף אותם ולהכניס אותם לפרויקטים אחרים.

### איך משתמשים בתרמיל עבור דמויות (אובייקטים)?

**הכנסת דמויות לתרמיל**

היכנסו לתצוגת הפרויקט של הפרויקט שממנו אתם רוצים להכניס דמות לתרמיל.

הדמות (כולל המראות, הצלילים והתסריטים שלה) תוכנס לתרמיל.

![הכנסת דמות לתרמיל](../../../media/getting-started/grafik-7.png)\
הקישו על שלוש הנקודות ליד הדמות כדי לפתוח את התפריט ההקשרי, ובחרו „הכנסה לתרמיל”.\
[פתיחת תמונה](../../../media/getting-started/grafik-7.png)

**הוספת דמויות מהתרמיל**

פתחו את הפרויקט שבו אתם רוצים להכניס את הדמות.

בתצוגת הפרויקט, הקישו על סימן הפלוס ובחרו „תרמיל”.

עכשיו תראו את כל הדמויות והאובייקטים ששמרתם בתרמיל.

![הוצאת דמות מהתרמיל](../../../media/getting-started/grafik-8-e1732702791199.png)\
הקישו על שלוש הנקודות ובחרו „הוצאה מהתרמיל”.\
[פתיחת תמונה](../../../media/getting-started/grafik-8-e1732702791199.png)

### איך משתמשים בתרמיל עבור תסריטים?

**הכנסת תסריטים לתרמיל:**

היכנסו לדמות שמכילה את התסריט. לחצו לחיצה ממושכת על התסריט הרצוי בעורך התסריטים.

![הוספה לתרמיל](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)\
בחרו „הוספה לתרמיל” מהתפריט ההקשרי.\
[פתיחת תמונה](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

![שמירת דמות בתרמיל](../../../media/getting-started/grafik-9.png)\
תנו לתסריט שם, ואשרו עם OK.\
[פתיחת תמונה](../../../media/getting-started/grafik-9.png)

![התרמיל שלכם](../../../media/getting-started/grafik-10.png)\
התסריט נשמר, ואפשר להשתמש בו בפרויקטים אחרים.\
[פתיחת תמונה](../../../media/getting-started/grafik-10.png)

**הוספת תסריטים מהתרמיל:**

הקישו על הדמות שאליה תרצו להכניס את התסריט. תראו את אזור התסריטים.

![הוצאת תסריט](../../../media/getting-started/grafik-11.png)\
הקישו על שלוש הנקודות כדי לפתוח את התפריט ההקשרי, והקישו על „תרמיל”.\
[פתיחת תמונה](../../../media/getting-started/grafik-11.png)

עכשיו תראו את כל התסריטים שכבר נמצאים בתרמיל שלכם.

מהתפריט ההקשרי אפשר גם למחוק תסריטים שכבר אינכם צריכים בתרמיל.

![תסריטים בתרמיל](../../../media/getting-started/grafik-12.png)\
הקישו על שלוש הנקודות ליד התסריט הרצוי, ובחרו „הוצאה מהתרמיל” בתפריט ההקשרי.\
[פתיחת תמונה](../../../media/getting-started/grafik-12.png)

### היתרונות של התרמיל

- **שימוש חוזר בין פרויקטים:** דמויות, תסריטים, צלילים ומראות אפשר ליצור פעם אחת ולהשתמש בהם שוב ושוב, כמה שצריך.
- **חיסכון בזמן:** אין צורך ליצור דמויות או תסריטים מחדש בכל פעם.
- **עקביות:** האלמנטים נשארים עקביים כשאתם צריכים אותם במספר פרויקטים.
