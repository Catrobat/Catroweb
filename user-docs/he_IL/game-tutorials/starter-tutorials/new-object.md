במדריך הזה תלמדו איך ליצור דמות חדשה בפרויקט שלכם, ואילו אפשרויות יש לכם לכך.

![דמות חדשה](../../../media/game-tutorials/New-Object.png)\
במדריך הזה תלמדו איך ליצור דמות חדשה בפרויקט שלכם, ואילו אפשרויות יש לכם לכך.\
[פתיחת תמונה](../../../media/game-tutorials/New-Object.png)

כדי לעשות את זה, צריך כבר להוריד את האפליקציה Pocket Code ולדעת ליצור פרויקט חדש. אם צריכים עזרה בנושא, אתם מוזמנים להציץ במדריך **[פרויקט חדש](new-project.md)**.

*כאן אפשר להוריד את המדריך בפורמט PDF:*

[פתיחת PDF](../../../media/game-tutorials/New-Object.pdf)

### 1. יצירת דמות חדשה

קודם כול צריך לפתוח את הפרויקט החדש שלכם.

תמצאו אותו במסך הבית של האפליקציה Pocket Code. אם יש לכם יותר מפרויקט אחד, אפשר ללחוץ על „פרויקטים במכשיר”. אחר כך בחרו את הפרויקט החדש שלכם. אם עוד לא יצרתם פרויקט חדש, או שאתם צריכים מידע נוסף על איך עושים את זה, כדאי להציץ במדריך **[פרויקט חדש](new-project.md)**.

### 2. יצירת דמות חדשה

עכשיו אתם מוכנים ליצור דמות חדשה. תראו חלון חדש שבו יש לכם שבע אפשרויות לבחירה.

![דמות חדשה (1)](../../../media/game-tutorials/New-Object-1.png)\
לשם כך הקישו פשוט על כפתור הפלוס הצהוב בפינה הימנית התחתונה.\
[פתיחת תמונה](../../../media/game-tutorials/New-Object-1.png)

### 3. דרכים ליצירה

![דמות חדשה (2)](../../../media/game-tutorials/New-Object-2.png)\
אלה האפשרויות שתוכלו לבחור מתוכן.\
[פתיחת תמונה](../../../media/game-tutorials/New-Object-2.png)

### 4. ציור תמונה

כדי להקל על ההתחלה, נשתמש באפשרות „ציור תמונה” ונצייר פשוט נקודה. כשציירתם את הנקודה ב־Pocket Paint, אפשר לצאת ממנה (על ידי חזרה צעד אחד אחורה).

### 5. נתינת שם

עכשיו צריך לתת לתמונה שלכם שם.

### 6. מיקום

אחר כך צריך למקם אותה בצורה חזותית, על ידי הזזה ימינה ושמאלה או למעלה ולמטה עם האצבע.

![דמות חדשה (3)](../../../media/game-tutorials/New-Object-3.png)\
צריך לשמור אותה בכפתור שבפינה הימנית העליונה.\
[פתיחת תמונה](../../../media/game-tutorials/New-Object-3.png)

### 7. הצלחתם! יצרתם את הדמות הראשונה שלכם.

עכשיו יש לכם פרויקט עם אובייקט שאפשר לתכנת!

כדי לעשות את זה, כדאי לדעת אילו לבנים זמינות. המדריך **[הלבנים הראשונות](first-bricks.md)** נותן סקירה טובה של הקטגוריות השונות של הלבנים. עם זאת, אפשר גם להתחיל ישר עם הפרויקט הראשון שלכם. בחרו מדריך מתאים מסדרת המתחילים.
