במדריך הזה תלמדו כל מה שצריך לדעת על Pocket Code כדי להתחיל ליצור את הפרויקט הראשון שלכם. ננחה אתכם צעד אחר צעד איך מורידים את האפליקציה, פותחים אותה ויוצרים פרויקט חדש.

![פרויקט חדש](../../../media/game-tutorials/New-Program.png)

זה המדריך הראשון, ואין צורך בידע קודם.

אז על מה אתם מחכים? קחו את הטלפון והתחילו עכשיו!

*כאן אפשר להוריד את המדריך בפורמט PDF:*

[פרויקט חדש](../../../media/game-tutorials/New-Program.pdf)

### 1. התקנת Pocket Code

קודם כול צריך להתקין את האפליקציה Pocket Code במכשיר שלכם. אפשר למצוא את האפליקציה בחיפוש „Pocket Code” ב־Google Play Store, ולהוריד אותה בלחיצה על „התקנה”. לשלב הזה נדרש חשבון Google. עכשיו המכשיר יוריד ויתקין את האפליקציה. השלב הזה עשוי לקחת זמן, בהתאם למהירות החיבור לאינטרנט.

![פרויקט חדש (2)](../../../media/game-tutorials/New-Program-2.png)

אחרי שהורדתם והתקנתם את Pocket Code בהצלחה, תמצאו את האפליקציה במגירת האפליקציות או במסך הבית, בהתאם למכשיר שלכם. אפשר בקלות להעביר את האפליקציה לכל מקום שתרצו.

### 2. פתיחת האפליקציה

כשפותחים את האפליקציה, רואים קטגוריות שונות:

![פרויקט חדש (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. יצירת פרויקט חדש

הצעד הבא הוא ליצור פרויקט חדש. לשם כך, הקישו על כפתור הפלוס הצהוב בפינה הימנית התחתונה. עכשיו צריך להזין שם לפרויקט ולבחור אם הפרויקט יהיה לרוחב או לא. בלחיצה על „OK” הפרויקט נוצר.

![פרויקט חדש](../../../media/game-tutorials/New-Program.png)

### 4. הצלחתם! יצרתם את הפרויקט הראשון שלכם.

עכשיו התקנתם את Pocket Code, ואתם יודעים איך ליצור פרויקט חדש. עכשיו אפשר להתחיל לתכנת!

כדי לעשות את זה, צריך לדעת איך ליצור דמות חדשה בפרויקט. כדאי להציץ במדריך **[דמות חדשה](new-object.md)**, שבו הכול מוסבר לכם צעד אחר צעד.
