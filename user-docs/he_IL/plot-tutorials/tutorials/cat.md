כשהשרטוט מתחיל, כל תנועה מצוירת כאילו בעזרת עט. אלה הקווים שהמכונה תחתוך לאורכם אחר כך.

הדמות שלנו פונה לכיוון 150 מעלות.

במדריך הזה, קודם מכינים את הצד הימני של ראש החתול. אם מסתכלים מקרוב, בהתחלה העקומה חדה, ולכן הדמות צריכה להסתובב יותר אחרי כל קו קטן. אחר כך הפניות נעשות קטנות יותר בחלק התחתון של הראש. הצד השמאלי של הראש שוב מעוקל בחדות. לכן החלק הזה של הראש משתמש בשלוש לולאות בסך הכול.

אחרי זה מגיע האוזן השמאלית. היא מורכבת רק מקווים ישרים, ולכן אפשר להשתמש בלבנה „זוז __ צעדים”.

החלק שבין האוזניים הוא שוב קשת, ומתוכנת בעזרת לולאה נוספת.

אחר כך מכינים את האוזן הימנית.

השרטוט מוכן עכשיו. מסיימים אותו בלבנה „עצור לשרטוט”, ושומרים אותו בטלפון בעזרת „שמור שרטוט כ־SVG ___”.

עכשיו אפשר לשלוח את קובץ ה־SVG למכונת חיתוך (לשרטוט).
