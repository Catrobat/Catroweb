במדריך הזה תלמדו איך לשמור ולשתף את העיצובים המוגמרים שלכם בטלפון.

לזה צריך עיצוב רקמה מוגמר שאתם רוצים לייצא. אם עוד אין לכם כזה, אתם מוזמנים להיות בהשראה מ[מדריכי הרקמה](index.md) שלנו!

*כאן אפשר להוריד את המדריך בפורמט PDF*:

[ייצוא עיצובים](../../../media/embroidery-tutorials/Export-Designs.pdf)

### 1. פתחו את הפרויקט שלכם והמתינו עד שהוא יתפרש לגמרי. אחרת הדפוס יהיה חסר.

### 2. חזרו אחורה והקישו על כפתור השיתוף.

![ייצוא עיצובים (1)](../../../media/embroidery-tutorials/Export-Designs-1.png)

### 3. שתפו את קובץ הרקמה שלכם במייל, או שמרו אותו בטלפון.

![ייצוא עיצובים (2)](../../../media/embroidery-tutorials/Export-Designs-2.png)

פונקציית השיתוף עשויה להיראות קצת אחרת בכל טלפון.

עיצוב הרקמה שלכם יישמר כקובץ DST.

מכונת הרקמה מכירה את פורמט הקובץ הזה, ותשלים את העיצוב שלכם על הבד.
