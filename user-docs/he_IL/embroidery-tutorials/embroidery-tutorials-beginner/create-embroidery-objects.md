במדריך הזה תלמדו איך ליצור דמויות שבעזרתן תוכלו לרקום את הדפוסים שלכם בהמשך.

למדריך הזה כדאי כבר לדעת איך יוצרים פרויקט. עיינו במדריכים מסדרת [המתחילים](../../game-tutorials/starter-tutorials/index.md), אם אתם צריכים עזרה.

לעוד מידע או להצעות לעיצובים, אתם מוזמנים להציץ במדריכים האחרים.

*כאן אפשר להוריד את המדריך בפורמט PDF*:

[יצירת דמויות רקמה](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. הקישו על כפתור הפלוס שבפינה הימנית התחתונה של הפרויקט כדי להוסיף דמות חדשה.

![יצירת דמויות רקמה](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. כדי לבחור תמונה, עברו לספריית המדיה.

![יצירת דמויות רקמה (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. דמות רקמה מייצגת שכבה אחת של המחט במכונת הרקמה. כמה דמויות רקמה ייתפרו אחת אחרי השנייה. כך אפשר להשתמש בכמה צבעים.

בחרו את הדמות לפי הצבע שאתם רוצים.

גללו למטה ומצאו את החץ המתאים.

![יצירת דמויות רקמה (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. תנו לדמות החדשה שם מתאים, ולחצו על OK.

![יצירת דמויות רקמה (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. עכשיו יצרתם דמות חדשה. אפשר להוסיף לה תסריט ולתכנת אותה.

![יצירת דמויות רקמה (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

עכשיו אתם יודעים איך ליצור דמות. הוסיפו דמות חדשה לכל צבע שתרצו להשתמש בו.

אפשר להוסיף תסריט בכל צבע ולתכנת עיצובים משלכם, ואפילו לרקום אותם בהמשך.

צריכים השראה או עזרה? הציצו במדריכים האחרים שלנו!
