במדריך הזה תלמדו איך לרקום כוכב בתפר זיגזג (58.2 x 61.2 מ״מ).

![תמונה (4)](../../../media/embroidery-tutorials/image-4.png)

כדאי כבר לדעת איך ליצור דמות חדשה ולהכניס לה לבנים. אתם מוזמנים להציץ במדריכים מסדרת [המתחילים](../../game-tutorials/starter-tutorials/index.md) אם עדיין צריכים עזרה. בנוסף, בלוקי הרקמה חייבים להיות מופעלים כבר. אפשר לגלות איך עושים את זה במדריך **[הפעלת בלוקי הרקמה](activate-embroidery-bricks.md)**.

לעוד מידע או להצעות לעיצובים, כדאי להציץ במדריכים האחרים.

*כאן אפשר להוריד את המדריך בפורמט PDF*:

[כוכב זיגזג](../../../media/embroidery-tutorials/Star-ZigZag.pdf)

### 1. צרו דמות רקמה חדשה (ראו [יצירת דמויות רקמה](create-embroidery-objects.md)).

### 2. עכשיו התחילו והכניסו את הלבנים אחת אחרי השנייה לתסריט שלכם.

![כוכב זיגזג](../../../media/embroidery-tutorials/Star-ZigZag.png)

### 3. הקישו על ההפעלה כדי להתחיל את העיצוב שלכם!
