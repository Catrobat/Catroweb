במדריך הזה יוסבר איך מפעילים את בלוקי הרקמה.

![הפעלת בלוקי הרקמה 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

לזה לא צריך שום ידע בתכנות. זה הצעד הראשון כדי להתחיל במדריכי הרקמה. בהמשך תוכלו לעצב, לתכנת ואפילו לרקום את העיצובים שלכם על חלק הטקסטיל האהוב עליכם.

לעוד מידע או להצעות לעיצובים, כדאי להציץ במדריכים האחרים.

*כאן אפשר להוריד את המדריך בפורמט PDF*:

[הפעלת בלוקי הרקמה](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. פתחו את האפליקציה „Pocket Code”. עקבו אחרי ההקשות!

### 2. פתחו את התפריט (הנקודות שבפינה הימנית העליונה).

![הפעלת בלוקי הרקמה](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. עברו ל„הגדרות”.

![הפעלת בלוקי הרקמה 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. בחרו „הרחבת רקמה”.

![הפעלת בלוקי הרקמה 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. תמצאו את בלוקי הרקמה כקטגוריה משלהם בתוך הלבנים שלכם!

[![הפעלת בלוקי הרקמה 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

עכשיו תמצאו את כל בלוקי הרקמה גם בין שאר הלבנים.

לעוד מידע על כל בלוק, אפשר להציץ בתיעוד של הלבנים [כאן](../../../reference/), או לעקוב אחרי מדריך **[בלוקי הרקמה](embroidery-bricks/index.md)**.

עכשיו אפשר להתחיל וליצור את העיצובים שלכם!

אם אתם צריכים רעיונות או עזרה, כדאי להציץ במדריכים האחרים, או להמשיך למדריך **[יצירת דמויות רקמה](create-embroidery-objects.md)**.
