תפר משולש תופר כל תפר שלוש פעמים.

התפר המשולש חוזר אחורה אחרי התפר הראשון, תופר, ואז קופץ קדימה שוב ותופר שוב.

![התחל תפר משולש באורך 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

פועל בדיוק כמו [התפר הרץ](running-stitch.md).

![תפר משולש](../../../../media/embroidery-tutorials/TripleStitch.png)

זה גורם לקו התפר להחזיק מעמד זמן רב יותר.
