Pocket Code, Catrobat’ın ana uygulamasıdır. Ücretsiz ve açık kaynaklı bu mobil uygulamayla akıllı telefonunda veya tabletinde oyunlar, animasyonlar ve etkileşimli hikâyeler yapabilirsin. Pocket Code’un **blok tabanlı kodlama sistemi** ile kod bloklarını birbirine takarak projeler kurarsın. Bu, bir yapbozun parçalarını birleştirmek gibidir. Programlama deneyimi gerekmez, bu yüzden yeni başlayanlar için çok uygundur!

Pocket Code sadece dijital projelerle kalmaz. Yeni **makerspace özellikleri** ile **kesim plotterları için SVG dosyaları** da tasarlayabilirsin. Böylece dijital eserlerini gerçek eşyalara dönüştürebilir ve ekranın ötesindeki yaratıcı fikirleri keşfedebilirsin.

İster kodlamayı öğreniyor, ister yeni fikirler deniyor, ister programlama öğretiyor ol: Pocket Code kodlamaya dalmak için eğlenceli ve kolay bir yol sunar

[Daha fazla bilgi](https://catrobat.org/pocket-code/)
