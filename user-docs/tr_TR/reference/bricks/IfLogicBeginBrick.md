![Eğer-değilse bloğu](../../../media/bricks/if_else_brick2.png)

*Bir koşulun doğru olup olmadığını kontrol eder. Doğruysa bir grup komutu, değilse başka bir grup komutu çalıştırır. İki seçenek vermek gibidir: “Bu doğruysa bunu yap, değilse şunu yap.”*

![Bölüm başladığında](../../../media/bricks/StartScene.png)

Bölüm başladığında X değişkeni 0 yapılır.

![Eğer-değilse](../../../media/bricks/IfElse.png)

Şimdi hayvana dokunulursa, X modülo 2 doğru mu diye kontrol edilir. Yani X tek sayı mı diye bakılır.

Öyleyse Tweet1 sesi çalınır ve X değişkeni 1 artırılır.

Değilse, yani X çift sayıysa, sadece X 1 artırılır.

Çalıştırılacak komutlar bir “Eğer sonu” ile ayrılır.
