![تنظیم رنگ قلم روی قرمز ۰ سبز ۰ آبی ۲۵۵](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

این بلوک رنگ قلمی را که بازیگر استفاده می‌کند تغییر می‌دهد. مثل این است که وسط نقاشی به یک قلم با رنگ دیگر عوض کنی.

**قرمز، سبز، آبی (RGB)**: مدل رنگ RGB از شدت‌های مختلف نور قرمز، سبز و آبی برای ساختن طیف گسترده‌ای از رنگ‌ها استفاده می‌کند. هر مؤلفه‌ی رنگ (قرمز، سبز و آبی) می‌تواند مقداری بین ۰ و ۲۵۵ داشته باشد:

- **قرمز**: مؤلفه‌ی قرمز رنگ. مقدار بالاتر یعنی قرمز بیشتر.
- **سبز**: مؤلفه‌ی سبز رنگ. مقدار بالاتر یعنی سبز بیشتر.
- **آبی**: مؤلفه‌ی آبی رنگ. مقدار بالاتر یعنی آبی بیشتر.

با ترکیب مقدارهای مختلف قرمز، سبز و آبی می‌توانی هر رنگی بسازی. برای مثال:

- `RGB(255, 0, 0)` قرمز خالص است.
- `RGB(0, 255, 0)` سبز خالص است.
- `RGB(0, 0, 255)` آبی خالص است.
- `RGB(255, 255, 255)` سفید است (بیشترین قرمز، سبز و آبی).
- `RGB(0, 0, 0)` سیاه است (بدون رنگ).

ترکیب این رنگ‌ها با مقدارهای متفاوت، همه‌ی رنگ‌هایی را می‌سازد که روی صفحه‌های دیجیتال می‌بینی.
