![بلوک یادداشت](../../../media/bricks/note_brick2.png)

یک توضیح یا یادداشت در اسکریپتت اضافه می‌کند تا یادت بماند هر بخش از کد چه کاری انجام می‌دهد. روی اجرای پروژه تأثیری ندارد. مثل این است که یک یادداشت چسبی برای خودت بگذاری.
