![بلوک اگر](../../../media/bricks/if_brick2.png)

*یک شرط را بررسی می‌کند و اگر درست باشد، یک مجموعه دستور را اجرا می‌کند. مثل این است که بگویی: «اگر این درست است، آنگاه این کار را انجام بده.»*

![شروع سکانس](../../../media/bricks/StartScene.png)

وقتی سکانس شروع می‌شود، متغیر X برابر ۰ می‌شود.

![اگر](../../../media/bricks/If.png)

اگر حالا روی حیوان ضربه زده شود، متغیر X یک واحد زیاد می‌شود.

برنامه بررسی می‌کند که آیا متغیر X برابر با عدد ۲ است یا نه.

اگر این‌طور باشد، صدای Tweet1 پخش می‌شود و متغیر X صفر می‌شود.
