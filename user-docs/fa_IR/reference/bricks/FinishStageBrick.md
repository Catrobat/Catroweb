![بلوک پایان صحنه](../../../media/bricks/finish-stage-brick.png)

این بلوک همه‌ی اسکریپت‌ها را متوقف می‌کند و صحنه یا سکانس فعلی را تمام می‌کند. مثل این است که بگویی: «این بخش از پروژه تمام شد.» همه چیز متوقف می‌شود و پروژه می‌تواند به سکانس دیگری برود یا کاملاً تمام شود. وقتی می‌خواهی یک صحنه یا مرحله‌ی مشخص از پروژه را تمام کنی از این بلوک استفاده کن.
