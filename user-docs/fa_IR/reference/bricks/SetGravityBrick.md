![بلوک تنظیم گرانش](../../../media/bricks/set-gravity-brick.png)

گرانش اعمال‌شده روی همه‌ی شیءهای پروژه را تنظیم می‌کند. مثل این است که تغییر دهی چقدر قوی همه چیز به پایین یا کنار کشیده شوند و این روی این‌که چطور می‌افتند یا حرکت می‌کنند اثر دارد.
