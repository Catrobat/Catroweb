![حذف این کلون](../../../media/bricks/delete_clone_brick2.png)

این بلوک کلونی را حذف می‌کند که با بلوک «ساختن کلون از» ساخته شده است. مثل این است که بگویی: «این نسخه‌ی تکراری را پاک کن.» از آن برای مدیریت و کنترل تعداد کلون‌ها در پروژه استفاده کن تا وقتی لازم نیستند حذف شوند.
