![بلوک اگر-وگرنه](../../../media/bricks/if_else_brick2.png)

*یک شرط را بررسی می‌کند. اگر شرط درست باشد، یک مجموعه دستور را اجرا می‌کند و اگر درست نباشد، مجموعه‌ی دیگری را. مثل این است که دو گزینه بدهی: «اگر این درست است، این کار را بکن؛ وگرنه آن کار را بکن.»*

![شروع سکانس](../../../media/bricks/StartScene.png)

وقتی سکانس شروع می‌شود، متغیر X برابر ۰ می‌شود.

![اگر-وگرنه](../../../media/bricks/IfElse.png)

اگر حالا روی حیوان ضربه زده شود، بررسی می‌شود که آیا باقی‌مانده‌ی X تقسیم بر ۲ درست است، یعنی آیا X عدد فرد است.

اگر این‌طور باشد، صدای Tweet1 پخش می‌شود و متغیر X یک واحد زیاد می‌شود.

وگرنه، اگر X عدد زوج باشد، فقط X یک واحد زیاد می‌شود.

دستورهایی که باید اجرا شوند با «پایان اگر» از هم جدا می‌شوند.
