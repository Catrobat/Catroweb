در این آموزش یاد می‌گیری چطور یک رنگین‌کمان را گلدوزی کنی (۱۱۲ × ۵۷٫۲ میلی‌متر).

![رنگین‌کمان](../../../media/embroidery-tutorials/Regenbogen.webp)

باید از قبل بدانی حلقه چیست و چطور کار می‌کند.

آموزش **[نیم‌دایره](../embroidery-tutorials-beginner/semicircle.md)** ممکن است برای این آموزش کمک‌کننده باشد.

اگر هنوز چیزی گلدوزی نکرده‌ای، آموزش‌های سری [مبتدی](../embroidery-tutorials-beginner/index.md) را ببین.

برای اطلاعات بیشتر یا ایده‌های طراحی، آموزش‌های دیگر را ببین.

*اگر بخواهی آموزش را به شکل PDF دانلود کنی*:

[رنگین‌کمان](../../../media/embroidery-tutorials/Rainbow.pdf)

### ۱. یک شیء گلدوزی جدید بساز (ببین [ساخت شیء گلدوزی](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![رنگین‌کمان](../../../media/embroidery-tutorials/Rainbow.png)

### ۲. اسکریپت زیر را اضافه کن:

![رنگین‌کمان (۱)](../../../media/embroidery-tutorials/Rainbow-1.png)

### ۳. کپی کردن شیء

برای کمان بزرگ‌تر بعدی، می‌توانی همان شیئی را که الان ساختی کپی کنی.

روی سه نقطه‌ی گوشه‌ی بالا سمت راست در نمای شیءها ضربه بزن.

بعد به «کپی» برو و شیء را انتخاب کن.

![رنگین‌کمان (۶)](../../../media/embroidery-tutorials/Regenbogen-6.png)

اگر برای هر کمان یک شیء جدا استفاده کنی، بعداً می‌توانی هر کدام را با رنگ متفاوتی گلدوزی کنی.

### ۴. تنظیم شیء

برای اینکه کمان‌ها حالا اندازه‌های متفاوتی داشته باشند، باید چند مقدار را تغییر بدهیم.

برای این کار، به اسکریپت شیء کپی‌شده برو و مقدارهای زیر را تنظیم کن:

![رنگین‌کمان (۲)](../../../media/embroidery-tutorials/Rainbow-2.png)

### ۵. قدم ۳ و ۴ را برای کمان‌های بیشتر تکرار کن!

### ۶. روی اجرا ضربه بزن تا طرحت شروع شود!
