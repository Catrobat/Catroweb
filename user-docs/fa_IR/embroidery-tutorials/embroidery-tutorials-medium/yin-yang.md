![یین و یانگ](../../../media/embroidery-tutorials/Yin-und-Yang.png)

باید از قبل بدانی حلقه چیست و چطور کار می‌کند.

آموزش **[دایره](../embroidery-tutorials-beginner/circle.md)** ممکن است برای این آموزش کمک‌کننده باشد.

اگر هنوز چیزی گلدوزی نکرده‌ای، آموزش‌های سری [مبتدی](../embroidery-tutorials-beginner/index.md) را ببین.

برای اطلاعات بیشتر یا ایده‌های طراحی، آموزش‌های دیگر را ببین.
