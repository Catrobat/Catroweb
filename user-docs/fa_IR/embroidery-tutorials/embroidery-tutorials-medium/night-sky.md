در این آموزش یاد می‌گیری چطور یک آسمان شب را گلدوزی کنی (۴۸٫۵ × ۹۶٫۱ میلی‌متر).

![آسمان شب](../../../media/embroidery-tutorials/Nachthimmel.png)

باید از قبل بدانی حلقه چیست و چطور کار می‌کند.

آموزش **[ستاره](../embroidery-tutorials-beginner/star.md)** ممکن است برای این آموزش کمک‌کننده باشد.

اگر از قبل با تابع پخش پیام آشنا باشی هم کمک می‌کند.

اگر هنوز چیزی گلدوزی نکرده‌ای، آموزش‌های سری [مبتدی](../embroidery-tutorials-beginner/index.md) را ببین.

برای اطلاعات بیشتر یا ایده‌های طراحی، آموزش‌های دیگر را ببین.
