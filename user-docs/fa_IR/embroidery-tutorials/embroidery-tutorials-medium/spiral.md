در این آموزش یاد می‌گیری چطور یک مارپیچ را گلدوزی کنی (۱۰۳٫۹ × ۱۱۶٫۶ میلی‌متر).

![تصویر (۱۴)](../../../media/embroidery-tutorials/image-14.png)

باید از قبل بدانی حلقه چیست و چطور کار می‌کند.

آموزش **[دایره](../embroidery-tutorials-beginner/circle.md)** ممکن است برای این آموزش کمک‌کننده باشد.

اگر هنوز چیزی گلدوزی نکرده‌ای، آموزش‌های سری [مبتدی](../embroidery-tutorials-beginner/index.md) را ببین.

برای اطلاعات بیشتر یا ایده‌های طراحی، آموزش‌های دیگر را ببین.

*اگر بخواهی آموزش را به شکل PDF دانلود کنی*:

[مارپیچ](../../../media/embroidery-tutorials/Spiral.pdf)

### ۱. یک شیء گلدوزی جدید بساز (ببین [ساخت شیء گلدوزی](../embroidery-tutorials-beginner/create-embroidery-objects.md)) و اسکریپت زیر را اضافه کن:

![مارپیچ](../../../media/embroidery-tutorials/Spiral.png)

### ۲. روی اجرا ضربه بزن تا طرحت شروع شود!

روی «جدید» ضربه بزن تا یک متغیر جدید بسازی.

![تصویر (۱۵)](../../../media/embroidery-tutorials/image-15.png)

متغیر «درجه» را در بخش داده‌ها پیدا می‌کنی.
