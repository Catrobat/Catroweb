در این آموزش یاد می‌گیری چطور شیء بسازی که بعداً بتوانی با آن الگوهایت را گلدوزی کنی.

برای این آموزش باید از قبل بدانی چطور یک پروژه بسازی. اگر کمک لازم داری، آموزش‌های سری **[اولیه](../../game-tutorials/starter-tutorials/index.md)** را ببین.

برای اطلاعات بیشتر یا ایده‌های طراحی، آموزش‌های دیگر را ببین.

*اگر بخواهی آموزش را به شکل PDF دانلود کنی*:

[ساخت شیء گلدوزی](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### ۱. روی دکمه‌ی + در پایین سمت راست پروژه‌ات ضربه بزن تا یک شیء جدید اضافه کنی.

![ساخت شیء گلدوزی](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### ۲. برای انتخاب یک تصویر، به کتابخانه‌ی رسانه برو.

![ساخت شیء گلدوزی (۱)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### ۳. یک شیء گلدوزی نشان‌دهنده‌ی یک سطح از سوزن دستگاه گلدوزی است. چند شیء گلدوزی پشت سر هم گلدوزی می‌شوند. به همین خاطر می‌توانی از چند رنگ استفاده کنی.

شیء را بر اساس رنگی که می‌خواهی انتخاب کن.

به پایین اسکرول کن و فلش مناسب را پیدا کن.

![ساخت شیء گلدوزی (۵)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### ۴. یک نام مناسب به شیء جدیدت بده و روی OK ضربه بزن.

![ساخت شیء گلدوزی (۳)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### ۵. حالا یک شیء جدید ساخته‌ای. می‌توانی یک اسکریپت اضافه کنی و شیء را برنامه‌نویسی کنی.

![ساخت شیء گلدوزی (۴)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

حالا می‌دانی چطور یک شیء بسازی. برای هر رنگی که می‌خواهی استفاده کنی، یک شیء جدید اضافه کن.

می‌توانی برای هر رنگ یک اسکریپت اضافه کنی و طرح‌های خودت را برنامه‌نویسی کنی و بعداً حتی گلدوزی‌شان کنی.

به الهام یا کمک نیاز داری؟ آموزش‌های دیگر ما را ببین!
