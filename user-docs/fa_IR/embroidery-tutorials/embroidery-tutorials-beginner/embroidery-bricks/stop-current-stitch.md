به کوک فعلی می‌گوید متوقف شود.

این بلوک را لازم داری اگر بعد از شروع یک کوک ساده، زیگزاگ یا سه‌تایی بخواهی موقعیت سوزن را عوض کنی.

![کوک فعلی را متوقف کن](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

وگرنه یک درز میانی ناخواسته ساخته می‌شود.
