Pocket Code برنامه‌ی اصلی Catrobat است، یک برنامه‌ی موبایلی رایگان و متن‌باز که به تو اجازه می‌دهد بازی، انیمیشن و داستان تعاملی را همان‌جا روی گوشی یا تبلتت بسازی. با **سیستم کدنویسی بلوکی** Pocket Code، بلوک‌های کد را کنار هم می‌گذاری، درست مثل تکه‌های یک پازل. برای این کار نیازی به تجربه‌ی برنامه‌نویسی نیست و برای تازه‌کارها عالی است!

Pocket Code فقط به پروژه‌های دیجیتالی محدود نمی‌ماند. با امکانات جدید **فضای ساخت‌وساز**، می‌توانی **فایل SVG برای دستگاه‌های برش** هم طراحی کنی. یعنی می‌توانی ساخته‌های دیجیتالی‌ات را به چیزهای واقعی تبدیل کنی و فراتر از صفحه‌ی گوشی ایده‌های خلاقانه‌ات را امتحان کنی.

چه داری کدنویسی یاد می‌گیری، چه ایده‌های تازه را امتحان می‌کنی، چه داری برنامه‌نویسی درس می‌دهی، Pocket Code راهی بازیگوش و ساده برای ورود به دنیای کدنویسی است.
