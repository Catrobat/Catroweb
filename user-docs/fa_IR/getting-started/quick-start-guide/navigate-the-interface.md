وقتی Pocket Code را باز می‌کنی، این صفحه‌ی اصلی را می‌بینی.

![صفحه‌ی اصلی](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
وقتی Pocket Code را باز می‌کنی، این صفحه‌ی اصلی را می‌بینی.\
[تصویر را باز کن](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![راهنما](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
در گوشه‌ی بالا سمت راست نماد هست که تو را به مستندات Catrobat می‌برد.

آن‌جا نکته‌های مفید زیادی پیدا می‌کنی.

![منو](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
کنار آن، منو است.

از آن‌جا به راحتی به تنظیمات می‌روی؛ می‌توانی زبان را عوض کنی یا افزونه‌هایی مثل بلوک‌های نقشه و موارد دیگر را روشن کنی.

![نماد ویرایش](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
روی نماد ویرایش ضربه بزن تا به صفحه‌ی پروژه بروی و کارت را ادامه بدهی.

زیر این‌ها آخرین پروژه‌ای را می‌بینی که ویرایش کرده‌ای.

![شروع پروژه‌ات](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
با دکمه‌ی اجرا پروژه‌ات را شروع کن.

![پروژه‌های روی دستگاه](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
با ضربه زدن روی «پروژه‌های روی دستگاه» به پروژه‌های ذخیره‌شده‌ات دسترسی پیدا می‌کنی.

![جامعه‌ی Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
اگر می‌خواهی پروژه‌های دیگر کاربران را ببینی و روی آن‌ها کار کنی، در بخش اشتراک‌گذاری روی «جامعه‌ی Catrobat» ضربه بزن.

آن‌جا پروژه‌های خوب زیادی پیدا می‌کنی.

![افزودن](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
اگر می‌خواهی یک پروژه‌ی جدید بسازی، روی نماد مثبت ضربه بزن.
