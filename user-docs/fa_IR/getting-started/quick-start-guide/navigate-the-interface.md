وقتی Pocket Code را باز می‌کنی، این صفحه‌ی اصلی را می‌بینی.

![صفحه‌ی اصلی](../../../media/getting-started/MainScreen-e1732269599192.jpg)

در گوشه‌ی بالا سمت راست نماد ![راهنما](../../../media/getting-started/Screenshot-2024-11-22-111748.png) هست که تو را به مستندات Catrobat می‌برد. آن‌جا نکته‌های مفید زیادی پیدا می‌کنی.

کنار آن، منو ![منو](../../../media/getting-started/Screenshot-2024-11-22-111804.png) است. از آن‌جا به راحتی به تنظیمات می‌روی؛ می‌توانی زبان را عوض کنی یا افزونه‌هایی مثل بلوک‌های نقشه و موارد دیگر را روشن کنی.

زیر این‌ها آخرین پروژه‌ای را می‌بینی که ویرایش کرده‌ای. روی نماد ویرایش ![نماد ویرایش](../../../media/getting-started/Screenshot-2024-11-22-111825.png) ضربه بزن تا به صفحه‌ی پروژه بروی و کارت را ادامه بدهی.

با دکمه‌ی اجرا ![شروع پروژه‌ات](../../../media/getting-started/Screenshot-2024-11-22-111818.png) پروژه‌ات را شروع کن.

با ضربه زدن روی «پروژه‌های روی دستگاه» به پروژه‌های ذخیره‌شده‌ات دسترسی پیدا می‌کنی. ![پروژه‌های روی دستگاه](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

اگر می‌خواهی پروژه‌های دیگر کاربران را ببینی و روی آن‌ها کار کنی، در بخش اشتراک‌گذاری روی «جامعه‌ی Catrobat» ضربه بزن. آن‌جا پروژه‌های خوب زیادی پیدا می‌کنی. ![جامعه‌ی Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

اگر می‌خواهی یک پروژه‌ی جدید بسازی، روی نماد مثبت ضربه بزن. ![افزودن](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
