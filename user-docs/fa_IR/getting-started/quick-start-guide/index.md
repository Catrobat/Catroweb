Pocket Code یک برنامه‌ی برنامه‌نویسی تصویری است که به تو اجازه می‌دهد بازی، انیمیشن و داستان تعاملی را مستقیم روی گوشی یا تبلتت بسازی. با یک رابط ساده‌ی کشیدن و رها کردن و با «بلوک‌ها» (بلوک‌های کد)، می‌توانی پروژه‌هایت را بدون تجربه‌ی قبلی برنامه‌نویسی طراحی کنی. به‌راحتی صدا، تصویر و حرکت اضافه کن تا ایده‌هایت جان بگیرند.

این راهنما به تو کمک می‌کند با این کارها شروع کنی:

- کار کردن با رابط کاربری،
- ساختن اولین پروژه‌ات،
- کار با اشیا و پس‌زمینه‌ها،
- استفاده از بلوک‌ها برای برنامه‌ریزی کارها، و
- ذخیره‌ی پروژه‌ات.

Pocket Code برای تازه‌کارها و معلم‌ها مناسب است و خلاقیت، حل مسئله و تفکر منطقی را تشویق می‌کند.
