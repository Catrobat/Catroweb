در این آموزش یاد می‌گیری چطور یک شیء جدید در پروژه‌ات بسازی و چه راه‌های مختلفی برای این کار داری.

![شیء جدید](../../../media/game-tutorials/New-Object.png)

برای این کار باید از قبل برنامه‌ی Pocket Code را دانلود کرده باشی و بدانی چطور یک پروژه‌ی جدید بسازی. اگر کمک لازم داری، آموزش **[پروژه‌ی جدید](new-project.md)** را ببین.

*اگر بخواهی آموزش را به شکل PDF دانلود کنی، این‌جاست:*

[شیء جدید](../../../media/game-tutorials/New-Object.pdf)

### ۱. یک شیء جدید بساز

اول باید پروژه‌ی جدیدت را باز کنی.

آن را در صفحه‌ی اصلی برنامه‌ی Pocket Code پیدا می‌کنی. اگر بیشتر از یک پروژه داری، می‌توانی روی «پروژه‌های روی دستگاه» ضربه بزنی. بعد پروژه‌ی جدیدت را انتخاب کن. اگر هنوز پروژه‌ای نساخته‌ای یا برای ساختنش به توضیح بیشتری نیاز داری، آموزش **[پروژه‌ی جدید](new-project.md)** را ببین.

### ۲. یک شیء جدید بساز

حالا آماده‌ی ساختن یک شیء جدید هستی. برای این کار روی دکمه‌ی زرد + در گوشه‌ی پایین سمت راست ضربه بزن. یک پنجره‌ی جدید باز می‌شود که هفت راه برای انتخاب به تو می‌دهد.

![شیء جدید (۱)](../../../media/game-tutorials/New-Object-1.png)

### ۳. راه‌های ساختن

این‌ها راه‌هایی هستند که می‌توانی انتخاب کنی:

![شیء جدید (۲)](../../../media/game-tutorials/New-Object-2.png)

### ۴. تصویر بکش

برای اینکه شروع کار ساده باشد، می‌خواهیم از گزینه‌ی «تصویر بکش» استفاده کنیم و فقط یک نقطه بکشیم. وقتی نقطه را با Pocket Paint کشیدی، می‌توانی از آن خارج شوی (با یک قدم به عقب برگردی).

### ۵. یک نام بده

حالا باید به تصویرت یک نام بدهی.

### ۶. آن را قرار بده

بعد باید آن را با انگشتت به چپ و راست یا بالا و پایین ببری و روی صفحه قرار بدهی. با دکمه‌ی گوشه‌ی بالا سمت راست آن را ذخیره کن.

![شیء جدید (۳)](../../../media/game-tutorials/New-Object-3.png)

### ۷. تمام شد! شیء خودت را ساختی.

حالا پروژه‌ای داری که یک شیء دارد و می‌توانی آن را برنامه‌نویسی کنی!

برای این کار باید بدانی چه بلوک‌هایی در دسترس هستند. آموزش **[بلوک‌های اول](first-bricks.md)** یک نمای کلی خوب از دسته‌های مختلف بلوک‌ها به تو می‌دهد. اما می‌توانی مستقیم هم با اولین پروژه‌ات شروع کنی. یکی از آموزش‌های مناسب از مجموعه‌ی مبتدی را انتخاب کن.
