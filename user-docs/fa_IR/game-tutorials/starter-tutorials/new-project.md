در این آموزش هر چیزی را که برای شروع ساختن اولین پروژه‌ات با Pocket Code لازم داری یاد می‌گیری. قدم‌به‌قدم به تو نشان می‌دهیم که چطور برنامه را دانلود کنی، بازش کنی و یک پروژه‌ی جدید بسازی.

![برنامه‌ی جدید](../../../media/game-tutorials/New-Program.png)

این اولین آموزش است و لازم نیست از قبل چیزی بدانی.

پس منتظر چی هستی؟ گوشی‌ات را بردار و همین حالا شروع کن!

*اگر بخواهی آموزش را به شکل PDF دانلود کنی، این‌جاست:*

[برنامه‌ی جدید](../../../media/game-tutorials/New-Program.pdf)

### ۱. نصب Pocket Code

اول باید برنامه‌ی Pocket Code را روی دستگاهت نصب کنی. می‌توانی با جستجوی «Pocket Code» در Google Play Store برنامه را پیدا کنی و با زدن «نصب» دانلودش کنی. برای این قدم یک حساب Google لازم است. حالا دستگاهت برنامه را دانلود و نصب می‌کند. این کار بسته به سرعت اینترنتت ممکن است کمی طول بکشد.

![برنامه‌ی جدید (۲)](../../../media/game-tutorials/New-Program-2.png)

بعد از دانلود و نصب موفق Pocket Code، برنامه را در فهرست برنامه‌ها یا صفحه‌ی اصلی گوشی پیدا می‌کنی؛ بسته به دستگاهت فرق دارد. می‌توانی برنامه را بگیری و هر جا که دوست داری بگذاری.

### ۲. برنامه را باز کن

وقتی برنامه را باز می‌کنی، دسته‌های مختلف را می‌بینی:

![برنامه‌ی جدید (۱)](../../../media/game-tutorials/New-Program-1.png)

### ۳. یک پروژه‌ی جدید بساز

قدم بعدی این است که واقعاً یک پروژه‌ی جدید بسازی. برای این کار روی دکمه‌ی زرد + در گوشه‌ی پایین سمت راست ضربه بزن. حالا باید یک نام برای پروژه وارد کنی و انتخاب کنی که پروژه افقی باشد یا نه. با زدن «OK» پروژه ساخته می‌شود.

![برنامه‌ی جدید](../../../media/game-tutorials/New-Program.png)

### ۴. تمام شد! پروژه‌ی خودت را ساختی.

حالا Pocket Code را نصب کرده‌ای و می‌دانی چطور یک پروژه‌ی جدید بسازی. حالا می‌توانی شروع به برنامه‌نویسی کنی!

برای این کار باید بدانی چطور یک شیء جدید در پروژه بسازی. آموزش **[شیء جدید](new-object.md)** را ببین که همه‌چیز را قدم‌به‌قدم توضیح می‌دهد.
