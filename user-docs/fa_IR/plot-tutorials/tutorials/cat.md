وقتی طرح شروع می‌شود، هر حرکت انگار با قلم کشیده می‌شود. این‌ها خطوطی هستند که بعداً دستگاه پلاتر روی آن‌ها برش می‌زند.

شیء ما رو به جهت ۱۵۰ درجه است.

در این آموزش، ابتدا سمت راست سر گربه ساخته می‌شود. اگر دقت کنی، منحنی در ابتدا خیلی تند است، پس شیء بعد از هر خط کوچک باید بیشتر بچرخد. بعد برای قسمت پایین سر، چرخش‌ها کوچک‌تر می‌شوند. سمت چپ سر دوباره منحنی تندی دارد. به همین دلیل این قسمت از سر، روی هم سه حلقه دارد.

بعد گوش چپ می‌آید. این گوش فقط از خطوط صاف ساخته شده، پس می‌توانیم از بلوک «__ قدم حرکت کن» استفاده کنیم.

بخش بین دو گوش دوباره یک قوس است و با یک حلقه‌ی دیگر برنامه‌نویسی می‌شود.

بعد گوش راست ساخته می‌شود.

حالا طرح تمام شده است. با بلوک «رسم با پلاتر را متوقف کن» آن را تمام کن و با «طرح را به‌صورت SVG ذخیره کن با نام __» روی گوشی‌ات ذخیره کن.

حالا می‌توانی فایل SVG را برای یک دستگاه پلاتر (برش) بفرستی.
