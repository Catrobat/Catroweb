Când pornește plotarea, fiecare mișcare este desenată ca și cum ai desena cu un creion. Acestea sunt liniile pe care le va tăia plotterul mai târziu.

Obiectul nostru se orientează în direcția de 150 de grade.

În acest tutorial, se desenează mai întâi partea dreaptă a capului pisicii. Dacă te uiți atent, curba este puternică la început, deci obiectul trebuie să se rotească mai mult după fiecare linie mică. Apoi, rotirile devin mai mici pentru partea de jos a capului. Partea stângă a capului este din nou foarte curbată. De aceea, această parte a capului folosește în total trei bucle.

Urmează urechea stângă. Este făcută doar din linii drepte, așa că putem folosi blocul „Mergi __ pași”.

Partea dintre urechi este din nou un arc și se programează cu o altă buclă.

Apoi se face urechea dreaptă.

Desenul este acum gata. Încheie-l cu blocul „Oprește plotarea” și salvează-l pe telefon cu „Salvează desenul plotterului ca SVG”.

Acum poți trimite fișierul SVG unui plotter (de tăiere).
