Când pornește plotarea, fiecare mișcare este desenată ca și cum ai desena cu un creion. Acestea sunt liniile pe care le va tăia plotterul mai târziu.

Această vulpe este făcută doar din linii drepte („Mergi ___ pași”) și rotiri.

**Sfat**: Testează-ți programul în timp ce îl construiești.
