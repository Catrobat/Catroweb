În acest tutorial vei învăța tot ce trebuie să știi despre Pocket Code ca să începi să creezi primul tău proiect. Te vom ghida pas cu pas: cum descarci aplicația, cum o deschizi și cum creezi un proiect nou.

![Program nou](../../../media/game-tutorials/New-Program.png)

Acesta este primul tutorial și nu ai nevoie de nicio cunoștință dinainte.

Deci, ce mai aștepți? Ia telefonul și începe chiar acum!

*Aici poți descărca tutorialul în format PDF:*

[Program nou](../../../media/game-tutorials/New-Program.pdf)

### 1. Instalarea Pocket Code

Mai întâi, trebuie să instalezi aplicația Pocket Code pe dispozitivul tău. Poți găsi aplicația căutând „Pocket Code” în Google Play Store și o poți descărca apăsând pe „Instalează”. Pentru acest pas este necesar un cont Google. Acum dispozitivul tău va descărca și instala aplicația. Acest pas poate dura un pic, în funcție de conexiunea ta la internet.

![Program nou (2)](../../../media/game-tutorials/New-Program-2.png)

După ce descarci și instalezi cu succes Pocket Code, găsești aplicația în sertarul de aplicații sau pe ecranul principal, în funcție de dispozitivul tău. Poți muta aplicația cu ușurință oriunde vrei.

### 2. Pornește aplicația

Când deschizi aplicația, vezi diferite categorii:

![Program nou (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Creează un proiect nou

Pasul următor este să creezi efectiv un proiect nou. Pentru asta, poți apăsa pe butonul galben cu plus din colțul din dreapta jos. Acum trebuie să introduci un nume pentru proiect și să alegi dacă proiectul tău va fi orizontal sau nu. Apăsând „OK”, proiectul este creat.

![Program nou](../../../media/game-tutorials/New-Program.png)

### 4. Ai reușit! Ai creat propriul tău proiect nou.

Acum ai instalat Pocket Code și știi cum să creezi un proiect nou. Acum poți începe să programezi!

Ca să faci asta, trebuie să știi cum să creezi un obiect nou într-un proiect. Uită-te la tutorialul **[Obiect nou](new-object.md)**, unde totul este explicat pas cu pas.
