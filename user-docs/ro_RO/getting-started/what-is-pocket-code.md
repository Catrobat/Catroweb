Pocket Code este aplicația principală a Catrobat, o aplicație mobilă gratuită și open-source care îți permite să creezi jocuri, animații și povești interactive direct pe smartphone sau tabletă. Folosind sistemul de programare **bazat pe blocuri** al Pocket Code, poți construi proiecte unind blocuri de cod – ca și cum ai pune cap la cap piesele unui puzzle. Nu este nevoie de experiență în programare, ceea ce îl face perfect pentru începători!

Pocket Code merge dincolo de simplele proiecte digitale. Cu noile **funcții pentru makerspace**, poți crea și fișiere **SVG pentru plottere de tăiere**. Asta înseamnă că îți poți transforma creațiile digitale în obiecte reale și poți explora posibilități creative care depășesc ecranul.

Fie că înveți să programezi, că experimentezi idei noi sau că predai programarea, Pocket Code îți oferă un mod jucăuș și accesibil de a intra în lumea programării.

[Mai multe informații](https://catrobat.org/pocket-code/)
