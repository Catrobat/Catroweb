Deschide aplicația pe smartphone sau tabletă. Apasă pe simbolul + ca să creezi un proiect nou.

![MainScreen_NewProject](../../../media/getting-started/MainScreen_NewProject.png)

Dă proiectului un nume (1) și decide dacă vrei să creezi un joc în format portret (vertical) sau peisaj (orizontal) (2). Apoi confirmă cu bifa (3).

![NewProject](../../../media/getting-started/NewProject.png)

Acum ești în vizualizarea proiectului tău. În partea de sus vezi numele jocului tău.

Mai jos vezi **fundalul** – momentan, fundalul este gol. Dacă vrei să îl schimbi, apasă pe el.

Sub fundal vezi zona pentru **personajele și obiectele** pe care le-ai adăugat în joc. Momentan, zona este încă goală.

În colțul din dreapta jos vezi două butoane importante:

![Start](../../../media/getting-started/Start.png) Cu butonul **Play** pornești jocul tău.

![Buton plus](../../../media/getting-started/Screenshot-2024-11-22-143219.png) Cu butonul **Plus** adaugi un personaj/obiect nou în jocul tău.
