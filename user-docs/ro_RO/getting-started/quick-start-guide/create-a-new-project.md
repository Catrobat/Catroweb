Deschide aplicația pe smartphone sau tabletă.

![MainScreen_NewProject](../../../media/getting-started/MainScreen_NewProject.png)\
Apasă pe simbolul + ca să creezi un proiect nou.\
[Deschide imaginea](../../../media/getting-started/MainScreen_NewProject.png)

Dă proiectului un nume (1) și decide dacă vrei să creezi un joc în format portret (vertical) sau peisaj (orizontal) (2).

![NewProject](../../../media/getting-started/NewProject.png)\
Apoi confirmă cu bifa (3).\
[Deschide imaginea](../../../media/getting-started/NewProject.png)

Acum ești în vizualizarea proiectului tău. În partea de sus vezi numele jocului tău.

Mai jos vezi **fundalul** – momentan, fundalul este gol. Dacă vrei să îl schimbi, apasă pe el.

Sub fundal vezi zona pentru **personajele și obiectele** pe care le-ai adăugat în joc. Momentan, zona este încă goală.

În colțul din dreapta jos vezi două butoane importante:

![Start](../../../media/getting-started/Start.png)\
Cu butonul **Play** pornești jocul tău.

![Buton plus](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Cu butonul **Plus** adaugi un personaj/obiect nou în jocul tău.

![Ecranul proiectului](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)\
Acum ești în vizualizarea proiectului tău.\
[Deschide imaginea](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
