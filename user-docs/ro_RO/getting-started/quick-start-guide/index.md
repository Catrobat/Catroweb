Pocket Code este o aplicație de programare vizuală care îți permite să creezi jocuri, animații și povești interactive direct pe smartphone sau tabletă. Folosind o interfață intuitivă de trage-și-plasează, cu „blocuri” (blocuri de cod), îți poți crea proiectele fără experiență anterioară în programare. Poți adăuga ușor sunete, imagini și mișcare ca să îți dai viață ideilor.

Acest ghid te va ajuta să începi, explicându-ți cum să:

- Navighezi prin interfață,
- Creezi primul tău proiect,
- Lucrezi cu obiecte și fundaluri,
- Folosești blocuri ca să programezi acțiuni și
- Îți salvezi proiectul.

Perfect pentru începători și profesori, Pocket Code încurajează creativitatea, rezolvarea de probleme și gândirea logică.
