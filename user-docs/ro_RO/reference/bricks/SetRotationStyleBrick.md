![Setează stilul de rotire](../../../media/bricks/set_rotation_style_brick2.png)

Schimbă felul în care se rotește obiectul (în toate direcțiile, doar stânga-dreapta sau fără rotire). Este ca și cum ai decide dacă personajul tău se poate întoarce complet, doar se poate răsuci stânga-dreapta sau nu se poate roti deloc.
