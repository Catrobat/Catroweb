![Pentru fiecare valoare din lista](../../../media/bricks/for-each-value_brick.png)

Acest bloc rulează un set de instrucțiuni pentru fiecare element dintr-o listă sau dintr-un interval. Este ca și cum ai parcurge fiecare element pe rând și ai face același lucru cu fiecare.

Imaginează-ți că ai o listă de numere, culori sau alte elemente. Acest bloc îți permite să iei fiecare element din listă și să faci ceva cu el. De exemplu, dacă ai o listă de culori și vrei să schimbi culoarea fundalului pentru fiecare culoare din listă, vei folosi acest bloc.

Este ca și cum ai spune: „Pentru fiecare element din acest grup, fă aceste instrucțiuni.”
