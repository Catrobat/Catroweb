![Pornește plotarea](../../../media/bricks/Start_to_plot.png)

Acest bloc pornește procesul de plotare pe măsură ce personajul se mișcă. Este asemănător cu a pune un creion pe hârtie ca să începi să desenezi o linie. Poți folosi blocul „Oprește plotarea” dacă vrei să pui desenul pe pauză, să muți personajul într-un alt loc și apoi să pornești din nou plotarea cu „Pornește plotarea”.
