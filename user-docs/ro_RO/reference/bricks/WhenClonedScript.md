![Când pornești ca o clonă](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Dă unei clone create dintr-un obiect instrucțiuni ca să facă acțiunile dorite. Acest proces permite replicarea funcționalității obiectului original, controlând clona independent. Pot fi stabilite diverse comportamente sau proprietăți ale clonei, pentru a răspunde unor cerințe specifice.
