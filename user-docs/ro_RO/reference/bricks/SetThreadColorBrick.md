![Setează culoarea aței la „#ff0000”](../../../media/bricks/Set_thread_color_to_ff0000.png)

Folosind acest bloc, poți schimba culoarea aței pentru proiectul tău de broderie. Culoarea se afișează în program. Asta nu înseamnă că mașina de broderie va folosi exact aceleași culori.
