Stabilește o reacție sau o acțiune care are loc când obiectul ricoșează de o anumită suprafață sau de un alt obiect. Este ca și cum ai spune: „Fă această acțiune ori de câte ori personajul meu ricoșează de un perete sau de alt obiect.”
