Acest bloc oprește scriptul curent până când toate celelalte scripturi din proiect termină de rulat. Imaginează-ți că pui scriptul tău în așteptare până se termină toate celelalte lucruri. Este util ca să te asiguri că nu se mai întâmplă alte acțiuni înainte de pașii următori din scriptul curent.
