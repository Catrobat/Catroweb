![Setează culoarea particulelor la „#ff0000”](../../../media/bricks/Set_particle_colour_to_ff0000.png)

Acest bloc schimbă culoarea particulelor emise de personaj. Este ca și cum ai schimba culoarea confetti dintr-un tun de petrecere.

Un cod de culoare hexazecimal este o modalitate de a reprezenta culorile folosind valori hexazecimale. Este format din șase caractere, care pot fi cifre (0-9) sau litere (A-F). Codul se scrie de obicei cu „#” la început, astfel: `#RRGGBB`.

- Primele două caractere (`RR`) reprezintă componenta roșie a culorii.
- Următoarele două caractere (`GG`) reprezintă componenta verde.
- Ultimele două caractere (`BB`) reprezintă componenta albastră.

Fiecare pereche de caractere poate avea valori de la `00` (care înseamnă că nu există deloc din acea culoare) până la `FF` (care înseamnă cantitatea maximă din acea culoare). De exemplu:

`#000000` este negru (lipsă de culoare).

`#FF0000` este roșu pur.

`#00FF00` este verde pur.

`#0000FF` este albastru pur.

`#FFFFFF` este alb (roșu, verde și albastru la maximum).
