![Închide zona de joc](../../../media/bricks/finish-stage-brick.png)

Acest bloc oprește toate scripturile și încheie zona de joc sau scena curentă. Este ca și cum ai spune: „Această parte a proiectului s-a terminat.” Totul se oprește, iar proiectul poate trece la altă scenă sau se poate termina complet. Folosește-l când vrei să încheii o anumită etapă sau un anumit nivel din proiect.
