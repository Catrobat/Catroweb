![Când pornește scena](../../../media/bricks/When_scene_starts_btn2.png)

Dacă folosești acest bloc, scriptul pornește imediat ce începe scena. O scenă este începutul programului tău. Este o nouă vizualizare a programului în care pot fi afișate alte elemente și pot avea loc diferite interacțiuni. Poți avea multe scene pentru diferite etape ale programului. De exemplu, o scenă pentru introducere, o scenă pentru meniul principal, una pentru primul nivel, una pentru al doilea nivel și așa mai departe. La programele mai simple, poate fi suficientă o singură scenă, iar începutul programului este și începutul scenei.

Ca orice script, acesta începe cu un bloc de eveniment: evenimentul stabilește **când** începe scriptul, iar blocurile de după el spun programului **ce** să facă.
