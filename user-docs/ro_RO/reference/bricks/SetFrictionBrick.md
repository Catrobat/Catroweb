![Setează frecarea la](../../../media/bricks/set_friction_to_brick2.png)

Reglează cantitatea de frecare aplicată obiectului, care influențează cât de ușor alunecă sau încetinește. Este ca și cum ai schimba cât de alunecos este suprafața pe care stă personajul tău: cu cât frecarea este mai mare, cu atât alunecă mai puțin.
