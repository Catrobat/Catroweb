![Pentru valori de la](../../../media/bricks/for-values-from-brick.png)

Acest bloc rulează un set de instrucțiuni de un anumit număr de ori, folosind un contor care pornește de la o valoare și se termină la alta. Este ca și cum ai face o buclă în care știi exact de câte ori vrei să se repete.

Imaginează-ți că ai o listă de elemente și vrei să faci ceva cu fiecare. Acest bloc te lasă să parcurgi fiecare element pe rând și să faci același lucru cu fiecare.
