![Plasează la x: y:](../../../media/bricks/place_at_x_y_brick.png)

Mută obiectul într-o poziție anume de pe ecran, definită prin coordonatele x și y. Este ca și cum ai teleporta personajul tău într-un loc exact.

Poziția se stabilește într-un sistem de coordonate, ca în planul cartezian: axele x și y trec prin centrul ecranului, deci x = 0 și y = 0 este mijlocul ecranului.
