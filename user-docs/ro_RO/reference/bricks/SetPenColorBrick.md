![Setează culoarea creionului la roșu 0, verde 0, albastru 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Acest bloc schimbă culoarea creionului folosit de personaj. Este ca și cum ai schimba la un creion de altă culoare în timp ce desenezi.

**Roșu, verde, albastru (RGB)**: Modelul de culoare RGB folosește intensități diferite de lumină roșie, verde și albastră ca să creeze un spectru larg de culori. Fiecare componentă de culoare (roșu, verde și albastru) poate avea o valoare între 0 și 255:

- **Roșu**: componenta roșie a culorii. O valoare mai mare înseamnă mai mult roșu.
- **Verde**: componenta verde a culorii. O valoare mai mare înseamnă mai mult verde.
- **Albastru**: componenta albastră a culorii. O valoare mai mare înseamnă mai mult albastru.

Combinând valori diferite pentru roșu, verde și albastru, poți crea orice culoare. De exemplu:

- `RGB(255, 0, 0)` este roșu pur.
- `RGB(0, 255, 0)` este verde pur.
- `RGB(0, 0, 255)` este albastru pur.
- `RGB(255, 255, 255)` este alb (roșu, verde și albastru la maximum).
- `RGB(0, 0, 0)` este negru (lipsă de culoare).

Amestecând aceste culori în cantități diferite, se creează toate culorile pe care le vezi pe ecranele digitale.
