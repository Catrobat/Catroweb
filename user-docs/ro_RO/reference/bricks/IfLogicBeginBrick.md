![Dacă este adevărat, atunci](../../../media/bricks/if_else_brick2.png)

*Verifică dacă o condiție este adevărată și rulează un set de instrucțiuni dacă este, și un alt set dacă nu este. Este ca și cum ai da două opțiuni: „Dacă este adevărat, fă asta; altfel, fă aia.”*

![La începutul scenei](../../../media/bricks/StartScene.png)

Când începe scena, variabila X este setată la 0.

![Dacă e atins, altfel](../../../media/bricks/IfElse.png)

Dacă animalul este atins acum, se verifică dacă X modulo 2 este adevărat, adică dacă X este un număr impar.

Dacă da, se redă sunetul Tweet1 și variabila X crește cu 1.

Altfel, dacă X este par, doar X crește cu 1.

Instrucțiunile care trebuie executate sunt separate printr-un „Sfârșit dacă”.
