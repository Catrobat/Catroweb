![Când ești atins](../../../media/bricks/when-tapped2.png)

Rulează scriptul când obiectul este atins.

Diferența față de blocul „Când se atinge zona de joc” este că „Când ești atins” se referă la un anumit personaj sau obiect, în timp ce „Când se atinge zona de joc” se aplică întregului ecran.
