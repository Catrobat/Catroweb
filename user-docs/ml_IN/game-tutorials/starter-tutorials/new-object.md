ഈ ട്യൂട്ടോറിയലിൽ, നിന്റെ പ്രോജക്റ്റിലെ പുതിയ ഒബ്ജക്റ്റ് എങ്ങനെ സൃഷ്ടിക്കാമെന്നും അതിനുള്ള വിവിധ സാധ്യതകൾ എന്തൊക്കെയാണെന്നും നീ പഠിക്കും.

![പുതിയ വസ്തു](../../../media/game-tutorials/New-Object.png)

ഇതിനായി, നീ Pocket Code ആപ്ലിക്കേഷൻ ഡൌൺലോഡ് ചെയ്യുകയും പുതിയ ഒരു പ്രോജക്ട് എങ്ങനെ സൃഷ്ടിക്കാമെന്ന് അറിയുകയും വേണം. ഈ വിഷയത്തില് നിങ്ങള് ക്ക് സഹായം ആവശ്യമുണ്ടെങ്കില് **[പുതിയ പദ്ധതി](new-project.md)** -ന്റെ ട്യൂട്ടോറിയല് നോക്കുക.

*ഇവിടെ നിനക്ക് ട്യൂട്ടോറിയൽ PDF ഫോർമാറ്റിൽ ഡൌൺലോഡ് ചെയ്യാംഃ:*

[പുതിയ വസ്തു](../../../media/game-tutorials/New-Object.pdf)

### 1. പുതിയ ഒബ്ജക്ട് സൃഷ്ടിക്കുക

ആദ്യം, നിങ്ങള് ക്ക് പുതിയ പ്രോജക്ട് തുറക്കണം.

Pocket Code ആപ്ലിക്കേഷന്റെ ഹോം സ്ക്രീനിൽ കാണാം. ഒന്നിലധികം പ്രോജക്റ്റുകൾ ഉണ്ടെങ്കിൽ, നിനക്ക് “പ്രോജക്റ്റുകൾ” എന്നതിലേക്ക് ക്ലിക്ക് ചെയ്യാം. എന്നിട്ട് നിന്റെ പുതിയ പ്രോജക്ട് തിരഞ്ഞെടുക്കുക. നിങ്ങള് ക്ക് പുതിയ ഒരു പ്രോജക്ട് ഉണ്ടായില്ലെങ്കില് അല്ലെങ്കിൽ അത് എങ്ങനെ ചെയ്യാമെന്ന് കൂടുതല് വിവരങ്ങള് വേണമെങ്കില് **[പുതിയ പദ്ധതി](new-project.md)** - ന്റെ ട്യൂട്ടോറിയലില് നോക്കുക.

### 2. പുതിയ ഒബ്ജക്ട് സൃഷ്ടിക്കുക

ഇപ്പോൾ നിങ്ങള് പുതിയ ഒരു വസ്തു സൃഷ്ടിക്കാൻ തയ്യാറായിരിക്കുന്നു. അത് ചെയ്യുന്നതിന് താഴെ വലത് മൂലയിലെ മഞ്ഞ പ്ലസ് ബട്ടണിൽ ക്ലിക്ക് ചെയ്യുക. നിങ്ങള് ക്ക് തിരഞ്ഞെടുക്കാവുന്ന ഏഴ് സാധ്യതകളില് നിന്നും ഒരു പുതിയ വിൻഡോ കാണാം.

![പുതിയ വസ്തു (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. സൃഷ്ടിക്ക് വഴികൾ

നിനക്ക് തിരഞ്ഞെടുക്കാവുന്ന സാധ്യതകൾ ഇവയാണ്ഃ:

![പുതിയ വസ്തു (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. ചിത്രം വരയ്ക്കുക

തുടക്കത്തിൽ ഇത് എളുപ്പമാക്കുന്നതിന്, നമുക്ക് “വരയ്ക്കുക” ഫംഗ്ഷൻ ഉപയോഗിച്ച് ഒരു പോയിന്റ് വരയ്ക്കാൻ ആഗ്രഹിക്കാം. Pocket Paint ഉപയോഗിച്ച് പോയിന്റ് വരച്ചുകഴിഞ്ഞാൽ, അത് ഉപേക്ഷിക്കാം (ഒരു പടി പിന്നോട്ട് പോകുക).

### 5. ഒരു പേര് പറയൂ

ഇനി നിങ്ങള് നിന്റെ ചിത്രത്തിന് ഒരു പേര് നല് കണം.

### 6. അത് ഇടുക

അതിനുശേഷം വിരൽ കൊണ്ട് ഇടത്/വലത് അല്ലെങ്കിൽ മുകളിലേക്കും താഴേക്കും നീക്കി അതിനെ ദൃശ്യപരമായി സ്ഥാപിക്കണം. വലതു മുകളിലെ കോണിലുള്ള ബട്ടൺ ഉപയോഗിച്ച് അത് സംരക്ഷിക്കണം.

![പുതിയ വസ്തു (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. നീ അത് ചെയ്തു, നീ നിന്റെ പുതിയ വസ്തു സൃഷ്ടിച്ചു.

ഇപ്പോൾ നിനക്ക് പ്രോഗ്രാം ചെയ്യാവുന്ന ഒരു വസ്തുവുള്ള ഒരു പദ്ധതി ഉണ്ട്!

ഇത് ചെയ്യുന്നതിന്, ഏതു കോഡ് ബ്ലോക്കുകളാണ് ലഭ്യമെന്ന് നീ അറിഞ്ഞിരിക്കണം. **[ആദ്യ കോഡ് ബ്ലോക്കുകൾ](first-bricks.md)** - ട്യൂട്ടോറിയൽ കോഡ് ബ്ലോക്കുകളുടെ വിവിധ വിഭാഗങ്ങളെക്കുറിച്ച് നല്ല ഒരു അവലോകനം നൽകുന്നു. എന്നിരുന്നാലും, നിന്റെ ആദ്യ പദ്ധതിയില് നിന്ന് നേരിട്ട് ആരംഭിക്കാം. തുടക്കക്കാര് എന്ന പരമ്പരയില് നിന്നും അനുയോജ്യമായ ഒരു ട്യൂട്ടോറിയൽ തിരഞ്ഞെടുക്കുക.
