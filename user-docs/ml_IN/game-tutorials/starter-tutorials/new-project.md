ഈ ട്യൂട്ടോറിയലിൽ, നിന്റെ ആദ്യ പ്രോജക്ട് സൃഷ്ടിക്കാൻ ആരംഭിക്കുന്നതിന് Pocket Code നീ അറിയേണ്ടതെല്ലാം പഠിക്കും. ആപ്ലിക്കേഷൻ ഡൌൺലോഡ് ചെയ്യാനും അത് തുറക്കാനും പുതിയ പ്രോജക്ട് സൃഷ്ടിക്കാനും ഞങ്ങൾ നിന്നെ ഘട്ടം ഘട്ടമായി നയിക്കും.

![പുതിയ പ്രോഗ്രാം](../../../media/game-tutorials/New-Program.png)

ഇത് ആദ്യ ട്യൂട്ടോറിയലാണ്, അതിന് മുൻകൂർ അറിവ് ആവശ്യമില്ല.

പിന്നെ നീ എന്തിനാ കാത്തു നിൽക്കുന്നത്? ഫോൺ പിടിച്ചു ഉടനെ തന്നെ തുടങ്ങൂ!

*ഇവിടെ നിനക്ക് ട്യൂട്ടോറിയൽ PDF ഫോർമാറ്റിൽ ഡൌൺലോഡ് ചെയ്യാംഃ:*

[പുതിയ പ്രോഗ്രാം](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code ന്റെ ഇൻസ്റ്റലേഷൻ

ആദ്യം, നിന്റെ ഉപകരണത്തിൽ Pocket Code ആപ്ലിക്കേഷൻ ഇൻസ്റ്റാൾ ചെയ്യണം. Google Play Store എന്നതിൽ “Pocket Code” തിരയുന്നതിലൂടെ നിനക്ക് ആപ്പ് കണ്ടെത്താനും “ഇൻസ്റ്റാൾ ചെയ്യുക” എന്നതിൽ അമർത്തി ഡൌൺലോഡ് ചെയ്യാനും കഴിയും. ഈ ഘട്ടത്തിന് ഒരു ഗൂഗിൾ അക്കൌണ്ട് ആവശ്യമാണ്. ഇപ്പോൾ നിന്റെ ഉപകരണം ആപ്ലിക്കേഷൻ ഡൌൺലോഡ് ചെയ്ത് ഇൻസ്റ്റാൾ ചെയ്യും. നിന്റെ ഇന്റർനെറ്റ് കണക്ഷന് അനുസരിച്ച് ഈ നടപടി കുറച്ചു സമയം എടുത്തേക്കാം.

![പുതിയ പദ്ധതി (2)](../../../media/game-tutorials/New-Program-2.png)

Pocket Code വിജയകരമായി ഡൌൺലോഡ് ചെയ്ത് ഇൻസ്റ്റാൾ ചെയ്തതിനുശേഷം നിന്റെ ഉപകരണത്തെ ആശ്രയിച്ച് ആപ്ലിക്കേഷൻ ഡ്രോവറിൽ അല്ലെങ്കിൽ ഹോം സ്ക്രീനിൽ നിനക്ക് ആപ്ലിക്കേഷൻ കണ്ടെത്താം. ആപ്ലിക്കേഷന് എളുപ്പത്തില് എടുക്കാനും നിങ്ങള് ക്ക് ഇഷ്ടമുള്ളിടത്ത് സ്ഥാപിക്കാനും കഴിയും.

### 2. ആപ്പ് ആരംഭിക്കുക

ആപ്ലിക്കേഷൻ തുറക്കുമ്പോൾ വ്യത്യസ്ത വിഭാഗങ്ങൾ കാണാംഃ:

![പുതിയ പദ്ധതി (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. പുതിയ പദ്ധതി സൃഷ്ടിക്കുക

അടുത്ത ഘട്ടം ഒരു പുതിയ പദ്ധതി സൃഷ്ടിക്കുക എന്നതാണ്. അത് ചെയ്യുന്നതിന്, താഴെ വലത് മൂലയിലെ മഞ്ഞ പ്ലസ് ബട്ടൺ അമർത്തുക. ഇപ്പോൾ നീ ഒരു പ്രോജക്ട് നാമം നൽകുകയും നിന്റെ പദ്ധതി ലാൻഡ്സ്കേപ്പ് ആയിരിക്കണമോ വേണ്ടയോ എന്ന് തിരഞ്ഞെടുക്കുകയും വേണം. “ശരി” അമർത്തിക്കൊണ്ട് പദ്ധതി സൃഷ്ടിക്കപ്പെടുന്നു.

![പുതിയ പ്രോഗ്രാം](../../../media/game-tutorials/New-Program.png)

### 4. നീ അത് ചെയ്തു, നീ നിന്റെ പുതിയ പ്രോജക്ട് സൃഷ്ടിച്ചു.

ഇപ്പോൾ നീ Pocket Code ഇൻസ്റ്റാൾ ചെയ്തിരിക്കുന്നു, പുതിയ ഒരു പ്രോജക്ട് എങ്ങനെ സൃഷ്ടിക്കാമെന്ന് അറിയുന്നു. ഇനി നിങ്ങള് ക്ക് പ്രോഗ്രാമിങ് തുടങ്ങാം!

ഇത് ചെയ്യുന്നതിന്, ഒരു പ്രോജക്റ്റിൽ പുതിയ ഒബ്ജക്റ്റ് എങ്ങനെ സൃഷ്ടിക്കാമെന്ന് അറിയണം. **[പുതിയ വസ്തു](new-object.md)** -ന്റെ ട്യൂട്ടോറിയൽ കാണുക, അവിടെ എല്ലാം ഘട്ടം ഘട്ടമായി വിശദീകരിക്കുന്നു.
