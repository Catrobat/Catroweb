ഈ ട്യൂട്ടോറിയലിൽ, എംബ്രോയിഡറി കോഡ് ബ്ലോക്കുകൾ സജീവമാക്കുന്നത് വിശദീകരിക്കും.

![നുകരികടൽ സജീവമാക്കുക- (Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

ഇതിനു് പ്രോഗ്രാമിങ് അറിവ് ആവശ്യമില്ല. ഇത് നുകരികടക്കൽ ട്യൂട്ടോറിയലുകളുമായി ആരംഭിക്കുന്നതിനുള്ള ആദ്യ ചുവടുവെപ്പാണ്. പിന്നീട്, നിന്റെ ഇഷ്ടപ്പെട്ട തുണിത്തരത്തിൽ നിനക്ക് സ്വന്തം ഡിസൈനുകൾ രൂപകൽപ്പന ചെയ്യാനും പ്രോഗ്രാം ചെയ്യാനും പോലും കഴിയും.

കൂടുതൽ വിവരങ്ങള് ക്കോ ഡിസൈന് നിർദ്ദേശങ്ങള് ക്കോ മറ്റ് ട്യൂട്ടോറിയലുകള് കാണുക.

*ഇവിടെ നിനക്ക് ട്യൂട്ടോറിയൽ PDF ഫോർമാറ്റിൽ ഡൌൺലോഡ് ചെയ്യാം*:

[അക്ടിവേറ്റ് ചെയ്യുകഇംബ്രോയിഡറി ബ്രിക്കുകൾ](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. “Pocket Code” ആപ്പ് ആരംഭിക്കുക. ക്ലിക്ക് ചെയ്യുക!

### 2. മെനു തുറക്കുക (വലത് മുകളിലുള്ള കുത്തുകൾ).

![എംബ്രോയിഡറി കോഡ് ബ്ലോക്കുകൾ സജീവമാക്കുക](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. “ക്രമീകരണങ്ങൾ” എന്ന നമ്പറിലേക്ക് പോകുക.

![നുകരികടൽ സജീവമാക്കുക- (Bricks3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. തിരഞ്ഞെടുക്കുക “എംബ്രോയ്ഡറി എക്സ്റ്റൻഷൻ”.

![നുകരികടൽ സജീവമാക്കുക- (Bricks4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. നിന്റെ കോഡ് ബ്ലോക്കുകളില് തന്നെ നിങ്ങള് ക്ക് സ്വന്തം വിഭാഗമായി ഇംബ്രോയിഡറി കോഡ് ബ്ലോക്കുകള് കാണാം!

[![നുകരികടൽ സജീവമാക്കുക- (Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

ഇപ്പോൾ നീ മറ്റ് കോഡ് ബ്ലോക്കുകൾക്കിടയിൽ എല്ലാ നെയ്ത കോഡ് ബ്ലോക്കുകളും കണ്ടെത്തും.

ഓരോ കോഡ് ബ്ലോക്കിനെയും കുറിച്ചുള്ള കൂടുതൽ വിവരങ്ങൾക്ക്, കോഡ് ബ്ലോക്കുകളുടെ ഡോക്യുമെന്റേഷൻ [ഇവിടെ](../../../reference/) പരിശോധിക്കുകയോ അല്ലെങ്കിൽ ഇതിനായി **[കോഡ് ബ്ലോക്കുകൾ](embroidery-bricks/index.md)** -ട്യൂട്ടോറിയൽ പിന്തുടരുകയോ ചെയ്യാം.

ഇപ്പോൾ നിങ്ങള് ക്ക് സ്വന്തം ഡിസൈനുകള് സൃഷ്ടിക്കാൻ തുടങ്ങാം!

നിനക്ക് ആശയങ്ങളോ സഹായമോ ആവശ്യമുണ്ടെങ്കിൽ, മറ്റ് ട്യൂട്ടോറിയലുകൾ പരിശോധിക്കുക അല്ലെങ്കിൽ **[ഇംബ്രോയിഡറി വസ്തുക്കൾ സൃഷ്ടിക്കുക](create-embroidery-objects.md)** -ന്റെ ട്യൂട്ടോറിയൽ ഉപയോഗിച്ച് തുടരുക.
