മാറ്റാവുന്ന നീളത്തിൽ മെഷീൻ നിരന്തരം തുന്നി നടക്കുന്നു.

സാധാരണയായി നീക്കം കോഡ് ബ്ലോക്കിനൊപ്പം ഓട്ടം സ്റ്റിച്ചും ചേർക്കുന്നു.

![റണ്ണിംഗ് സ്റ്റിച്ച് തുടങ്ങുക, നീളം: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

യന്ത്രം ഓരോ **10 നടപടികൾ** വും ഒരു ഓണാക്കൽ സ്റ്റീച്ച് ആരംഭിക്കും.

അതിനുശേഷം യന്ത്രം നീങ്ങുന്നു **200 ചുവടുകൾ**.

ഇത് **20 തൂവലുകൾ** ലേക്ക് നയിക്കുന്നു.

![റണ്ണിംഗ് സ്റ്റിച്ച് തുടങ്ങുക, നീളം:](../../../../media/embroidery-tutorials/RunningStitch.png)

ഓടുന്ന തൂവൽ ഒരു തൂവലിനെ എളുപ്പമാക്കുന്നു, കാരണം നിനക്ക് ഇനി ഒരു ലൂപ്പ് ആവശ്യമില്ല.
