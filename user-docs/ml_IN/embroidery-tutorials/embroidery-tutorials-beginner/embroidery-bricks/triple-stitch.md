ട്രിപ്പിൾ സ്റ്റീച്ച് ഓരോ സ്റ്റൈക്കും മൂന്നു പ്രാവശ്യം തയ്യുന്നു.

ആദ്യ തൂക്കത്തിനു ശേഷം ട്രിപ്പിൾ സ്റ്റീച്ച് പിന്നോട്ട് ചാടുന്നു, തൂക്കങ്ങൾ, പിന്നെ വീണ്ടും മുന്നോട്ട് ചാടുന്നു, വീണ്ടും തൂക്കങ്ങൾ.

![ട്രിപ്പിൾ സ്റ്റിച്ച് തുടങ്ങുക, നീളം: 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

[ഓടുന്ന തൂവൽ](running-stitch.md) യുടെ അതേ രീതിയിലാണ് പ്രവർത്തിക്കുന്നത്.

![ട്രിപ്പിൾ സ്റ്റിച്ച് തുടങ്ങുക, നീളം:](../../../../media/embroidery-tutorials/TripleStitch.png)

ഇത് ചേല കൂടുതൽ കാലം നിലനിൽക്കും.
