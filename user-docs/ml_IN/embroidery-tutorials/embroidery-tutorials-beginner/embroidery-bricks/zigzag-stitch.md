നീളവും വീതിയും മാറ്റാവുന്ന രീതിയിൽ നിരന്തരം തുന്നുക.

ഒരു സിഗസാഗ് പാറ്റേണിൽ തൂക്കിയിടുക.

![സിഗ്‌സാഗ് സ്റ്റിച്ച് തുടങ്ങുക, നീളം: 2 വീതി: 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

ഈ കോഡ് ബ്ലോക്ക് അറിയാൻ നീളത്തിനും വീതിക്കും വേണ്ടി വ്യത്യസ്ത മൂല്യങ്ങൾ പരീക്ഷിക്കുക.

![സിഗ്‌സാഗ് സ്റ്റിച്ച് തുടങ്ങുക, നീളം:](../../../../media/embroidery-tutorials/ZigzagStitch.png)

സിഗ്സാഗ് സ്റ്റൈ ഉപയോഗിച്ച് കൂടുതൽ കട്ടിയുള്ള തയ്യലുകൾക്ക് നെയ്താൽ മതി.
