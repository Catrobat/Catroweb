ഈ ട്യൂട്ടോറിയലിൽ നീക്കറിയേണ്ടതെല്ലാം പഠിക്കും എംബ്രോയിഡറി കോഡ് ബ്ലോക്കുകളെക്കുറിച്ച്!

ഇതിനു് പ്രോഗ്രാമിങ് അറിവ് ആവശ്യമില്ല.

ഓരോ ഇംബ്രോയിഡറി കോഡ് ബ്ലോക്കിനും ഒരു ഉദാഹരണം നല് കും.

നീ ഇതുവരെ എംബ്രോയിഡറി കോഡ് ബ്ലോക്കുകൾ സജീവമാക്കിയിട്ടില്ലെങ്കിൽ, **[എംബ്രോയിഡറി കോഡ് ബ്ലോക്കുകൾ സജീവമാക്കുക](../activate-embroidery-bricks.md)** - ന്റെ ട്യൂട്ടോറിയൽ കാണുക.

*ഇവിടെ നിനക്ക് ട്യൂട്ടോറിയൽ PDF ഫോർമാറ്റിൽ ഡൌൺലോഡ് ചെയ്യാം*:

[കോഡ് ബ്ലോക്കുകൾ](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**അവയെക്കുറിച്ച് കൂടുതലറിയാൻ വ്യത്യസ്ത കോഡ് ബ്ലോക്കുകളിൽ ക്ലിക്ക് ചെയ്യുകഃ:**

[![തുന്നുക](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*മെഷീന് ഒരിക്കൽ തുണിയിൽ കുത്തിവെക്കാൻ അനുവദിക്കുക!*

[![റണ്ണിംഗ് സ്റ്റിച്ച് തുടങ്ങുക, നീളം: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*മാറ്റാവുന്ന നീളത്തിൽ മെഷീൻ നിരന്തരം തുന്നി നടക്കുന്നു.*

[![സിഗ്‌സാഗ് സ്റ്റിച്ച് തുടങ്ങുക, നീളം: 2 വീതി: 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*നീളവും വീതിയും മാറ്റാവുന്ന രീതിയിൽ നിരന്തരം തുന്നുക.*

[![ട്രിപ്പിൾ സ്റ്റിച്ച് തുടങ്ങുക, നീളം: 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*ട്രിപ്പിൾ സ്റ്റീച്ച് ഓരോ സ്റ്റൈക്കും മൂന്നു പ്രാവശ്യം തയ്യുന്നു.*

[![നിലവിലെ സ്റ്റിച്ച് നിർത്തുക](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*നിലവിലെ തൂക്കങ്ങൾ അവസാനിപ്പിക്കട്ടെ.*

നിനക്ക് കൂടുതൽ എംബ്രോയിഡറി കോഡ് ബ്ലോക്കുകളും അവയെക്കുറിച്ചുള്ള വിവരങ്ങളും കണ്ടെത്താം [ഇവിടെ](../../../../reference/#category_embroidery).

കൂടുതൽ വിവരങ്ങള് ക്കോ ഡിസൈന് നിർദ്ദേശങ്ങള് ക്കോ മറ്റ് ട്യൂട്ടോറിയലുകള് കാണുക!
