ക്രിയേറ്റീവ് ആയിക്കൊണ്ടു് അതേ സമയം കളിക്കളത്തിൽ കോഡ് പഠിക്കണമെന്നുണ്ടോ? നീക്കു് ഉപയോഗിക്കാനും ധരിക്കാനും പിന്നീട് തന്നെ ഇഷ്ടപ്പെടാനുമുള്ള വസ്തുക്കൾ സൃഷ്ടിക്കുവാൻ നീക്കു് ഇഷ്ടമാണോ?

Embroidery Designer ഉപയോഗിച്ച്, മുൻ പരിചയമില്ലാതെ ഒരു തുന്നൽ യന്ത്രം പ്രോഗ്രാം ചെയ്യാവുന്നതാണ്. അത് നിന്റെ ഡിസൈൻ ടി-ഷർട്ട്, ബാഗ്, പാന്റ്സ്, സ്മാർട്ട്ഫോൺ കേസ് അല്ലെങ്കിൽ ഷൂ എന്നിവയിൽ സ്വയം തുന്നലിക്കും. തുണിനിരയില് നിന്നും ഉണ്ടാക്കിയ എല്ലാ വസ്തുക്കളിലും തയ്യല് സാധ്യമാണ്. നിന്റെ ഭാവനയ്ക്കും സൃഷ്ടിപരമായ കാര്യങ്ങള് ക്കും സ്വാതന്ത്ര്യം നല് കുക! ഞങ്ങളുടെ Catrobat കമ്മ്യൂണിറ്റിയിൽ നിന്നും മറ്റുള്ളവരുടെ ഡിസൈനുകൾ നിനക്ക് ഡൌൺലോഡ് ചെയ്യാനും എഡിറ്റുചെയ്യാനും കഴിയും. തീർച്ചയായും, നിന്റെ പദ്ധതികൾ സുഹൃത്തുക്കളോടും ലോകത്തോടും പങ്കുവെക്കാം!
