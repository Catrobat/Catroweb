ഈ ട്യൂട്ടോറിയലിൽ, ഒരു രാത്രി ആകാശം (48.5 x 96.1 മിമി) എങ്ങനെ നെയ്തുകൂടാം എന്ന് പഠിക്കും.

![നച്തിംലെ](../../../media/embroidery-tutorials/Nachthimmel.png)

ഒരു ലൂപ്പ് എന്താണെന്നും അത് എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്നും നീക്കറിയണം.

**[നക്ഷത്രം](../embroidery-tutorials-beginner/star.md)** - ഈ ട്യൂട്ടോറിയലിന് സഹായകമാകും.

പ്രക്ഷേപണ പ്രവർത്തനത്തെക്കുറിച്ച് നിനക്ക് ഇതിനകം തന്നെ അറിവുണ്ടെങ്കിൽ അത് സഹായകമാകും.

നീ ഇതുവരെ ഒന്നും ഇട്ടു കൂടാ എങ്കിൽ [തുടക്കക്കാരന്](../embroidery-tutorials-beginner/index.md) പരമ്പരയിലെ നുകം ട്യൂട്ടോറിയലുകൾ പരിശോധിക്കുക.

കൂടുതൽ വിവരങ്ങള് ക്കോ ഡിസൈന് നിർദ്ദേശങ്ങള് ക്കോ മറ്റ് ട്യൂട്ടോറിയലുകള് കാണുക.
