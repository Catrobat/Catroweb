![വേദിയിൽ ടാപ്പ് ചെയ്യുമ്പോൾ](../../../media/bricks/When_stage_is_tapped_btn.png)

സ്ക്രീനില് സ്പർശിക്കുമ്പോൾ സ്ക്രിപ്റ്റ് പ്രവർത്തിപ്പിക്കുന്നു.

ബ്ലോക്കിലെ വ്യത്യാസം *“ടാപ്പ് ചെയ്യുമ്പോൾ”* അത് *“വേദിയിൽ ടാപ്പ് ചെയ്യുമ്പോൾ”* മുഴുവൻ സ്ക്രീനും ബാധകമാണ്, *“ടാപ്പ് ചെയ്യുമ്പോൾ”* പ്രത്യേക സ്പ്രിറ്റുകളോ വസ്തുക്കളോ ആണ്.
