സ്ക്രീനിന്റെ അറ്റത്ത് എത്തുമ്പോൾ വസ്തുവിനെ തിരിച്ചു കുതിപ്പിക്കും. നിന്റെ കഥാപാത്രം കളിസ്ഥലത്തിന്റെ അറ്റത്ത് എത്തുകയും ഒരു പന്ത് പോലെ തിരിച്ചെത്തുകയും ചെയ്യുന്നുവെന്ന് സങ്കൽപ്പിക്കുക.
