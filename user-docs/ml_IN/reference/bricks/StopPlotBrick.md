![പ്ലോട്ടിംഗ് നിർത്തുക](../../../media/bricks/Stop_to_plot.png)

“പ്ലോട്ടിംഗ് നിർത്തുക” കോഡ് ബ്ലോക്ക് പ്ലാറ്റിംഗ് പ്രക്രിയ നിർത്തുകയും ഒരു പുതിയ സ്ഥാനത്തേക്ക് നടനെ നീക്കുകയോ പ്ലാറ്റിംഗ് പൂർത്തിയാക്കുകയോ ചെയ്യട്ടെ. അത് പേപ്പറിൽ നിന്ന് ഒരു പേന എടുത്തത് പോലെ ആണ്. അതിനെ മാറ്റാനോ, അല്ലെങ്കിൽ വരയ്ക്കുന്നത് നിർത്താനോ. നീ പ്ലാനിംഗ് പൂർത്തിയാക്കിയ ശേഷം, നിന്റെ ഡിസൈൻ ഒരു SVG ഫയലായി സംരക്ഷിക്കാൻ “പ്ലോട്ട് SVG ആയി സംരക്ഷിക്കുക” കോഡ് ബ്ലോക്ക് ഉപയോഗിക്കാം.
