ഈ കോഡ് ബ്ലോക്ക് പ്രോജക്റ്റിലെ മറ്റു സ്ക്രിപ്റ്റുകൾ എല്ലാം പ്രവർത്തിക്കുന്നതുവരെ നിലവിലുള്ള സ്ക്രിപ്റ്റ് നിർത്തുന്നു. ബാക്കി എല്ലാം തീരുന്നതുവരെ നിന്റെ സ്ക്രിപ്റ്റ് നിർത്തിവെക്കുക. നിന്റെ നിലവിലെ സ്ക്രിപ്റ്റിൽ അടുത്ത ഘട്ടങ്ങളിലൂടെ മുന്നോട്ടുപോകുന്നതിന് മുമ്പ് മറ്റേതെങ്കിലും പ്രവർത്തനങ്ങൾ ഉണ്ടാകുന്നില്ലെന്ന് ഉറപ്പുവരുത്താൻ ഇത് ഉപയോഗപ്രദമാണ്.
