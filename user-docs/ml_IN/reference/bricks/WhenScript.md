![ടാപ്പ് ചെയ്യുമ്പോൾ](../../../media/bricks/when-tapped2.png)

വസ്തു ടാപ്പുചെയ്താല് സ്ക്രിപ്റ്റ് പ്രവർത്തിപ്പിക്കുന്നു.

ബ്ലോക്കിലെ വ്യത്യാസം *“വേദിയിൽ ടാപ്പ് ചെയ്യുമ്പോൾ”* എന്നത് *“ടാപ്പ് ചെയ്യുമ്പോൾ”* വ്യക്തിഗത സ്പ്രിറ്റുകളിലോ വസ്തുക്കളിലോ പ്രത്യേകമാണെന്നതാണ്, അതേസമയം *“വേദിയിൽ ടാപ്പ് ചെയ്യുമ്പോൾ”* മുഴുവൻ സ്ക്രീനിലും ബാധകമാണ്.
