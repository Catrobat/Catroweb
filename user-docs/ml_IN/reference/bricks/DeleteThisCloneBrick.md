![ഈ ക്ലോൺ ഇല്ലാതാക്കുക](../../../media/bricks/delete_clone_brick2.png)

ഈ കോഡ് ബ്ലോക്ക് “ക്ലോൺ സൃഷ്ടിക്കുക:” കോഡ് ബ്ലോക്കിൽ സൃഷ്ടിച്ച ക്ലോൺ നീക്കം ചെയ്യുന്നു. ഇത് പറയുന്നത് പോലെയാണ്, “ഈ ഡ്യൂപ്ലിക്കേറ്റ് നീക്കം ചെയ്യുക.” നിന്റെ പ്രോജക്റ്റിലെ ക്ലോണുകളുടെ എണ്ണം നിയന്ത്രിക്കാനും നിയന്ത്രിക്കാനും ഇത് ഉപയോഗിക്കുക. അവ ആവശ്യമില്ലാത്തപ്പോൾ അവ ഇല്ലാതാക്കപ്പെടുന്നുവെന്ന് ഉറപ്പാക്കുക.
