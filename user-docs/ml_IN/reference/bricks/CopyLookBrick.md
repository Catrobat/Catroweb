ഈ കോഡ് ബ്ലോക്ക് നിലവിലുള്ള രൂപം ഇരട്ടിപ്പിക്കുകയും പുതിയ പേര് നൽകുകയും ചെയ്യുന്നു. ഒരു ഡ്രോയിംഗിന്റെ കോപ്പി ഉണ്ടാക്കുകയും അതിനെ മറ്റൊരു തരത്തിൽ ലേബലിംഗ് ചെയ്യുകയും ചെയ്യുന്നതുപോലെയാണ്.
