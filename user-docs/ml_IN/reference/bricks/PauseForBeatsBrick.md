![പൌസ 1 താളം](../../../media/bricks/Pause_for_1_beats.png)

ഈ കോഡ് ബ്ലോക്ക് സ്ക്രിപ്റ്റിന് തുടരുന്നതിന് മുമ്പ് ഒരു നിശ്ചിത എണ്ണം താളങ്ങൾ കാത്തിരിക്കേണ്ടി വരും. അടുത്ത നോട്ട് അല്ലെങ്കിൽ ശബ്ദം പ്ലേ ചെയ്യുന്നതിനു മുമ്പ് ഒരു ഗാനത്തിൽ കുറച്ചുകൂടി ഇടവേള എടുക്കുന്നതുപോലെയാണ്. നിന്റെ പ്രകടനം ഒരു നിമിഷം നിർത്തി, താളങ്ങൾ എണ്ണുക, തുടർന്ന് പ്രവർത്തനം പുനരാരംഭിക്കുക എന്ന് സങ്കൽപ്പിക്കുക.
