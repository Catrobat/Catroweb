![ഇതിൽ തട്ടി തെറിക്കുമ്പോൾ:](../../../media/bricks/when_you_bounce_off_brick2.png)

ഒരു വസ്തു നിർദ്ദിഷ്ട ഉപരിതലത്തിൽ നിന്നോ വസ്തുവിൽ നിന്നോ കുതിക്കുമ്പോൾ ഉണ്ടാകുന്ന പ്രതിപ്രവർത്തനമോ പ്രവർത്തനമോ സജ്ജമാക്കുന്നു. അത് പറയുന്നത് പോലെ, “എന്റെ കഥാപാത്രം ഒരു മതിൽക്കോ മറ്റേതെങ്കിലും വസ്തുവിനോ താഴേക്ക് ചാടുമ്പോഴെല്ലാം ഈ നടപടി എടുക്കുക.”
