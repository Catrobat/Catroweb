![അല്ലാത്തപക്ഷം കോഡ് ബ്ലോക്ക്](../../../media/bricks/if_else_brick2.png)

*ഒരു അവസ്ഥ ശരിയാണോ എന്ന് പരിശോധിക്കുകയും, അത് ശരിയാണെങ്കിൽ ഒരു കൂട്ടം നിർദ്ദേശങ്ങൾ പ്രവർത്തിപ്പിക്കുകയും, ഇല്ലെങ്കിൽ മറ്റൊരു കൂട്ടം നിർദ്ദേശങ്ങൾ പ്രവർത്തിപ്പിക്കുകയും ചെയ്യുന്നു. ഇത് രണ്ട് ഓപ്ഷനുകൾ നൽകുന്നത് പോലെയാണ്ഃ “ഇത് ശരിയാണെങ്കിൽ, ഇതു ചെയ്യുക; അല്ലാത്തപക്ഷം അതൊന്ന് ചെയ്യുക.”*

![ഈ രംഗം തുടങ്ങുക:](../../../media/bricks/StartScene.png)

രംഗം തുടങ്ങുമ്പോൾ, പരിവർത്തന X 0 ആയി സജ്ജമാക്കുന്നു.

![മറ്റൊരാൾ](../../../media/bricks/IfElse.png)

മൃഗത്തെ ഇപ്പോൾ ടാപ്പുചെയ്താൽ, X മോഡുലോ 2 ശരിയാണോ എന്ന് പരിശോധിക്കുക, അതായത് X ഒരു അപരിചിതമായ സംഖ്യയാണോ എന്ന് പരിശോധിക്കുക.

ഈ സാഹചര്യത്തിൽ, ശബ്ദം Tweet1 പ്ലേ ചെയ്യുകയും വേരിയബിൾ X 1 വർദ്ധിപ്പിക്കുകയും ചെയ്യുന്നു.

അല്ലെങ്കിൽ, X സമമാണെങ്കിൽ, X മാത്രം 1 കൊണ്ട് വർദ്ധിപ്പിക്കുന്നു.

നടപ്പാക്കേണ്ട പ്രസ്താവനകൾ ഒരു വ്യവസ്ഥയുടെ അവസാനം വരി കൊണ്ട് വേർതിരിക്കുന്നു.
