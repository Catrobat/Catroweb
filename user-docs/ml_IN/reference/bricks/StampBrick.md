![മുദ്ര പതിപ്പിക്കുക](../../../media/bricks/Stamp_.png)

ഈ കോഡ് ബ്ലോക്ക് ഉപയോഗിച്ചാല് നിന്റെ കഥാപാത്രത്തിന്റെ ഒരു പകര് ണം സ്ക്രീനില് വിടുക. അത് പേപ്പറിൽ നിറമുള്ള സ്റ്റാമ്പ് മുദ്രയിട്ടിട്ട് സ്റ്റാമ്പ് ഡിസൈനിന്റെ ഒരു പകർപ്പ് ഉപേക്ഷിക്കുന്നതുപോലെയാണ്. ഈ രീതിയിൽ, നിന്റെ പശ്ചാത്തലം മെച്ചപ്പെടുത്തുന്നു - നീ ഒരു ക്ലോൺ സൃഷ്ടിക്കുന്നില്ല!
