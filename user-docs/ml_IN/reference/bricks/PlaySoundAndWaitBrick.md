![ശബ്ദം തുടങ്ങി കാത്തിരിക്കുക:](../../../media/bricks/start_sound_and_wait_brick.png)

ഈ കോഡ് ബ്ലോക്ക് തിരഞ്ഞെടുത്ത ശബ്ദം പ്ലേ ചെയ്യുകയും അടുത്ത പ്രവർത്തനത്തിലേക്ക് നീങ്ങുന്നതിന് മുമ്പ് അത് പൂർത്തിയാകുന്നതുവരെ കാത്തിരിക്കുകയും ചെയ്യുന്നു. ഒരു ഗാനം പ്ലേ ചെയ്യുമ്പോഴും പാട്ട് അവസാനിക്കുന്നതുവരെ മറ്റൊന്നും ചെയ്യാതിരിക്കുമ്പോഴും അത് പോലെയാണ്.
