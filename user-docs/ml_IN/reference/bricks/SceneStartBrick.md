![ഈ രംഗം തുടങ്ങുക:](../../../media/bricks/start_scene_brick2.png)

ഈ കോഡ് ബ്ലോക്ക് നിന്റെ പ്രോജക്റ്റിലെ മറ്റൊരു രംഗത്തേക്ക് മാറുകയും ആ രംഗം തുടക്കം മുതൽ പ്രവർത്തിപ്പിക്കുകയും ചെയ്യുന്നു. ഒരു പുസ്തകത്തിലെ അധ്യായം മാറ്റുന്നതുപോലെയാണ്, അല്ലെങ്കിൽ ഒരു ഗെയിമിലെ അടുത്ത തലത്തിലേക്ക് നീങ്ങുന്നത്.

നിന്റെ പദ്ധതിയില് ഒന്നിലധികം രംഗങ്ങള് ഉണ്ടെന്ന് സങ്കല് പിക്കുക, ഓരോന്നും നിന്റെ കഥയുടെയോ കളിയുടെയോ മറ്റൊരു ഭാഗത്തെ പ്രതിനിധീകരിക്കുന്നു. ഈ കോഡ് ബ്ലോക്ക് ഉപയോഗിച്ച് നിനക്ക് ഏത് രംഗത്തും ചാടി അത് തുടക്കം മുതൽ തന്നെ ആരംഭിക്കാം, നിന്റെ പദ്ധതിയുടെ വിവിധ ഭാഗങ്ങൾക്കിടയിൽ സുഗമമായ ഒരു മാറ്റം സൃഷ്ടിക്കുക.
