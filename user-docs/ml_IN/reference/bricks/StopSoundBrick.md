![ശബ്ദം നിർത്തുക:](../../../media/bricks/Stop_sound_record.png)

ഈ കോഡ് ബ്ലോക്ക് ഒരു പ്രത്യേക ശബ്ദം പ്ലേ ചെയ്യുന്നതിൽ നിന്നും തടയുന്നു. അത് ഒരു ഗാനം മാത്രം നിർത്തുക എന്ന ബട്ടൺ അമർത്തുന്നതുപോലെയാണ്. മറ്റ് ശബ്ദങ്ങളോ സംഗീതമോ പ്ലേ ചെയ്യുമ്പോൾ. ഒരു ശബ്ദ ട്രാക്ക് നിർത്താൻ നിന്റെ കഥാപാത്രത്തിന് പറയുമെന്ന് സങ്കൽപ്പിക്കുക.
