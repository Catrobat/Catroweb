![നിങ്ങളുടെ ചലന തരം സജ്ജമാക്കുക:](../../../media/bricks/set_your_motion_type_brick.png)

വസ്തുവിന്റെ ചലന രീതി മാറ്റുന്നു, ഉദാഹരണത്തിന്, അത് ഗ്രാവിറ്റിക്ക് കീഴിൽ നീങ്ങാനും കുതിക്കാനും അനുവദിക്കുക, ഗ്രാവിറ്റിക്ക് കീഴിൽ നീങ്ങാതിരിക്കുക, പക്ഷേ മറ്റുള്ളവർ നിന്നെ വിട്ടു കുതിക്കുക അല്ലെങ്കിൽ ഗ്രാവിറ്റിക്ക് കീഴിൽ നീങ്ങുകയോ പരിധിയില്ലാതെ പോകുകയോ ചെയ്യുക. നിന്റെ കഥാപാത്രത്തിന്റെ ചലനവും ഇടപെടലും കണക്കിലെടുത്ത് എങ്ങനെ പെരുമാറണമെന്ന് തിരഞ്ഞെടുക്കുന്നതു പോലെയാണ്.
