വസ്തുവിന്റെ ദിശ ഒരു നിശ്ചിത കോണിലേക്ക് വെക്കുന്നു. നിന്റെ കഥാപാത്രത്തിന് ഒരു പ്രത്യേക ദിശയിലേക്ക് മുന്നോട്ട് പോകണമെന്ന് പറയുമ്പോള് പോലെയാണ് അത്. ഉദാ. മുകളിലേക്കും താഴേക്കും ഇടത്തോട്ടേക്കും വലത്തോട്ടേക്കും.
