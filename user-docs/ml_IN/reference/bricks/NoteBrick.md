![കുറിപ്പ്](../../../media/bricks/note_brick2.png)

നിന്റെ കോഡിന്റെ ഭാഗങ്ങൾ എന്തൊക്കെയാണെന്ന് ഓർക്കാൻ സഹായിക്കുന്നതിന് ഒരു അഭിപ്രായം അല്ലെങ്കിൽ കുറിപ്പ് നിന്റെ സ്ക്രിപ്റ്റിലേക്ക് ചേർക്കുന്നു. നിന്റെ പ്രോജക്ട് എങ്ങനെ നടക്കുന്നു എന്നതിനെ അത് ബാധിക്കുന്നില്ല. അത് ഒരു കുറിപ്പ് തനിക്കു വേണ്ടി വിടുന്നതുപോലെയാണ്.
