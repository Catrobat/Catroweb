ഈ ബ്ലോക്ക് നിന്റെ കഥാപാത്രത്തിന് കണികകൾ ചേർക്കുകയും അവ കാലക്രമേണ അപ്രത്യക്ഷമാവുകയും ചെയ്യുന്നു. ഉദാഹരണത്തിന്, ഒരു വെടിവയ്പ് പ്രദർശനം സൃഷ്ടിക്കുക, പുക ചേർക്കുക അല്ലെങ്കിൽ നിന്റെ കഥാപാത്രം വേഗത്തിൽ കാണിക്കാൻ ഉപയോഗിക്കുക.
