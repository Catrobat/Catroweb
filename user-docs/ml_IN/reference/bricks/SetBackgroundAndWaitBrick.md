ഈ കോഡ് ബ്ലോക്ക് ഒരു പുതിയ പശ്ചാത്തലം സജ്ജമാക്കുകയും സ്ക്രിപ്റ്റ് തുടരുന്നതിന് മുമ്പ് മാറ്റം പൂർത്തിയാകുന്നതുവരെ കാത്തിരിക്കുകയും ചെയ്യുന്നു. ഒരു നാടകത്തിലെ പ്രകൃതിദൃശ്യങ്ങൾ മാറ്റുന്നതും പുതിയ രംഗം പൂർണ്ണമായി സജ്ജമാകുന്നതുവരെ കാത്തിരിക്കുന്നതുപോലെയാണ്.
