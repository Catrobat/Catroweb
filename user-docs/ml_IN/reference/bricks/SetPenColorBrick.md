ഈ കോഡ് ബ്ലോക്ക് നടൻ ഉപയോഗിക്കുന്ന പേനയുടെ നിറം മാറ്റുന്നു. അത് ഒരു പെൻ നിറം മാറ്റുന്നതുപോലെയാണ്.

**ചുവപ്പ്, പച്ച, നീല (RGB)**: നിറങ്ങളുടെ വിശാലമായ ശ്രേണി സൃഷ്ടിക്കുന്നതിന് ചുവപ്പ്, പച്ച, നീല വെളിച്ചം എന്നിവയുടെ വ്യത്യസ്ത തീവ്രത ഉപയോഗിക്കുന്നതാണ് RGB കളർ മോഡൽ. ഓരോ നിറ ഘടകത്തിനും (ചുവപ്പ്, പച്ച, നീല) 0 മുതൽ 255 വരെയുള്ള ഒരു മൂല്യം ഉണ്ടായിരിക്കാംഃ:

- **ചുവന്ന**: നിറത്തിന്റെ ചുവന്ന ഘടകം. ഉയർന്ന മൂല്യം കൂടുതല് ചുവന്നത് എന്നാണ്.
- **പച്ച**: നിറത്തിന്റെ പച്ച ഘടകം. ഉയർന്ന മൂല്യം കൂടുതൽ പച്ചതരം എന്നാണ് അർത്ഥമാക്കുന്നത്.
- **നീല**: നിറത്തിന്റെ നീല ഘടകം. ഉയർന്ന മൂല്യം കൂടുതൽ നീല നിറം എന്നാണ് അർത്ഥമാക്കുന്നത്.

ചുവപ്പ്, പച്ച, നീല എന്നിവയുടെ വ്യത്യസ്ത മൂല്യങ്ങൾ കൂട്ടിച്ചേർത്ത് നിനക്ക് ഏത് നിറവും സൃഷ്ടിക്കാൻ കഴിയും. ഉദാഹരണത്തിന്:

- `RGB(255, 0, 0)` ശുദ്ധമായ ചുവപ്പ് ആണ്.
- `RGB(0, 255, 0)` ശുദ്ധമായ പച്ചയാണ്.
- `RGB(0, 0, 255)` ശുദ്ധമായ നീലയാണ്.
- `RGB(255, 255, 255)` വെളുത്തതാണ് (പരമാവധി ചുവപ്പ്, പച്ച, നീല).
- `RGB(0, 0, 0)` കറുത്തതാണ് (നിറമില്ല).

ഈ നിറങ്ങൾ വ്യത്യസ്ത അളവിൽ കലർത്തി ഡിജിറ്റൽ സ്ക്രീനുകളിൽ കാണുന്ന എല്ലാ നിറങ്ങളും സൃഷ്ടിക്കുന്നു.
