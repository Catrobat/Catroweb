![ഇതിന് നേരെ തിരിയുക:](../../../media/bricks/point_towards_brick.png)

വസ്തു മറ്റൊരു വസ്തുവിനെ അല്ലെങ്കിൽ മൌസ് പോയിന്ററിനെ മുഖം കാണിക്കുന്നു. നിന്റെ കഥാപാത്രത്തിന് എപ്പോഴും ഒരു പ്രത്യേക ലക്ഷ്യം അല്ലെങ്കിൽ ദിശ നോക്കണമെന്ന് പറയുമെന്ന് സങ്കൽപ്പിക്കുക.
