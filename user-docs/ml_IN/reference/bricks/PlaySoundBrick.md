ഈ കോഡ് ബ്ലോക്ക് തിരഞ്ഞെടുത്ത ശബ്ദം ഉടനെ പ്ലേ ചെയ്യുന്നു. നിന്റെ പ്രിയപ്പെട്ട ഗാനത്തിൽ പ്ലേ ചെയ്യുക എന്ന് സങ്കൽപ്പിക്കുക; ആ നിമിഷം മുതൽ ശബ്ദം കേൾക്കാൻ തുടങ്ങുന്നു.
