ഈ കോഡ് ബ്ലോക്ക് പശ്ചാത്തലം ഒരു പ്രത്യേക പശ്ചാത്തലത്തിലേക്ക് മാറ്റുന്നു, അത് പശ്ചാത്തലങ്ങളുടെ പട്ടികയിൽ അതിന്റെ സ്ഥാനത്തെ അടിസ്ഥാനമാക്കി സ്ക്രിപ്റ്റ് തുടരുന്നതിന് മുമ്പ് മാറ്റം പൂർത്തിയാകുന്നതുവരെ കാത്തിരിക്കുന്നു. ഒരു നാടകത്തിലെ പ്രകൃതിദൃശ്യത്തെ ഒരു പട്ടികയിൽ നിന്നും ഒരു പ്രത്യേക പശ്ചാത്തലത്തിലേക്ക് മാറ്റുകയും പുതിയ രംഗം പൂർണ്ണമായി സജ്ജമാകുന്നതുവരെ പ്രവർത്തനം നിർത്തുകയും ചെയ്യുന്നതുപോലെയാണ്.
