![ക്ലോൺ സൃഷ്ടിക്കുക:](../../../media/bricks/create_clone_of_brick2.png)

ഈ കോഡ് ബ്ലോക്ക് ഒരു ക്ലോൺ എന്ന് വിളിക്കപ്പെടുന്ന വ്യക്തമാക്കിയ വസ്തുവിന്റെ ഒരു പകർപ്പ് ഉണ്ടാക്കുന്നു, അത് യഥാർത്ഥത്തിൽ പോലെ പെരുമാറുന്നു. നിന്റെ ഗെയിമിലെ ഒരു കഥാപാത്രമോ വസ്തുവോ നീ തനിപ്പകർപ്പ് ചെയ്യുന്നുവെന്ന് സങ്കൽപ്പിക്കുക. ക്ലോണിന് അതിന്റേതായ സ്വഭാവങ്ങളും സ്ക്രിപ്റ്റുകളും ഉണ്ടായിരിക്കാം, അത് സ്വതന്ത്രമായി പ്രവർത്തിക്കാൻ കഴിയുന്ന ഒരു വസ്തുവിന്റെ ഒന്നിലധികം ഉദാഹരണങ്ങൾ സൃഷ്ടിക്കാൻ നിന്നെ അനുവദിക്കുന്നു.
