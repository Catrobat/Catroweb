നിന്റെ പദ്ധതിയുടെ മറ്റു ഭാഗങ്ങളിലേക്ക് ഒരു സന്ദേശം അയച്ചു, സ്വന്തം സ്ക്രിപ്റ്റുകൾ തുടങ്ങാൻ അവരോട് പറഞ്ഞു. എല്ലാവരും ശ്രദ്ധിക്കുന്ന ഒരു പ്രഖ്യാപനം നടത്തുന്നതു പോലെയാണ്.

**എന്തിന് പ്രക്ഷേപണ സന്ദേശങ്ങൾ അയയ്ക്കണം?**

സന്ദേശങ്ങളിലൂടെ നിനക്ക് ഒരു രംഗത്തിനുള്ളിലെ വ്യത്യസ്ത വസ്തുക്കളുമായി ആശയവിനിമയം നടത്താനും ഇടപെടാനും കഴിയും. ഒരു വസ്തുവിന് മറ്റ് എല്ലാ വസ്തുക്കളിലേക്കും സന്ദേശം അയയ്ക്കാൻ ഇത് അനുവദിക്കുന്നു, തുടർന്ന് സ്വീകർത്താക്കൾക്ക് ആ സന്ദേശത്തിന് പ്രതികരിക്കാനോ പ്രതികരിക്കാനോ കഴിയും.

ഈ സന്ദേശങ്ങള് സ്ക്രീനില് **കാണിക്കാത്തത്** ഉണ്ട്! സന്ദേശങ്ങൾ കാണിക്കണമെങ്കിൽ “രൂപങ്ങൾ” വിഭാഗത്തിലെ കോഡ് ബ്ലോക്കുകൾ ഉപയോഗിക്കുക!

**അത് എങ്ങനെ പ്രവർത്തിക്കുന്നു?**

- *അയയ്ക്കുന്ന വസ്തു:* അയയ്ക്കുന്ന വസ്തു ഒരു *“എല്ലാവർക്കും സന്ദേശം അയയ്ക്കുക:”* ബ്ലോക്ക് ഉപയോഗിച്ച് ആശയവിനിമയം ആരംഭിക്കുന്നു. ഈ ബ്ലോക്ക് രംഗത്തിലെ മറ്റ് എല്ലാ വസ്തുക്കളിലേക്കും (അതുപോലെ തന്നെ പശ്ചാത്തലത്തിലേക്കും) ഒരു സന്ദേശം അയയ്ക്കാൻ ഉപയോഗിക്കുന്നു.
- *സ്വീകർത്താവ്ഃ:* സന്ദേശങ്ങൾ കേൾക്കുകയും പ്രതികരിക്കുകയും ചെയ്യുന്നവയാണ് സ്വീകരിക്കുന്ന വസ്തുക്കൾ. ഒരു പ്രത്യേക സന്ദേശം ലഭിക്കുമ്പോൾ അത് കണ്ടെത്താൻ *“ഈ സന്ദേശം ലഭിക്കുമ്പോൾ:”* ബ്ലോക്ക് ഉപയോഗിക്കുന്നു.
- *സന്ദേശ കൈകാര്യം ചെയ്യൽഃ:* സന്ദേശം ലഭിക്കുമ്പോൾ, അത് *“ഈ സന്ദേശം ലഭിക്കുമ്പോൾ:”* ബ്ലോക്കിന് താഴെയുള്ള എല്ലാ ബ്ലോക്കുകളും നടപ്പിലാക്കും. ഒരു സന്ദേശം ലഭിക്കുമ്പോൾ സംഭവിക്കുന്ന സ്വഭാവമോ പ്രവർത്തനങ്ങളോ നിർവചിക്കാൻ ഇത് നിന്നെ അനുവദിക്കുന്നു.
