![കോഡ് തടയുന്ന സമയത്ത്](../../../media/bricks/when_brick3.png)

*വ്യക്തമാക്കിയ മൂല്യം അല്ലെങ്കിൽ ഫംഗ്ഷൻ സത്യമാകുന്നതുവരെ കാത്തിരിക്കുകയും തുടർന്ന് സ്ക്രിപ്റ്റ് പ്രവർത്തിപ്പിക്കുകയും ചെയ്യുന്നു.*

![ഈ രംഗം തുടങ്ങുക:](../../../media/bricks/StartScene.png)

രംഗം തുടങ്ങുമ്പോൾ, പരിവർത്തന X 0 ആയി സജ്ജമാക്കുന്നു.

![ടാപ്പ് ചെയ്യുമ്പോൾ മോഡുലോ](../../../media/bricks/WhenTappedWhenModulo.png)

ഇപ്പോൾ മൃഗത്തെ ടാപ്പുചെയ്യുകയാണെങ്കിൽ, X 1 വർദ്ധിപ്പിക്കുന്നു.

X മൊഡ്യൂൾ 2 ശരിയായിത്തീരുമ്പോൾ, അതായത് X ഒരു അപൂർവ സംഖ്യയാണെങ്കിൽ, ശബ്ദം Tweet1 പ്ലേ ചെയ്യുന്നു.
