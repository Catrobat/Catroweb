![ഗ്രാഫിക് ഇഫക്റ്റുകൾ മായ്ക്കുക](../../../media/bricks/Clear_graphic_effects.png)

ഈ കോഡ് ബ്ലോക്ക് ഒരു നടന് റെ മേല് പ്രയോഗിക്കുന്ന എല്ലാ ദൃശ്യപ്രഭാവങ്ങളും നീക്കം ചെയ്യുകയും അത് അതിന്റെ യഥാർത്ഥ രൂപത്തിലേക്ക് തിരിച്ചു വരുത്തുകയും ചെയ്യുന്നു. അത് ഒരു മലിനമായ വിൻഡോ വൃത്തിയാക്കുന്നതുപോലെയാണ്.
