![ഈ സ്ഥാനത്ത് വയ്ക്കുക](../../../media/bricks/place_at_x_y_brick.png)

x, y കോർഡിനേറ്റുകൾ നിർവചിച്ചിരിക്കുന്ന സ്ക്രീനിൽ ഒരു പ്രത്യേക സ്ഥാനത്തേക്ക് വസ്തു നീക്കുന്നു. അത് നിന്റെ കഥാപാത്രത്തെ കൃത്യമായ സ്ഥലത്തേക്ക് ടെലിപോർട്ട് ചെയ്യുന്നതുപോലെയാണ്.

കാർട്ടീഷ്യൻ വിമാനത്തിലെന്നപോലെ ഒരു കോർഡിനേറ്റ് സിസ്റ്റത്തിൽ സ്ഥാനം സജ്ജമാക്കിയിരിക്കുന്നുഃ x, y അക്ഷങ്ങൾ സ്ക്രീനിന്റെ മധ്യത്തിലൂടെ കടന്നുപോകുന്നു, അതിനാൽ x = 0 ഉം y = 0 ഉം സ്ക്രീനിന്റെ മധ്യമാണ്.
