![അവസാന ഘട്ട കോഡ് ബ്ലോക്ക്](../../../media/bricks/finish-stage-brick.png)

ഈ കോഡ് ബ്ലോക്ക് എല്ലാ സ്ക്രിപ്റ്റുകളും അവസാനിപ്പിക്കുകയും നിലവിലെ ഘട്ടം അല്ലെങ്കിൽ രംഗം അവസാനിപ്പിക്കുകയും ചെയ്യുന്നു. “പദ്ധതിയുടെ ഈ ഭാഗം അവസാനിച്ചു.” എല്ലാം അവസാനിക്കുന്നു, പദ്ധതി മറ്റൊരു രംഗത്തേക്ക് നീങ്ങുകയോ അല്ലെങ്കിൽ പൂർണമായും അവസാനിക്കുകയോ ചെയ്യാം. നിന്റെ പദ്ധതിയുടെ ഒരു പ്രത്യേക ഘട്ടം അല്ലെങ്കിൽ തലത്തിൽ അവസാനിപ്പിക്കണമെന്നുണ്ടെങ്കിൽ ഇത് ഉപയോഗിക്കുക.
