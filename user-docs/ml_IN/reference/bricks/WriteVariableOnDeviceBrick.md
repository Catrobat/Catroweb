ഒരു വേരിയബിളിന്റെ മൂല്യം നിന്റെ ഉപകരണത്തില് സംരക്ഷിക്കുക, അങ്ങനെ ആപ്ലിക്കേഷൻ അടച്ചതിനു ശേഷവും നിങ്ങള് ക്ക് പിന്നീട് അത് ഉപയോഗിക്കാനാകും. അത് ഫോണില് ഒരു കുറിപ്പ് എഴുതുന്നതുപോലെയാണ്.
