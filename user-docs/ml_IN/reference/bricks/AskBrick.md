ഈ കോഡ് ബ്ലോക്ക് ഉപയോക്താവിന് ഒരു ചോദ്യവുമായി ബന്ധിപ്പിക്കുകയും അവരുടെ പ്രതികരണം ഒരു നിശ്ചിത വേരിയബിളിൽ സംഭരിക്കുകയും ചെയ്യുന്നു. അത് പ്രേക്ഷകരോട് ഒരു ചോദ്യം ചോദിക്കുകയും അവരുടെ ഉത്തരം പിന്നീട് സ്ക്രിപ്റ്റിൽ ഉപയോഗിക്കുവാനായി സംരക്ഷിക്കുകയും ചെയ്യുന്നതുപോലെയാണ്.
