![കണികാ പ്രഭാവം ചേർക്കുക](../../../media/bricks/Turn_particle_effect_additivity_on.png)

ഈ കോഡ് ബ്ലോക്ക് കണികകളുടെ കൂട്ടിച്ചേർക്കൽ മിശ്രിത മോഡ് പ്രവർത്തനക്ഷമമാക്കുകയോ അല്ലെങ്കിൽ നിർജ്ജീവമാക്കുകയോ ചെയ്യുന്നു, ഇത് കണികകളെ കൂടുതൽ തിളക്കവും തീവ്രതയും കാണിക്കാൻ സഹായിക്കുന്നു. അത് തിളക്കവും തെളിച്ചവും ക്രമീകരിക്കുന്നതുപോലെയാണ്.
