![ക്ലോൺ ആയി തുടങ്ങുമ്പോൾ](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

ആവശ്യമുള്ള പ്രവർത്തനങ്ങൾ നടത്തുന്നതിനുള്ള നിർദ്ദേശങ്ങളുമായി ഒരു വസ്തുവിന്റെ സൃഷ്ടിച്ച ക്ലോണിനെ നയിക്കുക. ഈ പ്രക്രിയ യഥാർത്ഥ വസ്തുവിന്റെ പ്രവർത്തനത്തെ തനിപ്പകർപ്പ് ചെയ്യാൻ അനുവദിക്കുന്നു, അതേസമയം ക്ലോൺ സ്വതന്ത്രമായി നിയന്ത്രിക്കുന്നു. പ്രത്യേക ആവശ്യങ്ങൾ നിറവേറ്റുന്നതിനായി ക്ലോൺ വസ്തുവിന്റെ വിവിധ പെരുമാറ്റങ്ങളോ സ്വഭാവങ്ങളോ വ്യക്തമാക്കാം.
