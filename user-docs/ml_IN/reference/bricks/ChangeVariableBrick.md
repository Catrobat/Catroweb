ഒരു വേരിയബിളിന്റെ നിലവിലെ മൂല്യം ചേർക്കാനോ കുറയ്ക്കാനോ ആഗ്രഹിക്കുന്നുണ്ടോ? ഈ കോഡ് ബ്ലോക്ക് അത് ചെയ്യാൻ അനുവദിക്കുന്നു. അത് പറയുന്നത് പോലെ, “നിനക്ക് അറിയാവുന്നതെല്ലാം എടുത്തു, ഇതിനു ഇത് ചേർക്കുക.”
