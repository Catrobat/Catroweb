ഈ കോഡ് ബ്ലോക്ക്, സ്ക്രീനിന്റെ ഫോക്കസ് പോയിന്റായി ആക്ടർ നിശ്ചയിച്ചിട്ടുള്ള വഴക്കം ദീർഘചക്രത്തിലും ലംബചക്രത്തിലും നിർണ്ണയിക്കുന്നു. അത് ക്യാമറയ്ക്ക് ഒരു കഥാപാത്രത്തെ പിന്തുടരാൻ പറയുമ്പോഴും കേന്ദ്രം ചുറ്റും ചില ചലനങ്ങൾ അനുവദിക്കുന്നതുപോലെയാണ്.
