വസ്തുവിന്റെ ഭാരം കിലോഗ്രാമുകളായി നിർവചിക്കുന്നു, അത് എങ്ങനെ ചലിക്കുകയും മറ്റു വസ്തുക്കളുമായി ഇടപെടുകയും ചെയ്യുന്നു എന്നതിനെ ബാധിക്കുന്നു. ഭാരമുള്ള വസ്തുക്കളെ നീക്കാൻ ബുദ്ധിമുട്ടാണ്, അവരുടെ ദിശ മാറ്റാൻ കൂടുതൽ ശക്തി ആവശ്യമാണ്.
