![പ്ലോട്ടിംഗ് തുടങ്ങുക](../../../media/bricks/Start_to_plot.png)

ഈ കോഡ് ബ്ലോക്ക് നടൻ നീങ്ങുമ്പോൾ പ്ലോട്ട് പ്രക്രിയ ആരംഭിക്കുന്നു. ഒരു രേഖ വരയ്ക്കാൻ തുടങ്ങാൻ പേപ്പറിൽ പേന ഇടുന്നത് പോലെയാണ് ഇത്. നിനക്ക് ഡ്രോയിംഗ് നിർത്തി കളിക്കാരനെ മറ്റൊരു സ്ഥലത്തേക്ക് നീക്കാനും തുടർന്ന് വീണ്ടും “പ്ലോട്ടിംഗ് തുടങ്ങുക” എന്നതിലൂടെ പ്ലോട്ട് ആരംഭിക്കാനും ആഗ്രഹിക്കുന്നെങ്കിൽ “പ്ലോട്ടിംഗ് നിർത്തുക” കോഡ് ബ്ലോക്ക് ഉപയോഗിക്കാം.
