![സുതാര്യത 50%](../../../media/bricks/Set_transparency_to_50_pct_.png)

ഈ കോഡ് ബ്ലോക്ക് ഒരു നടന്റെ സുതാര്യതയെ നിശ്ചയിക്കുന്നു. 0% പൂർണ്ണമായും അപ്രത്യക്ഷവും 100% പൂർണ്ണമായും സുതാര്യവുമാണ്. ഒരു ചിത്രത്തിന്റെ അപ്രത്യക്ഷത ക്രമീകരിക്കുന്നത് പോലെയാണ്.
