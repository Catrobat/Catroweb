പദ്ധതിയിലെ എല്ലാ വസ്തുക്കളിലും ബാധകമായ ഗുരുത്വാകർഷണം ക്രമീകരിക്കുന്നു. അത് ഗുരുത്വാകർഷണത്തിന്റെ പ്രകാരം വസ്തുക്കളെ താഴേക്ക് വലിച്ചിഴക്കുമ്പോള് അല്ലെങ്കിൽ വശത്തേക്ക് വലിച്ചിഴക്കുമ്പോള് , അവ വീഴുന്നതോ ചലിക്കുന്നതോ ആയ രീതിയെ ബാധിക്കുന്നതുപോലെയാണ്.
