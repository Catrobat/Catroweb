ക്ലാസിൽ Pocket Code ഉപയോഗിക്കുന്നതിനെക്കുറിച്ച് അധ്യാപകരും വിദ്യാർത്ഥികളും പറയുന്നതെന്തെന്ന് നോക്കൂ.

::video{youtube=75i10o_uv0U}

ഈ വീഡിയോ കാണിക്കുന്നത് Pocket Code എങ്ങനെ പഠനത്തിന് ഉപയോഗിക്കാമെന്നതിനെക്കുറിച്ചുള്ള നമ്മുടെ സമീപനം. അധ്യാപകനും വിദ്യാർത്ഥികളും പഠന പരിതസ്ഥിതിയിൽ എന്തെല്ലാം ചുമതലകൾ വഹിക്കുന്നു Pocket Code?
