നിന്റെ ഫോണിലോ ടാബ്‌ലെറ്റിലോ ആപ്പ് തുറക്കൂ.

![പ്രധാന സ്ക്രീൻ പുതിയ പദ്ധതി](../../../media/getting-started/MainScreen_NewProject.png)\
പുതിയ പ്രോജക്റ്റ് ഉണ്ടാക്കാൻ + ചിഹ്നത്തിൽ തൊടൂ.\
[ചിത്രം തുറക്കൂ](../../../media/getting-started/MainScreen_NewProject.png)

പ്രോജക്റ്റിന് ഒരു പേര് കൊടുക്കൂ (1). കളിയുടെ സ്‌ക്രീൻ കുത്തനെയാണോ (പോർട്രെയിറ്റ്) കുറുകെയാണോ (ലാൻഡ്‌സ്‌കേപ്പ്) വേണ്ടതെന്ന് തിരഞ്ഞെടുക്കൂ (2).

![പുതിയ പദ്ധതി](../../../media/getting-started/NewProject.png)\
പിന്നെ ശരി ചിഹ്നത്തിൽ തൊട്ട് ഉറപ്പിക്കൂ (3).\
[ചിത്രം തുറക്കൂ](../../../media/getting-started/NewProject.png)

നിങ്ങള് ഇപ്പോൾ നിന്റെ പദ്ധതിയുടെ കാഴ്ചപ്പാടില് . മുകളിൽ, നിന്റെ കളിയുടെ പേര് കാണാം.

താഴെ കാണാവുന്നതാണ് **പശ്ചാത്തലം** - നിലവിൽ, പശ്ചാത്തലം ശൂന്യമാണ്. അത് മാറ്റണമെങ്കിൽ, അതിൽ ടാപ്പുചെയ്യുക.

പശ്ചാത്തലത്തിൽ, നിന്റെ ഗെയിമിലേക്ക് നീ ചേർത്തുവച്ചിരിക്കുന്ന നിന്റെ **അഭിനേതാക്കളും വസ്തുക്കളും** എന്ന പ്രദേശം കാണാം. നിലവിൽ ഈ സ്ഥലം ഇപ്പോഴും ശൂന്യമാണ്.

താഴെ വലതുവശത്ത്, നീ രണ്ടു പ്രധാന ബട്ടണുകൾ കാണുന്നു:

![ആരംഭിക്കുക](../../../media/getting-started/Start.png)\
**പ്ലേ ചെയ്യുക** എന്ന ബട്ടൺ ഉപയോഗിച്ച്, നീ നിന്റെ ഗെയിം ആരംഭിക്കുന്നു.

![പ്ലസ് ബട്ടൺ](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
**കൂടാതെ** ബട്ടൺ ഉപയോഗിച്ച്, നിന്റെ ഗെയിമിലേക്ക് ഒരു പുതിയ കഥാപാത്രം/ഓബ്ജക്ട് ചേർക്കുന്നു.
