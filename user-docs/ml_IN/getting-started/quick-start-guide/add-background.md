നിന്റെ പ്രോജക്റ്റിന് ഒരു പശ്ചാത്തലം Catrobat ൽ ചേർക്കാം.

പശ്ചാത്തലങ്ങളെ പല വിധത്തിലും ഉപയോഗിക്കാം. Pocket Code ൽ അവയെ ദൃശ്യപരമായി മെച്ചപ്പെടുത്തുന്നതിനും **കളികൾ** പറയാൻ **കഥകൾ** അല്ലെങ്കിൽ നിന്റെ അഭിനേതാക്കൾക്കും വസ്തുക്കൾക്കും കൂടുതൽ സന്ദർഭം നൽകുന്നതിനും ഉപയോഗിക്കാം.

**കൂട്ടുകെട്ടുകാർ** അല്ലെങ്കിൽ **തുന്നൽ യന്ത്രങ്ങൾ** പോലുള്ള മേക്കർ സ്പേസ് ഉപകരണങ്ങൾക്ക്, കട്ട് അല്ലെങ്കിൽ എംബ്രോയിഡറി പാറ്റേണുകൾ പോലുള്ള ഡിസൈൻ ടെംപ്ലേറ്റുകളായി പശ്ചാത്തലങ്ങൾ പ്രവർത്തിക്കുന്നു.

ഒരു പശ്ചാത്തലം ചേര് ക്കുന്നതിന്, പ്രോജക്ട് കാഴ്ചയില് “പശ്ചാത്തലം” എന്നതിലേക്ക് ടാപ്പുചെയ്യുക.

![പശ്ചാത്തലത്തെക്കുറിച്ചുള്ള നുറുങ്ങ്](../../../media/getting-started/grafik-16.png)

**സ്ക്രിപ്റ്റ് വിഭാഗം (2)** ൽ നിന്റെ പശ്ചാത്തലം പ്രോഗ്രാം ചെയ്യാവുന്നതാണ് - എന്നിരുന്നാലും, എല്ലാ ബ്ലോക്കുകളും ഇതിനായി ലഭ്യമല്ല. താഴെ പറയുന്ന രണ്ടു ബ്ലോക്കുകൾ പ്രത്യേകിച്ചും പ്രധാനമാണ്ഃ ![സുതാര്യത 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) ഉം ![വലുപ്പം സജ്ജമാക്കുക: 60%](../../../media/bricks/Set_size_to_60_pct_.png)

**കാഴ്ച വകുപ്പ് (1)** ൽ ഒരു പശ്ചാത്തലം ചേർക്കുന്നു. ഇത് ചെയ്യുന്നതിന് + ചിഹ്നം ടാപ്പുചെയ്യുക.

![ഒരു പശ്ചാത്തലം ചേർക്കുക](../../../media/getting-started/grafik-14.png)

നിനക്ക് നിന്റെ സ്വന്തം ചിത്രങ്ങൾ അപ്ലോഡ് ചെയ്യാം, മുൻകൂട്ടി നിശ്ചയിച്ച പശ്ചാത്തലങ്ങൾ ഉപയോഗിക്കാം, അല്ലെങ്കിൽ ഒരു പശ്ചാത്തലം സ്വയം സൃഷ്ടിക്കാം.

**വരയ്ക്കുക**: നിന്റെ സ്വന്തം പശ്ചാത്തലം സൃഷ്ടിക്കാൻ കഴിയും **Pocket Paint**. Pocket Paint ഒരു ഡ്രോയിംഗ് പ്രോഗ്രാം ([കൂടുതൽ വിവരങ്ങൾ Pocket Paint](https://catrobat.org/pocket-paint/))

**രൂപങ്ങൾ**: മുൻകൂട്ടി തയ്യാറാക്കിയ പശ്ചാത്തലങ്ങളുടെ ഒരു ശേഖരത്തിൽ നിന്നും ഒന്ന് തിരഞ്ഞെടുക്കുക ([മീഡിയ ലൈബ്രറി നെ കുറിച്ച് കൂടുതലറിയുക](../elements/medialibrary.md)).

**ഗാലറി**: നിന്റെ സ്മാർട്ട്ഫോണിന്റെ ഗാലറിയിൽ നിന്നും ഒരു ചിത്രം തിരഞ്ഞെടുക്കാം.

**ക്യാമറ**: നിന്റെ ഉപകരണത്തിന്റെ ക്യാമറ ഉപയോഗിച്ച് ഒരു ഫോട്ടോ എടുക്കാനും പശ്ചാത്തലമായി ചേർക്കാനും കഴിയും.

![മീഡിയ ലൈബ്രറിയിൽ നിന്നും തിരഞ്ഞെടുക്കുക](../../../media/getting-started/grafik-17.png)

നിങ്ങള് ക്ക് ഒരു പശ്ചാത്തലം കൂടി നല് കിയിട്ടുണ്ട്. **പദ്ധതി കാഴ്ച** ലേക്ക് മടങ്ങാൻ മുകളിൽ വലതുവശത്തുള്ള പിൻ അമ്പ് ക്ലിക്ക് ചെയ്യുക.
