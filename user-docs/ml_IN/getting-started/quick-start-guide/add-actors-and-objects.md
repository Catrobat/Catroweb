![ഒരു നടൻ ചേർക്കുക](../../../media/getting-started/FigurHinzufuegen.png)\
നിന്റെ പ്രോജക്ടിന് പുതിയ ചിത്രം അല്ലെങ്കിൽ വസ്തു ചേര് ക്കുന്നതിന് പ്ലസ് ബട്ടണില് ടാപ്പുചെയ്യുക.\
[ചിത്രം തുറക്കൂ](../../../media/getting-started/FigurHinzufuegen.png)

Pocket Code ൽ, നിന്റെ പ്രോജക്റ്റിന് ഒരു പ്രതീകമോ വസ്തുവോ ചേർക്കാൻ നിനക്ക് വിവിധ വഴികളുണ്ട്ഃ:

**വരയ്ക്കുക**: നിന്റെ സ്വന്തം കഥാപാത്രം സൃഷ്ടിക്കാൻ കഴിയും **Pocket Paint**. Pocket Paint ഒരു ഡ്രോയിംഗ് പ്രോഗ്രാം ([കൂടുതൽ വിവരങ്ങൾ Pocket Paint](https://catrobat.org/pocket-paint/))

**രൂപങ്ങൾ**: മുൻകൂട്ടി തയ്യാറാക്കിയ അഭിനേതാക്കളും വസ്തുക്കളും ഒരു ശേഖരത്തിൽ നിന്നും ഒന്ന് തിരഞ്ഞെടുക്കുക ([മാധ്യമ ലൈബ്രറി നെ കുറിച്ച് കൂടുതലറിയുക](../elements/medialibrary.md)).

**ഗാലറി**: നിന്റെ സ്മാർട്ട്ഫോണിന്റെ ഗാലറിയിൽ നിന്നും ഒരു ചിത്രം തിരഞ്ഞെടുക്കാം.

**ലൈബ്രറി**: ലൈബ്രറിയില്, ഇതിനകം പ്രോഗ്രാമുചെയ്തിട്ടുള്ള അഭിനേതാക്കളെയും വസ്തുക്കളെയും നിങ്ങള് കണ്ടെത്തും. അതിനർത്ഥം അവയ്ക്ക് ഇതിനകം ഒരു സ്ക്രിപ്റ്റ് ഉണ്ട് എന്നാണ്. നിന്റെ ഗെയിമിൽ റെഡിമെയ്ഡ് എലമെന്റുകൾ ഉപയോഗിക്കാൻ നീ ആഗ്രഹിക്കുന്നുവെങ്കിൽ നിനക്ക് അവ തിരഞ്ഞെടുക്കാം (ഉദാഃ ഒരു ബാക്ക് കൌണ്ട് ([ലൈബ്രറി സംബന്ധിച്ച കൂടുതൽ വിവരങ്ങൾ](../elements/medialibrary.md#മീഡിയ-ലൈബ്രറിയിൽ-നിന്നും-ഒരു-വസ്തു-ചേർക്കുക)).

**ക്യാമറ**: നിന്റെ ഉപകരണത്തിന്റെ ക്യാമറ ഉപയോഗിച്ച് ഒരു ഫോട്ടോ എടുക്കാനും അത് ഒരു പ്രതീകമായി ചേർക്കാനും കഴിയും.

**ബാക്ക്പാക്ക്**: ബാഗ് നിലവിൽ ശൂന്യമാണ്. നിന്റെ ബാഗിൽ സൂക്ഷിച്ചിരിക്കുന്ന അഭിനേതാക്കളോ വസ്തുക്കളോ നിനക്ക് വീണ്ടും ഉപയോഗിക്കാം. സ്ക്രിപ്റ്റ് മുഴുവനും അതിൽ നിന്നും അൺപാക്കേജ് ചെയ്യപ്പെടും ([ബാഗിനെ കുറിച്ച് കൂടുതല് അറിയാന്](../elements/backpack.md)).

**ഉപകരണത്തിലെ കഥാപാത്രങ്ങളും വസ്തുക്കളും**: നിന്റെ പ്രോജക്റ്റിൽ ഉപയോഗിക്കാവുന്ന റെഡിമെയ്ഡ് പ്രതീകങ്ങൾ ഇവിടെ കാണാം. പ്രാദേശിക കളിക്കാരും വസ്തുക്കളും ഒരു ഓഫ് ലൈൻ മീഡിയ ലൈബ്രറിയായി പ്രവർത്തിക്കുന്നു, അതിനർത്ഥം നിനക്ക് ഇന്റർനെറ്റ് കണക്ഷനില്ലെങ്കിലും ഈ കളിക്കാരെ ആക്സസ് ചെയ്യാൻ കഴിയും എന്നാണ്.

**ശൂന്യമായ വസ്തു**: ഒരു ശൂന്യമായ വസ്തു ചേർക്കുക, അത് രൂപമില്ലാത്ത വസ്തുവാണ്. ഈ വസ്തുവിനെ സാധാരണയായി പ്രോഗ്രാം ചെയ്യാം.

**ഉപകരണത്തിലെ പ്രോജക്റ്റുകൾ**: നിന്റെ പ്രോജക്റ്റിലേക്ക് ആദ്യ നടനെ സ്ക്രിപ്റ്റിനൊപ്പം ചേർക്കാൻ ആഗ്രഹിക്കുന്ന ഒരു പ്രോജക്ട് തിരഞ്ഞെടുക്കുക.
