നീ ആരംഭിക്കുമ്പോൾ Pocket Code താഴെ പറയുന്ന പ്രധാന സ്ക്രീൻ കാണാം.

![പ്രധാന സ്ക്രീൻ](../../../media/getting-started/MainScreen-e1732269599192.jpg)

മുകളിൽ വലതുവശത്തെ മൂലയിൽ, ![സഹായം](../../../media/getting-started/Screenshot-2024-11-22-111748.png) എന്ന ചിഹ്നം നിന്നെ Catrobat എന്ന രേഖയിലേക്ക് കൊണ്ടുപോകുന്നു.

അതിനു തൊട്ടടുത്തായി മെനു ![മെനു](../../../media/getting-started/Screenshot-2024-11-22-111804.png). അവിടെ നിന്ന് നിനക്ക് എളുപ്പത്തിൽ ക്രമീകരണങ്ങളിലേക്ക് പോകാം, അവിടെ നിനക്ക് ഭാഷ മാറ്റാനോ പ്ലാറ്റ് ബ്ലോക്കുകൾ പോലുള്ള വിപുലീകരണങ്ങൾ പ്രവർത്തനക്ഷമമാക്കാനോ കഴിയും.

താഴെ, നിന്റെ ഏറ്റവും പുതിയ എഡിറ്റുചെയ്ത പ്രോജക്ട് കാണാം. പ്രോജക്ട് സ്ക്രീനിൽ പ്രവേശിക്കാൻ ![ഐക്കൺ തിരുത്തുക](../../../media/getting-started/Screenshot-2024-11-22-111825.png) എഡിറ്റ് ഐക്കണിൽ ക്ലിക്ക് ചെയ്യുക, അവിടെ നിനക്ക് നിന്റെ പ്രോജക്ട് വികസിപ്പിക്കുന്നത് തുടരാം.

നിന്റെ പ്രോജക്ട് ആരംഭിക്കുന്നതിന് പ്ലേ ബട്ടൺ ![നിന്റെ പ്രോജക്ട് ആരംഭിക്കുക](../../../media/getting-started/Screenshot-2024-11-22-111818.png) ഉപയോഗിക്കുക.

ഒരു ക്ലിക്ക് കൊണ്ട് പ്രോജക്റ്റുകൾ, നിന്റെ സംരക്ഷിച്ച പ്രോജക്റ്റുകളിലേക്ക് പ്രവേശിക്കാം. ![ഉപകരണ പദ്ധതികൾ](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

മറ്റ് ഉപയോക്താക്കളിൽ നിന്നും കൂടുതൽ പദ്ധതികൾ അറിയാനും പ്രവർത്തിക്കാനും നീ ആഗ്രഹിക്കുന്നുവെങ്കിൽ, Catrobat കമ്മ്യൂണിറ്റി ഓൺ ഷെയറിന് ക്ലിക്ക് ചെയ്യുക. അവിടെ നിങ്ങള് ക്ക് ധാരാളം നല്ല പദ്ധതികൾ കാണാം. ![Catrobat സമുദായം](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

പുതിയ ഒരു പ്രോജക്ട് സൃഷ്ടിക്കണമെങ്കിൽ, പ്ലസ് ഐക്കണിൽ ക്ലിക്ക് ചെയ്യുക. ![ചേർക്കുക](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
