Pocket Code ലെ **ബാക്ക്പാക്ക്** സവിശേഷത ഒരു പ്രായോഗിക പ്രവർത്തനമാണ്, അത് നിന്നെ **സംരക്ഷിക്കുകയും വീണ്ടും ഉപയോഗിക്കുകയും ചെയ്യുക** പോലുള്ള അഭിനേതാക്കൾ (ഓബ്ജക്റ്റുകൾ), സ്ക്രിപ്റ്റുകൾ, ലുക്കുകൾ അല്ലെങ്കിൽ ശബ്ദങ്ങൾ **പദ്ധതികളിലുടനീളം** എന്നിവയിലേക്ക് അനുവദിക്കുന്നു. ഇത് നിന്നെ സമയം ലാഭിക്കാനും നിന്റെ പദ്ധതികൾ കൂടുതൽ കാര്യക്ഷമമാക്കാനും സഹായിക്കുന്നു.

നിന്റെ നിലവിലെ പദ്ധതിയുടെ വിവിധ ഘടകങ്ങൾ സൂക്ഷിക്കാൻ കഴിയുന്ന ഒരു ഡിജിറ്റൽ സംഭരണ സ്ഥലമാണ് ബാക്ക്പാക്ക്. ബാഗിൽ സംരക്ഷിച്ചുകഴിഞ്ഞാൽ, ഈ ഘടകങ്ങള് മറ്റ് പ്രോജക്റ്റുകളില് നിന്നും തിരികെ കൊണ്ടുവന്ന് ചേര് ക്കാവുന്നതാണ്.

### അഭിനേതാക്കൾക്കുള്ള (ആബ്ജക്റ്റുകൾക്കായുള്ള) ബാക്ക്പാക്ക് ഞാൻ എങ്ങനെ ഉപയോഗിക്കും?

**ആൾക്കാരുടെ കണക്കുകൾ ബാഗ് കയറ്റുക**

ഒരു ചിത്രം ബാഗ് കയറ്റാൻ ആഗ്രഹിക്കുന്ന പദ്ധതിയുടെ പ്രോജക്ട് കാഴ്ചയിലേക്ക് പോകുക.

കോൺടെക്സ്റ്റ് മെനു തുറക്കുന്നതിന് ചിത്രത്തിന് അടുത്തുള്ള മൂന്നു പോയിന്റുകളിൽ ക്ലിക്ക് ചെയ്ത് “ബാക്ക്പാക്കിൽ ഇടുക” തിരഞ്ഞെടുക്കുക.

ചിത്രം (അതിന്റെ രൂപവും ശബ്ദങ്ങളും സ്ക്രിപ്റ്റുകളും ഉൾപ്പെടെ) ബാഗിൽ പായ്ക്ക് ചെയ്യപ്പെടും.

![പായ്ക്ക് നടൻ](../../../media/getting-started/grafik-7.png)

**ബാഗ് നമ്പറുകളിൽ നിന്ന് കണക്കുകൾ ചേർക്കുക**

നിങ്ങള് ക്ക് ചിത്രം ചേര് ന്ന സ്ഥലത്ത് പദ്ധതി തുറക്കുക.

പ്രോജക്ട് കാഴ്ചയില്, പ്ലസ് ചിഹ്നത്തില് ടാപ്പുചെയ്ത് “ബാക്ക്പാക്ക്” തിരഞ്ഞെടുക്കുക.

നിന്റെ ബാഗിൽ സൂക്ഷിച്ചിരിക്കുന്ന എല്ലാ ചിത്രങ്ങളും വസ്തുക്കളും നീ കാണും. മൂന്നു പോയിന്റുകളില് ടാപ്പുചെയ്ത് “ബാക്ക്പാക്കിൽ നിന്ന് എടുക്കുക” തിരഞ്ഞെടുക്കുക.

![അൺപാക്കേജ് നടൻ](../../../media/getting-started/grafik-8-e1732702791199.png)

***

### സ്ക്രിപ്റ്റുകളില് ഞാന് ആ ബാഗ് എങ്ങനെ ഉപയോഗിക്കും?

**സ്ക്രിപ്റ്റുകൾ ബാഗിൽ വയ്ക്കുക :**

സ്ക്രിപ്റ്റ് അടങ്ങിയിരിക്കുന്ന ചിത്രം കാണുക. സ്ക്രിപ്റ്റ് എഡിറ്ററിൽ ആവശ്യമുള്ള സ്ക്രിപ്റ്റ് അമർത്തിപ്പിടിക്കുക.

സന്ദര് ശ മെനുവിൽ നിന്നും “ബാക്ക്പാക്കിൽ ഇടുക” തിരഞ്ഞെടുക്കുക.

![ബാഗ് ചേർക്കുക](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

സ്ക്രിപ്റ്റിന് ഒരു പേര് നല് കുകയും ശരി എന്ന നമ്പറിൽ സ്ഥിരീകരിക്കുകയും ചെയ്യുക.

![നടിക്ക് ബാഗ് വയ്ക്കാൻ](../../../media/getting-started/grafik-9.png)

സ്ക്രിപ്റ്റ് സംരക്ഷിക്കുകയും മറ്റ് പ്രോജക്ടുകളിലും ഉപയോഗിക്കപ്പെടുകയും ചെയ്യും.

![നിന്റെ ബാക്ക്പാക്ക്](../../../media/getting-started/grafik-10.png)

**ബാഗിൽ നിന്നും സ്ക്രിപ്റ്റുകൾ ചേർക്കുകഃ:**

നിങ്ങള് ക്ക് തിരക്കഥ ചേര് ന്നിരിക്കാന് ആഗ്രഹിക്കുന്ന നടനെ ടാപ്പുചെയ്യുക. നിങ്ങള് ക്ക് സ്ക്രിപ്റ്റ് ഏരിയ കാണാം. സന്ദര് ശ മെനു തുറക്കുന്നതിന് മൂന്ന് പോയിന് റ്റുകളില് ടാപ്പുചെയ്ത് “ബാക്ക്പാക്ക്” ടാപ്പുചെയ്ത് അടിക്കു.

![സ്ക്രിപ്റ്റ് അൺപാക്കേജ് ചെയ്യുക](../../../media/getting-started/grafik-11.png)

നിന്റെ ബാക്ക്പാക്കിൽ ഉള്ള എല്ലാ സ്ക്രിപ്റ്റുകളും ഇപ്പോൾ നിനക്ക് കാണാം. ആവശ്യമുള്ള സ്ക്രിപ്റ്റിന് അടുത്തുള്ള മൂന്നു പോയിന്റുകളില് ടാപ്പുചെയ്ത് സന്ദര് ശ മെനുവിൽ നിന്നും “ബാക്ക്പാക്കിൽ നിന്ന് എടുക്കുക” തിരഞ്ഞെടുക്കുക.

സന്ദര് ശ മെനു വഴി, നിന്റെ ബാക്ക്പാക്കിൽ ഇനി ആവശ്യമില്ലാത്ത സ്ക്രിപ്റ്റുകൾ ഇല്ലാതാക്കാം.

![സ്ക്രിപ്റ്റ് ബാഗ് അൺപാക്കേജ് ചെയ്യുക](../../../media/getting-started/grafik-12.png)

### ബാഗിന്റെ ഗുണങ്ങൾ

- **പദ്ധതികൾക്കിടയിൽ പുനരുപയോഗംഃ:** കണക്കുകൾ, സ്ക്രിപ്റ്റുകൾ, ശബ്ദങ്ങൾ, രൂപങ്ങൾ എന്നിവ ഒരിക്കൽ സൃഷ്ടിക്കുകയും ആവശ്യമുള്ളത്ര തവണ വീണ്ടും ഉപയോഗിക്കുകയും ചെയ്യാം.
- **സമയം ലാഭിക്കുക:** ഓരോ തവണയും നീ പുതിയതായി കണക്കുകളോ സ്ക്രിപ്റ്റുകളോ സൃഷ്ടിക്കേണ്ടതില്ല.
- **സ്ഥിരതഃ:** ഒന്നിലധികം പദ്ധതികളില് അവ ആവശ്യമുള്ളപ്പോൾ ഘടകങ്ങള് സ്ഥിരതയുള്ളതായി തുടരുന്നു.
