Pocket Code ആണ് Catrobat ന്റെ പ്രധാന ആപ്പ്. ഇത് സൗജന്യമാണ്. ഇതിന്റെ സോഴ്‌സ് കോഡ് ആർക്കും കാണാം. നിന്റെ ഫോണിലോ ടാബ്‌ലെറ്റിലോ കളികളും അനിമേഷനുകളും നീ ഇടപെടുന്ന കഥകളും ഉണ്ടാക്കാം. Pocket Code ൽ **ബ്ലോക്കുകൾ ചേർത്താണ് കോഡ് ഉണ്ടാക്കുന്നത്**. ഒരു പസിലിന്റെ കഷണങ്ങൾ ചേർക്കുന്നതുപോലെ കോഡ് ബ്ലോക്കുകൾ ചേർത്ത് പ്രോജക്റ്റ് ഉണ്ടാക്കൂ. തുടങ്ങാൻ നേരത്തേ പ്രോഗ്രാമിങ് അറിഞ്ഞിരിക്കേണ്ട!

Pocket Code ഡിജിറ്റൽ പദ്ധതികളെക്കാളും കൂടുതലാണ്. പുതിയ **മേക്കര് സ്പേസ് സവിശേഷതകൾ** ഉപയോഗിച്ച് നിനക്ക് ഡിസൈൻ ചെയ്യാനും കഴിയും **SVG കട്ടിംഗ് പ്ലാറ്റ്മെന്റുകൾക്കുള്ള ഫയലുകൾ**. അതിനർത്ഥം നിന്റെ ഡിജിറ്റൽ സൃഷ്ടികളെ യഥാർത്ഥ ലോകത്തിലെ വസ്തുക്കളാക്കി മാറ്റാനും സ്ക്രീനിന് പുറത്ത് സൃഷ്ടിപരമായ സാധ്യതകൾ പര്യവേക്ഷണം ചെയ്യാനും കഴിയും എന്നാണ്.

നീ കോഡ് പഠിക്കുന്നതായാലും പുതിയ ആശയങ്ങൾ പരീക്ഷിക്കുന്നതായാലും പ്രോഗ്രാമിങ് പഠിപ്പിക്കുന്നതായാലും Pocket Code കോഡിംഗിൽ മുഴുകാനുള്ള കളിയായതും ആക്സസ് ചെയ്യാവുന്നതുമായ ഒരു മാർഗം നൽകുന്നു
