കഥ തുടങ്ങുമ്പോൾ ഓരോ ചലനവും പേന ഉപയോഗിച്ച് വരച്ച പോലെ. ഈ വരികൾ പിന്നീട് ആ തന്ത്രവാദി മുറിച്ചു.

ഈ കുറുക്കൻ വെറും നേരായ വരിയിൽ “നീങ്ങുക: \_\_\_ ചുവടുകൾ” തിരിഞ്ഞു കൊണ്ടാണ് നിർമ്മിച്ചിരിക്കുന്നത്.

**നുറുങ്ങ്**: നീ പ്രോഗ്രാം നിർമ്മിക്കുന്നതിനിടയില് നിന്റെ പ്രോഗ്രാം പരീക്ഷിക്കുക.
