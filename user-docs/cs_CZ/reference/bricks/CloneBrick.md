Tento blok vytvoří kopii určeného objektu, které se říká klon. Klon se chová jako originál. Představ si, že zdvojíš postavu nebo objekt ve své hře. Klon může mít vlastní chování a skripty, takže můžeš vytvořit více kopií objektu, které budou jednat samostatně.
