Tento blok změní barvu pera, kterým postava kreslí. Je to jako když při kreslení přepneš na pero jiné barvy.

**Červená, zelená, modrá (RGB)**: Model barev RGB používá různou intenzitu červeného, zeleného a modrého světla, aby vytvořil širokou škálu barev. Každá složka barvy (červená, zelená a modrá) může mít hodnotu od 0 do 255:

- **Červená**: Červená složka barvy. Vyšší hodnota znamená víc červené.
- **Zelená**: Zelená složka barvy. Vyšší hodnota znamená víc zelené.
- **Modrá**: Modrá složka barvy. Vyšší hodnota znamená víc modré.

Kombinací různých hodnot červené, zelené a modré můžeš vytvořit jakoukoli barvu. Například:

- `RGB(255, 0, 0)` je čistě červená.
- `RGB(0, 255, 0)` je čistě zelená.
- `RGB(0, 0, 255)` je čistě modrá.
- `RGB(255, 255, 255)` je bílá (maximum červené, zelené a modré).
- `RGB(0, 0, 0)` je černá (žádná barva).

Míšením těchto barev v různém poměru vzniknou všechny barvy, které vidíš na digitálních obrazovkách.
