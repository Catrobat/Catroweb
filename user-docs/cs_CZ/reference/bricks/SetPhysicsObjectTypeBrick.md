![Nastav svůj typ pohybu na](../../../media/bricks/set_your_motion_type_brick.png)

Změní způsob, jakým se objekt pohybuje. Může se pohybovat a odrážet se vlivem gravitace, nebo se nepohybovat vlivem gravitace, ale ostatní se od něj mohou odrážet, případně se nemusí pohybovat ani odrážet vlivem gravitace. Je to jako když vybíráš, jak se má tvoje postava chovat při pohybu a při styku s ostatními objekty.
