Nastaví, jak velké tření působí na objekt. To ovlivňuje, jak snadno klouže nebo jak rychle zpomaluje. Je to jako když měníš, jak kluzký je povrch, po kterém tvoje postava chodí. Čím větší tření, tím méně klouže.
