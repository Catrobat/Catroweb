Tento blok zastaví určitý zvuk, který hraje. Je to jako když stiskneš stop jen u jedné písničky, zatímco ostatní zvuky nebo hudba hrají dál. Představ si, že řekneš své postavě, aby přestala přehrávat jednu konkrétní stopu.
