Dá vytvořenému klonu objektu pokyny, aby provedl požadované akce. Tento postup umožňuje zopakovat funkce původního objektu a zároveň klon ovládat samostatně. Chování nebo vlastnosti klonu můžeš nastavit tak, aby odpovídaly tvým požadavkům.
