![Pokud je pravda, pak … Jinak](../../../media/bricks/if_else_brick2.png)

*Zkontroluje, jestli je podmínka pravdivá. Pokud ano, provede jednu sadu příkazů. Pokud ne, provede jinou sadu. Je to jako když nabídneš dvě možnosti: „Když je tohle pravda, udělej tohle, jinak udělej tamto.“*

![Jeviště se spustí](../../../media/bricks/StartScene.png)

Když se scéna spustí, proměnná X se nastaví na 0.

![Pokud … Jinak](../../../media/bricks/IfElse.png)

Když se na zvíře teď klepne, zkontroluje se, jestli je X modulo 2 pravda, tedy jestli je X liché číslo.
Pokud ano, přehraje se zvuk Tweet1 a proměnná X se zvýší o 1.
Jinak, pokud je X sudé, zvýší se jen X o 1.
Příkazy, které se mají provést, jsou ukončeny blokem Konec podmínky.
