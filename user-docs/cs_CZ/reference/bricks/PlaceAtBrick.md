![Umísti na x: y:](../../../media/bricks/place_at_x_y_brick.png)

Přesune objekt na určité místo na obrazovce, které je dané souřadnicemi x a y. Je to jako když svou postavu přeneseš přesně na určené místo.

Pozice se zadává v souřadnicovém systému podobném kartézské rovině: osy x a y procházejí středem obrazovky, takže x = 0 a y = 0 je uprostřed obrazovky.
