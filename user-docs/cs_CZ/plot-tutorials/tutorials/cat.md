Když se plot spustí, každý pohyb se kreslí jako tužkou. Tyto čáry plotr později vyřízne.

Náš objekt míří ve směru 150 stupňů.

V tomto návodu se nejdřív udělá pravá strana kočičí hlavy. Když se podíváš pozorně, na začátku je křivka silná, takže se musí objekt po každé malé čáře víc otočit. Pak se zatáčky pro spodní část hlavy zmenšují. Levá strana hlavy je zase silně zakřivená. Proto tato část hlavy používá celkem tři smyčky.

Následuje levé ucho. Skládá se jen z přímých čar, takže můžeme použít blok „Posuň se o ___ kroků“.

Část mezi ušima je zase oblouk a naprogramuje se další smyčkou.

Pak se udělá pravé ucho.

Kresba je hotová. Ukonči ji blokem „Přestaň kreslit plotrem“ a ulož ji do telefonu blokem „Ulož kresbu plotru jako SVG ___“.

Soubor SVG teď můžeš poslat do (řezacího) plotru.
