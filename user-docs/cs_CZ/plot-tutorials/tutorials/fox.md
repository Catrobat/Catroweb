Když se plot spustí, každý pohyb se kreslí jako tužkou. Tyto čáry plotr později vyřízne.

Tato liška se skládá jen z přímých čar („Posuň se o ___ kroků“) a otáčení.

**Tip**: Svůj program zkoušej průběžně, jak ho stavíš.
