[Květina (PDF, německy)](../../../media/plot-tutorials/Blume.pdf)

Když se plot spustí, každý pohyb se kreslí jako tužkou. Tyto čáry plotr později vyřízne.

Tato květina má 7 okvětních lístků. Každý lístek je oblouk: nakreslíš malou čárku, otočíš se, nakreslíš další malou čárku a zase se otočíš (podívej se na smyčku „Opakuj 10krát“ – „Posuň se o 10 kroků“ – „Otoč se doprava o 16 stupňů“).

Než začne další lístek, musíš se ještě jednou otočit.
