[Hvězda (PDF, německy)](../../../media/plot-tutorials/Stern.pdf)

Když se plot spustí, každý pohyb se kreslí jako tužkou. Tyto čáry plotr později vyřízne.

Tato hvězda má 6 cípů. Cíp je přímá čára („Posuň se o 100 kroků“), otočení a další přímá čára, která dokončí tvar cípu. Před dalším cípem se musíš otočit opačným směrem, aby další cíp vyšel správně.

***Poznámka**: Celý kruh má 360°. Na každý cíp se otočíme o 100° doprava a 40° doleva, to je celkem 60° doprava.*

*Pro všech šest cípů dostaneme otočení o 360° doprava.*

**Jdi dál**: Zkus různé kombinace otočení a změň počet cípů.
