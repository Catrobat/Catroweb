[Otevři PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Instalace Pocket Code

Nejdřív musíš aplikaci Pocket Code nainstalovat do svého zařízení. Pro tento krok potřebuješ účet Google. Pak zařízení aplikaci stáhne a nainstaluje. Podle rychlosti internetu to může chvíli trvat.

![Nový program (2)](../../../media/game-tutorials/New-Program-2.png)\
Najdeš ji tak, že v Google Play Store vyhledáš „Pocket Code“, a stáhneš ji klepnutím na „Instalovat“.\
[Otevři obrázek](../../../media/game-tutorials/New-Program-2.png)

Až se Pocket Code stáhne a nainstaluje, najdeš ji v seznamu aplikací nebo na domovské obrazovce, podle typu zařízení. Aplikaci můžeš snadno přesunout, kam chceš.

### 3. Vytvoření nového projektu

Dalším krokem je vytvořit nový projekt. Teď musíš zadat název projektu a vybrat, jestli má být projekt na šířku, nebo ne. Stiskem „OK“ se projekt vytvoří.

![Nový program](../../../media/game-tutorials/New-Program.png)\
Stiskni žluté tlačítko plus vpravo dole.\
[Otevři obrázek](../../../media/game-tutorials/New-Program.png)

### 4. Hotovo! Vytvořil jsi svůj nový projekt.

Teď máš nainstalovaný Pocket Code a víš, jak vytvořit nový projekt. Můžeš začít programovat!

K tomu potřebuješ vědět, jak v projektu vytvořit nový objekt. Podívej se na návod **[Nový objekt](new-object.md)**, kde je všechno krok za krokem vysvětleno.
