Pocket Code je aplikace pro vizuální programování. Ve svém chytrém telefonu nebo tabletu v ní vytvoříš hry, animace a interaktivní příběhy. Pomocí přetahování „cihliček“ (bloků s kódem) navrhneš projekt bez předchozích znalostí programování. Snadno přidáš zvuky, obrázky a pohyb, aby tvoje nápady ožily.

Tento průvodce ti ukáže, jak:

- se orientovat v aplikaci,
- vytvořit první projekt,
- pracovat s objekty a pozadími,
- použít bloky k naprogramování akcí a
- uložit svůj projekt.

Pocket Code je ideální pro začátečníky i učitele. Podporuje kreativitu, řešení problémů a logické myšlení.
