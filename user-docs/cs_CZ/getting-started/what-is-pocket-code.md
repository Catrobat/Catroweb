Pocket Code je hlavní aplikace Catrobatu. Je to volně dostupná a open-source mobilní aplikace, ve které můžeš vytvářet hry, animace a interaktivní příběhy přímo v chytrém telefonu nebo tabletu. Pomocí **blokového programování** v Pocket Code skládáš projekt z programovacích bloků. Je to jako skládání puzzle. Programovat neumíš? Nevadí, je to ideální pro začátečníky!

Pocket Code umí víc než jen digitální projekty. S novými **funkcemi pro dílny** můžeš navrhovat i **soubory SVG pro řezací plotry**. Své digitální výtvory tak můžeš proměnit ve skutečné věci a objevovat tvůrčí možnosti i mimo obrazovku.

Ať se učíš programovat, zkoušíš nové nápady, nebo učíš ostatní, Pocket Code ti nabídne hravý a snadný způsob, jak do programování proniknout.

[Více informací](https://catrobat.org/pocket-code/)
