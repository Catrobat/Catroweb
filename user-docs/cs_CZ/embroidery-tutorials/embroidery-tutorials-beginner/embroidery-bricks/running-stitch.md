Nechá stroj šít nepřetržitě s proměnlivou délkou.

Přední steh obvykle kombinuješ s blokem pohybu.

![Začni přední steh s délkou 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Stroj začne přední steh, který vyšije každých **10 kroků**.

Pak se stroj posune o **200 kroků**.

Výsledkem je **20 stehů**.

![Přední steh](../../../../media/embroidery-tutorials/RunningStitch.png)

Přední steh usnadňuje vyšívání švu, protože už nepotřebuješ smyčku.
