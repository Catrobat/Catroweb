Trojitý steh prošije každý steh třikrát.

Trojitý steh se po prvním stehu vrátí zpět, zašije, pak se zase vrátí dopředu a zašije znovu.

![Začni trojitý steh s délkou 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Funguje stejně jako [přední steh](running-stitch.md).

![Trojitý steh](../../../../media/embroidery-tutorials/TripleStitch.png)

Tím šev vydrží déle.
