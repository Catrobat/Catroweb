Šije nepřetržitě s proměnlivou délkou a šířkou.

Šije ve tvaru „cik-cak“.

![Začni klikatý steh s délkou 2 a šířkou 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)

![Klikatý steh](../../../../media/embroidery-tutorials/ZigzagStitch.png)
