ఈ ట్యుటోరియల్లో, నువ్వు మీ మొదటి ప్రాజెక్ట్ను సృష్టించడం ప్రారంభించడానికి Pocket Code గురించి తెలుసుకోవలసిన ప్రతిదాన్ని నేర్చుకుంటారు. అప్లికేషన్ను డౌన్లోడ్ చేయడం, దాన్ని తెరవడం మరియు కొత్త ప్రాజెక్ట్ను సృష్టించడం ఎలాగో మేము నీకు దశల వారీగా మార్గనిర్దేశం చేస్తాము.

![కొత్త కార్యక్రమం](../../../media/game-tutorials/New-Program.png)

ఇది మొదటి ట్యుటోరియల్, మరియు నువ్వు ముందుగా ఏ జ్ఞానం అవసరం లేదు.

కాబట్టి, నువ్వు ఏమి కోసం వేచి ఉన్నాయి? మీ ఫోన్ తీసుకొని మరియు ఇప్పుడు ప్రారంభించండి!

*ఇక్కడ నువ్వు PDF ఫార్మాట్ లో ట్యుటోరియల్ డౌన్లోడ్ చేసుకోవచ్చుః:*

[కొత్త కార్యక్రమం](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code యొక్క సంస్థాపన

మొదట, నువ్వు మీ పరికరంలో Pocket Code అనువర్తనాన్ని ఇన్స్టాల్ చేయాలి. నువ్వు Google Play Store లో “Pocket Code” ను శోధించడం ద్వారా అనువర్తనాన్ని కనుగొనవచ్చు మరియు “ఇన్స్టాల్” నొక్కడం ద్వారా దాన్ని డౌన్లోడ్ చేసుకోవచ్చు. ఈ దశకు గూగుల్ ఖాతా అవసరం. ఇప్పుడు మీ పరికరం అప్లికేషన్ను డౌన్లోడ్ చేసి ఇన్స్టాల్ చేస్తుంది. మీ ఇంటర్నెట్ కనెక్షన్ ప్రకారం ఈ దశ కొంత సమయం పట్టవచ్చు.

![కొత్త కార్యక్రమం (2)](../../../media/game-tutorials/New-Program-2.png)

నువ్వు విజయవంతంగా డౌన్లోడ్ చేసి, ఇన్స్టాల్ చేసిన తర్వాత Pocket Code మీ పరికరానికి అనుగుణంగా అనువర్తనం డ్రాయర్లో లేదా మీ హోమ్ స్క్రీన్పై కనుగొనవచ్చు. నువ్వు సులభంగా అనువర్తనాన్ని తీసుకొని నీకు నచ్చిన చోట ఉంచవచ్చు.

### 2. యాప్ ప్రారంభించండి

నువ్వు అనువర్తనాన్ని తెరిచినప్పుడు, నువ్వు వివిధ వర్గాలను చూస్తారుః:

![కొత్త కార్యక్రమం (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. కొత్త ప్రాజెక్టును సృష్టించండి

తదుపరి దశలో ఒక కొత్త ప్రాజెక్టును సృష్టించడం. అలా చేయడానికి, నువ్వు కుడి దిగువ మూలలో ఉన్న పసుపు ప్లస్ బటన్ నొక్కవచ్చు. ఇప్పుడు నువ్వు ఒక ప్రాజెక్ట్ పేరును నమోదు చేసి, మీ ప్రాజెక్ట్ ప్రకృతి దృశ్యం కాదా అని ఎంచుకోవాలి. “సరే” నొక్కడం ద్వారా ప్రాజెక్ట్ సృష్టించబడుతుంది.

![కొత్త కార్యక్రమం](../../../media/game-tutorials/New-Program.png)

### 4. నువ్వు మీ సొంత కొత్త ప్రాజెక్ట్ సృష్టించారు.

ఇప్పుడు నువ్వు Pocket Code ను ఇన్స్టాల్ చేసి, కొత్త ప్రాజెక్ట్ను ఎలా సృష్టించాలో తెలుసు. ఇప్పుడు నువ్వు ప్రోగ్రామింగ్ ప్రారంభించవచ్చు!

ఇది చేయటానికి, నువ్వు ఒక ప్రాజెక్ట్ లో కొత్త వస్తువును సృష్టించడానికి ఎలా తెలుసుకోవాలి. **[కొత్త వస్తువు](new-object.md)** - ట్యుటోరియల్ చూడండి, ఇక్కడ నీకు ప్రతిదీ దశల వారీగా వివరించబడుతుంది.
