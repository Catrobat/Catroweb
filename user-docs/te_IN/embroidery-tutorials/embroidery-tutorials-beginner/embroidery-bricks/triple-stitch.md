ట్రిపుల్ కుట్టు ప్రతి కుట్టు మూడు సార్లు కుట్టు.

ముగ్గురు కుట్టు మొదటి కుట్టు తరువాత తిరిగి దూకడం, కుట్లు, అప్పుడు మళ్ళీ ముందుకు దూకడం మరియు మళ్ళీ కుట్లు.

![ఈ పొడవుతో ట్రిపుల్ స్టిచ్ ప్రారంభించు: 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

[నడుస్తున్న కుట్టు](running-stitch.md) తో సమానంగా పనిచేస్తుంది.

![ఈ పొడవుతో ట్రిపుల్ స్టిచ్ ప్రారంభించు:](../../../../media/embroidery-tutorials/TripleStitch.png)

ఇది కుట్టు ఎక్కువ కాలం ఉంటుంది.
