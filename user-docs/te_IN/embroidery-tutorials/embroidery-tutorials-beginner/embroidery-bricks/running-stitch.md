యంత్రం నిరంతరం వేరియబుల్ పొడవు తో కుట్టు అనుమతిస్తుంది.

సాధారణంగా నువ్వు ఒక కదిలే కోడ్ బ్లాక్ తో నడుస్తున్న కుట్టు కలపాలి.

![ఈ పొడవుతో రన్నింగ్ స్టిచ్ ప్రారంభించు: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

యంత్రం నడుస్తున్న కుట్టు ప్రారంభిస్తుంది ఇది ప్రతి **10 దశలు** కుట్టు ఉంటుంది.

అప్పుడు యంత్రం కదులుతుంది **200 దశలు**.

దీని ఫలితంగా **20 కుట్లు**.

![ఈ పొడవుతో రన్నింగ్ స్టిచ్ ప్రారంభించు:](../../../../media/embroidery-tutorials/RunningStitch.png)

నడుస్తున్న కుట్టు ఒక కుట్టు కుట్టు సులభం చేస్తుంది ఎందుకంటే నువ్వు ఇకపై ఒక ముక్క అవసరం లేదు.
