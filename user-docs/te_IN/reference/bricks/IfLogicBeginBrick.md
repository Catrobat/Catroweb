![లేకపోతే కోడ్ బ్లాక్](../../../media/bricks/if_else_brick2.png)

*ఒక పరిస్థితి నిజమా అని తనిఖీ చేసి, అది నిజమైతే ఒక సూచన సమితిని, లేకపోతే మరొక సూచన సమితిని అమలు చేస్తుంది. ఇది రెండు ఎంపికలను ఇవ్వడం లాంటిదిః “ఇది నిజమైతే, ఇలా చేయండి; లేకపోతే, అలా చేయి.”*

![దృశ్యాన్ని ప్రారంభించు:](../../../media/bricks/StartScene.png)

ఈ దృశ్యం ప్రారంభమైనప్పుడు, వేరియబుల్ X 0 కు సెట్ చేయబడుతుంది.

![ఇతర](../../../media/bricks/IfElse.png)

జంతువు ఇప్పుడు ట్యాప్ చేయబడితే, X మోడ్యూల్ 2 నిజమా అని తనిఖీ చేయాలి, అంటే X అనేది ఒక జంట సంఖ్య.

ఈ సందర్భంలో, ధ్వని Tweet1 ప్లే చేయబడుతుంది మరియు వేరియబుల్ X 1 ద్వారా పెంచబడుతుంది.

లేకపోతే, X సమానంగా ఉంటే, మాత్రమే X 1 ద్వారా పెంచబడుతుంది.

అమలు చేయవలసిన ప్రకటనలు ఒకవేళ ముగింపు ద్వారా వేరు చేయబడతాయి.
