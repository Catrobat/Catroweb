![ఇక్కడికి వెళ్లు:](../../../media/bricks/go_to_brick2.png)

వెంటనే వస్తువును మరొక వస్తువు యొక్క స్థానానికి లేదా యాదృచ్ఛిక స్థానంకు తరలించబడుతుంది. ఇది చెప్పడం వంటి ఆలోచించండి, “ఈ ఇతర పాత్ర ఎక్కడ వెళ్ళండి” లేదా “ఒక యాదృచ్ఛిక స్థలం వెళ్ళండి.”
