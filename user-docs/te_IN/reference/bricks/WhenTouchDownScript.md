![వేదికను నొక్కినప్పుడు](../../../media/bricks/When_stage_is_tapped_btn.png)

స్క్రీన్ తాకినప్పుడు స్క్రిప్ట్ నడుస్తుంది.

బ్లాక్ *“నొక్కినప్పుడు”* లోని తేడా ఏమిటంటే, మొత్తం స్క్రీన్కు *“వేదికను నొక్కినప్పుడు”* వర్తిస్తుంది, అయితే *“నొక్కినప్పుడు”* వ్యక్తిగత స్ప్రిట్స్ లేదా వస్తువులకు ప్రత్యేకమైనది.
