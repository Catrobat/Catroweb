*ఒక పరిస్థితి నిజమా అని తనిఖీ చేస్తుంది, మరియు అది నిజమైతే సూచనల సమితిని అమలు చేస్తుంది. ఇది ఇలా చెప్పడం లాంటిది, “ఇది నిజం అయితే, అప్పుడు ఈ చేయి.”*

![దృశ్యాన్ని ప్రారంభించు:](../../../media/bricks/StartScene.png)

ఈ దృశ్యం ప్రారంభమైనప్పుడు, వేరియబుల్ X 0 కు సెట్ చేయబడుతుంది.

![ఒకవేళ](../../../media/bricks/If.png)

జంతువు ఇప్పుడు ట్యాప్ చేస్తే, వేరియబుల్ X 1 పెరిగింది.

ప్రోగ్రామ్ వేరియబుల్ X విలువ 2 కి సమానం కాదా అని తనిఖీ చేస్తుంది.

ఈ సందర్భంలో, ధ్వని Tweet1 ప్లే చేయబడుతుంది మరియు వేరియబుల్ X 0 కు సెట్ చేయబడుతుంది.
