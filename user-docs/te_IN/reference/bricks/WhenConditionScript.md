*పేర్కొన్న విలువ లేదా ఫంక్షన్ నిజమైన అయ్యే వరకు వేచి ఉంటుంది, ఆపై స్క్రిప్ట్ను అమలు చేస్తుంది.*

![దృశ్యాన్ని ప్రారంభించు:](../../../media/bricks/StartScene.png)

ఈ దృశ్యం ప్రారంభమైనప్పుడు, వేరియబుల్ X 0 కు సెట్ చేయబడుతుంది.

![నొక్కినప్పుడు మోడూలో](../../../media/bricks/WhenTappedWhenModulo.png)

జంతువు ఇప్పుడు కొట్టబడితే, X 1 పెరిగింది.

X modulo 2 నిజమైతే, అంటే X ఒక అసంఖ్యాక సంఖ్య అయితే, Tweet1 ధ్వని వినిపిస్తుంది.
