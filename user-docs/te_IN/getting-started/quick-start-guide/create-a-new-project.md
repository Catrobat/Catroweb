నీ ఫోన్ లేదా ట్యాబ్లెట్‌లో యాప్ తెరువు. కొత్త ప్రాజెక్టు కోసం + గుర్తును నొక్కు.

![ప్రధాన తెర కొత్త ప్రాజెక్ట్](../../../media/getting-started/MainScreen_NewProject.png)

ప్రాజెక్టుకు పేరు పెట్టు (1). ఆట తెర నిలువుగా (పోర్ట్రెయిట్) ఉండాలా, అడ్డంగా (ల్యాండ్‌స్కేప్) ఉండాలా ఎంచుకో (2). తర్వాత నిర్ధారించడానికి సరైన గుర్తును నొక్కు (3).

![కొత్త ప్రాజెక్టు](../../../media/getting-started/NewProject.png)

నువ్వు ఇప్పుడు మీ ప్రాజెక్ట్ వీక్షణలో ఉన్నారు. పైన, నువ్వు మీ ఆట పేరు చూస్తారు.

క్రింద నువ్వు **నేపథ్యం** చూడవచ్చు - ప్రస్తుతం, నేపథ్యం ఖాళీగా ఉంది. నువ్వు మార్చడానికి అనుకుంటే, దానిపై నొక్కు.

నేపథ్యంలో, నువ్వు మీ ఆటకు జోడించిన మీ **నటులు మరియు వస్తువులు** కోసం ప్రాంతాన్ని చూస్తారు. ప్రస్తుతం, ఈ ప్రాంతం ఇంకా ఖాళీగా ఉంది.

కుడి దిగువన, నువ్వు రెండు ముఖ్యమైన బటన్లు చూస్తారుః:

![ప్రారంభించండి](../../../media/getting-started/Start.png) నువ్వు మీ ఆట ప్రారంభించడానికి **ప్లే చేయి** బటన్ తో.

![ప్లస్ బటన్](../../../media/getting-started/Screenshot-2024-11-22-143219.png) నువ్వు **ప్లస్** బటన్తో మీ ఆటకు కొత్త పాత్ర/ఆబ్జెక్ట్ను జోడిస్తారు.

![ప్రాజెక్ట్ స్క్రీన్](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
