Pocket Code అనేది Catrobat ప్రధాన యాప్. ఇది ఉచితం. దీని సోర్స్ కోడ్ అందరికీ అందుబాటులో ఉంటుంది. నీ ఫోన్ లేదా ట్యాబ్లెట్‌లోనే ఆటలు, యానిమేషన్లు, నువ్వు పాల్గొనగల కథలు తయారు చేయవచ్చు. Pocket Code లో **బ్లాక్‌లతో కోడ్ తయారు చేస్తావు**. పజిల్ ముక్కలను కలిపినట్టు కోడ్ బ్లాక్‌లను కలిపి నీ ప్రాజెక్టు తయారు చేయి. మొదలుపెట్టడానికి ముందే ప్రోగ్రామింగ్ వచ్చి ఉండాల్సిన పని లేదు!

Pocket Code కేవలం డిజిటల్ ప్రాజెక్టుల కంటే మించి ఉంటుంది. కొత్త **మేకర్స్పేస్ లక్షణాలు** తో నువ్వు కూడా డిజైన్ చేయవచ్చు **SVG కట్టింగ్ ప్లాటర్ల కోసం ఫైళ్లు**. దీని అర్థం నువ్వు మీ డిజిటల్ సృష్టిని వాస్తవ ప్రపంచ వస్తువులుగా మార్చవచ్చు మరియు స్క్రీన్ వెలుపల సృజనాత్మక అవకాశాలను అన్వేషించవచ్చు.

నువ్వు కోడ్ నేర్చుకోవడం, కొత్త ఆలోచనలతో ప్రయోగాలు చేయడం లేదా ప్రోగ్రామింగ్ బోధించడం అయినా, Pocket Code కోడింగ్లో మునిగిపోయేందుకు ఒక సరదాగా, అందుబాటులో ఉన్న మార్గాన్ని అందిస్తుంది
