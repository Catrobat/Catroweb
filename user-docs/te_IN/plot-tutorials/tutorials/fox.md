కథ ప్రారంభమైనప్పుడు, ప్రతి కదలికను ఒక పెన్తో లాగా చిత్రీకరించారు. ఈ పంక్తులు తరువాత ప్లాట్లు కట్ పాటు.

ఈ కోతి కేవలం సరళ రేఖలు (“కదులు: \_\_\_ అడుగులు”) మరియు మలుపులు మాత్రమే తయారు చేయబడింది.

**చిట్కా**: నువ్వు దానిని నిర్మించేటప్పుడు మీ ప్రోగ్రామ్ను పరీక్షించండి.
