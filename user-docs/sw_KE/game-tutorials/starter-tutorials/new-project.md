Katika mafunzo haya, utajifunza kila kitu unahitaji kujua kuhusu Pocket Code kuanza kujenga mradi wako wa kwanza. Tutakuongoza hatua kwa hatua jinsi ya kupakua programu, kuifungua, na kuunda mradi mpya.

![Programu Mpya](../../../media/game-tutorials/New-Program.png)\
Tutakuongoza hatua kwa hatua jinsi ya kupakua programu, kuifungua, na kuunda mradi mpya.\
[Fungua picha](../../../media/game-tutorials/New-Program.png)

Hii ni mafunzo ya kwanza kabisa, na huna haja ya ujuzi wowote wa awali.

Basi, unangojea nini? Chukua simu yako na kuanza sasa!

*Hapa unaweza kupakua mafunzo katika PDF-format:*

[Fungua PDF](../../../media/game-tutorials/New-Program.pdf)

### 1. Kuweka Pocket Code

Kwanza, unahitaji kusakinisha programu Pocket Code kwenye kifaa chako. Kwa hatua hii inahitajika Akaunti ya Google. Sasa kifaa chako kitapakua na kusakinisha programu. Huenda hatua hiyo ikachukua muda kulingana na uhusiano wako wa Intaneti.

![Programu Mpya (2)](../../../media/game-tutorials/New-Program-2.png)\
Unaweza kupata programu kwa kutafuta “Pocket Code” katika Google Play Store na kupakua kwa kupiga “kufunga”.\
[Fungua picha](../../../media/game-tutorials/New-Program-2.png)

Baada ya kupakua na kusakinisha Pocket Code unaweza kupata programu katika sanduku la programu au kwenye skrini yako ya nyumbani, kulingana na kifaa chako. Unaweza kuchukua programu hiyo na kuiweka popote unapotaka.

### 2. Anza Programu

![Programu Mpya (1)](../../../media/game-tutorials/New-Program-1.png)\
Unapofungua programu, unaona vikundi tofauti.\

### 3. Unda Mradi Mpya

Hatua inayofuata ni kuunda mradi mpya. Sasa una kuingia jina la mradi na kuchagua kama mradi wako lazima mazingira au si. Kwa kubonyeza “Sawa” mradi huundwa.

![Programu Mpya](../../../media/game-tutorials/New-Program.png)\
Ili kufanya hivyo, unaweza bonyeza kwenye kifungo cha manjano zaidi kwenye kona ya chini kulia.\
[Fungua picha](../../../media/game-tutorials/New-Program.png)

### 4. Umefanikiwa, umeunda mradi wako mpya.

Sasa umeweka Pocket Code na kujua jinsi ya kujenga mradi mpya. Sasa unaweza kuanza programu!

Ili kufanya hivyo, unahitaji kujua jinsi ya kujenga kitu kipya katika mradi. Angalia mafunzo ya **[Kitu Kipya](new-object.md)** ambapo kila kitu kinaelezwa hatua kwa hatua.
