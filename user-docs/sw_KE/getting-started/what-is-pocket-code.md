Pocket Code ni programu kuu kutoka Catrobat, programu ya bure na ya chanzo wazi ambayo hukuruhusu kuunda michezo, michoro, na hadithi za maingiliano kwenye smartphone au kompyuta kibao yako. Kwa **mfumo wa coding msingi block** katika Pocket Code, unaweza kujenga miradi kwa snap pamoja blocks code - kama kuweka pamoja vipande vya puzzle. Hakuna ujuzi wa programu unaohitajika, na hivyo ni bora kwa ajili ya Kompyuta!

Pocket Code ni zaidi ya miradi digital tu. Pamoja na mpya **makerspace vipengele**, unaweza pia kubuni **SVG faili kwa kukata plotters**. Hii inamaanisha unaweza kugeuza uumbaji wako wa digital kuwa vitu vya ulimwengu halisi na kuchunguza uwezekano wa ubunifu zaidi ya skrini.

Iwe unajifunza kuandika, kujaribu mawazo mapya, au kufundisha programu, Pocket Code hutoa njia ya kucheza na kupatikana ya kuzama katika coding
