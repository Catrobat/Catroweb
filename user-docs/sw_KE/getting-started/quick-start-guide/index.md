Pocket Code ni programu ya programu inayoonekana ambayo hukuruhusu kuunda michezo, michoro, na hadithi za maingiliano moja kwa moja kwenye smartphone au kompyuta kibao yako. Kwa kutumia kiolesura cha kuvuta na kuacha intuitive na “block code” (block code), unaweza kubuni miradi yako bila uzoefu wa awali programu. Kwa urahisi, ongeza sauti, picha, na mwendo ili ufanye mawazo yako yawe halisi.

Mwongozo huu utakusaidia kuanza kwa kueleza jinsi ya:

- Navigate interface,
- Kujenga mradi wako wa kwanza,
- Kazi na vitu na background,
- Tumia block code kwa programu ya vitendo, na
- Weka mradi wako.

Ni kamili kwa ajili ya Kompyuta na walimu, Pocket Code inatia moyo ubunifu, kutatua matatizo, na kufikiri kimaadili.
