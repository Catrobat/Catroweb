Je, unataka kuunda njama yako mwenyewe? Mafunzo yetu yatakuongoza kwa kutumia vipande vya nambari ili kukata mistari iliyochorwa kwenye kipande cha kuokota. Jifunze mbinu na zana zinazohitajika ili kufanya michoro yako iwe halisi kwa usahihi na ubunifu.
