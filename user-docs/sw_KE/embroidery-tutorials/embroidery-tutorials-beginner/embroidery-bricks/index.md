Katika mafunzo haya utajifunza kila kitu unahitaji kujua kuhusu Embroidery-code blocks!

Huna haja ya ujuzi wowote wa programu kwa ajili ya hili.

Kila block ya Embroidery code itaelezwa kwa mfano.

Kama bado haujatumia vifungo vya nambari ya Embroidery, angalia mafunzo **[Kuamsha Blocks ya Code Embroidery](../activate-embroidery-bricks.md)**.

*Hapa unaweza kupakua mafunzo katika PDF-format*:

[Vifaa vya kuunganisha](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Bonyeza kwenye blocks tofauti za code ili kujua zaidi kuhusu yao:**

[![Shona](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*Acha mashine ya kushona kwenye kitambaa mara moja!*

[![Kuanza kukimbia kushona kwa urefu 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*Inawezesha mashine kushona daima kwa urefu variable.*

[![Kuanza zigzag kushona na urefu 2na upana 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Kusanisha daima kwa urefu na upana tofauti.*

[![Kuanza kushona tatu kwa urefu 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*Mkusanyiko wa tatu hutia ndani kila mseto mara tatu.*

[![Simamisha mshono wa sasa](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Acha kushona kwa sasa kusimamike.*

Unaweza kupata zaidi Embroidery-code blocks na taarifa kuhusu yao [hapa](../../../../reference/#category_embroidery).

Ili kupata habari zaidi au mapendekezo ya kubuni, tazama mafunzo mengine!
