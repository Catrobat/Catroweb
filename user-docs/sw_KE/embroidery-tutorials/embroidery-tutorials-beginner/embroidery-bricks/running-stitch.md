Inawezesha mashine kushona daima kwa urefu variable.

Kwa kawaida wewe kuchanganya kukimbia kushona na block hoja code.

![Kuanza kukimbia kushona kwa urefu 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

mashine kuanza kuendesha kushona ambayo kushona kila **Hatua 10**.

Kisha mashine huanza kusonga **Hatua 200**.

Hii husababisha **Vipande 20**.

![Anza mshono wa kawaida wenye urefu](../../../../media/embroidery-tutorials/RunningStitch.png)

Kufunga kwa kutumia mashimo ya kuendesha hufanya kushona kwa mashine iwe rahisi zaidi kwa sababu hutataka tena mviringo.
