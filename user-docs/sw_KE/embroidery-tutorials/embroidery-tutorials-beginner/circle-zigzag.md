Katika mafunzo haya, utajifunza jinsi ya embroider mduara na zigzag stitch (54.7x 54.8mm).

![picha (8)](../../../media/embroidery-tutorials/image-8.png)

Unapaswa tayari kujua jinsi ya kujenga kitu kipya na kuingiza vitalu vya code huko. Jisikie huru kuangalia mafunzo katika [Mfululizo wa kuanza](../../game-tutorials/starter-tutorials/index.md) kama bado unahitaji msaada. Kwa kuongezea, vifungo vya nambari ya embroidery lazima tayari vifanye kazi. Unaweza kujua jinsi ya kufanya hivyo katika mafunzo **[Kuamsha Blocks ya Code Embroidery](activate-embroidery-bricks.md)**.

Ili kupata habari zaidi au mapendekezo ya kubuni, soma mafunzo mengine.

*Hapa unaweza kupakua mafunzo katika PDF-format*:

[Mzunguko Zigzag](../../../media/embroidery-tutorials/Circle-Zigzag.pdf)

### 1. Kujenga kitu kipya embroidery (tazama [Kujenga vitu embroidery](create-embroidery-objects.md)).

### 2. Sasa kuanza na kuingiza blocks code hatua kwa hatua kwenye script yako.

![Mzunguko Zigzag](../../../media/embroidery-tutorials/Circle-Zigzag.png)

### 3. Bonyeza kucheza ili uanze kubuni!

Angalia mafunzo **[Mzunguko](circle.md)** kwa habari zaidi juu ya jinsi ya embroider mduara.
