Katika mafunzo haya, kuamsha Embroidery block code itaelezwa.

![Kuamsha Embroidery-Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Huna haja ya ujuzi wowote wa programu kwa ajili ya hili. Hii ni hatua ya kwanza kuanza na mafunzo embroidery. Baadaye, unaweza kubuni, kupanga programu, na hata kuyaruka kwa ajili ya nguo unayopenda.

Ili kupata habari zaidi au mapendekezo ya kubuni, soma mafunzo mengine.

Sasa utapata pia kila embroidery code blocks kati ya nyingine code blocks.

Kwa habari zaidi kuhusu kila block code, jisikie huru kuangalia nyaraka ya blocks code [hapa](../../../reference/) au kufuata **[Vifaa vya kuunganisha](embroidery-bricks/index.md)**-mfunzo kwa ajili hiyo.

Sasa unaweza kuanza na kuunda miundo yako mwenyewe!

Ikiwa unahitaji mawazo au msaada katika hili, angalia mafunzo mengine au endelea na mafunzo ya **[Kujenga vitu embroidery](create-embroidery-objects.md)**.
