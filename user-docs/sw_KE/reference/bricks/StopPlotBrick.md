![Acha kuchora](../../../media/bricks/Stop_to_plot.png)

“Acha kuchora” kifungu cha code huzuia mchakato wa kupanga na inaruhusu wewe hoja mchezaji katika nafasi mpya au kumaliza mpango. Ni kama kuondoa kalamu kutoka kwenye karatasi ili kuiweka upya au kuacha kuchora. Baada ya wewe ni kumaliza kupanga, unaweza kutumia block code “Hifadhi mchoro kama SVG” kuokoa kubuni yako kama faili SVG.
