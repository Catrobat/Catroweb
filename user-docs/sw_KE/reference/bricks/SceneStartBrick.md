Hii block code hubadili kwa eneo tofauti katika mradi wako na kuanza kuendesha eneo hilo kutoka mwanzo. Ni kama kubadili sura katika kitabu au kusonga hadi ngazi inayofuata katika mchezo.

Wazia una matukio mengi katika mradi wako, kila moja ikirejelea sehemu tofauti ya hadithi yako au mchezo. Kwa kutumia kipande hiki cha code, unaweza kuruka kwenye eneo lolote na kuanza kutoka mwanzo, kuunda mpito wa usawaziko kati ya sehemu tofauti za mradi wako.
