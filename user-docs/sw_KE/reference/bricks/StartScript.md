Ukifanya hivyo, maandishi yataanza mara moja wakati wa tukio. Maonyesho ni mwanzo wa programu yako. Maonyesho ni maono mapya katika programu yako ambayo yanaweza kuonyesha mambo mengine na kuingiliana tofauti. Unaweza kuwa na matukio mengi kwa ajili ya vipindi mbalimbali katika programu yako. Kwa mfano, eneo moja kwa ajili ya utangulizi, eneo moja kwa ajili ya orodha kuu, eneo moja kwa ajili ya darasa la kwanza, darasa la pili na kadhalika. Kwa programu rahisi, eneo moja la tukio linaweza kutosha pia, basi mwanzo wa programu yako ni mwanzo wa tukio hilo.

Kama kila script, hii huanza na kuzuia code ya tukio: tukio hufafanua **wakati** script huanza, code blocks baada ya kuambia programu **nini** kufanya.
