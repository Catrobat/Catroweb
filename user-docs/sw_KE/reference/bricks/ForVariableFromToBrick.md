![kwa-maadili-kutoka block code](../../../media/bricks/for-values-from-brick.png)

Block hii code anaendesha seti ya maelekezo mara kadhaa, kwa kutumia counters kwamba huanza katika thamani moja na kumalizika katika nyingine. Ni kama kuweka mzunguko ambapo unajua hasa ni mara ngapi unataka kuendesha.

Wazia una orodha ya vitu, na unataka kufanya jambo fulani kwa kila moja. Blogu hii inaruhusu wewe kwenda kupitia kila kipengele moja kwa moja, kufanya kitu kimoja kwa kila.
