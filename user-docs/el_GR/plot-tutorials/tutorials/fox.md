Όταν ξεκινά η σχεδίαση, κάθε κίνηση σχεδιάζεται σαν να γράφεις με πένα. Αυτές είναι οι γραμμές που θα κόψει αργότερα ο σχεδιογράφος.

Αυτή η αλεπού φτιάχνεται μόνο με ευθείες γραμμές («Move \_\_\_ steps») και στροφές.

**Συμβουλή**: Δοκίμασε το πρόγραμμά σου καθώς το φτιάχνεις.
