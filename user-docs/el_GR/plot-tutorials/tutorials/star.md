[Αστέρι (PDF, στα γερμανικά)](../../../media/plot-tutorials/Stern.pdf)

Όταν ξεκινά η σχεδίαση, κάθε κίνηση σχεδιάζεται σαν να γράφεις με πένα. Αυτές είναι οι γραμμές που θα κόψει αργότερα ο σχεδιογράφος.

Αυτό το αστέρι έχει 6 άκρες. Μια άκρη είναι μια ευθεία γραμμή («Move 100 steps»), μια στροφή και μια άλλη ευθεία γραμμή που ολοκληρώνει το σχήμα της άκρης. Πριν την επόμενη άκρη, πρέπει να στρίψεις προς την αντίθετη κατεύθυνση, ώστε η επόμενη άκρη να βγει σωστή.

***Σημείωση**: Ένας πλήρης κύκλος είναι 360°. Για κάθε άκρη στρίβουμε 100° δεξιά και 40° αριστερά, δηλαδή συνολικά 60° δεξιά.*

*Και για τις έξι άκρες μαζί παίρνουμε στροφή 360° δεξιά.*

**Πήγαινε πιο πέρα**: Δοκίμασε διαφορετικούς συνδυασμούς στροφών και άλλαξε τον αριθμό των άκρων.
