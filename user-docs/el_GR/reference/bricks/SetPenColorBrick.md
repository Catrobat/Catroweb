![Όρισε το χρώμα της πένας σε κόκκινο 0, πράσινο 0, μπλε 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Αυτό το μπλοκ αλλάζει το χρώμα της πένας που χρησιμοποιεί ο ηθοποιός. Είναι σαν να αλλάζεις σε άλλη χρωματιστή πένα όσο ζωγραφίζεις.

**Κόκκινο, Πράσινο, Μπλε (RGB)**: Το μοντέλο χρωμάτων RGB χρησιμοποιεί διαφορετικές εντάσεις κόκκινου, πράσινου και μπλε φωτός για να φτιάξει ένα μεγάλο φάσμα χρωμάτων. Κάθε συνιστώσα χρώματος (κόκκινο, πράσινο και μπλε) μπορεί να έχει τιμή από 0 μέχρι 255:

- **Κόκκινο**: Η ποσότητα κόκκινου του χρώματος. Μεγαλύτερη τιμή σημαίνει περισσότερο κόκκινο.
- **Πράσινο**: Η ποσότητα πράσινου του χρώματος. Μεγαλύτερη τιμή σημαίνει περισσότερο πράσινο.
- **Μπλε**: Η ποσότητα μπλε του χρώματος. Μεγαλύτερη τιμή σημαίνει περισσότερο μπλε.

Συνδυάζοντας διαφορετικές τιμές για κόκκινο, πράσινο και μπλε, μπορείς να φτιάξεις οποιοδήποτε χρώμα. Για παράδειγμα:

- `RGB(255, 0, 0)` είναι καθαρό κόκκινο.
- `RGB(0, 255, 0)` είναι καθαρό πράσινο.
- `RGB(0, 0, 255)` είναι καθαρό μπλε.
- `RGB(255, 255, 255)` είναι λευκό (μέγιστο κόκκινο, πράσινο και μπλε).
- `RGB(0, 0, 0)` είναι μαύρο (χωρίς χρώμα).

Αναμιγνύοντας αυτά τα χρώματα σε διαφορετικές ποσότητες φτιάχνονται όλα τα χρώματα που βλέπεις στις ψηφιακές οθόνες.
