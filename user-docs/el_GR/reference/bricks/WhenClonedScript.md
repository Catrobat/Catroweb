![μπλοκ όταν ξεκινάς ως κλώνος](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Δίνει σε έναν δημιουργημένο κλώνο ενός αντικειμένου οδηγίες για να κάνει τις ενέργειες που θέλεις. Η διαδικασία αυτή επιτρέπει να αναπαραχθεί η λειτουργία του αρχικού αντικειμένου, ενώ ο κλώνος ελέγχεται ανεξάρτητα. Μπορείς να ορίσεις διάφορες συμπεριφορές ή ιδιότητες του κλώνου, ώστε να ταιριάζουν στις ανάγκες σου.
