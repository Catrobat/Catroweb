Με αυτό το μπλοκ αφήνεις ένα αντίγραφο της εμφάνισης του χαρακτήρα σου πάνω στην οθόνη. Είναι σαν να σφραγίζεις ένα χρωματιστό σφράγισμα πάνω σε χαρτί και να αφήνεις ένα αντίγραφο του σχεδίου της σφραγίδας. Έτσι εμπλουτίζεις το φόντο σου· δεν δημιουργείς κλώνο!
