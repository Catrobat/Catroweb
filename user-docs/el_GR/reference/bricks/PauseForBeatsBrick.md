![Κάνε παύση για 1 χτύπο](../../../media/bricks/Pause_for_1_beats.png)

Αυτό το μπλοκ κάνει το σενάριο να περιμένει ένα συγκεκριμένο αριθμό χτύπων πριν συνεχίσει. Είναι σαν να κάνεις ένα μικρό διάλειμμα μέσα σε ένα τραγούδι πριν παίξεις την επόμενη νότα ή τον επόμενο ήχο. Φαντάσου ότι κάνεις παύση στην παράστασή σου, μετράς τους χτύπους και μετά συνεχίζεις.
