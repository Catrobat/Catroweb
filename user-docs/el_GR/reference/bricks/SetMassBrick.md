![μπλοκ όρισε μάζα σε κιλά](../../../media/bricks/set_mass_to__kilogram_brick.png)

Ορίζει το βάρος του αντικειμένου σε κιλά, κάτι που επηρεάζει πώς κινείται και πώς αλληλεπιδρά με άλλα αντικείμενα. Τα βαρύτερα αντικείμενα είναι πιο δύσκολο να μετακινηθούν και χρειάζονται περισσότερη δύναμη για να αλλάξουν κατεύθυνση.
