![μπλοκ περίμενε μέχρι να σταματήσουν όλα τα άλλα σενάρια](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Αυτό το μπλοκ βάζει σε αναμονή το τρέχον σενάριο μέχρι να τελειώσουν όλα τα άλλα σενάρια του έργου. Φαντάσου ότι βάζεις το σενάριό σου σε αναμονή μέχρι να τελειώσουν όλα τα υπόλοιπα. Είναι χρήσιμο για να βεβαιωθείς ότι δεν γίνεται καμία άλλη ενέργεια πριν προχωρήσεις στα επόμενα βήματα του τρέχοντος σεναρίου.
