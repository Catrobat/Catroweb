![μπλοκ διαγραφής κλώνου](../../../media/bricks/delete_clone_brick2.png)

Αυτό το μπλοκ αφαιρεί τον κλώνο που δημιουργήθηκε με το μπλοκ «Δημιούργησε κλώνο από». Είναι σαν να λες: «Σβήσε αυτό το αντίγραφο». Χρησιμοποίησέ το για να ελέγχεις πόσοι κλώνοι υπάρχουν στο έργο σου, και για να τους σβήνεις όταν δεν τους χρειάζεσαι πια.
