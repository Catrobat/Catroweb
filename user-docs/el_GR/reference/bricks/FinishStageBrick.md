![μπλοκ τέλους σκηνής](../../../media/bricks/finish-stage-brick.png)

Αυτό το μπλοκ σταματά όλα τα σενάρια και τελειώνει την τρέχουσα σκηνή. Είναι σαν να λες: «Αυτό το κομμάτι του έργου τελείωσε». Όλα σταματούν, και το έργο μπορεί είτε να πάει σε άλλη σκηνή είτε να τελειώσει εντελώς. Χρησιμοποίησέ το όταν θέλεις να κλείσεις ένα συγκεκριμένο στάδιο ή μία πίστα του έργου σου.
