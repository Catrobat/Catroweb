Αυτό το μπλοκ σταματά να παίζει ένας συγκεκριμένος ήχος. Είναι σαν να πατάς το stop μόνο για ένα τραγούδι, ενώ συνεχίζουν να παίζουν άλλοι ήχοι ή μουσική. Φαντάσου ότι λες στον χαρακτήρα σου να σταματήσει να παίζει ένα συγκεκριμένο κομμάτι.
