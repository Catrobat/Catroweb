![μπλοκ όρισε τον τύπο κίνησής σου](../../../media/bricks/set_your_motion_type_brick.png)

Αλλάζει τον τρόπο που κινείται το αντικείμενο. Για παράδειγμα, μπορεί να κινείται και να αναπηδά υπό την επίδραση της βαρύτητας, να μην κινείται με τη βαρύτητα αλλά να αναπηδούν πάνω του άλλα αντικείμενα, ή να μην κινείται και να μην αναπηδά. Είναι σαν να διαλέγεις πώς θα συμπεριφέρεται ο χαρακτήρας σου ως προς την κίνηση και την αλληλεπίδραση.
