![μπλοκ όρισε τριβή σε](../../../media/bricks/set_friction_to_brick2.png)

Ρυθμίζει την τριβή που ασκείται στο αντικείμενο, κάτι που επηρεάζει πόσο εύκολα γλιστρά ή πόσο επιβραδύνεται. Είναι σαν να αλλάζεις πόσο γλιστερή είναι η επιφάνεια πάνω στην οποία στέκεται ο χαρακτήρας σου. Περισσότερη τριβή σημαίνει λιγότερο γλίστρημα.
