Αλλάζει τον τρόπο που περιστρέφεται το αντικείμενο: γύρω-γύρω, μόνο αριστερά-δεξιά ή καθόλου. Είναι σαν να αποφασίζεις αν ο χαρακτήρας σου μπορεί να γυρίσει εντελώς, αν απλώς γυρίζει αριστερά και δεξιά, ή αν δεν περιστρέφεται καθόλου.
