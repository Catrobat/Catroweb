Αυτό το μπλοκ φτιάχνει ένα αντίγραφο του επιλεγμένου αντικειμένου, που λέγεται κλώνος, και που συμπεριφέρεται όπως το αρχικό. Φαντάσου ότι αντιγράφεις έναν χαρακτήρα ή ένα αντικείμενο στο παιχνίδι σου. Ο κλώνος μπορεί να έχει τις δικές του συμπεριφορές και σενάρια, κι έτσι μπορείς να φτιάξεις πολλά στιγμιότυπα ενός αντικειμένου που δρουν ανεξάρτητα το ένα από το άλλο.
