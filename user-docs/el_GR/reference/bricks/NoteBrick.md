![μπλοκ σημείωσης](../../../media/bricks/note_brick2.png)

Προσθέτει ένα σχόλιο ή μια σημείωση στο σενάριό σου, για να θυμάσαι τι κάνει κάθε μέρος του κώδικά σου. Δεν επηρεάζει τον τρόπο που τρέχει το έργο σου. Είναι σαν να βάζεις ένα αυτοκόλλητο σημείωμα για τον εαυτό σου.
