![μπλοκ για τιμές από-μέχρι](../../../media/bricks/for-values-from-brick.png)

Αυτό το μπλοκ εκτελεί μια σειρά από εντολές ένα συγκεκριμένο αριθμό φορών, με έναν μετρητή που ξεκινά από μία τιμή και τελειώνει σε μια άλλη. Είναι σαν να φτιάχνεις έναν βρόχο όπου ξέρεις ακριβώς πόσες φορές θέλεις να τρέξει.

Φαντάσου ότι έχεις μια λίστα με στοιχεία και θέλεις να κάνεις κάτι με καθένα. Αυτό το μπλοκ σου επιτρέπει να περάσεις ένα-ένα από όλα τα στοιχεία και να κάνεις το ίδιο πράγμα σε καθένα.
