![μπλοκ για κάθε τιμή](../../../media/bricks/for-each-value_brick.png)

Αυτό το μπλοκ εκτελεί μια σειρά από εντολές για κάθε στοιχείο μιας λίστας ή μιας σειράς τιμών. Είναι σαν να περνάς ένα-ένα από όλα τα στοιχεία και να κάνεις το ίδιο πράγμα σε καθένα.

Φαντάσου ότι έχεις μια λίστα με αριθμούς, χρώματα ή οποιαδήποτε στοιχεία. Αυτό το μπλοκ σου επιτρέπει να πάρεις κάθε στοιχείο από τη λίστα και να κάνεις κάτι με αυτό. Για παράδειγμα, αν έχεις μια λίστα με χρώματα και θέλεις να αλλάζεις το χρώμα του φόντου σε καθένα από αυτά, θα χρησιμοποιήσεις αυτό το μπλοκ.

Είναι σαν να λες: «Για κάθε στοιχείο αυτής της ομάδας, κάνε αυτές τις εντολές».
