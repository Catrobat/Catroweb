*Ελέγχει αν μια συνθήκη είναι αληθής και, αν είναι, εκτελεί μια σειρά εντολών. Είναι σαν να λες: «Αν ισχύει αυτό, τότε κάνε εκείνο».*

![Όταν ξεκινά η σκηνή](../../../media/bricks/StartScene.png)

Όταν ξεκινά η σκηνή, η μεταβλητή X παίρνει την τιμή 0.

![Αν](../../../media/bricks/If.png)

Αν πατηθεί τώρα το ζώο, η μεταβλητή X αυξάνεται κατά 1.
Το πρόγραμμα ελέγχει αν η μεταβλητή X είναι ίση με το 2.
Αν ισχύει αυτό, παίζεται ο ήχος Tweet1 και η μεταβλητή X γίνεται 0.
