![Εμφάνισε το εφέ σωματιδίων σταδιακά](../../../media/bricks/Fade_particle_effect_in.png)

Αυτό το μπλοκ προσθέτει σωματίδια στον χαρακτήρα σου και τα κάνει σιγά σιγά να εξαφανίζονται. Χρησιμοποίησέ το, για παράδειγμα, για να φτιάξεις μια επίδειξη με πυροτεχνήματα, να προσθέσεις καπνό ή να κάνεις τον χαρακτήρα σου να εμφανιστεί γρήγορα.
