Σε αυτό το εκπαιδευτικό θα μάθεις πώς να κεντάς έναν κύκλο (76,2 x 76,2 mm).

![εικόνα (6)](../../../media/embroidery-tutorials/image-6.png)

Πρέπει ήδη να ξέρεις πώς να φτιάχνεις νέο αντικείμενο και να βάζεις μπλοκ μέσα σε αυτό. Μπορείς να δεις τα εκπαιδευτικά της [σειράς για αρχάριους](../../game-tutorials/starter-tutorials/index.md) αν χρειάζεσαι ακόμα βοήθεια. Επιπλέον, τα μπλοκ κεντήματος πρέπει να είναι ήδη ενεργοποιημένα. Μπορείς να μάθεις πώς γίνεται αυτό στο εκπαιδευτικό **[Ενεργοποίηση μπλοκ κεντήματος](activate-embroidery-bricks.md)**.

Για περισσότερες πληροφορίες ή ιδέες για σχέδια, δες τα άλλα εκπαιδευτικά.

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF*:

[Κύκλος](../../../media/embroidery-tutorials/Circle.pdf)

### 1. Φτιάξε νέο αντικείμενο κεντήματος (δες [Δημιουργία αντικειμένων κεντήματος](create-embroidery-objects.md)).

### 2. Τώρα ξεκίνα και βάλε τα μπλοκ ένα-ένα στο σενάριό σου.

![Κύκλος](../../../media/embroidery-tutorials/Circle.png)

### 3. Πάτα αναπαραγωγή για να ξεκινήσει το σχέδιό σου!

![Κύκλος (1)](../../../media/embroidery-tutorials/Circle-1.png)

Πρέπει να ορίσεις τη γωνία περιστροφής, εδώ ως 360 ÷ 60.
Το 360 μένει πάντα το ίδιο για έναν κύκλο! Γι' αυτό πρέπει να ορίσεις τις επαναλήψεις κατάλληλα, όπως το 60 εδώ. **Δοκίμασε άλλους συνδυασμούς!** Για παράδειγμα: 30 και 360 ÷ 30 ή 120 και 360 ÷ 120.
