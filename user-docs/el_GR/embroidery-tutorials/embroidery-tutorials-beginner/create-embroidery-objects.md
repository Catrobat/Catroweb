Σε αυτό το εκπαιδευτικό θα μάθεις πώς να φτιάχνεις αντικείμενα, με τα οποία αργότερα μπορείς να κεντάς τα σχέδιά σου.

Για αυτό το εκπαιδευτικό πρέπει ήδη να ξέρεις πώς να φτιάχνεις έργο. Δες τα εκπαιδευτικά της [σειράς για αρχάριους](../../game-tutorials/starter-tutorials/index.md), αν χρειάζεσαι βοήθεια.

Για περισσότερες πληροφορίες ή ιδέες για σχέδια, δες τα άλλα εκπαιδευτικά.

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF*:

[Δημιουργία αντικειμένων κεντήματος](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Πάτα το κουμπί + κάτω δεξιά στο έργο σου για να προσθέσεις νέο αντικείμενο.

![Δημιουργία αντικειμένων κεντήματος](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Για να διαλέξεις εικόνα, πήγαινε στη βιβλιοθήκη πολυμέσων.

![Δημιουργία αντικειμένων κεντήματος (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Ένα αντικείμενο κεντήματος αντιπροσωπεύει ένα επίπεδο της βελόνας της κεντητικής μηχανής. Πολλά αντικείμενα κεντήματος κεντιούνται το ένα μετά το άλλο. Έτσι μπορείς να χρησιμοποιήσεις πολλά χρώματα.
Διάλεξε το αντικείμενο ανάλογα με το χρώμα που θέλεις.
Κάνε κύλιση προς τα κάτω και βρες το κατάλληλο βέλος.

![Δημιουργία αντικειμένων κεντήματος (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Δώσε στο νέο σου αντικείμενο ένα κατάλληλο όνομα και πάτα OK.

![Δημιουργία αντικειμένων κεντήματος (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Τώρα έφτιαξες νέο αντικείμενο. Μπορείς τώρα να προσθέσεις σενάριο και να προγραμματίσεις το αντικείμενο.

![Δημιουργία αντικειμένων κεντήματος (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Τώρα ξέρεις πώς να φτιάχνεις αντικείμενο. Πρόσθεσε ένα νέο αντικείμενο για κάθε χρώμα που θέλεις να χρησιμοποιήσεις.

Μπορείς να προσθέσεις σενάριο σε κάθε χρώμα και να προγραμματίσεις τα δικά σου σχέδια, ακόμα και να τα κεντήσεις αργότερα.

Χρειάζεσαι έμπνευση ή βοήθεια; Δες τα άλλα εκπαιδευτικά μας!
