Σε αυτό το εκπαιδευτικό εξηγείται πώς ενεργοποιείς τα μπλοκ κεντήματος.

![Ενεργοποίηση μπλοκ κεντήματος 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Για αυτό δεν χρειάζεσαι γνώσεις προγραμματισμού. Είναι το πρώτο βήμα για να ξεκινήσεις τα εκπαιδευτικά κεντήματος. Αργότερα μπορείς να σχεδιάσεις, να προγραμματίσεις και ακόμα και να κεντήσεις τα δικά σου σχέδια πάνω στο αγαπημένο σου ύφασμα.

Για περισσότερες πληροφορίες ή ιδέες για σχέδια, δες τα άλλα εκπαιδευτικά.

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF*:

[ActivateEmbroideryBricks](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Άνοιξε την εφαρμογή «Pocket Code». Ακολούθησε τα κλικ!

### 2. Άνοιξε το μενού (οι τελείες επάνω δεξιά).

![Ενεργοποίηση μπλοκ κεντήματος](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Πήγαινε στις «Ρυθμίσεις».

![Ενεργοποίηση μπλοκ κεντήματος 3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Διάλεξε «Επέκταση κεντήματος».

![Ενεργοποίηση μπλοκ κεντήματος 4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Θα βρεις τα μπλοκ κεντήματος ως δική τους κατηγορία μέσα στα μπλοκ σου!

[![Ενεργοποίηση μπλοκ κεντήματος 5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Τώρα θα βρεις όλα τα μπλοκ κεντήματος και ανάμεσα στα υπόλοιπα μπλοκ.

Για περισσότερες πληροφορίες για κάθε μπλοκ, δες την τεκμηρίωση των μπλοκ [εδώ](../../../reference/) ή ακολούθησε το εκπαιδευτικό **[Μπλοκ κεντήματος](embroidery-bricks/index.md)**.

Τώρα μπορείς να ξεκινήσεις και να φτιάξεις τα δικά σου σχέδια!

Αν χρειάζεσαι ιδέες ή βοήθεια, δες τα άλλα εκπαιδευτικά ή συνέχισε με το **[Δημιουργία αντικειμένων κεντήματος](create-embroidery-objects.md)**.
