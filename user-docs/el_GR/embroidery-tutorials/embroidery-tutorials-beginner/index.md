Θέλεις να είσαι δημιουργικός και ταυτόχρονα να μαθαίνεις προγραμματισμό με παιχνιδιάρικο τρόπο; Σου αρέσει επίσης να φτιάχνεις πράγματα που μπορείς να χρησιμοποιήσεις, να φορέσεις και να θαυμάσεις αμέσως μετά;

Με το Embroidery Designer μπορείς, χωρίς καμία προηγούμενη εμπειρία, να προγραμματίσεις μια κεντητική μηχανή που θα κεντά αυτόματα το σχέδιό σου σε μπλούζα, τσάντα, παντελόνι, θήκη κινητού ή ακόμα και σε παπούτσια. Το κέντημα είναι δυνατό σε όλα όσα είναι φτιαγμένα από ύφασμα. Άφησε τη φαντασία και τη δημιουργικότητά σου να κινηθούν ελεύθερα! Μπορείς να κατεβάσεις και να επεξεργαστείς σχέδια άλλων από την Catrobat Community. Φυσικά, μπορείς επίσης να μοιραστείς τα έργα σου με τους φίλους σου και με όλο τον κόσμο!
