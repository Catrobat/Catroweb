Η τριπλή βελονιά ράβει κάθε βελονιά τρεις φορές.

Η τριπλή βελονιά κάνει ένα βήμα πίσω μετά την πρώτη βελονιά, ράβει, μετά πηδά ξανά μπροστά και ράβει πάλι.

![Start_triple_stitch_with_length_10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)

Λειτουργεί όπως η [ευθεία βελονιά](running-stitch.md).

![TripleStitch](../../../../media/embroidery-tutorials/TripleStitch.png)

Αυτό κάνει τη ραφή να κρατά περισσότερο.
