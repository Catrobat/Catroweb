Σταματά τη βελονιά που γίνεται αυτή τη στιγμή.

Θα χρειαστείς αυτό το μπλοκ αν θέλεις να αλλάξεις τη θέση της βελόνας αφού ξεκινήσεις μια ευθεία, ζιγκ-ζαγκ ή τριπλή βελονιά.
