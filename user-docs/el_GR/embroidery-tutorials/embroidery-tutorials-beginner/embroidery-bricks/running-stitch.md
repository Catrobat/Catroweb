Αφήνει τη μηχανή να ράβει συνεχώς με μεταβλητό μήκος.

Συνήθως συνδυάζεις την ευθεία βελονιά με ένα μπλοκ κίνησης.

![Start_running_stitch_with_length_10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Η μηχανή ξεκινά μια ευθεία βελονιά που θα ράβει κάθε **10 βήματα**.
Μετά η μηχανή κινείται **200 βήματα**.
Το αποτέλεσμα είναι **20 βελονιές**.

![RunningStitch](../../../../media/embroidery-tutorials/RunningStitch.png)

Η ευθεία βελονιά κάνει πιο εύκολο το ράψιμο μιας ραφής, γιατί δεν χρειάζεσαι πια βρόχο.

![εικόνα](../../../../media/embroidery-tutorials/image.png)
