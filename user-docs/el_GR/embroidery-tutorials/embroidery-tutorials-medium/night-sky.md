Σε αυτό το εκπαιδευτικό θα μάθεις πώς να κεντάς έναν νυχτερινό ουρανό (48,5 x 96,1 mm).

![Νυχτερινός ουρανός](../../../media/embroidery-tutorials/Nachthimmel.png)

Πρέπει ήδη να ξέρεις τι είναι ένας βρόχος και πώς λειτουργεί.

Το εκπαιδευτικό **[Αστέρι](../embroidery-tutorials-beginner/star.md)** μπορεί να σε βοηθήσει σε αυτό το εκπαιδευτικό.

Βοηθά επίσης αν ήδη ξέρεις τη λειτουργία της μετάδοσης μηνυμάτων (broadcast).

Δες τα εκπαιδευτικά κεντήματος της σειράς [αρχάριων](../embroidery-tutorials-beginner/index.md) αν δεν έχεις κεντήσει ακόμα τίποτα.

Για περισσότερες πληροφορίες ή ιδέες για σχέδια, δες τα άλλα εκπαιδευτικά.

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF*:

[Νυχτερινός ουρανός](../../../media/embroidery-tutorials/Night-Sky.pdf)
