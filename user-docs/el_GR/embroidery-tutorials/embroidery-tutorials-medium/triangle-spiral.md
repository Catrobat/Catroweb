Σε αυτό το εκπαιδευτικό θα μάθεις πώς να κεντάς μια σπείρα τριγώνου (50,2 x 58 mm).

![Σπείρα τριγώνου](../../../media/embroidery-tutorials/Triangle-Spiral.png)

Πρέπει ήδη να ξέρεις τι είναι ένας βρόχος και πώς λειτουργεί.

Δες τα εκπαιδευτικά κεντήματος της σειράς [αρχάριων](../embroidery-tutorials-beginner/index.md) αν δεν έχεις κεντήσει ακόμα τίποτα.

Για περισσότερες πληροφορίες ή ιδέες για σχέδια, δες τα άλλα εκπαιδευτικά.

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF*:

[Σπείρα τριγώνου](../../../media/embroidery-tutorials/Triangle-Spiral-1.pdf)

### 1. Φτιάξε νέο αντικείμενο κεντήματος (δες [Δημιουργία αντικειμένων κεντήματος](../embroidery-tutorials-beginner/create-embroidery-objects.md)) και βάλε το παρακάτω σενάριο:

![Σπείρα τριγώνου (2)](../../../media/embroidery-tutorials/Triangle-Spiral-2.png)

### 2. Πάτα αναπαραγωγή για να ξεκινήσει το σχέδιό σου!

Πάτα «Νέα» για να φτιάξεις νέα μεταβλητή.

![εικόνα (15)](../../../media/embroidery-tutorials/image-15.png)

Θα βρεις τη μεταβλητή «degree» στα «Δεδομένα».

![Σπείρα (1)](../../../media/embroidery-tutorials/Spiral-1.png)
