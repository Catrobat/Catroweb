Σε αυτό το εκπαιδευτικό θα μάθεις πώς να κεντάς ένα ουράνιο τόξο (112 x 57,2 mm).

![Ουράνιο τόξο](../../../media/embroidery-tutorials/Regenbogen.webp)

Πρέπει ήδη να ξέρεις τι είναι ένας βρόχος και πώς λειτουργεί.

Το εκπαιδευτικό **[Ημικύκλιο](../embroidery-tutorials-beginner/semicircle.md)** μπορεί να σε βοηθήσει σε αυτό το εκπαιδευτικό.

Δες τα εκπαιδευτικά κεντήματος της σειράς [αρχάριων](../embroidery-tutorials-beginner/index.md) αν δεν έχεις κεντήσει ακόμα τίποτα.

Για περισσότερες πληροφορίες ή ιδέες για σχέδια, δες τα άλλα εκπαιδευτικά.

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF*:

[Ουράνιο τόξο](../../../media/embroidery-tutorials/Rainbow.pdf)

### 1. Φτιάξε νέο αντικείμενο κεντήματος (δες [Δημιουργία αντικειμένων κεντήματος](../embroidery-tutorials-beginner/create-embroidery-objects.md)):

![Ουράνιο τόξο](../../../media/embroidery-tutorials/Rainbow.png)

### 2. Βάλε το παρακάτω σενάριο:

![Ουράνιο τόξο (1)](../../../media/embroidery-tutorials/Rainbow-1.png)

### 3. Αντίγραψε το αντικείμενο

Για το επόμενο μεγαλύτερο τόξο, μπορείς απλώς να αντιγράψεις το αντικείμενο που μόλις έφτιαξες.
Πάτα τις τρεις τελείες επάνω δεξιά στην επισκόπηση των αντικειμένων.
Μετά πήγαινε στην «Αντιγραφή» και διάλεξε το αντικείμενο.

![Ουράνιο τόξο (6)](../../../media/embroidery-tutorials/Regenbogen-6.png)

Αν χρησιμοποιήσεις ξεχωριστό αντικείμενο για κάθε τόξο, μπορείς αργότερα να τα κεντήσεις με διαφορετικά χρώματα.

### 4. Προσάρμοσε το αντικείμενο

Για να είναι τα τόξα τώρα διαφορετικού μεγέθους, πρέπει να αλλάξεις μερικές τιμές.
Για να το κάνεις αυτό, πήγαινε στο σενάριο του αντικειμένου που αντέγραψες και άλλαξε τις παρακάτω τιμές:

![Ουράνιο τόξο (2)](../../../media/embroidery-tutorials/Rainbow-2.png)

### 5. Επανάλαβε τα βήματα 3 και 4 για περισσότερα τόξα!

### 6. Πάτα αναπαραγωγή για να ξεκινήσει το σχέδιό σου!
