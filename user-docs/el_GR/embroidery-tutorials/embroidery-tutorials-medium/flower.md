Σε αυτό το εκπαιδευτικό θα μάθεις πώς να κεντάς ένα λουλούδι (73 x 74,2 mm).

![εικόνα (11)](../../../media/embroidery-tutorials/image-11.png)

Πρέπει ήδη να ξέρεις τι είναι ένας βρόχος και πώς λειτουργεί.

Το εκπαιδευτικό **[Κύκλος](../embroidery-tutorials-beginner/circle.md)** μπορεί να σε βοηθήσει σε αυτό το εκπαιδευτικό.

Δες τα εκπαιδευτικά κεντήματος της σειράς [αρχάριων](../embroidery-tutorials-beginner/index.md) αν δεν έχεις κεντήσει ακόμα τίποτα.
