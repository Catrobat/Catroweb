Σε αυτό το εκπαιδευτικό θα μάθεις πώς να κεντάς ένα χάρτινο αεροπλανάκι (58,2 x 80,7 mm).

![Χάρτινο αεροπλανάκι](../../../media/embroidery-tutorials/Papierflieger.png)

Δες τα εκπαιδευτικά κεντήματος της σειράς [αρχάριων](../embroidery-tutorials-beginner/index.md) αν δεν έχεις κεντήσει ακόμα τίποτα.

Για περισσότερες πληροφορίες ή ιδέες για σχέδια, δες τα άλλα εκπαιδευτικά.

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF*:

[Χάρτινο αεροπλανάκι](../../../media/embroidery-tutorials/Paper-Plane.pdf)

### 1. Φτιάξε νέο αντικείμενο κεντήματος (δες [Δημιουργία αντικειμένων κεντήματος](../embroidery-tutorials-beginner/create-embroidery-objects.md)) και βάλε το παρακάτω σενάριο:

![Χάρτινο αεροπλανάκι](../../../media/embroidery-tutorials/Paperplane.png)

### 2. Πάτα αναπαραγωγή για να ξεκινήσει το σχέδιό σου!
