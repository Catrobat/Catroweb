Πάτα το κουμπί + για να προσθέσεις νέα μορφή ή αντικείμενο στο έργο σου.

![FigurHinzufuegen](../../../media/getting-started/FigurHinzufuegen.png)

Στο Pocket Code μπορείς να προσθέσεις έναν χαρακτήρα ή ένα αντικείμενο στο έργο σου με διάφορους τρόπους:

**Ζωγραφική**: Μπορείς να φτιάξεις τον δικό σου χαρακτήρα με το **Pocket Paint**. Το Pocket Paint είναι ένα πρόγραμμα ζωγραφικής ([περισσότερα για το Pocket Paint](https://catrobat.org/pocket-paint/))

**Όψεις**: Διάλεξε έναν από μια συλλογή έτοιμων χαρακτήρων και αντικειμένων ([περισσότερα για τη βιβλιοθήκη πολυμέσων](../elements/medialibrary.md)).

**Συλλογή**: Μπορείς να διαλέξεις μια εικόνα από τη συλλογή του κινητού σου.

**Βιβλιοθήκη**: Στη βιβλιοθήκη θα βρεις χαρακτήρες και αντικείμενα που είναι ήδη προγραμματισμένα, δηλαδή έχουν ήδη σενάριο. Μπορείς να τα διαλέξεις αν θέλεις να χρησιμοποιήσεις έτοιμα στοιχεία στο παιχνίδι σου (π.χ. ένα χρονόμετρο αντίστροφης μέτρησης) ([περισσότερα για τη βιβλιοθήκη](../elements/medialibrary.md#πρόσθεσε-αντικείμενο-από-τη-βιβλιοθήκη-πολυμέσων)).

**Κάμερα**: Μπορείς να χρησιμοποιήσεις την κάμερα της συσκευής σου για να βγάλεις φωτογραφία και να την προσθέσεις ως χαρακτήρα.

**Σακίδιο**: Το σακίδιο είναι αυτή τη στιγμή άδειο. Μπορείς να ξαναχρησιμοποιήσεις χαρακτήρες ή αντικείμενα που έχεις αποθηκεύσει στο σακίδιό σου. Όλο το σενάριο θα βγει από το σακίδιο μαζί τους ([περισσότερα για το σακίδιο](../elements/backpack.md)).

**Τοπικοί χαρακτήρες και αντικείμενα**: Εδώ θα βρεις έτοιμους χαρακτήρες που μπορείς να χρησιμοποιήσεις στο έργο σου. Οι τοπικοί χαρακτήρες και αντικείμενα λειτουργούν σαν μια βιβλιοθήκη πολυμέσων χωρίς σύνδεση, δηλαδή μπορείς να τους χρησιμοποιήσεις ακόμα και όταν δεν έχεις σύνδεση στο ίντερνετ.

**Κενό αντικείμενο**: Πρόσθεσε ένα κενό αντικείμενο, δηλαδή αντικείμενο χωρίς εμφάνιση. Μπορείς να το προγραμματίσεις κανονικά.

**Τοπικά έργα**: Διάλεξε ένα έργο από το οποίο θέλεις να εισάγεις τον πρώτο χαρακτήρα μαζί με το σενάριό του στο δικό σου έργο.
