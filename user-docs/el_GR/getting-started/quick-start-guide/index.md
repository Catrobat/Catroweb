Το Pocket Code είναι μια εφαρμογή οπτικού προγραμματισμού που σε αφήνει να φτιάχνεις παιχνίδια, κινούμενα σχέδια και διαδραστικές ιστορίες απευθείας στο έξυπνο τηλέφωνο ή στο tablet σου. Με ένα εύχρηστο περιβάλλον σύρε-και-άφησε με «τούβλα» (μπλοκ κώδικα), σχεδιάζεις τα έργα σου χωρίς προηγούμενη εμπειρία προγραμματισμού. Εύκολα προσθέτεις ήχους, εικόνες και κίνηση για να κάνεις τις ιδέες σου να ζωντανέψουν.

Αυτός ο οδηγός θα σε βοηθήσει να ξεκινήσεις εξηγώντας πώς να:

- πλοηγείσαι στη διεπαφή,
- φτιάχνεις το πρώτο σου έργο,
- δουλεύεις με χαρακτήρες και αντικείμενα και με φόντα,
- χρησιμοποιείς μπλοκ για να προγραμματίζεις ενέργειες, και
- αποθηκεύεις το έργο σου.

Ιδανικό για αρχάριους και εκπαιδευτικούς, το Pocket Code ενθαρρύνει τη δημιουργικότητα, την επίλυση προβλημάτων και τη λογική σκέψη.
