Όταν ανοίγεις το Pocket Code, βλέπεις την παρακάτω κεντρική οθόνη.

![Κεντρική οθόνη](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Όταν ανοίγεις το Pocket Code, βλέπεις την παρακάτω κεντρική οθόνη.\
[Άνοιξε την εικόνα](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Βοήθεια](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Επάνω δεξιά υπάρχει το σύμβολο που σε πηγαίνει στην τεκμηρίωση του Catrobat, η οποία έχει χρήσιμες συμβουλές για σένα.

![Μενού](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Δίπλα του είναι το μενού.

Από εκεί μπορείς εύκολα να πας στις ρυθμίσεις, όπου μπορείς να αλλάξεις τη γλώσσα ή να ενεργοποιήσεις επεκτάσεις, όπως τα μπλοκ σχεδιογράφου και άλλα.

![Εικονίδιο επεξεργασίας](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Πάτα το εικονίδιο επεξεργασίας για να ανοίξεις την προβολή του έργου, όπου μπορείς να συνεχίσεις να το φτιάχνεις.

Από κάτω βλέπεις το πιο πρόσφατα επεξεργασμένο έργο σου.

![Ξεκίνα το έργο σου](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Χρησιμοποίησε το κουμπί παιχνιδιού για να ξεκινήσεις το έργο σου.

![Έργα της συσκευής](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Πατώντας «Έργα της συσκευής», έχεις πρόσβαση στα αποθηκευμένα έργα σου.

![Catrobat Community](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Αν θέλεις να γνωρίσεις και να δουλέψεις σε περισσότερα έργα άλλων χρηστών, πάτα το Catrobat Community στην ενότητα Share.

Εκεί θα βρεις πολλά υπέροχα έργα.

![Πρόσθεσε](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Αν θέλεις να φτιάξεις νέο έργο, πάτα το σύμβολο +.
