Μπορείς να προσθέσεις φόντο στο έργο σου στο Catrobat.

Τα φόντα μπορούν να χρησιμοποιηθούν με πολλούς τρόπους. Στο Pocket Code μπορούν να κάνουν πιο όμορφα τα **παιχνίδια**, να λένε **ιστορίες** ή να δίνουν στους χαρακτήρες και στα αντικείμενα σου περισσότερο πλαίσιο.

Για συσκευές makerspace, όπως **σχεδιογράφους** ή **κεντητικές μηχανές**, τα φόντα λειτουργούν ως πρότυπα σχεδίου, για παράδειγμα για κοψίματα ή σχέδια κεντήματος.

Για να προσθέσεις φόντο, πάτα το «Φόντο» στην προβολή του έργου.

![Πάτημα στο Φόντο](../../../media/getting-started/grafik-16.png)

Στην **ενότητα σεναρίων (2)** μπορείς να προγραμματίσεις το φόντο σου. Ωστόσο, δεν είναι διαθέσιμα όλα τα μπλοκ. Τα δύο παρακάτω μπλοκ είναι ιδιαίτερα σημαντικά: ![Set_transparency_to_50_pct_](../../../media/bricks/Set_transparency_to_50_pct_.png) και ![Set_size_to_60_pct_](../../../media/bricks/Set_size_to_60_pct_.png)

Στην **ενότητα όψεων (1)** προσθέτεις φόντο. Για να το κάνεις, πάτα το σύμβολο +.

![Προσθήκη φόντου](../../../media/getting-started/grafik-14.png)

Μπορείς να ανεβάσεις δικές σου εικόνες, να χρησιμοποιήσεις έτοιμα φόντα ή να φτιάξεις φόντο μόνος σου.

**Ζωγραφική**: Μπορείς να φτιάξεις το δικό σου φόντο με το **Pocket Paint**. Το Pocket Paint είναι ένα πρόγραμμα ζωγραφικής ([περισσότερα για το Pocket Paint](https://catrobat.org/pocket-paint/))

**Όψεις**: Διάλεξε ένα από μια συλλογή έτοιμων φόντων ([περισσότερα για τη βιβλιοθήκη πολυμέσων](../elements/medialibrary.md)).

**Συλλογή**: Μπορείς να διαλέξεις μια εικόνα από τη συλλογή του κινητού σου.

**Κάμερα**: Μπορείς να χρησιμοποιήσεις την κάμερα της συσκευής σου για να βγάλεις φωτογραφία και να την προσθέσεις ως φόντο.

![grafik](../../../media/getting-started/grafik-17.png)

Τώρα έχεις προσθέσει φόντο. Πάτα το βελάκι της επιστροφής επάνω δεξιά για να γυρίσεις στην **προβολή του έργου**.
