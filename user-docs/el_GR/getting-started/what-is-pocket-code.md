Το Pocket Code είναι η βασική εφαρμογή του Catrobat, μια δωρεάν εφαρμογή ανοιχτού κώδικα για κινητά που σε αφήνει να φτιάχνεις παιχνίδια, κινούμενα σχέδια και διαδραστικές ιστορίες απευθείας στο έξυπνο τηλέφωνο ή στο tablet σου. Με το **σύστημα προγραμματισμού με μπλοκ** του Pocket Code φτιάχνεις έργα ενώνοντας μπλοκ κώδικα, σαν να συναρμολογείς κομμάτια ενός παζλ. Δεν χρειάζεται εμπειρία προγραμματισμού, γι' αυτό είναι ιδανικό για αρχάριους!

Το Pocket Code πηγαίνει πέρα από τα απλά ψηφιακά έργα. Με τις νέες **δυνατότητες makerspace** μπορείς επίσης να σχεδιάζεις **αρχεία SVG για μηχανές κοπής σχεδίων**. Αυτό σημαίνει ότι μπορείς να μετατρέπεις τις ψηφιακές δημιουργίες σου σε πράγματα του πραγματικού κόσμου και να εξερευνήσεις δημιουργικές δυνατότητες πέρα από την οθόνη.

Είτε μαθαίνεις να προγραμματίζεις, δοκιμάζεις νέες ιδέες ή διδάσκεις προγραμματισμό, το Pocket Code σου προσφέρει έναν παιχνιδιάρικο και εύκολα προσβάσιμο τρόπο να μπεις στον κόσμο του προγραμματισμού.
