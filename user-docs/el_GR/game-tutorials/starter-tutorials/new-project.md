Σε αυτό το εκπαιδευτικό θα μάθεις όλα όσα χρειάζεται να ξέρεις για το Pocket Code, για να αρχίσεις να φτιάχνεις το πρώτο σου έργο. Θα σε καθοδηγήσουμε βήμα προς βήμα στο πώς κατεβάζεις την εφαρμογή, την ανοίγεις και δημιουργείς νέο έργο.

![Νέο πρόγραμμα](../../../media/game-tutorials/New-Program.png)

Αυτό είναι το πιο πρώτο εκπαιδευτικό και δεν χρειάζεσαι καμία προηγούμενη γνώση.

Λοιπόν, τι περιμένεις; Πιάσε το κινητό σου και ξεκίνα τώρα!

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF:*

[Νέο πρόγραμμα](../../../media/game-tutorials/New-Program.pdf)

### 1. Εγκατάσταση του Pocket Code

Πρώτα πρέπει να εγκαταστήσεις την εφαρμογή Pocket Code στη συσκευή σου. Μπορείς να τη βρεις αναζητώντας «Pocket Code» στο Google Play Store και να την κατεβάσεις πατώντας «Εγκατάσταση». Για αυτό το βήμα χρειάζεται λογαριασμός Google. Τώρα η συσκευή σου θα κατεβάσει και θα εγκαταστήσει την εφαρμογή. Αυτό μπορεί να πάρει λίγη ώρα, ανάλογα με τη σύνδεσή σου στο ίντερνετ.

![Νέο πρόγραμμα (2)](../../../media/game-tutorials/New-Program-2.png)

Αφού κατεβάσεις και εγκαταστήσεις με επιτυχία το Pocket Code, θα βρεις την εφαρμογή στο συρτάρι εφαρμογών ή στην αρχική οθόνη, ανάλογα με τη συσκευή σου. Μπορείς να τη μετακινήσεις όπου θέλεις χωρίς κόπο.

### 2. Άνοιξε την εφαρμογή

Όταν ανοίξεις την εφαρμογή, βλέπεις διάφορες κατηγορίες:

![Νέο πρόγραμμα (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Φτιάξε νέο έργο

Το επόμενο βήμα είναι να φτιάξεις πραγματικά νέο έργο. Για να το κάνεις, πάτα το κίτρινο κουμπί + στην κάτω δεξιά γωνία. Τώρα πρέπει να γράψεις όνομα για το έργο και να διαλέξεις αν θα είναι οριζόντιο ή όχι. Πατώντας «OK» δημιουργείται το έργο.

![Νέο πρόγραμμα](../../../media/game-tutorials/New-Program.png)

### 4. Τα κατάφερες! Έφτιαξες το δικό σου νέο έργο.

Τώρα έχεις εγκαταστήσει το Pocket Code και ξέρεις πώς να φτιάχνεις νέο έργο. Τώρα μπορείς να αρχίσεις να προγραμματίζεις!

Για να το κάνεις αυτό, πρέπει να ξέρεις πώς να φτιάχνεις νέο αντικείμενο μέσα σε ένα έργο. Δες το εκπαιδευτικό **[Νέο αντικείμενο](new-object.md)**, όπου όλα εξηγούνται βήμα προς βήμα.
