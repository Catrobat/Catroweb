Σε αυτό το εκπαιδευτικό θα μάθεις πώς να φτιάχνεις νέο αντικείμενο στο έργο σου και ποιες επιλογές έχεις γι' αυτό.

![Νέο αντικείμενο](../../../media/game-tutorials/New-Object.png)\
Σε αυτό το εκπαιδευτικό θα μάθεις πώς να φτιάχνεις νέο αντικείμενο στο έργο σου και ποιες επιλογές έχεις γι' αυτό.\
[Άνοιξε την εικόνα](../../../media/game-tutorials/New-Object.png)

Για να το κάνεις αυτό, πρέπει ήδη να έχεις κατεβάσει την εφαρμογή Pocket Code και να ξέρεις πώς να φτιάχνεις νέο έργο. Αν χρειάζεσαι βοήθεια με αυτό, μπορείς να δεις το εκπαιδευτικό **[Νέο έργο](new-project.md)**.

*Εδώ μπορείς να κατεβάσεις το εκπαιδευτικό σε μορφή PDF:*

[Άνοιξε το PDF](../../../media/game-tutorials/New-Object.pdf)

### 1. Φτιάξε νέο αντικείμενο

Πρώτα πρέπει να ανοίξεις το νέο σου έργο.

Θα το βρεις στην αρχική οθόνη της εφαρμογής Pocket Code. Αν έχεις περισσότερα από ένα έργα, μπορείς να πατήσεις «Έργα της συσκευής». Μετά διάλεξε το νέο σου έργο. Αν δεν έχεις φτιάξει ακόμα νέο έργο ή χρειάζεσαι περισσότερες πληροφορίες για το πώς γίνεται, δες το εκπαιδευτικό **[Νέο έργο](new-project.md)**.

### 2. Φτιάξε νέο αντικείμενο

Τώρα είσαι έτοιμος να φτιάξεις νέο αντικείμενο. Θα δεις ένα νέο παράθυρο με επτά επιλογές.

![Νέο αντικείμενο (1)](../../../media/game-tutorials/New-Object-1.png)\
Για να το κάνεις, πάτα απλώς το κίτρινο κουμπί + στην κάτω δεξιά γωνία.\
[Άνοιξε την εικόνα](../../../media/game-tutorials/New-Object-1.png)

### 3. Τρόποι δημιουργίας

![Νέο αντικείμενο (2)](../../../media/game-tutorials/New-Object-2.png)\
Αυτές είναι οι επιλογές από τις οποίες μπορείς να διαλέξεις.\
[Άνοιξε την εικόνα](../../../media/game-tutorials/New-Object-2.png)

### 4. Ζωγράφισε εικόνα

Για να είναι όλα όσο πιο εύκολα γίνεται στην αρχή, θα χρησιμοποιήσουμε τη λειτουργία «Ζωγράφισε εικόνα» και θα ζωγραφίσουμε απλώς μια τελεία. Όταν ζωγραφίσεις την τελεία με το Pocket Paint, μπορείς να βγεις από το πρόγραμμα (πηγαίνοντας ένα βήμα πίσω).

### 5. Δώσε όνομα

Τώρα πρέπει να δώσεις όνομα στη ζωγραφιά σου.

### 6. Τοποθέτησέ την

Μετά πρέπει να την τοποθετήσεις οπτικά, μετακινώντας την αριστερά/δεξιά ή πάνω/κάτω με το δάχτυλό σου.

![Νέο αντικείμενο (3)](../../../media/game-tutorials/New-Object-3.png)\
Πρέπει να την αποθηκεύσεις με το κουμπί επάνω δεξιά.\
[Άνοιξε την εικόνα](../../../media/game-tutorials/New-Object-3.png)

### 7. Τα κατάφερες! Έφτιαξες το δικό σου νέο αντικείμενο.

Τώρα έχεις ένα έργο με ένα αντικείμενο που μπορείς να προγραμματίσεις!

Για να το κάνεις αυτό, πρέπει να ξέρεις ποια μπλοκ υπάρχουν. Το εκπαιδευτικό **[Τα πρώτα μπλοκ](first-bricks.md)** σου δίνει μια καλή εικόνα των διαφορετικών κατηγοριών μπλοκ. Μπορείς όμως και να ξεκινήσεις κατευθείαν με το πρώτο σου έργο. Διάλεξε ένα κατάλληλο εκπαιδευτικό από τη σειρά για αρχάριους.
