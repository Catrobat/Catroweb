เมื่อพล็อตเริ่มทำงาน ทุกการเคลื่อนไหวจะถูกวาดเหมือนใช้ปากกาวาด เส้นเหล่านี้คือเส้นที่เครื่องตัดจะตัดตามในภายหลัง

วัตถุของเราชี้ไปทางทิศทาง 150 องศา

ในบทเรียนนี้ เราวาดด้านขวาของหัวแมวก่อน ถ้ามองดี ๆ จะเห็นว่าโค้งแรก ๆ จะแรงมาก ดังนั้นวัตถุต้องหมุนมากขึ้นหลังจากเส้นสั้น ๆ แต่ละเส้น จากนั้นการหมุนจะเล็กลงสำหรับส่วนล่างของหัว ด้านซ้ายของหัวก็โค้งมากอีกครั้ง นั่นคือเหตุผลที่ส่วนนี้ของหัวใช้การวนซ้ำทั้งหมดสามรอบ

ต่อไปคือหูซ้าย หูนี้ประกอบจากเส้นตรงเท่านั้น ดังนั้นเราใช้บล็อก "เดิน __ ก้าว" ได้

ส่วนระหว่างหูเป็นส่วนโค้งอีกครั้ง และเขียนโปรแกรมด้วยการวนซ้ำอีกชุดหนึ่ง

จากนั้นวาดหูขวา

ตอนนี้พล็อตเสร็จแล้ว จบด้วยบล็อก "หยุดพล็อต" และบันทึกลงโทรศัพท์ของคุณด้วย "บันทึกพล็อตเป็น SVG ___"

ตอนนี้คุณส่งไฟล์ SVG ไปยังเครื่องพลอตเตอร์ (ตัด) ได้แล้ว
