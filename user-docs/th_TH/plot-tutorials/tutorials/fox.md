เมื่อพล็อตเริ่มทำงาน ทุกการเคลื่อนไหวจะถูกวาดเหมือนใช้ปากกาวาด เส้นเหล่านี้คือเส้นที่เครื่องตัดจะตัดตามในภายหลัง

จิ้งจอกตัวนี้ประกอบจากเส้นตรงเท่านั้น ("เดิน \_\_\_ ก้าว") และการเลี้ยว

**เคล็ดลับ**: ทดสอบโปรแกรมของคุณไปพร้อม ๆ กับการสร้าง
