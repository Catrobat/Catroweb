![ตั้งประเภทการเคลื่อนที่](../../../media/bricks/set_your_motion_type_brick.png)

เปลี่ยนวิธีที่วัตถุเคลื่อนที่ เช่น ให้มันเคลื่อนที่และเด้งภายใต้แรงโน้มถ่วง ให้มันไม่เคลื่อนที่ภายใต้แรงโน้มถ่วงแต่วัตถุอื่นเด้งออกจากมันได้ หรือให้มันไม่เคลื่อนที่และไม่เด้งภายใต้แรงโน้มถ่วง เหมือนการเลือกว่าตัวละครของคุณควรทำตัวอย่างไรในแง่การเคลื่อนไหวและการโต้ตอบ
