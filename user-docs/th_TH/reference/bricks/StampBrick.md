เมื่อใช้บล็อกนี้ คุณจะทิ้งสำเนาของลักษณะตัวละครของคุณไว้บนหน้าจอ เหมือนการประทับตราสีลงบนกระดาษ แล้วทิ้งสำเนาของลายตราไว้ วิธีนี้ช่วยเพิ่มความสวยงามให้พื้นหลังของคุณ และคุณไม่ได้สร้างโคลนขึ้นมา!
