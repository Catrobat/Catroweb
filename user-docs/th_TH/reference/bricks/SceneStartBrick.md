![เริ่มฉาก](../../../media/bricks/start_scene_brick2.png)

บล็อกนี้สลับไปยังฉากอื่นในโปรเจกต์ของคุณ และเริ่มทำงานฉากนั้นตั้งแต่ต้น เหมือนการเปลี่ยนบทในหนังสือ หรือไปยังด่านถัดไปในเกม

ลองนึกภาพว่าโปรเจกต์ของคุณมีหลายฉาก แต่ละฉากแสดงส่วนต่างกันของเรื่องหรือเกมของคุณ ด้วยบล็อกนี้ คุณกระโดดไปยังฉากไหนก็ได้และเริ่มจากจุดเริ่มต้นของฉากนั้น ทำให้การเปลี่ยนระหว่างส่วนต่าง ๆ ของโปรเจกต์ราบรื่น
