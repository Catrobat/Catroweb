![สำหรับค่าตั้งแต่ ถึง](../../../media/bricks/for-values-from-brick.png)

บล็อกนี้ทำชุดคำสั่งตามจำนวนครั้งที่กำหนด โดยใช้ตัวนับที่เริ่มจากค่าหนึ่งและจบที่อีกค่าหนึ่ง เหมือนการตั้งลูปที่คุณรู้แน่นอนว่าต้องการให้ทำกี่รอบ

ลองนึกภาพว่าคุณมีรายการสิ่งของและอยากทำอะไรกับแต่ละชิ้น บล็อกนี้ให้คุณไล่ดูทีละชิ้น และทำสิ่งเดียวกันกับแต่ละชิ้น
