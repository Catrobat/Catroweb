![บล็อกจบด่าน](../../../media/bricks/finish-stage-brick.png)

บล็อกนี้หยุดสคริปต์ทั้งหมดและจบด่านหรือฉากปัจจุบัน เหมือนการบอกว่า "ส่วนนี้ของโปรเจกต์จบแล้ว" ทุกอย่างจะหยุด และโปรเจกต์อาจไปยังฉากอื่นหรือจบทั้งหมดก็ได้ ใช้เมื่อคุณอยากปิดด่านหรือระดับใดระดับหนึ่งในโปรเจกต์
