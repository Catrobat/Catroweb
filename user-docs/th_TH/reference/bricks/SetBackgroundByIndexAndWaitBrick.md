![ตั้งพื้นหลังเป็นหมายเลข 1 และรอ](../../../media/bricks/Set_background_to_number_1_and_wait_.png)

บล็อกนี้เปลี่ยนพื้นหลังเป็นพื้นหลังที่เจาะจง ตามตำแหน่งในรายการพื้นหลัง และรอจนการเปลี่ยนแปลงเสร็จก่อนจะทำสคริปต์ต่อ เหมือนการเปลี่ยนฉากในละครไปเป็นฉากหลังที่เลือกจากรายการ และหยุดการแสดงไว้จนกว่าฉากใหม่จะถูกจัดเรียบร้อย
