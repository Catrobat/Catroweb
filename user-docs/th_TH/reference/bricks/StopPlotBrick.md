![หยุดพล็อต](../../../media/bricks/Stop_to_plot.png)

บล็อก "หยุดพล็อต" จะหยุดกระบวนการพล็อตชั่วคราว และให้คุณย้ายตัวละครไปยังตำแหน่งใหม่ หรือจบการพล็อต เหมือนการยกปากกาออกจากกระดาษเพื่อวางตำแหน่งใหม่หรือหยุดวาด เมื่อพล็อตเสร็จแล้ว คุณใช้บล็อก "บันทึกพล็อตเป็น SVG" เพื่อบันทึกงานออกแบบของคุณเป็นไฟล์ SVG ได้
