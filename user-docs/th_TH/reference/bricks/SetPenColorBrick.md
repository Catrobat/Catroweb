![ตั้งสีปากกาเป็น แดง 0 เขียว 0 น้ำเงิน 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

บล็อกนี้เปลี่ยนสีของปากกาที่ตัวละครใช้ เหมือนการเปลี่ยนไปใช้ปากกาอีกสีขณะวาดรูป

**แดง เขียว น้ำเงิน (RGB)**: โมเดลสี RGB ใช้ความเข้มของแสงสีแดง เขียว และน้ำเงินต่างกันเพื่อสร้างสีที่หลากหลาย แต่ละองค์ประกอบสี (แดง เขียว น้ำเงิน) มีค่าได้ตั้งแต่ 0 ถึง 255:

- **แดง**: องค์ประกอบสีแดง ค่ายิ่งสูงหมายถึงมีสีแดงมากขึ้น
- **เขียว**: องค์ประกอบสีเขียว ค่ายิ่งสูงหมายถึงมีสีเขียวมากขึ้น
- **น้ำเงิน**: องค์ประกอบสีน้ำเงิน ค่ายิ่งสูงหมายถึงมีสีน้ำเงินมากขึ้น

เมื่อรวมค่าของสีแดง เขียว และน้ำเงินต่างกัน คุณจะสร้างสีใดก็ได้ ตัวอย่างเช่น:

- `RGB(255, 0, 0)` คือสีแดงแท้
- `RGB(0, 255, 0)` คือสีเขียวแท้
- `RGB(0, 0, 255)` คือสีน้ำเงินแท้
- `RGB(255, 255, 255)` คือสีขาว (สีแดง สีเขียว และสีน้ำเงินเต็มที่)
- `RGB(0, 0, 0)` คือสีดำ (ไม่มีสี)

การผสมสีเหล่านี้ในปริมาณต่างกันทำให้เกิดสีทั้งหมดที่คุณเห็นบนหน้าจอดิจิทัล
