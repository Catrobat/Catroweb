![ตั้งสีอนุภาคเป็น '#ff0000′](../../../media/bricks/Set_particle_colour_to_ff0000.png)

บล็อกนี้เปลี่ยนสีของอนุภาคที่ตัวละครปล่อยออกมา เหมือนการเปลี่ยนสีของกระดาษสีที่ปล่อยออกมาจากปืนยิงกระดาษในงานปาร์ตี้

รหัสสีแบบ hex คือวิธีแทนสีด้วยค่าฐานสิบหก ประกอบด้วยตัวอักษรหกตัว ซึ่งอาจเป็นตัวเลข (0-9) หรือตัวอักษร (A-F) โดยปกติจะเขียนโดยมี "#" นำหน้า เช่นนี้: `#RRGGBB`

- สองตัวแรก (`RR`) แทนค่าสีแดง
- สองตัวถัดไป (`GG`) แทนค่าสีเขียว
- สองตัวสุดท้าย (`BB`) แทนค่าสีน้ำเงิน

แต่ละคู่ของตัวอักษรมีค่าได้ตั้งแต่ `00` (หมายความว่าไม่มีสีนั้นเลย) ถึง `FF` (หมายความว่ามีสีนั้นเต็มที่) ตัวอย่างเช่น:

`#000000` คือสีดำ (ไม่มีสี)

`#FF0000` คือสีแดงแท้

`#00FF00` คือสีเขียวแท้

`#0000FF` คือสีน้ำเงินแท้

`#FFFFFF` คือสีขาว (สีแดง สีเขียว และสีน้ำเงินเต็มที่)
