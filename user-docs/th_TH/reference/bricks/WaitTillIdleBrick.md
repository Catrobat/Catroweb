![รอจนกว่าสคริปต์อื่นทั้งหมดจะหยุด](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

บล็อกนี้หยุดสคริปต์ปัจจุบันชั่วคราวจนกว่าสคริปต์อื่นทั้งหมดในโปรเจกต์จะทำงานเสร็จ ลองนึกภาพการพักสคริปต์ของคุณไว้จนกว่าทุกอย่างอื่นจะเสร็จ มีประโยชน์เพื่อให้มั่นใจว่าไม่มีการกระทำอื่นเกิดขึ้นก่อนจะไปยังขั้นตอนถัดไปในสคริปต์ปัจจุบันของคุณ
