![สำหรับแต่ละค่า](../../../media/bricks/for-each-value_brick.png)

บล็อกนี้ทำชุดคำสั่งกับทุกรายการในรายการหรือช่วงค่า เหมือนการไล่ดูทีละรายการและทำสิ่งเดียวกันกับแต่ละรายการ

ลองนึกภาพว่าคุณมีรายการตัวเลข สี หรือสิ่งของอะไรก็ได้ บล็อกนี้ให้คุณหยิบแต่ละรายการออกจากรายการนั้นแล้วทำอะไรบางอย่างกับมัน ตัวอย่างเช่น ถ้าคุณมีรายการสี และอยากเปลี่ยนสีพื้นหลังเป็นแต่ละสีในรายการ คุณจะใช้บล็อกนี้

เหมือนการบอกว่า "สำหรับทุกรายการในกลุ่มนี้ ให้ทำคำสั่งเหล่านี้"
