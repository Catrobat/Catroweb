บล็อกนี้ทำให้ฉากทำงานต่อจากจุดที่หยุดไว้ ถ้าฉากของคุณถูกขัดจังหวะด้วยการหยุดหรือรอ การใช้บล็อกนี้จะให้การกระทำกลับมาทำต่อจากจุดที่ค้างไว้

ลองนึกภาพว่าคุณหยุดเกมหรือแอนิเมชันไว้ และตอนนี้อยากให้มันทำงานต่อ บล็อกนี้ทำหน้าที่เหมือนปุ่มเล่น ทำให้ทุกอย่างกลับมาทำงานต่อจากจุดที่หยุดไว้
