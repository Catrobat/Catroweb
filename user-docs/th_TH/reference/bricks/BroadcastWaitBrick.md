![กระจายข้อความและรอ](../../../media/bricks/brodcast_wait_brick3.png)

ส่งข้อความไปยังส่วนอื่นของโปรเจกต์ แล้วรอจนกว่าพวกเขาทำงานเสร็จก่อนจะไปต่อ เหมือนขอให้เพื่อนทำบางอย่างแล้วรอให้เขาทำเสร็จก่อนที่คุณจะทำต่อ

**ทำไมต้องส่งข้อความกระจาย?**

ด้วยข้อความ คุณสื่อสารและโต้ตอบกันระหว่างวัตถุต่าง ๆ ในฉากได้ วัตถุหนึ่งส่งข้อความให้วัตถุอื่นทั้งหมดได้ และวัตถุที่ได้รับข้อความก็ตอบสนองได้

ข้อความเหล่านี้ **ไม่ถูกแสดง** บนหน้าจอ! ถ้าอยากแสดงข้อความ ให้ใช้บล็อกในหมวด "รูปลักษณ์"

**ทำงานอย่างไร?**

- *วัตถุผู้ส่ง:* วัตถุผู้ส่งเริ่มการสื่อสารด้วยบล็อก *"กระจายข้อความ"* บล็อกนี้ใช้ส่งข้อความไปยังวัตถุอื่นทั้งหมดในฉาก (รวมถึงพื้นหลังด้วย)
- *วัตถุผู้รับ:* วัตถุผู้รับคือตัวที่คอยฟังและตอบสนองต่อข้อความ มันใช้บล็อก *"เมื่อคุณได้รับ"* เพื่อตรวจจับว่ามีข้อความเฉพาะถูกส่งมาหรือไม่
- *การจัดการข้อความ:* เมื่อวัตถุผู้รับได้รับข้อความ มันจะทำบล็อกทั้งหมดที่อยู่ใต้บล็อก *"เมื่อคุณได้รับ"* ทำให้คุณกำหนดพฤติกรรมหรือการกระทำที่เกิดขึ้นเมื่อได้รับข้อความนั้นได้
