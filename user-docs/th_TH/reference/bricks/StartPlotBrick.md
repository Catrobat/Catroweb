![เริ่มพล็อต](../../../media/bricks/Start_to_plot.png)

บล็อกนี้เริ่มกระบวนการพล็อตขณะที่ตัวละครเคลื่อนที่ คล้ายกับการวางปากกาบนกระดาษเพื่อเริ่มวาดเส้น คุณใช้บล็อก "หยุดพล็อต" ได้ถ้าอยากหยุดวาดชั่วคราว ย้ายตัวละครไปยังตำแหน่งอื่น แล้วเริ่มพล็อตอีกครั้งด้วย "เริ่มพล็อต"
