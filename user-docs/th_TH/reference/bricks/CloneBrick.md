บล็อกนี้สร้างสำเนาของวัตถุที่กำหนด เรียกว่าโคลน ซึ่งทำงานเหมือนต้นฉบับ ลองนึกภาพการทำซ้ำตัวละครหรือวัตถุในเกมของคุณ โคลนสามารถมีพฤติกรรมและสคริปต์ของตัวเองได้ ทำให้คุณสร้างวัตถุหลายตัวที่ทำงานแยกจากกันได้
