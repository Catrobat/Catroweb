![เมื่อฉากเริ่ม](../../../media/bricks/When_scene_starts_btn2.png)

ถ้าคุณใช้บล็อกนี้ สคริปต์จะเริ่มทำงานทันทีเมื่อฉากเริ่ม ฉากคือจุดเริ่มต้นของโปรแกรมของคุณ ฉากคือมุมมองใหม่ในโปรแกรมของคุณ ซึ่งองค์ประกอบอื่นสามารถแสดงได้และการโต้ตอบต่าง ๆ เกิดขึ้นได้ คุณมีฉากหลายฉากสำหรับแต่ละช่วงของโปรแกรมได้ เช่น ฉากหนึ่งสำหรับบทนำ ฉากหนึ่งสำหรับเมนูหลัก ฉากหนึ่งสำหรับด่านแรก ฉากหนึ่งสำหรับด่านที่สอง และอื่น ๆ สำหรับโปรแกรมที่ง่ายกว่า ฉากเดียวก็เพียงพอ และจุดเริ่มต้นของโปรแกรมก็คือจุดเริ่มต้นของฉากนั้นด้วย

เหมือนสคริปต์ทุกอันนี้ เริ่มต้นด้วยบล็อกเหตุการณ์: เหตุการณ์กำหนดว่า **เมื่อไร** สคริปต์จะเริ่ม และบล็อกที่ตามมาบอกโปรแกรมว่า **ต้องทำอะไร**
