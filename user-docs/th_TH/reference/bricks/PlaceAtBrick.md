![วางที่ X และ Y](../../../media/bricks/place_at_x_y_brick.png)

ย้ายวัตถุไปยังตำแหน่งที่กำหนดบนหน้าจอ ตามพิกัด x และ y เหมือนการย้ายตัวละครของคุณไปยังจุดที่แน่นอนทันที

ตำแหน่งถูกกำหนดในระบบพิกัดแบบระนาบคาร์ทีเซียน แกน x และแกน y ตัดกันที่จุดกึ่งกลางของหน้าจอ ดังนั้น x = 0 และ y = 0 คือตรงกลางของหน้าจอ
