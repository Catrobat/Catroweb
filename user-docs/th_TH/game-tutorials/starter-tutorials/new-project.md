ในบทเรียนนี้ คุณจะได้เรียนรู้ทุกอย่างที่ต้องรู้เกี่ยวกับ Pocket Code เพื่อเริ่มสร้างโปรเจกต์แรกของคุณ เราจะแนะนำทีละขั้นตอนว่าจะดาวน์โหลดแอป เปิดแอป และสร้างโปรเจกต์ใหม่ได้อย่างไร

![โปรแกรมใหม่](../../../media/game-tutorials/New-Program.png)

นี่คือบทเรียนแรกสุด และคุณไม่ต้องมีความรู้มาก่อนเลย

แล้วจะรออะไรอยู่ล่ะ? หยิบโทรศัพท์ของคุณขึ้นมาแล้วเริ่มเลย!

*ที่นี่คุณดาวน์โหลดบทเรียนในรูปแบบ PDF ได้:*

[โปรแกรมใหม่](../../../media/game-tutorials/New-Program.pdf)

### 1. ติดตั้ง Pocket Code

ขั้นแรก คุณต้องติดตั้งแอป Pocket Code ลงในอุปกรณ์ของคุณ คุณค้นหาแอปได้โดยพิมพ์ "Pocket Code" ใน Google Play สโตร์ แล้วดาวน์โหลดด้วยการกด "ติดตั้ง" ขั้นตอนนี้ต้องใช้บัญชี Google ตอนนี้อุปกรณ์ของคุณจะดาวน์โหลดและติดตั้งแอป ขั้นตอนนี้อาจใช้เวลาสักพักตามความเร็วอินเทอร์เน็ตของคุณ

![โปรแกรมใหม่ (2)](../../../media/game-tutorials/New-Program-2.png)

เมื่อดาวน์โหลดและติดตั้ง Pocket Code สำเร็จแล้ว คุณจะพบแอปในลิ้นชักแอปหรือหน้าจอหลัก ขึ้นอยู่กับอุปกรณ์ของคุณ คุณสามารถย้ายแอปไปวางตรงไหนก็ได้ตามใจชอบ

### 2. เปิดแอป

เมื่อคุณเปิดแอป คุณจะเห็นหมวดหมู่ต่าง ๆ:

![โปรแกรมใหม่ (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. สร้างโปรเจกต์ใหม่

ขั้นต่อไปคือสร้างโปรเจกต์ใหม่ ให้กดปุ่มบวกสีเหลืองที่มุมขวาล่าง ตอนนี้คุณต้องใส่ชื่อโปรเจกต์และเลือกว่าจะให้โปรเจกต์เป็นแนวนอนหรือไม่ เมื่อกด "ตกลง" โปรเจกต์ก็จะถูกสร้างขึ้น

![โปรแกรมใหม่](../../../media/game-tutorials/New-Program.png)

### 4. ทำสำเร็จแล้ว! คุณสร้างโปรเจกต์ของตัวเองแล้ว

ตอนนี้คุณติดตั้ง Pocket Code และรู้วิธีสร้างโปรเจกต์ใหม่แล้ว ตอนนี้คุณก็เริ่มเขียนโปรแกรมได้!

ก่อนอื่น คุณต้องรู้วิธีสร้างตัวละครใหม่ในโปรเจกต์ ลองดูบทเรียน **[ตัวละครใหม่](new-object.md)** ที่อธิบายทุกอย่างทีละขั้นตอน
