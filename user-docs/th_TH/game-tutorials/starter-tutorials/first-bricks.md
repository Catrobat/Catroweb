ในบทเรียนนี้ คุณจะได้เรียนรู้ว่าจะหาบล็อกต่าง ๆ ได้จากที่ไหนเพื่อเขียนโปรแกรมให้วัตถุ นอกจากนี้บทเรียนยังให้ภาพรวมที่ดีของหมวดหมู่บล็อกด้วย

เพื่อใส่บล็อกและเขียนโปรแกรมให้วัตถุของคุณ คุณควรสร้างโปรเจกต์ที่มีวัตถุไว้แล้ว ถ้าต้องการความช่วยเหลือเรื่องนี้ ดูบทเรียน **[ตัวละครใหม่](new-object.md)** ได้

*ที่นี่คุณดาวน์โหลดบทเรียนในรูปแบบ PDF ได้:*

[บล็อกแรก](../../../media/game-tutorials/First-Bricks.pdf)

### 1. เปิดวัตถุที่มีอยู่

ขั้นแรก คุณต้องเปิดโปรเจกต์ของคุณ คุณควรสร้างวัตถุไว้แล้ว (ถ้ายังไม่มี ดูบทเรียน **[ตัวละครใหม่](new-object.md)** ได้) ตอนนี้คุณกดที่ชื่อของวัตถุได้เลย

### 2. บล็อกที่มีอยู่

หลังจากนั้นคุณจะเห็นว่ามีบล็อกบางอันอยู่แล้ว บล็อกเหล่านั้นถูกสร้างขึ้นตอนที่เราวางวัตถุบนหน้าจอ

บล็อกเหล่านี้ทำหน้าที่เพียงวางวัตถุของเราไว้ที่ตำแหน่งที่เราเลือกตอนเริ่มต้น ทันทีที่ฉากเริ่มต้น คุณเปลี่ยนตำแหน่งนี้ได้ตลอดเวลาตรงนี้

::brick{type=StartScript}

::brick{type=PlaceAtBrick}

### 3. ใส่บล็อก

ตอนนี้คุณสร้างบล็อกเพิ่มได้โดยกดปุ่มบวกสีเหลืองที่มุมขวาล่าง คุณจะเห็นหน้าต่างใหม่ที่มีหมวดหมู่บล็อกหลายหมวด หมวดเหล่านี้จะอธิบายในขั้นตอนถัดไป

![บล็อกแรก (1)](../../../media/game-tutorials/First-Bricks-1.png)

### 4. หมวดหมู่บล็อก

นี่คือหมวดหมู่บล็อกต่าง ๆ:

![บล็อกแรก (2)](../../../media/game-tutorials/First-Bricks-2.png)

### 5. ใส่บล็อกแรก

สำหรับบล็อกแรกของเรา เราจะใช้บล็อก "เลื่อนไปใน 1 วินาที ไปยังตำแหน่ง X: Y:" คุณหาบล็อกนี้ได้ในหมวด การเคลื่อนไหว ด้วยตัวแก้ไขสูตร คุณปรับจำนวนวินาที รวมถึงตำแหน่ง X และ Y ได้

::brick{type=GlideToBrick}

### 6. วางบล็อก

วางบล็อกไว้ที่ตำแหน่งสุดท้ายของโปรแกรม แล้วรันโปรแกรมครั้งแรก คุณทำได้ด้วยปุ่มเล่นสีเหลือง

![บล็อกแรก (3)](../../../media/game-tutorials/First-Bricks-3.png)

### 7. ทำสำเร็จแล้ว! คุณใส่บล็อกแรกของคุณแล้ว

ตอนนี้คุณเขียนโปรแกรมให้วัตถุชิ้นแรกของคุณแล้ว!

ถ้าอยากแชร์โปรเจกต์กับเพื่อน ๆ ดูบทเรียน **[อัปโหลดและแชร์](upload-and-share.md)** ซึ่งอธิบายวิธีการทำงานอย่างละเอียด หรือจะเริ่มโปรเจกต์แรกของคุณเองได้เลย ถ้าต้องการความช่วยเหลือหรือแรงบันดาลใจ ลองดูบทเรียนจากชุดระดับมือใหม่ได้เลย

คุณดูข้อมูลเพิ่มเติมเกี่ยวกับบล็อกทั้งหมดได้ [ที่นี่](../../../reference/)!
