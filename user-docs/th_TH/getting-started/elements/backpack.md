ฟีเจอร์ **กระเป๋าเป้** ใน Pocket Code เป็นฟังก์ชันที่ใช้ได้จริง ช่วยให้คุณ **บันทึกและนำกลับมาใช้ซ้ำ** ได้กับองค์ประกอบอย่างตัวละคร (วัตถุ) สคริปต์ รูปลักษณ์ หรือเสียง **ในหลายโปรเจกต์** ช่วยให้คุณประหยัดเวลาและทำให้โปรเจกต์ของคุณมีประสิทธิภาพมากขึ้น

กระเป๋าเป้เหมือนพื้นที่เก็บของดิจิทัล ที่คุณเก็บองค์ประกอบต่าง ๆ จากโปรเจกต์ปัจจุบันได้ เมื่อบันทึกลงกระเป๋าเป้แล้ว คุณสามารถดึงองค์ประกอบเหล่านี้ออกมาใส่ในโปรเจกต์อื่นได้

### ฉันจะใช้กระเป๋าเป้กับตัวละคร (วัตถุ) ได้อย่างไร?

**ใส่ตัวละครลงในกระเป๋าเป้**

ไปที่หน้าโปรเจกต์ของโปรเจกต์ที่คุณต้องการใส่ตัวละครลงในกระเป๋าเป้

กดจุดสามจุดข้างตัวละครเพื่อเปิดเมนูบริบท แล้วเลือก "ใส่กระเป๋าเป้"

ตัวละคร (รวมถึงรูปลักษณ์ เสียง และสคริปต์) จะถูกใส่ลงในกระเป๋าเป้

![ใส่ตัวละครลงกระเป๋าเป้](../../../media/getting-started/grafik-7.png)

**เพิ่มตัวละครจากกระเป๋าเป้**

เปิดโปรเจกต์ที่คุณต้องการใส่ตัวละคร

ในหน้าโปรเจกต์ กดสัญลักษณ์บวกแล้วเลือก "กระเป๋าเป้"

ตอนนี้คุณจะเห็นตัวละครและวัตถุทั้งหมดที่บันทึกไว้ในกระเป๋าเป้ กดจุดสามจุดแล้วเลือก "นำออกจากกระเป๋าเป้"

![นำตัวละครออกจากกระเป๋าเป้](../../../media/getting-started/grafik-8-e1732702791199.png)

***

### ฉันจะใช้กระเป๋าเป้กับสคริปต์ได้อย่างไร?

**ใส่สคริปต์ลงในกระเป๋าเป้:**

ไปที่ตัวละครที่มีสคริปต์นั้น กดค้างที่สคริปต์ที่ต้องการในตัวแก้ไขสคริปต์

เลือก "เพิ่มลงในกระเป๋าเป้" จากเมนูบริบท

![เพิ่มลงในกระเป๋าเป้](../../../media/getting-started/WhatsApp-Bild-2024-11-27-um-11.09.00_bec028aa.jpg)

ตั้งชื่อให้สคริปต์ แล้วยืนยันด้วยปุ่ม ตกลง

![บันทึกตัวละครลงกระเป๋าเป้](../../../media/getting-started/grafik-9.png)

สคริปต์จะถูกบันทึกและนำไปใช้ในโปรเจกต์อื่นได้

![กระเป๋าเป้ของคุณ](../../../media/getting-started/grafik-10.png)

**เพิ่มสคริปต์จากกระเป๋าเป้:**

กดที่ตัวละครที่คุณต้องการใส่สคริปต์ คุณจะเห็นพื้นที่สคริปต์ กดจุดสามจุดเพื่อเปิดเมนูบริบท แล้วกด "กระเป๋าเป้"

![นำสคริปต์ออกจากกระเป๋าเป้](../../../media/getting-started/grafik-11.png)

ตอนนี้คุณเห็นสคริปต์ทั้งหมดที่อยู่ในกระเป๋าเป้แล้ว กดจุดสามจุดข้างสคริปต์ที่ต้องการ แล้วเลือก "นำออกจากกระเป๋าเป้" จากเมนูบริบท

จากเมนูบริบทคุณยังลบสคริปต์ที่ไม่ต้องการแล้วออกจากกระเป๋าเป้ได้ด้วย

![กระเป๋าเป้สำหรับสคริปต์](../../../media/getting-started/grafik-12.png)

***

### ประโยชน์ของกระเป๋าเป้

- **ใช้ซ้ำข้ามโปรเจกต์ได้:** ตัวละคร สคริปต์ เสียง และรูปลักษณ์สร้างครั้งเดียวแล้วนำกลับมาใช้ได้บ่อยเท่าที่ต้องการ
- **ประหยัดเวลา:** คุณไม่ต้องสร้างตัวละครหรือสคริปต์ใหม่ทุกครั้ง
- **ความสม่ำเสมอ:** องค์ประกอบยังคงเหมือนเดิมเมื่อคุณต้องการใช้ในหลายโปรเจกต์
