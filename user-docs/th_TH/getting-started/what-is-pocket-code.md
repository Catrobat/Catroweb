Pocket Code คือแอปหลักของ Catrobat เป็นแอปมือถือฟรีและโอเพนซอร์สที่ให้คุณสร้างเกม แอนิเมชัน และเรื่องราวเชิงโต้ตอบได้ทันทีบนโทรศัพท์หรือแท็บเล็ตของคุณ ด้วย **ระบบการเขียนโปรแกรมแบบบล็อก** ของ Pocket Code คุณสร้างโปรเจกต์ได้โดยการต่อบล็อกคำสั่งเข้าด้วยกัน เหมือนการต่อจิ๊กซอว์ ไม่ต้องมีประสบการณ์การเขียนโปรแกรม เหมาะมากสำหรับมือใหม่!

Pocket Code ทำได้มากกว่าโปรเจกต์ดิจิทัล ด้วย **ฟีเจอร์แบบ makerspace** ใหม่ ๆ คุณยังออกแบบไฟล์ **SVG สำหรับเครื่องตัดพลอตเตอร์** ได้ด้วย นั่นหมายความว่าคุณสามารถเปลี่ยนสิ่งที่สร้างบนหน้าจอให้เป็นของจริงได้ และสำรวจความเป็นไปได้ที่สร้างสรรค์นอกเหนือจากหน้าจอ

ไม่ว่าคุณจะกำลังเรียนการเขียนโปรแกรม ลองไอเดียใหม่ ๆ หรือกำลังสอนการเขียนโปรแกรม Pocket Code ก็มีวิธีที่สนุกและเข้าถึงได้ง่ายให้คุณเริ่มเขียนโปรแกรมได้
