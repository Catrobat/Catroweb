กดปุ่มบวกเพื่อเพิ่มตัวละครหรือวัตถุใหม่ให้โปรเจกต์ของคุณ

![เพิ่มตัวละคร](../../../media/getting-started/FigurHinzufuegen.png)

ใน Pocket Code คุณเพิ่มตัวละครหรือวัตถุให้โปรเจกต์ได้หลายวิธี:

**วาดรูป**: คุณสร้างตัวละครของตัวเองด้วย **Pocket Paint** ได้ Pocket Paint คือโปรแกรมวาดรูป ([ดูเพิ่มเติมเกี่ยวกับ Pocket Paint](https://catrobat.org/pocket-paint/))

**รูปลักษณ์**: เลือกจากชุดตัวละครและวัตถุที่เตรียมไว้ ([ดูเพิ่มเติมเกี่ยวกับคลังสื่อ](../elements/medialibrary.md))

**แกลเลอรี**: คุณเลือกรูปจากแกลเลอรีของสมาร์ทโฟนได้

**ไลบรารี**: ในไลบรารี คุณจะพบตัวละครและวัตถุที่เขียนโปรแกรมไว้แล้ว หมายความว่ามีสคริปต์อยู่แล้ว คุณเลือกใช้ได้ถ้าอยากใช้องค์ประกอบสำเร็จรูปในเกมของคุณ (เช่น การนับถอยหลัง) ([ดูเพิ่มเติมเกี่ยวกับไลบรารี](../elements/medialibrary.md#เพิ่มวัตถุจากคลังสื่อ))

**ถ่ายภาพ**: คุณใช้กล้องของอุปกรณ์ถ่ายรูปและเพิ่มเป็นตัวละครได้

**กระเป๋าเป้**: กระเป๋าเป้ตอนนี้ยังว่างอยู่ คุณนำตัวละครหรือวัตถุที่เก็บไว้ในกระเป๋าเป้มาใช้ซ้ำได้ สคริปต์ทั้งหมดจะถูกนำออกมาพร้อมกัน ([ดูเพิ่มเติมเกี่ยวกับกระเป๋าเป้](../elements/backpack.md))

**ตัวละครและวัตถุในเครื่อง**: ตรงนี้คุณจะพบตัวละครสำเร็จรูปที่ใช้ในโปรเจกต์ได้ ตัวละครและวัตถุในเครื่องทำงานเหมือนคลังสื่อแบบออฟไลน์ ดังนั้นแม้ไม่มีอินเทอร์เน็ต คุณก็เข้าถึงตัวละครเหล่านี้ได้

**วัตถุว่างเปล่า**: เพิ่มวัตถุเปล่า ซึ่งเป็นวัตถุที่ไม่มีรูปร่าง คุณเขียนโปรแกรมให้วัตถุนี้ได้ตามปกติ

**โปรเจกต์ในเครื่อง**: เลือกโปรเจกต์ที่คุณต้องการนำตัวละครตัวแรกพร้อมสคริปต์มาใส่ในโปรเจกต์ของคุณ
