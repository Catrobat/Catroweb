เมื่อคุณเปิด Pocket Code คุณจะเห็นหน้าจอหลักดังต่อไปนี้

![หน้าจอหลัก](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
เมื่อคุณเปิด Pocket Code คุณจะเห็นหน้าจอหลักดังต่อไปนี้\
[เปิดรูปภาพ](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![ช่วยเหลือ](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
ที่มุมขวาบน มีสัญลักษณ์ ซึ่งจะพาคุณไปยังเอกสารของ Catrobat ที่มีเคล็ดลับดี ๆ ให้คุณ

![เมนู](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
ถัดมาคือเมนู จากตรงนั้นคุณไปที่การตั้งค่าได้ง่าย ๆ ซึ่งคุณสามารถเปลี่ยนภาษา หรือเปิดส่วนเสริมอย่างบล็อกพลอตและอื่น ๆ ได้

![ไอคอนแก้ไข](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
ด้านล่างจะเห็นโปรเจกต์ที่คุณแก้ไขล่าสุด กดไอคอนแก้ไข เพื่อเข้าไปหน้าโปรเจกต์ และพัฒนาโปรเจกต์ของคุณต่อได้

![เริ่มโปรเจกต์ของคุณ](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
กดปุ่มเล่น เพื่อเริ่มโปรเจกต์ของคุณ

![โปรเจกต์ในอุปกรณ์](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
กด "โปรเจกต์ในอุปกรณ์" เพื่อเข้าถึงโปรเจกต์ที่คุณบันทึกไว้

![ชุมชน Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
ถ้าอยากรู้จักและทำงานกับโปรเจกต์ของผู้ใช้คนอื่น ๆ ให้กด Catrobat Community ใน Share ที่นั่นคุณจะพบโปรเจกต์สนุก ๆ มากมาย

![เพิ่ม](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
ถ้าอยากสร้างโปรเจกต์ใหม่ ให้กดไอคอนบวก
