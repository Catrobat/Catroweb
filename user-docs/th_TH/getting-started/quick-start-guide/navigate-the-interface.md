เมื่อคุณเปิด Pocket Code คุณจะเห็นหน้าจอหลักดังต่อไปนี้

![หน้าจอหลัก](../../../media/getting-started/MainScreen-e1732269599192.jpg)

ที่มุมขวาบน มีสัญลักษณ์ ![ช่วยเหลือ](../../../media/getting-started/Screenshot-2024-11-22-111748.png) ซึ่งจะพาคุณไปยังเอกสารของ Catrobat ที่มีเคล็ดลับดี ๆ ให้คุณ

ถัดมาคือเมนู ![เมนู](../../../media/getting-started/Screenshot-2024-11-22-111804.png) จากตรงนั้นคุณไปที่การตั้งค่าได้ง่าย ๆ ซึ่งคุณสามารถเปลี่ยนภาษา หรือเปิดส่วนเสริมอย่างบล็อกพลอตและอื่น ๆ ได้

ด้านล่างจะเห็นโปรเจกต์ที่คุณแก้ไขล่าสุด กดไอคอนแก้ไข ![ไอคอนแก้ไข](../../../media/getting-started/Screenshot-2024-11-22-111825.png) เพื่อเข้าไปหน้าโปรเจกต์ และพัฒนาโปรเจกต์ของคุณต่อได้

กดปุ่มเล่น ![เริ่มโปรเจกต์ของคุณ](../../../media/getting-started/Screenshot-2024-11-22-111818.png) เพื่อเริ่มโปรเจกต์ของคุณ

กด "โปรเจกต์ในอุปกรณ์" เพื่อเข้าถึงโปรเจกต์ที่คุณบันทึกไว้ ![โปรเจกต์ในอุปกรณ์](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

ถ้าอยากรู้จักและทำงานกับโปรเจกต์ของผู้ใช้คนอื่น ๆ ให้กด Catrobat Community ใน Share ที่นั่นคุณจะพบโปรเจกต์สนุก ๆ มากมาย ![ชุมชน Catrobat](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

ถ้าอยากสร้างโปรเจกต์ใหม่ ให้กดไอคอนบวก ![เพิ่ม](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
