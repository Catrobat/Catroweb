![โปรเจกต์ใหม่](../../../media/getting-started/NewProject.png)\
ตั้งชื่อโปรเจกต์ (1) และเลือกว่าคุณอยากสร้างเกมในแนวตั้ง (portrait) หรือแนวนอน (landscape) (2) จากนั้นยืนยันด้วยเครื่องหมายถูก (3)\
[เปิดรูปภาพ](../../../media/getting-started/NewProject.png)

ตอนนี้คุณอยู่ในหน้าโปรเจกต์แล้ว ด้านบนคุณจะเห็นชื่อของเกม

ด้านล่างคุณจะเห็น **พื้นหลัง** ตอนนี้พื้นหลังยังว่างอยู่ ถ้าอยากเปลี่ยน ให้กดที่พื้นหลัง

ใต้พื้นหลังคือพื้นที่สำหรับ **ตัวละครและวัตถุ** ที่คุณเพิ่มลงในเกม ตอนนี้พื้นที่นี้ยังว่างอยู่

ที่มุมขวาล่างคุณจะเห็นปุ่มสำคัญสองปุ่ม:

![เริ่ม](../../../media/getting-started/Start.png)\
ด้วยปุ่ม **เล่น** คุณจะเริ่มเกมของคุณ

![ปุ่มบวก](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
ด้วยปุ่ม **บวก** คุณจะเพิ่มตัวละคร/วัตถุใหม่ให้เกมของคุณ
