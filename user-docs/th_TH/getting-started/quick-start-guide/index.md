Pocket Code คือแอปการเขียนโปรแกรมแบบภาพที่ให้คุณสร้างเกม แอนิเมชัน และเรื่องราวเชิงโต้ตอบได้โดยตรงบนโทรศัพท์หรือแท็บเล็ต ใช้การลากและวางที่เข้าใจง่ายกับ "บล็อก" (บล็อกคำสั่ง) คุณจึงออกแบบโปรเจกต์ได้โดยไม่ต้องมีประสบการณ์การเขียนโปรแกรมมาก่อน เพิ่มเสียง รูปภาพ และการเคลื่อนไหวได้ง่าย ๆ เพื่อทำให้ไอเดียของคุณมีชีวิตขึ้นมา

คู่มือนี้จะช่วยให้คุณเริ่มต้นได้ โดยอธิบายวิธี:

- ดูและใช้งานหน้าจอของแอป
- สร้างโปรเจกต์แรกของคุณ
- ทำงานกับตัวละครและพื้นหลัง
- ใช้บล็อกเพื่อสั่งให้ตัวละครทำสิ่งต่าง ๆ และ
- บันทึกโปรเจกต์ของคุณ

ทั้งมือใหม่และครูผู้สอนก็ใช้ Pocket Code ได้ดี มันส่งเสริมความคิดสร้างสรรค์ ทักษะการแก้ปัญหา และการคิดอย่างมีเหตุผล
