ในบทเรียนนี้ คุณจะได้เรียนรู้วิธีปักท้องฟ้ายามค่ำคืน (48.5 x 96.1 มม.)

![ท้องฟ้ายามค่ำคืน](../../../media/embroidery-tutorials/Nachthimmel.png)

คุณควรรู้ก่อนว่าการวนซ้ำคืออะไรและทำงานอย่างไร

บทเรียน **[ดาว](../embroidery-tutorials-beginner/star.md)** อาจช่วยคุณในบทเรียนนี้ได้

ก็ช่วยได้เช่นกันถ้าคุณคุ้นเคยกับฟังก์ชันการกระจายข้อความอยู่แล้ว

ลองดูบทเรียนงานปักใน ชุด [ระดับมือใหม่](../embroidery-tutorials-beginner/index.md) ถ้าคุณยังไม่เคยปักอะไรมาก่อน

หากต้องการข้อมูลเพิ่มเติมหรือไอเดียการออกแบบ ลองดูบทเรียนอื่น ๆ
