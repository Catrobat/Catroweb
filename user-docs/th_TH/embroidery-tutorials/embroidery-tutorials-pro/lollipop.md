![ลูกอม (2)](../../../media/embroidery-tutorials/Lollipop-2.png)

คุณควรรู้ก่อนว่าการวนซ้ำคืออะไรและทำงานอย่างไร

บทเรียน **[วงกลม](../embroidery-tutorials-beginner/circle.md)** อาจช่วยคุณในบทเรียนนี้ได้
