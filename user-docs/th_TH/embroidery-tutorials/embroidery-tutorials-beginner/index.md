อยากสร้างสรรค์และเรียนการเขียนโปรแกรมไปพร้อมกันแบบสนุก ๆ ไหม? อยากสร้างสิ่งที่คุณใช้ สวมใส่ และชื่นชมได้ทันทีหรือเปล่า?

ด้วย Embroidery Designer คุณสามารถเขียนโปรแกรมเครื่องปักโดยไม่ต้องมีประสบการณ์มาก่อน เครื่องนี้จะปักงานออกแบบของคุณลงบนเสื้อยืด กระเป๋า กางเกง เคสโทรศัพท์ หรือแม้แต่รองเท้าของคุณโดยอัตโนมัติ การปักทำได้กับทุกอย่างที่ทำจากผ้า ปล่อยให้จินตนาการและความคิดสร้างสรรค์ของคุณได้โลดแล่น! คุณดาวน์โหลดและแก้ไขงานออกแบบของคนอื่นจากชุมชน Catrobat ได้ และแน่นอน คุณยังแชร์โปรเจกต์ของคุณกับเพื่อนและทั่วโลกได้ด้วย!
