ในบทเรียนนี้ คุณจะได้เรียนรู้วิธีบันทึกและแชร์งานออกแบบที่เสร็จแล้วบนอุปกรณ์มือถือของคุณ

สำหรับขั้นตอนนี้ คุณต้องมีงานออกแบบปักที่เสร็จแล้วซึ่งต้องการส่งออก ถ้ายังไม่มี ลองหาแรงบันดาลใจจาก [บทเรียนงานปักของเรา](index.md)!

*ที่นี่คุณดาวน์โหลดบทเรียนในรูปแบบ PDF ได้*:

[ส่งออกงานออกแบบ](../../../media/embroidery-tutorials/Export-Designs.pdf)

### 1. เริ่มโปรเจกต์ของคุณและรอจนกว่าจะคลี่ออกเต็มที่ มิฉะนั้นลวดลายจะไม่สมบูรณ์

### 2. กดย้อนกลับและกดปุ่มแชร์

![ส่งออกงานออกแบบ (1)](../../../media/embroidery-tutorials/Export-Designs-1.png)

### 3. แชร์ไฟล์งานปักของคุณทางอีเมลหรือบันทึกลงโทรศัพท์ของคุณ

![ส่งออกงานออกแบบ (2)](../../../media/embroidery-tutorials/Export-Designs-2.png)

ฟังก์ชันการแชร์อาจดูต่างออกไปเล็กน้อยในโทรศัพท์แต่ละรุ่น

งานออกแบบงานปักของคุณจะถูกบันทึกเป็นไฟล์ DST

เครื่องปักรู้จักรูปแบบไฟล์นี้ และจะปักงานออกแบบของคุณลงบนผ้าให้เสร็จ
