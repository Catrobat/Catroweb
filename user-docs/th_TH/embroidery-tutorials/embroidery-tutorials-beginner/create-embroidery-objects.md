ในบทเรียนนี้ คุณจะได้เรียนรู้วิธีสร้างตัวละครที่คุณจะใช้ปักลวดลายของคุณได้ในภายหลัง

สำหรับบทเรียนนี้ คุณควรรู้วิธีสร้างโปรเจกต์มาก่อน ลองดูบทเรียนจาก [ชุดเริ่มต้น](../../game-tutorials/starter-tutorials/index.md) ถ้าต้องการความช่วยเหลือ

หากต้องการข้อมูลเพิ่มเติมหรือไอเดียการออกแบบ ลองดูบทเรียนอื่น ๆ

*ที่นี่คุณดาวน์โหลดบทเรียนในรูปแบบ PDF ได้*:

[สร้างตัวละครงานปัก](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. กดปุ่มบวกที่มุมขวาล่างของโปรเจกต์ของคุณเพื่อเพิ่มตัวละครใหม่

![สร้างตัวละครงานปัก](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. หากต้องการเลือกรูป ให้ไปที่คลังสื่อ

![สร้างตัวละครงานปัก (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. ตัวละครงานปักแทนเข็มหนึ่งระดับของเครื่องปัก ตัวละครงานปักหลายตัวจะถูกปักต่อกันทีละตัว ซึ่งทำให้ใช้หลายสีได้

คุณเลือกตัวละครตามสีที่ต้องการได้

เลื่อนลงและค้นหาลูกศรที่เหมาะสม

![สร้างตัวละครงานปัก (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. ตั้งชื่อที่เหมาะสมให้ตัวละครใหม่ของคุณ แล้วกด ตกลง

![สร้างตัวละครงานปัก (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. ตอนนี้คุณสร้างตัวละครใหม่แล้ว คุณเพิ่มสคริปต์และเขียนโปรแกรมให้ตัวละครได้

![สร้างตัวละครงานปัก (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

ตอนนี้คุณรู้วิธีสร้างตัวละครแล้ว เพิ่มตัวละครใหม่สำหรับแต่ละสีที่อยากใช้

คุณเพิ่มสคริปต์ในแต่ละสีได้ และเขียนโปรแกรมลวดลายของคุณเอง แล้วปักลงไปในภายหลังได้
