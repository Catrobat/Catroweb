ให้เครื่องเย็บต่อเนื่องด้วยความยาวที่ปรับได้

โดยปกติคุณจะใช้การเย็บแบบด้นตรงร่วมกับบล็อกเคลื่อนที่

![เริ่มเย็บแบบด้นตรงความยาว 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

เครื่องจะเริ่มการเย็บแบบด้นตรง ซึ่งจะเย็บทุก **10 ก้าว**

จากนั้นเครื่องเคลื่อนที่ **200 ก้าว**

ผลลัพธ์คือ **20 จุดเย็บ**

![การเย็บแบบด้นตรง](../../../../media/embroidery-tutorials/RunningStitch.png)

การเย็บแบบด้นตรงทำให้การเย็บตะเข็บง่ายขึ้น เพราะคุณไม่ต้องใช้การวนซ้ำอีกต่อไป
