ในบทเรียนนี้ คุณจะได้เรียนรู้ทุกอย่างที่ต้องรู้เกี่ยวกับบล็อกงานปัก!

คุณไม่จำเป็นต้องมีความรู้การเขียนโปรแกรมสำหรับบทเรียนนี้

บล็อกงานปักแต่ละอันจะอธิบายพร้อมตัวอย่าง

ถ้าคุณยังไม่ได้เปิดใช้งานบล็อกงานปัก ลองดูบทเรียน **[เปิดใช้งานบล็อกงานปัก](../activate-embroidery-bricks.md)**

*ที่นี่คุณดาวน์โหลดบทเรียนในรูปแบบ PDF ได้*:

[บล็อกงานปัก](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**คลิกที่บล็อกต่าง ๆ เพื่อดูข้อมูลเพิ่มเติม:**

[![เย็บ](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*ให้เครื่องเย็บลงในผ้าหนึ่งครั้ง!*

[![เริ่มเย็บแบบด้นตรงความยาว 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*ให้เครื่องเย็บต่อเนื่องด้วยความยาวที่ปรับได้*

[![เริ่มเย็บแบบซิกแซกความยาว 2 และความกว้าง 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*เย็บต่อเนื่องด้วยความยาวและความกว้างที่ปรับได้*

[![เริ่มเย็บแบบสามเส้นความยาว 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*การเย็บแบบสามเส้นจะเย็บทุกจุดสามครั้ง*

[![หยุดการเย็บปัจจุบัน](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*ให้การเย็บปัจจุบันหยุดลง*

คุณดูบล็อกงานปักเพิ่มเติมและข้อมูลเกี่ยวกับบล็อกเหล่านั้นได้ [ที่นี่](../../../../reference/#category_embroidery)

หากต้องการข้อมูลเพิ่มเติมหรือไอเดียการออกแบบ ลองดูบทเรียนอื่น ๆ ได้!
