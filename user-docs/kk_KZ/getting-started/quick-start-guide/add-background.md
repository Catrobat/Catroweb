Жобаңыздың тінін Catrobat дегеннен қосуға болады.

Тақырыбы әртүрлі жолдармен қолданылуы мүмкін. Pocket Code -де оларды көрнекті түрде көтеру үшін **ойын**, айту үшін **оқиғалар** немесе актерлеріңіз бен объектілеріңізді көбірек контекстпен қамтамасыз ету үшін пайдалануға болады.

**мылтықшы** немесе **тігісу машиналары** сияқты мейкиндік жасау құрылғылары үшін, тігінен жасалған кесулер немесе сайма үлгілері сияқты жобалау шаблондары ретінде қызмет етеді.

![Тақырыбы туралы кеңес](../../../media/getting-started/grafik-16.png)\
Баяғыны қосу үшін жоба көрінісінде «Фон» дегенді бас.\
[Суретті аш](../../../media/getting-started/grafik-16.png)

**сценарий бөлім(2)** -де сен фонуңызды бағдарламалай аласың, бірақ бұл үшін барлық блоктар да жоқ. Келесі екі блок ерекше маңызды: ![Мөлдірлік 50%](../../../media/bricks/Set_transparency_to_50_pct_.png) және ![Өлшемді орнату: 60%](../../../media/bricks/Set_size_to_60_pct_.png)

**көрінісі бөлім(1)** дегенге фонуны қосу керек.

![Тақырыбы](../../../media/getting-started/grafik-14.png)\
Бұл үшін + символын бас.\
[Суретті аш](../../../media/getting-started/grafik-14.png)

Сен өзіңіздің суреттеріңізді жүктей аласың, алдын ала анықталған фонуларды пайдалана аласың немесе өзіңіз фону жасай аласың.

**Салу**: Сен өзіңіздің фонусын жасай аласың **Pocket Paint**. Pocket Paint - бұл сурет салу бағдарламасы ([туралы көбірек Pocket Paint](https://catrobat.org/pocket-paint/))

**Суреттер**: Алдын ала жасалған фондарының жинағынан бірін таңда ([Media кітапханасы туралы көбірек](../elements/medialibrary.md)).

**Галерея**: Смартфоныңыздың галереясынан суретті таңдауға болады.

**Камера**: Сен құрылғыңыздың камерасын пайдаланып, сурет түсіріп, оны фон ретінде қоса аласың.

![Медиа кітапханасынан таңдау](../../../media/getting-started/grafik-17.png)\
**Жоба көрінісі** дегенге қайтару үшін оң жақтағы артқы жебеді бас.\
[Суретті аш](../../../media/getting-started/grafik-17.png)

Сен енді бір тақырыпты қостыңыз.
