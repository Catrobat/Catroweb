Pocket Code басталған кезде келесі негізгі экран көрінеді.

![Негізгі экран](../../../media/getting-started/MainScreen-e1732269599192.jpg)

Оң жақ жоғарғы бұрышта ![Көмек](../../../media/getting-started/Screenshot-2024-11-22-111748.png) символы бар, ол сізді Catrobat құжаттамасына алып келеді.

Оның жанында меню ![МЕНУ](../../../media/getting-started/Screenshot-2024-11-22-111804.png) бар. Сол жерден сен әдебиеттерді өзгерте аласың немесе карта блоктары сияқты кеңейтулерді қосуға болады.

Төменде сен соңғы рет өңделген жобаңызды көре аласың. Жоба экранына кіру үшін редакциялау таңбасына ![Айкондарын өңдеу](../../../media/getting-started/Screenshot-2024-11-22-111825.png) бас, онда жобаңызды дамытуды жалғастыра аласың.

Жобаңызды бастау үшін ойнау батырмасын ![Жобаңызды бастаңыз](../../../media/getting-started/Screenshot-2024-11-22-111818.png) қолданыңыз.

Жобалар батырмасын басып, сақталған жобаларға қол жеткізе аласың. ![Құрылғы бойынша жобалар](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

Егер сен басқа пайдаланушылардың қосымша жобаларын біліп, жұмыс істегіңіз келсе, Catrobat Community on Share дегенді бас. Сол жерде көптеген керемет жобалар болады. ![Catrobat Қоғамдық](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

Егер сен жаңа жоба құруды қаласаңыз, плюс таңбашасына бас. ![Қосылу](../../../media/getting-started/Screenshot-2024-11-22-143219.png)
