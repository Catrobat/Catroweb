Pocket Code басталған кезде келесі негізгі экран көрінеді.

![Негізгі экран](../../../media/getting-started/MainScreen-e1732269599192.jpg)\
Pocket Code басталған кезде келесі негізгі экран көрінеді.\
[Суретті аш](../../../media/getting-started/MainScreen-e1732269599192.jpg)

![Көмек](../../../media/getting-started/Screenshot-2024-11-22-111748.png)\
Оң жақ жоғарғы бұрышта символы бар, ол сізді Catrobat құжаттамасына алып келеді.

![МЕНУ](../../../media/getting-started/Screenshot-2024-11-22-111804.png)\
Оның жанында меню бар.

Сол жерден сен әдебиеттерді өзгерте аласың немесе карта блоктары сияқты кеңейтулерді қосуға болады.

![Айкондарын өңдеу](../../../media/getting-started/Screenshot-2024-11-22-111825.png)\
Жоба экранына кіру үшін редакциялау таңбасына бас, онда жобаңызды дамытуды жалғастыра аласың.

Төменде сен соңғы рет өңделген жобаңызды көре аласың.

![Жобаңызды бастаңыз](../../../media/getting-started/Screenshot-2024-11-22-111818.png)\
Жобаңызды бастау үшін ойнау батырмасын қолданыңыз.

![Құрылғы бойынша жобалар](../../../media/getting-started/Screenshot-2024-11-22-111832.png)\
Жобалар батырмасын басып, сақталған жобаларға қол жеткізе аласың.

![Catrobat Қоғамдық](../../../media/getting-started/Screenshot-2024-11-22-111847.png)\
Егер сен басқа пайдаланушылардың қосымша жобаларын біліп, жұмыс істегіңіз келсе, Catrobat Community on Share дегенді бас.

Сол жерде көптеген керемет жобалар болады.

![Қосылу](../../../media/getting-started/Screenshot-2024-11-22-143219.png)\
Егер сен жаңа жоба құруды қаласаңыз, плюс таңбашасына бас.
