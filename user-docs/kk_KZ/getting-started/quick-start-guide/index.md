Pocket Code - бұл бейнелік бағдарламалау бағдарламасы, ол саған тікелей смартфон немесе планшетіңізден ойындар, анимациялар және интерактивті әңгімелер жасауға мүмкіндік береді. «код блоктары» (код блоктары) арқылы интерфейсті сүйреп тастау арқылы сен жобаларыңызды алдын ала бағдарламалау тәжірибесі жоқ түрде жасай аласың. Ойларыңызды өмірге айналдыру үшін, дыбыстарды, суреттерді және қозғалыстарды қосу оңай.

Бұл нұсқаулық саған келесідей нәрселерді түсіндіру арқылы көмектеседі:

- Интерфейсті жүруге,
- Алғашқы жобаңызды жасаңыз
- Нысандар мен фонда жұмыс істеу,
- Бағдарламалық әрекеттер үшін код блоктарын қолдану және
- Жобаңызды сақтаңыз.

Алғашқылар мен білім берушілер үшін өте қолайлы Pocket Code шығармашылықты, проблемаларды шешуді және логикалық ойлауды ынталандырады.
