Телефоныңда немесе планшетіңде қолданбаны аш. Жаңа жоба жасау үшін + белгісін бас.

![Негізгі экран Жаңа жоба](../../../media/getting-started/MainScreen_NewProject.png)

Жобаңа атау бер (1). Ойын экраны тік (портрет) не көлденең (альбом) болатынын таңда (2). Содан кейін растау үшін құсбелгіні бас (3).

![Жаңа жоба](../../../media/getting-started/NewProject.png)

Енді сен жобаңыздың көрінісіне иесіз. Жоғарыда ойынның атауы көрінеді.

Төменде **Фон** - қазіргі уақытта, аясы бос. Егер оны өзгерте білсеңіз, оған бас.

Баяғы аяғында сен ойыныңызға қосқан **актерлер мен заттар** аймағын көресің. Қазіргі уақытта бұл аймақ әлі де бос.

Оң жақ төменгі жағында екі маңызды батырманы көресің:

![Бастаңыз](../../../media/getting-started/Start.png) Қатысу **Ойнау** Батырма, ойынды бастаңыз.

![Қосымша Батырма](../../../media/getting-started/Screenshot-2024-11-22-143219.png) **Қосымша** батырмасымен сен ойыныңызға жаңа кейіпкер/объектін қосыңыз.

![Жоба экран](../../../media/getting-started/ProjectScreen-1-e1732694778782.jpg)
