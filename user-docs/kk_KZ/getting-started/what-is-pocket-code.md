Pocket Code — Catrobat жобасының негізгі қолданбасы. Ол тегін және ашық кодты. Онымен телефоныңда немесе планшетіңде ойын, анимация және интерактивті оқиға жасай аласың. Pocket Code-та **код блоктармен құралады**. Жоба жасау үшін код блоктарын пазл бөліктері сияқты біріктір. Бастау үшін бағдарламалау тәжірибесі қажет емес!

Pocket Code тек қана цифрлық жобалардан тыс. Жаңа **makerspace ерекшеліктері** арқылы сен сондай-ақ **SVG кесушілерді кесу үшін файлдар** жобалай аласың. Бұл сенің цифрлық шығармаларыңызды нақты дүниедегі заттарға айналдыра аласың және экраннан тыс шығармашылық мүмкіндіктерді зерттей аласың.

Сен кодтануды үйреніп жатырсыз ба, жаңа идеялармен тәжірибе жасап жатырсыз ба, немесе бағдарламалауды үйретудесіз бе, Pocket Code кодтауға кірудің ойыншықты және қолжетімді әдісін ұсынады
