Бұл оқу құралында сен жобаңызда жаңа нысанды қалай құруға болатынын және осы үшін әртүрлі мүмкіндіктерді үйренесің.

![Жаңа нысан](../../../media/game-tutorials/New-Object.png)

Бұл үшін сен Pocket Code қосымшасын жүктеген және жаңа жобаны қалай құру керектігін білген болуыңыз керек. Егер саған бұл үшін көмек қажет болса, **[Жаңа жоба](new-project.md)** -тітуарлыққа көз жүгірте аласың.

*Мұнда сен PDF форматында оқу құралын жүктей аласың:*

[Жаңа нысан](../../../media/game-tutorials/New-Object.pdf)

### 1. Жаңа нысанды құру

Алдымен жаңа жобаңызды ашуыңыз керек.

Сен оны Pocket Code қосымшасының үй экранында таба аласың. Егер сен бірден астам жобаңыз болса, «Жобалар» дегенді батырмаға қойыңыз. Содан кейін жаңа жобаңызды таңда. Егер сен жаңа жобаны жасаған жоқсыз немесе оны қалай жасау керектігі туралы қосымша ақпарат қажет болса, **[Жаңа жоба](new-project.md)** -тітуарлық бағанды қараңыз.

### 2. Жаңа нысанды құру

Енді сен жаңа нысанды жасауға дайынсыз. Мұны істеу үшін оң жақ төменгі жаңсақ батырманы бас. Саған таңдаудың жеті мүмкіндікін беретін жаңа терезе көрінеді.

![Жаңа нысан (1)](../../../media/game-tutorials/New-Object-1.png)

### 3. Жаратудың жолдары

Сен мына мүмкіндіктерді таңдап ала аласың:

![Жаңа нысан (2)](../../../media/game-tutorials/New-Object-2.png)

### 4. Сурет салу

Алдымен ең оңай болу үшін «Салу» функциясы арқылы нүктелерді сызғызамыз. Pocket Paint арқылы нүкте тартқаннан кейін оны тастай аласың (бір қадам артта қалу арқылы).

### 5. Атыңызды беріңіз

Енді суретке бір есім беруіңіз керек.

### 6. Оларды орнату

Содан кейін оны сол жаққа немесе оң жаққа немесе жоғары/төменге саусағыңызбен ауыстырып, көрнекті түрде орналастырыңыз. Оны оң жақ жоғарғы бұрыштағы батырмамен сақтау керек.

![Жаңа нысан (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. Сен өзіңіздің жаңа зауытыңызды жасадыңыз.

Енді сен бағдарламалай алатын нысан бар жобаңыз бар!

Бұл үшін сен қандай код блоктарын білуіңіз керек. **[Бірінші код блоктары](first-bricks.md)** -тіуorial саған код блоктарының әртүрлі санаттарының жақсы шолуын береді. Алайда, сен бірінші жобаңыздан да тікелей бастауыңыз мүмкін. Бастапқылар сериясынан қолайлы оқу құралын таңда.
