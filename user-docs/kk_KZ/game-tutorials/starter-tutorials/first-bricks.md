Бұл оқу құралында сен нысанды бағдарламалау үшін әртүрлі код блоктарын қайдан табуға болатынын білесіз. Сонымен қатар, бұл оқулық код блогы санаттарының жақсы шолуын ұсынады.

![Бірінші код блоктары](../../../media/game-tutorials/First-Bricks.png)

Код блоктарын қосу және объектіні бағдарламалау үшін сен объектпен жобаны құру керек. Егер саған бұл үшін көмек қажет болса, **[Жаңа нысан](new-object.md)** -тітуарлы қараңыз.

*Мұнда сен PDF форматында оқу құралын жүктей аласың:*

[Бірінші код блоктары](../../../media/game-tutorials/First-Bricks.pdf)

### 1. Бар нысанды ашу

Алдымен жобаңызды ашу керек. Сен объектіні бұрыннан құрыған болуыңыз керек (егер жоқ болса, **[Жаңа нысан](new-object.md)** -тітуарлықты тексеріңіз). Енді сен нысанның атына түрте аласың.

### 2. Қолданыстағы код блоктары

Содан кейін сен біраз код блоктары бар екенін көресің. Бұл код блоктары біз объектіні көрнекті түрде орналастырған кезде пайда болды.

Бұл код блоктары біздің объектіні жоба басталған кезде біз таңдаған дәл орынға орналастырады. Сен бұл позицияны кез келген уақытта өзгерте аласың.

![Бірінші код блоктары (1)](../../../media/game-tutorials/First-Bricks-1.png)

### 3. Код блоктарын қосу

Енді сен оң жақ төменгі бұрыштағы сары плюс батырмасын басып, қосымша код блоктарын жасай аласың. Сен жаңа терезеде код блоктарының бірнеше санаттарын көресің. Бұл санаттар келесі қадамда сипатталады.

### 4. код блогы Категориялар

Бұл код блогының әртүрлі категориялары:

![Бірінші код блоктары (2)](../../../media/game-tutorials/First-Bricks-2.png)

### 5. Бірінші код блогын қосу

Алғашқы код блоктары үшін «Сырғу 1 секунд ішінде мына нүктеге x: Y:» код блогын пайдалану керек. Мұны қозғалыс категориясында таба аласың. Формула редакторы арқылы секунд саны мен X және Y позициясын өңдеуге болады.

### 6. Код блогын орнату

Код блогын бағдарламаңыздың соңғы орналасуына қойыңыз және бірінші рет бағдарламаңызды орындаңыз. Сен мұны сары ойнау батырмасымен жасай аласың.

![Бірінші код блоктары (3)](../../../media/game-tutorials/First-Bricks-3.png)

### 7. Сен бірінші код блогыңызды енгіздіңіз.

Енді сен алғашқы объектіні бағдарламаладыңыз!

Егер сен жобаңызды достарыңызбен бөлісеңіз, онда **[Жүктеп алу және ортақтандыру](upload-and-share.md)** -тітуарльға қарап шықсаңыз болады. Әйтпесе сен өзіңіздің алғашқы жобаңызбен бастауыңыз мүмкін. Егер саған көмек немесе рух қажет болса, бастаушы сериясындағы оқулықтарымызды қараңыз.

Сен барлық код блоктары туралы қосымша ақпаратты таба аласың [мұнда](../../../reference/)!
