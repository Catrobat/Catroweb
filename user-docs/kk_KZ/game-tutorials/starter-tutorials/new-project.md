Бұл оқу құралында сен өзіңіздің алғашқы жобаңызды құруға кірісу үшін білуіңіз керек барлық нәрселерді білесіз Pocket Code. Біз саған қосымшаны қалай жүктеу, ашу және жаңа жоба жасау туралы қадам-шақпай нұсқау береміз.

[Суретті аш](../../../media/game-tutorials/New-Program.png)

Бұл алғашқы оқу-әдістемесі, және саған ешқандай алдын ала білім қажет емес.

Не күтіп тұрсыз? Телефоныңызды алып, қазір бастаңыз!

### 1. Pocket Code

Алдымен, құрылғыңызда Pocket Code қосымшасын орнату керек. Бұл қадам үшін Google тіркелгісі қажет. Енді құрылғыңыз қосымшаны жүктеп, орнатады. Бұл қадам сенің интернет қосылымыңызға байланысты біраз уақыт талап етілуі мүмкін.

![Жаңа бағдарлама (2)](../../../media/game-tutorials/New-Program-2.png)\
Сен Google Play Store дегеннен «Pocket Code» іздеп, «орнату» дегенді басып, қолданбаны таба аласың.\
[Суретті аш](../../../media/game-tutorials/New-Program-2.png)

Pocket Code бағдарламаны жүгіріп, орнатудан кейін сен қолданбалар тартпасында немесе құрылғыңызға байланысты үй экраннан таба аласың. Қолданбаны өзің қалаған жерге орналастыра аласың.

### 2. Қолданбаны бастау

![Жаңа бағдарлама (1)](../../../media/game-tutorials/New-Program-1.png)\
Қолданбаны ашқанда әртүрлі санаттарды көресің.\
[Суретті аш](../../../media/game-tutorials/New-Program-1.png)

### 3. Жаңа жоба құру

Келесі қадам - жаңа жоба құру. Енді жобаның атын келтіріп, жобаңыздың пейзаж болуы керек-жоғын таңда. «Жарайды» басқаннан кейін жоба құрылады.

![Жаңа бағдарлама](../../../media/game-tutorials/New-Program.png)\
Мұны істеу үшін оң жақ төменгі бұрыштағы сары плюс батырмасын бас.\
[Суретті аш](../../../media/game-tutorials/New-Program.png)

### 4. Сен өзіңіздің жаңа жобаңызды жасадыңыз.

Енді сен Pocket Code орнатып, жаңа жобаны қалай құру керектігін білесіз. Енді бағдарламалауды бастай аласың!

Бұл үшін сен жобада жаңа нысанды қалай құру керектігін білуіңіз керек. **[Жаңа нысан](new-object.md)** -тіруалға қараңыз, онда саған барлық нәрсе қадам-қадам түсіндіріледі.
