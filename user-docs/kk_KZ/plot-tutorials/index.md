Өз сюжетіңізді құруды қалайсыз ба? Біздің оқулықтар саған код блоктарын пайдалану арқылы кесу платосында сызылған сызықтарды кесуге көмектеседі. Өз жобаларыңызды нақты және шығармашылықпен жүзеге асыру үшін қажетті техника мен құралдарды біліңіз.
