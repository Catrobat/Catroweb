Сөйлемді бастағанда, әрбір қозғалысы қаламмен сызылғандай болады. Бұл - кейіннен шебердің өлеңдері.

Бұл төл тек тік сызықтардан («Жылжу: \_\_\_ қадам») және бұрыштардан тұрады.

**Өкіме**: Бағдарламаны құрастыру кезінде сынап көріңіз.
