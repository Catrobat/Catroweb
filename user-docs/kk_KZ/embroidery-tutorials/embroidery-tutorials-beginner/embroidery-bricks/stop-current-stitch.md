Ағымдағы тігісті тоқтатқысы келеді.

Егер жүгіру, зигзаг немесе үш рет тігуді бастағаннан кейін иілдің орнын өзгерту үшін осы код блогы қажет болады.

![Ағымдағы тігісті тоқтату](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

Әйтпесе, қажетсіз аралық тігіс пайда болады.
