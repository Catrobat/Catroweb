Бұл оқулықта сен шикізаттық код блоктары туралы білуіңіз керек барлық нәрселерді үйрене аласың!

Бұл үшін саған бағдарламалау білімі қажет емес.

Әрбір шикізаттың блогы мысалмен түсіндіріледі.

Егер сен әлі де шырмалау код блоктарын белсендірмеген болсаңыз, **[Кескізу код блоктарын қосу](../activate-embroidery-bricks.md)** -тіуorialға назар аударыңыз.

*Мұнда сен PDF форматында оқу құралын жүктей аласың*:

[Шикізаттық кодтар блоктары](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Оларға қатысты көбірек білу үшін әртүрлі код блоктарына бас:**

[![Тігіс салу](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*Машинаның бір рет матаға тігілуіне рұқсат етіңіз!*

[![Түзу тігісті бастау, ұзындығы: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*Машинаның ұзындығы әрқашан өзгеріп отырады.*

[![Зигзаг тігісті бастау, ұзындығы: 2 ені: 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Ұзындығы мен ені өзгермейтін тігістікті ұдайы жалғастыру.*

[![Үш еселі тігісті бастау, ұзындығы: 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*Үш рет тігілген тігіс әрбір тігісті үш рет тігіп алады.*

[![Ағымдағы тігісті тоқтату](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Ағымдағы тігісті тоқтатқысы келеді.*

Сен бұдан да көп Бромди-код блоктарын және олар туралы ақпаратты таба аласың [мұнда](../../../../reference/#category_embroidery).

Көбірек ақпарат немесе жобалау ұсыныстары үшін басқа оқулықтарды қараңыз!
