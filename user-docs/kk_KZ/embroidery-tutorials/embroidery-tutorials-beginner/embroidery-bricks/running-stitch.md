Машинаның ұзындығы әрқашан өзгеріп отырады.

Әдетте, сен жүретін тігісті жылжыту код блогымен біріктіресіз.

![Түзу тігісті бастау, ұзындығы: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

Машина әр **10 қадам** тігілетін тігінді іске қосуда.

Содан кейін машина қозғалады **200 қадам**.

Бұл **20 тігіс** нәтиже береді.

![Түзу тігісті бастау, ұзындығы:](../../../../media/embroidery-tutorials/RunningStitch.png)

Жүгіру тігінен тікті оңайлатылады, өйткені бұдан былай цикл қажет болмайды.
