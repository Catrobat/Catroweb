Бұл оқу құралында сен нысандарды қалай жасауды үйренесің, содан кейін үлгілеріңізді сайрауға болады.

Бұл оқу үшін сен жобаны қалай құру керектігін білуге тиіссіз. Егер саған көмек қажет болса, [Бастапқы серия](../../game-tutorials/starter-tutorials/index.md) оқулықтарына көз жеткізіңіз.

Көбірек ақпарат немесе жобалау ұсыныстары үшін басқа оқулықтарды қараңыз.

*Мұнда сен PDF форматында оқу құралын жүктей аласың*:

[Кеспелік бұйымдар жасау](../../../media/embroidery-tutorials/Create-Embroidery-Objects.pdf)

### 1. Жаңа нысанды қосу үшін жобаның оң жақ төменгі жағында орналасқан плюс батырмасын бас.

![Кеспелік бұйымдар жасау](../../../media/embroidery-tutorials/Create-Embroidery-Objects.png)

### 2. Суретті таңдау үшін медиа кітапханасына кіріңіз.

![Жібектеу заттарын жасау (1)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-1.png)

### 3. Беттеуші заттың бір деңгейі тігілген кезде бірнеше тігілген заттарды бірімен-бірі тігіп алады.

Сен өзіңіздің зауытыңызды қалаған түске қарай таңдап ала аласың.

Төменге бұрып, дұрыс жебе іздеңіз.

![Жібектеу бұйымдарын жасау (5)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-5.png)

### 4. Жаңа нысанға тиісті атау беріңіз және баспаны бас Жарайды.

![Жібектеу бұйымдарын жасау (3)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-3.png)

### 5. Сен жаңа нысанды жасадыңыз. Енді сценарийді қосу және объектіні бағдарламалау мүмкін.

![Кескізу бұйымдарын жасау (4)](../../../media/embroidery-tutorials/Create-Embroidery-Objects-4.png)

Енді сен нысанды қалай жасау керектігін білесіз. Сен қолданғыңыз келетін әр түске жаңа нысанды қосу.

Әр түстеге сценарий қосып, өз жобаларыңызды бағдарламалай аласың және тіпті кейіннен тігіп бере аласың.

Сендерге рухтың жетелеуі не көмек қажет пе? Басқа оқулықтарымызға қараңыз!
