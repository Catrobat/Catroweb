Бұл кодты пайдаланып, сен персонаждарыңыздың экранға түсірілгенін қалдырасыз. Бұл қағаз бетіне түстерлі мөртаңба басып, мөртаңбаның дизайнын көшірмелеуге ұқсайды. Осылайша, сен өзіңіздің фоныңызды жақсартасыз - сен клон жасамайсыз!
