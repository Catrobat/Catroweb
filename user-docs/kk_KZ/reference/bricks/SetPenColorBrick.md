![Қалам түсін орнату: o қызыл 0 жасыл 0 көк 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

Бұл код блогы актер қолданатын қаламның түсі өзгертеді. Бұл сурет салу кезінде басқа түсті қаламға ауысу сияқты.

**Қызыл, жасыл, көк (RGB)**: RGB түсті модель түрлі қызыл, жасыл және көк жарық қарқынын пайдалана отырып, түстердің кең спектрін жасайды. Әр түстелік компоненттің (қызыл, жасыл және көк) 0-255 арасындағы мәні болуы мүмкін:

- **Қызыл**: Түстің қызыл компоненті. Жоғары мән қызыл түсті дегенді білдіреді.
- **Жасыл**: Түстің жасыл компоненті. Жоғары баға көгалданғаннан да жоғары.
- **Көк**: Түстің көк компоненті. Жоғары мән көк түсті түске ие.

Қызыл, жасыл және көк түсті әр түрлі мәндерді біріктіріп, кез келген түстерді жасай аласың. Мысалы:

- `RGB(255, 0, 0)` таза қызыл түсті.
- `RGB(0, 255, 0)` таза жасыл түсті.
- `RGB(0, 0, 255)` - таза көк түсті.
- `RGB(255, 255, 255)` ақ түсті (көк, жасыл және көгілдір).
- `RGB(0, 0, 0)` қара түсті (түссіз).

Бұл түстерді әр түрлі мөлшерде араластырып, сен цифрлық экрандарда көрген барлық түстерді пайда етеді.
