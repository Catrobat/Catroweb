*Шарттың дұрыс екенін тексеріп, егер дұрыс болса бір нұсқаманы орындайды, егер дұрыс болмаса басқа нұсқаманы орындайды: «Егер бұл шын болса, мынаны жасаңыз; егер жоқ болса, солды жасаңыз.»*

![Көріністі бастау:](../../../media/bricks/StartScene.png)

Сцена басталған кезде, өзгерісі X 0-ға орнатылады.

![Егер басқа](../../../media/bricks/IfElse.png)

Егер жануарды қазір тигізген болса, X modulo 2 дұрыс ма, яғни X жат сан болып табылмағанын тексеру жүргізіледі.

Егер бұл жағдай болса, дыбыс Tweet1 ойнады және өзгерісі X 1 есеге көбейтіледі.

Әйтпесе, егер X тең болса, тек X ғана 1 есеге көбейтіледі.

Орындалатын есептер Шарттың соңы арқылы бөлінеді.
