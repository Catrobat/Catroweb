![Сызуды тоқтату](../../../media/bricks/Stop_to_plot.png)

«Сызуды тоқтату» код блогы сюжет жасау процесін тоқтата тұрады және актерді жаңа орынға жылжытуға немесе сюжетті аяқтауға мүмкіндік береді. Бұл қағаздан қаламды алып тастау сияқты, оны қайта орналастыру немесе сурет салуды тоқтату үшін. Сен картаны жасауды аяқтағаннан кейін, сен «Сызбаны SVG ретінде сақтау:» код блогын пайдалана аласың дизайнын SVG файл ретінде сақтау.
