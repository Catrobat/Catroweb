![Орналастыру](../../../media/bricks/place_at_x_y_brick.png)

Объектіні экрандағы x және y координаталары арқылы анықталған нақты орынға жылжытады. Бұл сенің кейіпкеріңізді дәл бір жерге телепортациялау сияқты.

Орналасу Картезиялық жазықтығы сияқты координаталар жүйесінде орнатылады: x және y ошалары экранның ортасынан өтеді, сондықтан x = 0 және y = 0 экранның ортасы.
