![Клон ретінде басталғанда](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Қажетті әрекеттерді орындау үшін нұсқаулармен нысанның жасалған клонын бағыттау. Бұл процесс бастапқы объектінің функционалдылығын қайталауға мүмкіндік береді, сонымен қатар клонды тәуелсіз басқару. Клон объектісінің әртүрлі мінез-құлқы немесе қасиеттері нақты талаптарға сәйкес келтірілуі мүмкін.
