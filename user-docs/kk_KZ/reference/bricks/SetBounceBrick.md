![Серпімділік коэффициентін орнату:](../../../media/bricks/set_bounce_factor_to_brick.png)

Нысанның бір нәрсеге соғылған кезде қаншалықты көтерілетінін белгілейді. Жоғары пайыздық көрсеткіш - бұл күшті көтерілу. Бұл сенің кейіпкеріңіздің қабырғалардан не басқа нысандардан қаншалықты көтерілетінін анықтау сияқты.
