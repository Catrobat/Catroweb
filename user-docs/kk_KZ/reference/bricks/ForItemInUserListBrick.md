![Тізімдегі әр мән үшін:](../../../media/bricks/for-each-value_brick.png)

Бұл код блогы тізімдегі немесе диапазондағы әрбір элемент үшін нұсқаулар жиынтығын көрсетеді. Бұл әр элементті бір-бірінен қарап, әрқайсысына бірдей әрекет жасауға ұқсас.

Санаттар, түстер немесе кез келген заттардың тізімі бар дейік. Бұл код блогы саған тізімдегі әр элементті алып, онымен не істеуді ұсынады. Мысалы, егер сен түстер тізімі болса және сен тiзiмдегі әр түсiне фонолық түсiн өзгерте білсеңіз, осы код блогын пайдаланыңыз.

Бұл, "Біздің елімізге «Бұл топтағы әрбір заттарға мына нұсқауларды орындаңыз.»
