Бұл код блогы бір мәннен басталып, екіншісінен аяқталатын есептегішпен белгілі бір санда нұсқаулар жиынтығын орындайды. Бұл - цикл құруға ұқсас, онда сен оның қанша рет жүгіруін қалайтыныңызды білесіз.

Бірде бір нәрсеге қол жеткізгеніңді елестетіп көрші. Бұл блок әр элементті бір-бірінен қарап, әрқайсысына бірдей нәрсе жасай алады.
