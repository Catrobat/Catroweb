![күту-барлығына дейін-бұрақ скрипттер-тоқталған код блогы](../../../media/bricks/wait-until-all-other-scripts-stopped-brick.png)

Бұл код блогы жобадағы барлық басқа скрипттер орындалғанша ағымдағы сценарийді тоқтата тұрады. Сценарийді басқа нәрселер аяқталғанша тоқтатып тұрыңыз. Бұл сенің қазіргі сценарийіңіздегі келесі қадамдарды орындаудан бұрын басқа әрекеттердің болмауын қамтамасыз ету үшін пайдалы.
