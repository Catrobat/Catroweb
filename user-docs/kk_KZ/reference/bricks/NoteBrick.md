Кодтың қандай бөліктерін еске түсіруге көмектесетін сценарийіңізге түсініктеме немесе жазба қосылады. Бұл жобаның қалай жұмыс істейтінін қозғамайды. Бұл өзіңе жабысқақ жазба қалдыру сияқты.
