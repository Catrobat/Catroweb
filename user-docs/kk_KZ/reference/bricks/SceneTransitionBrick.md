![Көріністі жалғастыру:](../../../media/bricks/continue_scene_brick2.png)

Бұл код блогы ол тұрған жерден сахнаны қайта қалпына келтіреді. Егер сенің сахнаңыз бір сәттен кейін тоқтап немесе күтіп тұрса, осы код блогын пайдалану әрекетті тоқтаған жерден жалғастырады.

Ойынды немесе анимацияны тоқтатып, оны жалғастырып жатқаныңызды елестетіңіз. Бұл код блогы «Ойнау» батырмасы сияқты әрекет етеді, ол тоқтатылған сәттен бастап бәрін қайта қалпына келтіреді.
