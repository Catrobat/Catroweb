Объекттің айналу рәсімі өзгерді (барлығы айнала, тек сол-оңға немесе айналмайды). Бұл сенің кейіпкеріңіздің сол жаққа, оңға бұра алатынын немесе мүлдем айналып кетпейтінін шешуге ұқсас.
