![Сызуды бастау](../../../media/bricks/Start_to_plot.png)

Бұл код блогы актер қозғалған кезде сюжет жасау процесін бастайды. Бұл қаламды қағазға қоюмен бірдей. Сен «Сызуды тоқтату» кодты бөледі егер сен сызуды тоқтатып, актерді басқа жерге жылжытатын болсаңыз және кейін қайтадан сюжетті бастаңыз «Сызуды бастау».
