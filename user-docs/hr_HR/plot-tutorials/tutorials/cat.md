Kad crtanje počne, svaki pokret nacrtan je kao da ga crta olovkom. To su linije koje ploter kasnije reže.

Naš objekt okrenut je u smjeru 150 stupnjeva.

U ovom vodiču prvo se radi desna strana mačjeg lica. Ako pažljivo pogledaš, zakrivljenost je na početku jaka, pa se objekt mora više okretati nakon svake male linije. Zatim su zavoji manji za donji dio lica. Lijeva strana lica opet je jako zakrivljena. Zato taj dio lica ima ukupno tri petlje.

Sljedeće je lijevo uho. Sastoji se samo od ravnih linija, pa možemo koristiti blok „Pomakni se \_\_ koraka”.

Dio između ušiju opet je luk i programira se drugom petljom.

Zatim se radi desno uho.

Crtanje je sada gotovo. Završi ga blokom „Prestani crtati” i spremi ga na svoj telefon blokom „Spremi crtež kao SVG \_\_\_”.

Sada možeš poslati SVG datoteku (reznom) ploteru.
