U ovom vodiču naučit ćeš sve što trebaš znati o aplikaciji Pocket Code kako bi počeo stvarati svoj prvi projekt. Korak po korak pokazat ćemo ti kako preuzeti aplikaciju, otvoriti je i stvoriti novi projekt.

![Novi program](../../../media/game-tutorials/New-Program.png)

Ovo je prvi vodič i ne trebaš nikakvo prethodno znanje.

Pa, na što čekaš? Uzmi telefon i počni odmah!

*Ovdje možeš preuzeti vodič u PDF formatu:*

[Novi program](../../../media/game-tutorials/New-Program.pdf)

### 1. Instalacija aplikacije Pocket Code

Najprije moraš instalirati aplikaciju Pocket Code na svoj uređaj. Aplikaciju možeš pronaći tako da u Google Play trgovini potražiš „Pocket Code” i pritisneš „Instaliraj”. Za ovaj korak potreban je Google račun. Sada će uređaj preuzeti i instalirati aplikaciju. Ovaj korak može potrajati, ovisno o tvojoj internetskoj vezi.

![Novi program (2)](../../../media/game-tutorials/New-Program-2.png)

Nakon uspješnog preuzimanja i instalacije aplikacije Pocket Code, aplikaciju ćeš naći u izborniku aplikacija ili na početnom zaslonu, ovisno o uređaju. Aplikaciju možeš lako premjestiti i postaviti gdje god želiš.

### 2. Pokreni aplikaciju

Kada otvoriš aplikaciju, vidjet ćeš različite kategorije:

![Novi program (1)](../../../media/game-tutorials/New-Program-1.png)

### 3. Stvori novi projekt

Sljedeći korak je stvoriti novi projekt. Za to pritisni žuti gumb s plusom u donjem desnom kutu. Sada moraš upisati naziv projekta i odabrati želiš li vodoravni ili ne prikaz. Pritiskom na „OK” projekt će biti stvoren.

![Novi program](../../../media/game-tutorials/New-Program.png)

### 4. Gotovo je! Stvorio si svoj novi projekt.

Sada si instalirao Pocket Code i znaš kako stvoriti novi projekt. Sada možeš započeti programiranje!

Za to trebaš znati kako stvoriti novi objekt u projektu. Pogledaj vodič **[Novi objekt](new-object.md)**, u kojem je sve korak po korak objašnjeno.
