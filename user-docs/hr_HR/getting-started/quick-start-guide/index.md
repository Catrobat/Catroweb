Pocket Code je aplikacija za vizualno programiranje koja ti omogućuje stvaranje igara, animacija i interaktivnih priča izravno na pametnom telefonu ili tabletu. Pomoću intuitivnog sučelja s povlačenjem i ispuštanjem „blokova” (blokova koda) možeš dizajnirati svoje projekte bez prethodnog iskustva u programiranju. Lako dodaješ zvukove, slike i pokret te oživljavaš svoje ideje.

Ovaj vodič pomoći će ti da započneš objašnjavajući kako:

- se snalaziš u sučelju,
- stvoriš svoj prvi projekt,
- radiš s objektima i pozadinama,
- koristiš blokove za programiranje radnji i
- spremiš svoj projekt.

Pocket Code savršen je za početnike i nastavnike te potiče kreativnost, rješavanje problema i logično razmišljanje.
