Pocket Code je Catrobatova glavna aplikacija, besplatna aplikacija otvorenog koda za mobilne uređaje koja ti omogućuje stvaranje igara, animacija i interaktivnih priča izravno na pametnom telefonu ili tabletu. Pomoću Pocket Codeovog sustava programiranja temeljenog na **blokovima** projekte gradiš spajanjem blokova koda – kao slaganje dijelova slagalice. Nije potrebno iskustvo u programiranju, što je savršeno za početnike!

Pocket Code ide i dalje od digitalnih projekata. Uz nove **značajke za makerspace**, možeš dizajnirati i **SVG datoteke za rezne plotere**. To znači da svoje digitalne kreacije možeš pretvoriti u stvarne predmete i istražiti kreativne mogućnosti izvan zaslona.

Bez obzira učiš li programirati, isprobavaš nove ideje ili podučavaš programiranje, Pocket Code pruža zabavan i pristupačan način za ulazak u svijet programiranja.

[Više informacija](https://catrobat.org/pocket-code/)
