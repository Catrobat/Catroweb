![Kad počneš kao klon](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Stvoreni klon objekta usmjerava se uputama da izvrši željene radnje. Ovim postupkom može se ponoviti funkcionalnost izvornog objekta, dok se klonom upravlja neovisno. Mogu se odrediti različita ponašanja ili svojstva klona kako bi ispunio određene zahtjeve.
