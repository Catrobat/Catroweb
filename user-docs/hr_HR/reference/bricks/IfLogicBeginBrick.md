![Ako – inače](../../../media/bricks/if_else_brick2.png)

*Provjerava je li uvjet istinit, pa izvodi jedan niz uputa ako jest, a drugi ako nije. Kao da daješ dvije mogućnosti: „Ako je ovo točno, učini ovo; inače učini ono.”*

![Počni scenu](../../../media/bricks/StartScene.png)

Kad scena počne, varijabla X postavlja se na 0.

![Ako – inače](../../../media/bricks/IfElse.png)

Ako se sada dodirne životinja, provjerava se je li X modulo 2 istina, odnosno je li X neparan broj.

Ako jest, reproducira se zvuk Tweet1 i varijabla X povećava se za 1.

Inače, ako je X paran, samo se X povećava za 1.

Naredbe koje se izvršavaju odvajaju se blokom Kraj ako.
