Ovaj blok mijenja boju olovke kojom lik crta. Kao da se tijekom crtanja prebaciš na olovku druge boje.

**Crvena, zelena, plava (RGB)**: RGB model boja koristi različite intenzitete crvenog, zelenog i plavog svjetla da stvori širok raspon boja. Svaka komponenta boje (crvena, zelena i plava) može imati vrijednost između 0 i 255:

- **Crvena**: Crvena komponenta boje. Veća vrijednost znači više crvene.
- **Zelena**: Zelena komponenta boje. Veća vrijednost znači više zelene.
- **Plava**: Plava komponenta boje. Veća vrijednost znači više plave.

Kombiniranjem različitih vrijednosti za crvenu, zelenu i plavu možeš stvoriti bilo koju boju. Na primjer:

- `RGB(255, 0, 0)` je čista crvena.
- `RGB(0, 255, 0)` je čista zelena.
- `RGB(0, 0, 255)` je čista plava.
- `RGB(255, 255, 255)` je bijela (najviše crvene, zelene i plave).
- `RGB(0, 0, 0)` je crna (bez boje).

Miješanjem tih boja u različitim omjerima nastaju sve boje koje vidiš na digitalnim ekranima.
