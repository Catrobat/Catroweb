![Deter o son](../../../media/bricks/Stop_sound_record.png)

Este bloqueo de código impide que un son específico toque. É como tocar o botón de parada para unha canción mentres outros sons ou música continuan tocando. Imaxina que lle diches ao teu personaxe para deixar de tocar unha canción sonora en particular.
