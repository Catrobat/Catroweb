![Comezar a debuxar co plóter](../../../media/bricks/Start_to_plot.png)

Este bloque de código comeza o proceso de trama mentres o actor se move. É similar a poñer unha caneta sobre papel para comezar a trazar unha liña. Podes usar o bloque de código «Deixar de debuxar co plóter» se queres pausar o debuxo e mover o actor a un lugar diferente e, despois, comezar novamente a trama con «Comezar a debuxar co plóter».
