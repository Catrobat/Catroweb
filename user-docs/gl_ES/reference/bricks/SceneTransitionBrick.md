![Continuar a escena](../../../media/bricks/continue_scene_brick2.png)

Este bloque de código retoma a escena desde onde foi parado. Se a súa escena foi interrompida por unha pausa ou espera, usando este bloque de código vai recomezar a acción onde parou.

Imaxina que deixas un xogo ou animación e agora queres que continúe funcionando. Este bloque de código actúa como o botón «Executar», facendo que todo se reanude desde o punto en que foi pausa.
