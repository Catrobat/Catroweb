*Verifica se unha condición é verdadeira e executa un conxunto de instrucións se é así, e outro conjunto se non. É como dar dúas opcións: «Se isto é verdade, fai isto; se non, fai iso.»*

![Iniciar a escena](../../../media/bricks/StartScene.png)

Cando comeza a escena, a variável X está definida como 0.

![Se Outro](../../../media/bricks/IfElse.png)

Ao tocar no animal, o bloque comproba se X módulo 2 é verdadeiro. É dicir, se X é un número impar.

Se este é o caso, reproducirse o son Tweet1 e a variável X incrementarse por 1.

De outra forma, se X é par, só X é incrementado por 1.

As declaracións que se executarán están separadas por un Fin do se.
