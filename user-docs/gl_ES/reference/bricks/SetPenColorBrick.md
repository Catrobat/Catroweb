Este bloque de código cambia a cor da caneta usada polo actor. É como cambiar a unha caneta de cor diferente ao debuxar.

**Roxo, verde e azul (RGB)**: O modelo de cores RGB usa diferentes intensidades de luz vermella, verde e azul para crear un amplo espectro de cores. Cada componente de cor (verde, verde e azul) pode ter un valor entre 0 e 255:

- **Roxo**: O compoñente vermello da cor. Un valor máis alto significa máis vermello.
- **Verde**: O compoñente verde da cor. Un valor máis alto significa máis verde.
- **Azul**: O componente azul da cor. Un valor máis alto significa máis azul.

Combinando diferentes valores para o vermello, verde e azul, podes crear calquera cor. Por exemplo:

- `RGB(255, 0, 0)` é de cor vermella pura.
- `RGB(0, 255, 0)` é verde puro.
- `RGB(0, 0, 255)` é azul puro.
- `RGB(255, 255, 255)` é branco (máximo vermello, verde e azul).
- `RGB(0, 0, 0)` é negro (sen cor).

A mestura destas cores en diferentes cantidades crea todas as cores que ves nas pantallas dixitais.
