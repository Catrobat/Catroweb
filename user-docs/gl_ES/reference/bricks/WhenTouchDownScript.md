![Cando se toque o escenario](../../../media/bricks/When_stage_is_tapped_btn.png)

Corre o guión cando se toca a pantalla.

A diferenza do bloque *«Cando se toque»* é que *«Cando se toque o escenario»* se aplica a toda a pantalla, mentres que *«Cando se toque»* é específico para sprites ou obxectos individuais.
