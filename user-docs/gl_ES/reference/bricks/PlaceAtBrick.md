![Colocar en](../../../media/bricks/place_at_x_y_brick.png)

Move o obxecto a unha posición específica na pantalla, definida polas coordenadas x e y. É como teletransportar o teu personaxe a un lugar exacto.

A posición está establecida nun sistema de coordenadas como o plano cartesiano: os eixos x e y pasan polo centro da pantalla, polo que x = 0 e y = 0 é o medio da pantalla.
