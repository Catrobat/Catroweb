![para-valores-de código bloque](../../../media/bricks/for-values-from-brick.png)

Este bloque de código executa un conxunto de instrucións un número específico de veces, usando un contador que comeza nun valor e termina noutro. É como establecer un bucle onde sabes exactamente cantas veces queres que se execute.

Imaxina que tes unha lista de obxectos e queres facer algo con cada un deles. Este bloque permite que pases por cada elemento un a un, facendo o mesmo para cada unha.
