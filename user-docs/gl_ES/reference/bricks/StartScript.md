![Cando comece a escena](../../../media/bricks/When_scene_starts_btn2.png)

Se usas este bloque, o guión comezará inmediatamente cando comece a escena. Unha escena é o comezo do teu programa. Unha escena é unha nova vista no seu programa na que se poden mostrar outros elementos e realizar diferentes interaccións. Podes ter moitas escenas para diferentes fases do teu programa. Por exemplo, unha escena para a introdución, unha escena para o menú principal, unha para o primeiro nivel, outra para o segundo nivel e así sucesivamente. Con programas máis sinxelos, unha única escena tamén pode ser suficiente, entón o comezo do seu programa é tamén o inicio da escena.

Como todo script, este comeza cun bloque de código de evento: o evento define **cando** o script comeza, o código bloquea despois de que diga ao programa **Que** para facer.
