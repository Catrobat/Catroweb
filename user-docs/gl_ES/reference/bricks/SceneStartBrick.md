![Iniciar a escena](../../../media/bricks/start_scene_brick2.png)

Este bloque de código cambia a unha escena diferente no seu proxecto e comeza a executar esa escena desde o principio. É como cambiar un capítulo nun libro ou pasar ao seguinte nivel dun xogo.

Imaxina que tes varias escenas no teu proxecto, cada unha representando unha parte diferente da túa historia ou xogo. Usando este bloque de código, podes saltar a calquera escena e comezar desde o principio, creando unha transición sinxela entre diferentes partes do teu proxecto.
