Este bloque de código fai unha copia do obxecto especificado, chamado clon, que se comporta como o orixinal. Imaxina duplicar un personaxe ou obxecto no teu xogo. O clon pode ter o seu propio comportamento e scripts, permitindo-lle crear múltiples instancias dun obxecto que poida actuar de forma independente.
