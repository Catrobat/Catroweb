![Para cada valor de](../../../media/bricks/for-each-value_brick.png)

Este bloque de código corre un conxunto de instrucións para cada elemento dunha lista ou rango. É como revisar cada elemento un por un e realizar a mesma acción en cada unha.

Imaxina que tes unha lista de números, cores ou calquera cousa. Este bloque de código permite que tome cada elemento da lista e faga algo con el. Por exemplo, se tes unha lista de cores e queres cambiar a cor do fondo para cada cor na lista, usarías este bloque de código.

É como dicir, «Para cada elemento deste grupo, fai estas instrucións.»
