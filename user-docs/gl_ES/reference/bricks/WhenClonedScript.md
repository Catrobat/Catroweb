![Cando comeces como clon](../../../media/bricks/when_you_start_as_a_clone_brick2.png)

Direccionar un clonado creado dun obxecto con instrucións para realizar as accións desexadas. Este proceso permite replicar a funcionalidade do obxecto orixinal, mentres controla o clon de forma independente. Varias conductas ou propiedades do obxecto clonado poden especificarse para satisfacer requisitos específicos.
