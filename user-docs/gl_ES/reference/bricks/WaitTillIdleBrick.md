Este bloque de código pausa o script actual ata que todos os outros scripts do proxecto acaben de executar. Imaxina que estás a deixar o teu guión en espera ata que se acabe todo. É útil para garantir que non se realicen outras accións antes de proceder aos próximos pasos no seu guión actual.
