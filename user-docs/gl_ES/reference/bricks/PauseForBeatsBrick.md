![Pausa por 1 batida](../../../media/bricks/Pause_for_1_beats.png)

Este bloque de código fai que o guión espere un número especificado de batidas antes de continuar. É como facer unha pausa nunha canción antes de tocar a próxima nota ou son. Imaxina que fai unha pausa na súa actuación, conta os ritmos e retoma a acción.
