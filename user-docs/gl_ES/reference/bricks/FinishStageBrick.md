![Bloque de código da etapa final](../../../media/bricks/finish-stage-brick.png)

Este bloqueo de código paraliza todos os scripts e termina a etapa ou escena actual. É como dicir, «Esta parte do proxecto rematou.» Todo pára e o proxecto pode moverse a outra escena ou acabar completamente. Utilice este método cando queira concluír unha etapa ou nivel determinado do seu proxecto.
