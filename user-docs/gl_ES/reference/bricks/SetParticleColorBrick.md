![Establecer a cor das partículas en "#ff0000"](../../../media/bricks/Set_particle_colour_to_ff0000.png)

Este bloque de código cambia a cor das partículas emitidas polo actor. É como cambiar a cor dos confetti nunha festa.

Un código de cores hexados é unha forma de representar as cores usando valores hexadecimais. É composto por seis caracteres, que poden ser números (0-9) ou letras (A-F). O código adoita escribirse con un «#» no comezo, así: `#RRGGBB`.

- Os dous primeiros caracteres (`RR`) representan o compoñente vermello da cor.
- Os dous caracteres seguintes (`GG`) representan o componente verde.
- Os dous últimos caracteres (`BB`) representan o componente azul.

Cada par de caracteres pode variar desde `00` (que significa que non hai ningunha daquela cor) ata `FF` (que significa a cantidade máxima da cor). Por exemplo:

`#000000` é negro (sen cor).

`#FF0000` é de cor vermella pura.

`#00FF00` é verde puro.

`#0000FF` é azul puro.

`#FFFFFF` é branco (máximo vermello, verde e azul).
