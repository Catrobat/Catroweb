![Activa a aditividade do efecto de partículas](../../../media/bricks/Turn_particle_effect_additivity_on.png)

Este bloque de código permite ou desactiva o modo de mestura aditiva das partículas, que pode facer que as partículas aparezan máis brillantes e intensas. É como axustar o brillo e o resplandor dos destellos.
