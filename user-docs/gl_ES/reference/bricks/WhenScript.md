Corre o guión cando se toca o obxecto.

A diferenza do bloque *«Cando se toque o escenario»* é que *«Cando se toque»* é específico para sprites ou obxectos individuais, mentres que *«Cando se toque o escenario»* se aplica a toda a pantalla.
