![Deixar de debuxar co plóter](../../../media/bricks/Stop_to_plot.png)

O bloque de código «Deixar de debuxar co plóter» pára o proceso de trama e permite mover ao actor a unha nova posición ou rematar a trama. É como levantar unha caneta do papel para reposicionalo ou deixar de debuxar. Despois de terminar a traza, pode usar o bloque de código «Gardar o debuxo do plóter como SVG» para salvar o seu deseño como un arquivo SVG.
