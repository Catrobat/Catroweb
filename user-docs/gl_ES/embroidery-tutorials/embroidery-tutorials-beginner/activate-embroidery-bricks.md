Neste tutorial, explicamos como activar bloques de código Embroidery.

![Activar o bordado-Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)

Non precisas ningún coñecemento de programación para isto. Este é o primeiro paso para comezar cos tutoriais de bordado. Máis tarde, podes deseñar, programar e incluso bordar os teus propios deseños na túa peza de tecido favorita.

Para máis información ou suxestións de deseño, consulte os outros tutoriais.

*Aquí podes descargar o tutorial en PDF-formato*:

[Activar o bordado](../../../media/embroidery-tutorials/ActivateEmbroideryBricks.pdf)

### 1. Inicie a aplicación «Pocket Code» e siga os clics!

### 2. Abre o menú (puntos na parte superior dereita).

![Activar bloques de código de bordado](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks-1.png)

### 3. Vai á «Configuración».

![Activar o bordado-Bricks3](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks3.png)

### 4. Seleccione «Extensión de bordado».

![Activar o bordado-Bricks4](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks4.png)

### 5. Os bloques de código de bordado serán unha categoría propia dentro dos seus bloques de código!

[![Activar o bordado-Bricks5](../../../media/embroidery-tutorials/Activate-Embroidery-Bricks5.png)](../../../reference/#category_embroidery)

Agora tamén atoparás todos os bloques de código bordados entre os outros blocos de código.

Para obter máis información sobre cada bloque de código, consulte a documentación dos bloques de código [Aquí](../../../reference/) ou siga o tutorial **[Bloques de códigos de bordado](embroidery-bricks/index.md)**.

Agora podes comezar e crear os teus propios deseños!

Se necesitas ideas ou axuda, consulta os outros tutoriais ou continúa co **[Crea obxectos de bordado](create-embroidery-objects.md)**-tutorial.
