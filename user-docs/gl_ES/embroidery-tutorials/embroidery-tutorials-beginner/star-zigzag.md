Neste tutorial, aprenderás a bordar unha estrela co punto en zigzag (58,2 x 61,2 mm).

![imaxe (4)](../../../media/embroidery-tutorials/image-4.png)

Xa debería saber como crear un novo obxecto e insertar bloques de código alí. Si aínda necesitas axuda, podes consultar os tutoriais do [Série de inicio](../../game-tutorials/starter-tutorials/index.md). Ademais, os bloques de código de bordado xa deben activarse. Podes descubrir como facelo no tutorial **[Activar bloques de código de bordado](activate-embroidery-bricks.md)**.

Para máis información ou suxestións de deseño, consulte os outros tutoriais.

*Aquí podes descargar o tutorial en PDF-formato*:

[Estrella ZigZag](../../../media/embroidery-tutorials/Star-ZigZag.pdf)

### 1. Crea un novo obxecto de bordado (ver [Crea obxectos de bordado](create-embroidery-objects.md)).

### 2. Agora comeza e inserta os bloques de código paso a paso no seu guión.

![Estrella Zig Zag](../../../media/embroidery-tutorials/Star-ZigZag.png)

### 3. Toque a xogo para comezar o deseño!
