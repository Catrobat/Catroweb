Permite que a máquina coser constantemente cunha lonxitude variable.

Normalmente combinas un punto de execución con un bloque de código de movemento.

![Comeza a correr cosido con lonxitude 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

A máquina inicia un punto de unión que se corre a cada **10 pasos**.

Entón a máquina se move **200 pasos**.

Isto resulta en **20 puntos de sutura**.

![Comezar punto corrido con lonxitude](../../../../media/embroidery-tutorials/RunningStitch.png)

O punto de traballo facilita a costura porque non necesitarás máis un bucle.
