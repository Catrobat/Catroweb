Neste tutorial aprenderás todo o que necesitas saber sobre bloques de código de bordado!

Non precisas ningún coñecemento de programación para isto.

Cada bloque de código de bordado explicase con un exemplo.

Se aínda non activou os bloques de código de bordado, consulte o tutorial **[Activar bloques de código de bordado](../activate-embroidery-bricks.md)**.

*Aquí podes descargar o tutorial en PDF-formato*:

[Bloques de códigos de bordado](../../../../media/embroidery-tutorials/Embroidery-Bricks.pdf)

**Fai clic nos diferentes bloques de código para saber máis sobre eles:**

[![Puntada](../../../../media/embroidery-tutorials/Stitch.png)](stitch.md)

*Deixe a máquina coser o tecido unha vez!*

[![Comeza a correr cosido con lonxitude 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)](running-stitch.md)

*Permite que a máquina coser constantemente cunha lonxitude variable.*

[![Comeza a coser en zigzag con lonxitude 2 e ancho 10](../../../../media/embroidery-tutorials/Start_zigzag_stitch_with_length_2and_width_10.png)](zigzag-stitch.md)

*Coidados constantemente cunha lonxitude e ancho variables.*

[![Comeza a coser tres veces con lonxitude 10](../../../../media/embroidery-tutorials/Start_triple_stitch_with_length_10.png)](triple-stitch.md)

*O punto triplo cose cada punto tres veces.*

[![Deter a puntada actual](../../../../media/embroidery-tutorials/Stop_current_stitch.png)](stop-current-stitch.md)

*Deixe que o punto actual pare.*
