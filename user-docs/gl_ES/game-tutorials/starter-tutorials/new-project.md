Neste tutorial, aprenderás todo o que necesitas saber sobre Pocket Code para comezar a crear o teu primeiro proxecto. Guidámosche paso a paso sobre como descargar a aplicación, abrirla e crear un novo proxecto.

![Novo programa](../../../media/game-tutorials/New-Program.png)

Este é o primeiro tutorial, e non necesitas ningún coñecemento previo.

Entón, que estás a esperar? Agarra o teu teléfono e comeza agora!

*Aquí podes descargar o tutorial en PDF-formato:*

[Novo programa](../../../media/game-tutorials/New-Program.pdf)

### 1. Instalación de Pocket Code

Primeiro, ten que instalar a aplicación Pocket Code no seu dispositivo. Podes atopar a aplicación buscando «Pocket Code» no Google Play Store e descargá-la pulsando «instalar». Para este paso é necesario unha Conta de Google. Agora o teu dispositivo descargará e instalará a aplicación. Este paso pode levar un tempo segundo a súa conexión a Internet.

![Novo programa (2)](../../../media/game-tutorials/New-Program-2.png)

Despois de descargar e instalar con éxito Pocket Code podes atopar a aplicación na bandexa das aplicacións ou na pantalla inicial, dependendo do teu dispositivo. Podes levar facilmente a aplicación e colocá-la onde queiras.

### 3. Crea un novo proxecto

O seguinte paso é crear un novo proxecto. Para facelo, pode premer o botón amarelo máis na esquina inferior dereita. Agora ten que introducir un nome do proxecto e seleccionar se o seu proxecto debe ser paisaxe ou non. Ao presionar «Aceptar» se crea o proxecto.

![Novo programa](../../../media/game-tutorials/New-Program.png)

### 4. Creou o seu novo proxecto.

Agora tes instalado Pocket Code e sabes como crear un novo proxecto. Agora podes comezar a programar!

Para facelo, necesitas saber como crear un novo obxecto nun proxecto. Eche un ollo no tutorial **[O novo obxecto](new-object.md)** onde se explica todo paso a paso.
