Neste tutorial, aprenderás como crear un novo obxecto no teu proxecto e as diferentes posibilidades que tes para isto.

![O novo obxecto](../../../media/game-tutorials/New-Object.png)

Para facelo, xa debería ter descargado a aplicación Pocket Code e saber como crear un novo proxecto. Se necesitas axuda con isto, non te preocupes de ver o tutorial **[Novo proxecto](new-project.md)**.

*Aquí podes descargar o tutorial en PDF-formato:*

[O novo obxecto](../../../media/game-tutorials/New-Object.pdf)

### 1. Crea un novo obxecto

Ao principio, debes abrir o teu novo proxecto.

O atoparás na pantalla de inicio da aplicación Pocket Code. Se tes máis dun proxecto, podes facer clic en «Proxectos». Entón seleccione o seu novo proxecto. Se non creou un novo proxecto ou necesita máis información sobre como facelo, consulte o tutorial **[Novo proxecto](new-project.md)**.

### 2. Crea un novo obxecto

Agora estás listo para crear un novo obxecto. Para facelo, fai clic no botón amarelo máis na esquina inferior dereita. Verás unha nova ventana que lle dá sete posibilidades para escoller.

![O novo obxecto (1)](../../../media/game-tutorials/New-Object-1.png)

Estas son as posibilidades entre as que podes elixir:

### 4. Desenho de imaxe

Para facelo o máis sinxelo posible para o comezo, queremos usar a función «Debuxar» e só debuxar un punto. Cando desenhas o punto con Pocket Paint podes deixalo (dando un paso atrás).

### 5. Dáme un nome

Agora ten que darlle un nome á súa imaxe.

### 6. Coloca-o

Despois de iso, ten que colocá-lo visualmente movéndoo á esquerda/dereita ou cara arriba/abaixo co dedo. Ten que gardalo co botón na esquina superior dereita.

![O novo obxecto (3)](../../../media/game-tutorials/New-Object-3.png)

### 7. Creou o seu novo obxecto.

Agora tes un proxecto con un obxecto que podes programar!

Para iso, debes saber que bloque de código están dispoñibles. O tutorial **[Primeiro bloque de código](first-bricks.md)** dá unha boa visión xeral das diferentes categorías de bloques de código. Con todo, tamén podes comezar directamente co teu primeiro proxecto. Escolle un tutorial axeitado da serie de principiantes.
