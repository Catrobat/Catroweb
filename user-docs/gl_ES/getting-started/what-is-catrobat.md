Catrobat é unha **linguaxe de programación visual** gratuíta e de código aberto. Tanto se estás empezando como se xa sabes programar, podes facer os teus propios xogos, animacións e historias interactivas no móbil ou na tableta. Catrobat ten unha interface sinxela **baseada en bloques**. Arrastra e solta bloques de código para construír os teus proxectos paso a paso. Podes empezar sen experiencia!

Con **Pocket Code**, a aplicación principal de Catrobat, podes crear proxectos dixitais que van máis alá da pantalla. Ademais dos proxectos habituais de programación, Catrobat permíteche crear **ficheiros DST para máquinas de bordar** e **ficheiros SVG para plotters de corte**. Así, podes facer realidade os teus deseños dixitais en tea ou noutros materiais!

Se vostede é un estudante, hobbyista ou educador, Catrobat ofrece unha forma divertida e práctica de explorar a codificación, resolución de problemas e fabricación dixital.
