Pocket Code é unha aplicación de programación visual que permite crear xogos, animacións e historias interactivas directamente no seu teléfono intelixente ou tablet. Usando unha interface intuitiva de arrastre e soltado con «Bloques de código» (bloques de código), podes deseñar os teus proxectos sen experiencia previa en programación. Facilmente engade sons, imaxes e movementos para dar vida ás túas ideas.

Esta guía axudará a comezar explicando como:

- Navegación da interface,
- Crea o teu primeiro proxecto,
- Traballar con obxectos e fondos,
- Utilice bloques de código para programar accións, e
- Salva o teu proxecto.

Perfecto para principiantes e educadores, Pocket Code estimula a creatividade, resolución de problemas e pensamento lógico.
