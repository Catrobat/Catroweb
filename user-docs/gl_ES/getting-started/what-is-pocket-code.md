Pocket Code é a principal aplicación de Catrobat, unha aplicación móbil gratuíta e de código aberto que permite crear xogos, animacións e historias interactivas directamente no seu teléfono intelixente ou tablet. Co **Sistema de codificación baseado en bloques** en Pocket Code, podes construír proxectos co arranque de bloques de código, como poñer un puzzle. Non se necesita experiencia en programación, polo que é perfecto para principiantes!

Pocket Code vai máis alá dos proxectos dixitais. Con novo **características do creatorspace**, tamén pode deseñar **SVG ficheiros para cortar con tramas**. Isto significa que podes converter as túas creacións dixitais en obxectos do mundo real e explorar posibilidades creativas máis alá da pantalla.

Se estás a aprender a codificar, experimentando novas ideas ou ensinando programación, Pocket Code proporciona unha forma lúdica e accesible de mergullar na codificación

[Máis información](https://catrobat.org/pocket-code/)
