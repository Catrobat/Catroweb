Cando comeza a trama, cada movemento é desenhado como se fose cunha pluma. Estas son as liñas que o conspirador corta máis tarde.

Esta estrela ten 6 puntos. Un punto é unha liña recta («Mover 100 pasos»), un giro e outra liña recta que termina a forma do punto. Antes do seguinte punto, ten que virar na dirección oposta, para que o próximo punto sai ben.

***Nota**: Un círculo completo é de 360°. Para cada punto giramos 100° á dereita e 40° á esquerda, o que é 60° a dereita en total.*

*Para os seis puntos temos un giro de 360° á dereita.*

**Vai máis lonxe**: Experimenta diferentes combinacións de curvas e cambia o número de puntos.
