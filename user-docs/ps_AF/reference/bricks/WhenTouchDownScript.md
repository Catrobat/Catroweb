کله چې پر پرده کېکاږې، د کوډ لړۍ چلوي.

د بلاک *«کله چې ټک پرې وشي»* سره توپیر دا دی چې *«کله چې پر سټېج ټک وشي»* ټول سکرین باندې پلي کیږي ، پداسې حال کې چې *«کله چې ټک پرې وشي»* د انفرادي سپریټونو یا شیانو لپاره ځانګړی دی.
