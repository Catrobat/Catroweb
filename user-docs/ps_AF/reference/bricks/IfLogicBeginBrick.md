![که چیرې د کوډ بلاک نه وي](../../../media/bricks/if_else_brick2.png)

*دا بلاک ګوري چې شرط رښتیا دی که نه. که شرط رښتیا وي، یوه ډله امرونه چلوي. که نه وي، بله ډله چلوي. لکه چې ووایې: «که دا رښتیا وي، دا کار وکړه. که نه، بل کار وکړه.»*

![صحنه پیل کړئ](../../../media/bricks/StartScene.png)

کله چې صحنه پیل شي، متغیر X 0 ته تنظیم شوی.

![که بل څوک](../../../media/bricks/IfElse.png)

که اوس پر څاروي کېکاږې، پروګرام ګوري چې د X modulo 2 پایله رښتیا ده که نه. یعنې ګوري چې X طاق عدد دی که نه.

که دا حالت وي، غږ Tweet1 لوبیږي او متغیر X د 1 لخوا زیاتوالی کیږي.

که X جفت عدد وي، یوازې X په 1 زیاتېږي.

د عملي کیدو لپاره بیانونه په یو د «که» پای سره جلا شوي.
