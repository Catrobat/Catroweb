کله چې پر څیز کېکاږې، د کوډ لړۍ چلوي.

د بلاک *«کله چې پر سټېج ټک وشي»* توپیر دا دی چې *«کله چې ټک پرې وشي»* د انفرادي سپریټونو یا شیانو لپاره ځانګړی دی ، پداسې حال کې چې *«کله چې پر سټېج ټک وشي»* د ټول سکرین لپاره پلي کیږي.
