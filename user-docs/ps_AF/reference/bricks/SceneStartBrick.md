دا کوډ بلاک ستا په پروژه کې بل صحنه ته لیږدوي او د پیل څخه د دې صحنه چلولو پیل کوي. دا د کتاب په باب کې د بدلون په څیر دی یا په لوبو کې بلې کچې ته حرکت.

تصور وکړئ چې ته په خپل پروژې کې څو صحنې لرئ، هر یو ستا د کیسې یا لوبې مختلف برخه نمایندګي کوي. د دې کوډ بلاک په کارولو سره، کولی شې هرې صحنه ته کود کړه او له پیل څخه یې پیل کړه، ستا د پروژې د مختلفو برخو ترمنځ یو اسانه انتقال رامنځته کول.
