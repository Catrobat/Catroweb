![خپل د حرکت ډول وټاکئ په](../../../media/bricks/set_your_motion_type_brick.png)

د شیانو حرکت بدلوي، لکه د کشش ثقل لاندې یې حرکت او کود کولو ته اجازه ورکول، د کشش ثقل لاندې حرکت نه کول مګر نور ستا څخه پورته کیږي یا د کشش ثقل لاندې حرکت یا حد نه کول. دا د انتخاب په څیر دی چې ستا شخصیت باید څنګه چلند وکړي د حرکت او تعامل په شرایطو کې.
