![د هر ارزښت لپاره له](../../../media/bricks/for-each-value_brick.png)

دا کوډ بلاک د لیست یا حد کې د هرې برخې لپاره د لارښوونو سیټ پرمخ وړي. دا د هرې برخې په اړه یو له بل سره د تیریدو په څیر دی او په هر یوه کې ورته عمل ترسره کوي.

تصور وکړئ چې ته د شمېرو، رنګونو یا کومو شیانو لیست لرئ. دا کوډ بلاک تا ته اجازه درکوي چې له دې لیست څخه هر توکي واخلئ او د هغې سره یو څه وکړئ. د مثال په توګه، که ته د رنګونو لیست لرئ او غواړئ چې د شالید رنګ په هر رنګ کې بدل کړئ، نو ته به دا کوډ بلاک وکاروئ.

دا د دې په څیر دی چې ووایی، «د دې ډلې د هرې برخې لپاره، دا لارښوونې ترسره کړئ.»
