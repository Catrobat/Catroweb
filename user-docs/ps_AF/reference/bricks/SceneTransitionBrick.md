![صحنې ته دوام ورکړئ](../../../media/bricks/continue_scene_brick2.png)

دا بلاک درېدلې صحنه له هماغه ځایه بیا چلوي. که صحنه د تم کېدو یا انتظار پر مهال درېدلې وي، له هماغه ځایه به دوام وکړي.

ګومان وکړه چې لوبه یا خوځنده انځور دې درولی و. اوس یې بیا چلول غواړې. دا بلاک د «چلول» تڼۍ په څېر له هماغه ځایه هر څه بېرته چلوي.
