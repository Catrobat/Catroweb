دا کوډ بلاک هغه کلون لرې کوي چې د «کلون جوړ کړئ له» کوډ بلاک سره رامنځته شوی. دا د دې په څیر دی چې ووایاست، «دا نقل لرې کړئ.» د دې کارولو سره ستا په پروژه کې د کلونونو شمیر اداره او کنټرول کړه، ډاډ ترلاسه کړئ چې دوی حذف کیږي کله چې نور ورته اړتیا نشته.
