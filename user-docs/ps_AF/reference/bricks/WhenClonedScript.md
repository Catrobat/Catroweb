د مطلوبو کړنو د ترسره کولو لپاره لارښوونو سره د یو شی جوړ شوی کلون لارښوونه کول. دا پروسه د اصلي شی فعالیت تکرار کولو ته اجازه ورکوي ، پداسې حال کې چې کلون په خپلواک ډول کنټرولوي. د کلون څیز مختلف چلند یا ملکیتونه د ځانګړو غوښتنو پوره کولو لپاره مشخص کیدی شي.
