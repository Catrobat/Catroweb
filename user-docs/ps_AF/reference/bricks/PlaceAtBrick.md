![ځای ونیسئ په](../../../media/bricks/place_at_x_y_brick.png)

د x او y همغږۍ لخوا تعریف شوي په سکرین کې یو مشخص موقعیت ته څیز حرکت کوي. دا د خپل شخصیت په یوه دقیق ځای کې د ټیلیپورت کولو په څیر دی.

موقعیت د کارټیسین سټیشن په څیر د همغږۍ سیسټم کې تنظیم شوی: د x او y محورونه د سکرین له مینځه ځي ، نو x = 0 او y = 0 د سکرین مینځ دی.
