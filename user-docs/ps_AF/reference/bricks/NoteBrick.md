![یادښت](../../../media/bricks/note_brick2.png)

ستا په سکریپټ کې یو نظر یا یادونه اضافه کوي ترڅو ته سره مرسته وکړي چې په خپل کوډ کې د کومې برخې کار کولو یاد وساتي. دا ستا د پروژې په پرمختګ اغیزه نه کوي. دا د ځان لپاره د یو چپکونکي یادښت پریښودلو په څیر دی.
