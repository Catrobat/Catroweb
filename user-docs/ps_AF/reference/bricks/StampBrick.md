د دې کوډ بلاک په کارولو سره، ته په سکرین کې د خپل شخصیت د ظاهري کتنې کاپي پریږدي. دا د کاغذ پر سر د رنګین ټیمپ کولو په څیر دی او د ټیمپ ډیزاین کاپي یې پریږدي. په دې توګه، ته خپل شالید ته وده ورکوئ - ته کلون نه جوړوي!
