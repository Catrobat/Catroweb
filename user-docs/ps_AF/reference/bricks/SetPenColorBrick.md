![د قلم رنګ وټاکئ په سور 0، شین 0، آبي 255](../../../media/bricks/Set_pen_colour_to__red_0_green_0_blue_255_.png)

دا بلاک د کرکټر د قلم رنګ بدلوي. لکه د رسم پر مهال چې بل رنګ قلم راواخلې.

**سور، شین او آبي (RGB)**: RGB د سرې، شنې او آبي رڼا په ګډولو ډېر رنګونه جوړوي. د هرې رڼا ارزښت له 0 څخه تر 255 پورې کېدای شي:

- **سور**: د رنګ سره برخه. لوړه شمېره لا ډېر سور رنګ ورکوي.
- **شین**: د رنګ شنه برخه. لوړه شمېره لا ډېر شین رنګ ورکوي.
- **آبي**: د رنګ آبي برخه. لوړه شمېره لا ډېر آبي رنګ ورکوي.

د دغو دریو رنګونو بېلابېلې شمېرې سره ګډې کړه، څو نوی رنګ جوړ کړې. د بېلګې په ډول:

- `RGB(255, 0, 0)` سوچه سور دی.
- `RGB(0, 255, 0)` سوچه شین دی.
- `RGB(0, 0, 255)` سوچه آبي دی.
- `RGB(255, 255, 255)` سپین دی (درې واړه رڼاوې په پوره زور بلې دي).
- `RGB(0, 0, 0)` تور دی (هېڅ رڼا نشته).

د ډیجیټلي پردې ټول رنګونه د دغو دریو رڼاوو له ګډولو جوړېږي.
