![د پای مرحله کوډ بلاک](../../../media/bricks/finish-stage-brick.png)

دا کوډ بلاک ټول سکریپټونه ودروي او اوسنی مرحله یا صحنه پای ته رسوي. دا د دې په څیر دی چې ووایو، «د پروژې دا برخه پای ته رسیدلې ده.» هرڅه ودریږي، او پروژه یا بل صحنه ته حرکت کولی شي یا بشپړ پای ته ورسیږي. دا د هغه وخت لپاره وکاروئ کله چې ته غواړئ په خپل پروژې کې یو ځانګړی مرحله یا کچه پای ته ورسوي.
