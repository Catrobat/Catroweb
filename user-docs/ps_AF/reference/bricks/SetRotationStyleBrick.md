دا بلاک د څیز د تاوېدو ډول بدلوي. څیز پوره تاوېدای شي، یوازې کیڼې او ښي خوا ته مخ اړولی شي، یا بېخي نه تاوېږي. لکه دا ټاکل چې ستا کرکټر څنګه تاو شي.
