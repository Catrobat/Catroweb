![روڼوالی وټاکئ 50%](../../../media/bricks/Set_transparency_to_50_pct_.png)

دا بلاک ټاکي چې تر کرکټر شا پورې څومره لیدلی شې. په 0% کې کرکټر پوره ښکاري او څه شی ترې نه ښکاري. په 100% کې کرکټر نه ښکاري او هر څه ترې ښکاري. لکه د انځور روڼوالی چې بدلوې.
