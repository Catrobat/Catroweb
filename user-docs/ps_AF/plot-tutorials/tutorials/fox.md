کله چې رسم پیلېږي، هر حرکت د قلم په شان کرښه باسي. وروسته ماشین پر همدې کرښو پرېکول کوي.

دا ګیدړ یوازې له نېغو کرښو او تاوونو جوړ شوی. نېغې کرښې د «حرکت وکړئ \_\_\_ ګامه» په بلاک رسم کړه.

**لارښوونه**: د پروګرام د جوړولو پر مهال یې وازمویه.
