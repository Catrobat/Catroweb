کله چې رسم پیلېږي، هر حرکت د قلم په شان کرښه باسي. وروسته ماشین پر همدې کرښو پرېکول کوي.

زموږ څیز د 150 درجو خوا ته مخامخ دی.

په دې درس کې لومړی د پیشو د سر ښۍ خوا رسمېږي. په غور ورته وګوره. په پیل کې کږلېچ ډېر دی، نو څیز باید تر هرې وړې کرښې وروسته ډېر تاو شي. د سر لاندې خوا ته بیا تاوونه لږېږي. د سر کیڼه خوا بېرته ډېر کږلېچ لري. ځکه نو په دې برخه کې د تکرار درې کړۍ کاروو.

اوس کیڼ غوږ رسم کړه. دا غوږ یوازې نېغې کرښې لري. د «حرکت وکړئ \_\_ ګامه» بلاک وکاروه.

د غوږونو تر منځ برخه کږه ده. د هغې لپاره د تکرار بله کړۍ وکاروه.

وروسته ښی غوږ رسم کړه.

رسم بشپړ شو. په «رسمول ودروئ» بلاک یې پای ته ورسوه. په «رسم د SVG په توګه خوندي کړئ \_\_\_» یې په موبایل کې وساته.

اوس د SVG فایل د نقشو پرې کولو ماشین ته لېږلی شې.
