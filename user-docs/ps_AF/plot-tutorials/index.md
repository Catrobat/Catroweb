غواړې خپله نقشه جوړه کړې او پرې یې کړې؟ په دې درسونو کې به ووینې چې څنګه د کوډ په بلاکونو ماشین ته ووایې چې د رسم شویو کرښو پر سر پرېکول وکړي. هغه لارې او وسایل به زده کړې چې نقشه دې هماغسې پرې شي لکه څنګه چې دې رسم کړې ده.
