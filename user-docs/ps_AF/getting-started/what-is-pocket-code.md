Pocket Code د Catrobat اصلي اپ دی. وړیا دی او کوډ یې هر څوک کتلی شي. په موبایل یا ټابلیټ کې پرې لوبې، خوځنده انځورونه او داسې کیسې جوړولی شې چې لوستونکی پکې برخه واخلي. په Pocket Code کې **په بلاکونو پروګرام جوړوې**. د کوډ بلاکونه سره ونښلوه، لکه د معما ټوټې چې سره یوځای کوې. د پیل لپاره کوډ لیکلو ته اړتیا نشته!

په Pocket Code کې داسې پروژې هم جوړولی شې چې له پردې بهر ترې کار واخلې. د **لاسي کارونو د نویو وسایلو** په مرسته **د بڼو پرې کولو ماشین لپاره SVG فایلونه** جوړولی شې. په دې ډول له خپلو نقشو څخه داسې شیان جوړولی شې چې لاس پرې ولګوې. له پردې بهر نورې لارې هم وازمویه!

که کوډ لیکل زده کوې، نوې مفکورې ازمویې یا پروګرام جوړول ورزده کوې، په Pocket Code کې په اسانه او په خوند کوډ لیکلی شې.
