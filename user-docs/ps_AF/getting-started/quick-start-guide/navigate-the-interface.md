کله چې Pocket Code پرانیزې، دا اصلي پرده به ووینې.

![اصلي پرده](../../../media/getting-started/MainScreen-e1732269599192.jpg)

په پورتني ښي کونج کې د ![مرسته](../../../media/getting-started/Screenshot-2024-11-22-111748.png) نښه ده. دا نښه دې د Catrobat لارښود ته وړي، چې ګټورې لارښوونې پکې دي.

ورسره څنګ ته ![غورنۍ](../../../media/getting-started/Screenshot-2024-11-22-111804.png) ده. له هغې څخه «ترتیبات» پرانیزه. هلته ژبه بدلولی شې یا د رسم بلاکونه او نورې اسانتیاوې فعالولی شې.

لاندې هغه پروژه وینې چې تر ټولو وروستی بدلون دې پکې راوستی و. د ![سمون نښه](../../../media/getting-started/Screenshot-2024-11-22-111825.png) کېکاږه. د پروژې پرده به پرانیستل شي او خپلې پروژې ته به دوام ورکړې.

د پروژې د پیل لپاره د ![چلول](../../../media/getting-started/Screenshot-2024-11-22-111818.png) تڼۍ کېکاږه.

د خپلو خوندي شویو پروژو د لیدلو لپاره «پروژې» کېکاږه. ![په موبایل کې خوندي پروژې](../../../media/getting-started/Screenshot-2024-11-22-111832.png)

که د نورو خلکو پروژې لیدل او کارول غواړې، د Catrobat د شریکولو پر وېبپاڼه د ټولنې برخه پرانیزه. هلته به ډېرې ښې پروژې ووینې. ![د Catrobat ټولنه](../../../media/getting-started/Screenshot-2024-11-22-111847.png)

د نوې پروژې د جوړولو لپاره د ![زیاتولو](../../../media/getting-started/Screenshot-2024-11-22-143219.png) نښه کېکاږه.
