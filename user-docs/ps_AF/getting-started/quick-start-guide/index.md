Pocket Code د انځورونو په وسیله د پروګرام جوړولو اپ دی. په موبایل یا ټابلیټ کې پرې لوبې، خوځنده انځورونه او داسې کیسې جوړولی شې چې لوستونکی پکې برخه واخلي. د کوډ بلاکونه کش کړه او پر خپل ځای یې کېږده. په دې ډول له پخوانۍ تجربې پرته پروژه جوړولی شې. له غږونو، انځورونو او حرکتونو سره خپله مفکوره ژوندۍ کړه.

په دې لارښود کې به دا کارونه زده کړې:

- د اپ پرده وپېژنه.
- خپله لومړۍ پروژه جوړه کړه.
- څیزونه او شالیدونه وکاروه.
- د بلاکونو په مرسته امرونه ورکړه.
- خپله پروژه وساته.

Pocket Code د نویو زده‌کوونکو او ښوونکو لپاره ښه دی. نوې مفکورې پکې ازمویلی شې او د ستونزو حل او په ترتیب فکر کول زده کولی شې.
