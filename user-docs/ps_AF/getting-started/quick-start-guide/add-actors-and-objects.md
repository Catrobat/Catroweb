د + تڼۍ کېکاږه، څو خپلې پروژې ته نوی کرکټر یا څیز ورزیات کړې.

![کرکټر ورزیات کړه](../../../media/getting-started/FigurHinzufuegen.png)

په Pocket Code کې پروژې ته په څو لارو کرکټر یا څیز ورزیاتولی شې:

**رسم**: خپل کرکټر په **Pocket Paint** کې رسمولی شې. Pocket Paint د انځور رسمولو پروګرام دی ([د Pocket Paint په اړه نور معلومات](https://catrobat.org/pocket-paint/))

**بڼې**: له چمتو کرکټرونو او څیزونو څخه یو وټاکه ([د رسنیو د زېرمتون په اړه نور معلومات](../elements/medialibrary.md)).

**ګالري**: د خپل موبایل له ګالرۍ څخه انځور وټاکه.

**کتابتون**: په کتابتون کې داسې کرکټرونه او څیزونه موندلی شې چې له مخکې کوډ لري. که خپلې لوبې ته چمتو څیز غواړې، له همدې ځایه یې وټاکه. د بېلګې په ډول، داسې شمېرونکی شته چې شمېرې پر شا شمېري ([د کتابتون په اړه نور معلومات](../elements/medialibrary.md#له-رسنیو-زېرمتون-څخه-څیز-ورزیات-کړه)).

**کمره**: د موبایل په کمره عکس واخله او په لوبه کې یې د کرکټر په توګه وکاروه.

**کڅوړه**: کڅوړه اوس تشه ده. هغه کرکټرونه او څیزونه بیا کارولی شې چې مخکې دې پکې اچولي وي. د څیز ټوله کوډ لړۍ ورسره راځي ([د کڅوړې په اړه نور معلومات](../elements/backpack.md)).

**محلي لوبغاړي او شیان**: دلته داسې چمتو کرکټرونه شته چې په پروژه کې یې کارولی شې. دا لکه د رسنیو زېرمتون دی، خو له انټرنېټ پرته هم کار کوي.

**تش شی**: تش څیز هېڅ بڼه نه لري. د بل هر څیز په شان کوډ ورته لیکلی شې.

**محلي پروژې**: بله پروژه وټاکه. د هغې لومړی کرکټر او د کوډ لړۍ به ستا پروژې ته راشي.
