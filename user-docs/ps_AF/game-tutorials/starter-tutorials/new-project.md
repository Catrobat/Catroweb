په دې درس کې به له Pocket Code سره خپله لومړۍ پروژه جوړول زده کړې. په ګامونو به درته وښیو چې اپ څنګه ښکته او پرانیزې، او نوې پروژه څنګه جوړې کړې.

دا تر ټولو لومړی درس دی. پخوانۍ تجربې ته اړتیا نشته.

نو څه ته په تمه یې؟ موبایل راواخله او پیل کړه!

[PDF پرانیزه](../../../media/game-tutorials/New-Program.pdf)

### 1. Pocket Code ولګوه

لومړی په خپل موبایل کې Pocket Code ولګوه. د لګولو تڼۍ کېکاږه. د دې کار لپاره د Google حساب ته اړتیا لرې. موبایل اپ ښکته کوي او لګوي. دا کار ښايي د انټرنېټ له چټکتیا سره سم لږ وخت ونیسي.

![Pocket Code ولګوه (2)](../../../media/game-tutorials/New-Program-2.png)\
په Google Play Store کې «Pocket Code» ولټوه.\
[انځور پرانیزه](../../../media/game-tutorials/New-Program-2.png)

د لګولو وروسته به Pocket Code د اپونو په لړ یا د موبایل پر لومړۍ پرده ووینې. دا ستا په موبایل پورې اړه لري. د اپ نښه هر ځای ته وړلی شې.

### 2. اپ پرانیزه

![د Pocket Code اصلي پرده (1)](../../../media/game-tutorials/New-Program-1.png)\
کله چې اپ پرانیزې، بېلابېلې برخې به ووینې.\

### 3. نوې پروژه جوړه کړه

په لاندې ښي کونج کې د + ژېړه تڼۍ کېکاږه. په «سمه ده» کېکاږه څو پروژه جوړه شي.

![د نوې پروژې پرده](../../../media/game-tutorials/New-Program.png)\
خپلې پروژې ته نوم ورکړه او وټاکه چې پرده یې پرته (افقي) وي که نه.\
[انځور پرانیزه](../../../media/game-tutorials/New-Program.png)

### 4. بریالی شوې! خپله نوې پروژه دې جوړه کړه.

Pocket Code دې ولګاوه او د نوې پروژې جوړول دې زده کړل. اوس کوډ لیکل پیلولی شې!

د کوډ لیکلو لپاره لومړی څیز جوړ کړه. د **[نوي څیز](new-object.md)** په درس کې به یې ټول ګامونه ووینې.
