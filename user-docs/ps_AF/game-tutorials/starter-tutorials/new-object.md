په دې درس کې به زده کړې چې په څو لارو خپلې پروژې ته نوی څیز څنګه ورزیات کړې.

![نوی څیز](../../../media/game-tutorials/New-Object.png)\
په دې درس کې به زده کړې چې په څو لارو خپلې پروژې ته نوی څیز څنګه ورزیات کړې.\
[انځور پرانیزه](../../../media/game-tutorials/New-Object.png)

له دې مخکې Pocket Code ولګوه او د نوې پروژې جوړول زده کړه. که مرسته غواړې، د **[نوې پروژې](new-project.md)** درس وګوره.

*دا درس دلته د PDF په بڼه ښکته کولی شې:*

[PDF پرانیزه](../../../media/game-tutorials/New-Object.pdf)

### 1. نوی څیز جوړ کړه

لومړی خپله نوې پروژه پرانیزه.

د Pocket Code په اصلي پرده کې به خپله پروژه ووینې. که څو پروژې لرې، «پروژې» کېکاږه. بیا خپله نوې پروژه وټاکه. که پروژه دې لا نه وي جوړه کړې یا نورو معلوماتو ته اړتیا لرې، د **[نوې پروژې](new-project.md)** درس وګوره.

### 2. نوی څیز ورزیات کړه

اوس نوی څیز جوړولی شې. یوه کړکۍ به پرانیستل شي چې اووه لارې درښيي.

![نوی څیز (1)](../../../media/game-tutorials/New-Object-1.png)\
په لاندې ښي کونج کې د + ژېړه تڼۍ کېکاږه.\
[انځور پرانیزه](../../../media/game-tutorials/New-Object-1.png)

### 3. د څیز جوړولو لارې

![د څیز جوړولو لارې (2)](../../../media/game-tutorials/New-Object-2.png)\
له دغو لارو یوه وټاکه.\
[انځور پرانیزه](../../../media/game-tutorials/New-Object-2.png)

### 4. انځور رسم کړه

د اسانه پیل لپاره «رسم» وټاکه او یوازې یو ټکی رسم کړه. کله چې دې په Pocket Paint کې ټکی رسم کړ، یو ګام بېرته لاړ شه تر څو اپ وتړې.

### 5. نوم ورکړه

اوس خپل انځور ته نوم ورکړه.

### 6. ځای یې وټاکه

په ګوته یې کیڼې یا ښي خوا ته، یا پورته او ښکته وخوځوه، څو ځای یې وټاکې.

![د څیز ځای (3)](../../../media/game-tutorials/New-Object-3.png)\
په پورتني ښي کونج کې تڼۍ کېکاږه او خوندي یې کړه.\
[انځور پرانیزه](../../../media/game-tutorials/New-Object-3.png)

### 7. بریالی شوې! خپل نوی څیز دې جوړ کړ.

اوس داسې پروژه لرې چې څیز پکې دی او کوډ ورته لیکلی شې!

لومړی هغه بلاکونه وپېژنه چې کارولی یې شې. د **[د کوډ لومړي بلاکونه](first-bricks.md)** درس د بلاکونو ډلې درښيي. یا له خپلې لومړۍ پروژې سره سملاسي پیل کولی شې. د پیل له لړۍ یو مناسب درس وټاکه.
