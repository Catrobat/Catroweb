په دې درس کې به د ګل ګنډل زده کړې (73 x 74.2mm).

![انځور (11)](../../../media/embroidery-tutorials/image-11.png)

باید پوه شې چې د تکرار کړۍ څه ده او څنګه کار کوي.

د **[دایره](../embroidery-tutorials-beginner/circle.md)** درس درسره مرسته کولی شي.

که مخکې دې ګلدوزي نه وي کړې، [د ګلدوزۍ د پیل درسونه](../embroidery-tutorials-beginner/index.md) وګوره.

د نورو معلوماتو او د رسم د مفکورو لپاره نور درسونه وګوره.

*دا درس دلته د PDF په بڼه ښکته کولی شې*:

[ګل](../../../media/embroidery-tutorials/Flower.pdf)

### 2. اصلي بڼه

![ګل](../../../media/embroidery-tutorials/Flower.png)

### 3. دایرې

هر ځل چې د دایرې پیغام ولېږل شي، دا برخه چلېږي. دا هم د کوډ لړۍ ته ورزیاته کړه.

![ګل (1)](../../../media/embroidery-tutorials/Flower-1.png)

### 4. د رسم د پیل لپاره «چلول» کېکاږه!
