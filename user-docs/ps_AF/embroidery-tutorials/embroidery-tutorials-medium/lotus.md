په دې درس کې به د د نیلوفر ګل ګنډل زده کړې (64.8 x 64.8mm).

![انځور (12)](../../../media/embroidery-tutorials/image-12.png)

باید پوه شې چې د تکرار کړۍ څه ده او څنګه کار کوي.

که مخکې دې ګلدوزي نه وي کړې، [د ګلدوزۍ د پیل درسونه](../embroidery-tutorials-beginner/index.md) وګوره.

د نورو معلوماتو او د رسم د مفکورو لپاره نور درسونه وګوره.

*دا درس دلته د PDF په بڼه ښکته کولی شې*:

[د نیلوفر ګل](../../../media/embroidery-tutorials/Lotus.pdf)

### 2. اصلي بڼه

![د نیلوفر ګل](../../../media/embroidery-tutorials/Lotus.png)

### 3. د ګل پاڼې

هر ځل چې د ګل پاڼې پیغام ولېږل شي، دا برخه چلېږي. دا هم د کوډ لړۍ ته ورزیاته کړه.

![د لوټس (1)](../../../media/embroidery-tutorials/Lotus-1.png)

### 4. د رسم د پیل لپاره «چلول» کېکاږه!
