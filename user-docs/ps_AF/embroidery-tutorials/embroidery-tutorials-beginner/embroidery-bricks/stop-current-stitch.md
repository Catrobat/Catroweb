روانه ګنډنه دروي.

که له پرله‌پسې، زیګزاګ یا درې‌ګوني ګنډلو وروسته د ستنې ځای بدلول غواړې، دا بلاک وکاروه.

![اوسنۍ ګنډه ودروئ](../../../../media/embroidery-tutorials/Stop_current_stitch.png)

که دا بلاک ونه کاروې، تر منځ به یوه اضافي کرښه وګنډل شي.
