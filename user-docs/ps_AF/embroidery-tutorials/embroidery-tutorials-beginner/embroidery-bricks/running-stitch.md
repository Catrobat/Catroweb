ماشین پرله‌پسې ټانکې اچوي. ته د ټانکو اوږدوالی بدلولی شې.

اکثره د پرله‌پسې ګنډلو بلاک د خوځېدو له بلاک سره کاروې.

![ساده ګنډه پیل کړئ، اوږدوالی: 10](../../../../media/embroidery-tutorials/Start_running_stitch_with_length_10.png)

ماشین پرله‌پسې ګنډل پیلوي. ستنه په هرو **10 ګامونو** کې یوه ټانکه اچوي.

بیا ستنه **200 ګامه** ځي.

په پای کې **20 ټانکې** جوړېږي.

![ساده ګنډه پیل کړئ، اوږدوالی:](../../../../media/embroidery-tutorials/RunningStitch.png)

پرله‌پسې ګنډل کرښه ګنډل اسانه کوي. د تکرار کړۍ ته نوره اړتیا نه لرې.
